## 一、核心命题

> **"数"是计数操作在认知投影中的产物；数论结构 = 边束的可等分性结构。**

推论：12 的"神秘性"不在 12 本身，而在 **12 的约数表 `{1,2,3,4,6,12}`** ——它恰好允许三个正则三角剖分解。**数论的入口是整除，不是 12。**

这不是修辞。下文 §四给出的**整除强制定理**把这句话变成一条纯算术判据，§三给出的**计数投影算子 Π_c** 把它变成可直接运行的落地件。

## 二、层级标注规范（本篇的核心纪律）

同一个数字，按它**怎么来的**分成三档。**硬规则：越界项不得与读数项混列** —— 这正是 §0.1 的病根。

| 标注 | 含义 | 例 |
|------|------|-----|
| **预设** | L0 公理 / 操作假设，**不是数出来的** | `χ=2`（闭合）、`tri_only`（无洞=真三角剖分）、边-面规则、均匀饱和（全 `deg=C`） |
| **读数** | 对预设对象执行计数操作得到 | `12/30/20/42/50/62`、`Σ(6−deg)=12` |
| **越界（投影）** | 需 L0 之外的投影算子才得到 | 三维接吻数 12、`60°`、`16π` |

**凡出现"12"的段落，须能回答它是三者中的哪一个。** `knowledge.md` / `SPUM_系统总纲.md` / `knowledge-core.md` 三处把**读数**（12）写成了**L0 本体**（"拓扑常数"），故须加层级标注（见 §七）。

> **一项实测修正（2026-09-14）**：`χ=2` **不等于**"无边界"。开放 patch（`seed=patch`）的外边界在旋转系统里被一个 **12 边形面**包住，故其 `χ` **也是 2**（`V=19, E=42, F=25 ⇒ χ=2`）。"无边界"在旋转系统中表现为**所有面皆为三角**（`n_holes=0`）。因此 C1 的对象条件必须写成 **`χ=2 ∧ 无洞`**，单靠 `χ=2` 拦不住开放贴片。此结论由 Π_c 的反向控制实验给出（`l0_count.py` 自检第 ③ 项）。

## 三、计数投影算子 Π_c（NT-T5 落地件）

### 3.1 最小形式定义

把预设作为**显式入参**、读数作为**返回值**，两级分离：

```
Π_c : (G, obj_class) × presets → {value, preset, preset_ok, kind}
```

| 字段 | 含义 |
|------|------|
| `value` | 读数（int / 度数直方图）；预设不成立时为 `None` |
| `preset` | 成功时 = 已应用的预设串；失败时 = **挡住的那个预设** |
| `preset_ok` | 预设是否全部成立 |
| `kind` | `"readout"`（读数）或 `"undefined"`（预设不成立） |

**硬约束**：**预设不成立 ⇒ `value=None`、`kind="undefined"`** —— 不是 0，也不是"碰巧等于 12"。投影步因此可审计、可复算。

预设项（无默认值，不传 = 不设该预设）：

| 预设 | 判据 | 读法 |
|------|------|------|
| `closed_chi2` | `χ == 2` | 子图闭合 |
| `tri_only` | `n_holes == 0`（无非三角面） | 无边界（真三角剖分） |
| `uniform_C=C` | 全 `deg == C` | 均匀饱和 |
| `dmin=k` | 全 `deg >= k` | 无低度悬挂 |

### 3.2 落地件与冻结读数

实现：`openSPUM/src/l0/l0_count.py`（复用 `combinatorial_proto.audit`，不另写点数逻辑；纯整数，无浮点/角度/坐标）。

```
python l0_count.py selftest=1
python l0_count.py seed=icosa obj=V closed=1 tri=1 uniform=5
python l0_count.py seed=patch obj=sum6deg closed=1 tri=1
python l0_count.py table=1
```

| 输入 | 预设 | 读数 | 判词 |
|------|------|------|------|
| `seed=icosa`, `obj=V` | `closed_chi2 + tri_only + uniform_C=5` | **12** | `readout` |
| `seed=icosa`, `obj=E` / `obj=F` | 同上 | **30** / **20** | `readout` |
| `seed=icosa`, `obj=n_shells` | （无） | **1**（一个 5-正则分量） | `readout` |
| `seed=tetra`, `obj=sum6deg` | `closed_chi2 + tri_only` | **12** | `readout` |
| `seed=patch`, `obj=sum6deg` | `closed_chi2` | **30** | `readout`（χ=2 **成立**，但**非** C1 的 12） |
| `seed=patch`, `obj=sum6deg` | `closed_chi2 + tri_only` | `None`（挡在 `tri_only`） | `undefined` |
| `seed=icosa`, `obj=V` | `uniform_C=4` | `None`（挡在 `uniform_C=4`） | `undefined` |

**反向控制**：开放 patch 上「闭合」预设**成立而读数不是 12」**，证明 `closed_chi2` 单独**无判别力**；必须叠加 `tri_only`。若反向控制反而通过，说明测量无区分力（与 `l0_locality.py` 的可证伪性纪律一致）。

## 四、整除强制定理（数论进入 SPUM 的真正入口）

> 设 G 为闭合（`χ=2`）三角剖分（`tri_only`）子图，且**均匀饱和**（全 `deg=C`）。则 G 上存在整数节点数 N 的条件为
> `N(6−C) = 12`，即 **(6−C) | 12**；结合三角剖分约束 `C ≥ 3`，得 `C ∈ {3,4,5}`：
> `C=3 → N=4`（`K₄`）；`C=4 → N=6`（八面体图）；`C=5 → N=12`（二十面体图）。

**这是纯算术约束**，不依赖 π、不依赖角度、不依赖半径，也不依赖欧拉恒等式的几何解释。等价表述：**12 的约数表 `{1,2,3,4,6,12}` 决定正则三角剖分解的存在性。**

落地件 `forced_N(C)`（`l0_count.py` §4）实测：

| C | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| N | — | — | — | **4** | **6** | **12** | — | — | — |

（`—` = 无正整数解：`6−C ≤ 0` 或 `(6−C) ∤ 12`，或 `C < 3` 非三角剖分。）

**读法**：`N(6−C)=12` 是**计数重言**（对 C1 除以均匀性），不是外部定理；`(6−C) | 12` 是它的**整数可解性**条件。整除在此不是"算术技巧"，而是**边束能否被等分为同构子束**的判据（见 §五）。

## 五、基本数论族归约表

每条 = 对象 → 计数操作 → 数值 → 约束（与 `图论/spum-计数关系.md` 的四元组格式一致）。

| 概念 | V⁺/V⁻ 归约 | 图论化表述 | 状态 |
|------|-----------|-----------|------|
| 自然数 n | n 次 V⁺ 的累积计数（创生序列） | 长度 n 的路径 `P_n` 的边数 | ✅ |
| 加法 a+b | 两段边束首尾相接 | 路径衔接（V⁺ 拼接） | ✅ |
| 减法 a−b | 从边束尾部 V⁻ 掉 b 条 | 路径截断 | ✅ |
| 乘法 a×b | a 份长度 b 的等长边束并置（批量 V⁺） | 拷贝并置 | ✅ |
| 整除 `b\|a` | 长度 a 的边束可否等分为 b 份**同构**子束 | 长度可分解 `a=b·k` | ⚠️ 见 NT-T1 |
| 素数 p | 长度 p 的边束不可等分为 `b≥2` 份 | 无非平凡因子 | ⚠️ 见 NT-T1 |
| gcd / lcm | 两束的最大公共等分节 / 最小公共倍数节 | 长度 gcd / lcm | ✅ |
| 同余 `a≡b (mod n)` | 在 `C_n` 环上落位相同 | 环上同余类 | ✅ |
| 丢番图方程 | 每步 `+Δ` 的**可达性**（能否凑出目标长度） | 生成元半群 | ⚠️ 见 NT-T2 |
| 计数关系 | 对象 → 计数操作 → 数值 → 约束 | 四元组（C1–C10） | ✅ |
