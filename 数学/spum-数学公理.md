## 一、唯一公理种子：存在即关系

### 1.1 本体论基底

**SPUM_seed**：存在即关系。没有被连接的东西不存在——或者说，"存在"这个谓词只能赋予那些参与至少一条边关系的节点。

这不是哲学声明——是 SPUM 数学的形式化起点。传统集合论从"元素属于集合"（∈）出发，SPUM 数学从"节点连接节点"（⟨v₁, v₂⟩ ∈ ε）出发。两种数学的分叉点就在这一个选择上。

### 1.2 形式化定义

```
G = (V, E)    网络——SPUM 数学的唯一基础对象
V             节点集——拓扑关节
E ⊆ V × V    边集——二元连接关系

∀ v ∈ V, v 的度数 deg(v) = |{e ∈ E : v ∈ e}|
```

**不预设**：
- 没有天然空间维度（"三维"不是先验容器）
- 没有连续统（不存在 ℝ 作为先验域）
- 没有无穷集合（所有集合由有限节点的连接关系生成）
- 没有独立属性（节点的全部属性 = 其边的集合）

### 1.3 零度公理

```
deg(v) = 0  ⇔  v ≡ ∅
```

孤立无连接节点**等价于**虚无。不是"存在但没有被观测到"——是**不存在**。

推论：
1. 节点的全部信息由它的边集合决定——没有"自带属性"
2. 创建第一个边 = 同时确认两个端节点的存在
3. 删除节点最后一条边 = 节点消失

这是关系第一性原则的形式化表述：关系定义存在，而非"存在先于关系"。

### 1.4 加减本原：宇宙的唯一底层操作

```
V⁺(v₁, v₂):  E → E ∪ {(v₁, v₂)}     加边——建立连接
V⁻(v₁, v₂):  E → E \ {(v₁, v₂)}     删边——断开连接
```

宇宙在 [L0] 层面只做两件事：**建立连接、断开连接**。所有更复杂的操作——包括人类感知的"运动""变化""增长""衰退"——都是 V⁺/V⁻ 在多帧上的累积投影。

**这对应算术的本源**：加法 = 加边，减法 = 删边。加减不是人类发明的运算——是对宇宙底层操作的摹写。

## 二、基础运算体系：全部还原为 V⁺/V⁻

### 2.1 加法 = 新增节点 + 新增边

```
加法 a + b：
  创建新节点 v_new（或选中已有节点）
  执行 a 次 V⁺ 操作将其连接到网络
  执行 b 次 V⁺ 操作进一步连接
  结果 = 网络总度数增加了 a + b

等价于：网络的结构扩张，总边数增加
```

### 2.2 减法 = 移除节点 / 删除边

```
减法 a - b：
  从目标子图中执行 b 次 V⁻ 操作（删除 b 条边）
  若某节点度数降至 0 → 自动消失（零度公理）
  结果 = 网络总度数减少了 b

等价于：网络的结构消解，总边数减少
```

### 2.3 乘法 = 同一组边的重复叠加

```
乘法 a × b：
  将"添加一组 b 条边"的操作重复 a 次
  等价于：多层并行的关联叠加

  不是"a 组 b 个元素"的计数——
  是"a 层嵌套、每层 b 条边"的拓扑结构
```

### 2.4 除法 = 批量同步删边

```
除法 a ÷ b：
  对包含 a 条边的子网络，每次批量删除 b 条边
  重复直到剩余不足 b 条
  结果 = 可以完整执行多少次批量删除

等价于：连续减法，每次减去相同数量的边
```

### 2.5 幂次/对数 = 多层嵌套拓扑递归

```
幂次 a^b：在 a 条边构成的底层上，嵌套 b 层相同拓扑结构的重复叠加
对数 log_b(a)：从 a 条边的嵌套结构中，剥去 b 层嵌套需要多少次操作
```

### 2.6 微积分批判：不属于 SPUM 原生数学

传统微积分基于三个 SPUM 数学拒绝的前提：

| 传统微积分预设 | SPUM 数学的替代 |
|--------------|---------------|
| 连续函数 f: ℝ→ℝ | 离散帧序列：每帧独立跃迁，帧间无中间态 |
| 无穷小 dx → 0 | 离散差分 τ：一帧的跨度，不可再分 |
| 极限 lim | 帧序列遍历：从第 τ₀ 帧到第 τₙ 帧，逐帧观察 |
| 导数 df/dx | 帧差 ΔS/τ：一帧内的 S 向量变化量 |
| 积分 ∫f dx | 帧累加 Σ ΔS：逐帧变化量的累积和 |

微分是强行假定极小平滑差值的虚构工具。积分是虚构无穷小微元累加。它们适合人类在连续认知范式中的近似计算，但**不能描述离散网络的真实演化**。

SPUM 数学的"微积分"就是逐帧追踪 V⁺/V⁻ 的 ΔS 序列——不需要极限、不需要连续统。

## 三、反连续公理：宇宙无天然连续性

### 3.1 陈述

**不存在天然连续空间、无穷光滑区间、或无限可分微元。** 所有变化都是离散边的增减跃迁。

### 3.2 推论

1. **ℝ 是认知构造物**：实数集是对离散度的强行连续插值——[L1] 认知投影，不是 [L0] 本体
2. **"趋近于零"无物理意义**：任何可观测的量都有最小变化单位 = 一条边。变化要么发生（Δσ ≠ 0），要么不发生（Δσ = 0）
3. **"无穷"是有限集合的极限外推**：宇宙在任何时刻是有限网络——无穷只是一个方向性概念（"可以一直加下去"），不是一个"已经存在的东西"
4. **帧间无插值**：帧 τ 和帧 τ+1 之间没有"半帧"或"0.3 帧"——网络状态要么在 τ，要么在 τ+1

### 3.3 与传统数学的根本分叉

```
传统数学：      连续统 ℝ → 函数 → 极限 → 微积分 → 所有数学分支
SPUM 数学：     加边 V⁺ / 删边 V⁻ → 离散帧 → 网络拓扑 → 所有数学分支
```

两条路从根部分叉——不能用其中一条路上的概念去"证明"或"否定"另一条路。SPUM 数学的检验标准不是与传统公理系统的一致性，而是**与 ⟨P, ε⟩ 宇宙本体的对应精度**。
