# SPUM 数学范畴论——范畴的 ⟨P,ε⟩ 还原

> 归约路径：存在即关系 → 范畴 = 带组合结构的有向子图 → 对象 = 关系束（Yoneda）→ 函子 = 跨子图映射 → 自然变换 = 帧级一致变换
>
> 定位声明：范畴论**不作为公理、不作为基础**进入 SPUM。它被收编为 L0.5 描述层语言——把"结构保持翻译"统一形式化的语法工具。凡不能还原为 V⁺/V⁻ 操作序列的范畴概念，一律不引入。
>
> 节点：MATH-015~018 | 日期：2026-08-22

---

## 一、定位：三层声明

1. **不进 L0**：范畴论不新增本体。宇宙只有 ⟨P,ε⟩ 关系网络 + V⁺/V⁻ + 帧演化。范畴是网络的子图类，不是新的实体层。
2. **不加公理**：SPUM2611 的输入清单（A1-A5、M0）不增加条目。范畴论的组合律不是新公理——是既有路径结构上的约束描述。
3. **只作 L0.5 描述层语法**：地位等同于 L1 投影层的球面积公式与 π——显式声明的认知层约定，非本体组成部分。任何使用范畴论记法的地方，须显式声明，无隐藏假设。

## 二、核心还原：范畴 = 带组合结构的有向⟨P,ε⟩子图

### 2.1 逐项对应

| 范畴论概念 | ⟨P,ε⟩ 还原 |
|-----------|-----------|
| 对象 A | 节点束 V_A ⊂ V——网络中的局部结构（非独立实体，身份 = 全部关联边） |
| 态射 f: A→B | 有向路径类——从 A 到 B 的边序列等价类 |
| 组合 g∘f | 路径拼接——f 的终点与 g 的起点重合时的边序列连接 |
| 恒等 1_A | 长度 0 的自路径 |
| 结合律 (h∘g)∘f = h∘(g∘f) | 路径拼接的天然结合性——拼接顺序不改变结果边序列 |
| 单位律 1_B∘f = f = f∘1_A | 零长度拼接不改变路径 |

### 2.2 组合律不是新公理

范畴论把"组合存在、结合、有单位"当作定义的一部分。SPUM 还原后，这三条不是宇宙的新约束——它们是对"路径拼接"这一网络既有操作的性质描述：

- **结合性**：路径拼接天然结合——先拼 1-2 再拼 2-3，与先拼 2-3 再拼 1-2，得到同一路径。
- **单位**：零长度路径是平凡存在，不需要新的存在声明。
- **唯一新增项是有向性**：有向边 = 无向边 + ∇σ 方向（GT-011 的既有翻译），不是新的边类型。

### 2.3 对象为什么没有内容（Yoneda 的还原）

范畴论的核心洞见：对象（等价意义下）由它到所有对象的态射唯一确定——对象内部没有"内容"。这正是 SPUM 零度公理的范畴论镜像：

```
零度公理（SPUM）：deg(v) = 0 ⟺ v ≡ ∅ —— 无连接即不存在
Yoneda 引理（范畴论）：对象 A ≅ Hom(−, A) —— 对象由关系束唯一确定
```

还原：对象的身份 = 它的关系束（所有入射/出射边的集合）。两个对象若关系束完全相同，则在同一网络中不可区分——即同一个对象。**不是"对象承载关系"，是"关系定义对象"。** Yoneda 不增加任何本体，它只是把"关系定义存在"翻译成范畴论记法。

> **反向警戒**：经典范畴论把对象抽空为"只有恒等射的占位符"——这在 SPUM 中不可接受。对象不是占位符，对象是关系束的化身。抽空对象 = 回到"实体在前、关系在后"的旧范式。

## 三、三个派生概念的还原

### 3.1 函子 = 保持组合结构的子图映射

定义：F: C → D 是对象→对象、态射→态射的映射，保持组合与单位。

⟨P,ε⟩ 还原：F 是把子图 C 的节点束映射到子图 D 的节点束、路径类映射到路径类的**结构保持映射**——C 中可拼接的路径在 D 中仍可拼接。

**用途（引入范畴论的最大理由）**：仓库里已有的跨模块桥接正是函子：

- G_econ ⊂ G_social 的嵌入（经济学子图 → 社会子图）——包含函子
- L0 → L1 投影（节点度数 → 球体体积）——投影函子（认知层约定）
- 五形诊断：从网络结构提取 S 向量——函子

函子把"跨子图翻译"从叙述性描述升级为可检验的保持性条件：**翻译是否保持组合，是可验证的**。

### 3.2 自然变换 = 帧级一致变换

定义：α: F ⇒ G 是函子间的一族态射 α_A: FA → GA，使方块图交换。

⟨P,ε⟩ 还原：F、G 是两条并行的子图映射，α 是对每个节点束同时施加的一族 V⁺/V⁻ 变换——在同一帧内完成、且与两条映射的路径保持兼容。

用途：两套翻译方案之间的一致性比较（如经济学 σ_econ 与 社会学 σ_social 两套密度读法的关系）——α 的存在说明两种读法逐帧可互换而不破坏结构。

### 3.3 极限/余极限 = 有限子图上的通用构造

- 拉回（pullback）= 共享前驱结构：同时投影到同一目标的两个节点束的公共最大子结构
- 推出（pushout）= 共享后继的合并
- 积/余积 = 结构并/结构交的通用形式

⟨P,ε⟩ 还原：都是纯子图构造——公共邻居、合并、并交，不引入新实体。

> **警戒**：经典范畴论的极限常涉及"所有对象"的全局集合（如 Set 中的完备性）。SPUM 只保留当前帧有限子图内的通用构造；任何涉及"全体""一切"的全局极限一律禁止（潜无穷原则）。

### 3.4 伴随 = V⁺/V⁻ 对偶在映射层的投影

F ⊣ G（F 左伴随 G）在 SPUM 中的原型：创生/湮灭对偶。V⁺ 与 V⁻ 是同一张网上的对偶操作——每个 V⁺ 必对偶于某 V⁻（全局守恒）。伴随对是这种对偶性在函子层（跨子图翻译层）的推广：一个方向建边（F），其对偶方向删边（G），二者在结构保持的意义上互逆。

> **警戒**：伴随性是范畴论最"漂亮"的概念，也最容易被当作普适论证滥用。SPUM 只在能明确写出 V⁺/V⁻ 操作语义的场合使用伴随记法。

## 四、七大分界在范畴论上的落实

| 分界 | 范畴论的旧范式风险 | SPUM 落实 |
|------|------------------|----------|
| 逻辑优先 vs 事实优先 | 普适性质论证 → "定义即存在" | 每个范畴概念须给出 V⁺/V⁻ 操作语义才成立 |
| 连续统 | 函子空间、极限过程隐含连续构造 | 只允许有限子图上的离散构造 |
| 实无穷 | Set、全体范畴的范畴、大范畴 | 禁止——网络在任何时刻有限 |
| 对象-态射二元论 | 对象 = 无内容占位符 | 对象 = 关系束的化身（零度公理） |
| 数学审判官 | "框架最一般，所以最真" | 宇宙存在是唯一锚点，框架一般性 ≠ 真 |
| 可还原性 | 纯结构抽象无需操作语义 | 每个概念必须落到帧内 V⁺/V⁻ 序列 |

## 五、引入边界（使用规范）

1. **三不进入**：不进 L0 本体、不增加公理、不引入无法还原的概念。
2. **声明制**：任何使用函子/自然变换等记法的地方，须在文档中显式声明"此为 L0.5 描述层记法"——与 SPUM2611 输入清单的声明制一致，无隐藏假设。
3. **产出检验**：一个范畴论概念在 SPUM 中保留，当且仅当它能产出新结论（新的多路径锁定点、新的跨模块一致性条件），而非仅为旧结论换新名。
4. **有限性约束**：所有构造限于当前帧的有限子图；任何涉及"全体""一切"的构造自动出局。
