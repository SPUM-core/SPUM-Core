## 二、格式规范

沿用三层格式：

```
【原文】{法华经原文}
【译文】{现代汉语直译}
【SPUM】{⟨P, ε⟩ 拓扑翻译}
```

## 三、跨经典边标注

在法华经 SPUM 翻译中，遇到与已有佛家节点相关的概念时，必须显式标注引用：

- 随众生心 → 引用 BUD-005（楞严经）
- 五蕴 = S 向量 → 引用 BUD-008（心经）
- 凡所有相 = [L1] 投影 → 引用 BUD-013（金刚经）
- 见性 = 自指边裸采 → 引用 BUD-021（坛经）
- 一即一切 = 局部全息 → 引用 BUD-024（华严经）
