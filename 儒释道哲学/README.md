所有儒释道经典 SPUM 释义必须：

1. **原文标注**：引用经典原文作为归约起点
2. **归约路径完整**：从传统概念 → SPUM 中间层 → R1-R9 根节点的完整链条
3. **[L0] 还原表**：每篇末尾必须有传统概念 ↔ 图论/拓扑对应的对照表
4. **不做辩护律师**：经典中与 SPUM 不可调和的部分明确指出，不强行调和
5. **区分直觉与推导**：标注哪些是古人的直觉准确命中（如"邻虚尘"≈κ粒子），哪些是 SPUM 的严格推导
