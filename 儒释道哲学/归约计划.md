## 一、什么是"归约"

在 SPUM 语境下，**归约**不是"用科学解释哲学"，而是：

**把经典中已经直觉到的宇宙结构，用精确的图论语言重新写出。**

三步归约链：
```
经典原文 + 传统注释
    │
    ▼ M1 语义对应
SPUM 定性定义（用 R1-R9 的语言重述经典概念）
    │
    ▼ M2 图论精确化
[L0] 图论/拓扑表达（用 ⟨P, ε⟩ 的精确数学语言）
    │
    ▼
[L0] 还原表（传统概念 ↔ 图论/拓扑对应的最终对照表）
```

**归约完成的判断标准**：
1. 经典的核心概念全部追溯到 R1-R9 的某个或多个根节点
2. 归约链闭合——M1 → M2 → [L0] 无跳跃、无模糊词
3. 不可调和的部分被明确标注（不做辩护律师）
4. 该经典在 skill.md 中的节点已注册、子网边已绘制

## 四、归约方法论

### 4.1 单部经典的归约流程

每部经典的归约遵循统一的六步流程：

```
Step 1: 原文提取
  └─ 阅读经典，提取涉及宇宙论/本体论/认知论/社会网络论的核心段落
  └─ 标注原文出处（章节、通行本行号）
  └─ 输出：核心段落清单 → 存入 草稿/{经典名}草稿

Step 2: M1 语义对应
  └─ 对每个核心概念，找到 SPUM 的对应概念（R1-R9 语言）
  └─ 不是"翻译"，是证明两者在描述同一结构
  └─ 输出：M1 映射表

Step 3: M2 图论精确化
  └─ 对每个 M1 映射，写出精确的图论/拓扑定义
  └─ 使用 ⟨P, ε⟩、σ、V⁺/V⁻、Σ(6−deg)、S 向量、H 多面体等
  └─ 输出：M2 精确定义表

Step 4: [L0] 还原表
  └─ 创建最终对照表：传统概念 ↔ 图论/拓扑对应
  └─ 格式与 spum-道德经.md §[L0] 终极还原 一致
  └─ 输出：[L0] 还原表

Step 5: 冲突标注
  └─ 明确指出经典中与 SPUM 不可调和的部分
  └─ 标注原因：是 [L1] 时代局限、还是确证错误
  └─ 输出：冲突清单（可能为空）

Step 6: 节点注册
  └─ 在 skill.md 中注册新节点（分配 ID、填写 M1/M2 定义）
  └─ 绘制该经典的子网边
  └─ 更新 §九 子网全图
  └─ 更新共享根节点矩阵（如发现新的跨域连接）
```

### 4.2 归约质量标准

| 维度 | 合格标准 | 违规标记 |
|------|---------|----------|
| **闭合性** | M1→M2→[L0] 链条完整，无跳跃 | [R-OPEN] 归约链断裂 |
| **无伪加载** | 不出现 8 种典型错误模式（容器思维、力驱动、连续统等） | [R-PSEUDO] 伪加载污染 |
| **可追溯性** | 每个 M2 定义都能追溯到 R1-R9 的具体根节点 | [R-ORPHAN] 孤儿概念 |
| **诚实性** | 不可调和部分被明确标注，不做辩护律师 | [R-APOLOGIST] 强行调和 |
| **一致性** | 与该分区其他已完成经典不矛盾，与 R1-R9 底板一致 | [R-CONFLICT] 跨经典矛盾 |

### 4.3 草稿制度

```
草稿/{经典名}草稿
```

草稿文件的作用：
- **原文笔记**：核心段落的摘录和页码
- **初步 M1 映射**：还没有精确化的语义对应
- **归约难点记录**：哪些概念暂时找不到精确 R1-R9 对应
- **跨经典关联**：与其他经典的交叉引用

草稿是归约的**工作区**——不需要符合质量标准，允许模糊和不完整。草稿 → 正式 spum-*.md 的转换，意味着归约链已闭合。
