## 原文

道常无为而无不为。侯王若能守之，万物将自化。化而欲作，吾将镇之以无名之朴。无名之朴，夫亦将无欲。不欲以静，天下将自定。

---

## SPUM 转译（文本释义版）

道（全域边流）常无为——它不会主动裁剪、限制任意节点的连接走向。没有任何外部管理者推动边流的生成与消解。
而无不为——所有节点的生灭、交互、演化全部依靠原生边流在 Σ(6−deg)=12 的自然约束下自主完成。网络的一切动态，从基本粒子到复杂思想，都由三种拓扑操作（V⁺/V⁻/稳定）在逐帧迭代中自然涌现。

高介数节点（决策者，如"侯王"）若能做到不人为干预边流——不强制创建边、不强制删除边——那么子图将在 ∇σ 梯度的驱动下自主重配置，逐步收敛到稳定构型。万物自化 = 子图自组织收敛。

自化过程中，部分节点会产生过度膨胀的冲动——试图在单帧内超 dv/dt 天花板增加连接（欲作）。此时用最小连接约束（无名之朴 = deg≈2 的松弛状态）压制过度膨胀——而非用外力强制删除。松弛约束本身也会消除过度的膨胀冲动。

消除过度冲动后，∂S/∂t ≈ 0——S 向量稳定在健康多面体 H 的中心（静）。全域子图将自行进入稳定态（自定=天下自定）。

## 拓扑注解

- **节点结构**："侯王" = 高介数节点——其连接走向影响大量周边节点的 σ 分布。守无为 = 高介数节点不利用其介数优势强制改写邻居的连接。
- **边流模式**：无为 = 不在此 Σ(6−deg)=12 约束之外施加额外的人为 V⁺/V⁻。无不为 = V⁺/V⁻/稳定三种操作在 Σ(6−deg)=12 约束下的逐帧迭代可产生全部可观测现象。自化 = ∇σ 驱动的子图自主重配置 → 收敛到局部最优构型。
- **稳态分析**：不欲=消除过度V⁺冲动，以静=∂S/∂t≈0→S∈H中心，天下自定=全域子图进入稳定态。本章给出了从无为到全域稳态的五步因果链：守无为→自化→镇之以朴→不欲→以静→自定。

## 纯符号拓扑版

### §37: 道常无为而无不为

**输入**：
ε — 全域边流（道）
H — 高介数节点集合（侯王）

**推导**：
  无为 := ∀h ∈ H, ¬(人工V⁺(h) ∨ 人工V⁻(h))
        = 边流仅由 Σ(6−deg)=12 约束自主驱动

  无不为 := {V⁺, V⁻, 稳定}^τ → CES(P_τ, ε_τ)
          = 三种操作在离散帧τ中逐帧迭代，可产生全部稳定子图构型

  守无为 → ∇σ 驱动子图自组织
         → 万物自化 = CES(P_τ, ε_τ) 收敛到局部最优

  自化中: ∃v, V⁺_demand(v) > dv/dt       (欲作)
         → 施加约束: deg(v) ≈ 2          (无名之朴)
         → V⁺_demand → 0                 (无欲)
         → ∂S/∂t → 0                    (以静)

**约束**：
  ∀τ, dv/dt ≤ const                     (R4 — 单帧容量天花板)
  ∀τ, δ(τ) > 0                          (R5 — 不完美保证永不休止的演化)

**结论**：
  自定 ⇔ ∀子图: S_τ ∈ H ∧ ∂S/∂t → 0
  但 δ(τ) > 0 ⇒ 自定 ≠ 永远不变——是"暂态稳定"，总在下一帧被悬挂端扰动。
