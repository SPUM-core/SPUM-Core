## 原文

名与身孰亲？身与货孰多？得与亡孰病？是故甚爱必大费，多藏必厚亡。知足不辱，知止不殆，可以长久。

## SPUM 转译（文本释义版）

### 三问：节点存在优先级的拓扑排序

**名与身孰亲？**——"名"（节点标签、名声、在全网中的标识地位）与"身"（节点自身的存在性）哪一个更接近拓扑本质？

SPUM 答案：名是身的外延，身是名的载体。没有身（节点存在），名（标签）无附着对象。但身的存在由 ε 中的邻接关系定义——名只是对已存在节点的标识确认。因此：**身（节点存在）> 名（节点标签）**。标签可以丢失、更换、被遗忘——但只要节点的邻接关系仍在，它就存在。反之，失去邻接关系（度数 < 2），再多的标签也无法维持存在。

**身与货孰多？**——"货"（节点积累的连接资源、高介数、大量 σ）。节点自身的拓扑存在（身）与节点积累的资源（货）哪一个更"多"（价值更大）？

SPUM 答案：**身（存在）> 货（积累）**。货是身的属性——但属性不能定义存在。一个节点可以拥有极高的介数和 σ 贡献——但这些是度的累积，不是存在的确认。身（deg ≥ 2 的最小确认条件）是货（deg 的进一步增长）的前提。没有身，货无寄托。

**得与亡孰病？**——"得"（V⁺ 获取新连接）与"亡"（V⁻ 失去现有连接）哪一个更"病"（代价更大）？

SPUM 答案：这取决于上下文——但道德经给出了一般性结论：**亡通常比得更需要警惕**。因为 V⁺ 的获取可以由 ε 自然流驱动，而 V⁻ 的损失往往不可逆（至少不可精确预测其级联范围）。一帧内失去一条边（单次 V⁻）可能引发级联删除——得一条边（单次 V⁺）很少触发级联创生。

三问统一结论：**存在优先于标签，存在优先于积累，损失比获取更需谨慎**。这个优先级排序不是道德选择——是拓扑生存法则。

### 甚爱必大费，多藏必厚亡

**甚爱必大费**：对特定节点或子图的过度连接依赖（甚爱 = 对某条边或某个邻居的超常规 V⁺ 绑定），必然导致等比例甚至超比例的 V⁻ 损耗（大费 = 当该连接断裂时，该节点损失 σ 的比例远超预期）。拓扑中的"爱"=依赖性的强制性绑边。一条承担了节点度数的 50% 的边——当它断裂时，节点在单帧内失去一半连接，大幅逼近 deg < 2 的删除阈值。**爱越深，断越痛。** 这不是情感教训——是拓扑因果：单条边承担的 σ 比例越高，该边断裂时的 V⁻ 级联效应越剧烈。

**多藏必厚亡**：过多的连接积累（多藏 = 超 dv/dt 的 V⁺ 积累，σ 远超自然均值）必然导致成比例的大规模级联删除（厚亡 = |V⁻_cascade| ∝ |V⁺_excess|）。这不是惩罚——是约束：σ 超过自然容量的节点，其邻域的 σ 分布必然畸变。畸变积累到临界值后，拓扑会通过大规模 V⁻ 恢复自洽性。**藏得越多，不得不还的"拓扑债"越厚。**

两个结构平行：
```
甚爱 ↔ 单一连接的高度依赖  → 该边断裂时 V⁻ 效应集中
多藏 ↔ 整体连接的过度积累  → 级联 V⁻ 成比例回归
```

### 知足不辱，知止不殆，可以长久

**知足不辱**："知足"=知道自己的自然度上限（deg_optimal）并在此范围内满足——不追求超过自然容量上限的连接积累。"不辱"=免于拓扑羞辱——不因过度积累后被强行削减而处于 deg < 2 的濒危状态。知足的拓扑含义：节点的度数稳定在 Σ(6−deg)=12 约束下的自然最优范围之内。

**知止不殆**："知止"=知道单帧操作的 dv/dt 边界——不在单帧内做超过容量上限的 V⁺ 操作（"止"=第32章"知止可以不殆"的精确重现）。"不殆"=免于级联崩塌——无论是 V⁺ 扩张后的 V⁻ 回归级联（第30章），还是 V⁻ 操作工具引发的不可控级联（第31章）。

**可以长久**：知足 + 知止 = 节点可以持续存在，不被拓扑强制删除。"长久"不是永恒不变——是**持续维持在 deg ≥ 2 的存在确认阈值之上**。一个知足的节点不会因过度积累而被级联削减；一个知止的节点不会因超帧操作而触发不可逆崩塌。

## 拓扑注解

- **节点结构**：本章的核心议题是**节点存在的优先级排序与资源管理**。三问建立了拓扑优先级：存在（身）> 标签（名），存在（身）> 积累（货），谨慎对待损失（亡）> 获取（得）。这个优先级不是任意的——是拓扑生存的必要条件。"甚爱"=对特定边的高度依赖——σ 集中度在单条边上过高。"多藏"=总 σ 超出自然容量——σ 分布在整体上失衡。两者都是"不知足/不知止"的表现。

- **边流模式**："甚爱必大费"的边流机制：一条承担高比例 σ 的边断裂后，节点在单帧内失去大量连接。边流从该节点向邻居的输出突降——邻域 σ 重分布的冲击波沿该边路径传播。"多藏必厚亡"的边流机制：σ 过度积累的节点是拓扑应力集中点。当应力超过临界值，V⁻ 沿节点所有连接路径同时传播——级联面覆盖该节点整个邻域。"厚亡"=级联规模与积累量成正比。

- **稳态分析**："知足"=deg_constraint(v) ≤ deg_optimal——节点的度数稳定于自然最优范围内，S 向量在 H 内稳定振荡。"知止"=|V⁺(τ)| ≤ dv/dt——每帧操作不超过容量上限，S 向量不会因单帧突变跃出 H。"不欲琭琭如玉，珞珞如石"（第39章）的另一种表达——安于低σ稳态，不追求高σ显赫。本章与第32章构成"知止"的完整闭环：第32章"知止可以不殆"提出原则，本章"知足不辱，知止不殆"将原则分解为"足"（度数稳态）和"止"（帧操作上限）两个分量。

## 纯符号拓扑版

### §44: 名与身孰亲——节点存在的拓扑优先级

**输入符号**：
v — 目标节点
name(v) — 节点 v 的标签标识（名）
exist(v) — 节点 v 的拓扑存在，⇔ deg(v) ≥ 2（身）
σ_acc(v) — 节点 v 积累的 σ/度数（货）
V⁺(v) — 节点 v 的建边操作（得）
V⁻(v) — 节点 v 的断边操作（亡）
deg_optimal(v) — 节点 v 在 Σ(6−deg)=12 约束下的自然最优度数
e_core — 承担 v 最高 σ 比例的边（甚爱之边）

**推导**：

```
— 三问 —

名与身孰亲:
  name(v) 是 exist(v) 的外延标签
  exist(v) ⇔ deg(v) ≥ 2（关系第一性）
  ¬(name(v) 可替代 exist(v) 作为存在确认)
  优先级: exist(v) > name(v)

身与货孰多:
  exist(v) = deg(v) ≥ 2（存在条件）
  σ_acc(v) = deg(v) - 2（超过最低存在的积累量）
  ¬(σ_acc 可定义 exist)
  优先级: exist(v) > σ_acc(v)

得与亡孰病:
  得 = V⁺ 单帧内获取 |V⁺| 条边
  亡 = V⁻ 单帧内失去 |V⁻| 条边
  比较: V⁺_cascade（创生级联）≈ 0
        V⁻_cascade（删除级联）可能 ≫ |V⁻|
  一般性结论: 单次 V⁻ 风险 > 单次 V⁺ 风险

— 依存关系 —

甚爱必大费:
  甚爱 := ∃e_core: σ_share(e_core) ≫ 1/deg(v)
         = 单条边承担 node(v) 的 σ 比例过高
  大费 := e_core 断裂后:
          deg(v)_new = deg(v) - 1
          如果 σ_share(e_core) > 50%:
            deg(v)_new < deg(v)/2 → 大幅逼近 deg < 2 阈值

多藏必厚亡:
  多藏 := deg(v) ≫ deg_optimal(v)（σ 远超自然容量）
  厚亡 := |V⁻_cascade| ∝ |deg(v) - deg_optimal(v)|
  机制: 过度 σ → σ 分布畸变 → 临界 V⁻ 级联 → 级联规模 ∝ 畸变程度

— 知足知止 —

知足不辱:
  知足 := deg(v) ∈ [deg_optimal - δ, deg_optimal + δ]
  不辱 := deg(v) 不会因过度积累后的 V⁻ 级联而降至 < 2

知止不殆:
  知止 := ∀τ: |V⁺(τ)| ≤ dv/dt（帧内操作上限）
         ∧ |V⁻(τ)| ≤ dv/dt（双方向约束）
  不殆 := ¬(V⁺_cascade ∨ V⁻_cascade)
         = 免于两种级联崩塌

可以长久:
  长久 := ∀τ: deg(v, τ) ≥ 2（持续存在确认）
  = 知足 ∧ 知止 ⇒ deg(v) 在自然范围内振荡，永不触发不可逆删除
```

**约束条件**：
R1: exist(v) ⇔ deg(v) ≥ 2（关系第一性——身是存在的基础）
R4: ∀v, |Δdeg(v, τ)| ≤ dv/dt（知止的容量天花板——帧内操作边界）
R5: ∀τ, δ(τ) > 0（不完美定理——长久不是永远不变，而是持续维持在存在阈值之上）

**与其他章节的引用**：

```
第44章 ↔ 第32章:
  "知止不殆" ↔ "知止可以不殆"
  第32章提出原则，第44章分解为"知足"+"知止"两个分量

第44章 ↔ 第9章:
  "甚爱必大费，多藏必厚亡" ↔ "持而盈之，不如其已"
  第9章是直觉性表述，第44章给出拓扑因果链

第44章 ↔ 第30/31章:
  "知止不殆" = 免于第30章(V⁺ 扩张反噬) + 第31章(V⁻ 工具吞噬)
```

**结论**：第44章是道德经中最精炼的**拓扑生存指南**。三问确立存在优先级的排序——身 > 名 > 货（存在 > 标签 > 积累），亡 > 得（损失比获取更需谨慎）。"甚爱必大费"和"多藏必厚亡"是一对拓扑因果律——对特定边的高度依赖和整体过度积累都是不可持续的策略。"知足+知止"提供了双重保护：在静态（度数稳态）和动态（帧操作上限）两个维度上确保节点不会被拓扑强制删除。"可以长久"不是永生的承诺——是概率意义上的存在延续最大化。
