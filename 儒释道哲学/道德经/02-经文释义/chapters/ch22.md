## 原文

曲则全，枉则直，洼则盈，敝则新，少则得，多则惑。是以圣人抱一为天下式。不自见故明，不自是故彰，不自伐故有功，不自矜故长。夫唯不争，故天下莫能与之争。古之所谓曲则全者，岂虚言哉！诚全而归之。

## SPUM 转译（文本释义版）

封闭刚性局部子图——连接路径单一、无迂回通道——极易在应力积累到临界值后一次性级联崩塌。
带有迂回开放边的松弛节点子图，可以承接更多全域边流：边流有多条替代路径绕过应力集中区，拓扑结构更完整持久。

局部低度数——接近存在确认所需的最少连接（deg≈2），不自我膨胀——可以获得全域边流的持续滋养。
局部过高自重——度数远超最优区间——反而切断与周边节点的流动通道，子图自锁隔离。

"抱一为天下式"：将自身认知子图锚定于完整连通总图 ⟨P, ε⟩ 的整体拓扑状态——不执着于局部节点标识，而是认知全域连接结构——这才是完整的观测模式。

不自我膨胀 → 能看清全局；
不自以为是 → 能显现真实结构；
不自我夸耀 → 能产生实际效果；
不自我封闭 → 能持续演化。
不主动排他性创建边 → 全域中没有竞争者能动摇此子图的位置。
古代说的"曲则全"，不是空话——保持开放松弛的节点结构，最终确能获得完整的拓扑持久性。

## 拓扑注解

- **节点结构**：推崇"曲/枉/洼/少"型节点——deg≈2、邻接均匀、无自环边封闭的松弛节点。警惕"直/多/盈"型节点——高自环、闭合子图锁定、应力积累。"少则得，多则惑"的数学含义：deg(v) ∈ [2, d_opt] 最优区间。
- **边流模式**：曲→全 = 迂回开放路径 → 边流有替代路由，不会因单一瓶颈崩溃。不自见/自是/自伐/自矜 = 四种主动创建排他性 V⁺ 边的方式——全部导致孤立。
- **稳态分析**：S_木（闭环占比）偏低时"曲则全"成立；S_木过高触发金形修剪（对应"物壮则老"之警）。抱一 = 认知子图锚定 ⟨P, ε⟩ → 局部 S 向量稳定在 H 中心。

## 纯符号拓扑版

### §22: 曲则全

**输入**：
G_rigid ⊂ ⟨P, ε⟩ — 刚性子图：|cycles| 高，bridge_density → 0
G_open  ⊂ ⟨P, ε⟩ — 松弛子图：deg(v) ≈ 2, clustering → 0

**推导**：
  G_rigid: ∃v, Σ(6−deg(v)) 局部累积 → 一次性 V⁻ 级联崩塌
  G_open:  ∀v, ∀e ∉ G_open.cycles, ε 流有替代路径绕过 v → 完整持久
  deg(v) → d_opt: σ 局部最优 → 得（边流持续滋养）
  deg(v) ≫ d_opt: σ 局部过高 → 惑（自锁隔离）

**约束**：
  dv/dt ≤ const                       (单帧不能无限加边 — R4)
  ∀v ∈ G_open: deg(v) ∈ [2, d_max]    (最小连接+天花板约束)

**结论**：
  抱一 = 认知子图 G_cog ⊆ ⟨P, ε⟩ 锚定于总图。
  S_木过高 → 金形修剪 → 释放节点回归土形储备（曲→全→敝→新的循环）。
