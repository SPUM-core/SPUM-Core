## 一、SPUM 转译（文本释义版）

### 1.1 致虚守静：彻底清空局部基底

**致虚极，守静笃。**

- **虚极**：将局部子图$S_{self}$的密度$\sigma_{self}$彻底清空至趋近于零，不留任何私化凸起、执念残留、局部堆积。这不是第15章"浊以静之徐清"的逐步收敛，而是**一步到位地将基底完全清空**。
- **静笃**：清空之后，恒定锚定于全域基底$\sigma_\Omega$均衡态，不动摇、不漂移、不产生新的自发扰动。

**SPUM拓扑定义**：
```
虚极 = σ_self → 0，S_self内部完全清空，无残留私峰
静笃 = S_self ∈ H 恒成立，无偏移、无震荡
```

此即第15章功夫纯熟后的质变跃升：从"动态平衡"进至"彻底归零"。

### 1.2 万物并作观复：洞见全域循环节律

**万物并作，吾以观复。**

- **万物并作**：全网$V^+$操作大规模涌现，新边不断创建，新节点不断加入，全域拓扑处于剧烈的创生生发期。这是$\sigma$密度的全域性扩张。
- **吾以观复**：得道者不参与、不干预、不追逐，只是**观察**（观）整个网络的**回归循环**（复）——每一次$V^+$创生之后，必有$V^-$湮灭跟随；每一次扩张之后，必有收敛回归。

**复**的拓扑本质：帧间演化中，$\sigma$密度从偏离到回归的全过程。
```
V⁺（并作）→ σ↑偏离均衡 → V⁻（复）→ σ↓回归均衡
```

得道者的认知位置不在局部子图之内，而在全域框架之上——"吾"是认知主体的L0视角，不再被任何局部扰动牵动。

### 1.3 归根复命：归源的拓扑本质

**夫物芸芸，各复归其根。归根曰静，是谓复命。**

- **芸芸**：万物纷繁复杂，拓扑构型层出不穷——局部子图各有不同的$\sigma$分布、边连接模式、演化轨迹。
- **各复归其根**：无论多么复杂的构型，最终都会回归到**根**——即$\sigma$均衡态、基线密度、最基本的拓扑约束状态。
- **归根曰静**：回归本源均衡态，就是"静"——不再是动态平衡，而是**静态本体基底**本身。
- **是谓复命**：回归本质，就是回归自然的演化节律——**命** = 宇宙演化的固有节律 = V⁺/V⁻交替的必然规律。

**拓扑定义链**：
```
芸芸（纷繁构型）→ 归根（σ回归均衡）→ 静（本体基底）→ 复命（归顺演化节律）
```

### 1.4 知常曰明：把握不变约束的认知

**复命曰常，知常曰明。不知常，妄作凶。**

- **常**：不变 = 恒常约束规律。在SPUM框架中即**道纪**（第14章）——如$\Sigma(6-\deg)=12$、$\chi$守恒、V⁺/V⁻对偶性等不随时序演化的底层规则。
- **知常曰明**：认知把握了这些不变约束，就获得了真正的**明**——L0认知穿透，不再被L1幻象遮蔽。
- **不知常，妄作凶**：不了解不变约束而轻举妄动，必然产生与全域拓扑冲突的扰动——局部$V^+$操作超出$H$区间，破坏$\sigma$均衡，导致系统性震荡（凶）。

**SPUM**：
```
知常 = 认知抵达L0约束层，把握Σ(6−deg)=12等不变量
妄作 = 在L1幻象驱动下发起的V⁺/V⁻操作，偏离H区间
凶 = 局部扰动扩散为全域震荡
```

### 1.5 知常容→道乃久：从个体认知到全域自洽的递进链

**知常容，容乃公，公乃王，王乃天，天乃道，道乃久，没身不殆。**

这是全章最核心的递进链——从个体认知出发，经过六阶扩展，最终抵达全域永续自洽。这是**格物致知**的完整路径（与第12章、15章修身闭环同构）。

### 4.5 万法皆空：佛学与SPUM的终极对位 — 全章统一注

**万法皆空**（梵文：सर्वधर्माः शून्याः，sarvadharmāḥ śūnyāḥ）是般若系经典（《心经》《金刚经》《大品般若》等）的核心命题，意指**一切法（存在/现象）无独立自性（无svabhāva），缘起故空，本性寂灭**。

与本章的逐层对应：

| 佛学 | 本章 | SPUM |
|------|------|------|
| **万法**（सर्वधर्माः） | 万物并作、夫物芸芸 | $\forall S_i \in \Omega$：全网所有局部子图、所有拓扑构型、所有$\sigma$分布状态 |
| **皆空**（शून्याः） | 归根复命、各复归其根 | $\forall S_i, \sigma_i(t) \to \sigma_\Omega$：一切局部密度最终回归全域均衡基线 |
| **自性空**（无svabhāva） | 致虚极 | $\sigma_{self}\to 0$：子图无固有属性、无独立于全局的私化凸起 |
| **本性寂灭**（प्रकृतिपरिनिर्वृत्त） | 归根曰静 | $S\in H$：构型消解后，回归本体基底的寂静 |

**核心对位推演**：
```
佛学：万法（缘起生灭）→ 皆空（无自性）→ 究竟涅槃（寂灭为乐）
  ‖        ‖              ‖               ‖
SPUM：万物并作(V⁺) → 归根(σ→σ_Ω) → 守静笃(S∈H永恒)
```

**关键澄清**：「万法皆空」之**空**不是虚无（不存在），而是**无自性**（不独立存在）——正对应SPUM中$\sigma_{self}\to 0$不是消灭节点，而是消解**私化凸起**这一「自性执念」。空性是万法的如实相，不是断灭。

**与本篇五家同构体系闭环**：
| 体系 | 表述 | 统一公理 |
|------|------|---------|
| 道家 | 致虚极 → 归根复命 | $\sigma_{self}\to 0$，回归本体 |
| 佛家 | 万法皆空 → 涅槃寂静 | 一切法无自性，回归寂灭 |
| 儒家 | 格物致知 → 知止有定 | 剥离L1幻象，锚定本体 |
| 易学 | 洗心退藏 → 复见天地之心 | 清空局部，回归循环 |
| SPUM | $\sigma\to 0$ → $S\in H$ 永恒 | 彻底清空局部基底 = 归根复命 = 空 = 定 |

**一句话结论**：「万法皆空」不是哲学思辨，而是**第16章「致虚极→归根复命→没身不殆」的佛学命名**。两套语言描述的是同一个认知操作：彻底穿透局部执念，认知与全域实相同一。
