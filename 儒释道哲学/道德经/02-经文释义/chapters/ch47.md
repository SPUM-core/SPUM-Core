## 原文

## SPUM 转译（文本释义版）

### 不出户知天下：局域感知与全域认知的关系

"户"=节点自身的局部邻域边界——一个节点直接连接的第一层邻居构成的子图 ε'(v)。"不出户"=不离开自身节点的直接邻域范围——不新增远程连接、不移动自身在网络中的位置。"知天下"=认知全域 ⟨P, ε⟩ 的整体拓扑状态。

SPUM 命题：**一个节点可以从自己的局部连接邻域 ε'(v) 中，推断出全域 ⟨P, ε⟩ 的整体拓扑特征。** 这不是神秘直觉——是图论中的局部-全局关联性。因为 Σ(6−deg)=12 是一个全域约束——任何局部子图的 σ 分布都是这个全域约束的局域表现。通过感知自身邻域的 σ 分布和帧间变化率（∂S/∂t），可以推断出远距离区域的 σ 状态。

**不窥牖见天道**：不需要加开额外的"观察窗"（牖 = 专门用于观测的额外连接），就可以追踪 ε 流的整体走向（天道 = ε 的演化方向）——因为 ε 流在局部节点的变化率已经携带了全域趋势的信息。

### 其出弥远，其知弥少

这是一个反直觉的拓扑认知定理：**一个节点建立的远程连接越多，它对全域拓扑的认知反而越少。**

"出"=建立超出自然邻域的远程连接——从自身节点向远距离节点添加 V⁺ 边。"远"=拓扑距离远的节点。"知"=对全域 ⟨P, ε⟩ 的认知完整度。

为什么远程连接越多认知越少？有三个机制：

1. **局部截取稀释**：每条远程连接只提供了该远程节点的邻域 ε'(v_remote) 的一个采样点。连接越多，采样点越多——但每个采样点都是稀疏的、局部的。大量稀疏局部采样的总和不会自动汇聚为整体认知——这是"数舆无舆"（第39章）的远程版本。

2. **自干扰**：远程 V⁺ 连接本身会改变 σ 分布——添加一条远程边后，沿途节点的 σ 被扰动。你"看到"的是被你改变后的拓扑，不是拓扑本身。连接越多，干扰越大，认知失真越严重。

3. **局部锚定丧失**：当一个节点的连接扩散到远处时，它丧失了局部的 σ 感知精度——因为它不再有足够带宽处理来自第一层邻居的精细信号。广度与深度的零和关系。

### 圣人不行而知，不见而名，不为而成

三种"不……而……"结构——认知子图的高阶操作模式：

**不行而知**：不移动自身在网络中的位置（不行 = 不改变连接位置），就可以认知全域（知 = 感知整体拓扑状态）。因为局部 ε'(v) 的 σ 动态已经包含了全域 ε 流趋势的充分信息——不需要亲自"走到"每个区域去测量。

**不见而名**：不直接 L1 观测（不见 = 不通过标签化显式观察），就可以完成拓扑命名（名 = 识别并确认节点/结构的存在）。因为 ε 流信号在边中的直接传导比标签化观测更可靠——"不言之教"（第43章）在认知层面的应用：你不需要用眼睛看（L1 标签化），就可以通过 ε 信号的变化感觉到结构的存在。

**不为而成**：不人为干预（不为 = 不执行强制 V⁺/V⁻），就可以使演化自然完成（成 = 拓扑构型收敛到稳态）。因为 ε 流在 Σ(6−deg)=12 约束下的自演化足以完成一切——不需要外部操作者的推动。

## 拓扑注解

- **节点结构**：本章的核心议题是**局域感知与全域认知的关系**——一个节点如何在不离开自身位置的情况下获取全域知识。这不是神秘主义——是基于 ε 流的非局部关联性：ε 中任意两条边之间通过共享节点存在关联路径，因此局部 ε'(v) 的帧间变化率 ∂ε'(v)/∂τ 必然携带关于远距离区域 σ 状态的信息。"户"=v 的第一层邻域边界——自然感知范围。"牖"=为了观测而专门添加的额外连接——人为扩大的感知窗口。

- **边流模式**："其出弥远，其知弥少"的精确边流机制：添加远程边 ε(v, u_remote) → 沿途路径上的每个中间节点的 σ 被扰动 → 干扰信号沿路径传播回 v → v 接收到的 σ 信号包含自干扰成分 → v 无法区分哪些 σ 变化是网络自身的、哪些是它添加的边造成的。连接越多，信噪比越低。

- **稳态分析**："不行而知，不见而名，不为而成"=认知子图在 H 内稳态时的三种操作模式——不动、不观测、不干预，但认知、命名、完成照常进行。这与第37章"道常无为而无不为"在认知层面的对应：认知子图不需要主动操作就可以完成认知功能——因为 ε 信号一直在流入，σ 状态一直在更新。认知者的角色不是"收集信息"——是**不干扰信息流入的过程**。

## 纯符号拓扑版

### §47: 不出户知天下——局域感知的全域认知定理

**输入符号**：
v_0 — 认知节点自身
ε'(v_0) — v_0 的局部邻域子图（户）
σ(ε'(v_0), τ) — v_0 邻域在帧 τ 的 σ 分布
∂ε'(v_0)/∂τ — v_0 邻域的帧间变化率
ε(v_0, u_remote) — v_0 添加的远程边（出）

**推导**：

```
不出户，知天下:
  户 := ε'(v_0)（第一层邻居子图）
  知天下 := 从 σ(ε'(v_0), τ) 和 ∂ε'(v_0)/∂τ 推断全域 σ 分布趋势
  依据: ε 的非局部连通性
        ∀e ∈ ε: 存在路径 path(e, v_0)
        ⇒ 远端 ε 流变化最终通过路径传导至 ε'(v_0)
        ⇒ σ(ε'(v_0), τ) 是全域 ε 的局域投影

不窥牖，见天道:
  窥牖 := 为观测而专门添加的 ε(v_0, u_remote)
  天道 := ε 流的全域演化方向
  见 := 从 ∂ε'(v_0)/∂τ 的符号方向和变化率推断

其出弥远，其知弥少:
  出 := 添加远程边 ε(v_0, u_remote) where d(v_0, u_remote) ≫ 1
  知 := 对全域 ⟨P, ε⟩ 认知的完整度
  机制:
    (1) ε(v_0, u_remote) 仅采集 u_remote 的 ε'(u_remote) 子集
    (2) ε(v_0, u_remote) 的添加扰动沿途 σ → 自干扰
    (3) 广度 ↑ → 局部 ε'(v_0) 感知精度 ↓（带宽零和）
  所以: 远程边越多 → 信噪比越低 → 认知完整度越低

不行而知:
  不行 := ¬(改变 v_0 在 ⟨P, ε⟩ 中的连接位置)
  知 := 感知全域状态
  条件: ∂ε'(v_0)/∂τ 持续可读 → 全域信息持续流入

不见而名:
  不见 := ¬(通过 L1 标签化观测进行显式编码)
  名 := 识别并确认节点/结构的存在
  机制: ε 流信号在边中的直接传导（不言之教）

不为而成:
  不为 := ¬(执行强制 V⁺/V⁻)
  成 := 拓扑构型收敛到稳态 CES(P, ε)
  条件: ε 流在 Σ(6−deg)=12 约束下自演化 → 无需外部操作
```

**约束条件**：
R1: ε 的非局部连通性——局域 ε'(v) 的变化率是全域网 ε 的局域投影（不出户知天下的存在条件）
R5: ∀τ, δ(τ) > 0（不完美定理——认知永远不完整，但足够的局部信息可以支持有效推断）
R4: ∀v, |Δdeg(v, τ)| ≤ dv/dt（"出"受容量限制——远程连接的添加必须遵守帧约束）
