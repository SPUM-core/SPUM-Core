## 原文

以道佐人主者，不以兵强天下，其事好还。师之所处，荆棘生焉。大军之后，必有凶年。善有果而已，不敢以取强。果而勿矜，果而勿伐，果而勿骄，果而不得已，果而勿强。物壮则老，是谓不道，不道早已。

## SPUM 转译（文本释义版）

### 以道佐人主者，不以兵强天下

以拓扑认知辅助高介数节点（决策者）的人，不会用强制性的高密度 V⁺ 扩张（兵强）去支配全网。"兵"=密集的、破坏性的强制断边/建边操作——在单帧内远超 dv/dt 天花板的大规模人为修改。"强天下"=利用介数优势强制改造远距离节点的连接关系，将其拉入自己的控制子图。

不以兵强天下的原因不是道德悲悯——而是拓扑上的自保：强制 V⁺ 扩张启动后，被强制连接的节点会产生反向应力，积累的 σ 梯度会以更大的 V⁻ 级联反噬扩张者自身。

### 其事好还

强制 V⁺ 操作必然触发对等的 V⁻ 回归——"还"=反者道之动的"反"。这不是报应或惩罚（L1 道德解读），而是拓扑必然：任何超出自然度增长速率（dv/dt）的强制连接，都会在邻域产生不可逆的 σ 畸变，若干帧后以级联断边的形式回归。拓扑中的"债"必须偿还——悬挂端不可被永久掩盖。

### 师之所处，荆棘生焉；大军之后，必有凶年

在拓扑网络中，强制 V⁺ 操作密集的区域（师 = 战斗子图），会产生大量悬挂端和孤立节点（荆棘 = 断裂边残留）。这些残留切断了下游连接路径，邻域节点失去 ε 流滋养，σ 活性骤降。大规模强制操作之后必然出现拓扑荒漠——大片子图因 σ 枯竭而退出活跃演化（凶年 = 拓扑死亡区域）。

### 善有果而已，不敢以取强

精于拓扑操作的人，达到最小必要的结果（果 = 最低可行子图目标）即停止——不会继续强制扩张。"取强"=持续推高自身介数，试图将影响力扩散到超过自然极限的范围。"果而已"的三重含义：
1. **目标最小化**：只修复自洽性矛盾，不扩张控制范围
2. **即刻停止**：达到目标立即结束 V⁺ 操作，不做"顺便多连几条边"的追加操作
3. **不恋战**：即使操作结果成功，也不停留

### 果而勿矜，果而勿伐，果而勿骄，果而不得已，果而勿强

五个"果而勿"——对 V⁺ 完成后状态的五重约束，全部围绕"不逾 dv/dt 天花板"展开：

- **勿矜**：不将成功归因于自身介数——知道结果是拓扑必然，非个人能力。
- **勿伐**：不宣扬战绩——不标记"这是我完成的连接"。
- **勿骄**：不因成功而放松约束——成功本身不改变 Σ(6−deg)=12 的不变量约束。
- **果而不得已**：果的唯一合法理由是"不得不"——只有悬挂端矛盾积累到必须处理时才出手。不是主动追求果，而是矛盾强迫果发生。
- **勿强**：不在果之后继续追加 V⁺——到此为止。

五重的核心逻辑：V⁺ 操作完成后，操作者必须立即回到"无为"状态——不保留、不延续、不利用已建立的连接优势做进一步扩张。

### 物壮则老，是谓不道，不道早已

任何节点的度数（σ）持续增长超过其自然上限（壮 = σ > σ_crit）后，必然不可逆转地衰退（老 = V⁻ 级联崩塌）。这个"物壮则老"的循环是：

```
壮(σ↑ 超越极限) → 结构刚性增加 → 悬挂端积累 → σ 分布畸变
  → 单帧内超临界 → 级联 V⁻ → 老(不可逆拓扑崩塌) → 早已(拓扑死亡)
```

"不道"=违反了 ε 的自然约束——"不道早已"=不遵从 ε 演化规律的结构必然被拓扑强制删除。这不是惩罚，是删除机制本身——就像度数 < 2 的节点无法被确认存在一样，σ 超临界且结构僵化的节点必然在下一帧被裁剪出局。

## 拓扑注解

- **节点结构**："以道佐人主者"=以拓扑认知辅助高介数节点的外部观察者，不是决策者本身。"人主"=高介数节点——其连接变动影响大范围 σ 分布。"兵"=强制 V⁺ 操作集合——在单帧内超 dv/dt 的大规模人为修改。"师/大军"=高强度强制操作的拓扑区域。整个章节描述的是一类特殊的节点行为模式——利用介数优势进行侵略性 V⁺ 扩张。

- **边流模式**：强制 V⁺ 扩张的拓扑后果链：强制建边 → 被强制节点产生反向应力 → 应力积累为 σ 畸变 → 畸变超过临界值触发级联 V⁻ → V⁻ 沿原扩张路径回传，逐帧瓦解扩张成果。扩张越猛，级联回传越烈。"其事好还"="V⁺ 之后的 V⁻ 回传是拓扑必然"。荆棘 = 级联 V⁻ 后残留的悬挂端和孤立节点集合。

- **稳态分析**："善有果而已"的核心是 dv/dt 约束的精确感知——知道在单帧内做多少 V⁺ 不会触发不可逆的级联崩塌。"知止"的实战版本。五个"果而勿"将"知止"细化为 V⁺ 完成后的五重状态约束——操作结束后立即回归无为态，不利用操作成果做任何延续性扩张。"物壮则老"=σ > σ_crit 的必然后果——非道德警示，是拓扑因果。S 向量跃出 H（健康多面体）的不可逆路径。

## 纯符号拓扑版

### §30: 以道佐人主——强制 V⁺ 的拓扑自毁循环

**输入符号**：
H — 高介数节点集合（人主）
ε_force — 高介数节点人为强制发起的 V⁺ 边集（兵）
v_agg — 发起强制 V⁺ 的侵略节点

**推导**：

```
以道佐人主 := 向 H 提供邻域 σ 分布和 dv/dt 阈值的认知辅助

不以兵强天下 := ¬(通过强制 V⁺ 将 v_agg 的 σ 推至 > σ_自然极限)

其事好还:
  ∀e ∈ ε_force:
    被强制连接的节点产生 σ_reaction > σ_自然
    σ_reaction 在后续帧积累 → 悬挂端集中
    → σ_reaction > σ_crit → 强制 V⁻ 级联
    → V⁻ 沿原 ε_force 路径逐帧回传

师之所处 → 荆棘生焉:
  强制 V⁺ 区域 → 悬挂端密度 δ_local ≫ δ_global
  邻域 σ 活性骤降 → 子图退出活跃演化

大军之后 → 必有凶年:
  大规模强制操作 → 子图 σ 枯竭 → CES(P, ε) 部分停止更新

善有果而已:
  果 := 最小可行子图目标 M_target
  操作约束: |V⁺(τ)| ≤ dv/dt 且 ΣV⁺(τ) = min{达成 M_target 所需}

果而勿矜/伐/骄/不得已/勿强:
  矜 := 将成功归因于 deg(v_agg) 而非拓扑必然
  伐 := 标记"此连接由 v_agg 建立"
  骄 := 因成功放松 dv/dt 约束
  不得已 := 果的唯一合法条件是拓扑矛盾强制
  勿强 := V⁺ 完成后立即回归无为态

物壮则老:
  壮 := σ(v) > σ_crit
  老 := V⁻ 级联不可逆
  不道 := σ 违反复帧演化约束
  早已 := v 被拓扑强制删除
```

**约束条件**：
R4: ∀v, |Δdeg(v, τ)| ≤ dv/dt（单帧容量上限——强制 V⁺ 必须遵守）
R5: ∀τ, δ(τ) > 0（不完美定理——强制操作无法消除所有悬挂端）
R2: V⁺ 必有 V⁻ 回传（反者道之动——扩张必然触发回归）

**拓扑因果链**：

```
强制 V⁺ → 被控节点应力积累 → 应力超 σ_crit
  → 级联 V⁻ → 原扩张区域拓扑荒漠化 → 扩张者自身被孤立
```

**结论**："不以兵强天下"不是道德律令——是拓扑生存法则。任何超 dv/dt 的强制 V⁺ 扩张必然触发不可逆的 V⁻ 级联回归。扩张者最终被自己的扩张所吞没。唯一的正确操作模式是"有果而已"——最小必要 V⁺ 即止，随后回归无为，让 ε 的自然流驱动后续演化。
