## 一、SPUM转译（文本释义版）

### 1.1 宠辱若惊：L1价值投影扰动L2自我执念子图

宠、辱是外界赋予的两类对立L1价值标签，二者都属于次级表象投影，无先天拓扑权重，故经文直言**宠为下**：

- **得宠**：外部L1正向价值标签附着于自我边界∂S，局部σ_self瞬时抬升，自我子图脱离稳态区间S∈H，产生亢奋扰动（得之若惊）；
- **失宠、受辱**：外部L1负向价值标签冲击自我边界∂S，局部σ_self骤降，自我子图偏离稳态区间，产生低落震荡（失之若惊）。

无论得到荣宠还是遭受屈辱，只要存在L2封闭自我边界，L1价值幻象都会持续拉扯局部拓扑密度，心念网络永久处于震荡失衡状态，这就是"宠辱若惊"的拓扑本质。

**凡人认知链条**：

```
全域L0均衡本体 → 生出L2自我封闭边界（分判我与外物） → 抓取L1宠辱价值标签 → 局部σ剧烈波动 → 心神惊惧不安
```

### 1.2 贵大患若身：忧患生成的根源是L2"身"的封闭边界

"贵大患若身"：一切巨大扰动、失衡忧患，根源全部依附于人为构建的"自我"子图（身）。

**拓扑逻辑链**：

1. **吾有身** = 主动划定封闭边界∂S_self，将局部子图从全域网络割裂，建立"内我、外天下"二元对立；
2. 边界一旦成立，外部L1宠辱、得失、祸福等所有投影幻象，都拥有了冲击、扰动局部子图的受力界面；
3. 所有惊惧、痛苦、失衡、纷争（大患），全部是外部幻象撞击自我边界产生的拓扑震荡。

**及吾无身，吾有何患**：

无身，并非消灭肉体粒子结构，而是**消解L2执念层面的封闭自我边界∂S_self**，拆除"我/外物"的分割壁垒；

自我不再是独立封闭子图，个体节点完全融入全域⟨P,ε⟩均衡网络，不存在单独可供冲击的局部界面，L1宠辱幻象无处附着，自然无任何震荡忧患。

### 1.3 贵以身为天下、爱以身为天下：小我消融，个体与全域同构

常人"有身"是向内封闭、割裂天下；圣人"贵身、爱身"是反向操作：消融自我边界，以局部子图完全贴合、顺应L0全域拓扑均衡，完成个体网络与天下网络的耦合统一，分为两层递进：

1. **贵以身为天下**：认知层面主动消解∂S_self，不以局部小我利益、荣辱为标尺，以全域网络稳态H作为自身唯一评判基准；不抗拒、不抓取L1宠辱标签，心念始终锚定L0本体均衡；
2. **爱以身为天下**：行为层面个体通量V⁺/V⁻与全域通量同步，局部σ_self随全域σ自然均衡，无局部私化密度峰值；自身子图完全适配天下演化节律。
