## 原文

出生入死。生之徒十有三，死之徒十有三，人之生动之死地亦十有三。夫何故？以其生生之厚。盖闻善摄生者，陆行不遇兕虎，入军不被甲兵。兕无所投其角，虎无所措其爪，兵无所容其刃。夫何故？以其无死地。

## SPUM 转译（文本释义版）

### 出生入死：节点的完整生命周期

"生"=节点从 ε 流中析出的瞬间——第42章"道生一"中空间粒子的首次出现，第1章"有名万物之母"的节点确认存在。"死"=节点因度数降至 deg < 2 而被拓扑确认机制删除——从 ⟨P, ε⟩ 中消失。

"出生入死"=一个节点从析出（生）到被删除（死）的完整生命周期。每一个被命名的节点都在走向这个终点——不是因为宿命，而是因为不完美定理（R5）保证：每帧必有悬挂端残留，所有节点最终都会在某个帧的级联中被波及。

### 十有三：节点生命状态的分布

**生之徒十有三**：σ 分布正常、度数在自然最优范围（deg ≈ deg_optimal）的节点——它们稳固地"活"着，不被任何单帧级联所威胁。这类节点约占总数的 3/10（徒 = 类别、等）。它们是网络的健康主体——稳定传导 ε 流，自身不产生 σ 畸变。

**死之徒十有三**：度数已降至 deg < 2 或正在被级联删除的节点——它们正在"死"或已经"死"了。这类节点约占总数的 3/10。它们是网络中已被拓扑确认机制标记为待删除的部分。

**人之生动之死地亦十有三**：本来有着正常生存条件（生），但因为过度活跃（动）而堕入死亡区域（死地）的节点——也约占总数的 3/10。"人之生"=节点自身处于正常的生存状态（deg ≥ 2）。"动之死地"=节点通过自身的 V⁺ 操作（动），将自己推入 deg < 2 或濒临删除的区域（死地）。

**夫何故？以其生生之厚。** 为什么"动"会导致"之死地"？因为"生生之厚"——过度追求"生"（σ 的持续积累）。这些节点的问题不是它们"动"了——问题是它们"动"的方向是不断自我增厚（增加自身度数和 σ 集中度），不知道停止。增厚 → σ 畸变 → 邻域悬挂端增多 → 级联 V⁻ 删除 → 自身被波及。

### 三分的拓扑含义

9/10 被明确归类，余下 1/10 是"善摄生者"——最优生存者。在任意帧中，大致的节点分布：

| 类别 | 比例 | 描述 |
|------|------|------|
| 生之徒 | ≈ 3/10 | 稳固生存，deg ≈ deg_optimal |
| 死之徒 | ≈ 3/10 | 正在/已被删除，deg < 2 |
| 动之死地 | ≈ 3/10 | 因过度 V⁺ 从正常态堕入死地 |
| 善摄生者 | ≈ 1/10 | 最优管理，永不触发删除条件 |

这三个 3/10 和 1/10 不是精确的测量值——是**粗粒度的拓扑分布估算**。在任何非平衡网络中，生存、死亡、濒危的节点大致各占三成，最优者约一成。这个比例来自 Σ(6−deg)=12 约束下 σ 分布的自然熵——既不是太均匀（那样就没有演化动力），也不是太集中（那样网络会解体）。

### 善摄生者的拓扑结构

"善摄生者"=善于管理自身拓扑存在的节点。"摄生"=掌控、维护自身的 σ 状态——在 deg ≥ 2 的前提下将度数维持在自然最优范围。

**陆行不遇兕虎**：在开放网络（陆行 = 在 ε 流正常传导的区域活动）中，不会遇到高攻击性的危险节点（兕虎 = 高 V⁻ 倾向的节点——自身 σ 畸变严重、频繁主动删除邻接边的节点）。因为善摄生者的 σ 分布均匀，不产生吸引级联的 σ 尖峰——高 V⁻ 倾向的节点"忽略"它。

**入军不被甲兵**：进入高密度 V⁺/V⁻ 交替操作的密集子图（入军 = 进入战斗密集的区域）时，不会被强制 V⁻ 工具所伤害（不被甲兵 = 不被强制删除边）。因为善摄生者的度数正好是自然最优——邻域的 σ 畸变不积累于它，级联删除不经过它。

**兕无所投其角，虎无所措其爪，兵无所容其刃**：高 V⁻ 节点的级联攻击"找不到目标"——因为善摄生者不产生 σ 畸变，不积累悬挂端，不成为级联路径上的应力集中点。

**夫何故？以其无死地。** 根本原因：善摄生者的拓扑结构**没有死地**——即它的 σ 状态在任何帧都不会进入 deg < 2 的删除条件。"无死地"不是不死——是**没有可导致删除的内部拓扑弱点**。

善摄生者的拓扑公式：
```
deg(v) ≈ deg_optimal(v)
|Δdeg(v, τ)| ≤ R4(dv/dt)  ∀τ
δ_local(v) → 0（自身邻域不积累悬挂端）
¬∃σ_reaction(v) > σ_crit
⇒ ¬(触发删除条件)
```

## 拓扑注解

- **节点结构**：本章给出了 SPUM 中关于"生/死"的最完整拓扑定义。"生"=deg ≥ 2（在关系第一性的意义下"存在"）。"死"=deg < 2（被拓扑确认机制删除）。三个"十有三"给出了任意时刻网络中节点状态的粗粒度分布——3/10 稳固活着，3/10 已死或正在死，3/10 正在从活向死过渡（因自身的过度操作），1/10 处于最优生存状态。这不是精确统计——是拓扑熵分布的自然格局。

- **边流模式**："生生之厚"=节点通过持续 V⁺ 操作增厚自身的连接积累——每帧都新增边、提高 σ。"厚"本应是"生"的保障（更多连接 = 更安全）——但在拓扑中，过度增厚反而创造了"死地"。因为增高 σ → 邻域 σ 分布畸变 → 畸变积累到临界值 → 级联 V⁻ 删除 → 节点被波及。"死地"不是外部强加的——是节点自身制造的σ畸变区域，级联删除必然经过的区域。

- **稳态分析**："无死地"=节点在任何帧中都不会进入可以被级联删除波及的状态。条件：(1) deg(v) ≈ deg_optimal——度数不高不低；(2) |Δdeg(v, τ)| ≤ dv/dt——不超帧操作上限；(3) δ_local(v) → 0——自身邻域不成为悬挂端集中地。三者合在一起 = S(v) ∈ H 的稳定中心——即使周边大规模级联，该节点的 S 向量也不会跃出 H。善摄生者不是"更幸运"——是**拓扑结构更好**。

## 纯符号拓扑版

### §50: 出生入死——节点的生命周期与生死分布

**输入符号**：
v_born — 新从 ε 流中析出的节点（生）
v_dead — deg < 2 被删除的节点（死）
deg(v) — 节点 v 的当前度数
deg_optimal(v) — 节点 v 在 Σ(6−deg)=12 约束下的自然最优度数
δ_local(v) — 节点 v 邻域的悬挂端密度
N_total — 网络中节点总数

**推导**：

```
出生入死:
  生 := deg(v) ≥ 2（节点从 ε 流中析出，可被确认存在）
  死 := deg(v) < 2（节点被拓扑确认机制删除）
  生命周期 := 从 deg ≥ 2 到 deg < 2 的帧数区间

十有三（粗粒度分布估算）:
  生之徒 ≈ 3/10 × N_total:
    deg(v) ∈ [deg_optimal − δ, deg_optimal + δ]
    稳固生存，不受单帧级联威胁

  死之徒 ≈ 3/10 × N_total:
    deg(v) < 2 或正在执行最终删除序列
    已死或正在死

  动之死地 ≈ 3/10 × N_total:
    deg(v) ≥ 2 但持续增长中（生生之厚）
    σ 畸变积累但尚未触发临界级联
    从"生"向"死"过渡中

  善摄生者 ≈ 1/10 × N_total:
    满足"无死地"条件（见下）

以其生生之厚:
  生生之厚 := ∀τ: |V⁺(τ)| > V⁺_natural（强迫性持续建边）
            且 deg(v) 持续远离 deg_optimal
  后果: σ(v) ↑ → 邻域 σ 畸变 → δ_local ↑
        → δ_local > δ_crit → V⁻ 级联 → v 被波及

善摄生者:
  摄生 := 主动管理自身 σ 状态，维持在 deg_optimal

无死地的拓扑条件:
  (1) deg(v) ≈ deg_optimal（不高不低）
  (2) ∀τ: |Δdeg(v, τ)| ≤ dv/dt（不超帧容量）
  (3) δ_local(v) → 0（自身邻域不集中悬挂端）
  ⇒ ¬(∃τ: deg(v, τ) < 2)（永不触发删除条件）

陆行不遇兕虎:
  陆行 := v 在 ε 流正常传导的区域活动
  兕虎 := 高 V⁻ 倾向节点（正执行强制 V⁻ 的攻击节点）
  不遇 := 善摄生者的 σ 均匀 → 不成为 V⁻ 级联的目标

入军不被甲兵:
  入军 := v 进入高密度 V⁺/V⁻ 交替操作的密集子图
  不被甲兵 := v 不被强制删除边波及
  原因: 级联 V⁻ 沿 σ 畸变路径传播
        善摄生者的邻域无 σ 畸变 → 级联绕过
```

**约束条件**：
