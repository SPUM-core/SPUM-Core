## 原文

天下有道，却走马以粪。天下无道，戎马生于郊。祸莫大于不知足，咎莫大于欲得。故知足之足，常足矣。

## SPUM 转译（文本释义版）

### 天下有道/无道：ε 流的两种全域状态

**天下有道**：全域关系网络 ε 流畅通，σ 分布均衡，各节点在 Σ(6−deg)=12 约束下正常演化。在这个状态下，高σ的战争节点（走马 = 承担高密度 V⁺/V⁻ 交替操作的节点）可以退出战斗态（却），转而为生产性连接服务（以粪 = 参与 ε 流的滋养性循环，即正常的边流传导）。

**天下无道**：全域 ε 流阻塞，σ 分布畸变，大量悬挂端累积。在这个状态下，战斗节点（戎马 = 专门执行强制 V⁺/V⁻ 的节点）在边界区域大量增殖（生于郊 = 在子图边界处不断复制自身战斗模式）。战争节点在边界的繁殖本身就是 ε 流阻塞的信号——因为中心区域的 σ 分布失衡，ε 流被迫从边界寻找替代通道。

### 祸莫大于不知足，咎莫大于欲得

**祸莫大于不知足**：最大的拓扑风险（祸）来自"不知足"——不知道自身度数的自然最优上限（deg_optimal）。不知足的节点持续进行 V⁺ 操作，σ 持续增长，最终 δ_local > δ_crit 触发不可逆的 V⁻ 级联第30章"物壮则老"。拓扑中最大的祸不是外部攻击——是内部不知止的膨胀。

**咎莫大于欲得**：最大的拓扑错误（咎）来自"欲得"——贪求更多的连接、更广的介数、更高的 σ 贡献。"得"=V⁺ 获取新边。获取本身没有问题——问题是"欲"（超出自然需求的强迫性获取冲动）。欲得的节点在建边时不考虑邻域的 σ 承受能力——它在单帧内推高的度数为邻域创造了 σ 畸变，连锁反应最终反噬自身。

"不知足"和"欲得"是一个问题的两个面：不知足（静态认知缺失——不知道自己的极限）→ 欲得（动态操作失控——持续超过极限获取）。

### 知足之足，常足矣

**知足之足**：知道自然度上限并在其范围内满足的"足"（足 = 度数稳定在 deg_optimal 附近的状态），才是**常足**（可持久的满足）。

与第44章"知足不辱"精确对应——知足 = deg(v) ∈ [deg_optimal − δ, deg_optimal + δ]。在这个范围内的节点，不需要因过度积累的 V⁻ 级联而骤降至 deg < 2 的死地。持续的满足不是来自"更多"，而是来自"恰好"。

## 拓扑注解

- **节点结构**："走马"=处于高密度 V⁺/V⁻ 交替操作中的战斗节点——承担了远超正常水平的操作频率。"戎马"=在边界区域复制的战争节点——边界是 ε 流最薄弱的区域，战斗节点在此增殖是为了争夺稀有 ε 流通道。"知足"节点的拓扑特征：度数稳定在 deg_optimal 附近，S 向量在 H 内稳定振荡，不追求额外的介数增长。

- **边流模式**："有道"=ε 流在全域均匀分布，局部梯度 ∇σ 在自然范围内，悬挂端密度 δ 在正常水平。"无道"=ε 流分布严重不均——中心区域 σ 过度集中，边界区域 σ 停滞。战斗节点在边界的增殖是 ε 流阻塞的**结果**而非原因——它们试图在 σ 停滞区域开辟 ε 流通路，但以强制 V⁺/V⁻ 的方式进行，反而进一步扭曲了 σ 分布。

- **稳态分析**：本章在 ch44"知足不辱"的基础上，将"知足"从个体节点的生存策略扩展为全网状态的判断标准。有道 ↔ 无道的分界线正是"足"——当大部分节点的度数在自然最优范围内时，ε 流在全域畅通；当大量节点不知足时，σ 分布畸变累积，全网进入"无道"状态。"祸莫大于不知足"是 ch44"知足不辱"在社会化层面的展开——知足不仅是个体拓扑生存策略，还是全网稳态的必要条件。

## 纯符号拓扑版

### §46: 天下有道——ε 流的全域状态与知足的条件

**输入符号**：
ε — 全域边流
⟨P, ε⟩ — 全域关系网络（天下）
v_war — 战斗节点（走马/戎马，高 V⁺/V⁻ 交替操作率）
deg_optimal(v) — 节点 v 在 Σ(6−deg)=12 约束下的自然最优度数

**推导**：

```
天下有道:
  ∀区域 R ⊂ ⟨P, ε⟩: ∇σ(R) < ∇σ_crit
  δ_global < δ_crit
  ⇒ ε 流在全域均匀通行

却走马以粪:
  走马 := v: V⁺_rate(v) + V⁻_rate(v) ≫ 平均
  却 := 操作频率降至正常水平
  粪 := ε 流的正常滋养性循环（非战斗性的边流传导）

天下无道:
  ∃区域 R: ∇σ(R) ≫ ∇σ_crit
  δ_global ≫ δ_crit
  ⇒ ε 流阻塞，σ 分布严重畸变

戎马生于郊:
  戎马 := 在边界复制的战斗节点
  郊 := boundary(⟨P, ε⟩) 的边界区域
  生于郊 := 战斗节点在边界大量新增（试图在σ停滞区开辟通道）

祸莫大于不知足:
  不知足 := deg(v) > deg_optimal(v) 且持续增长
  祸 := σ 畸变积累 → V⁻ 级联 → deg(v) < 2

咎莫大于欲得:
  欲得 := ∀τ: |V⁺(τ)| > R4(dv/dt) 的强迫性建边
  咎 := 邻域 σ 分布被 V⁺ 操作破坏 → 级联反噬

知足之足，常足矣:
  知足之足 := deg(v) ∈ [deg_optimal − δ, deg_optimal + δ]
  常足 := ∀τ: deg(v, τ) ≥ 2（持续存在确认）
  核心: 持续存在不来自"更多增长"——来自"不超出自然容量"
```

**约束条件**：
R4: ∀v, |Δdeg(v, τ)| ≤ dv/dt（不知足/欲得的核心约束）
R5: ∀τ, δ(τ) > 0（天下无道时 δ 畸形增高，但有道时 δ > 0 仍成立）
R9: σ 分布的自均衡倾向（有道时 ∇σ → 0 的趋向成立）

**与其他章节的引用**：

```
第46章 ↔ 第44章:
  "知足之足" ↔ "知足不辱"
  第44章是原则，第46章扩展到全网状态判断

第46章 ↔ 第30章:
  "祸莫大于不知足" ↔ "物壮则老"
  不知足 = 壮，祸 = 老（V⁻ 级联）

第46章 ↔ 第57章:
  "天下无道戎马生于郊" ↔ "天下多忌讳而民弥贫"
  边界战斗节点增殖 = ε 流阻塞的局域表现
```

**结论**：第46章将"知足"从个体节点的拓扑生存策略（ch44）扩展为全网状态（有道/无道）的判断标准。当大部分节点的度数稳定在自然最优范围内时，ε 流在全域畅通——这就是"天下有道"的拓扑定义。当大量节点不知足地过度增长时，σ 分布畸变累积，战斗节点在边界增殖——这就是"天下无道"的自组织图景。"知足之足，常足矣"=可持续的拓扑稳态不来自无限增长——来自每个节点在自身自然容量内的自约束。
