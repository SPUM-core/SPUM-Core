## 一、核心映射锚点（全文统一，不偏移）

### 锚点 1：道 = 全域边集合 ε

道是一切节点间的关联、作用力、演化流、因果脉络、动态交互。
无实体形态，是网络运行的基底——**纯粹的关系活动是唯一本原**（反转图论）。

```
道 := ε
```

- **≠ 混沌/未分化态**（早期误读）：道是边本身——两个节点之间的那条连线。
- **≠ "宇宙规律"**（哲学抽象化）：道不是抽象原则，是 ε——具体存在的、逐帧演化的关系网络。
- **字面即定义**："道"的本义是"连接两个个体的路径"——正是 SPUM 中边的拓扑角色。

### 锚点 2：名/万物/有/器 = 节点集合 P

所有可区分、可命名、可观测、可分割的独立存在单元。

```
名/万物/有/器 := P
```

凡文中出现**物、象、身、民、天地、善恶、美丑、长短**等具象/概念名词，统一译为拓扑节点 $P_i$。

### 锚点 3：常道 vs 可道

| 概念 | SPUM | 定义 |
|------|------|------|
| 常道 | ε（完整全域） | 完整未截断的全域边集——无法被任何观察者完整获取 |
| 可道 | ε'（局部边子集） | 人为截取、固化、分割的局部边子集——观察者邻域内的可追踪路径 |

**"道可道，非常道"**：可被追溯描述的局部连接路径（可道=ε'），不等于恒常完整的全域边流（常道=ε）。

### 锚点 4：常名 vs 可名

| 概念 | SPUM | 定义 |
|------|------|------|
| 常名 | 原生节点（嵌入全网） | 未被单独割裂、嵌入完整连接网络的原生节点 |
| 可名 | 孤立标注节点 | 人为提取、定义、孤立标注的单一节点，切断了原有连接 |

**"名可名，非常名"**：可被单独命名割裂的节点（可名），不是嵌入完整网络的原生单元（常名）。

### 锚点 5：无 vs 有

| 概念 | SPUM | 定义 |
|------|------|------|
| 无 | 纯 ε 流拓扑基底 | 未生成独立节点、仅存纯粹关系流的拓扑基底。非"虚空"——是边流尚未析出节点的前状态 |
| 有 | P 中的节点 | 节点从关系流中析出，形成可辨识、可区分的独立单元 |

**"无，名天地之始；有，名万物之母"**：无边基底的纯关系流是所有网络演化的起点（无）；节点从关系流中析出是一切具象存在的生成源头（有）。

### 锚点 6：玄 —— 节点与边的拓扑过渡区域

玄 = 节点与边相互转化、边界模糊的拓扑过渡区域。

```
玄 := ∂(ε ↔ P)   （节点↔边转化的拓扑边界层）
玄之又玄 := 全域网络持续自演化的循环动态
```

**"此两者，同出而异名，同谓之玄"**：无边基底（无）与有节点网络（有）二者同源，仅因观测切割产生两种命名，二者交界的过渡拓扑区域即"玄"。

### 锚点 7：德 —— 单节点局部连接子图

德 = 单个事物专属的关系网络——该节点及其所有直接连接构成的局部子图。

```
德(v) := ε(v) = { (v, u) ∈ ε | u ∈ neighbors(v) }
```

- **上德**：节点的局部连接子图顺应全域 ε 的自然演化趋势——不主动切断边，不强制建边
- **下德**：节点人为强制修改局部连接——破坏全域均衡

**"道生之，德畜之"**：道（ε）使万物得以存在（确认节点），德（局部 ε(v)）维持节点的连接稳定（畜=蓄养）。

### 锚点 8：一/二/三 —— 拓扑自生成层级

| 概念 | SPUM | 定义 |
|------|------|------|
| 一 | ⟨P, ε⟩ | 完整连通拓扑总网络。空白基底纯边流 → 自组织形成完整连通总图 |
| 二 | {V⁺ 倾向边, V⁻ 倾向边} | 总图分化两类基础关系边——正负流量/生克方向 |
| 三 | {V⁺, V⁻, 稳定} | 二元关系交互催生三类基本拓扑操作。三者覆盖网络上一切可能变化——不存在第四种独立操作 |
| 万物 | 衍生节点集群 | 海量分层节点簇——全部稳定子图构型。包括12-晶子闭环（暗物质）、移动拓扑缺陷（光子）、缺口互锁静止态（物质）、集中剩余张力（引力） |

> 详细推演见 `spum-道生万物.md`，「三」的几何必然性（$2^2-1=3$）推导见 `spum-永恒粒子.md`。

### 锚点 9：无为 vs 有为

| 概念 | SPUM | 定义 |
|------|------|------|
| 无为 | 不干预 ε 原生流 | 不人为裁剪、阻断、强制改写原生边流，顺应拓扑自然演化 |
| 有为 | 强制修改边集 | 人工强行修改节点连接，破坏全域均衡 → 局部子图失衡崩塌 |

**无为 ≠ 什么都不做**。无为 = 顺应 Σ(6−deg)=12 约束下的自然演化——不在此约束之外施加人为干预。

### 锚点 10：水/谷/空/朴 —— 低度数开放节点

水/谷/空/朴 = 低度数、无固化边界、不自我孤立的松弛节点。

```
deg ≈ 2（维持存在的最低度数约束）
开放连接 = 不主动切断边、不形成排他性闭环
```

- **为何持久**：低度数 → 能耗低；高开放 → 可承接全域 ε 流；无固化边界 → 不阻断拓扑演化。
- **对比**：刚/强 = 大量自环封闭边 → 内部应力积累 → 拓扑崩塌。

## 二、三层翻译规则（全文统一执行标准）

### 第一层：字词转译规则

| 原文词类 | SPUM 符号 | 示例 |
|---------|----------|------|
| 具象/概念名词（物、象、身、民、天地、善恶、美丑、长短…） | 拓扑节点 $P_i$ | "天下皆知美之为美" → 全域 σ 分布中产生了 ∇σ(美)≠0 的梯度差异 |
| 动态作用词（行、生、灭、和、争、载、化、导、交、损、益…） | 关系边 $\varepsilon_{ij}$ | "有无相生" → 有节点(P)与无基底(ε流)之间存在双向 V⁺/V⁻ 转化边 |
| "常、恒、久" | 未被人为切割的完整原始网络 | "知常曰明" → 认知到全域 ε 的完整拓扑状态即为"明" |
| "言、名、制、分" | 人类对网络的局部截取操作 | "始制有名" → 人为开始切割、命名节点（定义可名而非认知常名） |

### 第二层：句式逻辑转译规则

**辩证句（有无、难易、高下、祸福）→ 成对节点互斥绑定共存**

不存在孤立单一节点。所有概念节点依靠对立关系边获得存在性：

```
P_美 ⟂ P_恶      （互斥边 —— 定义"美"必然同时生成"恶"）
P_有 ⟷ ε_无      （互补边 —— "有"从"无"中析出，二者相互定义）
```

古文"有无相生，难易相成"的 SPUM 标准化表达：

> 在全域 σ 分布中，不存在孤立的单一概念节点。任何概念 P_i 的存在性，由其与对立概念 P_j 的拓扑差异边 ε_{ij} 唯一确定。删除 ε_{ij} → P_i 和 P_j 同时失去定义。∇σ(P_i, P_j) ≠ 0 是概念存在的充要条件。

**演化句（道生一，一生二…）→ 拓扑自生成规则**

见 `spum-道生万物.md` 的完整推演链。

### 第三层：价值体系转译规则

| 道德经推崇 | SPUM 节点结构 | 拓扑优势 |
|-----------|-------------|---------|
| 朴 | deg ≈ 2，邻接集均匀分布 | 最低能耗，最长存续 |
| 静 | ∂S/∂t ≈ 0，S 在 H 中心 | 暂态稳定，无额外 V⁺/V⁻ 波动 |
| 柔 | 低局部闭环，无刚性环边锁定 | 可随 ∇σ 重塑形态，不折断 |
| 不争 | 不主动创建排他性 V⁺ 边 | 不挤压邻居的 σ 空间 |

| 道德经否定 | SPUM 节点结构 | 拓扑风险 |
|-----------|-------------|---------|
| 强/刚 | 大量自环边，闭环锁定 | 内部 σ 应力积累 → 一次性 V⁻ 级联崩塌 |
| 奢 | 过度 V⁺ 累积，超 dv/dt | 超出容量天花板 → 拓扑不自洽 |
| 争 | 主动创建排他性 V⁺ 边 | 挤压全局 σ 分布 → 触发级联冲突 |
