# SPUM × 道德经：翻译输出规范 + 质量控制

> 定位：规定道德经 SPUM 翻译的两种输出形式、质量控制标准、与父模块的接入规范。

---

## 一、翻译成品两种输出形式

### 形式 A：文本释义版（可读科普向）

保留古文原文，紧随其后白话文 SPUM 转译，末尾加注拓扑逻辑说明。适合阅读理解与科普传播。

**格式模板**：

```markdown
### 第 N 章：{章名或首句}

**原文**：
{古文原文}

**SPUM 转译**：
{白话文 SPUM 翻译——使用"关系网络""节点""连接""演化步数"等通俗用语，禁止出现 ε/P/V⁺/V⁻ 符号}

**拓扑注解**：
- 节点结构：{本章涉及何种节点拓扑形态}
- 边流模式：{本章描述何种关系连接模式}
- 稳态分析：{对应 S∈H 还是 S∉H}
```

### 形式 B：纯符号拓扑版（理论演算向）

全文完全使用 ⟨P, ε⟩、子图、边流量、拓扑演化等专业符号书写。剥离文学修饰，仅保留纯离散关系逻辑。可直接导入 spum-core 图谱程序做计算推演。

**格式模板**：

```markdown
### §N: {节点标识}

**输入符号**：
P_i (i=1..k) — 本章涉及的节点集合
ε_ij — 本章涉及的边集合

**拓扑推导**：
{纯数学符号推演链，无自然语言}

**约束条件**：
{涉及的 SPUM 公理约束——Σ(6−deg)=12 / dv/dt≤const / 悬挂端必残留}
```

**示例（第 42 章纯符号版）**：

```
§42: 道生万物

输入: ε（全域边基）

推导:
  ε → ⟨P₀, ε₀⟩                        (自组织 → 总图)
  ⟨P₀, ε₀⟩ → {ε⁺, ε⁻}                 (分化 → 两类边)
  {ε⁺, ε⁻} → {V⁺, V⁻, 稳定}           (交互 → 三种操作)
  {V⁺, V⁻, 稳定}^τ → CES(P_τ, ε_τ)     (逐帧迭代 → 全部稳定构型)

约束:
  ∀τ: Σ(6−deg(v)) = 12                (拓扑不变量)
  ∀v: |Δdeg(v, τ)| ≤ dv/dt             (单帧容量上限)
  ∀τ: δ(τ) > 0                         (不完美定理)

注解:
  万物 = ∪_{τ→∞} CES(P_τ, ε_τ)
  负阴抱阳 ⇔ ∀子图: V⁺_rate + V⁻_rate → 0 (动态平衡)
```

## 二、质量控制标准

### 2.1 自洽性检查

每章翻译完成后，执行以下三项闭合检查：

| 检查项 | 方法 | 不通过处理 |
|--------|------|----------|
| **概念溯源** | 每章中的每个核心概念能否在 10 项锚点中定位 | 未定位 → 补充锚点或标注为"待归约" |
| **符号一致性** | 同一个道德经概念在不同章节中的 SPUM 符号是否一致 | 不一致 → 择一统一，标注迁移记录 |
| **公理闭合** | 推演链是否可在 N001-N022 的现有 edges.txt 上追溯 | 不可追溯 → 标注为"新建推导边"，记录到儒释道子网 |

### 2.2 版本管理

- 每章翻译标注 **归约层级**（M1 语义对应 / M2 图论精确化）
- M1 级别的释义为"初译"，可被后续 M2 版本替换
- M2 级别的释义为"定译"，修改需在儒释道子网的归约计划中记录

### 2.3 与父模块的接入

翻译成品通过以下路径接入儒释道总网：

```
道德经/spum-章节释义.md (每章逐译)
  │
  ├──▶ 提取核心节点 → 注册到 儒释道哲学/skill.md
  │      （当前 DAO-001~009 已注册，后续章节新增节点追加为 DAO-010+）
  │
  └──▶ 提取跨区交叉边 → 添加到 儒释道哲学/skill.md 的边图
         （如：DJ-021(反者道之动) → BUD-004(如来藏) 的共享拓扑结构边）
```
