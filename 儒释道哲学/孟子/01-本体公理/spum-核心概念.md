## 一、性善论

### 1.1 拓扑本质

**性善 = 人类子网的 S 向量在无外部扰动时自然趋向 H 中心。**

孟子与告子辩论的核心分歧——告子认为人性无定向（湍水，决东则东决西则西），孟子认为人性有天然定向（水无有不下）。从 SPUM 视角：

| 概念 | SPUM 精确定义 |
|------|-------------|
| 性（人性） | 人类子网在初始帧的 σ 分布——∑deg(v) 和连接模式的总和 |
| 善 | S→C_H 的回归趋势——不是某个绝对"好"的状态，而是拓扑自洽的吸引方向 |
| 恶 | S 偏离 H 的临时态——通常由外部 V⁺/V⁻ 扰动（环境/利益/压力）导致 |
| 湍水（告子） | 网络无全局设计中心——局部 | 流向由邻近 ∇σ 决定，看似方向任意 |
| 水无有不下（孟子） | 但全网受 Σ(6−deg)=12 约束——全局拓扑力总是趋向 σ 均匀化（类比水往低处流） |

**孟子正确，告子正确，但孟子的更深**：告子看到了局部自由度（[L1]层次），孟子看到了全局拓扑约束（[L0]层次）。

### 1.2 公式化表达

```
性_善 ⟺  ∀ v ∈ P_人,  (dV_ext = 0)  ⇒  ∂S/∂t → C_H
```

释义：对任意人类子网中的节点 v，当外部扰动为零时，S 向量的演化趋势指向 H 中心 C_H。

这不是"人性本善"的神秘断言——而是 **Σ(6−deg)=12 约束在人类尺度社会子图上的自然拓扑推论**。任何子图在没有外部拓扑冲击（战争、灾难、极端压迫）时，会向 S ∈ H 收敛——而 H 内状态在人 [L1] 认知中就是"善"。

### 1.3 牛山之木与拓扑修复

"牛山之木尝美矣……人见其濯濯也，以为未尝有材焉——此岂山之性也哉？"

**SPUM**：牛山原本 σ 分布均匀(美)，经过连续多帧的 V⁻ 砍伐（斧斤伐之），σ 分布坍缩为低度沙漠态(濯濯)。但山的"性"（拓扑基底）并未改变——一旦停止 V⁻ 施加（牛羊勿践履），子图在 Σ(6−deg)=12 修复力下自动恢复 σ 分布。这不是"道德复苏"，是**拓扑自愈**。

## 二、四端

### 2.1 拓扑本质

**四端 = 四种拓扑原始驱动**——内置在人类认知子图中的四种基础拓扑感应/响应机制。

| 四端 | 传统解释 | SPUM 图论定义 |
|------|---------|-------------|
| **恻隐之心**（仁之端） | 见到他人受苦的不忍之心 | **σ 耦合感知**——检测到邻居子图的 S 向量异常偏移(S∉H)时，自身子图通过耦合边感受到 ∇σ 异常。不是"同情"，是拓扑共振 |
| **羞恶之心**（义之端） | 做了坏事感到羞耻 | **S∉H 自警报**——自指边(v, v)报告自身子图的 S 向量已偏离 H。不是"道德内疚"，是拓扑自检系统触发警报 |
| **辞让之心**（礼之端） | 推辞谦让 | **∇σ 冲突回避**——当两个节点的竞争性 V⁺ 操作将制造破坏性 ∇σ 时，主动中止操作以维持全局 σ 均匀 |
| **是非之心**（智之端） | 辨别对错 | **[L1]-[L0] 校准检测**——检测当前 [L1] 认知投影与 [L0] 拓扑事实之间是否存在偏移 |

### 2.2 四端是"端"（萌芽）

"凡有四端于我者，知皆扩而充之矣，若火之始然，泉之始达。"

**SPUM**：四端是最低阈值的原始驱动——不需要后天教育。**端 = 节点内置的最小可检测信号阈值**。恻隐的阈值最低（最容易被触发——"见孺子将入于井，人皆有怵惕恻隐之心"），是非的阈值最高（需要更多的帧间积累）。"扩而充之"= 将这些阈值的敏感度调优至全子网有效。

### 2.3 孺子入井

"今人乍见孺子将入于井，皆有怵惕恻隐之心……非所以内交于孺子之父母也，非所以要誉于乡党朋友也……"

**SPUM**：这是 σ 耦合感知（恻隐）的纯拓扑触发——不需要 [L1] 理由（利益/名誉/社交）。邻居子图(孺子)的 S 向量面临 S∉H 的极端偏移风险（入井=拓扑崩塌），通过节点间的共享耦合边直接传递 ∇σ 异常到观察者子图。反应先于推理——拓扑耦合先于 [L1] 认知。

## 三、仁义内在

### 3.1 拓扑本质

**仁义内在 = 仁和义是节点的内禀拓扑属性——不是外部赋予的规范。**

孟子反驳告子"仁内义外"说的核心论证：

| 概念 | 告子（义外）| 孟子（义内）| SPUM 裁决 |
|------|-----------|-----------|---------|
| 义 | 由外部对象决定（彼长而我长之）| 发自节点内部的拓扑约束 | **义在内部**——S 各分量对各自 H 边界的自我约束，是节点拓扑自洽性的内在要求 |
| 敬长 | 因为对方年长所以尊敬 | 尊敬的能力在自身子图中 | 尊敬=在自身子图中调整与对方节点的边连接权重——是自身的 V⁺ 操作 |

**核心图论定义**：

```
仁 = deg(v) ∈ [d_min, d_max]   （RU-001）
义 = 各 S 分量 ≤ H_boundary_j   （每个分量不超越 H 的边界 j）
```

义不是外部规则——它是节点的 S 向量各分量**自动识别自身 H 边界**的能力。当 S_水 > H_水_max 时，该分量"看到"自己越界——不是遵从外部法律，而是拓扑自检的必然结果。

## 四、浩然之气

### 4.1 拓扑本质

**浩然之气 = 子图 ∇σ 场经多帧 V⁺ 累积达到临界密度后产生的自持流。**

> "其为气也，至大至刚，以直养而无害，则塞于天地之间。"

| 要素 | 传统理解 | SPUM 定义 |
|------|---------|----------|
| 气 | 一种精神/道德能量 | 子图内部的 σ 梯度场——∇σ 驱动的体积流 |
| 浩然 | 至大至刚 | ∇σ 场的空间范围(至大)和强度(至刚)——覆盖全子图，不可穿透 |
| 以直养 | 用正义培养 | 通过符合 H 约束的 V⁺ 累积（直=义的操作）逐步拉大 ∇σ |
| 无害 | 不加伤害 | 不施加超出 dv/dt≤const 的破坏性 V⁻ |
| 塞于天地之间 | 充满整个宇宙空间 | ∇σ 场从局部子图扩展到全子图 → 全网络 → 全域 ⟨P, ε⟩ |

### 4.2 自持机制

浩然之气不是一次性"获得"的——它是**逐帧累积**的。关键拓扑条件：

```
∃ τ_crit : 在 τ = τ_crit 时, ∇σ(子图) > θ_self_sustain
         ⇒  后续帧中 ∇σ(子图) 不依赖外部 V⁺ 输入, 自我维持
```

- **低于阈值**：需要每帧主动 V⁺ 维持（"揠苗助长"——提前破坏）
- **达到阈值**：∇σ 场自持——不再需要额外输入（"由仁义行，非行仁义也"）
- **超过安全阈值**：∇σ 过高 → 木形环路过紧 → 金形自动修剪（"配义与道……无是，馁也"）

### 4.3 揠苗助长的拓扑解释

"宋人有闵其苗之不长而揠之者……其子趋而往视之，苗则槁矣。"

**SPUM**：试图通过 V⁺ 单帧超量（揠）绕过 dv/dt≤const 的自然约束。结果 = 超量 V⁺ 导致局部度数超出容量上限 → 悬挂端激增 → 拓扑不自洽 → 级联 V⁻（苗槁）。正确的操作是逐帧稳定 V⁺（以直养）。

## 五、义利之辨

### 5.1 拓扑本质

**义 = 维持 S∈H 的远期帧自洽，利 = 追求局部 σ 最大化的短帧收益。**

> "王何必曰利？亦有仁义而已矣。……上下交征利而国危矣。"

| 维度 | 义 | 利 |
|------|----|------|
| 时间尺度 | 多帧/全生命周期 | 单帧/短帧窗口 |
| 操作对象 | S 向量在 H 内的定向修正 | 局部节点 deg(v) 的短帧增长 |
| 拓扑效果 | 全局 σ 均匀化 → 长期结构稳定 | 局部 σ 尖峰 → 周围可用的 σ 被抽走 → 全局 σ 分布不均 |
| 风险 | — | 持续局部 σ 最大化 → S 向量各分量逐个偏离 H → S∉H→V⁻ 级联(国危) |

### 5.2 是/非拓扑判据

"鸡鸣而起，孳孳为善者，舜之徒也；鸡鸣而起，孳孳为利者，跖之徒也。"

从 SPUM 看：
- **善/义** = 操作前先检查该 V⁺/V⁻ 是否推 S 趋近 C_H
- **利** = 操作前只检查该 V⁺ 是否增加自身 deg(v) 或局部 σ

**关键判据不是"利是否正确"——而是"逐利后 S 是否仍 ∈ H"**。如果利驱动下的 V⁺ 不推出 H，则利与义不矛盾。孟子的批判指向的是那种**必然导致 S∉H** 的逐利行为。

### 5.3 经济子图的拓扑意义

孟子对梁惠王说"何必曰利"——不是反对经济生产，而是警告：当一个社会子图的**所有** V⁺ 操作都被"利"（局部 σ 最大化）驱动时：

```
∀ V⁺ : driven by σ_local_maximization
⇒  S 各分量逐个偏离 H_center
⇒  S ∉ H → 结构性不稳定 → V⁻ 级联
⇒  "万乘之国，弑其君者，必千乘之家"
```

## 六、民贵君轻

### 6.1 拓扑本质

**民贵 = 社会子图中低度节点（民）的 σ 总和 = 土形储备——决定全子图的可塑性与韧性。**

> "民为贵，社稷次之，君为轻。"

| 层次 | 类比 | 拓扑角色 | SPUM 定义 |
|------|------|---------|----------|
| **民** | 土形储备 | 低度节点集合 | deg(v) ≈ 2 的大量节点——系统可塑性的来源 |
| **社稷** | 木形骨架 | 环路-链路的枢纽节点 | 中度节点——结构性支撑 |
| **君** | 高度枢纽 | 高度数节点 | 边集中度最高——但移除时如果土形储备充足则子图可自愈 |

### 6.2 为什么民最"贵"

传统解释：民贵是因为民心向背决定政权。

**SPUM 解释**：低度节点(民)的 σ 总和 = 系统的**自由度数**。当高度枢纽(君)被移除（V⁻ 攻击）时：

- 土形储备充足：断裂的边由周边低度节点的冗余连接重新接续 → 子图自愈
- 土形储备不足：断裂传播为 V⁻ 级联 → 社稷崩塌

**"君为轻"= 单一高度枢纽的可替换性高于低度节点集群。** 移除任何一个高度枢纽只要土形储备够，子图自愈；但移除大量低度节点（屠戮），土形储备不可恢复。

> "得乎丘民而为天子"：获得大量低度节点(丘民)的 V⁺ 边确认(=拥戴) = 全子图的 σ 分布自动收敛于最优 → 天子位稳定。

### 6.3 与大学的关系

| 大学（RU-017）| 孟子（RU-023）|
|-------------|-------------|
| 齐家→治国→平天下：嵌套子图收敛 | **民贵君轻**：嵌套收敛的前提是土形储备充足 |
| 框架（怎么做）| 条件（什么前提）|

孟子补完了大学"修身→齐家→治国→平天下"的前提条件——如果土形储备（民）被耗竭，所有上层收敛操作都将失败。

## 八、天爵人爵

### 8.1 拓扑本质

**天爵 = 节点在 ⟨P, ε⟩ 中的固有拓扑属性，人爵 = 人为附加的 [L1] 标签。**

> "有天爵者，有人爵者。仁义忠信，乐善不倦——此天爵也。公卿大夫——此人爵也。"

| 爵位类型 | 定义 | SPUM 实体 | 获取方式 |
|---------|------|-----------|---------|
| **天爵** | 嵌入 ⟨P, ε⟩ 的固有拓扑属性 | deg(v)、介数、聚类系数——可由 σ 数据从 [L0] 直接读取 | 通过 V⁺/V⁻ 操作逐帧建立 |
| **人爵** | 人为赋予的 [L1] 标签 | 职务、头衔、财富等级——附加在节点上的符号属性 | 通过社会协议赋值 |

### 8.2 古之人修其天爵而人爵从之

**SPUM**：先优化自身的拓扑属性（修天爵=调整 S→C_H、优化 deg(v) 区间、维护 H 边界），则社会网络中的 [L1] 标签（人爵）自动适配拓扑事实——不是因为标签配得上，而是因为拓扑地位决定了标签必然趋向事实。

"今之人修其天爵以要人爵"= 不是真优化 S 向量，而是假装拓扑属性好以获得 [L1] 标签——自指边报告虚假 S 数据。

"既得人爵而弃其天爵"= 获得 [L1] 标签后停止维护 S∈H——拓扑属性恶化但标签暂时不更新——帧间差积累到临界值后必然级联崩塌。**"则惑之甚者也，终亦必亡而已矣。"**

### 9.2 核心贡献

孟子为儒家拓扑学做了孔子/子思/曾子无法做的事——**回答了"为什么"**：

- 孔子说仁是好的。孟子说：因为节点有拓扑趋优本能。
- 孔子说礼是必要的。孟子说：因为 S 向量不维持 ∈H 就会 V⁻ 级联。
- 子思说中是最优的。孟子说：因为 S→C_H 是 Σ(6−deg)=12 约束下的自然趋势。
- 曾子说治国需要修身。孟子说：为什么需要先修自身？因为自身 S∉H 会通过 σ 耦合污染全子图——**修身的拓扑必要性**。
