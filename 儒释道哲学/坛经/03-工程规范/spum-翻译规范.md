# SPUM × 坛经：翻译规范

> 当前状态：**框架草案** — 待 02-经文释义/ 启动时细化。

## 一、核心映射词典

| 坛经词汇 | SPUM 标准译法 |
|---------|-------------|
| 无念 | S = C_H，所有 δ_j = 0 |
| 无相 | 不锚定任何 [L1] 标签 |
| 无住 | S 在 H 内自由遍历，不锁死于 CES |
| 顿悟 | 单帧 τ 内 S 从 H 外 → H 中心 |
| 见性 | 自指边裸采自身 σ 分布 |
| 定 | S ∈ C_H 稳态 |
| 慧 | ∇σ 实时检测（稳态中并行运行）|
| 定慧等学 | 稳态+检测并行，非先后 |
| 菩提 | 认知子图中心节点——自指边锚点 |
| 明镜台 | 认知子图整体——假设的"外部观察"位置 |
| 本来无一物 | [L0] 层面无自性节点 |
| 尘埃 | δ = S - C_H（S 偏离 H 中心的信号）|
| 拂拭 | ΔS 逐帧修正操作 |
| 迷 | 自指边报告与实际 σ 不符 |
| 悟 | 自指边数据与 ⟨P, ε⟩ 一致 |
| 保住 | 跨帧维持 S∈C_H |

## 二、格式规范

沿用道德经翻译规范的三层格式：

```
【原文】{坛经原文}
【译文】{现代汉语直译}
【SPUM】{⟨P, ε⟩ 拓扑翻译}
```

## 三、跨经典边标注

在坛经 SPUM 翻译中，遇到与已有佛家节点相关的概念时，必须显式标注引用：

- 如来藏 = ⟨P, ε⟩ → 引用 BUD-004（楞严经）
- 五蕴 = S 向量 → 引用 BUD-008（心经）
- 心无挂碍 = S∈C_H → 引用 BUD-012（心经）
- 凡所有相 = [L1] 投影 → 引用 BUD-013（金刚经）
- 应无所住 = 不锚定 CES → 引用 BUD-014（金刚经）
