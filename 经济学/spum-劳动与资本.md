# SPUM × 劳动与资本

> 归约路径：劳动 = deg 贡献给资源转化 V⁺ 事件 → 工资 = deg 的市场价格 → 资本 = 累积 V⁺ 容量 → 利润率 = 资本边增速
> 劳动不是"人力的付出"——是节点将自身度数用于执行资源转化 V⁺ 操作。资本不是"钱"或"机器"——是节点已经累积的 V⁺ 容量——即该节点可以同时维持的连接数和可以执行的转化操作量。

---

## 核心命题

**劳动和资本是同一种东西——V⁺ 容量——的两种存在形态。** 劳动是当前帧中被消耗的 V⁺ 容量（流量），资本是跨帧累积的 V⁺ 容量（存量）。两者的区分只在时间尺度上——劳动是逐帧消耗的，资本是跨帧持有的。

---

## 一、劳动的 SPUM 定义

### 1.1 劳动 = deg 贡献给资源转化

```
Labor(v, t_frame) = deg_productive(v, t)
  其中 deg_productive(v, t) = v 在帧 t 中用于执行 V⁺_resource 操作的度数

简言之：一个人"工作" = 在某帧中将其部分度数用于创造或转化资源的 V⁺ 操作
```

经济学混淆了"劳动"的三重含义：
- **劳动行为** = 当前帧中的 deg 消耗（流量）
- **劳动力** = 节点未来的 deg 消耗潜力（预期流量）
- **劳动成果** = 该帧中 V⁺ 操作产生的资源边增量

### 1.2 劳动分工 = 度数专业化

```
分工 = 不同节点将其 deg 专门用于不同类型的 V⁺ 操作

分工优势（亚当·斯密的制针厂）：
  - 每个节点只执行一种 V⁺ 类型 → 减少上下文切换 → deg 利用效率提升
  - 专业化提升 deg 到 V⁺ 的转化比 → 同样的度数产生更多资源边
  - 交换网络密度增加（σ_econ ↓）→ 价格信号更准确
```

分工的拓扑前提：**经济子图必须足够连通**。如果交易边不足（σ_econ 高），分工出来的产品卖不出去，分工就无法维持。这也是为什么市场规模限制分工——"市场"就是连通子图，"规模"就是子图节点数。

### 1.3 工资 = 劳动度数的市场定价

```
Wage(v) = Price(deg_productive(v))
        = |E_money| / |deg 消耗| —— 货币边 / 消耗的度数
```

工资的水平不由"劳动价值"或"边际产出"单独决定——由**deg 消耗的替代性**决定：

| 高工资条件 | SPUM 机制 |
|-----------|----------|
| deg 不可替代 | 只有少数节点能执行该 V⁺ 类型 → 替代路径稀少 → 要价高 |
| deg 贡献的 V⁺ 规模大 | 同样 deg 消耗产生更多资源边 → 产值高 |
| 交易子图信息充分 | 工人知道自己的 deg 在其他雇主那里的价格 → 形成竞争 |
| 工人有移动性 | 工人节点可以在子图中移动——切换雇主边——增加替代路径 |

## 二、资本的 SPUM 定义

### 2.1 资本 = 累积的 V⁺ 容量

```
Capital(v, t) = 节点 v 在帧 t 时的总 V⁺ 容量 = 
  accumulated V⁺ capacity = Σ_{τ=1}^{t} (V⁺(τ) − V⁻(τ))_{persistent}

即：历史中净积累的、跨帧持续存在的连接能力
```

资本三种形态的 SPUM 统一：

| 资本形态 | SPUM 定义 | 例子 |
|---------|----------|------|
| 物理资本 | 持久化的资源转化 V⁺ 结构——稳定的子图构件 | 工厂、机器、基础设施 |
| 金融资本 | 累积的货币边——可随时兑换为任何资源的对偶令牌储备 | 存款、股票、债券 |
| 人力资本 | 节点自身认知子图中的 V⁺ 操作知识——提升 deg 转化效率 | 技能、教育、经验 |

**三者是同一种东西——跨帧 V⁺ 容量——在不同子图中的投影。**

### 2.2 利息——资本的时间价格

```
Interest = 将当前帧的 V⁺ 容量推迟到未来帧使用的补偿

为什么会有利息？
  1. 当前 σ 缺口 vs 未来 σ 缺口——现在用 vs 以后用的取舍
  2. 不确定性的拓扑表现——未来的 V⁺/V⁻ 序列不可预知
  3. 替代用途的存在——资本现在可以投入其他 V⁺ 路径
```

利息率不是"货币的价格"——是**跨帧 V⁺ 容量分配的拓扑折现率**。利息率高 = 人们更看重现在的 V⁺（当前 σ 缺口大）。利息率低 = 人们愿意把 V⁺ 留到以后（当前 σ 不太紧张）。

### 2.3 利润率——资本 V⁺ 效率

```
Profit_Rate = (ΔCapital / Capital) per frame
            = 每帧资本 V⁺ 容量的净增量 / 总资本 V⁺ 容量
```

利润率下降趋势（马克思的发现）在 SPUM 中的解释：

```
利润率下降的拓扑根源：
  1. 资本 V⁺ 容量越多 → 竞争性替代路径越多 → 价格趋近 σ 均衡
  2. 价格趋近 σ 均衡 → 货币边/资源边比率下降 → 利润空间压缩
  3. 不完美定理：永远会有局部的 ∇σ ≠ 0 → 总能找到利润 → 但越来越难
```

这不是"资本主义的内在矛盾"——是**任何基于 V⁺ 累积的子图达到一定规模后的拓扑饱和效应**。

## 三、劳资关系的拓扑学

### 3.1 雇佣关系 = 不对称 V⁺/V⁻ 边

```
雇佣边 e = (雇主 → 雇员):
  - 雇员向雇主输送 deg 消耗（劳动 V⁺）
  - 雇主向雇员输送货币边（工资 V⁺）
  - 非对称性：雇主的 deg_econ ≫ 雇员的 deg_econ
    → 雇员更难找到替代雇主边 → 议价能力低
```

### 3.2 剥削的拓扑定义

**剥削 = 不对称度数结构导致的价格偏离 ∇σ 信号。**

```
剥削 = Wage(v) < Price(deg_productive(v))_{在完全替代路径下的定价}

即：工资低于如果存在多个雇主角逐该工人的 deg 时的应有水平
```

剥削不是道德概念（虽然在 [L1] 层面它确实有道德含义）——它首先是**拓扑概念**：当工人的替代雇主路径被阻断时，工资就会被压低到 ∇σ 信号以下。工会、最低工资、劳动法的作用 = **在 G_econ 中为工人节点注入替代路径（或强制价格不跌破底线）。**
