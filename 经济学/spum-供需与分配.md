# SPUM × 供需与分配

> 归约路径：需求 = σ缺口 → 供给 = σ盈余 → 供需匹配 = ∇σ驱动下的资源流 → 分配 = σ分布的历史累积
> 供需不是两条交叉的曲线——是**同一张 σ 分布图上的两个区域**：高 σ（缺资源）= 需求端，低 σ（资源盈余）= 供给端。两者的差值 ∇σ 就是价格信号和资源流动的驱动因。

---

## 核心命题

**供给和需求不是两个独立的力量——它们是一个 σ 梯度的两端。** 没有"供给曲线"和"需求曲线"在二维平面上的神秘交叉——只有一个三维的 σ_resource 分布在逐帧演化。价格在交叉点出现，是因为在那个点上买卖双方的 σ 差距最小化。

---

## 一、需求的 SPUM 定义

### 1.1 需求 = σ 缺口

```
Demand(v, resource_r) = max(0, σ_resource_target(v) − σ_resource(v))

其中：
  σ_resource(v) = v 当前拥有的 resource_r 量 / v 的总度数
  σ_resource_target = v 维持其子图稳态所需的最小 σ_resource
```

需求不是"想要"——是**拓扑必需**。一个节点"需要"食物不是因为"偏好"，而是因为没有食物连接，其物理子图（身体）的度数会下降到致命水平。

### 1.2 需求的层次

| 需求层次 | SPUM 定义 | 传统对应 |
|---------|----------|---------|
| 生存需求 | deg(v) 接近 2——节点接近悬挂（死亡） | 食物、水、住所 |
| 维持需求 | deg(v) > 2 但在 H 边缘——连接稀疏 | 安全、健康 |
| 社会需求 | deg_social(v) < d_social_min——社会孤立 | 归属、关系 |
| 增长需求 | dv/dt 可承载的额外 V⁺——尚有余力 | 发展、自我实现 |

需求层次不是马斯洛金字塔——是**节点的 deg 约束层级**。最底层（deg → 2）的需求必然最紧迫，因为悬挂节点的存在确认最弱。

### 1.3 需求弹性 = σ 替代性

```
需求弹性 = ΔDemand / ΔPrice

在 SPUM 中：
  高弹性：存在替代 resource_r' 满足相同的 σ 缺口（可替代性强）
  低弹性：无替代资源——σ 缺口的唯一填补方式是 resource_r（不可替代）
```

需求弹性不是"消费者心理"——是**资源子图的可替代拓扑**。粮食的需求弹性低，因为在当前 κ 网络中，没有东西可以替代粮食填补人体子图的 σ 缺口。

## 二、供给的 SPUM 定义

### 2.1 供给 = σ 盈余

```
Supply(v, resource_r) = max(0, σ_resource(v) − σ_resource_need(v))

σ_resource_need(v) = v 自身子图维持所需的最小 resource_r 量
σ_resource(v) − σ_resource_need(v) > 0 → 盈余 → 可供给
```

供给不是"生产出来卖的东西"——是**节点自身子图中超出维持需要的资源连接量**。一个农民有粮食盈余，不是因为"他决定卖"——是因为他的子图不需要那么多粮食连接，多余的粮食边对他无用，但对于 σ 缺失的节点却极其有用。

### 2.2 供给的拓扑约束

| 供给约束 | SPUM 解释 |
|---------|----------|
| 生产能力上限 | dv/dt ≤ const ——单帧内的最大 V⁺ 产量 |
| 运输成本 | 交易边长度 L——资源从 vᵢ 到 vⱼ 需要的中间节点数 |
| 存储成本 | 未交换的资源边占用 deg 容量——降低节点灵活性 |
| 信息成本 | 寻找买家的 V⁺ 传播——价格信号沿交易边扩散 |

### 2.3 供给曲线为什么向上倾斜

经济学说"价格越高，供给量越大"——SPUM 的解释：

```
价格 ↑ → |E_money|/|V⁺_resource| ↑ → 同样的资源 V⁺ 换取更多的货币边
  → 原来不值得交易的边际供应者（运输 L 大、σ 盈余小）现在值得交易了
  → 更多节点进入供给 → 供给量增加
```

这不是"贪婪"——是**运输成本和节点容量约束**。当价格覆盖运输成本后，远程供应商才会被拉入交易子图。

## 三、分配的 SPUM 定义

### 3.1 分配 = σ 分布的历史快照

**资源分配 = 当前帧中 σ_resource 在 V_econ 上的分布。**

这个分布由历史交易序列决定——每一帧的交易都在修改 σ_resource 分布。当前帧看到的不平等，是过去所有帧的 V⁺/V⁻ 累积结果。

### 3.2 分配不平等的三种来源

| 不平等来源 | SPUM 机制 | 例子 |
|-----------|----------|------|
| 初始禀赋差异 | 初始帧中 σ_resource 分布已经不均匀 | 生在富裕家庭 = 初始 deg 更高 |
| 马太效应（V⁺ 正反馈） | deg 高的节点获得更多 V⁺ 机会 → deg 更高 | 富人更容易获得投资 |
| 路径依赖 | 过去的交易边锁定了未来的交易方向 | 产业聚集、地理锁定 |

### 3.3 再分配 = 强制 σ 重分布

```
再分配（税收/转移支付）：
  1. 从 σ_resource 低的节点强制 V⁻_resource（征税）
  2. 向 σ_resource 高的节点强制 V⁺_resource（转移）
  3. 对全局 ∇σ_resource 的降低效果取决于：
     - 转移效率（中间节点的消耗）
     - 是否扭曲了价格信号（货币边总量的变化）
```

再分配不是"劫富济贫"——是**人为加速 ∇σ_resource 的趋零过程**。市场自然也会趋零（通过交易），但速度受限于 dv/dt ≤ const 和不完美定理。政府干预是在市场 ∇σ 趋零太慢时，注入额外的 V⁺/V⁻ 事件来加速。

## 四、供需匹配——市场出清的拓扑过程

### 4.1 出清 = ∇σ_resource → 0 在可交易范围内

```
市场出清（market clearing）：
  对于某种资源 r，在当前的交易子图内，所有需求方（σ_r 高）和所有供给方（σ_r 低）
  已经完成了所有有利可图的交易——即任何剩余交易都会使至少一方变差。
```

从 SPUM 视角，出清 = 剩余 ∇σ_r 的幅度小于最低运输成本——不值得再交易了。

### 4.2 为什么市场不一定出清

| 不出清原因 | SPUM 机制 |
|-----------|----------|
| 价格粘性 | 价格信号传播速度 < 交易速度——信息 V⁺ 滞后 |
| 信息不对称 | 买卖双方不在同一个连通分量——无法相互发现 |
| 交易成本过高 | 运输路径 L 太长——∇σ 不足以覆盖 |
| 制度阻隔 | 制度边（见 spum-制度.md）阻断了供需匹配路径 |
| 非理性预期 | 价格信号中包含自指反馈环（泡沫）——偏离 ∇σ 信号 |

## [L0] 还原表

| 经济学概念 | SPUM 图论对应 |
|-----------|-------------|
| 需求 | σ_resource 缺口——节点维持子图所需与当前拥有之差 |
| 供给 | σ_resource 盈余——超出节点自身维持需要的资源连接量 |
| 供给曲线 | 当价格覆盖运输成本后，更多节点进入供给——由 σ 盈余 + L 运距决定 |
| 需求弹性 | 资源子图的可替代拓扑——是否有替代资源填补 σ 缺口 |
| 分配 | σ_resource 在 V_econ 上的当前分布——历史交易序列的累积 |
| 分配不平等 | σ_resource 分布的方差——马太效应 V⁺ 正反馈加剧 |
| 再分配 | 强制 V⁺/V⁻ 操作——人为加速 ∇σ 趋零 |
| 市场出清 | 剩余 ∇σ_resource 小于最低运输成本——交易终止 |
