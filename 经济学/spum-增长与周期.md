# SPUM × 增长与周期

> 归约路径：增长 = 经济子图的净 V⁺ 累积 → GDP = 总交易边权重和 → 周期 = σ 振荡波 → 繁荣 = ∇σ 急速趋零 → 衰退 = V⁻ 回撤 → 长期停滞 = dv/dt 趋近天花板
> 经济增长不是"经济规模的扩大"——是**经济子图的节点度数增加和交易边权重增长**。商业周期不是"经济的自然波动"——是**σ 分布围绕均衡的阻尼振荡**。

---

## 核心命题

**经济增长 = 经济子图中净 V⁺ > V⁻ 的持续累积。** GDP 不是抽象的"产出"——是交易边权重的总和。衰退不是"经济下行"——是交易子图的 V⁻ 事件在特定帧内超过 V⁺。长期停滞不是"需求不足"——是 dv/dt 逼近了该经济子图的天花板。

---

## 一、增长的 SPUM 定义

### 1.1 经济增长 = 净 V⁺ 累积

```
Growth(frame t) = Σ (V⁺_econ(t) − V⁻_econ(t))

即：该帧内新建交易边和强化交易边的总和，减去断裂和衰减的交易边
```

GDP（国内生产总值）= Σ（在特定行政子图内发生的所有交易边权重之和）。GDP 衡量的不是"价值"——是**交易边的总流量**。这就是为什么家务劳动不计入 GDP（没有交易边），而同样的劳动外包后就计入（有了交易边）。

### 1.2 增长的拓扑来源

增长的来源只有三种——全部是可追踪的 V⁺ 事件：

| 增长来源 | SPUM 机制 | 例子 |
|---------|----------|------|
| **新资源 V⁺** | 发现/创造新的资源类型——开辟全新的资源子图 | 新矿产、新技术产品 |
| **新交易边** | 之前互不交易的节点之间建立交易路径 | 全球化、新市场 |
| **效率提升** | 同样的 deg 消耗产生更多 V⁺——转化比提升 | 技术进步、管理改善 |

传统经济学把第三项（效率提升）称为"全要素生产率"，然后说"我们不知道为什么它会增长"。SPUM 的答案：效率提升 = 交易子图中替代路径的增多 + 信息传播路径的缩短。

### 1.3 增长的天花板

```
增长约束 = dv/dt ≤ const（单帧 V⁺ 变化上限）

每个经济子图都有一个由以下因素决定的增长天花板：
  1. 物理天花板：资源总量守恒——全球资源边总量有上限
  2. 认知天花板：每个节点的 deg 容量有限——人只能处理有限交易伙伴
  3. 拓扑天花板：交易路径 L 有下限——不能短于 1 步（直销）
```

当一个经济子图逼近天花板时，增长率自然下降——这不是"政策失败"，是**拓扑饱和**。日本 1990 年代以来的低增长、欧洲的低增长——都可以从这个角度重新理解。

## 二、经济周期的 SPUM 定义

### 2.1 周期 = σ 分布的振荡

```
经济周期 = ⟨σ_econ(t), ∇σ_econ(t)⟩ 的时间序列振荡

繁荣期：∇σ 大 → 交易活跃 → σ 快速下降 → 价格信号强
衰退期：∇σ 小 → 交易减速 → σ 上升 → 价格信号弱
```

这个过程不是"动物精神"或"信心波动"——是**σ 自反馈系统**的自然振荡：

```
繁荣机制：
  σ 低（连接多）→ 交易活跃 → 价格信号清晰 → 更多 V⁺ → 更多连接 → σ 更低
  → 但最终触及 dv/dt 天花板 → V⁺ 无法继续加速 → ∇σ 开始缩小

衰退机制：
  ∇σ 缩小 → 交易减少 → V⁻ 开始超过 V⁺ → deg 下降 → 部分交易边断裂
  → σ 回升 → 直到 ∇σ 重新出现 → 新一轮繁荣
```

### 2.2 周期阶段的拓扑特征

| 周期阶段 | σ 状态 | 交易边 | 节点度数 | 价格信号 |
|---------|--------|--------|---------|---------|
| 扩张 | σ↓ ——密度上升 | V⁺ > V⁻ | deg 整体上升 | 价格信号清晰 |
| 顶峰 | σ 接近最小值 | V⁺ ≈ V⁻ | deg 接近天花板 | 信号最强 |
| 收缩 | σ↑ ——密度下降 | V⁺ < V⁻ | deg 整体下降 | 信号开始模糊 |
| 谷底 | σ 接近最大值 | V⁺ 回升 | deg 在低点稳定 | 信号最弱 |

### 2.3 为什么无法消灭周期

**不完美定理（R5）保证周期不可消除。** 每帧必然残留悬挂端——在经济子图中，表现为：

- 刚进入市场的新节点（deg_econ < 2）——经济经验的悬挂端
- 价格信号传递不到的边远节点——信息悬挂端
- 技术过时的交易边——结构悬挂端

这些悬挂端是下一帧 V⁺ 的启动点——它们驱动着复苏。试图"熨平周期" = 试图消除悬挂端 = 消除下一波增长的起点。最好的政策不是"消除周期"，而是**让周期的振幅不超过 H_econ（经济健康多面体）**。

## 三、长期增长趋势

### 3.1 长期增长 = 天花板的外推

```
长期增长率 = f(技术进步, 资源发现, 制度演化)

技术进步 = 新的 V⁺ 操作符——同样的 deg 消耗产生更多资源边 → 天花板外移
资源发现 = 可交易资源子图的扩展——新的资源类型进入 G_econ
制度演化 = 交易边的规则更稳定 → V⁺/V⁻ 摩擦降低 → 转化比提升
```

### 3.2 增长极限——稳态经济

```
稳态（steady-state）= V⁺ ≈ V⁻ ——交易边总量不再净增长

前提：
  1. 资源子图边界已触及——没有新资源可以加入 G_econ
  2. 交易路径已最优化——L_econ 不能再缩短
  3. 所有节点的 deg_econ 已达到其容量天花板
```

稳态不是"停滞"——是经济子图已经**拓扑饱和**。在稳态中，经济活动的意义从"增长"转为"维持"——保持 S_econ ∈ H_econ（经济健康向量的值在健康多面体内）。
