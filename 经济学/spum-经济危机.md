# SPUM × 经济危机

> 归约路径：危机 = V⁻ 级联 → 金融 = 货币子图的连通坍塌 → 实体经济 = 商品子图的连坐崩塌 → 恢复 = σ 重构
> 经济危机不是"市场失灵"或"资本主义的内在矛盾"——是**经济子图中的 V⁻ 级联事件**：一个关键节点的度数检查失败触发连锁删边，波及整个子图。就像金形修剪在社会子图中的运作一样——只不过这次是在经济子图上。

---

## 核心命题

**经济危机 = 经济子图中的 V⁻ 级联。** 机制与社会变迁中的"快变迁"完全相同（见 spum-社会变迁.md §三）：δ（异常比）超过临界值 → 一度数检查触发连锁删边 → 子图碎裂 → 大量节点从子图中脱落（失业/破产）。这不是隐喻——这就是危机发生的实际拓扑过程。

---

## 一、危机的拓扑机制

### 1.1 V⁻ 级联的经济版本

```
经济 V⁻ 级联的触发条件：

  1. 存在节点 v_critical（关键经济节点——通常是大型金融机构或核心产业）
  2. v_critical 的 deg_econ 出现不可恢复的下降（偿付能力丧失）
  3. v_critical 的邻节点注意到这个下降——交易边开始断开
  4. 邻节点的邻节点的 V⁻ 连锁反应
  5. 子图碎裂——交易边大范围断裂
```

级联为什么发生：**经济子图的高度数节点是其他节点 deg 维持的必要条件**。当一个核心银行破产 → 依赖它的企业失去信贷边 → 这些企业无法支付供应商 → 供应商失去收入 → 供应商的员工失业 → 消费交易边断裂 → 更多企业失去收入。这是单帧内的一连串 V⁻——在传统经济学中称为"系统性风险"。

### 1.2 危机的前提条件

| 前提条件 | SPUM 描述 | 历史上的例子 |
|---------|----------|------------|
| 核心节点度数过高 | 金融/产业过度集中于少数节点 → 任何其一的 V⁻ 都可能触发级联 | "大而不倒" |
| 子图连通度过高 | 所有节点高度互连 → 没有隔离子图阻断裂缝传播 | 全球化金融系统 |
| 价格信号失真 | 泡沫期 ∇σ 被人为放大 → 交易边建立在虚假 σ 信号上 → 必回撤 | 2008 房地产泡沫 |
| 制度边松弛 | 制度子图（监管）的 V⁻ 检测阈值过高 → 悬挂边积累 → 崩溃 | 2008 金融监管缺失 |
| 货币边过度膨胀 | 信贷过度扩张——货币边总量远超商品边总量 → 通胀压力 → 强制 V⁻ | 恶性通胀/债务危机 |

### 1.3 危机的不可消除性

**不完美定理保证经济危机不可完全消除。** 原因：

1. 任何经济子图在任何帧都存在 deg_econ < 2 的节点（经济悬挂端）
2. 价格信号不可能完美——∇σ 永远有局部失真
3. 制度边永远落后于交易边的演化——制度是被伤害后的产物
4. 人的认知子图容量有限（邓巴数 d_max）→ 无法预知所有可能的 V⁻ 连锁路径

最好的政策不是"消除危机"——是**控制危机的振幅不超过 H_econ**，并通过子图碎片化（分业经营、防火墙）来阻止级联传播。

## 二、危机的类型学

### 2.1 按触发位置分类

| 危机类型 | 触发子图 | 级联路径 | 例子 |
|---------|---------|---------|------|
| 金融危机 | 货币子图（银行/金融中介） | 金融节点 V⁻ → 信用边断裂 → 实体经济节点失去信贷 | 2008 全球金融危机 |
| 实体经济危机 | 商品子图（生产/消费） | 需求 σ 缺口消失 → 生产边断裂 → 失业 → 消费进一步萎缩 | 1929 大萧条 |
| 货币危机 | 货币边自身 | 货币边信任崩塌 → 货币边被抛弃 → 退回到物物交换 | 魏玛恶性通胀 |
| 债务危机 | 信用延期边 | 债务边到期无法清算 → 债权人 V⁻ → 债权人也无法偿还其债主 | 希腊债务危机 |
| 供应链危机 | 交易链 | 关键中间节点断裂 → 下游全部缺货 → 下游生产停顿 | COVID 供应链中断 |

### 2.2 按级联规模分类

```
局部危机：V⁻ 级联限制在单个连通分量内——其他分量不受影响
  例：单一行业的衰退（如煤炭行业）
  拓扑特征：不同行业/区域的子图之间有足够的隔离子图（防火墙）

系统性危机：V⁻ 级联穿透分量边界——波及全经济
  例：2008 全球金融危机
  拓扑特征：各子图之间连通度极高——没有隔离子图
```

## 三、危机的恢复——σ 重构

### 3.1 恢复的两个阶段

```
阶段 1：V⁻ 停止——级联耗尽
  所有的"坏边"（基于虚假 σ 信号的交易边、无法偿还的债务边）被清除
  经济子图退化为更小但更健康的状态
  特征：σ 升高（密度下降）、但剩余节点的度数更"真实"

阶段 2：V⁺ 重启——σ 重构
  旧的悬挂端消失、新的∇σ 出现
  交易边开始在剩余的可靠节点间重新建立
  新的制度边出现——防止同样的级联路径再次被使用
  特征：σ 缓慢下降、新节点的度数开始增长
```

### 3.2 为什么有些危机恢复快、有些慢

| 恢复速度 | SPUM 条件 |
|---------|----------|
| V 型（快恢复） | 级联只清除悬挂边——核心子图完好 → V⁺ 快速恢复 |
| U 型（慢恢复） | 核心子图的度数也受损——需要重建信任边（社会 V⁺）→ 恢复慢 |
| L 型（不恢复） | 制度子图/认知子图永久锁定——新 V⁺ 被制度边阻隔 → 停滞 |
| W 型（二次探底） | 第一轮 V⁺ 建立在未完全出清的坏边上 → 再次 V⁻ 级联 |

### 3.3 政策干预——V⁺ 注入

```
危机时期的政策干预 = 外部注入的 V⁺ 事件：

  货币政策：降低利息（降低货币边的跨帧折现率）→ 鼓励当前的 V⁺
  财政政策：政府直接代替断裂的节点进行 V⁺（政府采购/基建）
  救助政策：向关键节点注入货币边（bailout）→ 阻止级联从关键节点开始
```

注意：这些干预的实质是在经济子图外（政府子图）创建额外的 V⁺ 来对冲 V⁻ 级联。它们不是"免费的"——是**将货币边从未来帧预支到当前帧**（财政赤字），或**增加货币子图的总边数**（量化宽松→通胀风险）。

## 四、危机与社会模块的连接

经济危机和社会模块的"快变迁"是同一种机制在不同子图上的投影：

| 模块 | 子图 | V⁻ 级联触发 | 恢复 |
|------|------|-----------|------|
| 社会变迁 | G_social | 制度的自指边确认失效 + 核节点的度数断裂 | 社会重构 |
| 经济危机 | G_econ | 金融/产业核节点的偿付能力丧失 + 信任边断裂 | σ 重构 |

两者可以同帧发生（如法国大革命——金融危机触发社会快变迁），也可以各自独立。
