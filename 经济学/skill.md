> 当前版本：2026-06-16 (v1.0 — 22 节点)

## 一、范式总纲

### 1.1 什么是 SPUM 经济学

SPUM 经济学 = ⟨P, ε⟩ 在交换尺度的应用。不是"用网络比喻经济"——经济**就是** κ 网络中交换子图上的 V⁺/V⁻ 动力学。每一笔交易是一次双向边创建事件（V⁻_resource + V⁺_money），每一个价格是 σ_resource 分布在该时刻的压缩信号，每一个市场是一个高连通的多替代路径子图。

| 维度 | 传统经济学 | SPUM 经济学 |
|------|---------|-----------|
| 第一原则 | 稀缺性 + 理性选择 | 经济子图 G_econ ⊂ G_social ⊂ ⟨P, ε⟩ |
| 基础对象 | 商品、货币、市场主体 | 节点、有向加权交易边、σ_resource 分布 |
| 价值定义 | 劳动价值 / 效用价值 / 边际价值 | ∇σ_resource ——稀缺性梯度信号 |
| 价格机制 | 供需曲线交叉 | σ 交换比的瞬时编码——min(货币边/资源边) |
| 市场 | 交易场所/机制 | 高连通 + 替代路径子图 |
| 变化机制 | 增长/周期/危机 | 逐帧 V⁺/V⁻ 累积 / σ 阻尼振荡 / V⁻ 级联 |

### 1.3 研究规范

1. **可还原性**：每个经济学概念必须追溯到 G_econ 上的 V⁺/V⁻ 或 σ 指标
2. **非比喻**：不使用"经济就像生态系统"——经济就是 G_econ 上的拓扑过程
3. **与社会学模块互通**：经济 V⁺ 是社会 V⁺ 的子集——无社会信任边则无经济交易边
4. **不预设均衡**：均衡是 ∇σ 趋零的拓扑结果，不是先验假设

## 二、根节点映射（R1-R9 的经济学映射）

| 编号 | 根节点 | SPUM 定义 | 经济学映射 |
|------|--------|----------|---------|
| R1 | **⟨P, ε⟩** | 节点集 + 边集 | G_econ = (V_econ, E_econ)——经济交换子图。人=节点，交易=有向加权边 |
| R2 | **V⁺/V⁻** | 创生/湮灭事件 | 交易 = 双向 V⁺/V⁻——V⁻_resource（商品流出）+ V⁺_money（货币流入） |
| R3 | **离散帧 τ** | 演化步数 | 经济变化逐帧累积——GDP 变化 = 帧间 V⁺ 差额 |
| R4 | **dv/dt ≤ const** | 单帧变化上限 | 个人交易容量天花板——认知容量 + 物理时间约束 |
| R5 | **不完美定理** | 每帧必残留悬挂端 | 永远存在经济孤立者和资源局部稀缺——危机不可消除 |
| R6 | **S 向量** | 五维结构健康向量 | 经济健康向量——σ 分布、∇σ 幅度、deg 分布、制度边稳定性 |
| R7 | **健康多面体 H** | S 向量的稳定区间 | H_econ——经济周期的安全振幅范围 |
| R8 | **ΔS** | 单帧 S 变化量 | ΔS_econ——帧内 GDP 变化 + σ 分布变化 + 制度边变化 |
| R9 | **σ** | 空间密度 = \|P\|/\|ε\| | σ_resource——每种资源在各节点的密度分布。∇σ_resource = 经济驱动力 |

| ECON-002 | **交易 V⁺/V⁻** | 双向边创建——V⁻_resource（资源流出）+ V⁺_money（等价物流入）。要求社会边作为信任基底 | `spum-经济网络.md` §三 |

## 四、子网边图

```
ECON-001 G_econ
  ├── ECON-002 交易 V⁺/V⁻
  ├── ECON-003 σ_econ
  └── ECON-004 经济不完美定理

ECON-005 价值 → ECON-006 货币 → ECON-007 价格
  └── 依赖 ECON-003 σ_resource 分布

ECON-008 市场
  ├── ECON-009 竞争（替代路径）
  └── ECON-010 均衡（∇σ→0）

  └── ECON-013 分配（σ 分布快照）

ECON-014 劳动（deg 流量） ⟷ ECON-015 资本（V⁺ 存量）
  └── ECON-016 工资与利润

ECON-020 危机（V⁻ 级联） → ECON-021 系统性风险 → ECON-022 σ 重构
```
