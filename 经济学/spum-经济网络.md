# SPUM × 经济网络

> 归约路径：经济 = 社会子图的交换子图 → 人=节点 → 交易=交换边 → 经济结构=交换子图拓扑模式
> 经济不是独立于社会的"系统"——是社会子图 G_social 中的一个特殊边子集，其中每条边代表一次商品/服务/信息的 V⁺/V⁻ 交换事件。亚当·斯密的"看不见的手" = ∇σ 梯度。马克思的"生产关系" = 经济子图中度数分布的不对称性。

---

## 核心命题

**经济是社会子图的交换边集。** 每笔交易不是"钱与物的交换"——是两个节点之间的一次双向 V⁺/V⁻ 事件：一方向另一方转移资源（V⁻），同时接收等价的信用或商品（V⁺）。经济学的全部研究对象——市场、货币、价格、供需、增长、危机——都是这张交换子图上的拓扑动力学。

经典经济学用了三百年试图把"价值""价格""市场"说清楚，但始终无法给出一套不含循环定义的基底——因为它的基底是错的：它先预设了"稀缺""理性人""均衡"，然后用这些概念互相定义。SPUM 经济学不做这件事——它从 G_econ ⊂ ⟨P, ε⟩ 出发，不预设任何经济学概念。

## 一、经济子图的形式化定义

### 1.1 基本对象

```
经济子图 G_econ ⊂ G_social ⊂ ⟨P, ε⟩

V_econ = V_social                    经济主体——与社会子图共用节点集
E_econ ⊆ V_econ × V_econ             交易边——经济交换关系
```

每条经济边 e = (vᵢ, vⱼ) 代表一次**已完成的交换**。与一般社会关系边不同，经济边具有：
- **方向**：从资源流出方指向资源流入方
- **权重**：交换的资源量——映射为 deg 增量
- **对偶边**：每次交换同时产生反向的信用/货币边（暂记，后续清算）

### 1.2 经济关系的基本属性

| 属性 | SPUM 对应 | 经济学含义 |
|------|----------|-----------|
| deg_econ(v) | 经济度数 | 一个人参与的交易关系数——交易伙伴的数量 |
| 边的权重 | V⁺/V⁻ 的事件规模 | 交易量——一次交换涉及的资源/货币量 |
| σ_econ | \|V\|/\|E_econ\| | 经济密度——市场参与者数与交易边数的比率 |
| dv/dt ≤ const | 单帧交易容量上限 | 一个人一帧内能完成的交易数有限——认知容量 + 物理容量 |
| 悬挂边 | deg_econ < 2 | 经济孤立——不参与任何交易的人 |

### 1.3 经济边的基本类型

| 交易类型 | 拓扑定义 | 示例 |
|---------|---------|------|
| 单向转移 | vᵢ → vⱼ 新建边，无对偶边 | 馈赠、援助、抢劫 |
| 双边交换 | vᵢ → vⱼ 与 vⱼ → vᵢ 同时新建（或等效存在） | 以物易物——等价交换 |
| 货币中介交换 | vᵢ → vⱼ（商品）+ vⱼ → vᵢ（货币边），后者可在任意第三方兑现 | 所有现代市场交易 |
| 信用延期交换 | vᵢ → vⱼ（商品），vⱼ → vᵢ（承诺边）——对偶边延期结算 | 借贷、赊账、期货 |
| 重复交换 | 多个帧内 (i,j) 边持续存在——高频 V⁺/V⁻ | 供应商-客户关系、雇佣关系 |

### 1.4 经济子图与社会子图的关系

经济不能脱离社会独立存在——G_econ 的边是社会子图 G_social 的边的一个子集。两者的关系：

```
社会边（无方向，强度 = V⁺ 频率）⊇ 经济边（有方向，权重 = 交易量）

社会 V⁺ → 经济 V⁺ 的转化路径：
  1. 两个人先有社会连接（认识——共享上下文子图）
  2. 在共享上下文中发现资源不对称（一方有 σ 缺口，另一方有 σ 盈余）
  3. 协商交换比率（价格——σ 压缩信号）
  4. 执行经济 V⁺/V⁻（交易）——同时强化社会边
```

没有社会边的信任基底，经济边无法存在——你不知道对方会不会履行对偶边的义务。这就是为什么所有市场经济都不能纯粹靠价格信号运转：**价格不能编码信任。信任由社会边的历史 V⁺ 频率决定。**

## 二、经济子图的拓扑度量

### 2.1 核心指标

| 指标 | 公式 | 经济学解读 |
|------|------|-----------|
| 平均经济度数 ⟨deg_econ⟩ | Σ deg_econ(v) / \|V\| | 经济参与度——平均每人有多少交易伙伴 |
| 聚类系数 C_econ | 三角形数 / 可能三角形数 | 市场的"闭环"程度——A 卖给 B、B 卖给 C、C 卖给 A 的程度 |
| 平均路径长度 L_econ | 最短路径平均值 | 供应链长度——商品从生产者到消费者经过多少中间节点 |
| 介数中心性分布 | 经 v 的最短路径数 | "中间商"——控制资源流动路径的节点 |
| σ_econ 方差 | Var(deg_econ) | 经济参与不平等——有人狂交易、有人从不交易 |

### 2.2 经济子图的连通性

```
连通类型：
  - 全连通经济：任何两个节点间存在交易路径 → 全球化
  - 局部连通经济：存在多个互相隔离的连通分量 → 区域经济/封锁经济
  - 碎裂经济：大量孤立节点（deg_econ = 0）+ 小连通分量 → 经济崩溃
```

## 三、经济 V⁺/V⁻ 的形式化

### 3.1 经济 V⁺——交易事件

**一笔交易 = 两节点之间新建经济边的 V⁺ 事件。**

```
V⁺_econ(vᵢ, vⱼ, resource_r):
  前提条件：
  1. (vᵢ, vⱼ) ∈ E_social —— 双方存在社会连接（信任基底）
  2. resource_r 存在于 vᵢ 的子图中——vᵢ 拥有该资源
  3. vⱼ 的 σ 分布中存在 resource_r 的缺失——vⱼ 需要该资源
  4. 双方就交换比达成共识——价格 = σ 压缩信号（见 §四）
  
  执行：
  1. resource_r 从 vᵢ 的子图删除（V⁻_resource）
  2. resource_r 加入 vⱼ 的子图（V⁺_resource）
  3. 新建有向边 e = (vᵢ → vⱼ)，权重 = resource_r 的 σ 映射值
  4. 新建对偶边 e' = (vⱼ → vᵢ)，权重 = 约定价格（货币或商品）
```

### 3.2 经济 V⁻——交易关系终结

经济关系不像社会关系——它可以瞬时终结（一旦交易完成，特定交易的边就进入历史）。但**持续交易关系**的终结需要触发条件：

```
V⁻_econ(vᵢ, vⱼ) 触发：
  1. 交易完成——该笔交易的边从活跃状态转为历史记录
  2. 信任破坏——社会边 (vᵢ, vⱼ) 的 V⁺ 频率降至阈值以下
  3. σ 匹配消失——vⱼ 不再需要 vᵢ 的资源（或 vᵢ 不再有盈余）
  4. 替代路径出现——vⱼ 通过更短的路径（更低的 σ 成本）获取资源
```

## 四、经济 σ——资源分布的空间密度

### 4.1 σ_econ 的定义

```
σ_econ = |V_econ| / |E_econ|
```

但这不是唯一的经济密度度量。更重要的度量是 **资源 σ 分布**——每种资源在各节点的分布密度：

```
σ_resource(v) = 节点 v 拥有资源 resource 的量 / v 的总度数
```

当 σ_resource 在某区域极低（资源匮乏），而另一区域极高（资源盈余），则形成 **∇σ_resource ≠ 0**——这就是经济驱动力。贸易的本质是沿 ∇σ 梯度定向输送资源。

### 4.2 稀缺性的 SPUM 定义

**稀缺 = 局部子图中 σ_resource > σ_critical** ——即某种资源在该子图中的拥有密度低于临界值。

稀缺不是资源的绝对属性——是 σ 分布的不均匀。在全局尺度上，宇宙的总资源量（总边数）守恒（拓扑守恒公理 N008），"稀缺"是局部的 σ 梯度。经济学把稀缺当作第一前提，SPUM 将其还原为 σ 分布——可以在不改变总资源量的情况下通过重新分配边来消除局部稀缺。
