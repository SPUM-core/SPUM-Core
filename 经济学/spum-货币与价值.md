# SPUM × 货币与价值

> 归约路径：价值 = σ 梯度 → 交换比 = ∇σ 信号 → 货币 = σ 压缩代理令牌
> 货币不是"一般等价物"——是**双向 V⁺ 操作中的对偶边标准化令牌**，用于将 n(n−1)/2 种物物交换比率压缩为 n 种价格。而"价值"不是事物的固有属性——是**在 σ 分布中资源稀缺性的拓扑信号**。

---

## 核心命题

**货币是 σ 压缩令牌。价值是 ∇σ 信号。** 经典经济学纠缠了三百年的"价值理论"（劳动价值论 vs 主观价值论 vs 边际效用论）之所以陷入僵局，是因为它们都在 [L1]（认知投影层）争论，从未触及 [L0]：价值的基底是资源的 σ 分布——价格只是 ∇σ_resource 在交换时刻的瞬时编码。

---

## 一、价值——σ 梯度的拓扑信号

### 1.1 价值不是"属性"

经典经济学的核心困境：价值到底是"客观的"（劳动价值论）还是"主观的"（边际效用）？SPUM 的回答：**两者都错——价值不是事物的属性，是 σ 分布中的拓扑关系。**

```
价值的 SPUM 定义：

Value(resource_r, v) = f(σ_resource_r(v), ∇σ_resource_r)

其中：
  - σ_resource_r(v) = v 拥有 resource_r 的量 / v 总度数
  - ∇σ_resource_r = σ_resource_r 在 v 的邻域中的梯度
```

一个人认为某物"有价值"，是因为：
1. 他自己 σ_resource 高（缺少该资源）
2. 他的邻域中也 σ_resource 高（周围人也缺）→ ∇σ 大 → "稀缺"
3. 他的邻域中 σ_resource 低（周围人拥有）→ ∇σ 方向明确 → "可以交易获得"

**价值是 ∇σ 的认知压缩。** 没有"客观价值"也没有"纯主观价值"——价值是观测者自身 σ 状态与其邻域 σ 分布的对比关系。

### 1.2 劳动价值论的 SPUM 校正

劳动价值论说"商品价值 = 凝结的社会必要劳动时间"。这在 [L1] 层面对大量商品近似成立，但基底不对：

```
SPUM 校正：
  劳动 = 一个人将自己的 deg 贡献给资源转化 V⁺ 操作（见 spum-劳动与资本.md）
  "社会必要劳动时间" = 平均 deg 消耗（用于该资源转化的总 V⁺ 事件数）
  
  劳动时间 → 价值的映射是统计的、非因果的：
  - 在 σ 均匀的社会中，劳动时间与 σ_resource 弱相关（不精确但能凑合）
  - 在 σ 极度不均匀的社会中，劳动时间与价值完全脱钩（比如：挖比特币）
```

### 1.3 边际效用论的 SPUM 校正

边际效用论说"价值 = 最后一单位的效用"。SPUM 校正：

```
效用 = σ_resource 的倒数——拥有越多，下一单位降低的 σ 越小 → "效用递减"

边际效用递减 = σ_resource(v) → 0（饱和）时：
  再增加 resource_r，σ_resource 的变化趋零 → 认知层的"效用感"趋零
```

这不是心理规律——是拓扑约束：一个节点的子图容量有限，同类资源的增量连接无法无限累积。

## 二、货币——V⁺/V⁻ 对偶边的标准化令牌

### 2.1 物物交换的拓扑困境

没有货币的经济 = 所有的交换都必须是**即时对偶**的：

```
以物易物：
  vᵢ 给 vⱼ 鱼（V⁻_fish）
  vⱼ 必须同时给 vᵢ 等值的米（V⁺_rice）
  
  问题：
  1. 双重巧合——vᵢ 想要米，vⱼ 正好有且想要鱼 → 概率极低
  2. 不可分割——鱼的"半个"不可交换
  3. 无可储存价值——鱼会腐烂，σ 交换边过期
  4. 无共同度量——鱼和米的 σ 比率在不同时间/地点不同
```

在拓扑上，物物交换要求**交换双方在交换时刻有对称的 σ 需求**——这在高度分工的社会子图中极难满足。

### 2.2 货币的拓扑本质

**货币 = 一种特殊的边——可以拆分为任意份额、不腐烂、且被子图中所有节点接受的 V⁺ 对偶令牌。**

```
货币 M 的拓扑属性：
  1. M 是 E_econ 中的一种特殊边类型——"信用边"
  2. M 可以分割——一条货币边可以拆分为多条子边（找零）
  3. M 跨帧稳定——不腐烂、不贬值（在 σ 稳定时）
  4. M 具有全局可接受性——子图中任何节点都接受 M 作为对偶 V⁺ 的结算
```

货币将 n(n−1)/2 种物物交换比率压缩为 n 种价格：

```
无货币：对于 n 种商品，需要 n(n−1)/2 个交换比率
有货币：只需 n 个价格（每种商品对货币的比率）

压缩比：(n−1)/2 —— 随着商品种类增多，货币的拓扑收益是指数级的
```

### 2.3 货币的三重 σ 压缩

| 压缩层次 | 货币的功能 | SPUM 对应 |
|---------|-----------|----------|
| [L0] 拓扑层 | 将对偶边从"即时对称"解放为"延期清算" | V⁺ 与 V⁻ 解耦——可以先收货币、后花货币 |
| [L1] 认知层 | 统一价值尺度——所有商品用同一个数字标记 | σ_resource 的认知压缩——复杂 σ 分布→ 单一价格向量 |
| [L2] 符号层 | 具体的货币符号——纸、金属、数字 | 货币的物理/数字载体——纯粹的约定边 |

### 2.4 通货膨胀——货币边的拓扑稀释

**通货膨胀 = 货币边总量 V⁺ 超过商品子图总量 V⁺。**

```
通胀机制：
  1. 货币创造：发行方 V⁺_money（凭空加货币边）
  2. 商品恒定：商品子图的总 V⁺ 不变
  3. 每条货币边对应的商品 σ 份额减少 → 货币边的"购买力"下降
  4. 价格（货币边数 / 商品边数）上升
```

通货膨胀不是"钱不值钱了"——是**货币子图膨胀速度超过商品子图膨胀速度**。这是一种拓扑不匹配。

## 三、价值、价格与 σ 的动态耦合

### 3.1 价格的 σ 基底

```
Price(resource_r) = |E_money(vᵢ→vⱼ)| / |V⁺_resource_r|

即：完成交易所需的货币边数量 / 交易的商品资源量
```

价格的本质是 **σ_money 与 σ_resource 的交换比率**。

### 3.2 价格信号的有效性条件

价格作为 ∇σ 信号的准确度取决于：

| 条件 | 违反后果 |
|------|---------|
| 交易边足够密集（σ_econ 高） | σ 稀疏 → 价格噪声大 → 信号失真 |
| 信息传播路径短（L_econ 小） | L 大 → 套利消失慢 → 价格长期失真 |
| 无节点可以单方面操纵货币 V⁺ | 有人滥发货币 → 全局 σ 失真 → 通胀 |
| 无节点可以阻塞资源路径 | 垄断 → 某资源的介数中心性极端化 → 价格被人为抬高 |
