# SPUM 股票预测 — 关键发现与代码总结

> 2026-08-13 验证版。本文档由 `verify_daily_phase.py` 的实际运行结果驱动撰写。
> 原则：**只记录验证事实，诚实标注局限**——不夸大预测力，不隐藏校准失败。

---

## 一、项目定位

将 SPUM 五形相位理论应用于 A 股市场，核心主张是从"价格曲线拟合"转向"实体相位识别"：
一家公司是 G_econ 的一个子图，其状态不是价格曲线，而是子图的五维拓扑相位
S = (S_水, S_木, S_土, S_金, S_火) 的离散帧演化。

**主交付物**：`daily_phase.py` — 自适应百分位相位检测引擎。
每个相位值 = 当前指标在滚动历史窗口中的百分位排名（0~1），即"异常程度"。

| 相位 | 指标 | 语义 |
|------|------|------|
| 火 | ROC5 百分位 × (0.6+0.4×量比) | 动量驱动（密度梯度 ∇σ） |
| 水 | VPT 21 日差分百分位 | 资金流（关系流） |
| 木 | 1 − 布林带宽(4σ/MA20) 百分位 | 骨架稳定性（波动率低=僵化） |
| 金 | ATR5/ATR20 比率百分位 | 修剪/更新（波动放大） |
| 土 | 1 − 40日段内相对振幅百分位 | 储备池（窄幅横盘） |

## 二、验证发现（v1.2，2026-08-13）

### 2.1 合成数据语义验证 — 8/8 通过

`verify_daily_phase.py --synthetic`（seed=42，六类已知模式）：

| 场景 | 断言 | 结果 |
|------|------|------|
| 陡涨放量(末10日) | fire ≥ 0.8 | fire=98.3% ✅ |
| 高波动(末12日) | wood < 0.3, metal ≥ 0.8 | wood=0.5%, metal=97.0% ✅ |
| 先动后静(横盘42日) | earth ≥ 0.8 | earth=99.8% ✅ |
| 放量缓涨(末5日) | water ≥ 0.7 | water=92.5% ✅ |
| 波动骤升(末8日) | metal ≥ 0.8 | metal=97.3% ✅ |
| 放量阴跌(末8日) | fire ≥ 0.8, water < 0.3 | fire=99.8%, water=2.5% ✅ |

### 2.2 修复的缺陷（验证暴露）

1. **`_percentile_rank` 并列极值低估 bug**：原用严格小于 `values < current`。
   当当前值是历史极端但存在并列极值（如指数陡涨末段 ROC5 相等）时，百分位被严重低估。
   修复为半开区间 `(below + 0.5×equal) / len`。
2. **earth 公式缺陷**：原 `1 − |净位移|/|路径|` 无法区分"窄幅横盘"与"宽幅震荡"——
   两者比值都接近 0（实测横盘 42 日 earth 仅 70%）。宽幅震荡是火形活跃而非储备。
   修复为段内相对振幅的补：`1 − (max−min)/mean 的百分位`。修复后 earth=99.8%。
3. **backtest 死代码分支**：`direction in ('↗↘','→↗')` 永假（predict 只返回单字符），已删除。
4. **README 示例类名错误**：`DayProfileGenerator` 不存在，实为 `DailyPhaseDetector`。

### 2.3 已知设计特性（非缺陷）

- **百分位检测器 = 相对异常检测**：异常持续超过均线窗口（火=ROC5、金=ATR5/ATR20、土=40日段、水=VPT 21日）后会被"正常化"——持续放量 20 日后量比回归 1.0，火焰冷却是语义特性而非 bug。
- **缩量阴跌 ≠ 水枯**：VPT 增量 = 价×量，缩量时增量小，"资金枯竭无方向"是合理语义；水枯须测放量下跌。

## 三、预测规则 v3 数据校准

### 3.1 诊断方法

`verify_daily_phase.py --rules`：5 只股票（002415/600519/000858/300750/600887）16 年全历史，
按饱和组合分类，统计后一日涨/跌/横盘占比与均值收益。合计约 2 万样本。

### 3.2 v2 → v3 规则修正（数据 + SPUM 语义双驱动）

| 相位组合 | v2 规则 | 后验事实 | v3 规则 |
|---------|--------|---------|---------|
| 火（单独） | ↘0.55 回调 | **涨54.0%，均值+0.24%** | **↗0.55 动量延续** |
| 火+水 | ↘0.67 回调 | 跌48.7%，均值−0.23% | ↘0.6 过热反转（保留） |
| 火+木 | ↘0.7 回落 | 涨50.3%，均值+0.11% | ↗0.5 骨架锁定动量延续 |
| 金（单独） | →0.3 横盘 | **涨50.5%，均值+0.26%** | **↗0.5 波动放大=突破偏上** |
| 土+火 | ↗0.5 看涨 | **涨53.3%，均值+0.18%** | ↗0.5（最强信号，保留） |
| 水+火+金 | ↘0.75 强回调 | 跌45.0%，均值−0.03% | ↘0.55（置信度下调） |
| 土（单独） | →0.25 横盘 | 横盘率10.1%（最高） | →0.25（保留） |

### 3.3 校准的 SPUM 语义论证

- **火亢单独 → 动量延续（↗）**：fire 饱和但 water 未饱和 = 强动量无量能确认 =
  火形 ∇σ 驱动未消退，趋势延续。旧规则误判为回调。
- **火+水 → 过热反转（↘）**：fire+water 双饱和 = 量价齐升到极端 =
  dv/dt 达容量上限（关系饱和），结构性拒绝继续扩张 → 回调。
- **金亢 → 突破偏上（↗）**：ATR 比率骤升 = 波动放大 = 网络修剪后新连接建立，
  数据证实突破方向偏上（均值+0.26%）。旧规则（→横盘）与 spum_cycle 投影（金亢→↘）均被数据否定。
- **土+火 → 看涨（↗）**：储备被驱动 = 低 σ 节点被火形梯度激活，53.3% 为最强信号。

## 五、诚实结论与局限

### 5.1 结论

1. **引擎可运行，相位识别语义正确**（合成 8/8）。
2. **↘（过热反转/量价极端）是唯一有统计优势的方向信号**：53.0%（对照无信号基准跌率 42.9%，+10pt）。
   火+水双饱和规则经数据验证有效。
3. **↗ 信号（50.1%）与随机基准无显著差异**——A 股长期略偏多（无信号基准涨率 49.5%），
   看涨信号没有超额预测力。
4. **总方向准确率 50.5%**，含交易成本后不构成可盈利的日线策略。

### 5.2 局限

- 规则校准基于 5 股样本内诊断，存在过拟合风险；样本外表现未验证。
- 日线方向预测本就不是 SPUM 相位理论的强项——**相位引擎的正确用途是"状态监控"
  （识别子图处于哪一相位、是否过热/僵化/枯竭），而非高频方向交易**。
- 财务相位（`spum_cycle.py`，季度级）才是相位过渡预测的主战场，本验证未覆盖该引擎。

### 5.3 与 SPUM 理论对齐

- **不完美定理**：锚点持续震荡、预测不可达完美——50.5% 的日线准确率正是
  "完整拓扑闭合在标准演化中不可达"（N016 实验）在经济子图日线尺度上的投影。
- **周期定位**：相位引擎的输出应作为"σ 分布的相位快照"（S 向量诊断），
  辅助判断公司子图处于五形耦合链的哪个环节，而非逐日多空信号。
- **下一合理方向**：将 daily_phase 的相位输出接入 spum_cycle 的耦合链过渡预测，
  用日线相位作为财务相位的先行观测，在季度尺度上验证相位过渡的正确率。

## 六、地支周期因子验证（2026-08-13）

### 6.1 理论桥接（待检验命题）

前序讨论将天干地支与 SPUM 桥接：**地支 12 = 拓扑常数 12**（闭合结构 12 折叠）、
**天干 10 = 五形 × V⁺/V⁻ 极性**。据此形成可检验命题：

> 同地支 / 同五行 / 同天干年份的市场相位状态是否统计相似（流年作为帧先验是否可检验）？

### 6.2 检验设计（`verify_ganzhi_cycle.py`）

- 数据：A股 4 宽基指数（上证 1990~、深证成指 1993~、沪深300 2005~、创业板指 2010~），合计 ~109 个年观测
- 指标：年收益率 / 年波动率（市场内百分位，消除水平差异）+ 五形相位饱和天数占比（daily_phase）
- 检验：Kruskal-Wallis（12 地支 / 5 五行 / 10 天干）+ 置换检验（500 次）+ 同地支年份明细表
- **数据现实**：东财全球指数接口不可用、新浪全球指数仅返回 4 年 → 跨市场独立演化扩展失败；
  4 宽基高度相关（非独立样本），每地支组 ~9 观测，功效有限

### 6.3 结果

KW 大量"显著"（收益·天干 p=0.000，ε²=0.34；水/木/金/土相位·地支 p<0.01；
置换检验 perm_p 与渐近 p 接近，证实非偶然）——**但被同地支年份明细表决定性证伪**：

```
子(水): 1996:94% | 2008:2%  | 2020:75%
戌(土): 1994:10% | 2006:94% | 2018:10%
亥(水): 1995:22% | 2007:96% | 2019:78%
```

同地支年份（相隔 12 年）的收益百分位极差普遍 60~90，覆盖几乎全范围。
**若 12 年周期为真，同地支年份应聚类相似——实测毫无一致性。**

### 6.4 结论

1. **地支周期因子在现有数据下不成立**（作为可预测的市场周期）。
   KW 显著性 = 特定年份效应伪影：亥年收益高因 2007/2019 恰为牛市，寅年低因 2022 为熊市——
   是"特定年份的市场环境"，不是"亥年/寅年周期"。
2. **不证伪结构同一性**：地支 12 = 拓扑常数 12 是纯拓扑推导（欧拉恒等式强制解）；
   本次检验否定的是"干支 → 市场状态的可预测映射"，后者在数据上不成立。
3. **理论启示（与 SPUM 对齐）**：数据证实"**流年先验 ≠ 市场实现**"——
   干支是帧索引标签（先验分布），市场状态由 ⟨P,ε⟩ 演化决定（实现），
   两者之间的偏离正是经济不完美定理（ECON-004：σ 交换比永不完全归零）的体现。
4. 局限：4 宽基非独立样本、相位为单帧快照；美股 8 个地支周期因数据接口不可用未覆盖——
   若需更强证伪，应扩展独立市场长历史。

## 七、股票八字先天五行向量验证（2026-08-13）

### 7.1 理论桥接（待检验命题）

上市时刻 = 股票的"出生时刻"。将每只股票的**上市四柱干支**视为其先天相位编码：

> 先天五行相同的股票（S_bazi 向量接近）→ 同相位 → 行情走势趋同？

构建流程（`stock_bazi.py`）：
- 股票池：深交所主板（00 开头），1991~2023 每年分层抽样 3 只 = 90 只
- **真太阳时**：均时差 EoT + 经度修正（深交所 114.06°E，基准 120°E 每度 4 分钟），统一假设上市时刻 09:30
- **八字**：lunar_python `Solar → Lunar → EightChar`（已验证 1990-12-19 上证 → 庚午/戊子/戊午/丁巳 ✓）
- **先天五行相量**两套版本：
  - 明字版（列 水/木/火/土/金）：四柱 8 明字五行计数归一化
  - 藏干版（列 *_hide）：天干权重 1.0 + 地支藏干分级权重（本气 0.7 / 中气 0.2 / 余气 0.1）加权归一化
    （未含纳音/旺衰；权重为子平通用简化，非节气当权天数精细方案）
- 五行向量分布：明字版 火 0.269 > 土 0.237 > 水 0.175 ≈ 金 0.174 > 木 0.144；
  藏干版 火 0.238 > 土 0.238 > 金 0.198 > 水 0.175 > 木 0.152（藏干使金/木抬升）

### 7.2 检验设计（`verify_bazi_correlation.py`）

- 行情：新浪源日线（限流 0.6s + 重试），共同窗口 2022-01-01~（保证覆盖率）
- 指标：周收益两两 Pearson 相关（84 只可用 → 3486 对）
- 分组：A = S 向量欧氏距离最近 top-10%（348 对）；B = 随机对（同规模）；C = 同行业对
- 统计：置换检验（500 次打乱 S 向量行重算 top-10% 组均值 → null 分布 → p 值）
- 混杂检查：A 组内同行业对比例 vs B 组；S 相似 × 同行业双重筛选
- 参数：`--vec ming|hide` 选择向量版本（默认 hide 藏干版），两套独立运行

### 7.3 结果（两套向量版本）

```
                        明字版             藏干版
A  S向量最近对(348对)  0.2423  中位.2416   0.2289  中位.2326
B  随机对   (348对)    0.2346  中位.2347   0.2346  中位.2347
C  同行业对 (1696对)   0.2342  中位.2298   0.2342  中位.2298
A−B 差值               +0.0077           −0.0057
置换 p 值              0.357  不显著      0.826  不显著
A 组同行业比例         39.9%  < B 52.6%   41.4%  < B 52.6%
S相似×同行业双重筛选   0.2325 (215对)     0.2321 (170对)
                      vs 同行业全集 0.2342
```

### 7.4 结论

1. **证伪"先天五行相同 → 走势趋同"**（两套向量一致）：
   - 明字版：S 最近对相关 0.2423 vs 随机 0.2346，差 +0.0077，p=0.357 不显著；
   - 藏干版：相关 0.2289 甚至**低于**随机基线（差 −0.0057，p=0.826 完全不显著）。
   上市时刻八字与 30 年后股价走势无先验相关性——先天五行对行情相关无解释力。
2. **藏干版本证伪更彻底**：加入本气/中气/余气的完整五行信息后，明字版微弱的
   +0.0077 正差翻转为 −0.0057 负差。**提升八字编码精细度不增强、反而消除相关性**——
   不是"信息不够"，而是该信息维度本身与市场实现无关。
3. **排除行业混杂**：两版本 A 组同行业比例（39.9% / 41.4%）均低于随机基线（52.6%），
   S 相似选择无行业聚集；双重筛选（相似×同行业）相关（0.2325 / 0.2321）均低于同行业全集
   0.2342——若"同相位→同走势"存在，双重条件下应增强，实测无。
4. **与地支周期验证一致**：干支类先验（年支 / 上市时刻）在 A股 数据上均不可预测市场实现。
   三次独立证伪（地支周期 + 明字版 + 藏干版）共同指向：**干支是帧索引标签，不是市场状态驱动**。
5. SPUM 解读：先天相位编码（上市单帧）与 30 年后的市场实现之间隔着 ~10⁴ 数量级的演化帧，
   单帧标签的信息量被演化完全淹没——这正是经济不完美定理（σ 交换比永不完全归零）的体现：
   实现由 ⟨P,ε⟩ 演化决定，先验标签不约束实现。
6. 局限：藏干权重为固定分级（0.7/0.2/0.1）非节气当权天数、统一假设 09:30 上市、
   周收益相关仅覆盖 4.5 年窗口、A股单一市场（政策与板块因子主导相关性）。
   更强证伪方向：纳音/旺衰加权 + 跨市场（美股长历史）独立样本。
