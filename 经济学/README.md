# SPUM 经济学

> 经济交换子图的拓扑形式化。将经济学的全部研究对象——市场、货币、价格、供需、劳动、资本、增长、周期、危机——统一还原为 ⟨P, ε⟩ + σ 梯度 + V⁺/V⁻ 的图论表达。
>
> **核心立场**：经济学不是"关于稀缺资源配置的学问"——是关于**资源 σ 分布在交换子图中如何通过 V⁺/V⁻ 操作进行重配置的拓扑动力学**。亚当·斯密的"看不见的手" = ∇σ 梯度。马克思的"生产关系" = 度数分布不对称。凯恩斯的"有效需求不足" = ∇σ 通讯断裂。
>
> **导航**：[skill.md](skill.md) — 研究范式（22 节点）

## R1-R9 经济学映射

| 编号 | 根节点 | SPUM 定义 | 经济学映射 |
|------|--------|----------|---------|
| R1 | **⟨P, ε⟩** | 节点集 + 边集 | G_econ——经济交换子图。人为节点，交易为有向加权边 |
| R2 | **V⁺/V⁻** | 创生/湮灭事件 | 交易——双向 V⁺/V⁻：商品流出+货币流入 |
| R3 | **离散帧 τ** | 演化步数 | 经济变化的逐帧累积——没有"趋势"，只有逐笔交易 |
| R4 | **dv/dt ≤ const** | 单帧变化上限 | 交易容量天花板——单人单帧能完成的交易数有限 |
| R5 | **不完美定理** | 每帧必残留悬挂端 | 永远存在经济孤立者（deg_econ<2）和资源稀缺（∇σ≠0） |
| R6 | **S 向量** | 五维结构健康向量 | 经济健康向量——σ分布、∇σ幅度、deg分布等 |
| R7 | **健康多面体 H** | S 向量的稳定区间 | H_econ——周期振幅在可容忍范围内的经济健康区间 |
| R8 | **ΔS** | 单帧 S 变化量 | ΔS_econ——一帧内的GDP变化+σ分布变化 |
| R9 | **σ** | 空间密度 = \|P\|/\|ε\| | σ_resource——资源分布密度，∇σ = 经济驱动力 |
