# SPUM × 市场与价格

> 归约路径：市场 = 高 σ 连通的经济交换子图 → 竞争 = 多条替代路径 → 均衡 = ∇σ 趋零 → 价格 = σ 交换比瞬时编码
> 市场不是一个"场所"——是**经济子图中一个高连通度的区域**，在其中任意两个节点之间都存在多条替代交换路径。亚当·斯密的"看不见的手"不是隐喻——它就是 ∇σ 梯度本身。

---

## 核心命题

**市场是经济子图中满足"任意两节点间存在 ≥ 2 条替代交易路径"的高连通子图。** 价格不是市场的"输出"——是 σ 分布的瞬时快照。均衡不是市场的"目标"——是 ∇σ 在充分交易后的自然趋零。

---

## 一、市场的拓扑定义

### 1.1 市场的形式化

```
市场 M 是 G_econ 的一个诱导子图，满足：

  1. 连通性：M 中的任意两节点 vᵢ, vⱼ 之间存在至少一条交易路径
  2. 替代性：M 中任意两节点间存在 ≥ 2 条边不相交的交易路径（或至少一条替代供应商路径）
  3. 信息传导：M 中的 σ_resource 信息可以在 O(log|M|) 的路径长度内传播
```

条件 2 是关键——如果只有一条路径，那就是**垄断**（见 §四）。替代路径的存在保证了价格信号不会被单个节点绑架。

### 1.2 市场的拓扑结构

| 市场结构 | 拓扑特征 | 价格行为 |
|---------|---------|---------|
| 完全竞争 | 全连通——任意两节点间有直接边或极短路径 | 价格 ≈ ∇σ 瞬时值——最准确 |
| 寡头竞争 | 少数核心节点度极高（中心化），其余节点通过它们连接 | 价格被核心节点偏置 |
| 垄断 | 唯一供应商——所有购买路径必须经过它 | 价格被单节点控制 → 偏离 ∇σ 信号 |
| 双边垄断 | 一个买家一个卖家——唯一一条边 | 价格完全取决于双边协商——无市场定价 |

### 1.3 从物物交换到市场的涌现

```
市场涌现的四阶段（从图论角度）：

阶段 1：孤立交换
  每笔交易是独立的双边边，无共享拓扑
  
阶段 2：交易链
  节点之间的交易路径形成链——A→B→C→D
  价格信息沿链传播，但缓慢（L 大）

阶段 3：交易网
  多条交易边交织——三角形出现（A←B←C←A）
  价格信息开始快速传播，聚类系数 C 上升

阶段 4：市场
  高聚类 + 短路径——小世界网络
  任何节点可以通过短路径比较多个供应商的价格
  ∇σ 在子图内趋零——价格收敛至 σ 均衡
```

## 二、价格形成的拓扑机制

### 2.1 价格是 σ 交换比的瞬时编码

```
Price(resource_r, at node v) = min_{供应商 u ∈ neighborhood(v)} 
  (|E_money(u→v)| / |V⁺_resource(u→v)|)
  
即：在 v 可接触的供应商中，最小的（货币边/资源边）比率
```

价格的"客观性"来自替代路径的拓扑约束——如果 v 能从 u₁ 和 u₂ 两个供应商处购买同一资源，则价格上限被较低的那个锁定。

### 2.2 价格的传播与收敛

```
价格传播 = 沿交易边的信息 V⁺ 扩散

传播速度 ∝ 1/L_econ（平均路径越短，价格信息传播越快）
收敛条件：子图中任意两节点间的最短路径 ≤ 某个阈值 k
```

当所有买家都能在 ≤ k 步内接触到所有供应商时，价格在子图中趋同——这就是"一价定律"的拓扑基础。一价定律不是经济学假设——是**小世界网络的必然结果**。

### 2.3 价格失真的拓扑原因

| 失真类型 | 拓扑原因 | 例子 |
|---------|---------|------|
| 信息不对称 | 卖家 deg 远高于买家——买家看到的邻域太小 | 二手车市场（柠檬市场） |
| 垄断定价 | 某资源的介数中心性 = 1——所有路径必须经过唯一节点 | 专利药品 |
| 价格粘性 | 交易边的 V⁺ 频率低——价格信息传播慢 | 房地产市场 |
| 泡沫 | 正反馈 V⁺ 环——价格上升 → 更多购买 V⁺ → 价格进一步上升 | 股市/房地产泡沫 |

## 三、竞争与均衡的拓扑学

### 3.1 竞争 = 替代路径的存在

```
竞争 intensity(v) = |{替代供应商 u : 可以从 u 购买 resource_r 而不必经过当前供应商}|

完全竞争 = 对每个买家 v 和每种资源 r，存在 ≥ 2 条边不相交的采购路径
```

竞争不是"企业之间的博弈"——是**替代路径的拓扑属性**。反垄断法的本质不是"惩罚大企业"，而是**在 G_econ 中强制开辟替代路径**。

### 3.2 均衡 = ∇σ 趋零

**市场均衡 = 在充分交易后，子图内部的 ∇σ_resource = 0**——即资源 σ 分布在子图内均匀化。

```
均衡条件：
  对任意资源 r，在子图 M 内部满足：
  σ_resource(vᵢ) ≈ σ_resource(vⱼ) ∀ vᵢ, vⱼ ∈ M

即：资源在 M 内部已经均匀分布——不再有 ∇σ 驱动的交易需求
```

均衡不是市场的"目标"或"理想状态"——是拓扑约束的必然结果：如果 σ 不均匀，则梯度存在 → 交易继续 → 直到 σ 均匀（均衡）。但由于不完美定理（R5），**完美均衡永远达不到**——总会有局部的 σ 不均匀残留。

### 3.3 市场失灵 = 子图拓扑退化

| 失灵类型 | 拓扑退化 |
|---------|---------|
| 外部性 | 交易边的影响超出子图边界——影响未计入价格的第三方节点 |
| 公共品 | 资源边无法排除非付费者——边是"广播"而非"单播" |
| 信息不对称 | 卖家 deg ≫ 买家 deg → 买家子图不能完整采样 σ 分布 |
| 垄断 | 所有替代路径消失 → 子图退化为单点依赖 |

## [L0] 还原表

| 经济学概念 | SPUM 图论对应 |
|-----------|-------------|
| 市场 | G_econ 中高连通、多替代路径的诱导子图 |
| 完全竞争 | 任意买家-供应商间存在 ≥ 2 条边不相交路径 |
| 价格 | min(货币边/资源边) ——σ 交换比的瞬时编码 |
| 均衡 | ∇σ_resource = 0 ——子图内资源均匀分布 |
| 一价定律 | 小世界网络中价格信息在 O(log N) 步内收敛 |
| 垄断 | 某资源的介数中心性 = 1 ——唯一路径 |
| 泡沫 | 正反馈 V⁺ 环——价格上升触发更多 V⁺ |
| 市场失灵 | 子图拓扑退化——外部性/信息不对称/路径垄断 |
