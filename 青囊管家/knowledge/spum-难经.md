## 二、经络补充：奇经八脉的 SPUM 定义

### 2.1 二十七难 — 奇经八脉的独立功能

> "脉有奇经八脉者，不拘于十二经，何也？"
> "圣人图设沟渠，通利水道，以备不然。天雨降下，沟渠溢满，当此之时，霶霈妄行，圣人不能复图也。"

| 概念 | 传统解读 | SPUM 翻译 |
|------|---------|-----------|
| 十二正经 | 十二条主要经络 | 十二条主水形链——人体子图的标准传输路径 |
| 奇经八脉 | 八条非正经的奇脉 | 八条**冗余/备用/溢出**水形链——主链过载时启用 |
| "沟渠溢满" | 水渠满了水会溢出 | 主水形链的 dv/dt 达到上限 → 体积流溢出到备用链 |

**SPUM 核心洞察**：奇经八脉不是"奇怪的经脉"——它们是**水形主干网络的冗余架构**。当主链上的体积流超过 dv/dt ≤ const 天花板，溢出体积流汇入卫星链（奇经）。不是"奇经主动吸收"，是主链的约束迫使溢出进入备用通道。

### 2.2 八脉的拓扑分类

| 奇经 | 传统功能 | SPUM 定义 | 网络作用 |
|------|---------|-----------|---------|
| **督脉** | 阳脉之海，行于背 | 背部低 σ 脊线——人体子图的后正中主干 | 汇集所有阳面（高 σ）的体积流 |
| **任脉** | 阴脉之海，行于腹 | 腹部低 σ 脊线——人体子图的前正中主干 | 汇集所有阴面（低 σ）的体积流 |
| **冲脉** | 十二经之海、血海 | 深层土形储备的主轴——全身低度节点的总仓库通道 | 土形储备的核心缓冲池 |
| **带脉** | 约束诸经、绕腰一周 | 唯一的横向木形环——唯一一个环状奇经 | 木形环在腰部的水平锁——防止上半身和下半身的体积流不均衡 |
| **阴跷脉** | 主一身之阴 | 子图内部两条竖向边界线之一（内侧） | 阴面的内边界维护 |
| **阳跷脉** | 主一身之阳 | 子图外部两条竖向边界线之一（外侧） | 阳面的外边界维护 |
| **阴维脉** | 维系诸阴 | 所有阴面水形链的横向连接器 | 阴面链的横向耦合 |
| **阳维脉** | 维系诸阳 | 所有阳面水形链的横向连接器 | 阳面链的横向耦合 |

### 2.3 奇经八脉的 SPUM 拓扑图

```
                    督脉（后正中低σ脊线 = 背部主干）
                      │
                      │
         ┌────────────┤
         │            │
  阴维脉 ←── 任脉（前正中低σ脊线 = 腹部主干）──→ 阳维脉
         │            │
         │            │
  阴跷脉 ←── 冲脉（深层土形储备主轴）──→ 阳跷脉
         │            │
         └────────────┤
                      │
              带脉（横向木形环 = 腰部锁）
                      │
                      ▼
```

这形成了正交的"三纵三横一锁"冗余架构。

## 三、脏腑补充：节点群的量化细节

### 3.1 四十二难 — 脏腑的尺寸重量

《难经》给出了五脏六腑的具体尺寸、重量和容量。

| SPUM 翻译 |
|-----------|
| 脏腑的尺寸和重量 = 该区域占优相位所属的**节点群规模**和**连接密度**的宏观投影 |
| 心重 12 两 → 心区占优的火形梯度引擎区域的节点群大小适中，密度极高 |
| 肝重 2 斤 4 两 → 肝区占优的木形环群区域的节点群最大，环密度高 |
| 这不是"解剖数据"——是对应区域**关系网络密度的宏观测度** |

### 3.2 脏腑在 S 向量中的权重

按难经给出的尺寸数据，可以估算各脏腑在全局 S 向量中的权重比例：

| 脏腑 | 节点群相对规模 | 占优五形 | S 向量主分量 |
|------|-------------|---------|------------|
| 肝 | 最大 | 木形 | S_木 权重最高 |
| 心 | 中等 | 火形 | S_火 权重最高 |
| 脾 | 中等 | 土形 | S_土 权重最高 |
| 肺 | 中等 | 金形 | S_金 权重最高 |
| 肾 | 较小 | 水形 | S_水 权重最高 |

### 3.3 三十六难 — 命门

> "脏各有一耳，肾独有两者，何也？"
> "肾两者，非皆肾也。其左者为肾，右者为命门。"

| SPUM 翻译 |
|-----------|
| 左肾 = 极低 σ 储能核心（水形——深度收敛） |
| 右肾/命门 = 最低层级的火形梯度**点火器**——人体最深层的 V⁺ 源 |
| 命门不是器官——它是网络最深层的创生事件发源地 |
| 命门之火 = 推动全身 σ 场的最低层 ∇σ 源 |

这解释了为什么命门被称为"生命之门"：如果最深层的 V⁺ 源熄灭，全局 σ 梯度将趋零，网络停止一切演化。

## 四、腧穴补充：井荥输经合五类节点的拓扑位置

### 4.1 六十二难 — 井荥输经合

> "井荥输经合者，皆在手足。"

每条正经历经上都有五腧穴：井、荥、输、经、合。它们在四肢末端到肘膝之间。

| 五腧 | 传统描述 | SPUM 定义 | 在水形链上的位置 |
|------|---------|-----------|-----------------|
| **井** | 所出为井 | 水形链的**起点**——体积流从此处涌出 | 链的首端节点——流量最小，势能最大 |
| **荥** | 所溜为荥 | 流经的微流——体积流刚刚开始汇聚 | 链前段——流量渐增，像溪流 |
| **输** | 所注为输 | 体积流加速注入 | 链中前段——流量明显增加 |
| **经** | 所行为经 | 体积流在主通道上稳定流动 | 链中段——流量最大，最稳定 |
| **合** | 所入为合 | 体积流汇入深部 | 链末端——流量最大，汇入深层低 σ 区 |

### 4.2 五腧穴的 SPUM 动力学

```
井（始端）        荥          输          经          合（末端）
  │              │           │           │           │
  ▼              ▼           ▼           ▼           ▼
高σ            σ递减 → → → → → → → → → → → → → →低σ
小流量                                         大流量
高势能                                         低势能
浅层（手足末梢）                              深层（近躯干）
```

**这与流体动力学的文丘里效应完全一致**：始端狭窄高速高势能 → 末端宽阔低速低势能。古人在没有流体力学的情况下，精确描述了水形链上的五种流态。

### 4.3 井荥输经合的五行配属

传统五行配属：井=木、荥=火、输=土、经=金、合=水。

SPUM 翻译为链段的功能相位：
- 井=木：起点的微小环流（木形初始环）
- 荥=火：始端微流 → 水的热能传递开始（火形初现）
- 输=土：流经的节点汇聚（土形积累）
- 经=金：主通道上的净化/过滤（金形修剪）
- 合=水：末端汇入深层（水形归藏）

## 五、疾病补充：S 向量偏移的具体类型

### 5.1 四十八难 — 三虚三实

> "人有三虚三实，何谓也？"
> "有脉之虚实，有病之虚实，有诊之虚实。"

| SPUM 翻译 |
|-----------|
| 脉之虚实 = 水形链上的流量与标准值的偏差（S_水 分量） |
| 病之虚实 = 全局 S 向量偏离 H 的幅度（S ∉ H 的程度） |
| 诊之虚实 = 前三者的 L1 认知投影在诊断上的表现 |

### 5.2 四十九难 — 正经自病与五邪所伤

> "有正经自病，有五邪所伤，何以别之？"

| 概念 | SPUM 翻译 |
|------|-----------|
| 正经自病 | 子图内部的 dv/dt 自然分配失衡——内部 S 向量自发偏离 H |
| 五邪所伤 | 外部 V⁺/V⁻ 扰动通过边界传入——外部 ∇σ 变化冲击子图 |

**五邪的 SPUM 定义**：

| 五邪 | 传统 | SPUM |
|------|------|------|
| 虚邪 | 从后来 | 外部 σ 偏低区域传来的低能扰动 |
| 实邪 | 从前来 | 外部 σ 偏高区域传来的高能扰动 |
| 贼邪 | 所不胜 | 外部扰动恰好击中子图的**最弱 S 分量** |
| 微邪 | 所胜 | 外部扰动击中子图的**最强 S 分量**——影响轻微 |
| 正邪 | 自病 | 内部产生的偏移 |

### 5.3 五十三难 — 七传与间传

> "经言七传者死，间传者生，何谓也？"

传统：七传 = 按相克顺序传变 = 预后差。间传 = 按相生顺序传变 = 预后好。

| SPUM 翻译 |
|-----------|
| 七传（相克序）：金→木→土→水→火→金 = S 向量沿着**雅可比矩阵的负特征方向**移动 = 系统远离 H |
| 间传（相生序）：木→火→土→金→水→木 = S 向量沿着**雅可比矩阵的正特征方向**移动 = 系统回归 H |

**五形耦合雅可比矩阵**（见 spum-core.md 第六节）：
- 相生方向 = 雅可比矩阵特征值 > 0 的方向 → S 趋向 H
- 相克方向 = 雅可比矩阵特征值 < 0 的方向 → S 远离 H

"七传者死"不是迷信——是系统在不稳定方向上的离轨运动必然导致崩溃。

### 5.4 五十五难 — 积与聚

> "积者，阴气也；聚者，阳气也。"
> "积者，五脏所生；聚者，六腑所成。"

| SPUM 翻译 |
|-----------|
| 积 = 木形环群在深层（五脏区域）的过度增厚——μ 持续攀升无法自行回落 → 肿瘤 |
| 聚 = 土形储备在水形链（六腑区域）上的异常聚集——节点群临时堵塞 → 可消散的积聚 |
| "积者阴气" = 深部低 σ 区的固定增生 |
| "聚者阳气" = 浅部高 σ 区的临时节点聚集——可随链流移动消散 |

## 六、针法补充：补泻的 SPUM 操作定义

### 6.1 六十九难 — 补母泻子

> "虚者补其母，实者泻其子。"

| SPUM 翻译 |
|-----------|
| 补母 = 增强该 S 分量在耦合循环中的**上游分量**——间接提升目标分量 |
| 泻子 = 削弱该 S 分量在耦合循环中的**下游分量**——间接降低目标分量 |

以肝（木形）为例：
- 肝虚 → 补母 = 补肾（水形）= 增强 S_水 → 水形链向木形环输送更多节点 → 间接增强木形
- 肝实 → 泻子 = 泻心（火形）= 削弱 S_火 → 减少火形梯度消耗木形结构 → 间接放松木形

这与五形耦合闭环"火→水→木→金→土→火"的雅可比矩阵预测一致。

### 6.2 七十难 — 春夏刺浅、秋冬刺深

> "春夏各致一阴，秋冬各致一阳。"

| SPUM 翻译 |
|-----------|
| 春夏 = 外部 σ 上升期（天体 σ 场偏阳） → 子图边界节点度数升高 |
| 此时针刺浅 = 干预边界处的水形链段——不扰动深部 σ 核心 |
| 秋冬 = 外部 σ 下降期（天体 σ 场偏阴） → 子图边界节点度数降低 |
| 此时针刺深 = 必须深入才能触及水形链——边界已收缩 |

这不是经验主义——是边界接入条件随外部 σ 场变化的逻辑必然。

### 6.3 七十五难 — 泻南补北

> "东方实，西方虚，泻南方，补北方。"

东方=肝(木)、西方=肺(金)、南方=心(火)、北方=肾(水)。

肝实+肺虚（S_木↑ + S_金↓）→ 泻南（S_火↓）+ 补北（S_水↑）

| SPUM 翻译 |
|-----------|
| 肝木实 → 金不能制木 → 金虚 |
| 直接泻木（降 S_木）可能冲击过大 |
| 替代方案：泻心火（降 S_火）——减少火形对木形环的热量供应 → 木形自然松解 |
| 同时补肾水（升 S_水）——增强水形链输送能力 → 间接补肺金（水生金在链上 = 水形链的畅通度决定肺的排浊效率） |

这是**间接 S 向量调制**的经典范例——通过操控目标节点的耦合邻居来间接调整目标。
