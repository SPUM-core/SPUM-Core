# open_SPUM

**空间粒子宇宙模型 (Space Particle Universe Model) 的开源实现与理论迭代仓库**

## 核心理念

宇宙是关系网络 `(P, ε)` 的自我编织，一切存在皆为拓扑模式的涌现。  
本仓库致力于：

- **理论迭代**：通过版本号与四维评分机制，持续优化理论纯净度与逻辑严密性。
- **开源协作**：接纳所有认同“关系本体论”的研究者，共同构建离散宇宙语言。
- **实证检验**：将理论预言转化为可计算、可验证的实验与模拟。

## 仓库结构

- `core/` ：核心理论库（版本归档，需通过高阈值评分）
- `draft/` ：草稿区（待完善的理论或实验方案）
- `tools/` ：辅助工具（评分脚本、哈希验证）
- `citations/` ：标准参考文献（BibTeX、PDF）
- `references/` ：外部低分文献（作为对照或批判对象）

## 快速开始

1. **阅读核心理论**：进入 `core/v1.0/theory.md` 了解 SPUM 基底。
2. **提交草稿**：在 `draft/` 下创建新目录，包含 `theory.md` 和 `version.json`（留空版本号）。
3. **CI 自动评分**：提交 PR 后，GitHub Actions 将自动计算四维得分并生成版本号。
4. **参与讨论**：通过 Issues 或 Discussions 提出建议。
