## 使用指引

### 1. 加载策略

- 当任务涉及**知乎风格写作**时，读取该目录下相关 md 文件作为参考模板
- 当任务涉及**具体主题**（潮汐、哥德尔、波粒二象性等）时，先检索对应文件获取已有论证
- 写作时遵循 SPUM 推理规范（见 `spum-core.md`），保持 L0-L3 层级标注

### 2. 写作风格

- 面向非专业读者的科普语言，避免公式轰炸
- 保留论证深度，但不牺牲可读性
- 使用类比（像素→屏幕、积木→造型）帮助理解
- 从"推翻错误前提"而非"灌输新知识"的角度切入

### 3. 与 SPUM 框架的关系

```
SPUM 核心公理 (.trae/rules/spum-core.md)
    │
    ├── 数学的有效性.md          (项目内正式文档 — 维格纳问题)
    ├── .trae/skills/zhihu-knowledge/skill.md  (本文件 — 知识库索引)
    │
    └── F:\知乎问答\              (外部知识库)
        ├── 26-4/  早期探索性问答（潮汐、信息、哥德尔、诺特、赋予关系、民科）
        ├── 26-5/  中期定型论证（光粒二象性、离散高斯博内、科学常识去魅）
        └── 26-6/  当前主力（数学有效性、空间围城、五形网络形式化、拓扑认知实验）
```

知识库中的文章是 SPUM 理论面向大众的**第一层投影**——最简化、最直观的表述。项目内的正式文档（`knowledge.md`、`spum-core.md`、`数学的有效性.md`）是严谨的理论基底。两者之间不应有矛盾，如有不一致以正式文档为准。

### 4. 新增内容规范

向知识库添加新问答时遵循：
- 按月份创建子目录，格式 `YY-M/`
- 命名规范：`{主题}_v{版本号}.md` 或 `{知乎问题标题}.md`
- 文件头部标注：日期、问题链接、SPUM 版本号、目标读者
- 同步更新本 skill 文件的主题索引
