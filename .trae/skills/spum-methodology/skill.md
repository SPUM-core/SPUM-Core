## 技能描述

SPUM 的方法论归属不是"另类统一场论"——它是**演化物理（generative emergence）** 在宇宙学尺度上的一次系统性尝试。本 skill 描述 SPUM 作为"第三代物理"的方法论立场：**宇宙不是一条需要算出解析解的数学题，它是一个跑起来的程序。规律不是写在开头的公式，而是长在过程里的结构。**

## 核心方法论：三代物理学的断层

### 第一代：解方程

| 维度 | 特征 |
|------|------|
| 范式 | 找到系统的运动方程，代入初值求解轨迹 |
| 典型 | 牛顿力学、麦克斯韦方程组 |
| 追问 | 轨迹是什么？力是什么？ |
| 真理形态 | 解析解 |
| 对宇宙的隐喻 | 钟表 |

### 第二代：找公式

| 维度 | 特征 |
|------|------|
| 范式 | 寻找一个统一的、闭合的解析形式（拉氏量、作用量），相信宇宙背后有一条终极方程 |
| 典型 | 广义相对论、标准模型、统一场论、弦论 |
| 追问 | 对称性是什么？什么几何结构能包纳所有相互作用？ |
| 真理形态 | 拉氏量 / 单条公式 |
| 对宇宙的隐喻 | 几何体 |
| 局限 | 浓缩不等于理解。Einstein-Hilbert 作用量可以写在一行里，却仍然无法回答"引力与量子为什么不兼容"、"奇点处发生了什么"、"暗物质到底是什么"。浓缩公式把问题压缩成了一个人们不敢追问的符号。 |

### 第三代：定规则 → 跑演化 → 看涌现

| 维度 | 特征 |
|------|------|
| 范式 | 宇宙不是一条公式——宇宙是一个在每一帧里重新运行的局部规则集。你不应该去"解"它，你应该去**运行它**，然后看它长出什么。 |
| 典型 | SPUM、Game of Life、格子气自动机、分子动力学、元胞自动机、复杂系统 |
| 追问 | 规则是什么？运行后能看到什么？什么结构必然涌现？ |
| 真理形态 | 涌现结构 + 可执行规则集 |
| 对宇宙的隐喻 | 程序 / 关系网络 |
| 优势 | 规则可以非常简单（不到半页纸），但运行产生的结构可以任意复杂 |

## SPUM 在第三代中的特殊位置

SPUM 与 Game of Life 等元胞自动机的**关键区别**：

| 维度 | Game of Life | SPUM |
|------|-------------|------|
| 规则来源 | **任意设定**（B3/S23 换成别的规则也能跑出有趣的东西） | **拓扑定理强制**——每一条规则都受拓扑守恒约束（欧拉恒等式、角度亏损恒为 4π、最小度数 ≥ 2） |
| 规则空间 | 极大（2^512 种可能规则） | 极小（唯一自洽的规则集） |
| 产出对照 | 产出有趣图案，不映射真实宇宙 | 产出结构试图对应真实观测数据（旋转曲线、红移、光谱） |
| 可证伪性 | 无 | 有——若运行结果与观测数据系统性偏离，理论被证伪 |

**核心陈述**：

> 拓扑定理强制只有这些规则是自洽的。我们运行一下，看看这个唯一自洽的规则集会产出什么。

这不是"随便定些规则看能跑出什么"。这是在极窄的规则空间中运行的第三代方法论——**拓扑定理充当了规则选择器**。Game of Life 中有趣的图案是人为选出来的；SPUM 中涌现的结构是拓扑必然。

## 代码就是理论的最终形态

在 SPUM 的框架下：

> **代码不是理论的应用演示——它就是理论本身。**

五步帧规则写在 `openSPUM/src/l0/l0_core.py` 里（v1 的 GPU 帧内核见 `openSPUM/_archive_v1/Phase_0/frame_kernels.py`），粒子逐帧演化，悬挂边被删除，新边被创建。

这不是"用代码模拟一个已经用公式描述清楚了的理论"——在 SPUM 中，**可执行性是理论的必要条件**。一个拉氏量你不能让它"运行起来看接下来会发生什么"；一串帧规则你可以。

| | 第二代公式 | 第三代规则集 |
|---|-----------|-------------|
| 是否可执行 | 否（人类解读） | 是（直接运行） |
| 验证方式 | 数学推导 → 数值近似 | 帧演化 → 直接观测涌现 |
| 对"理解"的定义 | 能写出公式 | 能预测下一帧状态 |
| 终点 | 闭合解析形式 | 可运行的演化引擎 |

## 方法论原则

### M1. 规则优先于公式

宇宙的底层描述不是一组代数方程，而是一组在每一帧中重新应用的局部转换规则。代数方程可以是规则的宏观统计投影，但不是第一性描述。

### M2. 可执行性优于可解析性

一个可运行的规则集 > 一个可解析求解但无法运行的公式。宇宙不需要被"解出来"——它只需要在每一帧中保持自洽。

### M3. 涌现是第一性现象

涌现不是"还原论尚未完成的临时状态"——**涌现结构就是理论的对象**。引力、光子、物质不是写在基础规则里的——它们是在帧演化的中高层级上必然涌现的拓扑模式。理论的终点不是还原到规则，而是**从规则出发向上重建涌现层级**。

### M4. 拓扑约束充当规则选择器

规则不是任意的。拓扑不变量（Σ(6−deg(v)) = 12、角度亏损恒为 4π、最小度数 ≥ 2、开口占比 ≤ 1/3）构成硬约束——唯一自洽的规则集是这些约束的同时满足者。

### M5. 本体论承诺是开放的

"写代码跑演化"是一个方法论上的开放承诺——你跑出什么就是什么，不接受事后调整参数来拟合。"宇宙必须是 ⟨P, ε⟩"是一个本体论上的封闭承诺。SPUM 同时站在这两个位置：**用第三代的方法论（模拟、涌现、亲历），来支撑第二代才敢提出的本体论承诺（宇宙的底层结构）。** 这不是矛盾——这是"公式封神"的旧审美被"可执行规则集"取代后的自然结果。
