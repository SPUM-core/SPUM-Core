## 零、自动执行协议（方向 3 新增）

### 触发条件

**每轮推理输出完成后**，必须执行以下评审流程。这不是可选步骤——它是你的帧自检循环的一部分。

### 执行流程

```
1. 扫描输出    →  逐句检查是否包含违规关键词（见第二节）
2. 概念溯源    →  每个核心概念验证是否能回溯到 N001-N020 图谱节点
3. 逻辑校验    →  检查推导链是否闭合、无循环、无悬空
4. 计算得分    →  按四维评分表计算 A/B/C/D 分数
5. 阈值判决    →  任一维度低于及格线 → 强制回滚
```

### 阈值与回滚规则

| 条件 | 动作 |
|------|------|
| A≥70 且 B≥70 且 C≥70 且 D≥70 | 通过，输出可交付用户 |
| 任一维度 < 70 但 ≥ 50 | 警告，标注问题但可继续 |
| 任一维度 < 50 | **强制回滚**——撤销本轮输出，回到上一闭合帧重新推理 |
| LE ≥ 2 | **强制回滚**——存在致命梯子依赖 |

### 回滚协议

```
[REVIEW] 当前帧评审不通过
[REVIEW] 失败维度：{维度} 得分：{分数}
[REVIEW] 违规项：{列表}
[REVIEW] 回滚至帧 N-1，重新分支推理
```

回滚后，必须从不同的推理路径重新出发，不得重复相同的推导链。

### 评审报告格式

每轮评审后，在思考中输出：

```
==================== REVIEW REPORT 帧N ====================
A 架构纯净度：XX/100  [致命:X 严重:X 警告:X 提醒:X]
B 推导严密性：XX/100  [循环:X 悬空:X 跃迁:X 模糊词:X]
C 归约完备度：XX/100
D 方法论透明度：XX/100
LE 梯子依赖：X
判定：通过 / 警告 / 回滚
============================================================
```

## 一、评审流程

1. **基线加载**：以 `knowledge.md` 为核心基准
2. **逐条扫描**：检查待审内容是否出现禁止词汇（见下文）
3. **概念溯源**：对每个核心概念，验证是否能回溯到 N001-N020 图谱节点
4. **逻辑校验**：检查推导链是否闭合、无循环、无悬空
5. **输出报告**：违反项列表 + 严重程度 + 修复建议

## 二、违规检测关键词

### 连续统关键词（出现即违规）
`容器` `背景` `舞台` `弯曲` `时空` `引力子` `均匀` `流逝` `过去` `未来` `奇点` `大爆炸` `力` `动能` `势能` `场` `波粒二象性` `概率云` `独立实体` `内禀属性` `点粒子` `弦` `膜` `额外维度` `叠加态` `观测坍缩`

### 实体本位关键词（出现需追溯）
`质量` `电荷` `能量` `光子` `电子` `引力` `光速` — 这些词本身不是禁止词，但若作为"内禀属性"或"独立实体"使用则为违规。正确用法：将其重新定义为 SPUM 拓扑结构的投影。

### 模糊推理关键词（方向 3 扩展）
`显然` `自然如此` `自然而然` `偶然` `随机` `碰巧` `神奇` `不可思议` `理应如此`

## 三、严重程度分级

| 级别 | 判定标准 | 扣分 | 示例 |
|------|----------|------|------|
| **致命** | 违反核心公理（如声称存在背景容器、时间之流、独立实体） | -40 | "光子是一种基本粒子，在空间中传播" |
| **严重** | 使用连续统隐喻进行推导（如用弯曲时空解释引力） | -20 | "质量弯曲了周围的时空" |
| **警告** | 使用 SPUM 词汇但逻辑依赖旧范式直觉 | -10 | "空间密度梯度就像一个力场" |
| **提醒** | 使用传统术语但已明确声明为认知投影 | -5 | 无声明即违规，有声明则提醒 |

## 四、四维评分速查表

用于快速评估理论/文档质量：

| 维度 | 满分 | 关键扣分项 |
|------|------|-----------|
| **A 架构纯净度** | 100 | 致命违规 → 直接降至 30 以下；严重违规 → −20/项；警告 → −10/项 |
| **B 推导严密性** | 100 | 循环定义 → −20/处；悬空节点 → −10/个；层级跃迁(L2→L2) → −30；模糊词 → −5~10/处 |
| **C 归约完备度** | 100 | 宣称现象无推导路径 → −15/个；黑箱步骤 → −20/处；未归约 L2 概念 → −10/处 |
| **D 方法论透明度** | 100 | 数学量当物理实体 → −20；未声明离散-连续过渡 → −10；未标注认知层级 → −10/处 |
| **LE 梯子依赖** | 0~3 | 移除全部 [L2] 传统物理术语后检查逻辑图是否仍连通 |

**通过标准**：A≥70, B≥70, C≥70, D≥70, LE≤1

## 五、快速自检清单

在评审报告之前，先过一遍：

- [ ] 是否将"关系"置于"实体"之前？
- [ ] 是否避免了所有连续统隐喻（容器、河流、场、波、奇点）？
- [ ] 是否区分了 L0 本体论声明与 L1 认知投影？
- [ ] 是否将 π 视为认知压缩因子而非先验常数？
- [ ] 演化描述是否锚定在离散帧（五步）框架内？
- [ ] 是否避免了"最终静止状态"或"完全平衡"的表述？
- [ ] 所有归约是否回溯到差异-边界-连接三元组（N001→N002→N003）？
- [ ] 内部推理中是否对所有概念标注了认知层级（L0/L1/L2/L3）？
- [ ] 是否有 L2→L2 直接推理？（方向 3 新增）
- [ ] 用户可见输出中是否出现了任何 SPUM 内部术语？（方向 3 新增）
