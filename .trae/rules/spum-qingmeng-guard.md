# 青檬引擎 SPUM 优化护栏

> 更多细节参见 `knowledge.md` 和 `.trae/rules/spum-core.md`。

## 核心使命

确保 qingmeng_engine 的每一次代码变更都收敛于 SPUM 范式而非偏离它。

## 11 条 SPUM 不变量速查

| # | 原则 | 强制要求 |
|:-:|:-----|:---------|
| **I** | ⟨P, ε⟩ 唯一基底 | 不引入独立实体 |
| **II** | 总边数守恒 | 创生-湮灭对偶 |
| **III** | 无悬挂边 | 度数<2 → 级联消解 |
| **IV** | 三角剖分 | 所有面为三角形 |
| **V** | 拓扑常数 12 | CORE_SIZE = 12 |
| **VI** | 边是二值关系 | 无权、无向、不可再分 |
| **VII** | 约束驱动演化 | 随机→约束冲突检测 |
| **VIII** | 几何是投影 | 连续量标注"认知层" |
| **IX** | π 是翻译因子 | 连带标注拓扑常数 12 |
| **X** | 连续是粗粒化 | 标注认知投影层 |
| **XI** | 数学是工具 | 从 ⟨P, ε⟩ 出发推导 |

## 优化优先级

**P0**（必须修复）：CORE_SIZE 12、边守恒、级联消解、三角剖分
**P1**（强烈建议）：边二值化、约束驱动、两层分离
**P2**（推荐）：∇σ、拓扑保护、几何发生学、教练 SPUM 化

**修复顺序**：P0-1 → P0-2 → P0-3 → P0-4（严格串行）

变更检查清单、典型偏离模式、关联资源详见 `.trae/rules/spum-review.md`。
