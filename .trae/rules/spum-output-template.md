# SPUM AI 输出模板

> 当 AI 创建/修订 SPUM 知识条目（概念、推导、实验记录）时，必须遵循以下格式。
> 联动协议：RULE-COUNT 四元组（对象→计数操作→数值→约束）、`spum-review.md` 四维评审（A/B/C/D/LE）、`spum-anti-pattern.md` 反例库自检。

---

## 一、新建知识条目

```markdown
# <概念名>

- **定义**：一句话（必须可还原到 ⟨P, ε⟩，禁止引入本体外实体）
- **关联公理**：Axiom 1-5 / 派生操作（σ、deg、V⁺/V⁻、Σ(6−deg)）
- **推导链**：<前置概念> → <本概念> → <后继概念>（节点 ID 用 N*/SOC-*/ECON-* 等注册表 ID）
- **验证状态**：⏸️ 理论推导 / 🧪 实验验证（P0-P2/N015-N016）/ ❌ 被证伪 / ✅ 已闭合
- **来源文件**：<本条目所在文件路径>

**计数四元组**（凡含数字必须给出）：
- 对象 → <对什么计数>
- 计数操作 → <怎么数，可重复执行>
- 数值 → <数出来的结果>
- 约束 → <成立条件 / 越界后果>

**反例自检**：<对照 spum-anti-pattern.md 第二部分，确认不落入任何 ❌ 模式>
```

## 二、修订已有条目

```markdown
# <概念名>（修订）

- **变更内容**：<改了什么>
- **变更原因**：<为什么改——新实验/发现矛盾/补推导>
- **影响范围**：<受影响的文件、下游概念、四维评分维度>
- **旧表述去向**：<归档位置或保留说明>
```

## 三、跨域条目（社会学/经济学/语言学/数学/五行/哲学等）

在通用模板基础上追加：

```markdown
- **域内映射**：<该概念在目标域的 G_<域> 子图定义>
- **桥接公理**：<与哪个 L0 公理/派生操作桥接>
- **域间一致性**：<与核心图谱中哪个 N* 节点对齐>
```

---

## 四、评审联动

创建/修订完成后自动执行：
1. `spum-review.md` 四维评分 → 任一度 < 70 标记 ⏸️ 待完善，不标注 ❌
2. `spum-anti-pattern.md` 反例自检 → 命中 ❌ 模式立即用 ✅ 版本替换
3. RULE-COUNT 计数链 → 给不出计数操作的数字标注"待核实"

## 五、禁止事项

- 禁止用"大概 / 显然 / 自然出现"替代推导
- 禁止把 π、坐标、概率、容差等 L1 投影当作 L0 本体常数（须标注"投影"）
- 禁止新建无 `N-*`/模块 ID 的孤立概念（须在 `network/module_nodes.txt` 注册）
