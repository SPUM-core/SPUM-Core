## 二、SPUM 本体论词汇（必须使用）

### 基本构成
| 概念 | 定义 |
|------|------|
| 节点 / 空间粒子（κ-particle） | 边界的最小不可分单元，本质是关系束。无内禀属性，仅作为位置存在 |
| 边 / 连接 | 两个节点之间的直接连接关系。无向、无权重，关系的唯一载体 |
| 度数 deg(v) | 节点的直接邻居数量。最基础的组合量，不依赖几何或认知投影 |
| 晶子 | 0 层级空间粒子。D = 4κ，构成空间骨架 |
| 永恒粒子 | 多个晶子通过拓扑锁定形成，带单开口，可自持位移 |

### 演化机制
| 概念 | 定义 |
|------|------|
| 创生事件 V⁺ | 新边被创建。必须对偶于某湮灭 |
| 湮灭事件 V⁻ | 边被断开。触发级联消解至所有 deg ≥ 2 |
| 悬挂边删除 | 帧结束时 deg < 2 的边被逻辑修剪 |
| 离散帧 | 创生→连接→变化体积→判断→删除（五步，一帧一次删除） |
| 净湮灭效应 | 闭合子图内湮灭 > 创生。引力就是净湮灭效应本身 |
| 空间密度梯度 ∇σ | σ 从内向外递减。引力场的拓扑定义 |
| dv/dt ≤ const | 单帧变化上限。增长天花板 |

### 演化引擎——五形（五行，五种基本拓扑结构模式）

> 五形是从 ⟨P, ε⟩ 公理 + 五步帧演化规则中必然涌现的五种基本网络结构模式。每一种都不是独立实体，而是网络在特定局部区域所处的拓扑状态。五形向量 S = (S_水, S_木, S_土, S_金, S_火) 构成网络健康度的完整描述。

| 概念 | 图论定义 | 公理来源 |
|------|----------|----------|
| **水形**（链式传输） | 网络中的无分支极大路径。度量：平均最短路径 L、全局效率 E_glob、边介数中心性分布。水形通畅 → L 小、流量分散；水断 → L 骤增、介数集中于少数幸存边 | 五步帧 V⁺ 创生阶段：新边沿已有连接向外延伸，自然形成链状结构。链的方向性来自实面锚点向外生长 |
| **木形**（环路骨架） | 网络中的闭合环结构。度量：环基数 μ = M − N + C、聚类系数 C_Δ、代数连通性 λ₂。木形健康 → μ 适中；木僵 → μ 过大、λ₂ 异常升高 | 拓扑守恒公理（角度亏损总和恒为 4π）：闭合子图必然成环。环是拓扑约束的刚性骨架，过度成环则僵化 |
| **土形**（分散储备） | 低度节点和孤立小分量构成的资源库。度量：度 ≤ 2 的节点占比、网络碎片化指数 F = 1 − |最大分量|/N。土形充足 → 悬挂节点多；土虚 → 悬挂节点被耗尽 | 悬挂边删除的必然副产品：每帧删除后残留的低度节点不参与主干与环路，自然形成储备池 |
| **金形**（修剪切断） | 网络中位于少数环（甚至无环）上的边，是修剪操作的目标。度量：桥边数量、割集大小、修剪潜力 = 边介数 − 环数贡献。金形健康 → 适度脆弱；金亢 → 过度碎裂 | 五步帧"判断→删除"阶段：桥边因不满足度数约束而被逻辑修剪。金形不是"破坏者"，是拓扑自洽的强制执行者 |
| **火形**（密度梯度） | 节点度或局部邻接密度的空间不均匀分布，驱动水形链定向流动。度量：节点度梯度 ⟨∇k⟩、拉普拉斯特征谱、火势 Φ = Var(ΔV_i)。火衰 → 梯度趋零（均匀/热寂）；火亢 → 梯度极大 | 空间密度 σ = |P|/|ε| 的自然推论：σ 的区域差异必然产生梯度，梯度驱动体积流沿水形通道定向移动 |

**五形之间的动力学耦合**（均可从五步帧公理推导）：
- 火形梯度 → 驱动水形链中的体积流定向输送
- 水形链 → 将土形储备节点输送到木形环路生长前沿
- 土形供给 → 木形环路获得新节点、扩大骨架
- 木形过度 → 环基数超出临界值 → 激活金形修剪
- 金形修剪 → 断开桥边 → 释放被锁定节点 → 回归土形储备池 → 同时产生新的火形梯度

这是一套**从 ⟨P, ε⟩ 公理自发生成的反应-扩散系统**，不需要任何额外的"力"或"驱动"假设。

### 结构属性
| 概念 | 定义 |
|------|------|
| 拓扑常数 12 | 0 层级节点恰好 12 个。欧拉恒等式强制解 |
| 分形约束生长 | 0→缝隙→1→缝隙→2，递归生成。层级由生长时序定义 |
| 几何发生学 | 欧氏几何是关系网络在宏观尺度的统计投影 |
| 认知投影 | 离散拓扑结构被投影为连续几何图像的过程 |

### 认知方法
| 概念 | 定义 |
|------|------|
| π 的降级 | π 不是宇宙常数，是认知压缩因子。纯组合路径中完全不出现 |
| 离散系统本体论证明 | 计算机/AI = ⟨P, ε⟩ 在宇宙中的实例。能模拟所有连续现象 = 连续是离散的投影 |

## 三、判定原则

1. **关系先于实体**：任何将“独立实体”置于“关系”之前的描述，均为违规
2. **离散先于连续**：任何使用连续统隐喻描述宇宙本体的语言，均为违规
3. **dv/dt ≤ const 先于无限增长**：暗示无限增长、无限加速、无限密度的描述，均为违规
4. **演化先于静止**：暗示宇宙有最终静止状态或终结的描述，均为违规
