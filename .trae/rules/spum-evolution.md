# SPUM 演化规则：离散帧、创生湮灭与驱动力

## 一、演化的根本驱动力：几何矛盾

演化不是由外部推动的——没有“力”、没有“能量”、没有“第一推动”。驱动力是一个内生的、不可消除的**几何矛盾**：

> **填补一个空隙，必然产生更多新空隙。**

当局部网络通过创生填补已有空隙时，新生成的粒子之间的相切关系，必然产生更小尺度的新生空隙。填补得越多，新生缝隙越多。变化不是被“驱动”的，变化本身就是关系网络存在的常态。

## 二、离散帧结构

### 2.1 五步帧序列

```
1. 创生     →  新边被创建（V⁺ 事件），必须对偶于某湮灭事件
2. 连接     →  新边建立后，节点连接关系更新，度数重算
3. 变化体积 →  节点度数变化导致等效体积变化，σ 局部波动
4. 判断     →  检查所有节点度数——是否存在悬挂边（deg < 2）？
5. 删除     →  删除所有悬挂边。若某节点度数降至 0，同步删除该节点
```

### 2.2 关键约束

- 一帧内没有循环，没有级联消解——一帧只做**一次**删除
- 删除后新产生的悬挂边，是**下一帧**处理的起点
- 帧与帧之间没有中间状态，不存在“概率云”或“叠加态”
- 节点要么连接，要么不连接，系统状态唯一且确定

## 三、创生与湮灭

### 3.1 创生事件 V⁺

一条新边被创建。必须遵循**创生-湮灭对偶**约束——每个创生必是某湮灭的对偶补偿。伴随效应：局部边数增加、σ 降低、体积膨胀。

### 3.2 湮灭事件 V⁻

一条已存在的边被断开。触发级联消解——若某节点度数降至 1，同步删除该节点及其所有关联边，重复直至所有节点度数 ≥ 2。伴随效应：σ 升高、体积收缩。

### 3.3 创生-湮灭对偶

任何一个局部闭合子图内部的湮灭事件，其净边删除量必然转移到背景混沌网络中，表现为背景的净创生。演化的本质不是“创造”或“毁灭”，而是**关系容量的重分配**。

### 3.4 悬挂边删除

在一帧结束时，度数 < 2 的边被逻辑修剪。这是逻辑自洽的强制执行，不是物理过程。

## 四、净湮灭效应：引力的拓扑本质

### 4.1 闭合子图中的特殊动力学

闭合子图内部：创生事件被严格禁止（破坏拓扑不变量——角度亏损总和恒为 4π），湮灭事件仍自由发生。结果：稳定的净边删除。

**引力不是“力”——它就是净湮灭效应本身。**

### 4.2 空间密度梯度：引力场的拓扑定义

物质粒子的净湮灭导致周围 σ 升高，形成从内向外递减的梯度场。这就是引力场的拓扑定义。

在宏观弱场近似下，σ(r) = σ₀ + km/r²，代入加速度方程得到 a = −2kc²m/r³，与牛顿万有引力 a = −Gm/r³ 完全一致（G = 2kc²）。

## 五、永恒粒子与物质粒子

### 5.1 永恒粒子

多个晶子通过拓扑锁定形成的稳定结构。带单开口，具有自持位移能力。开口驱动的自持位移循环：吞噬前方空间粒子 → 内部湮灭与重排 → 向后方排出 → 净位移 Δx = 4κ/τ = c。

- 小开口：质量 > 0，对应电子
- 大开口：质量 = 0，速度恒为 c，对应光子

### 5.2 物质粒子

12 个永恒粒子以正二十面体对称性锁定。所有开口朝内，对外不暴露——对外等效开口占比为 0，结构高度稳定。对应质子/中子。

## 六、不完美：永恒演化的保证

一帧结束时，网络永远无法达到“所有节点度数 ≥ 2”的完美状态。因为删除悬挂边必然产生新的悬挂边——被删除节点的邻居可能因此度数降到 1。旧帧的残留，是新帧的动力。宇宙自身就是一部永动机，无需任何外部“第一推动”。
