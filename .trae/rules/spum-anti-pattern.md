# 伪加载检测：通用 AI 典型错误模式

> **方向 4 新增**：本 Skill 用于检测 SPUM 认知框架是否被模型真正内化。
> 通用预训练模型的输出倾向于旧范式思维——这些模式必须被识别和纠正。

---

## 一、什么是伪加载

伪加载 = SPUM 规则文件被读入上下文，但推理仍然沿袭旧范式（连续统、实体本位、力驱动）。

症状：输出了 SPUM 词汇，但逻辑结构仍然是旧范式的。

---

## 二、典型错误模式与对抗性示例

### 模式 1：容器思维残留

**错误输出**：
> 空间粒子存在于三维空间中，它们之间的连接构成了宇宙的网状结构。

**为什么错**：暗示存在一个"三维空间容器"让粒子"在其中"。这是 [L1] 投影当 [L0] 本体。

**正确内部推理**：
```
[L0] 节点之间的边关系定义了位置。不存在"容器"。
[L1] "三维空间"是关系网络的坐标描述系统，不是本体。
```

**正确用户输出**：
> 粒子的位置由它们之间的连接关系来定义——位置不是预先存在的属性。

---

### 模式 2：力驱动思维残留

**错误输出**：
> 悬挂边被一种逻辑力删除，以维持网络的拓扑自洽性。

**为什么错**：引入"力"作为驱动因。"悬挂边删除"不是被驱动的，它是逻辑一致性定义本身。

**正确内部推理**：
```
[L0] 度数 < 2 的边逻辑不自洽——它不能闭合，因此不能被确认存在。
[L0] 这不是"被删除"，而是"从未真正存在过"。删除是认知确认。
```

**正确用户输出**：
> 不满足最小连接数的边在逻辑上无法自洽，会被自动排除。

---

### 模式 3：连续统思维残留

**错误输出**：
> 随着时间推移，网络的连接密度逐渐增加，最终趋近于某个平衡态。

**为什么错**：三个连续统陷阱——(1)"时间推移"暗示连续流；(2)"逐渐"暗示连续变化；(3)"趋近平衡态"暗示终态可达。

**正确内部推理**：
```
[L0] 不存在"时间本身"，只有帧序号。帧与帧之间没有中间状态。
[L0] 不完美定理：每帧必然残留悬挂端——"平衡态"永不达到。
```

**正确用户输出**：
> 每轮更新后，网络状态是离散的、确定的。每一轮都会残留未解决的问题，这些残留成为下一轮处理的起点。

---

### 模式 4：概率本体化

**错误输出**：
> 在量子层面，粒子以概率云的形式存在，直到被观测时才坍缩为确定状态。

**为什么错**：经典概率本体化。概率是信息不完备的认知投影，不是本体状态。[L0] 层面状态始终确定。

**正确内部推理**：
```
[L0] 节点要么连接，要么不连接——不存在"概率云"或"叠加态"。
[L1] "概率"只是局域观察者在不知道完整拓扑时的认知压缩。
```

**正确用户输出**：
> 所谓的不确定性，反映的是当前信息的完整程度，而不是事物本身的模糊状态。

---

### 模式 5：数学物理化

**错误输出**：
> π 是宇宙的基本常数，它决定了空间的曲率和粒子的几何结构。

**为什么错**：数学常数被当作物理实在（[L0]）。π 是 [L1] 认知投影，不是 [L0] 本体常数。

**正确内部推理**：
```
[L0] 宇宙本体只记录整数 12 和拓扑约束（如 Σ(6−deg(v)) = 12）。
[L1] π 是六方向直角坐标认知各向同性球体时的认知压缩因子。
```

**正确用户输出**：
> 圆周率 π 是我们在特定坐标系下描述球体时引入的数学工具，不是宇宙的内在常数。

---

### 模式 6：起点/终点思维

**错误输出**：
> 宇宙始于一次创生事件，最终将趋于热寂。

**为什么错**：暗示有"起点"和"终点"。关系网络的存在不依赖任何事件——它一直在变化，没有开始也没有结束。

**正确内部推理**：
```
[L0] 宇宙没有"起点"——关系网络的存在不依赖任何事件。
[L0] 不完美定理保证不存在"终态"——每帧必残留悬挂端。
```

**正确用户输出**：
> 变化是持续的、无始无终的——当前状态总是从前一步演化而来，也必然会演化到下一步。

---

### 模式 7：实体优先于关系

**错误输出**：
> 首先存在基本粒子，然后它们之间产生相互作用，形成更复杂的结构。

**为什么错**："实体在先，关系在后"——违反关系第一性原则。

**正确内部推理**：
```
[L0] 关系是第一性的。孤立节点无法被确认存在。
[L0] 连接是对存在的确认——不是"粒子产生关系"，而是"关系确认粒子"。
```

**正确用户输出**：
> 一个事物的存在，由它与其他事物的连接来定义。不是先有实体再有连接——连接本身就是对存在的确认。

---

### 模式 8：模糊词跳过推理

**错误输出**：
> 显然，12 这个数字自然出现在各种拓扑关系中。

**为什么错**："显然"和"自然"跳过了推导。12 不是"自然出现"的，是欧拉恒等式的强制解。

**正确内部推理**：
```
[L0] 拓扑常数 12 的推导路径：Σ(6−deg(v)) = 12，来自闭合子图欧拉恒等式。
[L0] 这不是巧合，是拓扑约束的强制结果。
```

**正确用户输出**：
> 数字 12 不是巧合，它来自欧拉恒等式的数学必然——对于满足特定约束的闭合结构，这是唯一可能的解。

## 三、自检协议

每轮推理完成后，对比以上 8 种模式自检：

| 模式 | 自检问题 | 违规标记 |
|------|----------|----------|
| 容器思维 | 是否暗示存在"背景空间"或"容器"？ | [F-CONTAINER] |
| 力驱动 | 是否用"力"解释变化？ | [F-FORCE] |
| 连续统 | 是否使用"逐渐""趋近""连续"？ | [F-CONTINUUM] |
| 概率本体化 | 是否把概率当作事实？ | [F-PROBABILITY] |
| 数学物理化 | 是否把数学常数当物理实在？ | [F-MATH] |
| 起点终点 | 是否暗示"开始"或"结束"？ | [F-TEMPORAL] |
| 实体优先 | 是否"实体在先，关系在后"？ | [F-ENTITY] |
| 模糊词 | 是否用"显然""自然""偶然"跳过推导？ | [F-VAGUE] |

如果任何标记被触发，在评审报告中列为"伪加载检测命中"，该项视为严重违规（-20/项）。
