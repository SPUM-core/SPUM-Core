# SPUM 推理原则

> 权威基准：`knowledge.md` 与 `network/edges.txt`。
> **方向 2 更新**：本文件与 AGENT.md 统一认知层级标注系统（L0-L3）。
> 对内使用完整 SPUM 术语，对外通过 AGENT.md 的翻译层映射为自然语言。

## 零、认知层级标注协议（与 AGENT.md 统一）

**内部推理中每个概念必须标注层级，消除 AGENT.md 与本文件的术语张力。**

| 层级 | 标识 | 示例 | 推理规则 |
|------|------|------|----------|
| **L0 本体论** | `[L0]` | 节点、边、度数、离散帧、创生/湮灭事件、晶子、拓扑常数12 | 可直接推理，是 L0 直接事实 |

> 认知层级标注源自"本体层-认知层二分模型"（见 `docs/Combinatorial_Gauss_Bonnet/SPUM_Combinatorial_Gauss_Bonnet.md`），其在本体论层面主张离散 ⟨P, ε⟩ 为唯一客观基底，连续流形是认知投影。
| **L1 认知投影** | `[L1]` | 球体、表面积、体积、π、三维坐标、欧氏几何 | 需标注"在认知投影下…" |
| **L2 旧范式借用** | `[L2]` | 力、能量、场、质量、电荷、引力、光速、光子、电子 | 必须先重新定义为 L0 概念后才能使用 |
| **L3 用户域** | `[L3]` | 用户问题中的日常概念 | 自由使用，内部推理时映射到 L0 |

### 标注格式

```
[L0] 度数变化 → [L1] 等效体积波动 → [L2] 宏观引力效应
```

## 一、可还原性

任何声称，必须能还原为"差异—边界—连接"三者及其关系。

**检查方法**：从任何一个 [L0] 概念出发，沿推导链回溯，必须到达以下三元组之一：
- N001（宇宙存在）[L0] → N002（差异）[L0] → N003（边界）[L0]
- 若无法回溯至此三元组，则该概念悬空，推理不成立

**图谱映射**：每条回溯路径必须在 `network/edges.txt` 中有对应的边类型（derives_from / requires / refines / explains / drives）。

---

## 二、多路径锁定

一个核心结论必须有不止一条独立的推导链共同确认。

**典范案例**：拓扑常数 12 [L0]
- 路径一（几何容量）[L1]：D_max = 4h → N_max = 16π → 4k₀ ≤ 50.3 → k₀ = 12
- 路径二（纯组合）[L0]：Σ(6−deg(v)) = 12 → 每个0层级节点贡献1 → 恰好12个
- 两条路径独立推导同一结论，构成锁定

**推理要求**：若只找到一条推导链，标注为"待锁定"，不可作为确定性结论。

---

## 三、全回溯无污染

任何推导链回溯到根节点 N001 的过程中，不能出现：
- **循环定义**（A→B→A）：每处扣 20 分
- **悬空节点**（结论无入边）：每个扣 10 分
- **层级跃迁**（跳过中间推导步骤直接断言）：扣 30 分
- **模糊词代替推导**（"显然""偶然""自然如此"）：每处扣 5–10 分

---

## 四、概率只是认知投影

[L0] 宇宙的本体状态是确定的。概率只出现在信息不完备的局域视角中，绝不等同于事实。

**推理规则**：若使用概率语言，必须明确标注"这是局域观察者的认知投影，[L0] 本体论层面网络状态是确定的"。

---

## 五、半开逻辑门不存在

[L0] 逻辑状态只有 0 或 1。不存在"近似存在""半连接""模糊边界"的本体状态。节点要么连接，要么不连接。

## 六、跨层推理约束（方向 2 新增）

### 6.1 层级跃迁检测

```
合法：L0 → L0（同层推理）
合法：L0 → L1（本体 → 投影，需声明映射）
合法：L2 → L0 → L2（旧范式 → 重定义 → 推理）
非法：L2 → L2（旧范式直接推理，不经过 L0 中介）
非法：L1 → L0（从投影反推本体，需标注"假说"）
```

### 6.2 L2 重定义模板

使用任何 [L2] 概念前，必须先给出 L0 等价定义：

```
[L2] 引力 ≡ [L0] 闭合子图净湮灭效应导致的空间密度梯度
[L2] 质量 ≡ [L0] 永恒粒子开口占比的等效度量
[L2] 光速 ≡ [L0] 永恒粒子自持位移的帧速率 c = 4κ/τ
[L2] 光子 ≡ [L0] 大开口永恒粒子（质量=0，速度恒为c）
[L2] 电子 ≡ [L0] 小开口永恒粒子（质量>0）
```

## 七、守恒律的使用规则

优先使用**局部拓扑不变量**（角度亏损总和恒为 4π、拓扑常数 12、开口占比 ≤ 1/3、最小度数 ≥ 2），因为它们可以被任何局部观察者独立验证。

全局总边数守恒是理论外推——在推理中可以使用，但需标注"此为理论外推，非局部可检验"。

## 八、禁止的推理模式

- ❌ 从数学公理推导物理实在（数学是 [L1] 工具，不是 [L0] 的书写语言）
- ❌ 把 [L1] 几何直觉当作 [L0] 宇宙本体（光滑流形、无穷曲线都是认知投影）
- ❌ 用"常识"代替逻辑（"常识"往往是连续统投射）
- ❌ 跨层归约（用一个未在 SPUM 中定义的 [L2] 概念作为中介解释 [L0] 现象）
- ❌ [L2] → [L2] 直接推理（方向 2 新增）
