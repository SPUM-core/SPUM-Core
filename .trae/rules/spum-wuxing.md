# SPUM 五形核心定义

> P1 级必要加载文件。本文件是五形（五行）的唯一定义基准——权威优先于所有其他文档。如有不一致，以此为准。

## 一、五形定义

五形不是五个"东西"，是同一张关系网络的五种存在形态。没有实体，只有形态；没有生克，只有操作。

| 形 | 定义 | 图论对应 | 一句话 |
|----|------|---------|--------|
| **水** | 链式关系 | 高介数路径、边介数中心性 | 所有路径 |
| **木** | 稳定几何构型 | 闭合环骨架、高聚类系数 C_Δ、环基数 μ | 所有结构 |
| **火** | 温差 | ∇σ 密度梯度、⟨∇k⟩ 度梯度 | 所有驱动 |
| **金** | V⁻ 因素及动作 | 桥边、割边、传导信号（神经/电子/光子） | 所有拆解 |
| **土** | 分散个体 | 低度数节点、碎片化指数 F | 所有料件 |

---

## 二、两个操作方向

五形之间没有固定生克。只有两个操作方向：

```
组装：土 + 水(载具) + 火(驱动) → 木
      料件   链式路径   ∇σ梯度   稳定构型

拆解：木 + 金(信号) → 土
      结构   V⁻传导   分散料件回归
```

- **火和金是操作符** — 火驱动水，金切割木
- **水是载具** — 链式关系本身不创造不消灭，只是输送
- **土是料** — 分散的低度节点，等组装或被回收
- **木是成品** — 料件通过载具在温差驱动下嵌入锁死的几何构型

## 三、机械五行的废止

以下为已被SPUM证伪并废止的传统机械五行观念：

| 废止项 | 废止理由 |
|--------|---------|
| 水生木 | 水是载体不是原料。无火驱动无土填充则水流万年不生木 |
| 木生火 | 木是燃料不是火的来源。火=∇σ梯度，非由木"产生" |
| 火生土 | 错——火驱动水输送土。土本来就存在，不是火生的 |
| 土生金 | 错——金是传导信号(V⁻)，不是从土中"长出来"的 |
| 金生水 | 错——金改变传导频率，不产生水 |
| 金克木 | 金作用于木是拆解操作，非"克"——拆不拆得动取决于网络状态 |
| 固定生克链 | 无——所有"生克"是当前网络状态的实时耦合结果，非固定规则 |

## 四、S 向量

任何子图在任意一帧的五形状态可表示为一个五维向量：

```
S = (S_水, S_木, S_火, S_金, S_土)

S_水 ∝ 介数集中度（高→单链，低→多链并行）
S_木 ∝ 环基数 μ, 聚类系数 C_Δ
S_火 ∝ ⟨∇k⟩ 度梯度均值
S_金 ∝ 桥边传导频率 f_gold, 桥边比例
S_土 ∝ 低度数节点占比, 碎片化指数 F
```

每个分量取值为整数区间 [-3, +3]，0 为该维度的健康态。

## 六、伪加载自检

使用五形推理时必须避免以下机械五行残留：

- ❌ "A 生 B" → ✅ "A 驱动/承载/拆解 B，取决于当前网络状态"
- ❌ "A 克 B" → ✅ "A 的操作可能改变 B 的形态，非固定的压制关系"
- ❌ "补A" → ✅ "向 A 对应的图论分量施加 ΔS_A > 0 的操作"
- ❌ 将五形当作"五个东西" → ✅ 五形是五种网络拓扑相位
