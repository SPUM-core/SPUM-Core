## R1 │ ⟨P, ε⟩ — 节点集 + 边集，关系定义存在

**SPUM 定义**：宇宙的本体是一张动态关系网络。P 为节点集合，ε 为边集合。无悬挂边，最小度数≥2。所有节点统称为空间粒子（κ‑particle）。没有背景容器，没有时空舞台——关系网络本身就是空间。

**不可简化的核心**：关系是第一性的。孤立节点无法被确认存在。连接是对存在的确认。

**推导链**：N001（宇宙存在）→ 本节点即 ⟨P, ε⟩ 本身。

| 模块 | 映射 |
|------|------|
| 社会学 | G_social — 社会网络子图。人为节点，社会关系为边 |
| 经济学 | G_econ — 经济交换子图。人为节点，交易为有向加权边 |
| 语言学 | G_ling — 认知子图间信号编码协议。词=符号边，句法=组合约束 |
| 物理学 | 一切物理实体的终极底板——没有"场"，只有网络 |
| 五形/五行 | 一切存在论的终极底板 |
| 儒释道 | 如来藏（楞严经）；道 = ε（道德经） |

## R2 │ V⁺ / V⁻ — 创生事件 / 湮灭事件，全局守恒，局域有净差

**SPUM 定义**：V⁺ = 新边被创建。V⁻ = 已存在的边被断开。总边数全局守恒（|ε|=常数），创生与湮灭必须严格对偶——任何一个局部闭合子图内部的湮灭事件，其净边删除量必然转移到背景混沌网络中，表现为背景的净创生。演化的本质是关系容量的重分配，不是"创造"或"毁灭"。

**不可简化的核心**：变化=边连接方式的重新配置。没有"从零创造"也没有"彻底消灭"。

**推导链**：N008（总边数守恒）→ N009（创生事件）→ N011（悬挂边删除=V⁻的强制形式）

| 模块 | 映射 |
|------|------|
| 社会学 | 社会边的创建/衰减。友谊建立=社会V⁺，断交=社会V⁻ |
| 经济学 | 交易=双向V⁺/V⁻：商品流出+货币流入 |
| 语言学 | 说话=概念子图→信号V⁺发射；理解=信号→概念子图V⁺重建 |
| 物理学 | 能量守恒=总边数守恒；力的推动=局域净V⁺/V⁻差 |
| 五形/五行 | 阴阳、消长、生死、药物作用 |
| 儒释道 | 生灭（楞严经）；"有无相生"（道德经）——边的创建(阳)与删除(阴) |

## R3 │ 离散帧 τ — 演化步数，帧内无循环

**SPUM 定义**：一个完整帧 = 创生 → 连接 → 变化体积 → 判断悬挂边 → 删除悬挂边。一帧内没有循环，没有"级联消解"，一帧只做一次删除。删除后新产生的悬挂边是下一帧处理的起点。帧与帧之间没有中间状态——节点要么连接，要么不连接。dt = 一个离散帧。

**不可简化的核心**：没有"时间本身"，只有"网络演化到第几步"。时间不是背景、不是河流。

**推导链**：N012（离散帧）← N011（悬挂边删除）← N010（体积变化）← N009（创生）

| 模块 | 映射 |
|------|------|
| 社会学 | 逐帧变迁累积。没有"时代趋势"，只有逐帧微调 |
| 经济学 | 经济变化的逐帧累积——没有"趋势"，只有逐笔交易 |
| 语言学 | 语言变化的逐帧漂移——没有"时代趋势"，只有逐帧微调 |
| 物理学 | 时间=帧计数；dt=一个帧步长 |
| 五形/五行 | 病程阶段（六经传变）、药效时序 |
| 儒释道 | "生灭相续，如旋火轮"（楞严经）——帧的离散序列 |

## R4 │ dv/dt ≤ const — 单帧关系变化上限

**SPUM 定义**：dv 指单个节点在一次离散帧跃迁中关系变化量的绝对值。dt = τ（一个离散帧周期）。const 由关系网络的拓扑容量决定的内禀上限。D_max=4κ 意味着没有节点可以在一次帧内吞下超过自身容量上限的关系量。它是物理事实，不是认知约束。

**不可简化的核心**：任何事物的增长都存在关系饱和的上限。不是经验观察，是关系网络拓扑容量的逻辑必然——节点触及容量极限即达关系饱和，任何超越在结构上被拒绝。

**推导链**：N004（节点/空间粒子）→ D_max=4κ 为节点容量的绝对上限

| 模块 | 映射 |
|------|------|
| 社会学 | 邓巴数——认知容量上限≈150。单人单帧能维护的社会连接数有限 |
| 经济学 | 交易容量天花板——单人单帧能完成的交易数有限 |
| 语言学 | 单句容量——一句话内不能嵌入超过认知deg上限的嵌套结构 |
| 物理学 | 光速上限c=λ₀/τ₀；普朗克尺度；隧穿概率边界 |
| 五形/五行 | 病变起源、治疗的安全边界 |
| 儒释道 | 道给万物设定的天花板——一条边在单帧内只能传播一个邻接位 |

## R5 │ 不完美定理 — 每帧必残留悬挂端

**SPUM 定义**：一帧结束时，网络永远无法达到"所有节点度数≥2"的完美状态。因为删除悬挂边必然产生新的悬挂边。不完美是双层的：(1) 边缘不完美——每帧必残留悬挂端；(2) 中心不完美——锚点持续震荡，永不"锁定"。2026年N016实验：DeepCNN 97.1%正确率下锚点漂移率Δμ最小6.16，完整拓扑闭合在标准训练中不可达。

**不可简化的核心**：不完美不是待消除的缺陷——它是系统持续运行的本质结构。旧帧的残留是新帧的动力。

**推导链**：N013（不完美）← N012（离散帧）← N011（悬挂边删除）。N013→N009→驱动下一帧。

| 模块 | 映射 |
|------|------|
| 社会学 | 永远存在社会孤立者(deg<2)和∇σ≠0。制度永有漏洞 |
| 经济学 | 永远存在经济孤立者(deg_econ<2)和资源稀缺(∇σ≠0) |
| 语言学 | 任何通信都不可能完美传递全部拓扑信息——图→序列→图必有损失 |
| 物理学 | 永动机不存在；热寂不可达；真空涨落 |
| 五形/五行 | 慢性病根、亚稳态吸引子。完全健康不可达 |
| 儒释道 | "反者道之动"——不完美驱动持续演化；轮回——永无终态 |

## R6 │ S 向量 = (S_水, S_木, S_土, S_金, S_火) — 五维结构健康向量

**SPUM 定义**：五形是从 ⟨P, ε⟩ 公理+五步帧演化规则中必然涌现的五种基本网络结构模式。S 的五个分量分别度量当前帧中五种拓扑相位的活跃程度/健康程度。S∈H（健康多面体）⇔ 健康。S 越出 H 边界 ⇔ 异常态。

- **S_水**：链式传输结构健康度（度量：平均最短路径L、全局效率E_glob）
- **S_木**：闭合环路骨架健康度（度量：环基数μ、聚类系数C_Δ、代数连通性λ₂）
- **S_土**：分散储备池充足度（度量：度≤2节点占比、碎片化指数F）
- **S_金**：修剪切断活跃度（度量：桥边数量、修剪潜力）
- **S_火**：密度梯度驱动力（度量：节点度梯度⟨∇k⟩、火势Φ）

**不可简化的核心**：五形不是五个独立实体——它们是同一张关系网络在演化中必然呈现的五种拓扑相位。

**推导链**：N012（离散帧五步）→ N009（创生产生水形）→ N007（闭合产生木形）→ N011（删除产生土形/金形）→ N020（∇σ产生火形）

| 模块 | 映射 |
|------|------|
| 社会学 | 制度的S向量——是否在H内 |
| 经济学 | 经济健康向量——σ分布、∇σ幅度、deg分布等 |
| 语言学 | 语言健康向量——σ_ling分布、词汇边稳定性、音系边完整性等 |
| 物理学 | 凝聚态相变=S穿越H边界 |
| 五形/五行 | 人体闭合子图的S向量健康/偏移/修复 |
| 儒释道 | 五蕴=S向量的五个分量（心经）；中=S在H中心（中庸）|

## R7 │ 健康多面体 H — S 向量的合理区间凸区域

**SPUM 定义**：H 是五维空间中一个凸多面体，定义为 S 的各分量在合理区间内的交集。S∈H 表示系统的五种拓扑相位处于相互制衡的健康状态。S 跃出 H 的某个面→对应的异常态（水断/木僵/土虚/金亢/火衰）。

**不可简化的核心**：H 不是"黄金标准"——它是由不完美定理保证的、存在宽度但非无限的稳定区域。没有任何系统可以永久停留在 H 中心。

**推导链**：N016（拓扑常数12）→ 健康结构的几何容量约束 → H 的形状由拓扑常数锁定

| 模块 | 映射 |
|------|------|
| 社会学 | 社会流动的健康区间 |
| 经济学 | 经济健康区间——通胀/失业/增长的合理范围 |
| 语言学 | H_ling——语言变化的健康范围（过快=崩解，过慢=僵化）|

## R8 │ ΔS — 干预 = 五维位移向量

**SPUM 定义**：ΔS 是单帧内 S 向量的变化量。任何外部干预（药物、政策、教育、通信）都表现为一个五维位移向量——五个拓扑相位各被推动多少。ΔS 的大小受 dv/dt≤const 约束。

**不可简化的核心**：所有"作用"都归结为对 S 向量的位移操作。没有"力"，只有拓扑相位的调整。

**推导链**：N011（悬挂边删除）= ΔS 的一种特殊形式——通过修剪金形分量推动 S 向量

## R9 │ σ = |P| / |ε| — 空间密度

**SPUM 定义**：σ 是节点数对边数的比值。节点平均度数⟨deg⟩=2/σ。高σ区域=度数低、连接稀疏→温度更高。低σ区域=度数高、连接饱和→温度更低。σ 的区域差异产生 ∇σ——这是所有定向运动的唯一驱动因。不需要"力"。引力 = 净湮灭驱动的空间流，其宏观读数是 ∇σ。

**不可简化的核心**：σ 是连接网络中最重要的单一标量场——温度、引力、电磁力、经济压力、社会密度，全部是 σ 或其梯度的投影。

**推导链**：N020（运动与引力）→ 引力=空间流（读数 ∇σ）。N010（体积/存在权重）→ σ决定节点等效体积。

| 模块 | 映射 |
|------|------|
| 社会学 | σ_social=社会密度。不平等=σ分布不均匀 |
| 经济学 | σ_econ=经济密度。价格=σ交换比的瞬时编码 |
| 语言学 | σ_ling=词汇量/语义边数。语言精确度/丰富度度量 |
| 物理学 | 温度T=f(σ⁻¹)；引力=空间流（读数 ∇σ）；电磁力=σ层级差异 |
| 五形/五行 | 寒热、温度、能量分布。火形=∇σ |
| 儒释道 | 道=ε(边集)→ε越多σ越低→万物越"实" |
