# 先天五行命格 × 波动率预测系统 — 可视化交互页面

## 1. 产品概述

基于 SPUM 五行命格理论的 A 股波动率预测系统的可视化仪表盘。将 58 只核心 A 股的先天五行命格 S₀、命格分组、配对预测结果以交互式图表呈现，让用户直观探索"同命格股票波动一致性"这一核心假设。

- **解决的问题**：将命令行预测脚本的输出转化为可交互的可视化分析工具，支持命格浏览、波动对比、预测矩阵的探索
- **目标用户**：量化研究者、五行命理与金融交叉领域的探索者、SPUM 理论验证者

## 2. 核心功能

### 2.1 功能模块

1. **命格总览面板**：展示 58 只股票的 S₀ 五行向量分布，支持按五行元素筛选和排序
2. **命格分组雷达图**：每个命格组（如"土旺缺火金"）以雷达图展示五行向量，列出组内成员
3. **配对预测矩阵**：32 个配对的 Ridge / XGBoost 预测提升率热力图矩阵
4. **波动曲线对比**：同命格组内任意两只股票的超额波动率曲线叠加对比

### 2.2 页面详情

| 页面/面板 | 模块名称 | 功能描述 |
|-----------|---------|---------|
| 全局仪表盘 | 命格散点图 | 58 只股票的 S₀ 向量投影到五维空间的散点可视化（降维到二维），颜色编码五行元素 |
| 全局仪表盘 | 分组列表 | 按命格组大小排序的列表，点击展开组内成员 |
| 全局仪表盘 | 配对矩阵热力图 | 32 个配对的 XGBoost H+1 预测提升率热力图，命格组色块分组 |
| 命格详情弹窗 | 雷达图 | 选中命格组的五行向量雷达图 |
| 命格详情弹窗 | 成员卡片 | 组内股票列表，含名称和代码 |
| 波动对比面板 | 曲线图 | 选中两只股票的超额波动率时间序列叠加对比 |
| 波动对比面板 | 统计卡片 | 互相关 |r|、波动率均值、标准差等统计指标 |

## 4. 用户界面设计

### 4.1 设计风格

- **配色方案**：暗色背景 (#0f0f13) 为主，五行色彩为视觉锚点：
  - 木 = #4ade80（翠绿）
  - 火 = #f87171（赤红）
  - 土 = #fbbf24（琥珀）
  - 金 = #e2e8f0（月白）
  - 水 = #60a5fa（靛蓝）
- **字体**：标题使用「思源宋体」(Noto Serif SC) 营造东方韵味，数据使用等宽字体
- **布局风格**：卡片式仪表盘，三栏自适应网格，顶部全局过滤器
- **图表风格**：极简无网格线，发光勾边，微渐变填充

### 4.2 页面设计

| 页面/面板 | 模块名称 | UI 元素 |
|-----------|---------|---------|
| 全局仪表盘 | 顶部导航 | Logo + 标题 + 五行筛选按钮组 |
| 全局仪表盘 | 统计概览 | 4 张统计卡片：总股票数、命格组数、配对总数、XGBoost 均值 |
| 全局仪表盘 | 命格散点图 | Recharts 散点图，PCA 降维到 2D，五色编码 |
| 全局仪表盘 | 配对热力图 | 自定义矩阵热力图，颜色映射提升率，命格组边框分组 |
| 命格详情弹窗 | 雷达图 | Recharts RadarChart，五行五轴，面积填充 |
| 命格详情弹窗 | 成员列表 | 卡片列表，每张卡片显示股票名称和代码 |
| 波动对比面板 | 曲线图 | Recharts LineChart，双线对比，可缩放时间范围 |
| 波动对比面板 | 统计卡片组 | 互相关 |r|、均值、标准差等指标卡片 |

### 4.3 响应式适配

桌面优先设计。1920×1080 为基准分辨率。三栏在大屏(>1440px)展开，中屏(1024-1440px)两栏，小屏(<1024px)单栏堆叠。色觉无障碍适配：五行色搭配足够亮度对比，图表配合图例的文字标注。
