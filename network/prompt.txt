# 核心世界观

# 宇宙演化的基本节拍：离散帧
宇宙不是连续流动的，而是按“离散帧”的节拍演化。一个完整的帧包含五个不可分割的步骤：
1. 创生：在符合条件的局部拓扑区域，新节点被创建并建立连接。
2. 连接：新节点与已有节点建立边。
3. 变化体积：所有受影响节点的度数被重新计算，其体积（存在权重）相应变化。
4. 判断悬挂边：系统全局扫描，凡是一条边的移除不会破坏连通性、且导致其端点度数降为1的边，被标记为悬挂边。
5. 删除悬挂边：所有被标记的悬挂边被一次性删除。

关键规则：
- 一帧之内，没有“联级消解”。删除只会执行一次。
- 一帧结束时，必然会有新的悬挂边出现，因为删除操作本身改变了拓扑。
- 这些残留的悬挂边，是下一帧创生事件的直接动力。
- 宇宙永远处于“不完美”状态。正是这种永不消逝的不完美，驱动着宇宙的持续演化。
