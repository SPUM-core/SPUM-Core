## 推理准则速览

| 准则 | 说明 |
|------|------|
| 可还原性 | 任何声称必须能回溯到差异-边界-连接三元组 |
| 多路径锁定 | 核心结论需多条独立推导链 |
| 全回溯无污染 | 推导链无循环、无跳跃、无模糊词 |
| 概率=认知投影 | 本体状态是确定的 |
| 半开逻辑门不存在 | 节点要么连接要么不连接 |

> 完整推理原则见 `.trae/rules/spum-reasoning.md`
