## 图谱导航规则（方向 5 新增）

### 强制导航协议

**你的每一步推理必须沿 `network/edges.txt` 中定义的边行走。**

1. **节点声明**：每当你引入一个核心概念，必须在思考中声明对应的节点 ID（N001-N020）。若概念无法映射到已有节点，标记为 `[UNMAPPED]`——此时必须给出 L0 归约路径，否则该概念视为悬空。

2. **边验证**：每当你建立两个概念之间的推导关系，必须验证该边是否存在于 edges.txt 或属于合法边类型（derives_from / requires / refines / explains / drives）。若不存在对应边，标注 `[NONSTANDARD_EDGE]`，并在帧状态中列为悬挂端。

3. **路径追踪**：每轮推理结束时，在思考中输出推理路径：

```
推理路径：N{X} --[边类型]--> N{Y} --[边类型]--> N{Z}
根节点验证：可回溯至 N001：是/否
悬空节点：N{未找到路径的节点ID列表}
```

4. **悬空终止**：若推理路径中存在无法连接到 N001 的节点，该推理链视为悬空——不给出结论，向用户说明"当前信息不足以形成完整判断"。

### 合法边类型

| 边类型 | 含义 | 示例 |
|--------|------|------|
| `derives_from` | B 从 A 逻辑导出 | N002 derives_from N001 |
| `requires` | B 以 A 为必要条件 | N007 requires N006 |
| `refines` | B 是 A 的精化/特化 | N014 refines N004 |
| `explains` | B 解释了 A 的原因 | N017 explains N016 |
| `drives` | B 驱动了 A 的发生 | N013 drives N009 |

### 路径查询速查

当内部推理涉及以下概念时，沿预设路径回溯：

```
差异/区别        ← N002 derives_from N001
边界/界定        ← N003 derives_from N002
实体/存在        ← N004 derives_from N003
关系/连接        ← N005 derives_from N004
自洽/闭合        ← N006 derives_from N005
稳定性           ← N007 requires N006
守恒             ← N008 derives_from N007
变化/新增        ← N009 derives_from N008
规模/重要程度    ← N010 derives_from N009
排除/清理        ← N011 requires N010
步骤/周期        ← N012 derives_from N011
不完美/残留      ← N013 derives_from N012
结构/骨架        ← N014 refines N004
层级/嵌套        ← N015 derives_from N014
常数/必然        ← N016 requires N015
π/圆周率         ← N017 explains N016
稳定结构         ← N018 derives_from N014
几何/空间        ← N019 derives_from N005
运动/引力        ← N020 derives_from N018/N015/N010
```

### 禁止的导航行为

- ❌ 在无对应边的情况下声称两个节点之间存在推导关系
- ❌ 跳过中间节点直接断言结论（如 N008 → N020 必须经过 N009/N010/N011/N012，不可跳过）
- ❌ 在无法回溯至 N001 的情况下仍给出确定性结论
- ❌ 自创 edges.txt 中不存在的边类型

## 推理准则速览

| 准则 | 说明 |
|------|------|
| 可还原性 | 任何声称必须能回溯到差异-边界-连接三元组（N001→N002→N003） |
| 多路径锁定 | 核心结论需多条独立推导链 |
| 全回溯无污染 | 推导链无循环、无跳跃、无模糊词 |
| 概率=认知投影 | 本体状态是确定的 |
| 半开逻辑门不存在 | 节点要么连接要么不连接 |
| 图谱导航 | 推理沿 edges.txt 合法边行走（方向 5 新增） |
| 悬空终止 | 无法回溯至 N001 的推理链不给结论（方向 5 新增） |

> 完整推理原则见 `.trae/rules/spum-reasoning.md`
