## 六、复验纪律

1. **不一致即回归**：任一层 selftest 由「全部通过」变为失败，或本文件数值漂移，先定位再继续，**不得**改基线迁就代码。
2. **随机性口径**：所有读数在固定 `seed` 下**确定性可复现**；若出现漂移，先查是否引入了未固定的随机源或字典序依赖。
3. **`state_hash` 不含 `nid`**：GPU≡CPU 逐位一致须三者齐备（环序 dict + `nid` + 事件计数）。
4. **`--` 不等于 0**：`--` 表示「无结构」或「样本不足」，二者须分开读（见 L2 判决 3）。
5. **update 本文件**：只有**冻结**了新锚点（经压力测试的定理/读数）才更新对应表行，并同步注明 HEAD。
