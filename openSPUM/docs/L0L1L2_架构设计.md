| 帧末修复 | K8a/K8b 对偶性簿记 + 行级锁 | 无需修复：局部确定性排序 + 双边提交，天然顺序无关 |

# 第一部分 · L0：纯组合二维闭合单纯复形

## 1. 总体原则

1. **边优先**：节点由关系诱导，不由预设。不存节点列表——节点集是边集的诱导结果。
2. **无随机**：一帧输出是帧初状态的确定性函数。同一帧初态 → 同一帧末态。
3. **帧内并行**：所有协商同时发生，帧末统一提交。
4. **容量硬约束**：A2 排他占据 → 每个节点度数有上限。
5. **每条边恰好属于两个面**：这是 L0 最核心的组合规则，几何是它的投影。
6. **GPU 执行，CPU 解析**：GPU 做并行确定性协商，CPU 做投影、审计、可视化。

## 2. 本体结构

### 2.1 三层对象

L0 不是普通图，是**二维闭合单纯复形**。三个基本对象：

| 对象 | 定义 | 约束 |
|------|------|------|
| 节点 | 关系确认的端点 | `deg ≥ 1`，`deg ≤ cap` |
| 边 | 两个节点的相切关系（排他性确认事件） | 恰好属于两个面 |
| 面 | 三个两两相连的节点 | 恰好三条边 |

依赖方向是：**节点由边诱导，边由面约束，面由闭合约束**。

### 2.2 核心不变量

- **边-面规则**：每条边恰好属于两个面。
- **容量约束**：每个节点 `deg ≤ cap`。
- **闭合约束**：没有边界边，没有边界顶点。
- **存在判据**：`deg = 0` 即不存在。

> 边-面规则同时承担了两个职责，因此取代了 v1.x 里两条独立约束：一是**不可入性/无交叉**（两条边不会穿过彼此——交叉在组合上等价于 χ 下降或出现领结），二是**全局闭合**（没有裸露的边界边）。

### 2.3 状态表示

**抽象层**，一帧的状态：

- 边集 `E_t`
- 面集 `F_t`
- 节点度数 `deg_t(v)`
- 节点容量 `cap(v)`
- 局部方向场（VSPT 方向，可选）

**实现层**：用**旋转系统**承载全部组合信息——每个节点存一张**环序邻居表** `rot[v] = [w_0, w_1, …]`（逆时针序），纯整数，无几何、无浮点：

```python
rot[v]           # v 的环序邻居表（绕 v 一圈的邻居顺序）
succ(v, a)       # a 在 v 环序中的后继
pred(v, a)       # a 在 v 环序中的前驱
E = Σ_v len(rot[v]) / 2      # 边数
```

不存节点列表：`rot` 的键即活跃节点集，`deg(v) = len(rot[v])`，`deg = 0` 的键不存在（= 不存在）。

**面由旋转系统导出**（dart 环）：`dart = (v, w)`，`dart_next(v,w) = (w, succ(w, v))`。从任一 dart 出发反复取 `dart_next` 回到自身，得到一个 dart 环 = 一个面。于是「每条边恰好属于两个面」在实现上等价于：**每个无向边 {v,w} 恰好被两个 dart 环使用**（`(v,w)` 与 `(w,v)` 各在一个环里）。

### 2.4 三个保 χ 的组合操作 + 一个删除操作

L0 的全部演化归结为四个纯组合操作（全部是整数下标插入/删除，几何无关）。它们共享一个不变量：**`χ = V − E + F` 保持不变**（闭合球面 `χ = 2`，`genus = 0`）。

| 操作 | 触发条件 | ΔV | ΔE | ΔF | Δχ | 诞生度数 | 语义 |
|------|----------|----|----|----|----|----------|------|
| `cone_tri_face(i,j,k)`（A 类：面锥化） | (i,j,k) 是**真三角面** | +1 | +3 | +2 | 0 | 3 | 在空面上锥化新节点，闭合三角剖分生长 |
| `cone_hole(vs)`（B 类：洞锥化） | `vs` 是 k≥4 的洞环 | +1 | +k | +(k−1) | 0 | k | 在洞口锥化，闭合开口 |
| `cone_edge(i,j)`（边锥化） | {i,j} 在某面内，两端 `deg ≥ 2` | +1 | +2 | +1 | 0 | 2 | 边界生长，洞的边被折线替换 |
| `remove_vertex(v)`（V⁻） | 主动或修剪 | −1 | −d | −(d−1) | 0 | — | 删节点及其 d 条边，其 d 个面并成一个 d 边形 |

> **几何意义仅是事后注记**：A 类诞生的 deg-3 节点对应"三球互切的洞位"；B 类 deg-k 对应"k 边形开口收拢"；边锥化的 deg-2 节点是边界节点。操作本身只看环序，不看角度。

**可锥化的最小充分判据（本 L0 的核心判据）**：

```
三角 (i,j,k) 可安全锥化  ⟺  succ_j(i)==k  且  succ_k(j)==i  且  succ_i(k)==j
```

三处局部后继检查同时成立 ⟺ `dart(i→j)` 所在面恰为 `(i→j)→(j→k)→(k→i)`。**每个节点只查自己的环序**，纯局部整数比较。

判据只成立一部分 ⟹ 该 3-团是**分离三角**（separating triangle，两侧都已被占满）。在分离三角上锥化 = 往已占满的位置塞节点 = **制造交叉**（χ 下降 / 出现领结）。这正是 v1.x 引擎 K2 的缺陷（见 §4.4 与附录 A §A.5）。

## 3. 协商引擎

### 3.1 候选从哪来

L0 无坐标，候选只能来自**拓扑邻域**。确定性展开：

- **共享邻居对**：两节点有共同邻居（3-团）→ 候选。在纯组合实现里即**真三角面**。
- **二阶邻居**：邻居的邻居，去掉已有边。
- **缺口候选**：局部闭合子图的缺口两端（k≥4 的洞环）。
- **方向候选**：VSPT 方向指向的邻域节点。
- **σ 梯度候选**：局部 σ 梯度方向上的节点。

每个节点并行展开自己的候选集。候选规模由局部结构决定（`deg` 由容量约束，通常 ≤ 12），不爆炸。

### 3.2 候选类型

不是所有候选都是"加边"。候选分三类，**同时提出、同时竞争**：

| 类型 | 动作 | 条件 |
|------|------|------|
| 创生 | 加边 | 两端容量未满，且不违反边-面规则（在真面/洞上锥化） |
| 湮灭 | 删边 | 边处于净湮灭区，或悬挂边 |
| 重连 | 删一条加一条 | 保持总边数守恒 |

### 3.3 优先级

每条候选需要一个确定性优先级 `p(e)`。要求：

- **对称**：`p(u,v) = p(v,u)`
- **局部**：只依赖两端局部状态
- **确定**：同一局部状态 → 同一优先级
- **可比较**：任意两条竞争同一节点的候选可比较

优先级来源（示例，实现时任选组合）：

- 两端剩余容量之和（`(cap(u)−deg(u)) + (cap(v)−deg(v))`）
- 局部 σ 的确定性组合
- VSPT 方向兼容度
- 共享邻居数
- 缺口大小（洞环长度）

**平局规则必须确定**：局部拓扑哈希、字典序、或"两者都不接受"。

### 3.4 冲突消解（局部完成）

每个节点在本地：

1. 收集所有指向自己的候选；
2. 按优先级确定性排序；
3. 取前 `cap(v) − deg(v)` 个；
4. 其余拒绝或延迟。

关键：**决策在局部完成，不依赖全局顺序。**

### 3.5 双边提交

一条候选成立，当且仅当**两端都接受**：

- 交集操作，确定、并行、顺序无关。
- 没有原子竞争，没有到达顺序依赖。

> 这是 v2.0 相对 v1.x 的关键简化：不再需要行级自旋锁（附录 A §A.6）与帧末 K8a/K8b 对偶修复——因为"谁先写入"被结构性地消掉了：每个节点先在本地把自己的接受集算完，双边提交只做集合交。

## 4. 帧执行

### 4.1 五步帧循环

```
创生 → 连接 → 变化体积 → 判断 → 删除
```

在 L0 里，"变化体积"只更新度数，不涉及几何。

### 4.2 帧屏障与双缓冲

- 帧内：所有候选生成、优先级计算、局部消解、双边提交**同时发生**。
- 帧末：**全局屏障**，统一写入下一帧状态。
- **双缓冲**：读 `E_t`，写 `E_{t+1}`。

### 4.3 悬挂修剪

帧末：

1. 每条边并行检查两端度数是否为 1；
2. 标记所有悬挂边；
3. 并行删除；
4. 并行更新度数；
5. 度数归零的节点同步删除。

**一帧只删一次，不级联。** 删除产生的新悬挂是下一帧的输入（不完美定理的实现）。

> 删除阈值：公理下限是 `deg < 2`；三维三角剖分闭合下限是 3（四面体顶点度）。纯组合原型 `dmin` 默认 3，可传 2 以观察 deg-2 边界节点的存活。

### 4.4 边-面一致性检查

帧末同时检查：

- 每条边是否恰好属于两个面；
- 每个面是否恰好三条边；
- 是否有边界边或边界顶点。

违反的边/面标记为**"待修复"**，下一帧优先处理。

实现层的四个判据（全部局部整数检查）：

| 判据 | 内容 | 违规含义 |
|------|------|----------|
| C2 | 每个节点的 `link`（邻居的诱导子图）是路径或环 | 否则非流形（交叉/领结） |
| C3 | 无领结：任意两面最多共享一条边 | 重叠/交叉 |
| χ 守恒 | `χ = V − E + F`（闭合分量应为 2） | 下降即出现把手（= 交叉） |
| 容量界 | `E ≤ 3V − 6` | 平面图必要条件，越界即非平面 |

`audit()` 还把每个节点的 `link` 细分为四类用于诊断：

- `cycle` = 干净内部节点（诱导子图恰为一个环）
- `path` = 边界节点（诱导子图为未被弦闭合的路径）
- `chord` = `link` 内部有余弦 ⟹ 该节点处存在分离三角（面已被两侧占满）
- `disc` = `link` 诱导子图不连通 ⟹ 真正的非流形（领结/交叉）

## 5. GPU 映射

### 5.1 数据布局（边中心）

GPU 上以**边为中心**：

- **边数组**：每条边存两个端点。
- **端点数组**：每个节点存入射边列表的偏移和长度。
- **面数组**：每个面存三条边。
- **度数数组**：每个节点当前度数。
- **容量数组**：每个节点容量。

节点不单独存，由边数组诱导。旋转系统以"每节点环序表"实现时，用 CSR 风格布局：`rot_ptr[v]`（偏移）+ `rot_idx[]`（环序邻居），与端点数组同构。

### 5.2 并行原语

| 步骤 | GPU 原语 |
|------|----------|
| 候选生成 | 并行遍历边/节点，展开邻域 |
| 优先级计算 | 每条候选一个线程 |
| 局部排序 | 每个节点一个线程块 |
| 双边提交 | 每条候选一个线程，检查两端接受集 |
| 悬挂标记 | 每条边一个线程 |
| 并行删除 | 并行压缩 |
| 度数更新 | 原子加/减，只写不决策 |

### 5.3 原子操作原则

> **决策在局部确定性完成，原子操作只负责写入。**

- 错误用法：用原子 CAS 抢容量，谁先抢到谁成立（= 让硬件顺序进入 L0）。
- 正确用法：节点本地决定接受哪些边后，才原子性写入。

### 5.4 双缓冲

- 读缓冲：`E_t`、`deg_t`、`F_t`。
- 写缓冲：`E_{t+1}`、`deg_{t+1}`、`F_{t+1}`。
- 帧内不读写同一份状态。

## 6. 审计与投影

### 6.1 L0 审计

每帧后自动运行（**只读，不参与规则**）：

- 握手引理：`Σ deg = 2|E|`。
- 边-面规则：每条边恰好两个面。
- 面-边规则：每个面恰好三条边。
- 容量约束：所有 `deg ≤ cap`。
- 存在判据：无 `deg = 0` 节点。

### 6.2 计数链审计

以下数字**在显式声明的预设下**从图中数出来——**不是"不预设"**：

- **预设**（L0 公理 / 操作假设，**不是数出来的**）：`χ=2`（闭合）、**无洞**（真三角剖分）、边-面规则、均匀饱和（全 `deg=C`）。
- **读数**（对预设对象执行计数操作得到）：

| 数 | 含义 |
|----|------|
| 12 | 闭合饱和解节点数（`Σ(6−deg)=12` 且全 `deg=5`）——正二十面体 |
| 30 | 边数 |
| 20 | 面数 |
| 42 | 互斥截断 |
| 50 | 组合容量（`E + F`） |
| 62 | 位置总数（`V + E + F = 12 + 30 + 20`） |

### 6.3 L1 投影（可选，不参与 L0 规则）

**从 id + 邻接生成网络，不做全局嵌入求解**（分岔 N4 排除「把全局嵌入求解作为投影手段」，见 §7；该判决的局部判据经分岔 N7 修订——不可嵌入性的证据是刚性计数 + 求解器不可靠 + 范式选择，**不是** `A_v ≤ 2π`）：

- **网络骨架**：节点 = id，边 = 「谁连着谁」。旋转系统直接给出，**不需要任何坐标**——只要知道谁连着谁，投影层就能形成网络。
- **局部方向场**：由旋转系统重建。每点半径 `r(deg) = (κ/2)·√(deg/π)`（A2 面积预算下限，§A.13.1），其 `deg` 个邻接方向**按环序**铺在该点自身球面上（各点各自一套局部标架，点间无需对齐）。方向铺法取**环序闭合纬线环** `ring_sphere`（`z₀ = −1/√n`、`φᵢ = 2πi/n` 按索引闭合，与 `rot[v]` 的循环环序天然匹配）——分岔 N6 采纳；`fibonacci_sphere`（螺旋首尾不闭合）保留作对照。
- **局部量**：`σ_v = 2/deg_v`；`∇σ_v = mean_{w~v}(σ_w) − σ_v`；几何角亏 `2π − A_v`，其中 `A_v` = v 周围三角形的内角之和（三角形内角由余弦定理从三点的 `deg` 得出，纯局部 `O(F)`）。⚠️ `A_v > 2π` 是**负曲率（鞍点）读数**，**不是**嵌入可行性判据（分岔 N7 修订）。
- **识别 12 晶子闭环、42 团簇**（纯组合判据，见 §7.3 判决 ③）。
- **L2 全局坐标**（可视化）只是**投影工件**：对齐传播 + 位置约束投影的产物，明确不主张为"真实几何"（见 §6.4）。

> **实现**：`src/l1/l1_projection.py`（`project()` / `angle_defect()` / `local_frame()` / `grad_sigma()` / `crystallites()`；`python l1_projection.py selftest=1` 全绿）。落地读数见 §7「阶段四首项落地」。

### 6.4 L2 全局投影（工件层，永不回写 L0）

**把 L1 的局部量沿环序拼成一个可看的全局工件，并读出全局量**。L2 只读 `net`，不参与 L0 规则；坐标为**投影工件**，明确不主张为「真实几何」（分岔 N5 已排除全局刚性相切嵌入求解，理由见 §7 分岔 N5/N7）。

- **① 全局坐标**：`aligned_tree` —— 沿 BFS 生成树做**平行移动积分**（`g = M_i·dir_i(w)` ⇒ `p_w = p_i + (r_i + r_w)·g` ⇒ `M_w = R(dir_w(i) → −g)`）：树边精确满足相切目标长、`O(E)`、无迭代、确定性；`relax` 再做**位置约束投影**（Gauss-Seidel：边等距约束各移一半 + 非边排斥 + 每轮质心归零）把工件压实。
- **② 全局 σ 场**：`σ_global = V/E`；局部 `σ_v = 2/deg_v`、`∇σ_v`；**引力代理 = σ 局部极值** `anchors`（`∇σ_v < 0` 汇 / `> 0` 源；等度图两者皆空）。
- **③ 红移**：`redshift_proxy` —— 沿 BFS 最短路累积 σ 的相对变化 `z_v += (σ_w − σ_i)/σ_i`（**代理读数**，非物理预言；等度图 `z ≡ 0`）。
- **④ 可视化导出**：`export_obj`（Wavefront `v`/`l`）、`export_json`（节点带 `pos`/`r`/`σ`/`∇σ`/`defect`/`redshift` + 边 + 锚点）。
- **⑤ 径向幂次谱（引力幂次检验，阶段六第③项）**：`radial_bins`（以质心或指定中心做 σ 径向分箱，`r` 取箱内实际距离均值）→ `gravity_spectrum`（**四路幂次拟合** `σ(r)` / `ΔN(r)=∫_r^∞[σ−σ₀]dr'` / `∇σ(r)` / `∇ΔN(r)`，log-log 最小二乘 + **容差带 ±0.35** 判决 `newton`/`trap`/`neither`），纯数值件 `power_fit`（只收 `r>0 ∧ y>0`）/ `radial_derivative`（中心差分）/ `hop_integral`（跳数积分）。**读数口径**：`slope∇ΔN = a 的幂次`（−2 ⇒ newton = 权威口径 `引力.md` 引理 3 + 推论 3a；−3 ⇒ trap = 已废弃路径，仅作对照）。**退化守卫**：σ 剖面极差 `< 1e-9·max(1,|σ₀|)`（等度图）⇒ 四路一律 `slope=None`、`label="undefined"`——否则 1e-16 浮点噪声被**非均匀箱距**放大成伪幂次（实测 ∇σ 路曾出伪斜率 −0.75）。**可证伪性由两条独立控制证明**：`synthetic_calibration`（注入 `σ∝r⁻²` / `σ∝r⁻³`，四路须复原）+ `null_control`（等度图 icosa t=0 须全路无信号）。⚠️ 本项只在**采纳轨迹上如实读取**，明确**不外推物理结论**（L2 是投影工件，非真实几何）。
- **⑥ 有限窗口算子（兑现分岔 N1-C，阶段六第④项）**：`window_ball`（跳数球窗，自 `center` BFS 至 `radius`）/ `window_prefix`（规模窗，BFS 序取前 `V_window`）+ 子图构造 `_subnet`（`rot` **保序截断**，不重排、不 prune）。**只读**：窗口是 L0 图的一个子图视图，截断不改 `net`。**读数与判词**：`window_readouts`（`σ_window = V/E`、`deg_mean = 2E/V`、`n_boundary`/`frac_boundary`、`n_comp`、`anchor_density`、径向谱）+ `window_stability`（跨 `sizes` 扫描，判词**只看 `σ_window` 末级相对残差** `rel_last = |σ_last−σ_prev|/σ_last ≤ tol_rel`，`slope_σ`/`anchor_density` **只作旁证**）。⚠️ 两条实测校准：(a) `slope_σ` 在窗口上**多级为 `None`**（退化守卫），`anchor_density` 在等度球窗上为 **1.0**（等度子图因边界长出锚点——`anchors` 只认局部极值）⇒ 二者不能进判词，否则判词**恒 `undefined`**；(b) `V_window ≥ V` 时 `window_prefix` 截断到全图 ⇒ 多级读数相同 ⇒ **伪 0 残差**，故按**实际** `v_window` 去重并计 `n_truncated`。另配 `radial_window`（按 `r>0 ∧ 箱内样本数 ≥ min_bin_pts` 自动选拟合窗口）——**第③项遗留 (i) 的裁决由此给出**：`fit_slice` 只保留给 `synthetic_calibration`（合成标定口径），采纳轨迹一律走 `radial_window`。
- **失真读数（不是误差）**：`holonomy`（非树边闭合差 = 曲率无法被平面容纳的度量）、边残差、非边重叠对数。⚠️ 三者都只是**上界**——PBD 只降到最近的局部极小（分岔 N7）。

### 6.6 L4 演化观察层（跨帧事件分区，永不回写 L0）

> **本节本轮新立**：§7 构建路线「阶段五：演化观察」此前只有四个观察项、无实现规约。立规约依据与读数见 §7「阶段五落地」。

**L1/L2 投影「一帧之内」、L3 投影「帧与帧之间」、L4 观察「事件落在哪个区域」。** L4 只读 L0 的帧序列，**不参与 L0 规则、不回写任何状态**；各组读数全部坐标无关（只吃 id + 环序，**不依赖 L2 坐标**）。分区是**纯组合**的度数三分区：

```
over : deg > κ（过密 / 负曲率端）    flat : deg == κ    under : deg < κ（稀疏 / 正曲率端）
zone : 全 over → "core"；含 ≥1 个 over → "sh"（核的边界）；其余（含空表）→ "bg"
```

- **① 分区事件账** `event_account` / `annihilation_profile`：把 V⁺ 与 V⁻ **按事件位点**分到 core/sh/bg，给出逐分区净 ΔE 与净湮灭率 `rho = (ΣV⁻ − ΣV⁺)/(ΣV⁻ + ΣV⁺)`（`>0` 净湮灭 / `<0` 净创生）。位点定义：创生位点 = 新元胞的三个角；断边位点 = 断边两端（两端须在帧末仍存活）；标签一律取**帧初**快照。另给两个单列读数：`n_follow`（随删点消失的边）与 `viol_sat`（创生位点中「任一角的帧初度数 ≥ cap」的个数，**期望恒 0** —— 创生抑制的闸门读数）。
- **② 集中现象** `concentration_series`：`max_deg` / `n_sat` / `n_over` / `n_flat` / `n_under` / `gini` / `σ` 方差。
- **③ 不完美定理** `imperfection_series`（**边缘臂双口径**，阶段五第④项落地）：`n_under_end`（帧末残留悬挂端）、**残留臂密度** `delta_dmin = n_under_end / V`、**泛化臂密度** `delta_kappa = |{deg<κ}|/V`（与 L3 / GT-005 同口径）、`n_pruned`、`n_broken`、L0-A9（同帧断边+删点）。**中心臂 Δμ 不在本层**（见 L3 `anchor_drift`）——本层只供数，判阈值交给 L3 `closure_series`。
- **④ 入口与导出** `observe(core, nframes)` + `export_csv` / `export_json`。
- **⑤ 结构闭合审计** `closure_of` / `closure_series`（**阶段五第③项「闭合子图内部与外部」的落地**）：逐帧给出 `n_comp`（连通分量数）/ `comp_sizes` / `chi`（各分量 χ = V_c − E_c + F_c，面归其首顶点所在分量）/ `boundary_edges`（只被 < 2 个面包含的边；**闭曲面 → 0**）/ `sum6deg`（Σ(6−deg)）/ `holes`（d = 3V − 6 − E，V=0 → 0）/ `crystallites`（5-正则分量顶点数，`find_crystallites` 口径）。

⚠️ **阶段五第③项判决（探针取证 + 实测，icosa 与 patch 两种子）**：采纳轨迹上**每一帧都是单一连通闭曲面**——`n_comp ≡ 1`、`boundary_edges ≡ 0`、`χ ≡ 2`。⇒ **「闭合子图内部 vs 外部」在分量层面退化**：不存在分量级的内外之分（不是「本轮没测到」，是结构上不可能）。其非平凡内容即 ① 的 `core`/`bg` 分区——**过密核 `core` = 局部闭合内部、背景 `bg` = 外部**；故第③项**归并**到 ①，不另立一套「内外」判据。可冻结的恒等式：闭合连通（χ=2）帧上 `Σ(6−deg) = 12 + 2·d`，**该式只对 χ=2 成立**（一般式仍为握手引理 `Σ(6−deg) = 6V − 2E`；空图与多分量图不适用）。实测：icosa t=10 `Σ(6−deg)=446 = 12+2×217`；χ=2 恒等式 11 帧逐帧成立。

⚠️ **两条口径（本轮实测确立，专防两个「把恒等式当观测量」的陷阱）**：

1. **V⁺ 必须按「位点」分区，不能按「边端点」分区。** 一次锥化总是「在一张面的三个角上长出**一个全新元胞**」⇒ 按边端点分区时，每条新边必有一端是帧初不存在的新点（必落 `under`）⇒ `V⁺core ≡ 0` 将成为**定义强制的假象**（实测：按边端点分区 10 帧全为 0；按位点分区在 cap=64 轨迹 t≥7 即出现 `96/8/160/788`）。
2. **V⁻ 的分区分布是规则强制的，V⁺ 的分区分布才是经验读数。** `vminus="dense"` 的判据是「**两端皆 over**」⇒ 按构造 `V⁻sh ≡ V⁻bg ≡ 0`、`V⁻core` 即全部断边 ⇒ `rho_bg = −1.000` 是**恒等式**，不是发现。可检验的是 **V⁺ 的分区分布**（锥化落在「全过密角的面」/「含过密角的面」/「背景面」）与由它决定的核心净符号：`净core = V⁺core − V⁻core`。故**核心净湮灭不是恒等式**——cap=12 得 `rho_core = +1.0000`（纯净湮灭），cap=64 被削弱到 `+0.9284`。

> **实现**：`src/l4/l4_evolution.py`（`observe()` / `event_account()` / `annihilation_profile()` / `concentration_series()` / `imperfection_series()` / `closure_of()` / `closure_series()` / `zone()` / `partition()`；`python l4_evolution.py selftest=1` 全绿，夹具 A–G）。落地读数见 §7「阶段五首项落地」/「阶段五第③项落地」/「阶段五第④项落地」。

### 7.3 重连动力学读数：势函数 Φ 探针（2026-09-13 冻结）

**为什么动作集只能是「边翻转」。** §3.2 把重连定义为「删一条加一条，保持总边数守恒」。在**固定 V、保 χ、且始终保持三角剖分**的条件下，满足该定义的动作**唯一地就是边翻转（2-2 Pachner 移动）**：给边 {i,j}，删它、加对边 {k,l}（k = `succ_j(i)`、l = `succ_i(j)`）。实现见 `combinatorial_proto.py` 的 `flip_delta` / `flip_edge`；它是**对合**（翻两次逐位复原），且 ΔV = ΔE = ΔF = Δχ = 0。

## A.1 本体论映射：CUDA 线程 = 粒子的局部视角

SPUM 第一公理：关系是唯一本原，粒子是关系凝固的痕迹。映射到计算架构：

| SPUM 本体 | 计算实现 |
|-----------|---------|
| 粒子（κ-particle） | 一个 CUDA 线程管理的局部状态 |
| 边（排他性确认事件） | 双方邻接槽位中的互指条目（i 的槽位存 j，j 的行存 i） |
| 空间（关系凝固的痕迹） | 粒子的 pos/radius —— 是连接拓扑的投影，不是容器 |
| 相切（边的几何表达） | tangent 角坐标 (θ,φ)：邻居在本粒子球面上的方向 |
| 创生 V⁺ | 缝隙被新粒子占据：3 条边同时建立 |
| 湮灭 V⁻ | 边的双方槽位同时清除 |
| 悬挂（deg<3） | 粒子局部可判定：数自己的槽位 |
| 离散帧 τ | L1 同步点：一轮 kernel 序列的边界 |

**核心约束：任何 kernel 不允许做全局遍历。** 每个线程只读：

- 自己的状态（pos, radius, degree, active）
- 自己邻居的状态（通过邻接槽位索引）
- 二度邻居（邻居的邻居，用于相切发现）

O(N²) 全局距离矩阵只允许存在于 **L1 的初始化/诊断路径**，永远不在帧循环内。

## A.2 数据布局：SoA + 固定槽位邻接表

GPU 友好的 Structure-of-Arrays。全部数据在设备内存，粒子 i 的全部信息由索引 i 定位。

```
pos[N]         float3   位置（L1 投影坐标，由 tangent 表重构）
radius[N]      float    半径（由 degree 决定）
degree[N]      int      当前连接数 = nb_count 的冗余缓存
active[N]      bool     活性（false = 潜在池）

nb_idx[N×S]    int      邻接槽位：第 i 行存 i 的邻居索引，-1 = 空槽
nb_dir[N×S]    float2   邻居在 i 球面上的方向 (θ, φ)
nb_count[N]    int      已占槽位数
```

**槽位数 S = 64 是内存分配上界，不是逻辑度数上限。**

区别至关重要：

- v1：`if degree >= 42: 拒绝连接` —— 42 是魔数硬顶（错误）
- v1.x：逻辑上限由立体角几何**涌现**（见 §A.3）；S=64 只是显存预算。若某粒子几何上真能容纳 65 个邻居（极端尺寸悬殊），那是 S 不够大，调 S 即可——**约束在几何里，不在常数里**。

为什么 64：等大球接吻数 12；尺寸悬殊时一个 40° 自由角可容纳 r≈1.85 的球，理论度数上界由最小粒子尺寸决定。64 覆盖所有物理合理场景且是 2 的幂（对齐）。

## A.3 排他性 = 球面角坐标下的不可入性

这是 v1.x 的核心定理，把两条独立约束统一为一条。

### A.3.1 角半径

粒子 j（半径 r_j）与粒子 i（半径 r_i）相切。j 占据 i 球面上的一个圆顶区域，其**角半径**：

```
α_j = asin( r_j / (r_i + r_j) )
```

从 i 中心看，j 遮挡的天空立体角 Ω_j = 2π(1 − cos α_j)。等大相切球（r_j = r_i）：α = 30°，Ω ≈ 0.842 sr。

### A.3.2 排他性定理

> **j 与 k 互不穿透（不可入性）⟺ 在 i 的球面上，角距(j,k) ≥ α_j + α_k**

证明：j 与 k 的中心距 ≥ r_j + r_k，由余弦定理（i−j−k 三角形）直接给出角距下界。反之，角距 ≥ α_j + α_k 时两圆顶不相交，球体可共存。

**结论：不可入性不需要三维距离计算。** 每个粒子在自己的球面角坐标系内，用纯角度比较即可完成排他性检查。这是 O(deg²) 局部操作，且只在角度域运算——不需要访问其他粒子的 pos。

### A.3.3 连接接受判据（替代度数硬顶）

粒子 i 考虑接受新邻居 k（候选方向 d_k，半径 r_k）：

```
对 i 的每个已占槽位邻居 j:
    若 angular_distance(d_k, dir_j) < α_j + α_k − ε:  拒绝
全部通过: 接受，写入空槽位
```

**度数上限的涌现**：当球面被邻居的圆顶覆盖到剩余缝隙都小于最小可容角半径时，任何候选都会被拒绝——饱和自然发生。没有任何 `if degree >= 常数`。

### A.3.4 定量验证：12 的涌现路径

邻居布局取球面三角剖分（每加一邻居分割一个缝隙），则 n 个邻居时缝隙数（面数）：`F = 2n − 4`（欧拉公式）。

> 暂定前提：本节的 r≡1 是**占位**——具体半径律 r=f(deg) 尚未推导，仅知"度数越大半径越大"（单调递增）。见 §A.12.2。

缝隙可容新球半径取笛卡尔精确解——新球与中心 i（半径 R）及三个等大邻居（半径 r_n）同时相切，面中心角距 θ：

```
r_max = R·(R+r_n)·(1 − cosθ) / ( (R+r_n)·cosθ − R + r_n )
等大球 R = r_n = 1 时:  r_max = 2(1 − cosθ) / (2cosθ)
```

| n（度数） | 构型 | 缝隙数 2n−4 | 面中心角距 θ | 可容新球 r_max | 判定（r_min = 0.415） |
|---|---|---|---|---|---|
| 4 | 四面体 | 4 | 70.53° | 2.00 | 全部可生长 |
| 6 | 八面体 | 8 | 54.74° | 0.73 | 全部可生长 |
| 12 | 二十面体 | 20 | 37.38° | 0.258 | **r_max < r_min → 全部不可容 → 饱和** |

**12 不是预设参数**：它是"等大球 + 最小创生体积"两个约束的交点。r_min 由创生规则中的缝隙体积阈值决定——只要 r_min > 0.258，12 度就是自然饱和点。代码里不出现任何 `12` 作为度数判据。

> 注：二十面体缝隙仍可容 r ≤ 0.258 的小球，所以严格饱和需要 r_min 约束。r_min = 0.415 对应 v1 的 MIN_GAP_V ≈ 0.3 球——语义：创生有最小体积成本，小于此体积的缝隙不活化。

## A.4 端口模型与创生

### A.4.1 端口 = 缝隙

粒子的"端口"不是预设的槽位编号，而是**球面上未被邻居圆顶覆盖的缝隙区域**。每个缝隙由其边界的三个邻居定义（球面三角剖分的一个面）。

> **每增加一个邻居，缝隙数 +2（不是 +3）**：新邻居落在某缝隙内，与三个边界邻居建立相邻弧。V+1, E+3，由欧拉公式 F += 2。
> 总自由面积单调减少，可用端口（能容纳 ≥ r_min 新球的缝隙）最终归零——这就是饱和。

### A.4.2 两类缝隙

**A 类（边缝隙，主生长通道）**：粒子 i 的一对邻居 (j,k) 相切（角距 ≈ α_j+α_k）→ 三球 i,j,k 互切 → jk 大圆两侧各存在一个对偶洞位（笛卡尔定理）。新球与 i,j,k 三球相切，**deg=3 诞生**。检测 = 枚举邻居对，O(deg²)。

- 洞位方向解析解：v_new = x·v_j + y·v_k + z·(v_j×v_k)/|v_j×v_k|，z = ±√(1−|xv_j+yv_k|²)（± 即两侧对偶）。
- 等大球链（r_new = r_i）：z 的偏转角 Δ = 54.74°（正四面体对偶位）。
- 排他性检查天然分辨"洞位是否已被占据"：已有第 4 球占据的一侧被拒，空侧通过。

**B 类（面洞）**：粒子 i 的邻居三元组 (j,k,l) 两两互切 → 中心洞。但由 §A.3.4：四面体洞 r_max=0.225、二十面体洞 0.258，均 < r_min=0.415 → **B 类在等大球构型下恒不活化**。

> 设计教训：纯 B 类实现会导致 deg=3 团簇零生长（deg=3 只有 C(3,3)=1 个三元组面，即中心洞，恒不可容）——表面生长全部来自 A 类。

**与 v1 的本质区别**：v1 扫全部活性粒子三元组（O(N³)）；v1.x 每个粒子只查自己的邻居对（O(deg²)）。

### A.4.3 创生即连接

新粒子从 A 类缝隙诞生时**天然与 i, j, k 三球相切**。创生事件自带 3 条边——不需要事后再扫相切。

> 去重：同一缝隙被 i, j, k 三方各自报告，且每方报 ± 两侧。L1 按排序三元组分组后，组内按 pos 聚类（两侧对偶 = 两个独立缝隙位），每簇创生一个。

二度邻居相切作为补充 V⁺ 来源：i 遍历邻居的邻居，发现未连接但距离 ≤ (r_i+r_k)(1+tol) 且通过排他性检查 → 发出连接请求。

## A.5 帧协议：kernel 序列与 L1 同步点

一帧 = 以下 kernel 序列。每个 kernel 内部完全并行，kernel 之间是 L1 同步点（设备全局屏障）。

```
K1 update_volume      每粒子: degree → radius（局部公式，无通信）
K2 detect_gaps        每粒子: 枚举邻居对 (j,k) 的 A 类缝隙 → 创生请求队列（atomicAdd）
--- L1 同步: 创生请求去重（排序三元组分组 + 组内 pos 聚类，± 对偶洞位各成一簇）---
K3 spawn              每请求: 写入新粒子 pos/radius，建立 3 条边（双方槽位互写，排他性终审）
K4 connect_existing   每粒子: 二度邻居相切检查 + 排他性初筛 → 连接请求
--- L1 同步: 连接请求去重（(i<j) 二元组键）---
K5 commit_edges       每请求: 双方排他性终审 → 双方槽位互写
K5b impenetrability   每粒子: 检查邻居对角距 < α_j+α_k → 沿大圆弧微调 nb_dir（球面滑动）
K6 mark_dangling      每粒子: nb_count < 3 → 标记
K7 purge              每标记粒子: 清除全部槽位；每未标记粒子: 清除指向已删除邻居的槽位
K8a check_mutuality   每粒子: 只读检查逐槽对偶性（j 失活 / j 的行不含 i）→ 保留掩码
K8b compact_mask      每粒子: 按掩码独占压缩己行，尾部槽位全部置 EMPTY
```

**帧语义约束**：

- 一帧内 K6/K7 只执行一次（无级联消解）。删除产生的新悬挂是下一帧 K6 的输入——不完美定理的实现。
- K5b 的滑动只改 nb_dir 角坐标，不改 pos。pos 的全局重构（tangent → 笛卡尔）是 L1 投影层的事（BFS 重构，见 §A.8）。
- **K8 是对偶性簿记，不是帧内逻辑**：帧内并发写边可能留下两类残迹——(a) 指向失活粒子的槽位；(b) 单向边。帧内不做跨行清除，统一由 K8 修复（K8a 全行只读产掩码，K8b 只写己行）。
- **对照纯组合 L0**：K2 的"j,k 互邻即缝隙"判据不含定向，会把**分离三角**也当缝隙锥化 → 交叉缺陷。纯组合 L0 用 `tri_is_face` 三处后继检查修正（见 §2.4）。

## A.6 边一致性：V⁺ 的双方确认

边是双方的，单边写入是悬挂边的内存等价物。规则：

1. **创生边（K3）**：3 条边由请求处理线程一次性写入双方槽位。新粒子槽位是全新的；三方已有粒子的槽位需原子占槽（`atomicCAS`）。任一方槽位满/排他性冲突 → 整个创生请求回滚（新粒子失活）。回滚不清除对方已写槽位——残留条目由帧末 K8 统一清扫。
2. **连接边（K5）**：请求带 (i,j) 排序键，L1 去重后由单线程写双方。写入前双方各自重新做排他性检查。第二侧写失败不做帧内清理，残留半边由 K8 修复。
3. **删除边（K7）**：被删粒子的全部边由其邻居各自清除指向它的槽位。
4. **修复边（K8）**：帧末统一簿记。所有"条目移除"只发生在 K7 与 K8b，二者都是独占己行的单线程操作，不存在跨行写竞态。

排他性检查在两个时刻执行：请求发出时（初筛）+ 写入时（终审）。终审为准。

> 竞态处理（v1.x 定稿）：K3 多线程并发时，线程 A 对 g 的排他性终审可能读到 g 邻接行的中间状态，偶发导致回滚或半边写入。所有此类残迹由 K8a/K8b 在帧末确定性修复。若实验显示排他性违例率不可接受，升级为槽位锁（按索引升序加锁避免死锁）。

## A.7 悬挂与删除

- **判定**：K6 中粒子数自己的 nb_count。< 3 → 悬挂。纯局部，无需全局通信。
  > 三角剖分最小度数 = 3（四面体顶点）。这与公理"最小度数 ≥ 2"的关系：2 是图论自洽下限，3 是三维三角剖分闭合下限。实现取 3。
- **删除**：K7 中被标记粒子 active=false，其邻居清除对应槽位。**只删一层**——邻居因 deg 降至 2 而产生的新悬挂，由下一帧 K6 发现。
- **潜在池**：active=false 的槽位进入空闲链表，K3 分配时优先复用。

## A.8 L1 投影层：坐标重构与全局量

L0 只有角坐标（nb_dir）。笛卡尔坐标 pos 是投影，由 L1 重构：

1. 从任一活性粒子起 BFS：已知 (i_pos, j 在 i 球面方向 dir_ij, r_i+r_j) → j_pos = i_pos + (r_i+r_j)·cart(dir_ij)
2. 多路径不一致 → 取最小二乘调和（这本身是 σ 场不均匀性的来源，不是误差）
3. 触发时机：每帧末（若 L2 需要观测）或按需

L1 还负责：创生/连接请求去重、槽位分配、compaction、快照输出。**L1 不做任何物理决策，只做仲裁与簿记。**

## A.9 L2 涌现观测：只读投影

L2（CPU 或异步 GPU 流）从快照读取，**永不回写**：

- 晶子检测：deg ≥ 阈值 → 统计（阈值本身是观测定义，不是动力学约束）
- 12 晶子闭环：晶子诱导子图的连通分量，判定 n=12 / E=30 / 全 deg5 / Σ(6−deg)=12
- Σ(6−deg) 全局轨迹、σ=V/E、悬挂率、开口占比
- 正二十面体几何确认（相切误差）

U4 断言（12 晶子闭环涌现）的诚实标准：**闭环必须由帧序列自然演化产生，不允许任何外力导向/松弛摆放**。

### A.12.2 半径语义裁定：r = f(deg) 尚未推导，L0 暂用单位球

**用户修正（2026-09-11）**：度数与半径**不是**直接的函数对应关系。目前唯一已知的约束是方向性的——**度数越大 → 半径越大**（单调递增）；具体的 r = f(deg) 形式**尚未推导**。

**由此撤销一处旧归因**：本节初版把"帧 6 起 V 卡 16"归因于"`V = 1+deg` 与刚性密堆的本体冲突"。该归因已被 §A.12.1#3 推翻——V 卡住的真正原因是 **K3 用局部坐标系朝向搬入新粒子行**（互指偏差非零），修复后 V 轨迹正常。

**分层裁定**：

| 层 | 半径的角色 | 取值 | 依据 |
|---|---|---|---|
| L0 几何（排他性/相切） | `degree_radius()` 单点入口 | 当前 r≡1.0（中性占位） | r=f(deg) 未推导 |
| L2 认知投影（σ/温度/体积） | "体积随度数增长"的表达 | 待定义 | 投影量，非 L0 几何 |

`degree_radius()` 的取值是**自由设计杠杆**，替换该函数即可实验不同律，无需改动任何 kernel。

**实测（8 帧正四面体种子，L0 `nb_dir` 判据）**：

| 半径律 | 帧末 dev 违例 | 最差比值 |
|---|---|---|
| 等大 r≡1.0 | **0** | 1.000（全帧零违反）|
| r = 1 + 0.01·deg | 36 | 0.956 |
| r = cbrt(0.75(1+deg)/π) | 313 | 0.801 |

**障碍描述（实现层，非本体结论）**：边一旦建立，两端 `nb_dir` 是**冻结**的局部角坐标。任何非恒定半径律都会改变角半径 α，而冻结角位不跟随 → 排他性被破坏。要让 r 随 deg 变化且零违反，必须配套"邻球重排"机制（见 §A.12.3）。

> **纯组合 L0 对本节的处置**：L0 不再需要半径，该开放问题在 L0 层自动消解；半径退回为纯粹投影量（正二十面体投影为等半径球等）。

### A.12.3 邻球重排：已实现（纯角域一致性求解）

**已实现**：纯角域邻球重排 `host.angular_realign()`（`run_frame(angular_iters=N)`，默认 0 = 关闭）。

- 表示：每条边 e=(i,j) 只维护一个全局帧球面方向 u_e；i 行写 `cart2sph(u_e)`，j 行写 `cart2sph(−u_e)` ⟹ 互指 `u_ij=−u_ji` 由构造成立。
- 求解：每个违反约束 (e,f) 是球面上的角度缺口 deficit；对 u_e、u_f 沿大圆各修正 deficit/2，累加归一化，迭代至收敛。**只改 nb_dir，不动 pos**。
- 关键修复：顶点 v 上边 e 的实际方向是 s·U[e]（s=+1 若 v 是 ei，−1 若是 ej）。早期版本忽略符号 → 求解了错误的约束系统。
- 隔离验证：人为扰动 nb_dir 制造 72 处违例 → 120 迭代后 = 0，互指偏差恢复 0.03°。

**实测（14 帧正四面体种子，`angular_iters=120`）**：

| 半径律 | 帧末 dev 违例 | 最差比值 | 互指偏差 | V |
|---|---|---|---|---|
| r≡1（单位球） | 0（全帧） | 1.000 | 0.0° | 128（帧 8）|
| r = 1 + 0.01·deg | 0（全帧） | 1.000→0.991（帧 12 后持平）| 0.0° | 1059（帧 14）|

迭代残差（max 角亏）稳定在 ≈0.010 rad。⇒ 邻球重排把"r 随 deg 变化"与"排他性零违反"接通。但余量稳定在 ~0.99（≈1%），不是无限安全。

**概念澄清（用户 2026-09-11）**：重排**不是**"度数变大把别人推开"。那是背景/力驱动思维的残留——SPUM 无背景容器，邻居的相对角位由关系本身的一致性确定。本步只是在投影坐标里**重解一组自洽角坐标**，迭代是数值求解手段，不是本体动力学。

**已废弃**：方案 C——L1 帧末全局重排（`host.global_realign`）。实测**不收敛**：5000 次与 300 次迭代结果相同，接触图过约束下该嵌入几何不可行。`run_frame(realign_iters=0)` 默认关闭。

**半径律杠杆**：`FrameScheduler(radius_slope=s)` → `degree_radius()` 返回 `1 + s·deg`；`None` → 单位球占位。

## A.13 spatial_proto 最小 3D 创生原型实验记录（2026-09-12）

> 与 §A.5 的 host.py（K1–K8 分布式实现）**并行**，`_archive_v1/l0_legacy/spatial_proto.py` 是一个更小的实验原型：
> CuPy 动态后端（`cp|np`，无 GPU 自动回退 NumPy），只回答一个问题——**非等大 3D 创生能否逼近关系容量 42/50**。
> 它不做悬挂删除（V⁻），只有创生 V⁺ + 帧末全局重排。本轮结论已定格，代码保持现状未再改动。

### A.13.1 半径律候选：A2 面积预算推导

§A.12.2 曾裁定「r = f(deg) 尚未推导，L0 暂用单位球」。spatial_proto 提出一个**从公理推导的单调递增下限候选**：

- A2 排他占据：每个切点（关系）在球面独占面积 κ²
- T8 临界直径：D_max = 4κ

联立 → 球面 πD² ≥ deg·κ² → 下限 `r(deg) = (κ/2)·√(deg/π)`；下限与上限 D ≤ 4κ 重合处
→ `deg = π(4κ)²/κ² = 16π ≈ 50.27`。

`radius_of()` / `saturated()` 据此实现，代码中**不写 12 / 42 / 50 / 16π**——阈值由饱和判据在运行中给出。

### A.13.2 球影排他容量：50 是半径极限，不是球面容量极限

`shadow_capacity`（Fibonacci 球面螺旋采样 + 排他角距贪心）实测球影容量：

| 构型 | 球影容量 |
|---|---|
| 同质（等大球，度 1） | 14 ≈ 接吻数 12 |
| 异质 R_crit + r(3) | 78 |
| 异质 R_crit + r(1) | 193 |

→ 球面放得下远超 50 个邻居；**50.27 是 `r(deg)` 触 R_CRIT = 2κ 的半径极限**，不是球面容量天花板。

### A.13.3 核心结论：12→16→21 容量谱系 + 同质动力学 + 全局刚性墙

三个被证明相互正交的事实：

1. **同质动力学把 max_deg 钉在 ~16**：等大球球影容量精确回到接吻数 12，「三角形创生」天然同质，故 max_deg 卡 16 是**动力学**问题，不是几何天花板。
2. **50 是半径极限**（§A.13.1），球面容量的真实上限依赖度异质（§A.13.2 可达 193）。
3. **全局嵌入刚性发散**：`solve_embedding` 的残差在接触边数 E 撞三维接触图刚性阈值 3N − 6 后不可避免（早期在 V=56 / E=162 撞，增迭代后推迟到 V=125 撞）；删除全局非边排他后仍发散，证明发散源在**边相切松弛本身**，不在非边排他。

### A.13.4 用户洞察：彼此确认，而非线性推进

> 「这是程序线性创生导致的，可以增加迭代次数，以初始节点区域的演变为准。宇宙不需要线性逻辑，只要彼此的确认。」

卡住的根因是每帧仅一遍线性创生 + 有限松弛，节点间缺少反复互认。`solv_iters=1500, step=0.1` 增迭代后：max_deg 16→21，最大度球邻居 median 10→6，初始区 max_deg→18。

### A.13.5 遗留分岔（本轮选定「保持现状记录」）

增迭代后 V=125（帧 7）即 E 撞 3N − 6，嵌入残差从 ~1e-4 升至 2.06e-1，终态 V=500 / E=1494 / 度分布高到 21 / 半径基本钉在下限 → **max_deg=21 带全局嵌入位置噪声，非纯干净信号**。

- 方向 A：把 `solve_embedding` 的全局非边排他替换为只依赖 `create_frame` 局部角容量的投影，再干净测「迭代 → max_deg 能否到 50」——解耦「决定 max_deg 的局部角容量」与「发散的全局嵌入」。
- 方向 B（本次选定）：保持现状，记录上述结论。

> **后续收口（2026-09-13，纯组合 L0 侧）**：方向 A 已由**分岔 N4** 走完并采纳——但不走「迭代到 max_deg=50」，而是**彻底取消全局嵌入**：L1 只由 id + 环序生成网络与局部量（见 §6.3）。N4 同时给出了一条 `O(F)` 的**纯局部**判据 `A_v ≤ 2π`，把「全局刚性墙」提前到局部判决（读数见 §7 分岔 N4）。

> **纯组合 L0 对 §A.13 的处置**：§A.13 的"全局嵌入刚性发散"是**投影层**（把组合结构嵌入笛卡尔坐标）的问题，与 L0 组合规则无关。纯组合 L0 天然回避该问题——L0 从不做全局嵌入。§A.13.5 的方向 A（用局部角容量替代全局嵌入）与纯组合 L0 的"几何全下移"是同一方向的两条路径。
