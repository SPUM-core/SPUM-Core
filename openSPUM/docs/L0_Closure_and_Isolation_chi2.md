## 3. Internal/External = Reachability: Strict Form of the User Proposition

> User proposition (2026-09-14): "Internal is reachable, external is possible to be isolated by the boundary. **This must be a sphere.**"

Two candidate strictifications:

- **F1 (Separability)**: For **any** closed cycle C, removing C splits the network into **two parts** (inside / outside);
- **F2 (Double-disk property)**: Stronger — those two parts are **each disk without holes**.

Third number: **Isolation capacity `b₁ = 2 − χ`** (the first Betti number of the surface = number of independent "non-separating cycles").

### 3.4 Proof skeleton and equivalence chain 〔Derivation·No probe〕

If C splits M into A, B,

```
χ(M) = χ(A) + χ(B) − χ(S¹) = χ(A) + χ(B)
```

Require A, B are both disks (χ=1) ⇒ `χ(M) = 2`. Conversely, if g≥1, there exist non-separating cycles ⇒ F1 fails. ∎

⇒ **F1 ⟺ F2 ⟺ b₁=0 ⟺ χ=2 ⟺ Sphere.**

## 4. χ=2 from where: from classification to generation
