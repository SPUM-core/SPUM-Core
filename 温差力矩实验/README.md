# 温差力矩实验

温差力矩（Temperature Difference Torque）——不对称空间抽运产生净力矩的实验验证。

## 实验概述

扭摆天平装置，Peltier 元件产生温差，Tracker 视频跟踪软件记录位移-时间曲线。

- **实验时期**: 2026年2月 - 4月（保留 4-26/4-27 两日数据 + 25页实验报告）
- **装置**: 扭摆悬丝 + Peltier 制冷片 + 光杠杆放大
- **测量**: 视频跟踪（Tracker 软件，27-30fps）
- **红外测温**: MLX90640 32×24 点阵

## 竞力分析结果

详见 `invert_competition.py` 和 `analysis_output/competition_summary.json`。

三组数据集的阻尼谐振子竞力拟合：

| 数据集 | f₀ (Hz) | ζ | R_type | 阻尼区制 |
|--------|---------|----|--------|---------|
| 根目录_质量A | 0.997 | 0.096 | 2.46 | 欠阻尼（惯性主导） |
| 4-26_质量 | 0.236 | 0.500 | 2.21 | 过阻尼（阻尼主导） |
| 4-27_质量 | 0.761 | 0.001 | 2.40 | 强欠阻尼（惯性主导） |

关键发现：
- R_type (驱动类型比) ≈ 2.5 跨条件一致——温差力矩是脉冲型驱动
- ζ 跨条件变化 500 倍——竞力平衡高度依赖于装置参数
- 根目录_质量A: f₀=0.997Hz, ζ=0.0964, A=9.43mm（最佳数据）
