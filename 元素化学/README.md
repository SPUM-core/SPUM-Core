# SPUM 元素化学：晶子几何 → 元素 VSPT 构型

>
> 核心原则：**到达物质层级后，完全使用球体几何**——不再引用关系第一性公理。原子核即为晶子结（永恒粒子簇），可视作凸球体簇。晶子的实面决定 VSPT 可否生长，晶子的虚面决定缺口的位置与方向。
