# 元素耦合与温度-势框架（v2.0 收敛）

> SPUM 归约路径：原子核 = 晶子闭锁团簇 → 核自跳数势 ΔN_self（谱学内禀基座）→ 环境跳数势 ΔN_env 线性叠加 → 温度读数 = 势读数（普适）→ 元素温度差 δ 在线性框架下 ≡ 0，搁置为开放项 O-δ。
>
> **版本史**：v1.0（2026-09）把元素特征耦合建模为"壳层透射结构 p = Πτ_m"，预言外场盈余 s 穿入原子被壳层逐层吸收 → 深通道元素读冷（δ = (p−1)s/(1+s)），并构造 V1–V4 预言。该版建立在"温度 = 局域 σ 读出"之上。v2.0 依据温度定义的重新锚定（η 不可测 → 温度必须锚定可测量量 = 跳数势差 ΔN，见 `物理学/相对论与宇宙学/引力场温度与Tolman关系.md`）作废局域读出：**势无方向、无穿透、无物可屏蔽**——壳层透射 p 机制失去基座，元素温度差 δ 收敛为 0，预言体系整体搁置。
>
> 定位声明：本文是 v1.0 的收敛版。文件名沿用 v1.0 主题（壳层透射 p 与温度偏差 δ）以维持引用链，内容为 v2.0 收敛结果：元素结构在新框架下的唯一剩存内容 = 核自势谱学；温度侧的 δ 全部移入开放项 O-δ。

## 〇、核心命题（v2.0）

1. **元素谱学 = 核自势的投影**：原子核是晶子源（质子 = 12 永恒粒子闭锁，源强 ∝ A），电子壳层驻留在核自势 ΔN_self(x) ∝ A/x 的梯级上——能级能量、壳层结构（2n²）是核自势几何的读数。这是元素"结构常数"的全部物理内容，无温度含义。
2. **环境势是线性叠加的普适标量**：跳数积分线性，ΔN_total(x) = ΔN_env + ΔN_self(x)。温度读数 T = T∞·g(ΔN_total)。线性 g 下，谱线诊断温度只由 ΔN_env 决定——**同一点不同元素必须读同一温度**。这不是巧合，是 R5（不完美定理：永动机不存在）/第零定律在势型框架里的形态。
3. **δ 的线性死亡**：v1.0 的壳层透射 δ = (p−1)s/(1+s) 需要一个"盈余穿入原子被屏蔽"的局域机制；势是标量累积量，无穿透对象。δ 在 v2.0 框架下 ≡ 0（线性），全部元素依赖预言（V1–V4、排序表、EDT 判别式）随之失效。
4. **元素差只可能在 g 非线性的二阶项复活**（O-δ），量级被 g 的线性归一压制——当前诚实状态：几乎不可测，搁置。

## 一、核自势：元素谱学的势基座（v1.0 §2.2 的势型重述）

### 1.1 核 = 晶子源

原子核是晶子（饱和终极单元）的闭锁团簇：[原子结构.md](../物理学/量子与原子/原子结构.md) 核 = 12 永恒粒子正二十面体微子团簇；永恒粒子 = 多晶子拓扑锁定。晶子占据空间、不参与空间变化（闭锁、零关系流交换——12 晶子闭环=暗物质的仓库先例），但对环境持续产生拓扑需求：**每晶子固定 12 单位**（[引力.md](../物理学/基本相互作用/引力.md) ∮nc dA = 12M̃/μ，拓扑常数 12 是欧拉恒等式的强制解，非拟合常数）。

晶子源的净湮灭抽离关系 → 核周围 σ 盈余 → 核自跳数势（原子尺度）：

$$\Delta N_{\text{self}}(x) = \int_x^\infty \big[\sigma_{\text{self}}(x') - \sigma_0\big]\,dx' \propto \frac{A}{x}$$

（x = 距核心距离；能级 n = 球层序数，壳层容量 2n² 由球面面积约束强制，见 [证明.md](证明.md)。）

### 1.2 能级 = 核自势梯级上的驻留层

电子驻留在 ΔN_self 梯级的离散位置 x_n。能级能量、跃迁频率 = 相邻驻留层核自势差：

$$\Delta E_{n\to m} = h\nu \;\longleftrightarrow\; \Delta N_{\text{self}}(x_n) - \Delta N_{\text{self}}(x_m)$$

谱线的"元素身份"（位置、系结构）完全由核自势几何决定——这是元素与 σ 场接口的全部内禀内容。**它在任何外场下都存在，是谱学而非温度。**

### 1.3 v1.0 结构常数 vs v2.0 核自势

| 项 | v1.0 | v2.0 |
|----|------|------|
| 元素结构常数 | 壳层透射乘积 p = Πτ_m（对外场盈余的透射率） | 核自势 ΔN_self ∝ A/x（自身的势结构） |
| 谱学来源 | （未触及，只处理外场响应） | 能级差 = 核自势驻留层差 |
| 温度含义 | p < 1 深通道读冷 | **无**——谱学内禀不携带温度 |

## 二、环境势叠加与 δ 的线性死亡

### 2.1 叠加是线性的

跳数势差是 σ 沿路径的积分（[SPUM2611.md](../../SPUM2611.md) 第十节），积分线性 → 势线性叠加：

$$\Delta N_{\text{total}}(x) = \Delta N_{\text{env}} + \Delta N_{\text{self}}(x)$$

原子尺度内 ΔN_env 恒定（盈余梯度在 ~Å 尺度变化可忽略）。温度读数（完整推导见相对论文档 §四）：

$$T(x) = T_\infty\cdot g\!\left(\frac{\Delta N_{\text{total}}(x)}{N_0}\right)$$

### 2.2 线性 g：δ ≡ 0

g 弱场线性归一（g(0)=1，g 几乎线性——相对论文档 §四 用它获得与 Tolman 的同形）。线性的两个直接后果：

1. 环境项与自势项可分离：T = T∞·[g(ΔN_env/N₀) 公共因子] × [g(ΔN_self/N₀) 内禀因子]（对乘法型 g）——**外场对一切元素的作用是同一公共因子**；
2. 谱线布居的诊断温度参数由公共环境项决定 → 同点所有元素线给出同一 T_diag。

故同一点、不同元素、不同谱线：**温度读数必须相同**。v1.0 的"深通道元素读冷"在此框架下是结构性的不可能——不存在让元素差存身的自由度。

### 2.3 v1.0 的 V1–V4 命运

| v1.0 预言 | v2.0 命运 | 原因 |
|----------|----------|------|
| V1 价层通道元素盲 | 升级为普适定理：**全部通道元素盲** | 温度=普适势读数 |
| V2 核探针重元素读冷 | 作废 | 无 p<1 通道概念 |
| V3 内层激发温度偏低 | 作废 | 布居温度由公共环境项定 |
| V4 满壳屏蔽 | 作废 | 无屏蔽对象 |

## 三、O-δ：元素差复活的唯一边界

元素差若存在，只能来自 g 的非线性（∂²g ≠ 0）与谱学色散的交叉：

$$\delta \;\sim\; \frac{g''}{g'}\cdot\frac{\partial(\Delta E_n)}{\partial \Delta N_{\text{env}}}\cdot\Delta N_{\text{env}}$$

- 物理图像：外场使整把"核自势刻度尺"平移；g 线性时平移是刚性的（无元素差）；g 非线性时刻度间距随势位变化，各元素线系漂移率出现二阶色散。
- 压制：g 的线性归一（c²_proj 弱场锚定，相对论文档 §四）意味着 g''/g' ≈ 0，二阶差在弱场可忽略。
- 复活条件（缺一不可，均未满足）：
  1. g 非线性的**机制来源**（g 目前只是待锚形式，无独立推导）；
  2. 可测的交叉项量级（需逃过 R5 且大过诊断系统学）。

**诚实状态：O-δ 搁置。** 在 O-δ 复活前，元素耦合文档不再声称任何与温度相关的判别预言。

## 四、版本对账

| 版 | 机制 | 形式 | 命运 |
|----|------|------|------|
| v0 | 元素特征耦合 = 纯常数 | δ_i = k·Aⁿ | 废弃：纯常数违反平坦空间热平衡（永动机，R5）+ 与仓库原子模型不符（把接口归于核内部） |
