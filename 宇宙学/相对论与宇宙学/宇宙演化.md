# 宇宙演化

> SPUM 归约路径：多中心收缩驱动全局 σ 缓慢上升。宇宙不是在膨胀——而是以每一个物质聚集中心为锚点持续收敛。

## SPUM 定义

宇宙的演化 = **全局 σ 缓慢上升 + 多中心持续收敛** 的双重过程。

- **全局 σ 上升**：每一帧净湮灭事件产生新的悬挂端 → 边数净增长 → 节点平均度数下降 → σ = |P|/|ε| 上升。这是宇宙"时间"的方向性来源——帧计数本身就是时间。
- **多中心收敛**：物质粒子（12 永恒粒子正二十面体锁闭）内部的净湮灭效应是局部收缩引擎。宇宙中每一个星系、星系团都是一个收缩中心。两个收缩中心之间的空间被双侧牵引——在大尺度上投影为"相互远离"的表象。

演化不是"从某事件开始走向某终点"——而是无始无终的帧序列，受不完美定理驱动永不休止。

## 一、核心动力学：多中心收缩

### 1.1 收缩的层级结构

| 层级 | 尺度 | 收缩中心 | 表现 |
|------|------|---------|------|
| **微观** | ~10⁻¹⁵ m | 原子核（12永恒粒子锁闭） | 核子内部持续湮灭 | 
| **星系** | ~10⁴ pc | 星系核心 | 旋转曲线、径向质量分布 |
| **星系团** | ~10⁷ pc | 星系团质心 | 星系向团中心收敛 |
| **宇宙学** | ~10⁹ pc | 所有物质聚集中心的并集 | 大尺度 σ 场演化 |

### 1.2 收缩如何产生"膨胀"表象

考虑两个收缩中心 A 和 B，它们都在各自的局部区域内吸引周围空间。A 和 B 之间的空间被双向牵引——在 A 看来，B 似乎在远离；在 B 看来，A 也在远离。

这不是空间在膨胀——而是 **两个局部锚点之间的空间中，没有哪个点是静止的**。每一个观察者都以为自己在"中心"，而其他所有星系在"退行"。

**数学类比**：设想二维球面上的多个收缩中心。每一个中心周围的局部区域都在向中心汇聚——但从远处看，任意两个中心之间的距离在增加。这并非球面在膨胀——而是收缩的几何必然。

### 1.3 与 ΛCDM 膨胀的关系

SPUM 的多中心收缩在**大尺度统计平均**上，与 ΛCDM 的膨胀在数学上可以等价描述——但物理本质完全相反：

| 方面 | ΛCDM（膨胀） | SPUM（收缩） |
|------|-------------|-------------|
| 红移的起源 | 空间膨胀拉伸波长 | 链上累积跳数差（光子数据链的读数，非光子被拉伸） |
| 宇宙的"动力" | 暗能量（负压） | 净湮灭（无外部驱动） |
| 均匀性 | 初始条件（暴胀） | 统计投影（大尺度收缩中心的随机分布） |
| 终点 | 热寂 / 大撕裂 | 永不停止（不完美定理） |

## 三、暗物质的替代解释

### 3.1 星系旋转曲线 → 子图协动

星系盘外围恒星的平坦旋转曲线不是暗物质晕的引力作用——而是**悬挂端沿水形链的协同运动**（子图协动机制）。

已在 SPARC 175 星系数据上验证：94.3% 有效，χ² 中位数 0.68，AIC/BIC 优于 NFW 暗物质晕模型。详见 `docs/Subgraph_CoMotion/`。

### 3.2 星系团速度弥散 → σ 梯度投影

星系团内观测到的"速度弥散"不是星系在引力势阱中的本动——而是同一星系团内不同局部 σ 的差异在光谱线上的叠加。

核心区（高 σ）星系的本征频率低，外围（低 σ）星系的频率高——两者同时出现在同一光谱线测量中，产生等效于"速度弥散"的线宽。详见 `宇宙学大纲.md §三`。

### 3.3 引力透镜 → σ 梯度路径

大质量天体 = σ 场的局部极大值。光子穿越时选择 σ 梯度的最优路径（最小阻力路径）——偏转量由 ∇σ 决定，不需要暗物质参与。

## 四、黑洞的 SPUM 解释

传统：时空奇点，事件视界。
ΛCDM 扩展：超大质量黑洞是星系形成的关键组分。

SPUM：
- 极端质量 → 净湮灭速率极高 → 物质粒子周围的空间流被持续向内抽拉，**收绳速度**趋近乃至超过 \(c\)
- **黑洞 = 绞盘**：它不停地把绳子（空间本身）往里收。收绳速度在某个半径处追上绳波速度 \(c\) ——这个半径就是**视界**
- 光子是绳波。视界以内收绳速度 > \(c\)，向外的绳波根本不存在（不是被"挡住"，是发不出去）
- **无奇点**——σ 局部极高只是视界内的**读数**（空间粒子被收成的极致收敛排列），不是本体；不发散，也没有"点"
- 黑洞的"视界" = **收绳速度追上 c 的边界**；其**读数**是 σ 梯度足够陡峭以至于向外记账无法兑现
- 超大质量黑洞 = 星系收缩中心，星系子网的 σ 锚点（而非"形成产物"）

> **注意区分（见 `物理学/基本相互作用/引力.md` §1.4）**：引力**本体**是净湮灭驱动的**空间流**（介质本地移动），速率**不受 c 限制**；σ 梯度排列只是它的**读数**。把黑洞描述成"σ 场的压缩态"是读数表述，说清"绞盘在收绳、收速可超 c"才是本体表述。
