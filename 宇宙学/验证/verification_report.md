## P1 结果

- **节点数**：500 条光谱 → P = 500
- **边数**：4761（互 kNN k=25，连通）
- **σ 全局**：0.105（恒量，所有节点在同一分量）
- **σ 局部**：均值 0.205，标准差 0.105
- **σ 空间结构**：ρ(σ_local, spatial_density) = -0.058 (p=0.195)
  - 核心 σ = 0.201，外围 σ = 0.208
  - 方向符合预期（核心密度更高→σ 更低），但信号弱

## 关键判断

1. **光谱指纹子网可构建**：✅ 原始光谱可构建 ⟨P, ε⟩
2. **σ 有空间结构**：⚠️ 方向符合预期，但信号在模拟数据中较弱（信噪比 ~15-40 下 σ 梯度被噪声淹没）
3. **σ-谱线偏移相关**：⚠️ SII 检验通过了，但其他谱线未通过
4. **线比变化**：⏸️ 方向符合，样本量不足以结论
