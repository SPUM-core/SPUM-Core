## 一、范式总纲

### 1.1 什么是 SPUM 宇宙学

SPUM 宇宙学 = ⟨P, ε⟩ 在星系尺度及以上的应用。不是"用网络比喻宇宙"——宇宙**就是** κ 网络的星系子网集合。每一个星系团是一个拓扑子网，其所有的观测特征（星系分布、旋转曲线、速度弥散、形态分布）都是该子网的**本征属性**，而非动力学演化结果。

| 维度 | ΛCDM 标准宇宙学 | SPUM 宇宙学 |
|------|----------------|------------|
| 第一原则 | 宇宙膨胀 + 暗物质 + 暗能量 | 星系子网 ⟨P, ε⟩ + σ 场 + 子网间耦合 |
| 基础对象 | 时空、暗物质晕、重子物质 | 节点、边、σ 分布、子网拓扑参数 |
| 红移 | 空间膨胀拉伸波长 | σ 差异的本征频率读数（待推理） |
| 速度弥散 | 星系在引力势阱中的运动 | σ 梯度在子网内的投影 |
| 旋转曲线 | 暗物质晕 | 子网边权重的径向分布 |
| 暗物质 | 不可见的冷暗物质粒子 | 引力是净湮灭效应，所需额外质量可能源自 σ 梯度 |
| 暗能量 | 驱动加速膨胀的负压能量 | 不需要——红移-距离非线性来自 σ(z) 演化（待推理） |

### 1.2 核心理论基础

```
⟨P, ε⟩ 核心公理
    │
    ├─ 物质粒子 = 12 永恒粒子正二十面体锁闭 → 净湮灭引擎
    │
    ├─ 引力 = ∇σ（净湮灭效应产生的空间密度梯度）
    │
    ├─ 星系子网 = 物质粒子聚集形成的局部 ⟨P, ε⟩ 子图
    │   ├─ 子网内部 σ 分布 = 星系团结构
    │   ├─ 子网边界 = 与背景网络的 σ 过渡区
    │   └─ 子网间耦合 = 观测的本质（谱线、光度、形态）
    │
    ├─ 红移 = σ_source/σ_obs − 1（待推导，见 §9.2）
    │
    └─ 宇宙演化 = 全局 σ 上升 + 子网持续收敛
```

## 二、SPUM 本体论根节点（R1-R9 的宇宙学映射）

> **R1-R9 唯一定义来源**：`.trae/rules/spum-root-nodes.md`。以下为宇宙学模块的应用映射。

| 编号 | 根节点 | SPUM 定义 | 宇宙学映射 |
|------|--------|----------|----------|
| R1 | **⟨P, ε⟩** | 节点集 + 边集，关系定义存在 | 宇宙中不存在"时空"——只有星系子网及其间的σ场 |
| R2 | **V⁺ / V⁻** | 创生/湮灭事件，全局守恒 | 物质粒子持续湮灭空间 = 宇宙收缩的引擎；V⁺ 产生新节点补偿 |
| R3 | **离散帧 τ** | 演化步数，帧内无循环 | 宇宙"年龄" = 总帧数；不同σ区域的帧节奏不同 |
| R4 | **dv/dt ≤ const** | 单帧关系变化上限 | 光速 c = 4κ/τ；任何"膨胀"速率同样受此约束 |
| R5 | **不完美定理** | 每帧必残留悬挂端 | 宇宙永不休止——全局均匀各向同性态不可达 |
| R6 | **S 向量** | 五维结构健康向量 | 星系子网的健康态 = S ∈ H |
| R7 | **健康多面体 H** | S 的合理区间凸区域 | 稳定星系团 = 子网 S 落在 H 内 |
| R8 | **ΔS** | 干预 = 五维位移向量 | 星系团并合 = 子网间 ΔS 驱动力 |
| R9 | **σ = \|P\|/\|ε\|** | 空间密度 | 宇宙最基本的场——σ 的梯度分布决定了全部观测信号 |

### 根节点归约流程图

```
传统宇宙学概念（如"红移"）
    │
    ▼
观测事实：远处星系光谱红移 z > 0
    │
    ▼
SPUM 重定义：红移不是退行速度，而是 σ_source/σ_obs − 1（本征频率差）
    │
    ▼
[L0] 图论表达：原子振荡频率 f ∝ 1/σ → 更高 σ 环境中的原子发出更低频的光
    │
    ▼
与 ΛCDM 的分野：不需要膨胀、不需要暗能量、不需要暗物质粒子
```
