## 一、物理接口：SPUM ↔ 以太形式化

> 完整形式化映射见 `地基/SPUM-以太映射.md`

SPUM 不继承以太的本体论。SPUM 借用以太研究的数学结构为 σ = |P|/|ε| 赋予物理直观。

| SPUM 图论量 | 以太数学等价物 | 物理含义 |
|-------------|---------------|---------|
| σ = \|P\|/\|ε\| | 局域真空极化度 Π | 真空被"掰弯"的程度 |
| n(σ) = σ/σ₀ | 真空折射率 n(x) | 光速随位置变化（从公理推导） |
| ∇σ | 真空折射率梯度 ∇n | 引力场的**读数**（引力本体是空间流） |
| z ∝ Σ_k (σ(l_k)−σ₀)/σ₀ | 累积折射相位 | **光子数据链**的聚合读数（逐跳追加 σ 记录），不是单个光子被改造 |

**不继承的假设**：
- 不假设优先参考系（∇σ 方向局域确定，非全域）
- 不假设连续真空（σ 来自离散图，连续是投影）
- 不假设作用量原理（σ 由帧演化规则确定）

## 二、地基层：可接受的数据

**核心原则**：从望远镜直接获得的物理量，或经过不涉及 ΛCDM 公理的标准仪器校准获得的量，是可接受的。其他的一切都是模型输出。

### 可接受（地基干净）
- CCD 像素通量值（ADU 或已标定的 flux）
- 波长校准（真空波长，使用实验室光源标定）
- RA/Dec 指向（ICRS 国际天球参考系）
- 曝光时间（MJD 起始/结束）
- 观测站标准大气折射校正
- 谱线中心在像素阵列上的位置（像素索引）

### 不可接受（含 ΛCDM 或其他模型假设）
- 红移 z（任何标量值，无论以何种方式输出）
- 退行速度（km/s）
- 光度/共动距离
- 绝对星等（需距离模量）
- 暗物质晕质量
- 速度弥散
- 星族年龄（需恒星演化模型）
- 星族金属丰度（需恒星大气模型）

### 有条件接受（经 SPUM 重新校准后可）
- 通量的绝对标定（依赖标准星模型 → 标记为"待 SPUM 校准"）
- 星/星系分类（依据形态而非红移）

## 二、迈克尔逊-莫雷实验的正确解读

> 这是 AI 推理 SPUM 宇宙学时必须加载的约束上下文。

**核心论点**：MM 实验不是对空间介质的否定——**它是子图协动的直接验证**。

### 前置定理：往返盲定理（写死，不可跳过）

方向依赖度量（Finsler/Randers，GEO-021~030）中，光速的方向依赖由 $b_i \propto \nabla_i\sigma$ 承载。但

$$F(x,v) + F(x,-v) = 2\sqrt{g_{ij}v^i v^j}$$

$b_i$ 项是 $v$ 的**奇部**，在"同一段路正反各走一次再取和"的任何构型中**精确相消**。

**推论**：往返光速恒为各向同性，且**与 ∇σ 的大小无关**。MM 及其全部变体（Kennedy-Thorndike、Brillet-Hall、现代光腔 $\Delta c/c \lesssim 10^{-17}$）**对 $b_i$ 完全盲**——不是精度不够，是判据本身不含 $b$。环路亦盲：$b_i \propto \nabla_i\sigma$ 是梯度场，$\oint \nabla\sigma \cdot dl = 0$。

单向光速的测量要求"同时"的定义先行，而同步时钟必须用光（慢搬运亦受单向光速支配）——循环。这是"单向光速不可测"这条范式级结论在 SPUM 里的重述，且 SPUM 给出的根据比 GR 更干净：不是拖曳或同步约定的麻烦，而是 **$b$ 的奇性 + 路径配对 ⇒ 代数相消**。完整推导见 `几何学/Finsler几何/spum-Randers度量.md` §1.4 推论 R1。

### 推理链（写死，不可跳过）

```
步 1: MM 寻找以太风（绝对运动），发现零条纹偏移
        → 否定了"静态、均匀、单一全域参考系"的以太模型
        ✅ SPUM 接受

步 2: 20 世纪物理学的解读
        → "不存在静态均匀以太 → 不存在任何空间介质"
        ❌ SPUM 不接受——这是逻辑跳跃

步 2': SPUM 的解读——零结果是两条独立理由的叠加
        (1) 硬约束：往返盲定理 → 光速各向异性不进入任何往返读数
            （与 ∇σ 大小无关；即使局域 ∇σ 很大，往返仍精确相消）
        (2) 辅助：地球局部子图 = 高度连接、密集的 σ 均匀区
            → 连度量偶部 g_ij 的局域空间变化也很小
        ✅ 与实验完全一致

步 3: 关键命题
        红移读数 = 光子数据链沿途逐跳追加的局部 σ 记录的累积
        （z ∝ Σ_k (σ(l_k)−σ₀)/σ₀ ⟺ ∫(σ−σ₀)/σ₀ dl），
        光子自身在途中不被改造；与"绝对速度"无关
        → MM 零结果不构成对 ∇σ 的测量（往返盲，见前置定理）
        → 星系团尺度 ∇σ ≠ 0 意味这光谱系统性偏移（SPUM 预言的）

步 4: 结论
        MM 零结果 = 验证了局部子图在度量偶部（g_ij）上的均匀性
        = 子图协动机制在实验室尺度的直接验证
        = 与 SPARC 175 星系旋转曲线（星系团尺度）同源
```

### 约束规则

1. **不得以"MM 实验证伪了以太"为前提进行推理**。MM 仅否定了特定模型，未否定空间介质类别。
2. **不得把 MM 零结果归因于"∇σ_local ≈ 0"**。往返盲定理是硬约束，与 ∇σ 大小无关；局域 σ 均匀只是辅助理由（它说明度量偶部 $g_{ij}$ 也近乎不变）。MM 测的是度量**偶部** $g_{ij}$ 的局域均匀性，**对奇部 $b_i = \nabla_i\sigma$ 完全盲**，不构成对 σ 梯度的测量。零结果说明局域均匀，不否定全域存在。
3. **不得以"MM 实验 → 没有以太 → 空间不需要介质 → 相对论必然正确"这一链条作为推理前提**。SPUM 不承认此链条的逻辑有效性。
4. 子图协动机制的形式化基础见 `docs/Subgraph_CoMotion/`。
5. **区分两类证据**：SPARC 175 旋转曲线证的是 $\nabla\sigma$ 的**存在性**（度量偶部的空间变化），**不是**"光速各向异性"。二者不可互换引用。

## 三、相对论导向的研究为何不可信

> 不是否定相对论的工程有效性（GPS、粒子加速器依赖它）。这是方法论判断：**相对论作为宇宙学的基础框架，已走到自身假定边界的极限。**

### 核心分歧

| | GR（几何框架） | SPUM（拓扑/网络框架） |
|--|---------------|---------------------|
| 引力 = 时空弯曲 | 引力 = 空间流（介质本地移动）；σ 梯度是它的读数 |
| 红移 = 空间膨胀（a(t)） | 红移 = **光子数据链**的累积读数（逐跳追加局部 σ 记录，与接收端标准帧时钟比对） |
| 需暗物质 + 暗能量 = **4+ 自由参数** | 1 个 σ，由数据自然涌现 |
| 与量子力学无法统一（不可重整化） | 同源（真空极化是接口） |
| 奇点处自爆 | 不完美定理保证永不停机 |

### 推理禁令

- **不得以 GR 的几何预设为前提来提出宇宙学问题**。例如"暗物质粒子是什么？""暗能量的状态方程是多少？""暴胀的标量势是什么？"——这些问题的形式本身预设了 GR 框架的有效性。SPUM 不同意它们的前提。
- GR 的暗物质 + 暗能量等价于哥白尼时代的"本轮"——每发现一个异常的观测就在已有框架上叠加一个补丁。四个独立自由参数在同一张图上拟合不是验证，是过拟合。

## 四、从原始光谱到 ⟨P, ε⟩

每条光谱转化为一个指纹向量：

```
S_i = [flux_norm(λ_1), flux_norm(λ_2), ..., flux_norm(λ_m)]
```

其中：
- λ_k 为固定波长槽（统一重采样到同一网格）
- flux_norm 为总通量归一化后的相对通量（消除亮度差异，保留谱型信息）

**建边规则**：
```
cos_sim(S_i, S_j) > θ → (i, j) ∈ ε
```

**σ 定义**：
```
σ_i = |P_i| / |ε_i|
```
其中 P_i 为节点 i 所在连通分量，ε_i 为该分量内边数。
