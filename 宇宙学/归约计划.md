## 〇、全局使命

### 0.1 归约计划的定位

SPUM 宇宙学的使命不是"改进 ΛCDM"，而是**为全部宇宙学观测提供不需要暗物质、暗能量、膨胀假设的替代解释**。归约计划是执行此使命的路线图——从核心框架定义开始，逐层展开具体推导，最终用观测数据验证。

归约的内容结构：

```
⟨P, ε⟩ 核心公理
    │
    ▼
    星系子网基本模型
    │
    ├─ 红移与 σ ──── 已完成 §9.2 框架，待推导 f(σ)
    ├─ 引力与暗物质 ── 已完成子图协动（SPARC 验证），待推广到星系团
    ├─ 宇宙收缩 ──── 框架已定义，待形式化
    ├─ 大尺度结构 ── 待展开
    └─ CMB ──────── 待展开
```

### 0.2 归约原则

每个宇宙学概念的归约需满足：

1. **可回溯性**：从观测事实回溯到 ⟨P, ε⟩ 公理，每一步可验证
2. **可量化性**：归约结果必须能用观测数据检验（SDSS/DESI/SPARC）
3. **与 ΛCDM 可区分**：归约必须产生 ΛCDM 无法（或难以）给出的定量预言

### 0.3 术语规范

| 传统术语 | SPUM 术语 | 说明 |
|---------|----------|------|
| 宇宙膨胀 | 宇宙收缩 | 多中心收缩产生膨胀表象 |
| 暗物质晕 | 子网 σ 梯度 + 子图协动 | 不需要不可见粒子 |
| 暗能量 | σ(z) 演化 | 不需要负压流体 |
| 速度弥散 | σ 本征频率差 | 不是多普勒效应 |
| 星系团质量 | 子网 σ 积分 | 不需要维里质量假设 |
| 红移 | σ_source/σ_obs − 1 | 本征频率比，不是速度 |
