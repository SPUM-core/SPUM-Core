## 核心论点

ΛCDM 认为：光谱中的谱线偏移 = 多普勒效应 → 退行速度 → 宇宙膨胀。
SPUM 认为：光谱中的谱线偏移 = 不同 σ 环境下局部帧周期的差异。

二者对同一组观测数据给出不同解释。区分它们的关键可检验推论：
- 如果谱线偏移来自多普勒 → 所有谱线同比例偏移，线比不变
- 如果谱线偏移来自 σ 差异 → 不同激发态的谱线对 σ 敏感度不同 → 线比变化
