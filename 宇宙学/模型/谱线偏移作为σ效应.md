# 谱线偏移作为 σ 效应 — 真空折射波长漂移

> 谱线的系统性偏移不是多普勒速度的表现——是光在真空折射率梯度中传播时被拉长或压缩。
>
> 物理接口：Δλ/λ = β·Δσ/(1+βσ₀) ← 真空折射率梯度的积分效应
> 详见：`地基/SPUM-以太映射.md`

---

## ΛCDM 教条

ΛCDM 对所有红移偏移的唯一解释：

```
Δλ/λ = v/c
```

即所有谱线同比例向红端（或蓝端）移动，偏移量只与"视向速度"有关。因此：
- 谱线偏移与谱线**种类无关**
- 线比（如 [OIII]/Hβ）在偏移前后**不变**
- 唯一依赖的物理量是速度 v

---

## SPUM 替代解释：真空折射率梯度

在 ⟨P, ε⟩ 框架中，谱线偏移来自局部 σ（真空极化度）的差异。完整推导见 `模型/折射率第一原理推导.md`。

```
Δλ/λ = σ_source/σ_obs − 1
```

推导：
1. n(σ) = σ/σ₀（从公理推导，非假设）
2. 光从 σ_source 传播到 σ_obs：λ_obs/λ_source = n(σ_obs)/n(σ_source) = σ_source/σ_obs
3. 因此 Δλ/λ = σ_source/σ_obs − 1

**无自由参数**——不引入 β，不引入 H₀，不引入 Ω_m。唯一需要的量是路径两端点的 σ，从光谱数据自身算出。

**与旧形式的关系**：旧形式 Δλ/λ = β·Δσ/(1+βσ₀) 是 Δλ/λ = σ_source/σ_obs − 1 在 σ₂ = σ₁ + Δσ, |Δσ| ≪ σ₁ 时的一阶展开。在星系团尺度上，Δσ/σ ∼ 0.01-0.1，二者差异可忽略。但新形式在概念上更干净——无自由参数。

### 路径积分形式

对非均匀 σ 场，光从 r_source 到 r_obs 经过连续变化的真空极化区域。此时红移为 σ 对数的路径积分：

\[
z(\mathbf{r}) = \exp\left(\int_{\mathbf{r}_{source}}^{\mathbf{r}_{obs}} \nabla\ln\sigma \cdot d\mathbf{l}\right) - 1
\]

**离散形式**（帧演化）：图 ⟨P, ε⟩ 中，光沿最短路径传播，每帧更新一次 σ 读数：

\[
z = \prod_{k=1}^{N_{frames}} \frac{\sigma_{k}}{\sigma_{k+1}} - 1
\]

其中 σ_k 为第 k 帧时光子所在位置的局部 σ。

**与 ΛCDM 路径的不同**：
- ΛCDM：红移 = 尺度因子之比 z + 1 = a(t_obs)/a(t_emit)——需要背景 FLRW 度规
- SPUM：红移 = 路径两端 σ 之比——只需要子图密度，不需要背景度规

**物理图像**：高真空极化区域（高 σ）等效于"光密介质"，光经过后波长被拉长——就像白光经过玻璃棱镜后红端偏折更大。区别在于这不是玻璃的折射，而是真空本身极化梯度的折射。

## 跨领域一致性：与子图协动的连接

星系团尺度的 σ 梯度（谱线偏移）与星系尺度的 σ 梯度（旋转曲线）在拓扑上同源。

| 尺度 | 现象 | σ 梯度的表现 | 已验证 |

| 星系 | 旋转曲线平坦 | ∇σ 驱动星体轨道，无需暗物质 | SPARC 175, 94.3% |
| 星系团 | 核心-外围谱线偏移 | ∇σ → ∇n → Δλ/λ | 当前工作 |
| 星系团内 | 线比变化 | 不同激发区域处于不同 σ 环境 | P2 p=0.036 |

**子图协动的参数（V_co, r_co）在 ∇σ 语言中的含义**：
- V_co（渐近速度）∝ |∇σ|·L（梯度强度 × 特征尺度）

- 高 V_co → 强 σ 梯度 → 核心-外围 σ 差异大 → 谱线偏移大

**交叉验证路径**：同一星系团中，SPARC 拟合出的 V_co 分布应与 σ_local 的梯度强度正相关。如果成立，则星系动力学 + 星系团光谱学指向同一个 σ 场——两个独立观测通道，同一个拓扑本源。

## 关键区分性预言

| 预言 | ΛCDM（多普勒） | SPUM（真空折射） | 检验方式 |
|------|---------------|-----------------|---------|
| 线比变化 | 不变 | 随 σ 变化 | P2 管道 |
| 激发态依赖 | 无 | 高激发态谱线更敏感 | P2 线比检验 |
| 空间分布 | 团内动力学 | 直接与 σ 梯度相关 | P1 空间结构 |
| 波长依赖 | 无（所有 λ 同比例） | 更长波长的谱线偏移更大 | 未来检验 |

**为什么不同谱线偏移不同？**
在真空折射解释中，所有谱线的 Δλ/λ 比例相同——这是由 n(σ) 的形式决定的。
但线比变化来自另一个机制：不同激发态的谱线其等效"发射深度"不同，对局域 σ 的敏感度不同。
- Hα（低激发，来自 HII 区外围）→ 感受平均 σ
- [OIII]（高激发，来自 HII 区核心）→ 感受局部高 σ

这不是谱线本身的折射差异——是不同发射区域处于不同 σ 环境。
