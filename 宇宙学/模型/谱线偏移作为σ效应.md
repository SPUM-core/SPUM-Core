# 谱线偏移作为 σ 效应 — 光子数据链的逐跳读数

> 谱线的系统性偏移不是多普勒速度的表现，也不是"光在途中被拉长"——它是光子沿途逐跳追加的局部 σ 记录链被读出后的聚合读数。
>
> 观测形式：累积跳数差 $z \propto [\Delta N(r_s) - \Delta N(r_o)]$，$\Delta N(r) = \int_r^\infty [\sigma(r') - \sigma_0]\,dr'$
> 详见：`地基/SPUM-以太映射.md`、`模型/折射率第一原理推导.md`

---

## ΛCDM 教条

ΛCDM 对所有红移偏移的唯一解释：

```
Δλ/λ = v/c
```

即所有谱线同比例向红端（或蓝端）移动，偏移量只与"视向速度"有关。因此：
- 谱线偏移与谱线**种类无关**
- 线比（如 [OIII]/Hβ）在偏移前后**不变**
- 唯一依赖的物理量是速度 v

## SPUM 替代解释：光子数据链

### 本体：红移不是单个光子的变化

红移**不是**这一个光子在传播途中被介质逐帧改造的结果。光子在发射端即封装完毕——它的频率由发射原子的局部 σ 锁定，途中不拉伸、不失能、不被逐帧更新。

光子是**一条数据链的载体**：光每跳一次，就在链上追加一条"此处局部 σ"的记录。整条链抵达接收端后，被与本地标准帧时钟比对，读出累积偏差。因此，**"红移"这个量定义在链上，不定义在单个光子上**——问"这个光子在途中变红了多少"是没有意义的问法。

### 观测量：累积跳数差，不是两端 σ 之比

``` 
z = [ΔN(r_source) − ΔN(r_obs)]·K,    ΔN(r) = ∫_r^∞ [σ(r′) − σ₀] dr′
```

σ 高（近源）= 空间粒子小 = 单位距离跳数多。ΔN 是**沿途数出来的、可数的累积量**（L0 整数），不是某一处的局部量。

写成两端局部值之比 `z = σ_source/σ_obs − 1` 是**错误翻译**：质量场中 σ ∝ 1/r²，它会给出 z ∝ 1/r²，而观测到的是 z ∝ 1/r。问题不在帧时钟机制（那一层是同一套），而在翻译——**可观测对应的不是两端 σ 的比，而是链上累积跳数的差**。

**无自由参数**——不引入 β，不引入 H₀，不引入 Ω_m。唯一需要的量是沿路径读出的 σ，从光谱数据自身算出；K 由 σ₀ 标定。

**与旧形式的关系**：旧形式 Δλ/λ = β·Δσ/(1+βσ₀) 与两端比值式同属"局部读数"翻译，是累积跳数式在**路径 σ 起伏可忽略**时的退化取值。在星系团尺度上二者差异可忽略，但通式是累积跳数式。

---

### 路径积分形式：链上记录的逐段累加

对非均匀 σ 场，把光路沿途**每跳的记录**逐个加起来：

\[
z = \sum_{k=1}^{N_{frames}} \frac{\sigma(l_k) - \sigma_0}{\sigma_0}
\]

光每帧位移 4κ，经过一个局部区域，就向链上追加一条"此处 σ 与本地 σ₀ 之差"的记录；整个光路累加，即得接收端的读数。**累加的是链上的记录，不是光子自身的频率**——这是本式与"每帧更新一次光子波长"说法的根本区别。

> 反例（禁止）：把上式读作"光子的 σ 每帧被更新一次"、写成 $\prod_k \sigma_k/\sigma_{k+1} - 1$ 的乘积链。乘积链在数值上等价于**两端 σ 之比** $\sigma_{source}/\sigma_{obs}$，即上文已判为错误翻译的局部读数式——它把整条链的记录压成两端读数，因而复现了 z ∝ 1/r² 的错误幂次。

**与 ΛCDM 路径的不同**：
- ΛCDM：红移 = 尺度因子之比 z + 1 = a(t_obs)/a(t_emit)——需要背景 FLRW 度规
- SPUM：红移 = 光路上累积跳数的差——只需要子图密度，不需要背景度规

**物理图像**：高真空极化区域（高 σ）意味着单位距离的跳数更多。光穿过它时，链上追加的记录值更大——**读数是变红了，但光本身没有变**。区别在于这不是玻璃的折射（那会改造光），而是链上记录的累积。

## 跨领域一致性：与子图协动的连接

星系团尺度的 σ 梯度（谱线偏移）与星系尺度的 σ 梯度（旋转曲线）在拓扑上同源。

| 尺度 | 现象 | σ 梯度的表现 | 已验证 |
|------|------|-------------|:------:|
| 星系 | 旋转曲线平坦 | ∇σ 驱动星体轨道，无需暗物质 | SPARC 175, 94.3% |
| 星系团 | 核心-外围谱线偏移 | ∇σ → ∇n → Δλ/λ | 当前工作 |
| 星系团内 | 线比变化 | 不同激发区域处于不同 σ 环境 | P2 p=0.036 |

**子图协动的参数（V_co, r_co）在 ∇σ 语言中的含义**：
- V_co（渐近速度）∝ |∇σ|·L（梯度强度 × 特征尺度）
- r_co（特征半径）∝ σ 过渡区的宽度
- 高 V_co → 强 σ 梯度 → 核心-外围 σ 差异大 → 谱线偏移大

**交叉验证路径**：同一星系团中，SPARC 拟合出的 V_co 分布应与 σ_local 的梯度强度正相关。如果成立，则星系动力学 + 星系团光谱学指向同一个 σ 场——两个独立观测通道，同一个拓扑本源。

## 关键区分性预言

| 预言 | ΛCDM（多普勒） | SPUM（数据链累积） | 检验方式 |
|------|---------------|-----------------|---------|
| 线比变化 | 不变 | 随 σ 变化 | P2 管道 |
| 激发态依赖 | 无 | 高激发态谱线更敏感 | P2 线比检验 |
| 空间分布 | 团内动力学 | 直接与 σ 梯度相关 | P1 空间结构 |
| 波长依赖 | 无（所有 λ 同比例） | 更长波长的谱线偏移更大 | 未来检验 |

**为什么不同谱线偏移不同？**
在数据链框架中，同一条链上的所有谱线共享同一串 σ 记录，故 Δλ/λ 的比例相同——这是链的性质决定的，与谱线种类无关。
但线比变化来自另一个机制：不同激发态的谱线其等效"发射深度"不同，对局域 σ 的敏感度不同。
- Hα（低激发，来自 HII 区外围）→ 感受平均 σ
- [OIII]（高激发，来自 HII 区核心）→ 感受局部高 σ

这不是谱线本身被介质改造的差异——是不同发射区域处于不同 σ 环境，写入链的记录不同。

## 可检验的观测效应

在星系团核心-外围对比中：

**ΛCDM 预期**：核心和外围的光谱差异来自速度弥散，线比不变。

**SPUM 预期**：
1. 核心 σ 低（Π 小）→ 单位距离跳数少 → 累积跳数差小 → 光谱偏蓝
2. 外围 σ 高（Π 大）→ 单位距离跳数多 → 累积跳数差大 → 光谱偏红
3. [OIII]/Hβ 随 σ 变化（p=0.036 已在模拟数据中检出）

如果 P2 管道在线比检验中找到显著的相关性，这就是一个 ΛCDM 无法用"速度假设"解释的观测事实。
