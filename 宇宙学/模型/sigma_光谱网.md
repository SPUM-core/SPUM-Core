# σ：光谱相似网络中的空间密度 — 局域真空极化度 Π

> 在 ⟨P, ε⟩ 框架下，σ 是一个纯粹的图论量。但在物理投影中，σ 对应**局域真空极化度** Π——真空被"掰弯"了多少的读数。
>
> 物理接口：σ ↔ Π（局域真空极化密度）→ n(σ)（真空折射率）→ ∇n（折射率梯度 → 引力场的读数；引力本体是空间流）
> 详见：`地基/SPUM-以太映射.md`

---

## 图论定义

对由光谱指纹向量构建的 ⟨P, ε⟩ 子网：

```
P = {S_1, S_2, ..., S_n}     # 每条光谱是一个节点
ε = {(i,j) | cos(S_i, S_j) > θ}  # 相似度高于阈值的连边
```

**全局 σ**：σ_global = |P| / |ε|，整个连通分量的节点数与边数之比。
**局部 σ**：σ_local(i) = |P_i| / |ε_i|，节点 i 的一阶邻域子图。

## 物理投影：局域真空极化度 Π

| 图论量 | 物理量 | 含义 |
|--------|--------|------|
| σ 高（稀疏） | Π 高 → 真空极化强 | 空间单元排列松散 → 折射率大 |
| σ 低（密集） | Π 低 → 真空极化弱 | 空间单元排列紧密 → 折射率小 |
| ∇σ ≠ 0 | 真空极化梯度 | 折射率空间变化 → 光路径弯曲 |

## 真空折射率 n(σ)

```
n(σ) = σ / σ₀    （第一原理推导，见 模型/折射率第一原理推导.md）
```

### 推导概要

从三条 SPUM 公理导出（详见 `模型/折射率第一原理推导.md`）：

```
A1: 光子 = 移动拓扑缺陷（spum-core.md）
A2: 光速 c = 4κ/τ（spum-core.md）
T1: τ ∝ σ（帧周期因悬挂端数量正比于 σ）
T2: c(σ) = c₀ · σ₀/σ
T3: n(σ) = c₀/c(σ) = σ/σ₀
```

**与旧形式 n = 1 + βσ 的关系**：
```
n(σ) = σ/σ₀ = 1 + (σ - σ₀)/σ₀ = 1 + βΔσ
```
其中 β = 1/σ₀。β 不是自由参数——是参考密度 σ₀ 的倒数。

**物理含义**：
- 高 σ 区域：σ > σ₀ → n > 1（真空极化强 → 折射率大 → 光速慢）
- 低 σ 区域：σ < σ₀ → n < 1（真空极化弱 → 折射率小 → 光速快）
- σ = σ₀ 区域：n = 1（参考真空，光速 = c₀）

## σ 与帧周期

```
τ ∝ σ ∝ Π
```

- 高 σ（高 Π）→ 帧周期长 → 本征频率低 → 该处写入链的 σ 记录偏大 → 谱线红端偏移
- 低 σ（低 Π）→ 帧周期短 → 本征频率高 → 该处写入链的 σ 记录偏小 → 谱线蓝端偏移

**与以太理论的差别（一处必须纠正）**：以太理论说"光经过高极化区后波长被拉长"——这是**单光子变化**范式，SPUM 不接受。光子不被介质改造，它只是链的载体：每跳追加一条局部 σ 记录，整条链的记录总和构成红移读数。以太的"折射率梯度"在 SPUM 中保留为**局部**读数（n(σ) = σ/σ₀），但红移的通式是累积跳数差，不是"光子被拉长"。
