## 一、核心立场（局部尺度）

### 1.1 基础声明

SPUM 宇宙学建立在以下三个不可约公理之上：

1. **星系团/星系 = ⟨P, ε⟩ 子网**。不存在"时空容器"——星系的分布及其内部结构是空间粒子网络的拓扑呈现。星系团是网络中拓扑自洽的子图，拥有本征的 σ 分布、环基数 μ、代数连通性 λ₂、晶子密度 ρ_κ 等拓扑参数。

2. **光谱观测是子网间的拓扑耦合读数**。我们所获取的每一个光谱，是两个星系子网（本地子网 × 目标子网）之间的耦合读数。红移中一部分可能反映两者 σ 的差异。

3. **局部 σ 差异是可检验的**。同一个星系团内部不同区域 σ 不同，这导致同一团内不同星系的本征红移差异。此预言已在 10 个星系团中得到验证。

### 1.2 当前不假设

以下内容**不**作为当前框架的预设：

| 不假设的内容 | 原因 |
|-------------|------|
| 宇宙是膨胀的还是收缩的 | 全局动力学数学不自洽（见矛盾一、三） |
| 红移公式 z = σ_source/σ_obs - 1 可扩展到宇宙学尺度 | 与全局 σ 演化冲突（见矛盾一） |

| 多中心收缩可产生哈勃流 | 矢量几何不兼容（见矛盾三） |

### 2.4 晶子密度 ρ_κ：集中度的 L0 定义（v3.2 新增）

> 本小节定义一个新 **L0 量**——晶子密度 ρ_κ = 晶子数量 / 节点数量。它位于 L0 本体层（纯组合计数），不涉及任何投影算子，故**不受本节"投影映射待定义"状态约束**——定义在单帧内即可检验。其动力学角色单独声明（见"状态声明"）。

**定义（L0 组合）**：

- **晶子节点集**（饱和节点集）：P_κ = {v ∈ P : deg(v) ≥ deg_sat}，deg_sat = 50。
  - 阈值来源：T8 临界直径 D_max = 4κ → 表面积容量 16π ≈ 50.3 → 整数化 50（OpenSPUM `CRYSTALLITE_DEGREE_THRESHOLD = 50`）。度数达此阈值的节点即晶子——抵达三维密堆拓扑硬上限的饱和终极形态。饱和判定**只依赖度数**：ρ_κ 是纯结构量，与节点所在结构是否闭合/锁闭无关——光子的晶子同样计入 |P_κ|（见下"晶子数量-质量关联"的光子例外）。
- **全局晶子密度**：ρ_κ = |P_κ| / |P|。
  - 语义：网络中已晶化节点的占比——**集中度**的 L0 读数。集中（净湮灭效应）使晶子持续富集，ρ_κ 升高是其 L0 指纹。
- **局域晶子密度**：ρ_κ(v) = |P_κ ∩ B(v, r)| / |B(v, r)|，B(v, r) = {u ∈ P : d(u, v) ≤ r} 为 r 跳球（L0 组合定义，无几何预设）。
  - 语义：v 的 r 跳邻域内晶子占比——局域集中度场。
- **晶子密度梯度**：∇ρ_κ(v) = 沿边比较邻域 ρ_κ 的离散差值——与 ∇σ 同构的离散梯度定义（火形语义的第二个载体）。

**归约链**：ρ_κ → |P_κ|/|P| → deg(v) ≥ 50 的计数 → deg(v) = 出边计数 → 边 = 排他性确认事件（A2）。全程 L0：无连续、无几何、无概率。

**与 σ 的关系（互补，不可互相归约）**：

| 量 | 定义 | 度量对象 | 高值语义 |
|----|------|---------|---------|
| σ | \|P\|/\|ε\| | 整体稀疏度（平均度数 2/σ） | 连接稀疏、帧周期长 |
| ρ_κ | \|P_κ\|/\|P\| | 饱和子集占比 | 晶子富集、集中度高 |

晶子富集区（高 ρ_κ）内部关系饱和——低 σ 核心；净湮灭在核心外围提升 σ（关系外排）。ρ_κ 刻画"已锁死的部分"，σ 刻画"整体松紧"。二者方向语义不同：∇ρ_κ 定位集中源（饱和节点），∇σ 规定密度流向（高 σ → 低 σ）。**ρ_κ 不是 σ 的替代，二者共同构成集中过程的两个 L0 读数。**

**可截取性与可对比性（ρ_κ 独有，σ 不具备）**：

- ρ_κ 是**纯节点计数比率**——分子 |P_κ ∩ B| 与分母 |B| 均为节点成员资格计数，饱和判定使用全局度数（压缩为节点属性）。任意区域 B（任意 r 跳球、任意子图、任意连通分量）都可截取计算，且**截取封闭（cut-invariant）**：数值不依赖区域边界处理约定。
- σ = |P|/|ε| 依赖**边计数**，边是二元关系、横跨区域；截取必然切断跨边界边，|ε ∩ B| 取值依赖边界约定（算入/不算入），σ_B 非截取不变——σ 仅定义于自然划分（全局/连通分量）之上。
- 后果：ρ_κ 支持"任意截取 + 跨区域对比"的采样检验协议（如核心 vs 外围 ρ_κ 直接可算），σ 无此能力。这是 ρ_κ 可检验性的第二层支撑（第一层：单帧内由度数分布直接可算）。

**状态声明**：ρ_κ 的**定义**在 L0 层面完成（单帧内由度数分布直接可算）。其**动力学角色**（如"补位流沿 ∇ρ_κ 指向晶子富集区"）为待验证命题，本版本不作断言——纳入预言清单前须经帧演化模拟确认（与"三大矛盾"同样的审慎标准）。

**认知投影：ρ_κ 的现实意义（v3.2 补充）**：

- ρ_κ 是 L0 纯组合计数，**无直接观测对应**——现实中没有任何仪器能直接数"晶子数量/节点数量"。其现实意义完全经由认知投影（L0→L2）实现（宇宙学方法论：L2 桥接优先，见 §2.5）。
- 投影映射：
  | ρ_κ 的 L0 读数 | L2 可测物理量 | 投影路径 |
  |---|---|---|
  | 高 ρ_κ（饱和占比高） | 质量密度高 | m = κ_q·\|P_κ\| |
  | 高 ρ_κ（晶子密集） | 空间致密、体积密度大 | 节点体量 ρ(v)=φ(deg)，晶子 = 最大体量 |

**晶子数量-质量关联（v3.2 补充，投影待标定）**：

晶子数量可关联质量概念——精确形式为质量与晶子数量成正比：

$$m = \kappa_q \cdot |P_\kappa|$$

- m = 质量，|P_κ| = 晶子数量，κ_q = **晶子质量子**（每晶子的锁闭动能当量，L0→L2 投影常数）。
- 局域质量密度（节点粒度均匀时）∝ ρ_κ(v)——晶子占比即归一化质量密度。跨尺度表中 ρ_κ 的单调递减因此获得物理意义：核物质密度（原子核 ρ≈1）到宇宙平均密度（星系团 ρ≈10⁻¹²）约 18 个数量级差距的量级吻合。

内部自洽证据：
1. **静质量 = 被锁闭的动能**（物质定义）。锁闭 = 关系饱和 = 晶子。质量 ∝ 锁闭量 ∝ 晶子数量——定义层面的直接对应。
2. **12 晶子闭环 = 核子质量基本单元**。正二十面体闭环是第一个无缺口稳态，即质子/中子的刚性支撑——κ_q 的天然锚点（数值需实验标定质子晶子数）。
3. **等效原理的 L0 起源**：引力质量（净湮灭强度 ∝ 集中度 ∝ |P_κ|）与惯性质量（锁闭动能 ∝ |P_κ|）同源于晶子数量 → m_g = m_i 是同一 L0 源的必然，而非巧合。

两处待标定/边界情形：
- **κ_q 恒等性假设**：晶子 deg ≥ 50 但度数可不同（50 vs 60），一阶取"每晶子等量锁闭"，精确形式可能需按过饱和度加权求和。
- **光子例外（ρ_κ 与 m 的边界划清）**：光子含**晶子**（饱和节点）且**计入 ρ_κ**——ρ_κ 是纯结构量，与所在结构是否闭合/锁闭无关，只问是否饱和。光子无锁闭（关系流永不停歇）→ 不计入 m。故 **m ∝ 锁闭的晶子数量**（质量子集 ⊂ 晶子集合），非全部节点；而 ρ_κ 计数晶子全集（含光子晶子）。

**层级属性**：|P_κ| → m 是 **L0 → L2 投影关系**（与 §2.2 三大矛盾同属投影映射层），非 L0 内定义——按审慎标准标注"投影待标定"，不构成断言。

**m₁、m₂ 为划定计数（v3.2 补充）**：

- **核心命题**：牛顿引力公式中的 m₁、m₂ 不是物自体内禀常数，而是**观察者划定区域 A 的内容计数**：m(A) = κ_q·|P_κ^锁闭 ∩ A|。划定边界不同 → 计入的锁闭晶子集合不同 → m 不同。
- **划定边界依赖（从超市到土星）**：
  - 超市称重：注水猪肉（注水 = 划入水）、摘取菜叶（排除叶）、绑螃蟹的草绳（捆绑物是否划入）——称重结果是"划定内容"的计数，不是"猪肉本质"。
  - 土星质量：土星本体 vs 土星系统（环是否划入）——质量数值依赖观测者划定的范围。
- **本体 vs 投影**：物自体层面，区域 A 内锁闭晶子集合 P_κ^锁闭 ∩ A 是客观事实；现象层面，观察者选择 A 的边界——m 的数值是划定的结果。牛顿把划定结果误认为内禀属性，是"实体优先于关系"的残留。
- **温度仅作类比，不构成预言**：内部热状态（σ 分布）改变度数分布 → 可能改变晶子计数——方向性机制成立，但"温度 → 绝对质量"的定量推导未完成（含热运动对锁闭判定的影响），本版本不作断言。

**净湮灭强度与内外之分（v3.2 补充）**：

- **晶子的角色**：晶子 = 占据关系容量且无法消化湮灭的因素（deg = D_max = 4κ 容量满，湮灭无法通过新增关系补偿）。区域内晶子数量共同决定该处**净湮灭强度**：N(A) ∝ |P_κ ∩ A|。
- **内外之分（现象层，观察者划定）**：任意观察者从其锚点划定区域 A（r 跳球/可达子图），净湮灭强度强侧为"内"（集中/引力源侧），弱侧为"外"（被拉入侧）。**二体、多体引力均为观察者划定**——牛顿/GR 描述的正是观察者坐标系下的净湮灭场，这是桥接现有理论的关键。
- **与几何拓扑的分层（本体 vs 投影）**：几何拓扑的闭合曲面内外（χ=2、12 晶子闭环）属于**物自体范畴**——客观拓扑事实，与观察无关；引力内外由观察者划定行为 + 晶子计数共同产生，属**现象层**（L1/L2 投影）。二者**结构同构但本体论地位不同**：前者是"结构是什么"，后者是"观察者看到什么"——不可混同（"异曲同工"止于结构相似）。
- **判定可截取性**：N(A) 与 ρ_κ 一样只依赖区域内晶子计数，内外判定继承可截取性——任意观察者可局域完成（饱和 = 可观察的拒绝新连接行为，无需全局度数知识）。

### 2.5 自主运动与星系旋转的拓扑起源（演化方向，待验证）

> **方法论声明（v3.2）**：宇宙学子网的 L2 认知层权重增大，不严格执行 L0 本体规约——与观测事实桥接优先，未完全规约的节点作为演化方向明确列出。这是 SPUM 宇宙学的科研方法论。

**核心命题（替代中心驱动）**：星系旋转不是被中心质量"拉着"绕转的轨道运动，而是**自主运动**——每个节点沿自身所在处的局部空间密度差决定运动方向，没有谁在"拉"谁。

**机制三步**：
1. **驱动（多米诺效应）**：任一区域空间密度不均均引发多米诺效应——局部 σ 差异 → 度数差 → 节点连接重组 → 级联传播。这是毛球定理引入的关键：无数局域级联在球面拓扑上自组织为整体结构。
2. **偏转（排他性约束 A2）**：中心区密度极高、节点饱和——径向邻接位被排他占据，径向推进被堵死；密度梯度仍在，节点沿等势面切线方向"滑"。
3. **组织（毛球定理）**：星系 σ 场为球形包络 → 等势面 = 同心球面（S²，χ=2）→ 节点切向运动向量构成等势面切向量场 → 连续切场必有零点、零点指数和 = 2 → 旋转在拓扑上不允许不存在。

**"允许"与"实现"分离**：
- 允许（必要性）= 毛球定理：拓扑排除无零点连续切场——"不是被驱动的，是被允许的"
- 实现（充分性）= 多米诺级联 + 排他性偏转的自组织 → 整体涡旋【待帧演化模拟确认】

**与观测的桥接**：
- 平坦旋转曲线：v = k·|∇σ_切向|，盘面 σ_disk(r) = σ₀ + c·r（线性增长）→ |∇σ_disk| ≈ const → v(r) ≈ const【待 SPARC 175 拟合 c、k】
- 一致旋转方向：由 σ 场对称破缺决定——每星系独立随机（与"星系旋转方向无整体手性"的观测一致）；一致性 = 同一 σ 场 + 等势面层间耦合
- 银心零点与质量集中**分离**：旋转零点（球对称使毛球零点固定于中心）+ 质量集中（净湮灭峰，m = κ_q·|P_κ|）共因重合；S2 等近核高速轨道为质量集中点周围的局部强梯度现象，不同尺度并存——黑洞口径内为"中心驱动"有效域，其外为自主运动域

**未完全规约节点（演化方向）**：
1. v = k·|∇σ_切向| 的 k、c——待 SPARC 数据标定
2. 等势面层间耦合强度（一致性维持机制）
3. 自组织实现性的帧演化模拟验证
4. 与已验证子图协动（SPARC 94.3%）的关系：并列/分工待定
