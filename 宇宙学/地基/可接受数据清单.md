# 可接受数据清单

> 定义 SPUM 宇宙学分析中哪些数据是"地基干净"的。
> 原则：望远镜直接测量 → 可接受。包含模型假设 → 不可接受。

---

## 可接受（直接观测或仪器校准）

| 数据 | 来源 | 说明 |
|------|------|------|
| CCD 像素通量 | SDSS 原始图像/光谱 FITS 文件 | 以 ADU 或已标定 flux 为单位 |
| 波长阵列 | FITS 头文件中的波长校准系数 | 实验室光源标定，不涉及宇宙学假设 |
| RA/Dec 指向 | 望远镜指向或 FITS 头文件 | ICRS 国际天球参考系 |
| MJD 时间戳 | FITS 头文件 | 太阳系质心时，不涉及宇宙时 |
| 曝光时间 | FITS 头文件 | 积分时间，秒 |
| 光纤/狭缝位置 | FITS 头文件 | 仪器几何配置 |
| 天光光谱 | 同时采集的天光纤 | 用于背景扣除，不含模型 |
| 标准星光谱 | SDSS 标准星观测 | 通量标定依赖——标记为"待 SPUM 校准" |
| 大気消光曲线 | 站点测量 | 站点的实测消光曲线，不涉及宇宙学 |

## 不可接受（含 ΛCDM 或其他模型假设）

| 数据 | 来源 | 含有的假设 |
|------|------|-----------|
| **红移 z** | SDSS specObj 管线 | z = 速度→距离的整个 ΛCDM 框架 |
| **退行速度 (km/s)** | 从 z 换算 | 同一假设 |
| **谱线拟合参数** | SDSS 谱线测量管线 | 拟合时使用模板谱的波长是 ΛCDM 红移校正后的 |
| **星族年龄** | 星族合成模型 | 依赖恒星演化模型和恒星大气模型 |
| **金属丰度** | 谱线强度比 | 依赖同一套模型 |
| **光度距离** | 从 z 计算 | 需要 H₀ 和 ΛCDM 宇宙学参数 |
| **绝对星等** | 视星等 - 距离模量 | 需要光度距离 |
| **暗物质晕质量** | 从动力学质量推算 | 需要 ΛCDM 引力理论 |
| **速度弥散 (km/s)** | 从谱线展宽计算 | 假设展宽 = 多普勒 = 速度 |
| **环境密度 (Mpc⁻³)** | 从 3D 位置计算 | 需要光度距离→需要 z→需要 ΛCDM |

## 灰色地带（标记使用条件）

| 数据 | 问题 | 在 SPUM 中的处理 |
|------|------|-----------------|
| SDSS 的"星/星系"分类 | 形状分类本身不依赖 ΛCDM，但训练数据有偏 | 直接使用形状分类，不排除任何结果 |
| 通量绝对标定 | 依赖标准星大气模型 | 接受作为仪器标定，标注"待 SPUM 校准" |
| 大气折射校正 | 依赖大气模型 | 接受，不涉及宇宙学 |
| 谱线模板 | 依赖实验室测量 | 接受（实验室光谱是量子力学数据，非宇宙学） |
| 银河消光校正 | 依赖银河尘埃模型 | 标记使用版本，记录校正量和不确定度 |

## 在原始数据管线中的过滤规则

加载 SDSS 光谱时，以下字段**禁止读取**：
- `z` （任何形式的红移）
- `z_err`
- `z_warning`（因其定义基于 z 框架）
- `v_disp` / `vel_disp`
- `class`（SDSS 的光谱分类包含红移假设）
- `subclass`
- `snMedian`（信噪比可以读取，但不用来过滤）

**仅读取**：
- `flux`（通量数组）
- `loglam` / `wavelength`（波长数组）
- `ra`, `dec`
- `mjd`, `plate`, `fiberID`（身份标识）
- `spectroflux`（可选，仅使用未校正值）
