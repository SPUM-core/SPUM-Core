# 光谱指纹管道规范

> 从 SDSS 原始光谱到光谱指纹向量的完整处理流程。
> **关键约束**：用于计算 σ 的光谱指纹**必须不依赖于谱线的绝对像素位置**。

---

## 核心约束：σ 的独立性问题

待检验的 SPUM 预言是：**σ 的差异导致谱线偏移**。

这意味着 σ 和谱线偏移必须是**独立测量的量**——如果 σ 本身就来自含谱线位置信息的光谱特征，那么 σ 与谱线偏移的相关性就是内禀耦合，不构成独立验证。

**约束规则**：
```
σ ← 仅来自连续谱形状（不含窄线信息）  ← 独立变量
谱线偏移 ← 来自窄线的重心位置           ← 被解释变量
```

不允许将同一组数据（含谱线的全谱型）同时用于 σ 计算和偏移测量。

---

## 输入/输出

```
输入：SDSS 原始光谱 FITS
  │  flux 数组（已标定，counts/s 或 10⁻¹⁷ erg/cm²/s/Å）
  │  loglam 数组（对数波长，Å）
  │  ra, dec
  │  mjd, plate, fiberID
  ▼
输出：两个独立的光谱指纹
  ├─ 指纹_A（连续谱）：用于 σ 计算
  └─ 指纹_B（全谱）：  用于谱线偏移测量
```

## Step 1：加载与验证

**规则**：不加滤 ΛCDM 值。

```python
# 正确的做法
flux = hdu['FLUX'].data           # ✅ 原始仪器输出
wavelength = 10 ** hdu['LOGLAM'].data  # ✅ 波长校准
ra = hdu['RA'].data
dec = hdu['DEC'].data
# 不读：z, z_err, class, subclass, veldisp
```

## Step 2：波长统一重采样

每条光谱采样网格不同。所有指纹向量必须对齐到同一波长网格。

```
λ_grid = [3800, 3800 + Δλ, ..., 9200]  （Δλ = 1Å）
```

对每条光谱的 flux 做线性插值到 λ_grid。

## Step 3：双通道分流

这是整个管道的核心设计。一条光谱产生两个独立指纹：

```
原始光谱 flux(λ)
    │
    ├──→ [高斯平滑 σ=150Å] → 连续谱 → 归一化 → 谱段bin → 指纹_A（连续谱指纹）
    │                                                               ↓
    │                                                         用于 σ 计算
    │
    └──→ [原始通量] → 归一化 → 谱段bin → 指纹_B（全谱指纹）
                                                                  ↓
                                                           用于谱线偏移测量
```

### 指纹_A：连续谱（σ 的输入）

**目的**：捕获光谱型（早型/晚型），消除所有窄线信息。

**方法**：对通量做高斯平滑，σ_smooth = 150Å（远大于典型谱线宽度 2-20Å）。

```python
from scipy.ndimage import gaussian_filter1d
flux_continuum = gaussian_filter1d(flux_interp, sigma=150 / Δλ)
```

150Å 的平滑核确保：
- 窄发射线（Hα FWHM ~2-5Å）完全被抹平
- 宽吸收线（CaII H&K FWHM ~20-30Å）也被抹平
- 连续谱的大尺度形状（幂律斜率、4000Å 跳变）保留

**归一化**：`flux_continuum_norm = flux_continuum / ∫flux_continuum dλ`

**谱段 bin**：将 3800-9200Å 划分为 50 个宽 bin（每个 108Å 宽），bins 足够宽使谱线偏移（典型值 ~1-3Å）不会显著改变任一个 bin 的值。

```
指纹_A = [μ_bin_1, μ_bin_2, ..., μ_bin_50]   ← 仅含连续谱形状
```

### 指纹_B：全谱（谱线偏移的输入）

**目的**：保留线信息用于谱线重心测量。

**方法**：不做平滑，直接归一化后 bin 降维。

```python
flux_full_norm = flux_interp / ∫flux_interp dλ
```

**谱段 bin**：200 个 bin（每个 ~27Å 宽），保留足够分辨率以定位谱线。

```
指纹_B = [μ_bin_1, μ_bin_2, ..., μ_bin_200]   ← 含窄线信息
```

---

## Step 4：独立检验

在 σ 与谱线偏移做相关性检验之前，必须先验证 σ 与谱线偏移之间的独立性预设成立：

**独立性检验** — 构造一个人工"伪偏移"测试：
```
1. 随机打乱光谱之间的位置标签
2. 用打乱后的数据重新计算 σ 与谱线偏移的相关性
3. 如果真实数据的 ρ 显著大于打乱后的 ρ 分布
   → 信号真实
4. 如果打乱后的数据也产生相似的 ρ
   → σ 与偏移之间存在内禀耦合，管道设计失败
```

## 数据输出格式

```python
光谱指纹数据集 = {
    "metadata": [
        {"ra": ra_i, "dec": dec_i, "mjd": mjd_i, 
         "plate": plate_i, "fiber": fiber_i}
    ],
    "fingerprint_continuum": [S_i],    # → σ 计算
    "fingerprint_full": [S_i],         # → 偏移测量
    "continuum_smoothed": [flux_i],    # 平滑后的连续谱
    "wavelength_grid": lambda_grid,
}
```

**不包含**：z, class, subclass, 任何 SDSS pipeline 宇宙学输出。
