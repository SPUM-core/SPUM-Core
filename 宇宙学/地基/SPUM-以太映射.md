## 四对核心映射

### 映射一：σ → 局域真空极化度

| 概念 | SPUM 原名 | 新名称 | 定义 |
|------|-----------|--------|------|
| 基本量 | σ = \|P\|/\|ε\| | **局域真空极化度** \( \Pi \) | 图密度 → 真空极化密度 |
| 高值 | 高 σ（节点多边少） | **高真空极化** → 折射率大 | 光速慢、单位距离跳数多 |
| 低值 | 低 σ（节点少边多） | **低真空极化** → 折射率小 | 光速快、单位距离跳数少 |

**对应**：
- 以太理论：真空极化密度 \( \rho_{vac} = \nabla \cdot \mathbf{P} \)
- SPUM：\( \Pi(\mathbf{x}) = \sigma(\mathbf{x}) = |P|_{\mathbf{x}} / |\varepsilon|_{\mathbf{x}} \)
- **物理含义**：局域拓扑密度 = 局域真空极化程度。σ 不再是一个图论数字——它是真空被"掰弯"了多少的读数。

### 映射二：∇σ → 真空折射率梯度

| 概念 | SPUM | 新名称 | 公式 |
|------|------|--------|------|
| 空间变化 | ∇σ | **真空折射率梯度** ∇n | n(σ) = σ/σ₀ |
| 引力 | 净湮灭效应 | **极化梯度力** | F ∝ −∇n |

**对应**：
- 以太理论：\( n(\mathbf{x}) = \sqrt{\varepsilon(\mathbf{x})\mu(\mathbf{x})} \)
- SPUM：\( n(\sigma) = \sigma/\sigma_0 \)（**从公理推导，零自由参数**）
- 谱线偏移：\( z \propto [\Delta N(r_s) - \Delta N(r_o)] \)，\( \Delta N(r) = \int_r^\infty[\sigma(r')-\sigma_0]dr' \)（链上累积跳数差的读数；两端 σ 之比只是退化取值）
- **引力不再是时空弯曲**——它是净湮灭驱动的空间流（介质本地移动）；真空极化梯度（σ 梯度）是它的稳态**读数**。

### 映射三：谱线偏移 → 光子数据链的累积读数

| 概念 | SPUM 原名 | 新名称 |
|------|-----------|--------|
| 红移 | Δλ/λ = f(ΔN) | **光子数据链的聚合读数** |
| 空间膨胀 | 帧周期差异 | **链上逐跳追加的 σ 记录累加** |

**对应**：
- 以太理论：真空折射率变化 → 光波长变化（**单光子变化范式——SPUM 不采用此读法**）
- SPUM：\( z \propto [\Delta N(r_s) - \Delta N(r_o)] \)（完整推导见 `模型/折射率第一原理推导.md`）
- **红移不是膨胀，也不是"光在途中被拉长"**——光子在发射端封装完毕、途中不被介质改造（不拉伸、不失能）；它是数据链的载体，每跳向链上追加一条局部 σ 记录，整条链的记录总和构成红移读数。**红移定义在链上，不定义在单个光子上。**

### 映射四：σ 场 → Einstein-Æther 场（可计算版）

| 概念 | Einstein-Æther | SPUM σ 场 |
|------|---------------|-----------|
| 基本量 | 单位矢量场 u^a | 标量场 σ(x) 及其梯度 ∇σ |
| 动力学 | 由作用量决定 | 由帧演化规则决定 |
| 洛伦兹破缺 | 假设 | ∇σ = 0 恢复洛伦兹对称性 |

**关键优势**：Einstein-Æther 理论中的 Æther 场 u^a 有 4 个自由度，需要手动选择 Lagrange 量。SPUM 的 σ 场只有 1 个自由度（标量密度），它的梯度 ∇σ 由帧演化自动产生——不用假设、不用调参数。且 n(σ) = σ/σ₀ 从第一原理推导，无自由参数。

## 迈克尔逊-莫雷实验 = 子图协动的证据

> 这是 SPUM 对 20 世纪物理学最大误读的正式纠正。
> MM 实验不是对空间介质的否定——**它是子图协动的直接验证**。

### 实验的真正逻辑

MM 实验寻找的是**以太风**（地球在静态以太中的绝对运动），发现的是**零条纹偏移**（零结果）。

```
前提：存在一种静态、均匀、具有单一全域参考系的以太介质
假设：地球穿过这种介质运动 → 光速在不同方向上有差异
实验：测量光速各向异性
结果：零条纹偏移
```

| 步 | 解读分支 | ΛCDM 接受 | SPUM 接受 |
|:--:|----------|:----------:|:---------:|
| 1 | 否定了静态均匀以太 | ✅ | ✅ |
| 2 | → 不存在任何空间介质（逻辑跳跃） | ✅ | ❌ |
| 2' | → 往返读数对 ∇σ 精确盲；且局部子图的度量偶部近乎不变 | ❌ | ✅ |

**ΛCDM 从 1→2 的跳跃正是其地基裂缝所在。** 一个实验否定了特定模型，不等于否定了该模型所属于的整个类别。

### SPUM 的完整推理链

```
1. 硬约束：往返盲定理（几何学/Finsler几何/spum-Randers度量.md §1.4 推论 R1）
   F(v) + F(−v) = 2√(g_ij v^i v^j)
   → b_i ∝ ∇σ 是度量奇部，在任何"配对累加"读数中精确相消
   → 即使局部 ∇σ 很大，MM 型往返实验仍读不到各向异性

2. 辅助：地球及其局部实验室 → 高度连接、密集的局部子图
   高 |P|，低 |ε| → 均匀 σ（局域真空均匀极化）
   → 连度量偶部 g_ij 的局域空间变化也很小

3. 光子传播不依赖于"绝对速度"
   它依赖于路径上链的累积 σ 记录

4. 两条理由叠加 → 光在所有方向上往返时间相同 → **零条纹偏移 = 正确结果**

5. 因此，MM 的零结果不否定全局空间介质
   它验证的是：往返读数对 ∇σ 完全盲（推论 R1）+ 局部子图在度量偶部上的均匀性
   在星系团尺度上，σ 梯度以累积跳数差的形式可测 → 谱线偏移可测
```

**逻辑枢纽**：MM 测的是度量**偶部** g_ij 的局域均匀性，**对奇部 b_i = ∇σ 完全盲**——零结果不是对 ∇σ 的测量，与 ∇σ 大小无关。零结果说明局域均匀，不否定全域存在。

## 相对论导向的研究为何不可信

> 这不是否定相对论在工程上的有效性——GPS 和粒子加速器都依赖它。这是断言：相对论作为宇宙学的基础框架，已经走到了自身假定边界的极限。继续以它为基础推进宇宙学研究，是在重复修补一个越补越大的裂缝系统。

### 核心分歧：几何 vs 介质

| | 广义相对论（GR） | SPUM |

| 基本对象 | 度规张量 g_μν（弯曲流形） | σ 标量场（网络密度投影） |
| 红移解释 | 空间膨胀（尺度因子 a(t)） | 光子数据链的累积跳数差（链上读数，非光子自身变化） |
| 自由参数 | GR 本身 2 个 + 暗物质 + 暗能量 = **4+ 自由参数** | 1 个（σ），由数据自然涌现 |

### 暗物质 + 暗能量 = GR 的"本轮"

哥白尼时代的天文学用"本轮"（epicycles）来修补地心说与观测的偏差。每发现一个新的行星运动异常，就在已有的圆周上叠加一个更小的圆周。

GR 宇宙学的暗物质 + 暗能量做着完全相同的事：

```
观测：星系旋转曲线平坦 → 补丁① 暗物质（存在但不发光）
观测：宇宙加速膨胀 → 补丁② 暗能量（存在但不理解）
观测：ΛCDM 参数无法从第一原理推导 → 暗物质是什么？暗能量是什么？
→ 补丁③ 候选粒子搜索（WIMP、轴子……40 年未发现）
→ 补丁④ 修改引力（MOND、f(R)……）
```

每次都在已有的几何框架上叠加一个新的"本轮"。每个补丁都有观测证据（否则不会被接受），但补丁之间没有逻辑联系。**四个彼此独立的自由参数（Ω_m, Ω_Λ, H₀, σ₈）在同一张图上拟合，这不是"验证"，是过拟合。**

### SPUM 的替代

SPUM 用一个标量场 σ（及其梯度 ∇σ）取代 GR 的三个自由参数：

| GR 需要的假设 | SPUM 需要的假设 |
|--------------|----------------|
| 暗物质粒子（存在但不发光） | σ 梯度∇σ 取代引力（从 ⟨P, ε⟩ 帧演化自动产生） |
| 暗能量（宇宙常数 Λ） | 不需要——红移是链上累积读数，非膨胀 |
| 弯曲几何（g_μν 10 个分量） | 不需要——π 是认知投影，非宇宙固有常数 |

**不存在"暗物质粒子"需要寻找。不存在"暗能量密度"需要测量。不存在"时空曲率"需要张量微积分。** 只有一个图论量 σ = |P|/|ε|，从光谱数据自身算出。

### 方法论判断

1. **GR 在工程精度上有效**。GPS、粒子加速器、引力透镜计算——在这些尺度上 GR 的几何近似足够好。SPUM 不否定这一点。

2. **GR 作为宇宙学框架已经走到了自己的边界外**。奇点、暗物质、暗能量、量子引力不可重整化——这些都是"框架外"的信号，不是"待解决的难题"。

3. **SPUM 是对 GR 的替代，而非修正**。SPUM 不从 GR 继承任何几何假设。它从更基础的 ⟨P, ε⟩ 出发，在宏观极限下恢复牛顿引力和 GR 的局部有效——就像牛顿力学在高速极限下被相对论取代，但基础假设不同。

4. **"以相对论为导向"意味着以 GR 的几何预设为前提来提问**："暗物质粒子是什么？""暗能量的状态方程参数是多少？""暴胀的标量场势函数是什么？"——这些问题的形式本身预设了 GR 框架的有效性。SPUM 根本不同意这些问题的前提。
