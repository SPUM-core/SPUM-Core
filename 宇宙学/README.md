# SPUM 宇宙学

> **地基声明**：本模块不自 ΛCDM 继承任何解释。不读红移 z，不读速度弥散，不读距离模量，不读暗物质晕质量。所有分析从原始观测数据（CCD 像素阵列、波长校准、RA/Dec 指向）直接出发，在 SPUM 的 ⟨P, ε⟩ 框架内重新定义一切概念。
>
> **物理接口**：SPUM 不以"新理论"自居。SPUM 借用以太研究已成熟的数学结构（真空极化密度、折射率、介电常数、Æther 场），为 σ = |P|/|ε| 赋予物理直观。数学不变，解释力翻倍。详见 `地基/SPUM-以太映射.md`。
>
> 版本：v3.0（2026-07-09）— 地基重建版 + 以太数学接口

## 核心路线

```
原始光谱数据
    │  strip ΛCDM pipeline 输出
    ▼
光谱指纹向量 S_i = [flux_1, ..., flux_n]
    │  cos_sim(S_i, S_j) > θ → connect
    ▼
⟨P, ε⟩ 光谱子网
    │  σ = |P|/|ε|    ← 局域真空极化度 Π
    │  n(σ) = σ/σ₀    ← 真空折射率（从公理推导，零自由参数）
    │  ∇σ 梯度          ← 折射率梯度 = 等效引力
    ▼
σ 空间分布 → 谱线偏移梯度（SPUM 内生预言）
            ↓
    真空折射波长漂移：Δλ/λ = σ_src/σ_obs − 1
```

**不自 ΛCDM 继承任何量。** 每一步只使用：

| 使用 | 不使用 |
|------|--------|
| CCD 通量值 | SDSS Pipeline 红移 z |
| 波长校准（仪器公理） | 退行速度 |
| RA/Dec 指向 | 光度距离 |
| 曝光时间 | ΛCDM 宇宙时 |
| 谱线中心像素位置 | 任何 km/s 单位 |

## 检验逻辑

SPUM 宇宙学不自外部引入"正确性"标准。一个假设成立，当且仅当它能用原始光谱数据构造出一个自洽的 ⟨P, ε⟩ 子网，且该子网的内生结构（σ 分布）能解释光谱之间的系统性差异——不需要外部的 z 值作为锚定。

**检验一**：同一指向区域内，光谱指纹向量之间可构建连通子图，σ 呈现空间结构（非均匀）。
**检验二**：σ 高的区域，谱线重心系统性红移——方向与量级均由 σ 差异预测，非拟合得来。
**检验三**：不同激发态的谱线（Hα vs [OIII] 等）对 σ 的敏感度不同 → 线比变化可检验，ΛCDM 纯多普勒无此效应。

## 旧范式文件的处理

`旧/` 目录下的文件保留了原有内容，但**不作为当前宇宙学模块的执行依据**。它们记录了在 ΛCDM 框架内寻找 SPUM 信号的历史尝试。新分析不从这些文件中读取任何输入。
