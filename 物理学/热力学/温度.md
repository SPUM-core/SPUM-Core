# 温度

> SPUM 归约路径：局部邻接密度 ρₐ → 耦合频率 → 宏观温度 T
> 草稿来源：第十八章

---

## SPUM 定义

温度不是动能度量，而是**空间粒子网络局部密度状态的宏观回响**——空间粒子相互作用速率的宏观体现，该速率由局部邻接密度 ρₐ 直接决定。

## 温度的本体论重置

经典热力学：温度 = 理想气体分子平均平动动能 → 循环依赖质量与速度

SPUM 版本：
- 当单位体积内空间粒子数量增加 → 每个粒子平均可用体积被压缩
- 虚面被迫更频繁地与其他粒子发生拓扑耦合
- 耦合频率提升 → 在观测尺度上表现为"温度升高"

## 空间系数 η

```
η = V_avg / V_max
```

- V_max = 单个空间粒子在无邻接压力下的理论最大体积（绝对孤立态）
- η ∈ (0, 1]
- η 越小 → 空间越"拥挤" → 温度越高
- η → 1 → 系统趋近真空基态

## 温度公式

```
T = (1 − η) / η · κ + T₀
```

- T₀ = 绝对零度（η = 1 时的极限）
- κ = 拓扑响应常数，由空间粒子虚面弹性模量与联络张量本征尺度决定

温度不是能量的函数，而是**几何压缩比的单调映射**。

## 密度极限自然截断

当 η → 0（极端高密度），T → ∞，但物理上不会真正发散——κ 网络通过拓扑破缺（粒子湮灭或维度折叠）释放压力，形成自然截断。解释了黑洞奇点为何在 SPUM 中不存在。

## [L0] 本体论还原

温度 T = 局域 σ = |P|/|ε| 的倒数映射。高 σ（稀疏、每节点边少）→ 高 T；低 σ（密集、每节点边多）→ 低 T。"热"不是能量——是关系网络稀疏度的可观测表现。
