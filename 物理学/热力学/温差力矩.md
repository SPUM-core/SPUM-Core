# 温差力矩效应

> SPUM 归约路径：不对称空间抽运 → κ 网络全局拓扑失衡 → 净力矩
> 草稿来源：第二十二章（第十九章重复编号）

---

## SPUM 定义

任何**不对称的空间抽运操作**，必将产生指向抽离区的净力矩。力与温同源——皆是空間粒子网络在外部操作下发生非对称重构的宏观显化。

## 制冷本质的 SPUM 重构

制冷不是"移除热量"，而是通过外部做功**从特定区域主动抽离空间量**：

- 制冷作业面：虚面扩张，局部 κ 网络拉伸，空间粒子密度降低 → **空间抽离区**
- 散热作业面：被抽离的空间量注入 → κ 网络压缩，密度升高 → **空间注入区**
- 若两个操作面几何不对称 → κ 网络全局拓扑失衡 → **净力学反作用**指向抽离区

## 实验现象

| 现象 | 时间尺度 | SPUM 解释 |
|------|---------|----------|
| 通电 → 偏转 | <10 ms | 空间结构快速重构，非热传导（>100 ms） |
| 断电初期 → 持续偏转 | 短暂 | 压缩区储存的拓扑应变能尚未释放 |
| 多周期 → 共振 | 非线性 | 抽运与弛豫相位差激发系统共振 |
| 低压 → 衰减减缓 | — | 经典阻尼减弱，空间本征动力学主导 |

## 核心洞察

此力源于**空间本体的再分布**，而非能量传递。它不应随真空度升高消失，而应在无气体干扰时更清晰显现——装置结构本身就是 κ 网络中的刚性扰动源。

## 三大意义

1. **可观测**：毫秒级响应，方向稳定，可重复
2. **可工程化**：优化迁移面占比与几何布局
3. **本体论革新**：证明空间不仅是舞台，更是可被操作、可做功的参与者
