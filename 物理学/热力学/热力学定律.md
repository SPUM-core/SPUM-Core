# 热力学定律

> SPUM 归约路径：四大定律全部还原为拓扑守恒与变分原理的推论
> 草稿来源：第二十五章

## SPUM 定义

热力学四大定律不再是神秘的"自然法则"，而是**κ 网络拓扑结构的必然逻辑结果**。

## 四大定律的 SPUM 还原

### 第零定律（热平衡）

两个系统分别与第三个系统热平衡 → 彼此热平衡。

SPUM 还原：σ 密度趋同 = κ 网络连接重分布达稳态。热平衡 = 局域 σ 相等。

### 第一定律（能量守恒）

能量既不能创生也不能消灭。

SPUM 还原：宇宙总边数守恒（N008）。σ 涨落 + 虚面势能 + V⁺/V⁻ 事件 = 相互转换但总量锁定。

### 第二定律（熵增）

孤立系统熵永不减少。

SPUM 还原：不完美定理的统计表述——每帧必残留悬挂端 → 网络复杂度单调增加。"无序度" = 悬挂端分布的统计投影。

### 第三定律（绝对零度不可达）

SPUM 还原：η = 1 的拓扑冻结态被不完美定理锁定不可达。任何逼近都触发新的悬挂边产生。

## [L0] 还原

热力学四大定律 = 五步帧演化的必然推论：
1. 守恒律 → 第零 + 第一定律
2. 不完美定理（每帧残留悬挂端）→ 第二定律
3. 最小度数 ≥ 2（孤立不可存在）→ 第三定律
