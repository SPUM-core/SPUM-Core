# 宇宙演化

> SPUM 归约路径：κ 网络从高张力向低张力的整体松弛
> 草稿来源：第三十章 §30.4

---

## SPUM 定义

宇宙的演化 = **κ 网络在大尺度上的缓慢松弛过程**。宇宙膨胀、红移、CMB 冷却等现象皆可还原为 κ 网络的状态变化，无需"空间本身膨胀"的假设。

## 宇宙膨胀的替代解释

传统：空间本身膨胀 → 星系退行 → 红移

SPUM：
- κ 网络在大尺度上缓慢松弛（早期高张力 → 今日低张力）
- 光子 CES 穿越数十亿年 → 途中 κ 密度渐降 → 方向场被持续拉伸 → 累积红移
- **无需"空间膨胀"假设**，仅需 κ 网络历史演化

## 暗物质的替代解释

星系旋转曲线异常 → 传统推测不可见质量

SPUM：
- 星系外围 κ 网络可能因早期结构形成而保留残余高密度晕
- 此"κ 晕"不发光，但影响光子与物质运动 → 模拟暗物质效应

## 黑洞的替代解释

传统：时空奇点，事件视界

SPUM：
- 极端质量 → κ 密度极高 → 虚面树完全闭合
- 光子 CES 无法找到向外通道 → 被困于局部闭环
- **无奇点**，只有 κ 网络的极致压缩态

## CMB 冷却

大爆炸不是"能量爆发"，而是初始高密度拓扑态（η ≪ 1）的快速弛豫过程。随着宇宙 η 增大，T 下降——CMB 冷却曲线**无需"光子气体"假设**。

## 热寂否定

宇宙永无真正热寂。只要存在非平凡纽结结构（如星系尺度的链环拓扑），局部密度扰动将持续再生。熵增不过是拓扑复杂度在宏观尺度的统计投影。

## [L0] 还原

宇宙演化 = 全局 σ 的缓慢上升过程。早期 σ → 0（所有节点高度连接），随时间推移 σ 逐渐增大（不完美定理每帧产生悬挂端 → 边数净增长 → 节点平均度数下降 → σ 上升）。红移 = 边从早期低 σ 帧传播到当前高 σ 帧的过程中频率拉伸。CMB = 早期帧的残余边激发，其频率已被 σ 上升所稀释。
