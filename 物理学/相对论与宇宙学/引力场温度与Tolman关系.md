# 引力场温度与 Tolman 关系：ΔN 势场共源框架（v2.0）

> SPUM 归约路径：晶子源（核 = 晶子闭锁团簇）净湮灭抽离关系 → σ 盈余场 σ(r) = σ₀ + σ₁M̃/r² → 跳数势差 ΔN = ∫(σ−σ₀)dr ∝ M/r → 同一势场的三类读数：∇ΔN ≠ 0 = 引力、ΔN 差 = 红移、ΔN 读数 = 温度。
>
> **版本史**：v1.0（2026-09）把温度当作"局域 σ 的读出"，引入元素壳层透射 p 预言元素依赖温度差 δ，并构造 EDT 判别式对抗 Tolman。v2.0 作废局域读出——温度定义必须锚定可测量量，而 SPUM 中唯一可测的 L0 量是跳数势差 ΔN（红移的还原对象）。收敛结果：**温度、引力、红移共用一个 ΔN 势场**；单物种温度剖面与 Tolman 关系同形（不是对抗）；元素差 δ 在线性框架下 ≡ 0，整体搁置为开放项 O-δ（详论证见 [元素耦合与温度-势框架](../../元素化学/元素耦合参数推导：壳层透射p与温度偏差δ.md) v2.0）。
>
> 定位声明：本文自 v2.0 起为**确认型/归约型**文档——它统一温度/引力/红移到同一势场，不再声称与 GR 的可判别分歧；与 Tolman 的关系是"同形确认"。宇宙学 P2（谱线波长依赖）是传播路径效应（[SPUM宇宙学预言清单.md](../../宇宙学/模型/SPUM宇宙学预言清单.md) P2），不属本收敛范围，仍独立存活。

## 〇、核心命题（v2.0）

1. **共源**：温度、引力、红移是同一个跳数势差场 ΔN 的三类读数。ΔN 是 L0 累积量（可数），GR 的势 φ = GM/r 是它的宏观身份（[SPUM2611.md](../../SPUM2611.md) 第十节已为红移确立）。
2. **同形**：单物种温度剖面 T(P) = T∞·g(ΔN(P)) 在弱场自动满足 Tolman 关系 T√(−g₀₀) = const——不是新预言，是同一势场读数的必然。
3. **内禀**：温度场 = 质量（晶子）分布的唯一导出。地核热、恒星核心热不依赖外部辐射源——深（ΔN 大）即热。绝对零度 = 无源极限（开放项 O-背景，见 §五）。
4. **普适**：温度是普适势读数 → 同点不同元素必须同温（R5 形态）→ 元素依赖 δ ≡ 0（线性），只留 g 非线性二阶角落（O-δ）。

## 一、温度定义必须锚定可测量量

### 1.1 η 不可测

温度.md 定义 T = (1−η)/η·κ + T₀，η = V_avg/V_max（几何压缩比）。这是概念链（压缩 → 耦合频率 → 温度）的中间量，**没有任何可测对应**。温度的一切认知都是间接变化的投影（温度计、黑体谱、线强度比），定义不能断在概念层。

### 1.2 SPUM 唯一可测的 L0 量是跳数

仓库中温度最接近的可测先例是红移：谱线频率差 → 还原为跳数势差 ΔN（L0 可数，SPUM2611 §十）。若温度要与可测量挂钩，它必须挂在同一个 ΔN 上——没有第二个独立的 L0 可测量可供温度使用。

**锚定命题**：

$$T(P) = T_\infty \cdot g\!\left(\frac{\Delta N(P)}{N_0}\right),\qquad g(0)=1,\; g'>0$$

ΔN(P) = 测量点 P 处的跳数势差；N₀ = 特征跳数（标度，待锚 O-g）；T∞ = 无源极限读数（§五）。g 的形式是开放项 O-g——弱场线性归一（见 §四）是唯一已锚的性质。

### 1.3 内禀性：源自身的场

地球内部温度（地核 ~6000 K）、恒星内部温度（核心 ~10⁷ K）在没有任何外部辐射源的条件下存在——它们是**质量（晶子）分布自身的投影**。晶子源抽离关系使周围 σ 升高（[引力.md](../基本相互作用/引力.md) 引理 3：中心抽离最多、σ 最高），ΔN 向重心单调增大，温度随深度单调升。这就是"地温是地球的内禀属性"的 SPUM 表达：温度场不需要环境参数，T∞ 只是归一。

## 二、晶子源与 σ 盈余场

### 2.1 晶子 = 冻结源

- 晶子 = 饱和终极单元（度数达容量上限），占据空间、不参与空间变化（闭锁、零关系流交换——12 晶子闭环 = 暗物质）。
- 物质 = 晶子闭锁团簇（质子 = 12 永恒粒子，永恒粒子 = 多晶子锁定）。
- 每晶子对外产生**固定 12 单位拓扑需求**（[引力.md](../基本相互作用/引力.md)：∮nc dA = 12M̃/μ；12 是欧拉恒等式的强制解）→ σ 盈余场无自由参数。

### 2.2 盈余场

晶子源的净湮灭把关系抽走，周围空间粒子变小、σ 升高（[引力.md](../基本相互作用/引力.md) 引理 3 / 反例库 概念2）：

$$\sigma(r) = \sigma_0 + \frac{\sigma_1 \widetilde{M}}{r^2},\qquad \sigma_1 > 0$$

- 无晶子（M̃ = 0）→ σ ≡ σ₀：无盈余 → 无 ΔN 梯度 → 无温度结构（绝对零度极限，§五）。
- 晶子越集中（M̃ 大）→ 盈余场越强、等值面越远、梯度越陡——场强、程、陡峭度全部由晶子分布唯一决定（P3，见 §三注）。

## 三、ΔN 势场：引力、红移、温度三位一体

### 3.1 跳数势差

盈余沿路径的累积（L0 可数）：

$$\Delta N(r) = \int_r^\infty \big[\sigma(r') - \sigma_0\big]\,dr' = \frac{\sigma_1 \widetilde{M}}{r} \propto \frac{1}{r}$$

### 3.2 同一 L0 量的三类读数

| 读数 | 形式 | 现象身份 |
|------|------|---------|
| 引力 | ∇ΔN ≠ 0（势的梯度） | 定向运动因（SPUM 无"力"，只有跳数差） |
| 红移 | ΔN(r_s) − ΔN(r_o)（两端势差） | 谱线引力红移（SPUM2611 §十，已验证路径） |
| 温度 | ΔN(P)（势读数） | 本框架的锚定命题（§一） |

> **注（P3 的势型表达）**：晶子越集中 → M̃ 越大 → ΔN 的等值面（ΔN = const ⟺ r ∝ M̃）越远、径向梯度 dΔN/dr = σ₁M̃/r² 越陡。引力、红移、温度分享同一个"越集中越强越陡"的结构——没有独立自由度。

### 3.3 与 GR 的关系

ΔN 的宏观身份 = GR 势（SPUM2611 已为红移确立 ΔN ↔ GM/(c²r)）。本框架把温度挂上同一个量，因此温度不再有任何独立于引力的现象学——这不是缺陷，是收敛的代价：温度的可判别内容全部移入 O-δ 与 O-背景。

## 四、单物种温度剖面与 Tolman 同形（O1 关闭）

### 4.1 推导

弱场线性归一 g(x) ≈ 1 + x（N₀ 为唯一标度）：

$$T(r) \approx T_\infty\left(1 + \frac{\Delta N(r)}{N_0}\right) = T_\infty\left(1 + \frac{\sigma_1 \widetilde{M}}{N_0\, r}\right)$$

Tolman 关系（静态平衡，GR）：T·√(−g₀₀) = const。弱场 √(−g₀₀) ≈ 1 + φ/c²（φ = −GM/r）：

$$T(r) \propto \frac{1}{1 - GM/(rc^2)} \approx 1 + \frac{GM}{c^2 r}$$

令 N₀ 吸收盈余耦合标度：取 N₀ = σ₁c²/G（G 与盈余耦合 σ₁ 的关系同 v1.0 的 G = 2kc² 处理——都是投影层常数组合），即得

$$T(r) \approx T_\infty\left(1 + \frac{GM}{c^2 r}\right) \qquad \Longleftrightarrow \qquad T\sqrt{-g_{00}} = \text{const}$$

**结论**：SPUM 单物种温度剖面与 Tolman 同形。v1.0 的 O1 翻译选择（A 局域 1/r² vs B 势 1/r）**关闭**——不是选了 B，而是温度从未单独翻译：它与红移共用 ΔN，势型是定义锚定的必然。深 = 热（ΔN 大）方向与恒星/地热内禀一致。

### 4.2 单物种层面不再有判别性

同形意味着：测量单物种温度剖面只能**确认**势场结构，不能判别 SPUM 与 GR。判别性（若有）只可能在元素依赖（O-δ）与背景标度（O-背景）里——这正是收敛的方向。

## 五、绝对零度与背景标度（O-背景）

### 5.1 无源极限

无晶子（M̃ → 0）→ σ ≡ σ₀ → ΔN ≡ 0 → T → T∞。若 T∞ 取绝对零度（T₀），则：**一个不包含晶子的区域读绝对零度**。晶子是温度结构的唯一来源；背景网络 σ₀ 自身不携带温度（它是 0 基准）。

### 5.2 光子与 CMB（裁决未决）

"晶子密度包含光子"的两种读法未裁决：

1. **光子不计入源**：CMB 2.7 K 无法由本框架给出 → 背景有独立的非晶子温度源，或 CMB 是别的 L2 现象（与温度定义脱钩）；
2. **光子计入源**：光子（关系流/移动缺陷）也是密度贡献者 → CMB 2.7 K = 宇宙残余光子场的读数，绝对零度 = 物质晶子与光子全缺席（理论极限，不可达）。

地温类比（§1.3）在两读法下都成立（它只依赖物质晶子近场）。**O-背景 记录此裁决**：绝对零度的精确定位 + CMB 的地位，待光子-晶子关系定案。

## 六、元素依赖：δ ≡ 0 与 O-δ

温度 = 普适势读数 → 同点不同元素必须读同一温度（R5/第零定律在势型框架的形态）。叠加线性（ΔN_total = ΔN_env + ΔN_self）与 g 弱场线性共同给出 δ ≡ 0；壳层透射 p 机制（v1.0）在势框架下无穿透对象而作废。元素差只可能在 g 非线性的二阶交叉项复活（O-δ），量级被 g 的线性归一压制。

完整论证见 [元素耦合与温度-势框架 v2.0 §二–§三](../../元素化学/元素耦合参数推导：壳层透射p与温度偏差δ.md)——本文不重复，只声明：**本框架下不存在"元素依赖温度"的可判别预言**。

## 附：v1.0 判别型框架废弃记录（摘要）

v1.0 曾构造以下判别内容，随 δ ≡ 0 全部失去对象：

1. **壳层透射 p 机制**（p = Πτ_m，价层盲道/深通道读冷）——废弃原因：势无方向、无穿透、无物可屏蔽；局域 σ 读出作废。
2. **EDT 判别式** Δln(T_i/T_j) = γs(p_i−p_j)——废弃：δ = 0 时恒零，判别对象消失。
3. **两段式观测设计**（太阳校准 P2 / 白矮星 H-Fe 交叉）——废弃：同因。
4. **接触式 Johnson 噪声设计（已排除，记录备查）**——即使 v1.0 框架内也不可行（违反第零定律/R5 + 探针-机制错位）；v2.0 下同点同温是定义必然，该设计的失败预期不变。
5. **v1.0 的防稻草人三点澄清**（同点耦合同温 ≠ Tolman；单点解耦差温不违 GR；GR 断言剖面形状普适）——v2.0 下不再需要：SPUM 与 GR 同形，无对抗可澄清。

保留价值：v1.0 完整记录了"局域读出 → 元素差预言"这条被证伪的路径，其废弃链条（Aⁿ → p → δ≡0）是理解温度-势框架为何必然收敛的教材。
