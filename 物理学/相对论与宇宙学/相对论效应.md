# 相对论效应

> SPUM 归约路径：无弯曲时空，唯虚面之疏密；无相对时间，实塌缩之频律
> 草稿来源：第三十章

---

## SPUM 定义

宇宙中并无"时空"实体，只有**κ 网络及其动态结构**。所谓"引力""时间膨胀""红移"，皆是 κ 网络密度与虚面树张力分布不均所引发的可观测效应。

## 三大核心效应

### 一、引力透镜

光线未被"引力拉弯"——光子 CES 总是选择 κ 密度梯度最小阻力路径。大质量天体 = 局部 κ 网络高密度区 → 光子路径被偏转。

引力透镜 = **κ 密度地形图上的光子导航**。

### 二、引力红移

光子 CES 在强引力场（高 κ 密度区）发射时，需推开周围致密虚面树才能弹射 → 消耗动能 → 方向场振荡频率降低 → 到达远处时频率已永久下降。

**无需"时间变慢"解释**：红移是发射过程的动力学结果。

### 三、时间膨胀

时间不是基本量，而是**κ 网络塌缩事件的统计节奏**：

- **运动时间膨胀**：高速运动物体内部虚面树整体平移，每次塌缩需"追赶"前方 κ 网络状态 → 塌缩间隔拉长
- **引力时间膨胀**：高 κ 密度区虚面树张力大，塌缩需克服更大阻力 → 发生更慢

**时间 = 局域塌缩频率**。无绝对时间，只有不同 κ 环境下的节奏差异。

## [L0] 还原

相对论效应 = 不同 σ 区域中帧进程的差异。时间膨胀 = 高密度区的帧周期更长（更多节点需协商状态变化）。引力红移 = 边从低 σ 区传播到高 σ 区时能量/频率的帧间衰减。Lorentz 变换是 σ 分布非均匀导致的帧同步修正公式。
