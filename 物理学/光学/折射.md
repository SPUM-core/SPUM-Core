# 折射

> SPUM 归约路径：永恒粒子穿越嵌套空间层级时的连续路径偏折
> 草稿来源：第十七章 §17.3

---

## SPUM 定义

折射不是"速度变化"，而是**空间层级几何引导下的路径弯曲**。

## 机制

部分永恒粒子可穿透表层碗状结构进入物体内部：

- 遭遇连续嵌套的空间层级
- 每一层均为球面曲率结构，对粒子路径施加连续微偏转
- 宏观上，无数微小偏转叠加为平滑曲线，在界面处近似为折线

由于空间层级密度由外向内递增，偏折能力增强，导致：

```
n = c / v_eff > 1
```

其中有效速度 v_eff 并非真实减速，而是路径延长所致的时间延迟。

---

## [L0] 还原

折射 = 传播边从一种 σ 介质进入另一种 σ 介质时，因局域 σ 分布变化而改变传播方向。折射率 n = σ₂ / σ₁——σ 越高的介质（越热、越稀疏），边传播越快；σ 越低的介质（越冷、越密集），边传播越慢。
