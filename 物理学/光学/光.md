# 光

> SPUM 归约路径：移动的拓扑缺陷——13+晶子带缺口结构的永动传播
> 草稿来源：第十七章
> **最新理解**：光子不是"大开口永恒粒子"，而是晶子组合超过12个后必然产生的移动拓扑缺陷。缺口源于不完美定理的几何强制——13+晶子无法完美闭壳。光速 c = 4κ/τ 不是宇宙限速，而是**绳波**的传播速率上限（移动拓扑缺陷与扰动在网络上扩散的速率）；它**不约束空间流本身**——空间（介质）被收动的速率不受 c 限制。

## SPUM 定义

光不是电磁波，也不是纯粹粒子——它是**移动的拓扑缺陷**在 κ 网络中的永动传播。当晶子组合超过12个（13+晶子），完美闭壳被打破，必然产生无法愈合的缺口（悬挂边）。缺口产生内禀方向——外部关系流持续从缺口吸入，在内部经历净湮灭效应后从后方排出。这个永不停歇的关系流引擎驱动整个结构持续改变自身坐标。光波则是光子运动时在空间网络中激发的弹性形变模式，具有波长、频率、偏振等波动属性，但不是独立实体。

## 光速不变

"光速不变"实则是**绳波**的传播速率上限 c = 4κ/τ，由 κ 网络的格点间距 λ₀ 与最小帧周期 τ₀ 决定。在物质中，"慢光"只是路径蜿蜒的表观效应。光速不是宇宙被设定了"最高限速"，而是**波在离散帧网络上传播**的拓扑上限——它管的是绳波，不是绳子本身的移动。

## [L0] 本体论还原

光 = 13+晶子构成的移动拓扑缺陷——缺口产生的内禀方向与关系流引擎驱动永动位移。光速 c = 4κ/τ = **绳波**在离散帧网络上的最大传播拓扑速率（不约束空间流本身）。光的"频率" = 吞噬速率 J。光波 = 光子运动时在空间网络中激发的弹性形变模式（集体激发，非独立实体）。
