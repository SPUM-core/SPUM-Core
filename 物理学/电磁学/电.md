# 电

> SPUM 归约路径：虚面塌缩链式传递 → 宏观电流
> 草稿来源：第十九章

---

## SPUM 定义

"电非物，乃空间之舞；流非子，实虚面之迁。"

电流的本质不是电子从 A 移动到 B，而是**κ 网络中虚面塌缩事件的链式传递**。

## 基础概念重定义

| 传统概念 | SPUM 重定义 |
|---------|-----------|
| 电荷 | 虚面树方向场的拓扑极性 |
| 电压 | κ 密度梯度驱动的虚面失衡势 |
| 电流 | 虚面塌缩波的宏观统计表现 |

## 三种材料的 SPUM 解释

### 1. 导体

- 金属原子排列高度对称 → 虚面树呈规则网格
- 外加 κ 密度梯度轻易扰动虚面方向场
- 虚面塌缩事件迅速传播 → 低电阻

### 2. 绝缘体

- 原子结构复杂 → 虚面树方向混乱或高度绑定
- 虚面塌缩难以触发链式反应
- 即使强 κ 密度梯度也无法形成有效传导 → 高电阻

### 3. 半导体

- 虚面树可调控——通过掺杂改变局部方向场弹性
- n 型：额外电子 CES 使虚面树更易变形
- p 型：缺失电子 CES = 方向场空隙 → 塌缩波可借道传播

## 电的统一图景

电流 = 塌缩波。当导线两端存在 κ 密度差（如电池），前方 κ 粒子因虚面塌缩融合 → 后方生成新粒子 → 链式传递，如多米诺骨牌。

## [L0] 还原

电 = ∇σ 驱动的边重连事件链。电压 = 两个节点子图之间的 σ 差。电流 = 每帧在指定方向完成的边重连事件数。电阻 = 材料网络中桥边/割边的密度——桥越多，σ 差驱动的重连越困难（电导率越低）。
