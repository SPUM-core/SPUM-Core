# 原子结构

> SPUM 归约路径：κ 网络中的嵌套空间层级——原子核 = 低 σ 核心，电子 = 特定层级上的边激发驻波
> 草稿来源：第二十七章 §27.1

---

## SPUM 定义

原子不是"核+电子云"的量子概率图像，而是**κ 网络中一个多层级嵌套的稳定拓扑结构**：

- **原子核** = κ 网络的致密压缩区（极低 σ）——由 12 永恒粒子的正二十面体微子团簇构成
- **电子** = 在核周围空间层级上驻留的 CES（复合永恒结构），对应虚面树的特定拓扑激发模式
- **轨道/能级** = 不同曲率半径的空间球层，每层具有特定的 κ 密度和虚面树连通度

## 空间层级结构

每个原子周围的空间被组织为同心球层：

- ρ ∝ r⁻³ （密度由内向外递减）
- 分支角 120°，连通度 k = 3
- 每一层可容纳有限数量的 CES 驻波模式（对应量子数 n, l, m）

## 能级的 SPUM 解释

| 传统概念 | SPUM 对应 |
|---------|----------|
| 主量子数 n | 空间层级编号（球层序数） |
| 角量子数 l | CES 驻波模式的虚面树拓扑手性（0=s 直线, 1=p 平面等） |
| 磁量子数 m | 虚面树方向相对于外场的离散取向 |
| 自旋 | CES 绑定虚面树的固有手性（左/右） |
| 泡利不相容 | 同一轨道无法容纳两个方向冲突的虚面树 |

## 能级跃迁

电子在能级间的跃迁 = CES 在相邻空间层级之间的弹射——吸收/发射一个永恒粒子（光子 CES）。光谱线 = 各层级间弹射的能量特征。

---

## [L0] 还原

原子 = 一个 σ 梯级结构：中心 σ → 0（12 节点正二十面体骨架），外围 σ 逐级升高。每个 σ 层级上可以驻留度 ≥ 2 的边激发——这就是"电子轨道"。跃迁 = 边激发从一个 σ 层级跳到另一个。吸收/发射光子 = 边激发的能量以单个帧间边传播的方式释放或获取。
