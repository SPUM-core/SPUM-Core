## SPUM 定义

**真空涨落不是本体层的随机事件——它是观察者把"帧间残留活动"的统计投影为"涨落"。其机制是不完美定理。**

[L0] 本体：帧事件确定发生，节点要么连接要么不连接——没有随机性，没有"涨落"。
[L1] 认知：观察者读不到完整拓扑，把每帧残留的 V⁺/V⁻ 活动量 ΔV 的波动投影为"真空涨落"——与"连续是离散的投影"同一类（R5 → spum-core §3.1）。

---

## 一、核心命题

> **不完美定理本身就是量子真空涨落的机制。**

这句话的两层含义，缺一不可：

| 层 | 断言 | 图论表达 |
|----|------|----------|
| [L0] 本体 | 演化永不停：删除悬挂边必生新悬挂边 | δ(τ) > 0 恒成立（GT-002） |
| [L1] 认知 | 观察者把残留活动投影为"涨落" | ΔV(τ) = V⁺ + V⁻ 的帧间波动 |

涨落是**认知现象**（[L1] 投影），机制是**不完美定理**（[L0] 必然）。二者隔着离散帧——不可互相归约，也不可混淆。

---

## 二、推导链（5 步）

```
1. 五步帧（创生→连接→变化体积→判断→删除）
   ⇒ 每帧结束时删除全部悬挂边（deg < 2 的边）

2. 删除悬挂边必生新悬挂边（GT-002）
   ⇒ 被删除节点的邻居度数可能降到 1

3. 一帧内无级联消解
   ⇒ 新悬挂端留待下一帧处理——残留活动永不终止

4. 每帧的残留活动量 = ΔV = V⁺ + V⁻
   ⇒ ΔV 是有限、离散、逐帧变化的统计量

5. [L1] 观察者把 ΔV 的帧间波动投影为"真空涨落"
   ⇒ 涨落是认知投影，不是本体状态（反模式 4 校准）
```

## 三、两层结构：不完美 vs 涨落

调试演示过程中确立的关键校准——**涨落不在 δ 的幅度上**：

| 量 | 行为 | 物理对应 |
|----|------|----------|
| δ(τ) 悬挂端密度 | 恒 > 0（稳态 ≈ 1/N，即恰有一个残留悬挂端） | **边缘不完美**（spum-core §2.3）：每帧必残留悬挂端 |
| ΔV(τ) 帧活动量 | 围绕均值波动（std/mean ≈ 48%） | **涨落**：帧间关系重分配的活动 |
| 悬挂端位置 | 沿链转移/漂移，永不锁定 | **中心不完美**（Δμ 锚点漂移的图论对应） |

不完美定理保证 δ(τ) 永不归零——这是"涨落永不消失"的本体保证。涨落的**量**由 ΔV 表达，涨落的**存在**由不完美定理保证。

## 七、标准几何化演示（已验证）

`src/spum_graph/demo_imperfection.py` 在均匀随机网络（近均匀 σ 真空区域）上执行 500 帧五步演化。

**验证结果**（N=200, p=0.015, seed=42）：

```
── 不完美定理验证（GT-002）──
  δ > 0 帧占比 = 500/500 (100.0%)
  δ = 0 帧数   = 0
  结论         = ✅ 成立：δ 永不归零

── 涨落谱分析（ΔV 活动量）──
  ΔV 均值      = 3.06 事件/帧
  ΔV 标准差    = 1.48（涨落幅度，std/mean ≈ 48%）
  谱峰频率     = 0.128 cycles/frame
  自相关 lag-1 = 0.1053（有结构，非白噪声）
  谱 bin 数    = 250/251 非零，Nyquist 截断
```

输出：`imperfection_demo/` 下 fig1_delta_fluctuation.png、fig2_spectrum.png、fig3_autocorr.png、report.txt。

**调试中确立的引擎规则**：悬挂端 = 单侧张力未配平边界 = 创生热点（∇σ 驱动）。存在悬挂端时创生确定性沿其延伸——"悬挂端 v 接新节点 u → v 配平、u 悬挂 → 删 u → v 回 deg1"的转移引擎永不熄火。这是"删除必生新悬挂"的最简实现。
