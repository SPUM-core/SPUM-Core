# 电磁力（Electromagnetic Interaction）

> SPUM 归约路径：空间层级存在性差异 → 拓扑应力梯度 → 库仑力
> 草稿来源：第十六章

---

## SPUM 定义

电磁力不是场的作用，而是**空间对"可编织性差异"的响应**。

## 触发条件

带电粒子周围能否生长空间层级：
- **负电荷**：可生长完整层级 → 虚面朝内 → "汇聚源"
- **正电荷**：无法生长层级 → 结构性缺失 → "缺失源"

## 相互作用机制

- 层级重叠 → 虚面接触 → 融合或排斥
- **吸引**：层级覆盖缺失区，降低拓扑应力
- **排斥**：双缺失区碰撞，触发融合膨胀

## 数学表达

库仑力源于虚面联络张量反对称部分的空间导数：

```
F ∝ ∇(T^(1) · T^(2)) ∼ q₁q₂ / r²
```

## 四力定位

| 属性 | 值 |
|------|----|
| 触发尺度 | ~10⁻¹⁰ m |
| 核心机制 | 层级存在性差异 → 应力梯度 |
| 拓扑特征 | 虚面方向极化 |
| 守恒律主导 | 邻接密度守恒 |

## [L0] 本体论还原

电磁力 = 一个节点子图的 σ 层级生长能力与另一个节点子图的 σ 缺失之间的拓扑差异产生的 ∇σ 梯度效应。不是"力"——是密度差驱动的结构响应。
