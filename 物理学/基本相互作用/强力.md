# 强力（Strong Interaction）

> SPUM 归约路径：多个微粒子实面接触 → 拓扑闭合自封闭网络 → 空间扩张禁锢
> 草稿来源：第十六章

---

## SPUM 定义

强力不是"胶子拉扯"，而是**空间被拓扑锁死后的收缩应力**。

## 触发条件

多个微粒子通过实面接触形成自封闭网络（如 12 粒子正二十面体）。

## 拓扑约束

- ∂M = ∅（无边界）
- H₂(M) = 0（无空洞）
- 缝隙导流效应 → 动态隔离域，限制外部空间流入

## 动力学核心

死力主导（V⁻ ≫ V⁺），导致净空间收缩：

```
δV_net = V⁻ − (V⁺ + δV_in) > 0  ⇒  净空间收缩
```

内部空间增量无法满足扩张需求（δV_总 ≤ V_growth），产生刚性束缚。

## 临界现象

当 δV_总 = V_growth 时，系统处于夸克禁闭临界距离，进一步分离将触发新永恒粒子生成（类比"弦断裂产生成对夸克"）。

## 四力定位

| 属性 | 值 |
|------|----|
| 触发尺度 | ~10⁻¹⁵ m |
| 核心机制 | 拓扑闭合 → 空间禁锢 |
| 拓扑特征 | ∂M = ∅, H₂ = 0 |
| 守恒律主导 | 欧拉示性数 χ |
