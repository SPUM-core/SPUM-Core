# 弱力（Weak Interaction）

> SPUM 归约路径：高能扰动 → 虚面-实面角色翻转 → 拓扑缺陷类型转换
> 草稿来源：第十六章

---

## SPUM 定义

弱力不是"交换 W/Z 玻色子"，而是**拓扑重构过程中的守恒律过渡态**。

## 触发条件

微粒子组合在高能扰动下发生虚面-实面角色翻转（如中子 → 质子 + 电子 + 反中微子）。

## 机制特征

- 原本满足 H₂(M) = 0 的闭合结构被打破
- 短暂出现游离边界（∂M ≠ ∅）或瞬时空洞（H₂(M) ≠ 0）
- 系统通过发射低连通度拓扑激发（对应中微子）恢复守恒

## 物理表现

- 粒子身份改变（味变）
- 作用距离极短（~10⁻¹⁸ m），因拓扑失稳仅在极小尺度可容忍
- 违反宇称（P）对称性，因虚面方向锁定具有手征偏好

## 四力定位

| 属性 | 值 |
|------|----|
| 触发尺度 | ~10⁻¹⁸ m |
| 核心机制 | 缺陷类型转换 → 守恒松弛 |
| 拓扑特征 | 边界/空洞瞬时出现 |
| 守恒律主导 | 手征流守恒 |

## [L0] 本体论还原

弱力 = 闭合子图在边缘帧中的 dv/dt 瞬时超出 const 天花板 → 拓扑结构被迫暂时破裂 → 通过释放低度数激发（中微子 = 度 1 边）恢复自洽。不是"力"——是局部拓扑不平衡的瞬时释放。
