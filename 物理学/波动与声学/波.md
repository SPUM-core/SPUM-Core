# 波

> SPUM 归约路径：κ 网络对局部扰动的集体响应模式
> 草稿来源：第二十一章

---

## SPUM 定义

波不是某种实体在空间中传播，而是**κ 网络对局部扰动的集体响应模式**：

- 当某处发生虚面塌缩、CES 弹射或 κ 密度突变 → 邻近 κ 粒子立即响应
- 响应以有限速度 c = λ₀ / τ₀ 向四周扩散
- 扩散过程表现为密度、方向或拓扑状态的周期性起伏

**波是现象，不是本体。本体唯有 κ 粒子及其网络。**

## 波类型统一

| 波类型 | SPUM 对应机制 |
|--------|-------------|
| 声波 | κ 密度梯度的机械传播 |
| 电磁波 | 虚面树方向场的周期性扭曲 |
| 引力波 | 虚面树拓扑对称性的远距离涟漪 |
| 量子概率波 | 虚面塌缩可能性的统计分布 |

## 波速恒定的解释

光速 c 在真空中恒定——SPUM 给出底层解释：

κ 网络具有固定格点间距 λ₀ 与最小响应时间 τ₀。任何扰动在 κ 网络中的传播速度上限为 c = λ₀ / τ₀。此速度由空间本身的离散结构决定，与观察者运动状态无关。

## [L0] 还原

波 = 网络中的边激发或节点状态变化以逐帧逐边的离散方式在 ⟨P, ε⟩ 中传播。频率 = 激发的帧间周期。波长 = 相邻同相激发之间的边数。波速 = 每帧传播的边数（上限为 1 边/帧 = c）。衍射干涉 = 多路径边激发在目标节点的帧数差叠加。
