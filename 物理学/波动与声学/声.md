# 声

> SPUM 归约路径：κ 密度涨落在介质中的集体传递——压缩波沿空间链传播
> 草稿来源：第二十八章

---

## SPUM 定义

"声非振，乃 κ 密之涟。"

声 = 低频、局域 κ 密度涨落在介质中的集体传递——**压缩波沿空间链逐帧传播**。

## 光与声的 SPUM 统一

| 属性 | 光 | 声 |
|------|---|----|
| 本质 | 高频、无质量 CES（永恒粒子）定向传播 | 低频、局域 κ 密度涨落集体传递 |
| 载体 | 无需介质（自由空间） | 需介质（κ 网络实体链） |
| 速度 | c = λ₀ / τ₀（常数） | 取决于介质 σ 和虚面树弹性模量 |
| 频率 | 对应 CES 的帧间周期 | 对应 κ 密度涨落的帧间周期 |

两者统一于 κ 网络对扰动的响应模式——**光是边激发，声是节点密度波**。

## 声学效应的 SPUM 还原

### 多普勒效应

声源运动 → 改变每次密度脉冲的发射位置 → 接收端单位时间扰动次数变化：
- 接近 → 扰动压缩 → 音调升高
- 远离 → 扰动拉伸 → 音调降低

本质：运动改变扰动在 κ 网络中的空间分布密度。

### 声光效应（Acousto-Optic Effect）

超声波 = 介质中 κ 密度的周期性涨落 → 形成动态光栅：
- 高密度区虚面树更刚硬
- 低密度区更柔韧
- 光子 CES 经过时被此光栅衍射 → 多级衍射斑

## [L0] 还原

声 = 节点密度扰动以逐帧逐边的方式在网络的某连通子图中传播。声速 = 该子图的 σ 与虚面弹性模量的函数（σ 越高、路径越稀疏 → 声速越低）。声波频率 = 节点密度波在目标节点的帧间周期。
