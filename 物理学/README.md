# SPUM 物理学概念释义

> 以 SPUM 关系网络本体论重新定义经典物理学概念。每个概念一个 MD 文件，按领域归类到子目录。
>

>
> **导航 Skill**：[skill.md](skill.md) — 9 子域 25 节点、R1-R9 物理学映射、全域连接图、消歧规则、加载策略。

## 引用规范

所有物理学概念释义必须：
1. 不引入"力"作为独立实体——所有现象还原为 ⟨P, ε⟩ 的拓扑响应
2. 标注对应的 SPUM 根节点（R1-R9）
3. 可在草稿中追溯原始推导
4. 区分 [L0] 本体论描述与 [L1]/[L2] 认知投影语言
