# 凝聚态物理

> SPUM 归约路径：κ 网络的几何结构与虚面树拓扑响应能力决定一切材料性质
> 草稿来源：第二十九章

---

## SPUM 定义

"材非死物，乃 κ 网之构；性非天赋，实扰动之应。"

材料的一切宏观性质，皆源于其内部 κ 网络的几何结构与虚面树的拓扑响应能力。电阻、磁阻、热导等效应，不过是外部扰动触发 κ 网络局部重构的必然结果。

## 核心效应 SPUM 还原

### 巨磁阻效应（GMR）

| 状态 | 机制 |
|------|-----|
| 无外场 | 磁性层虚面树方向反平行 → 电子 CES 穿越界面频率调整方向 → 高散射 → 高电阻 |
| 加外场 | 虚面树强制对齐 → 电子 CES 方向场一致 → 散射减少 → 电阻骤降 |

电阻变化 = 虚面树方向匹配度的函数。

### 庞磁阻效应（CMR）

材料中存在**双相共存**：绝缘相（虚面树局域化）+ 金属相（虚面树连通）。磁场使局域自旋有序 → 虚面树突然连通 → 形成贯穿网络的低阻通道 → 电阻崩溃。

**CMR = κ 网络的临界相变现象**。

### 压阻效应

应力 → 原子间距变化 → 局部 κ 密度改变：
- 拉伸：虚面树连接变弱 → 电阻 ↑
- 压缩：虚面树耦合增强 → 电阻 ↓

### 维德曼-夫兰兹定律

金属中热与电均由同一类自由电子 CES 传导——两者共享相同的虚面树传导通道与散射机制 → 比例恒定。

## 材料智能：κ 网络拓扑工程

| 材料类型 | κ 网络特征 | 功能 |
|---------|-----------|------|
| 超导体 | 全局相干虚面树 | 零电阻、迈斯纳效应 |
| 拓扑绝缘体 | 表面连通、体内局域 | 表面导电、体内绝缘 |
| 自旋电子材料 | 虚面树方向可磁控 | GMR、自旋阀 |
| 热电材料 | 电子通道畅通，热通道阻塞 | 温差发电 |
| 压电/压阻材料 | 应力-虚面树耦合强 | 传感与驱动 |

## [L0] 还原

材料性质 = 子图的局部 σ 分布、环基数 μ、桥边密度。导体 = 桥边少、环多的高连通子图。绝缘体 = 桥边多的碎片子图。超导 = 全局 σ 均一的完美环网（μ 极高，无桥边）。GMR = 磁场改变两个子图间的边连接数。相变 = σ 越过临界阈值的网络重构。
