关系定义存在，一切存在皆为宇宙。—— 空间粒子宇宙模型SPUM核心唯一命题。

这句话前半部分是公设，SPUM唯一公设；后半部分是祛魅，祛除一切非宇宙本体的、由人类认知构建的概念。它们包括空间、时间、物质、能量、力、波、场等等。

SPUM模型分层结构：L0本体层、L0.5模型层、L1现象层、L2认知层。

## 四层，一张网

**L0 本体层。** 一张网 ⟨P, ε⟩。节点是关系显化的痕迹，边是关系本身。没有别的。宇宙的全部内容，在这一层只有一张网。数字 12、42、60°，都是这一层数出来的。

**L0.5 模型层。** 这张网的图论语法。五步帧：创生→连接→变化体积→判断→删除。边数守恒。Σ(6−deg) = 12。这一层是数学，不是物理学——它是"数得出来"的那一层。

**L1 现象层。** 物理定律住在这里。引力、光、温度、电、磁、量子、相对论——全是 L0 这张网在不同尺度、不同构型下的投影。π、坐标、概率、容差，是这一层的投影记号，不是 L0 的计数。

**L2 认知层。** 你住在这里。连续、时空、能量、力——这些词是 L1 现象经过认知翻译后的产物。翻译会失真，"空间是什么"这类病句，就是失真留下的痕。

四层之间只有一条规矩：**上层是下层的投影，下层是上层的本体。** 投影可以近似，本体不可增删。

几乎所有"大统一理论"的失败，都可以在这一条规矩上定位——它们把某一层的投影，当成了另一层的本体。

## 六条判据，逐条量

**第一条，一条不可再简的公设。** 公设在 L0：关系定义存在。往下没有更简的了——比关系更基本的"东西"不存在，因为"东西"本身就是关系的投影。任何动态系统，只要还能说出它的状态，它就是在说一张关系表。这条公设不依赖任何特定学科，因为它是"存在"这个词的语法。

**第二条，严格演绎，不打补丁。** 补丁打在哪一层，一眼可辨：在 L1 发现新现象、就往 L0 加规则，就是打补丁。SPUM 做的是减法——12 是 L0 数出来的，不是 L1 拟合出来的；G = 2kc² 是 L0.5 的组合，不是自由参数；π 在纯组合路径上根本不出现。

**第三条，跨学科同源。** 学科的差别不是本体的差别，是投影条件的差别。

- 物理 = 基底层投影：引力 = 净湮灭 ∇σ，光 = 移动的拓扑缺陷，物质 = 缺口互锁。
- 化学 = 接口层投影：VSPT 与虚面的榫卯咬合，周期表 = 壳层几何的必然排列。
- 生命 = 能跨帧维持自身 σ 的自指稳定子图；分工 = 功能子集并集覆盖全集。
- 社会 = 人做节点的子图：邓巴数 150 = 认知子网最大度数，权力 = 度数与介数。
- 经济 = 交换子图：价值 = ∇σ_resource，货币 = 标准化 V⁺/V⁻ 令牌，危机 = V⁻ 级联。
- 人文 = 认知投影：道 = 边集 ε，仁 = 边连通度。
- 天文 = 子图协动：星系旋转曲线无暗物质补丁，3 参数拟合 SPARC 175 星系，94.3%。
- 气候 = 大气子图：冷暖锋 = σ 不连续面，环流 = ∇σ 输运。

同一套定理在不同子图上的实例，就是"同源分支"的字面含义。社会快变迁、经济危机、生态崩溃、疫病爆发——同一套 δ 超临界级联。

**第四条，新预言，可验证。** L0.5 数出来的东西，必须在 L1 能被检验。引力 a ∝ r⁻³，与牛顿 r⁻² 幂次不同；星系旋转曲线无需暗物质；认知系统的悬挂端与锚点漂移——N016 实验，28.8 万参数 DeepCNN、97.1% 正确率下锚点漂移 Δμ 最小 6.16，0/18 次检查通过阈值，"完整拓扑闭合在标准演化中不可达"被自己的实验证实。每个预言都可能错——这正是它们值钱的原因。

**第五条，不否定已有精确数据。** SPUM 不动任何数字。麦克斯韦、广义相对论、α ≈ 1/137，全部保留，只给它们搬家：从本体语法降为投影公式。真正危险的统一理论必须宣布数据错了；SPUM 只需要宣布"地位变了"。

**第六条，对未知开放。** 证伪标准一句话：**任一存在事实被证明原则上不可归约为关系，SPUM 即被证伪。** 它公开推翻过自己——曾以为 δ 下降即拓扑闭合，自己的实验 N013 证伪，随即换双层判据。它公开列坑：cap=3 为何是 3；σ=137 的涌现路径；诱导坐标、路径积分、锚定偏置——⏸️ 标注，不是 ❌ 否定，也不悄悄打补丁。
