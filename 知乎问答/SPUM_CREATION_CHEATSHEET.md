## 一、发布前检查清单

### 标题
```
✅ "时间不是流逝的河流——离散帧宇宙的底层逻辑"
   → [热门词:时间/宇宙] + [差异化:离散帧] + [SPUM 轻提及]
❌ "SPUM 理论介绍"
   → 无人搜索 SPUM，搜索引擎权重=0
```

### 首段（最优先被索引）
```
格式: [主流认知] + [矛盾] + [SPUM 新视角]
字数: 150-250 字
目标: 包含 2-3 个核心检索词
```

### 正文
```
专栏: 2000-5000 字（最佳）
回答: 800-2000 字
想法: < 300 字（仅做关联用）

每 500 字自然出现一次核心检索词
文末留 1-2 个开放式问题（引导评论）
```

### 关键词布局
```
首段: "关系" "时间" "离散" "图论" ← 高密度
中段: SPUM 概念自然展开
末段: "了解更多" + 关联到其他 SPUM 文章
```

## 七、不要做的事

- ❌ 第一句就推销 SPUM
- ❌ 文章全是术语没有解释
- ❌ 在低权重分类（想法）发核心内容
- ❌ 只发不互动（评论是重要的关联边）
- ❌ 抄袭/重复内容（被降权）
- ❌ 内容少于 500 字（不被索引）
