## 一、为什么模拟：把"边界截断→引力源"翻译成网络操作

阿基米德实验的物理链条是：热调制超导样品越过 T_c → 堆叠卡西米尔腔边界反射率变化 → 腔内真空模式截断程度变化 → 真空能量变化 → 样品重量变化。

SPUM 把这条链条的每一环翻译为 ⟨P,ε⟩ 网络操作，使整个机制变成一个可运行的确定性算法：

| 实验要素 | SPUM 网络映射 |
|---------|--------------|
| 样品（YBCO/GdBCO 材料核） | R = 按度数最高的 40 节点构成的稠密闭合子图 |
| 卡西米尔边界反射率 | 边界刚度 b ∈ [0,1] |
| 正常态（T>T_c，边界透明） | b=0：无模式截断，内部真空涨落可逆自愈 |
| 超导态（T<T_c，边界全反射） | b=1：全模式截断，内部创生被抑制 |
| 腔内真空涨落 | 每帧 ann_rate = \|R\|/8 条 R 内部边自发断裂（速率与 b 无关） |
| 真空能量差 | 净湮灭率 δ⁻(R) = 内部湮灭 − 内部补偿 |
| 引力源强度 | δ⁻(R) ∝ 样品质量（质量的拓扑定义） |
| 重量变化 ΔF | ΔF ∝ Δδ⁻(R)（调制前后净湮灭率之差） |

**核心物理**：湮灭是"自由发生"的（真空涨落，与边界无关）；边界只决定补偿的去向——透明边界让补偿回到样品内部（自愈），反射边界把补偿强制转移到背景（对偶转移原理，闭合子图创生抑制）。于是：

```
δ⁻(R; b) = 湮灭 − 补偿 = ann_rate − (1−b)·ann_rate = b·ann_rate
```

边界越"反射"，样品内部净湮灭越强，样品作为引力源的强度越大——重量变化与调制深度成正比。这是本模拟要检验、并转交给实验的核心预言。

## 二、模拟设置

- 背景网络：SeedEpochEngine（target_edges=20000，seed_duration=100）→ V=194，E=936，晶子 15，悬挂 1
- 样品 R：度数最高 40 节点；初始 E_R(内)=162，E(边界)=679，σ_R=0.2469，σ_out=0.1990，Δσ=+0.0479
- 每帧：3 条背景生长边（候选优先低度数/悬挂节点，极少落入样品区 R——对应创生抑制）+ ann_rate=5 条内部自发湮灭 + 按 b 分配补偿去向 + 级联消解（cap=3，与引擎一致）
- 全部确定性（无随机数），同一参数逐位复现

## 三、模拟结果

### 实验 1：稳态净湮灭率 vs 边界刚度 b（每帧，40 帧窗口）

| b | δ⁻(R) | σ_R | σ_out | Δσ | E_R(末) |
|---|------|------|------|------|--------|
| 0.00 | 0.000 | 0.2469 | 0.1990 | 0.0479 | 162 |
| 0.20 | 1.000 | 0.2922 | 0.1987 | 0.0935 | 122 |
| 0.40 | 2.000 | 0.3561 | 0.1978 | 0.1583 | 95 |
| 0.60 | 3.000 | 0.4627 | 0.1970 | 0.2657 | 56 |
| 0.80 | 3.312 | 0.6578 | 0.1967 | 0.4611 | 39 |
| 1.00 | 3.719 | 0.7126 | 0.1984 | 0.5142 | 39 |

**发现 1（线性响应）**：b ∈ [0, 0.6] 区间 δ⁻ 严格正比 b，斜率 = 5.00 = ann_rate，截距 0。全区间线性拟合 δ⁻ = 3.79b + 0.28。**净湮灭率与调制深度成正比——ΔF 正比调制深度**。

**发现 2（高 b 饱和/耗损）**：b ≥ 0.8 时 δ⁻ 偏离线性（次线性、帧间方差增大），同时 E_R 从 162 骤降至 39（-76%）。**持续全截断会耗尽样品内部真空结构**——这正是实验必须使用周期性小调制、而非持续截断的原因。

**发现 3（密度梯度增强）**：σ_R 随 b 单调上升（0.247→0.713），σ_out 基本不变，Δσ = σ_R − σ_out 从 0.048 放大到 0.514（×10.6）。**截断越强，样品周围真空密度梯度（∇σ）越陡——引力场的拓扑定义被边界调制直接增强**。

### 实验 2：阶跃响应（b: 0.0 → 0.6，第 20 帧阶跃）

- 逐帧 δ⁻：第 1 帧即达稳态 3.00/帧，之后恒定 → **响应时间 τ = 1 帧（同相、瞬时、无记忆）**
- σ_R：0.252 → 0.449（漂移 0.0079/帧）→ **力瞬时跳变，密度剖面持续累积**（净湮灭在时间上积分）

**发现 4（同相锁定）**：力的响应没有弛豫时间常数——它逐帧跟随边界刚度，与调制同相。密度剖面则是慢变量（积分型）。

### 实验 3：标度律（不同样品大小 |R|）

| |R| | δ⁻(0) | δ⁻(0.6) | Δδ⁻ | Δδ⁻/\|R\| |
|----|------|---------|---------|-------|-----------|
| 20 | 0.000 | 0.406 | 0.406 | 0.020 |
| 30 | 0.000 | 1.688 | 1.688 | 0.056 |
| 40 | 0.000 | 3.000 | 3.000 | 0.075 |
| 60 | 0.000 | 4.000 | 4.000 | 0.067 |

**发现 5（强度量）**：每节点净湮灭率 Δδ⁻/|R| ≈ 0.067 恒定（除 |R|=20 因内部边太少提前耗损的离群点）。**ΔF 正比样品体积/质量——引力强度是强度量，总量随质量线性增长**。

## 四、对阿基米德实验的改进方案

由模拟的三条规律（线性、同相、体积标度 + 高 b 耗损），直接导出四条实验改进：

### 改进 1：调制深度扫描（检验线性度）

现方案只在 T_c 两侧做开关式调制（b≈0/1 两态）。**改为扫描调制深度**：以固定频率热调制，但逐步增大温度摆幅 ΔT 的中心偏移或幅度，使样品在每个周期内低于 T_c 的时间占比 b 从 0 扫到 1（等效于扫描边界刚度）。

- 预言：ΔF(b) 严格线性（斜率即每帧净湮灭率），这是 SPUM 的指纹。
- 分辨力：在 b∈[0, 0.6] 线性、b>0.6 开始饱和的拐点若被观测到，直接验证"样品内部真空结构耗损"这一独有机制；若全程线性，则约束耗损率参数。

### 改进 2：以样品局域温度为相位基准（同相锁定检验）

现有锁定参考是驱动信号。**改用样品表面/内部的局域温度探头作为相位基准**，测量力的振荡相位差 Δφ：

- SPUM 预言：Δφ = 0（力逐帧跟随边界状态，τ=1 帧，无记忆）。
- 热膨胀、磁致伸缩、洛伦兹力等伪影均滞后于局域温度（热扩散时间常数 + 机械谐振相位）。**零相位差是与一切热-力伪影分离的判决性判据**。
- 附加检验：在多个调制频率 f₁ < f₂（如 1 mHz / 10 mHz）下测量。SPUM 预言幅度与 f 无关（直至热弛豫极限）、相位仍为零；热伪影在 f₂ 处出现明显相位滞后与幅度压缩。频率色散的存在与否直接区分"真空耦合信号"与"热力学伪影"。

### 改进 3：堆叠腔数与样品质量扫描（体积标度检验）

固定样品横向尺寸，改变堆叠层数（腔数）N_cav，或更换不同质量样品：

- 预言：ΔF ∝ 样品质量 ∝ N_cav；ΔF/单位质量 = 常数。
- 这是"净湮灭率 = 引力源强度"的最直接检验——若 ΔF 随质量线性而随表面积线性（常规卡西米尔压强信号），可立即区分机制。

### 改进 4：持续截断实验（耗损预言——SPUM 独有的可证伪特征）

常规卡西米尔模型预言：持续保持超导态的力是一个静态偏移。**SPUM 预言：持续截断下，异常力贡献随时间缓慢衰减（样品内部真空结构耗尽，σ_R 爆炸），并伴随帧间方差的增长**。

- 操作：保持 T < T_c 数小时，监测扭矩信号的时间包络。
- 若观察到衰减包络 → SPUM 的耗损机制；若无衰减 → 耗损率低于实验窗口，给出上限约束。

### 改进 5：b > 0.6 饱和区专项验证（本次新增）

改进 1 的线性扫描到 b>0.6 之后会进入模拟预言的饱和区，其特征有三：(1) ΔF(b) 偏离线性、趋于饱和；(2) 信号逐周期方差显著增大；(3) 样品内部真空结构耗损，且回到低 b 后**不恢复**（迟滞）。为此设计四个验证步骤：

- **步骤 A（拐点定位，已执行）**：在 b = 0.0–1.0 加密采样（0.6–1.0 段步长 0.05，拐点附近加密至 0.02），画出完整 ΔF(b) 曲线。实测结果（openSPUM 实测）：**饱和拐点 b_c ≈ 0.72**——判据修正为双判据（逐段斜率判据因离散帧整数阶梯效应失效）：① 方差跃升（std/δ⁻ 首次 > 0.2）出现于 b = 0.72；② E_R 耗损过半出现于 b = 0.5（结构耗损起点，但此时净湮灭率仍严格确定）。两者合并给出拐点区间 b ∈ [0.5, 0.72]，饱和起点取 b_c = 0.72。
- **步骤 B（方差特征，参数按实测拐点 0.72 更新）**：对每档记录信号时间序列，计算逐周期重复性与 Allan 方差。采样档位按三段设计：
  - **线性对照段（确定性区）**：b ∈ {0.5, 0.6, 0.7}——预言 std/ΔF = 0（逐周期完全可重复）；
  - **拐点过渡带（关键区，步长 0.02）**：b ∈ {0.68, 0.70, 0.72, 0.74}——预言 std/ΔF 在 0.72 处从 0 跃升到 0.38；
  - **饱和深段**：b ∈ {0.8, 0.9, 1.0}——预言 std/ΔF = 0.37（0.8–0.85）、0.52（0.9–1.0）。
  - 积分要求：逐周期重复性分辨阈值 ≤ 0.05（区分 0 与 0.38 的跃升需 ≥ 8 倍裕度），每档至少 20 个调制周期；实验上 b 通过"每周期低于 T_c 的占空比"实现，占空比分辨率需 ≤ 2%（对应 Δb = 0.02 的过渡带采样能力）。
  - 判据：方差跃升拐点应落在 b = 0.72 ± 0.02；若跃升提前至 b < 0.6（耗损机制过早触发）或推迟至 b > 0.85（饱和区保持确定性），则修正耗损的时间尺度假设。热伪影表现为稳定系统偏差（不改变逐周期 std）而非方差跃升——此特征把饱和信号与热漂移区分开。
- **步骤 C（迟滞/可逆性检验）**：完成 b=1.0 档测量后，把调制切回 b=0（透明态），观察：① 净湮灭率是否 1 帧内归零（模拟：delta 瞬时恢复，信号快速消失）；② 随后再切到中等 b 时，信号基线是否整体低于首次扫描的同 b 值。模拟实测：b=1 持续 25 帧后 E_R 162→59；切回 b=0 跑 40 帧只恢复到 62（不回 162），σ_R 滞留 0.65——**净湮灭率瞬时归零，但内部真空状态不恢复**。判据：若观测到"信号快速归零但基线整体下移"的迟滞，即直接验证内部真空结构耗损；若与首次扫描完全重合，则耗损可逆，约束耗尽率。
- **步骤 D（耗尽时间常数分离）**：持续保持超导态，测量异常力包络的衰减时间常数 τ_dep。模拟给出耗尽过程：E_R 在 40 帧内消耗 76%。实验需确认 τ_dep >> τ_th（热弛豫时间）——只有耗损时间远长于热时间常数，衰减包络才能判定为真空结构耗损而非热效应残余。

## 五、精确预测（数值化）

1. **线性律**：ΔF(b) = ΔF_max · (b/b_max)。结合合作组预期的满调制信号 ~5×10⁻¹⁶ N（40 cm³ YBCO），SPUM 预言半调制（b=0.5）信号 = 2.5×10⁻¹⁶ N，b=0.25 信号 = 1.25×10⁻¹⁶ N——可用同一装置直接验证比例关系。
2. **同相律**：力与样品局域温度同相（Δφ = 0，误差 < 一个调制周期），且在两个以上频率上成立。
3. **体积律**：ΔF/单位体积 = 常数；两倍堆叠 → 两倍信号（在测量灵敏度内）。
4. **饱和律（量化，实测修正）**：b > 0.72 时 ΔF(b) 偏离线性、趋于饱和。模拟实测给出饱和区三个可检验的数值预言：
   - **拐点位置** b_c ≈ 0.72（b ≤ 0.7 时 δ⁻ 严格线性且逐周期确定；b = 0.72 起方差跃升、斜率降至 1/3 以下）；结构耗损起点更早，b ≈ 0.5（E_R 耗损过半，但净湮灭率仍严格确定）；
   - **相对波动跃升**：std/δ⁻ 从 0（b≤0.7）跃升至 0.37–0.38（b=0.72–0.85）、0.52（b=0.9–1.0）；
   - **耗损水平**：40 帧满截断 E_R 消耗 76%（162→39）；且回到 b=0 后 E_R 仅恢复至 62（≈38% 水平）即滞留——**内部真空状态不可逆，净湮灭率却瞬时归零**（迟滞预言）。
5. **组合预言**：设满调制（b=1）产生的异常信号扭矩为 S_max（正比于力臂 × 5×10⁻¹⁶ N），则任意调制深度 b 的信号扭矩 S(b) = b·S_max。若满调制信号达原型机本底量级（S_max ≈ 5×10⁻¹² Nm/√Hz），则在两周积分灵敏度 3.5×10⁻¹³ Nm/√Hz 下，达到信噪比 1 所需调制深度仅 b_min = 3.5×10⁻¹³/5×10⁻¹² ≈ 0.07——即 7% 的调制深度即可在两周内被探测，为参数选择提供直接依据（此条为条件式预言，S_max 需以实际力臂标定）。

## 六、可证伪性边界

- 本模拟检验的是"边界截断 → 净湮灭率变化 → 引力源强度变化"这条连接链。无信号排除的是这条链，而非"真空有能量"。
- 若实验在深度扫描中观测到**非线性响应早于 b≈0.72**（在拐点前就偏离线性）、或在多频率下观测到**相位滞后**，则 SPUM 的简单映射（净湮灭率仅由 b 决定、无记忆）被证伪，需要引入密度剖面反馈项（σ 对 b 的反作用）。
- 若体积扫描中 ΔF 不随质量线性增长，则"净湮灭率 = 引力源强度"的映射被证伪。
- 若 b>0.72 饱和区**不出现**（ΔF(b) 直至 b=1 全程线性、逐周期方差不增长、回到低 b 无迟滞），则"内部真空结构耗损"预言被证伪——此时 SPUM 模型退化为纯线性映射，饱和机制（耗损 + 方差增长 + 迟滞三件套）不成立。
