# 贡献指南

感谢您参与 SPUM 数据考古计划！

## 如何贡献数据

1. **检索文献**：使用 `docs/radiometer_lit_review.md` 中的关键词和方法寻找相关论文。
2. **提取信息**：
   - 定性数据：记录环境温度、压强、材料、旋转方向。
   - 定量数据：若论文包含转速-温度曲线，使用 WebPlotDigitizer 提取数值点。
3. **填写模板**：使用 `data/processed/` 中的 CSV 模板填写。
4. **提交**：通过 Pull Request 将 CSV 文件放入对应目录，在 PR 中说明数据来源和提取方法。

## 如何贡献代码

- **脚本改进**：优化 `scripts/` 下的数据清洗、绘图、拟合脚本。
- **新功能**：实现 SPUM 理论中的其他模块（如光子尾迹模拟、VSPT 生长规则）。

## 如何讨论问题

在 Issues 中创建新话题，使用标签：
- `data-collection` – 数据收集相关
- `analysis` – 数据分析讨论
- `theory` – 理论推导问题
- `code` – 代码实现

## 数据伦理与版权

- 优先使用开放获取文献或已过版权期的资料。
- 若使用付费论文，仅提取数据点，不分享全文。
- 所有贡献的数据默认以 CC0 协议释放，代码以 MIT 协议释放。

## 获得认可

所有数据贡献者和代码贡献者将被列入最终论文的致谢或共同作者（根据贡献度）。
