# SPUM 核心文档索引

本目录存放 SPUM 理论的核心文档，分别承担不同的理论职能：

## 理论文档

| 文档 | 定位 | 职责 |
|------|------|------|
| SPUM2610 | 主理论 | 从公理到实验的完整理论体系，是 SPUM 的唯一权威入口 |
| 拓扑涌现导论 | 数学底层 | 公理-命题-定理的形式化推导，纯拓扑语言 |
| 空间几何发生学 | 几何基础 | 从拓扑关系涌现全部几何概念，消解连续统先验 |
| 高斯-博内重构 | 数学专题 | 离散组合视角下高斯-博内定理的底层重构，论证 π 的认知投影本质 |

## 实证支撑模块

| 文档 | 定位 | 职责 |
|------|------|------|
| 子图协动 | 天文实证 | SPUM2610 第 8 章独立抽取。以子图协动机制替代暗物质解释星系旋转曲线，基于 SPARC 175 星系定量验证，附带可运行拟合代码 |

理论文档之间存在严格的逻辑依赖关系：
- SPUM2610 依赖拓扑涌现导论提供严格的数学支撑
- 拓扑涌现导论依赖空间几何发生学提供几何概念的定义
- 空间几何发生学是 SPUM 的认知投影层，与主理论构成双向循环
- 高斯-博内重构为拓扑涌现导论中的常数 12 提供独立数学验证
- 子图协动是 SPUM2610 第 8 章的应用推导，依赖第 2/3/4/5 章的拓扑基础
