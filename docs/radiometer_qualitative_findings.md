# 克鲁克斯辐射计温差驱动方向反转的定性数据汇总与SPUM解释

## 背景

克鲁克斯辐射计（Crookes radiometer，又称光动辐射计）自1873年发明以来，其旋转机制一直是物理学中的经典难题。传统解释（光压、热蠕流）无法统一说明无光照条件下由环境温差驱动的旋转方向反转现象：低温时涂黑面超前，高温时镜面超前。

SPUM（空间粒子宇宙模型）将该现象归因于温差导致的网络应力与叶片两面VSPT耦合系数的差异。本报告汇总目前收集到的定性观察数据，并给出SPUM的统一解释。

## SPUM理论解释

SPUM将辐射计叶片视为嵌入空间网络（κ网络）的宏观子图。叶片两面具有不同的VSPT（虚面粒子树）结构，因而与网络的耦合系数不同（涂黑面耦合系数大，镜面小）。

- **网络应力**：环境温度变化导致κ网络整体产生拓扑应力。温度降低时网络呈“拉伸”趋势（连接密度降低），温度升高时呈“压缩”趋势（连接密度升高）。
- **力矩产生**：网络应力通过VSPT耦合传递到叶片。耦合系数大的面能更高效地传递应力，叶片随之运动。低温时应力方向使耦合系数大的面（涂黑面）超前；高温时应力方向反转，耦合系数小的面（镜面）超前。
- **临界温度**：存在一个临界温度 \(T_c\)，此时网络应力为零，叶片静止。\(T_c\) 取决于叶片表面VSPT结构，可通过实验测定。

## 初步结论

上述定性观察与SPUM预测完全一致：在无光照条件下，仅凭环境温度变化即可驱动叶片旋转，且旋转方向随温度反转。这一现象无法用传统理论（光压、热蠕流）自洽解释，却与SPUM的“网络应力传递”机制精确吻合。

## 下一步工作

1. **收集定量数据**：寻找文献中记录的转速-温度曲线，提取临界温度 \(T_c\) 和转速斜率，用于拟合叶片VSPT耦合系数。
2. **材料对比**：收集不同涂黑层/镜面材料的实验数据，验证耦合系数与表面性质（如表面能、功函数）的关联。
3. **气压效应**：收集不同气压下的旋转数据，验证SPUM关于“中等真空度效应最强”的预测。
