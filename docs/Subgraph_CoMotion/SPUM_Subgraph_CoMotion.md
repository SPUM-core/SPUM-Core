# 子图协动：星系旋转曲线的拓扑替代方案

> **所属**：SPUM 实证支撑模块 — SPUM2610 第 8 章独立抽取  
> **定位**：为 SPUM 核心公理提供最坚实的宏观观测支撑  
> **核心结论**：子图协动（闭合子图的全局拓扑运动）可在仅 3 个自由参数下解释 94% 星系的旋转曲线，在 AIC/BIC 上系统性地优于同参数数量的 NFW 暗物质晕模型。

---

## 摘要

星系外围旋转曲线为何平坦？传统答案：暗物质晕。SPUM 的答案：**子图协动**。

空间粒子网络 ⟨P, ε⟩ 中的大尺度闭合子图（如星系盘），受全局拓扑守恒约束产生整体旋转运动。该运动不依赖不可见物质——它是关系网络的自组织现象。重子物质贡献的牛顿引力在内区（r ≪ r_co）主导，子图协动在外区（r ≫ r_co）主导。两者之间的过渡由一个特征半径 r_co 平滑连接。

基于 SPARC 数据库 175 个星系的定量拟合表明，该模型仅需 3 个参数（Υ, V_co, r_co），中位数 χ²_red = 0.68，94.3% 的星系获得有效拟合。与 NFW 暗物质晕模型（同样 3 参数）相比，SPUM 在约 2/3 的星系上 AIC/BIC 更优。

## 1. 引言：暗物质困境与 SPUM 的替代方案

星系旋转曲线——星系外围恒星/气体的绕转速度随半径的变化——是暗物质假说最有力的观测证据。传统 ΛCDM 模型需要每个星系嵌入一个延展的暗物质晕，其质量约为可见物质的 5 倍，才能解释外围速度不随半径下降（"平坦"曲线）。

然而，暗物质假说面临多重困境：所有直接探测实验均无阳性结果；在小尺度（矮星系、星系中心）的预测与观测严重偏离（"核心-尖点问题""卫星星系过多问题"）；ΛCDM 模拟预测的暗物质晕密度轮廓（NFW）与许多星系的旋转曲线形状不符。

SPUM 提供了一种完全不同的解释：**星系外围的平坦旋转曲线不是由暗物质晕的引力维持，而是由星系盘所在的空间粒子子图的整体拓扑运动（子图协动）主导**。这种运动是关系网络 ⟨P, ε⟩ 的自组织现象，不依赖任何不可见物质。

## 2. 子图协动的拓扑定义与速度分布

### 2.1 闭合子图与惯性系锁定

**定义（子图协动）**：设 G ⊂ ⟨P, ε⟩ 是由空间粒子（0 层级节点）构成的大尺度闭合子图（例如一个星系盘）。若 G 的边界满足闭合性条件（无悬挂边，整体拓扑自洽），则 G 作为一个整体可以相对于外部网络运动。这种运动不是由局部密度梯度驱动的"加速"，而是**惯性系锁定**：G 内部的所有物质粒子（恒星、气体）和光子与 G 的空间粒子网络协同运动，局域无法感知该运动。

**定理（子图协动的刚体旋转趋势）**：对于具有轴对称性的盘状子图 G，全局拓扑约束迫使 G 整体围绕对称轴**刚体旋转**：角速度 Ω 在 G 的盘面内为常数，与半径无关。因此，理想情况下切向速度分布为 v_co(r) = Ω·r。然而，实际子图不是无限刚性的：随着半径增大，子图边界并非完全闭合，存在**边缘泄露**——外围空间粒子与外部网络的连接增加，导致有效角速度随半径衰减。

### 2.2 边缘泄露与速度分布

基于离散网络的扩散方程，边界处开口密度随半径增加而增加，角动量的径向传递导致速度分布平滑过渡。最简洁的参数化形式为：

```
v_co(r) = V_co · r / √(r² + r_co²)        [公式 1]
```

其中：
- **V_co**：渐近速度（r → ∞ 时 v_co → V_co）
- **r_co**：特征半径，表征子图从刚体旋转过渡到平坦旋转的尺度

该形式满足：当 r ≪ r_co 时，v_co ≈ (V_co/r_co)·r（刚体旋转）；当 r ≫ r_co 时，v_co ≈ V_co（平坦）。

### 2.3 重子物质的贡献

在 SPUM 中，重子物质（恒星、气体）仍然通过局域空间密度梯度产生引力效应，该效应在短距离内近似为牛顿引力（作为空间密度梯度的线性近似）：

```
v_bar(r) = √(G · M_bar(r) / r)            [公式 2]
```

其中 M_bar(r) 是半径 r 内累积的重子质量（恒星 + 气体），由星系的面亮度分布和气体分布积分得到。这一项在星系内区（r ≲ r_co）起主导作用，在外区逐渐被子图协动取代。

### 2.4 总旋转速度

星系的总旋转速度由重子贡献与子图协动贡献平方和构成（两者相互独立，分别源于局域密度梯度和全局拓扑约束）：

```
v_tot(r) = √( G·M_bar(r)/r + V_co²·r²/(r² + r_co²) )    [公式 3]
```

**参数说明**：
- 模型仅含 **3 个自由参数**：恒星质光比 Υ（用于从面亮度计算 M_bar）、子图协动渐近速度 V_co、特征半径 r_co
- 与 NFW 暗物质晕模型（同样 3 参数）相比，SPUM 的参数具有明确的几何与拓扑意义，且无需引入不可见物质
- 重子质量分布直接由观测光度得到，无需自由缩放

## 3. 基于 SPARC 星系样本的拟合结果

### 3.1 数据与拟合方法

使用 SPARC（Spitzer Photometry and Accurate Rotation Curves）数据库，包含 175 个晚型星系的 3.6 μm 测光数据和高质量旋转曲线。对每个星系：

- 重子质量 M_bar(r) 通过积分面亮度（恒星）和气体面密度（若提供）或气体速度估算得到
- 采用非线性最小二乘法（`scipy.optimize.curve_fit`，TRF 算法）拟合 公式 3
- 参数边界：Υ ∈ [0.1, 2.0]，V_co ∈ [20, 400] km/s，r_co ∈ [0.5, 30] kpc
- 拟合质量由约化卡方 χ²_red = Σ(v_obs - v_fit)²/(σ_v²·(N-3)) 评估

### 3.2 整体拟合质量

在 175 个星系中，**165 个（94.3%）获得有效拟合**（χ²_red < 100）。中位数 χ²_red = 0.68，均值 3.4（受少数高 χ² 星系影响）。

### 3.3 参数分布与物理意义

| 参数 | 中位数 | 四分位距 | 与独立观测的关系 |
|------|--------|----------|----------------|
| Υ | 0.52 | 0.30–0.85 | 与恒星种群模型一致 |
| V_co | 98 km/s | 62–146 km/s | 与 v_max 线性相关 (r=0.94) |
| r_co | 3.1 kpc | 1.4–4.9 kpc | 与盘尺度长 R_d 正相关 (ρ=0.71) |

**关键关系**：V_co = (0.96 ± 0.02) · v_max + (4.5 ± 2.1) km/s，表明子图协动直接决定了星系外区的旋转幅度。

### 3.4 与 NFW 暗物质晕模型的定量比较

| 指标 | SPUM | NFW |
|------|------|-----|
| 自由参数 | 3 (Υ, V_co, r_co) | 3 (Υ, M_200, c) |
| AIC 占优星系比例 | **67.9%** (112/165) | 32.1% |
| BIC 占优星系比例 | **66.1%** (109/165) | 33.9% |
| 平均 ΔAIC | **-167.7** | 0 |
| 平均 ΔBIC | **-165.2** | 0 |

NFW 占优的星系（约 30%）大多为旋转曲线未充分延伸至平坦区或存在明显非轴对称结构的系统。

## 4. 子图协动的物理根源与可证伪预言

### 4.1 物理根源：惯性系的拓扑扩展

子图协动的本质是**惯性系的拓扑扩展**。对于一个大尺度闭合子图，其内部所有物质粒子共享同一个"局部惯性系"，该惯性系相对于背景网络的运动由子图的整体拓扑状态决定。当子图具有轴对称性且边界条件稳定时，该运动表现为刚体旋转（内区）或平坦旋转（外区）。边缘泄露的微观机制是：外围空间粒子与外部网络的连接逐渐增多，导致角动量向外传递，角速度平滑下降。

### 4.2 可证伪预言

1. **环境依赖性**：星系团内部子图受邻近星系扰动，r_co 应系统性小于场星系。预言：团内星系的旋转曲线在外围下降更快。

2. **矮星系核心平坦度**：低质量矮星系中，子图协动可能完全主导，旋转曲线从中心即开始平坦。这与 ΛCDM 的核心-尖点矛盾，可通过高分辨率 HI 观测检验。

3. **无暗物质星系**：SPUM 预言存在极低重子质量的星系，其旋转曲线仍由子图协动主导，表现为完全平坦。已有候选（如 NGC 1052-DF2）的观测初步支持。

4. **旋转曲线形状与星系盘尺度的定量关系**：r_co 与盘尺度长 R_d 的相关性（ρ = 0.71）是 SPUM 独有的预测——暗物质模型无法从重子分布出发解释这种相关性。
