# SPUM 经典纳入计划

> 将中国古代核心文献逐部归约到 SPUM 关系网络本体的路线图。
> 每部经典的纳入 = 完成其核心概念的 T1→T2 翻译，注册节点，建立与根节点 R1-R9 的归约链。

---

## 一、纳入原则

### 准入标准

一部经典具备纳入资格，需满足以下至少两项：

1. **五行可还原性** — 其核心概念可直接映射到五形（水木土金火）拓扑相位或 σ 梯度
2. **网络结构化** — 其描述的是一个可被建模为子图或子网的系统（人体、地表、社会、天体）
3. **操作可定义** — 其操作/干预方法可翻译为 ΔS 五维位移向量或等价图论操作
4. **与已有节点连通** — 可通过归约链连接到至少一个已有的 SPUM 节点

### 排除标准

- 纯叙事/历史记录（无结构化概念体系）→ 不纳入
- 纯粹神秘主义断言，无法做任何形式化翻译 → 不纳入
- 内容完全被已有经典覆盖 → 不纳入（标注为"冗余"）

### 纳入 ≠ 全盘接受

SPUM 不对经典做"辩护律师"——归约后若发现概念本身逻辑不自洽，标注为"❌ 已排除"并记录原因。

## 四、逐部纳入方案

### Phase A：神农本草经

| 项目 | 内容 |
|------|------|
| **归约路径** | 每味药 → ΔS 五维向量 → 对应 S 分量操作定义 → R8(ΔS) |
| **依赖** | 黄帝内经（S 向量框架）、伤寒论/金匮要略（已有方剂的 ΔS 译例） |
| **T1 产出** | 上中下三品分类的 SPUM 翻译 |
| **T2 产出** | 核心药物（约 50 味）的 ΔS = (火, 水, 木, 土, 金) 五维符号向量 |
| **不纳入部分** | 已失传/无法考证的药物；仅有名称无性味的条目 |
| **文件** | `spum-神农本草经.md` |

**归约示例**：

```
人参：
  T1: "土形储备增强剂 + 水形链慢速补给器"
  T2: ΔS = (火=0, 水↑, 木=0, 土↑↑, 金=0)
  操作定义: 向土形储备池注入低度节点，增加水形链介数但不改变流速

大黄：
  T1: "金形修剪器 + 水形链加速冲刷器"
  T2: ΔS = (火=0, 水↑↑, 木=0, 土↓, 金↑↑)
  操作定义: 剪除肠胃水形链上的冗余桥边，加速内容物沿链排出
```

| **归约路径** | 阴阳爻 → 二进制位 → 边 ON/OFF；八卦 → 8 种基础三边构型；64 卦 → 64 种六位状态向量及转移矩阵 |
