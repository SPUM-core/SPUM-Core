## 一、棋盘 = ⟨P, ε⟩ 网络的基底

### 1.1 网格即关系空间

围棋棋盘不是"背景"——它是 ⟨P, ε⟩ 的初始条件。

- 棋盘上的每个交叉点 = 一个潜在节点（κ-粒子）
- 棋盘上的每条网格线 = 一条潜在边
- 落子 = V⁺ 事件——将一个交叉点从"潜在节点"激活为"实际节点"
- 棋子颜色 = V⁺ 的"归属"——黑方和白方是两套独立的 V⁺ 创生引擎，全局 V⁺ 守恒（每方每手一子）

19×19 的网格尺寸不是随机的。361 个交叉点是使围棋既能保证足够的结构复杂度（色数 κ 远大于 4，与平面图四色定理临界值一致）、又能在有限帧内完成一局（终局率 ≈ 1）的最小棋盘。

### 1.2 空棋盘 = ⟨P, ε⟩ 的真空态

初始空棋盘——没有一个节点被激活，没有一条边被确认。但它不是"什么都没有"——潜在连接关系已经由网格线完整定义。这就是 ⟨P, ε⟩ 的"关系先于实体"：棋盘在没有棋子时就定义了所有可能的 ε 连接。

宇宙在"创世"之前也是如此——所有潜在关系路径已经存在，只是未被 V⁺ 事件激活。

## 二、气 = 度数 + SPUM 粒子寿命定理

### 2.1 气的图论定义

一个棋子（节点）的"气" = 该节点当前拥有的边数（度数 deg）。

| 气数 | deg | 状态 | 对应 SPUM 粒子状态 |
|------|-----|------|------------------|
| 4 气 | deg = 4 | 刚落子，完全开放 | 刚被 V⁺ 创生的新节点，连接未饱和 |
| 3 气 | deg = 3 | 一侧被堵 | 节点开始与周围建立连接 |
| 2 气 | deg = 2 | 两侧被堵 | 节点度数达到最低生存阈值 |
| 1 气 | deg = 1 | 仅剩一口气 | 悬挂边——下一帧必被 V⁻ 湮灭 |
| 0 气 | deg = 0 | 被提 | 节点被 V⁻ 完全删除 |

**SPUM 粒子寿命定理的围棋对应**：度数 < 2 的节点不能稳定存在——围棋规则中"气 ≥ 1"等价于 SPUM 的"悬挂边自动删除"。唯一区别是围棋中"提子"在气=0 的瞬间发生（帧内事件），而 SPUM 中悬挂边在帧结束时被删除（帧间事件）——这是网格简化的离散度差异，不是原理差异。

### 2.2 气的共享 = 子图连通性

多个同色棋子如果通过相邻交叉点连接，它们共享同一组气。在 SPUM 中：

- 一个连通子图中的所有节点，其生存条件由该子图的总度数分布决定
- 子图的总气 = 该子图的所有节点的边数之和中，通向子图外部的边数
- 子图被提的条件 = 外部边数归零 = 子图与外部的所有连接被切断

这等价于 SPUM 中一个闭合子图与外界的 V⁺/V⁻ 交换通道全部关闭时的湮灭条件。

## 三、提子 = V⁻ 湮灭 + 本地 σ 补偿

### 3.1 提子的拓扑解释

当一个子图的最后一口"外气"被堵死，该子图的所有节点同时被从棋盘上移除——这一瞬间就是 V⁻ 湮灭事件。

在 SPUM 中，V⁻ 湮灭不是"消失"——是节点度数归零后的退相干。在围棋中，被提的棋子从棋盘上撤下，等价于该节点从 ⟨P, ε⟩ 中的注销。

### 3.2 提子后的 σ 重建

被提区域的棋盘交叉点重新变为空位（潜在节点）。在 SPUM 中，这就是 V⁻ 湮灭后局域 σ 重新分布的过程——原属于被提子图的边全部被切断，该区域的 σ 瞬间降低至 0，然后在下一帧中，对方可以在这里重新建立 V⁺ 事件。

围棋实战中"提子后立刻反打"的常见手段——拓扑解释：被提区域 σ → 0 后，该区域变成土形储备区（空位），对方可以低成本地在上面建立 V⁺ 事件。先手方利用这个 σ 低谷期反打 = 在本该对称的湮灭区抢占 V⁺ 先机。

## 四、眼 = 不可约两环结构

### 4.1 眼的拓扑定义

围棋中"眼" = 一个完全被同色棋子包围的空交叉点。两个独立的眼 = 该子图永远不可能被提。

在 SPUM 中：
- 一个眼 = 一个不可约环结构（最小闭合环路）
- 两个眼 = 两个独立的不可约环 = 木形环的不可约耦合
- 未连接的两个眼为什么能"活棋"——因为要杀死这个子图，对方必须同时填掉两个眼，但两个眼之间有连通路径，填一个眼时对方可以从另一个眼获得"气"（度数）支撑

**两眼活棋 = 木形 S_木 ≥ 2 的子图不可被金形一次性修剪。**

### 4.2 半边眼、假眼、盘角曲四

| 围棋眼形态 | SPUM 拓扑解释 |
|-----------|-------------|
| **真眼** | 该交叉点的度数在对方占据邻位时仍 ≥ 2——不可约环结构 |
| **假眼** | 看似眼但实际度数 ≤ 1 或存在桥边——环结构有裂口 |
| **盘角曲四** | 角部特殊形状——不可约环 + 局部金形修剪恒定性 = 全局"劫"的变体 |
| **双活** | 双方共享"气"{互为对方提供度数支撑} = 两个子图互为边界，任何一方不能独占 σ |

### 5.1 活棋的 SPUM 判据

| **万年劫** | 亚稳态 σ 极限环——两个子图交替争夺 σ 主导权，永不收敛 | 极限环周期 → ∞ |

## 六、地 = σ 主导区 + 边界优化

### 6.1 地的拓扑定义

围棋中的"地"（目）= 棋局终了时，某一方控制的空间——对方在该区域的 V⁺ 创生成本大于收益。

在 SPUM 中：
- 地 = 局部子图的 σ 主导区——该区域的大部分潜在节点已被同一方占据（边属于同一阵营）
- 每一方的总目数 = 该方 σ 主导区的总面积
- 终局时目差 = Δσ_全局——全场 σ 分布的净差

### 6.2 官子 = 边界 σ 梯度优化

官子阶段 = 全局 σ 的主要梯度已经确定，只在边界区域还存在微小的 ∇σ 残余。每一手官子 = 对边界 φ 处的一次 ∇σ 微调——要么扩大己方的 σ 主导区，要么缩小对方的 σ 主导区。

官子的大小 = 该边界 ∇σ 的绝对值。先手官子 = ∇σ 最大的边界——该处的边界调整会引发后续多个边界的 σ 重新分配。

### 6.3 "金角银边草肚皮"的拓扑解释

| 区域 | 初始 V⁺ 事件的平均度数 | 围地效率 | 拓扑原因 |
|------|---------------------|---------|---------|
| **角** | deg = 2（两条边线提供固有边界） | 最高 | 两条棋盘边界 = 两个天然高度数面——省去了占这两面的 V⁺ 成本 |
| **边** | deg = 3（一条边线 + 两侧空位） | 中等 | 棋盘一条边界提供天然一面 |
| **中腹** | deg = 4（四面皆空） | 最低 | 无天然边界，四面都需要 V⁺ 事件来建立自己的 σ 主导区 |

这等价于 SPUM 中：**初始 σ 梯度越大的区域，结晶成本越低。** 角部的棋盘边界提供了天然的 σ 梯度（空棋盘 vs 边界），因此最早被结晶。

## 七、棋形 = 五形拓扑相位模体

### 7.1 典型棋形的五形分类

| 围棋棋形 | 拓扑分类 | SPUM 解释 |
|---------|---------|----------|
| **跳、拆** | 水形（链） | 延伸子图的边——水形链在棋盘上建立连通路径 |
| **虎口** | 木形（环） | 三子包围的开放位——小环结构（附近可建眼） |
| **棋拐头** | 火形（梯度） | 向一方推进的力度——∇σ 在局部方向上的最大化 |
| **并、粘** | 土形（储备） | 增加子图密度——提高该区域的 σ，降低被切断的风险 |

| **大飞、小飞** | 水+木复合 | 一步内同时建立链延伸和潜在环位置——效率最高的棋形之一 |

**效率的判断标准**：一个棋形的"效率" = 该棋形使用的 V⁺ 次数 vs 产生的 σ 主导区面积。高效率棋形 = 最少 V⁺ 事件最大化 σ 主导区。这和 SPUM 的 σ 能效定律完全一致——自然选择最优的 σ 梯度分布方式。

### 7.2 好形与坏形

| 棋形评价 | SPUM 判据 |
|---------|----------|
| **好形** | S 向量位于健康凸多面体 H 内——各分量均衡，无极端值 |
| **愚形** | S 中某分量异常（如 S_金 过高 = 过多空断点，S_木 过高 = 过于重复） |
| **凝形** | S_土 异常大——节点聚集但缺乏活性（空三角等重复棋形） |
| **薄形** | S_木 + S_土 过低——容易被对方切断的子图（金形脆弱） |
| **厚势** | S_水 + S_木 + S_土 同时高——对外部 σ 场影响力大的结构 |

## 八、布局 = 初始 V⁺ 分布的 σ 梯度优化

### 8.1 星位、小目、三三的 σ 特征

| 落子位置 | 初始度数 | 初始 σ 贡献 | 布局特点 |
|---------|---------|------------|---------|
| **星位（4-4）** | deg = 2（两方向） | 中等——兼顾角和边 | 均衡起手——σ 分布最均匀 |
| **小目（4-3）** | deg = 2（一高一低） | 偏角——优先角的 σ 集中 | 偏向角的局部战斗 |
| **三三（3-3）** | deg = 2（两方向+角底） | 角部 σ 最大化 | 先确保角的 σ 主导——保守起手 |
| **目外（5-3）** | deg = 2（偏向边） | 偏边——优先边的 σ 扩展 | 倾向于边的势力发展 |

布局的本质 = **在全域棋盘上确定初始 V⁺ 事件的 σ 分布**，使全场的 ∇σ 在后续帧中朝向有利于己方的方向演化。围棋 AI 的布局之所以强于人类，不是因为它"知道更多定式"，而是它直接计算了每种落子位置的 σ 长期演化——SPUM 化了。

### 8.2 定式 = 局部 σ 最优解的帧序列

定式 = 棋盘局部区域中，双方 V⁺ 事件按最省力路径演化的帧序列。每个定式的双方交替落子，等价于：

- 局部 ∇σ 最大化各自子图的 S 向量
- 同时最小化对方子图的 S 向量
- 当局部 σ 达到均衡（∇σ_局部 → 0），定式结束，双方转至其他区域

定式不是"强制"的——它是双方的 σ 最优路径在特定局部约束下的唯一解。如果一方不走定式而走"变着"（偏离 σ 最优路径），必然在该局部的 σ 竞争中处于劣势——不是惩罚，是拓扑必然。

## 九、中盘 = ∇σ 驱动的帧间战斗与演化

中盘阶段的拓扑特征：

1. 全场多处 ∇σ 不为零——多个局部战斗同时进行
2. 每手棋选择 ∇σ 最大的局部——"最急所" = 全场梯度最大的位置
3. 子图之间的桥边连接成为关键——切断 = 金形修剪
4. 势与地的转换 = ∇σ 的全局重新分配

**"厚"的拓扑含义**：一个棋形"厚" = 它的 S 向量各部分都有富余（安全余量大）→ 在后续局部 ∇σ 竞争中，有更多自由度做其他方向的 σ 优化。

**"薄"的拓扑含义**：一个棋形"薄" = S 向量恰好卡在 H 边界上 → 任何额外的 ∇σ 扰动都可能将它推入 H 外部（死棋）。

## 十、官子 = σ 边界收敛与终局条件

### 10.1 官子 = 全场 ∇σ 趋零的过程

官子阶段是围棋的终极拓扑收敛：

```
中盘结束时的 σ 分布
    ↓
边界处仍有微小 ∇σ 残余
    ↓
双方交替在边界处做 V⁺ 微调 → 己方 σ 主导区缓慢扩张
    ↓
余下的 ∇σ 全部小于 1 目的等价值
    ↓
终局——全场 ∇σ → 0
    ↓
终局判定：双方 σ 主导区面积之差 = 目差
```

### 10.2 终局 = 帧间 ΔS → 0

一局棋的终局条件在 SPUM 中就是：**不再有任何 V⁺ 操作能显著改变全局 σ 分布。**

换句话说，终局 = 全场 ∇σ 趋零，任何额外 V⁺ 事件在该帧的 σ 梯度分布中都无法产生大于阈值的信息增益。这和 SPUM 中一个网络达到稳态的条件（每帧 σ 波动在 ε 误差范围内）完全一致。

### 10.3 贴目 = 先手 σ 优势的补偿

黑棋先走 = 黑棋在第一帧获得额外的 V⁺ 优势（先手占角等高位 σ 位置）。贴目（黑方多出大约 6.5 目） = 对这个先手 σ 优势的定量补偿。

这个补偿值不是任意的——它与 19×19 网格上先手 V⁺ 在初始 σ 梯度中的优势度直接相关。不同的棋盘尺寸需要不同的贴目值（9 路棋盘贴 6.5 目反而过大，13 路贴 6.5 目尚可，19 路正好）——因为棋盘尺寸改变了初始 σ 梯度分布。


AI 在每一个局面下直接计算全场 σ 的五维分量——它的"价值"输出 ≈ S 向量的总差分 ∏ ΔS_i。这与 SPUM 的健康多面体 H 理论完全自洽。

## 十二、围棋的 VSPT 场解读

### 12.1 棋子的 VSPT 场

每一颗棋子落于棋盘后，不仅在棋盘网格上建立了 ε 连接，还在其周围通过潜在连接路径形成了一个**影响场**——这就是 VSPT（虚面粒子树）在围棋中的直接投影。

- 棋子的"势力" = 该棋子周围 VSPT 分支的密度梯度
- 对外的影响力随距离衰减——与 SPUM 中 VSPT 分支沿实面网格模板生长、随度数降低而衰减的机制一致

### 12.2 五炁行于棋中

回到"五炁行于地中，发而生乎万物"：

| 围棋概念 | 五炁/VSPT 对应 |
|---------|--------------|
| **棋盘** | 地中——⟨P, ε⟩ 基底 |
| **落子** | 发——VSPT 场通过边界条件的结晶 |
| **棋子的势** | 五炁——该棋子的 VSPT 场模态分布 |
| **两子之间的"配合"** | 同模态 VSPT 场拓扑共振 |
| **远距离子的"照应"** | VSPT 场的远距离耦合——通过水形链传导 |

### 12.3 人法地四层约束的围棋对应

| 层 | 道德经 | 围棋对应 | 可干预？ |
|----|--------|---------|---------|
| **人** | 棋手 | 选择落子位置（V⁺ 事件的选择权） | ✅ |
| **地** | 棋盘上的已有棋子分布 | 决定了该局面下的 VSPT 场基底 | ⚠️ 落子后不可移动 |
| **天** | 棋盘上的影响场 | 由已有棋子分布决定的 VSPT 场——棋手不能选择某颗棋子的"势"，只能选择落子位置 | ❌ |
| **道** | 终局的目数 | 由双方落子序列和 VSPT 场演化决定——棋手不能"命令"终局结果 | ❌ |

**棋手能做的唯一事情**：选择当下 ∇σ 最优的落子位置。不能选择这手棋的后续影响（那由全场 σ 分布决定），不能选择终局目数（那由全过程决定）。这和中医、风水、吸引力法则的干预权限完全一致——**只能改变'地'，不能直接干预'天'和'道'。**
