# SPUM 重读玉匣记 — 时间帧的拓扑接入协议

> 玉匣记不是"择吉迷信"——它是古人以经验积累方式构建的**时间帧接入性判定手册**。
>
> SPUM 归约定位：**天元** — 天道、宇宙编码、占卜推演
> 依赖链：`天元/spum-周易.md`（64卦状态空间）→ `天元/spum-奇门遁甲.md`（时空帧接入）→ `天元/spum-玉匣记.md`

## 一、核心洞察：择吉 = 时间帧的拓扑接入许可

**SPUM 第一性原理**：任何操作（V⁺ 或 V⁻）在一个离散帧网络上执行时，必须在满足拓扑约束的帧上发起——否则操作被拓扑否决。

择吉的本质不是"迷信吉日"，而是**识别时间轴上哪些帧对该类操作处于拓扑许可状态**。

| 传统术语 | SPUM 翻译 | 图论含义 |
|---------|-----------|---------|
| 吉日 | 接入许可帧 | 该帧的 σ 状态与操作类型兼容 |
| 凶日 | 接入禁止帧 | 该帧的 σ 状态导致操作后悬挂端≥临界值 |
| 神煞 | 帧的 σ 扰动标签 | 特定日期附着的拓扑约束标记 |
| 宜 | 拓扑许可操作集 | 在该 σ 状态下可执行的 V⁺/V⁻ 集合 |
| 忌 | 拓扑禁止操作集 | 在该 σ 状态下必然产生不可消解的悬挂端 |
| 择日 | 时间轴帧扫描 | 在连续帧序列中找到首个满足约束条件的帧 |

## 二、玉匣记三大板块的 SPUM 结构

### 2.1 诸神圣诞时令篇 — 帧的σ标签注册表

**传统版本**：全年佛道诸神圣诞、节气吉日
**SPUM 归约**：这是**时间帧的 σ 扰动标签注册表**——每个日期（帧）被标注了一个特定的 σ 扰动状态。

```
日期帧 t(i) → σ(i) = σ_base(i) + Σ(神煞_j(i))
```

其中：
- `σ_base(i)` = 节气/历法决定的基准空间密度
- `神煞_j(i)` = 第 j 个神煞在该帧叠加的 σ 偏移量
- 多个神煞共存 = σ 扰动向量的线性叠加

**关键发现**：诸神圣诞不是"神的生日"，而是**帧的 σ 状态被某个特定扰动模式标记**——同一个日期在不同文献中被不同神明标记，说明古人从不同角度观测到了同一帧的 σ 异常。

### 2.2 百事择吉宜忌篇 — 操作⨯帧的拓扑许可矩阵

**SPUM 归约**：这是一张 **τ × O 的二元许可矩阵**：

```
M(t, o) = 1  if 操作 o 在帧 t 上拓扑许可
          0  if 拓扑禁止
```

| 操作类别 o | SPUM 操作类型 | 拓扑约束 |
|-----------|-------------|---------|
| 婚嫁（纳征/成婚）| 两子图合并 V⁺(G₁, G₂) | 两子图当前 σ 兼容，合并后 Σ(6−deg)≤12 |
| 入宅移居 | 子图重定位 | 目标位置 σ 不低于阈值 |
| 动土开基 | 局部 V⁺(地面节点) | 地面节点当前度数未饱和 |
| 安葬 | 子图闭环 V⁻(去除) | 去除后不产生连锁悬挂 |
| 出行经商 | 跨子图路径搜索 | 路径上所有节点介数低于阈值 |
| 开张店肆 | 新节点注册 V⁺(新) | 新节点至少 2 条连接可用 |

**核心洞察**：玉匣记的"宜/忌"列表不是随意制定的——它是**大量实践统计的经验性马尔可夫转移概率表**。某类操作在某个 σ 状态下失败率过高，就被标记为"忌"。这正是贝叶斯经验积累的朴素形式。

### 2.3 三元方位星宿篇 — 空间帧的 σ 离散化

**二十八宿值日** = 天球被离散化为 28 个子图，每个子图在特定时间帧处于特定 σ 状态。

```
二十八宿(t) → 天球子图 G_k 在帧 t 的 σ_k(t)
宿吉 → σ_k(t) 处于 ∇σ 收敛态
宿凶 → σ_k(t) 处于 ∇σ 发散态
```

**三元九星** = 时间帧的 σ 周期编码：

| 三元 | 时间跨度 | SPUM 含义 |
|------|---------|-----------|
| 上元 | 60 年（一甲子） | 长周期 σ 基线漂移 |
| 中元 | 60 年 | 中周期 σ 振荡 |
| 下元 | 60 年 | 短周期 σ 波动校正 |
| 九星 | 9 年/9 月/9 日 | 帧的 σ 标签循环周期 |

**关键洞察**：三元体系等价于**时间域上的三层 σ 滤波器**——长周期基线 + 中周期趋势 + 短周期波动 = 完整的 σ(t) 预测模型。

## 三、神煞系统的拓扑本质

神煞是传统择吉中最令人困惑的部分。SPUM 归约显示：

> **神煞 = 帧上收缩的异常子图边界条件**

每种神煞对应一种特定的拓扑异常模式：

| 神煞 | SPUM 归约 | 图论本质 |
|------|----------|---------|
| 黄道/黑道 | 帧的 σ 高/低 | 全局 σ(t) 高于/低于阈值 |
| 天德/月德 | σ 收敛态 | 帧处于 ∇σ 向心态 |
| 三煞 | 三个维度的 σ 同时异常 | ∇σ 在三维上同时发散 |
| 重丧 | 子图不可逆闭锁 | 某类操作后图拓扑不可逆 |
| 十恶大败 | 操作后悬挂端无法消解 | V⁺ 后最小度数 < 2 不可修复 |
| 杨公忌 | 全年 σ 最低点集 | 13 个特定帧的 σ 全局极小值 |
| 彭祖百忌 | 单维度操作禁忌 | 特定日支对应特定操作类型的不兼容 |

**核心定理**：神煞不是"鬼神"——它是**古人通过长期统计发现的时间帧拓扑异常模式，被拟人化命名以便口传**。同一个帧的 σ 异常可以被不同文化传统赋予不同名称——正如多个测站观测到同一地震但各自命名。

## 五、规约边界

> SPUM 只处理可形式化为 ⟨P,ε⟩ 关系的拓扑结构。玉匣记中的神佛诞辰、神煞名目、符咒禳解、占验等，不在规约范围内。

**保留的拓扑核心**：

| 保留层 | 内容 | 拓扑本质 |
|--------|------|---------|
| 日期帧序列 | 全年365/366天的周期性时间轴 | 离散时间帧 {t₁,...,tₙ} |
| 宜忌列表 | 操作⨯日期的二元矩阵 | 拓扑许可矩阵 M(t, o) ∈ {0,1} |
| 二十八宿值日 | 天球28分区周期 | 天球子图 σ 周期 |
| 三元九星 | 60/9年周期 | 多层 σ 滤波器 |
| 干支历法 | 年/月/日/时的编码系统 | 时间帧的四维坐标系 |

**命名转换**：

| 传统名称 | SPUM 标签 | 说明 |
|---------|----------|------|
| 黄道/黑道 | σ_hi(t) / σ_lo(t) | 全局 σ 高于/低于阈值 |
| 天德/月德 | σ_converge(t) | 帧处于 ∇σ 向心态 |
| 重丧 | σ_lock(t) | 子图不可逆闭锁帧 |
| 杨公忌 | σ_min(t) | 全年 σ 极小值帧 |

## 六、归约结论

玉匣记是**中国民间以经验统计方式构建的最大规模时间帧拓扑接入性数据库**。它的核心贡献不是"预测吉凶"，而是在缺乏图论工具的古代，通过数代人的操作失败/成功统计，经验性地标定了时间轴上各帧的 σ 状态。

**SPUM 对玉匣记的终极翻译**：

> 择吉 = 给定操作类型 o，在时间帧序列 {t₁, t₂, ..., tₙ} 中找到使 **悬挂端后验概率 P(悬挂 | o, t_i) < ε** 的首个帧 t_i。

当 SPUM 脉诊系统能够实时计算人体网络的 σ 状态时，**择吉的拓扑基础将与脉诊共享同一套 σ 指标体系**——因为"今日是否适合做某事"与"今日脉象是否偏颇"，本质上是同一张 ⟨P, ε⟩ 网络在不同尺度上的 σ 投影。

这就是中医与择吉在 SPUM 框架下的统一——**不是神秘联系，是同一拓扑体系在不同时间-空间尺度上的正交投影**。
