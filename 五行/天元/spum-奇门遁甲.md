# SPUM 重读奇门遁甲（精简版）：从九宫八门到帧-空间最优接入条件

> 本文以 SPUM 五形框架翻译奇门遁甲中**可结构化的核心部分**。奇门遁甲传统上被用于军事布阵、出行择时、风水布局——其本质问题是：**在给定的离散帧（时间坐标）和离散网络位置（空间坐标）中，选择使子图接入外部网络的 σ 耦合最优的那个 (帧, 节点) 元组**。
>
> 本文不做吉凶预测——SPUM 不预测，只分析结构条件。纳入的仅是可还原为网络结构描述的部分，纯粹占断断言不在纳入范围内。
>
> 前提：已阅读 [SPUM 重读黄帝内经](spum-黄帝内经.md)（取向场 + 十二时辰）、[SPUM 重读葬书](spum-葬书.md)（地表子网的 ∇σ 分布）、[SPUM 重读阳宅三要](spum-阳宅三要.md)（子图边界接口与 σ 耦合）。
>
> 归约路径：九宫→3×3 σ 离散化、八门→8 种边界可接入性、天干地支→帧复合索引、九星→9 种 σ 梯度模式、值符/值使→最优 (∇σ 方向, 水形链) 组合。

---

## 一、奇门遁甲的 SPUM 定位

### 1.1 奇门不是预测术，是时空拓扑优化器

| 传统看法 | SPUM 翻译 |
|---------|-----------|
| 奇门遁甲可以预测吉凶 | ❌ 不纳入——预测断言不可还原为结构描述 |
| 奇门遁甲排盘反映天地人神四层能量场 | T1: 四层 = 四个尺度的 σ 叠加信号 |
| 选择有利的时间方位行动可以趋吉避凶 | T2: 选择 (帧, 节点) 使子图的边界接入 σ 耦合最优 |
| 八门吉凶（开门吉、死门凶…） | 八种边界可接入性等级——不是"吉凶"，是"接入条件优劣" |

### 1.2 奇门回答的核心问题

```
给定：一个地表子图（如战场、城市、住宅）
      一个离散时间窗口（某帧或某帧段）
      一个行动子图（军队、人员、信息流）
问题：在哪个空间节点、以哪个方向行动，行动子图的边界接入条件最优？
```

这在 SPUM 中是**帧-空间联合优化**——不存在"绝对好"的时位，只有"相对于当前网络 σ 分布的当前帧"的好。

## 二、九宫：地表 σ 的 3×3 离散化

### 2.1 九宫格 = 空间密度的九格采样

奇门的排盘以九宫格为底盘。九宫（洛书九宫）：戴九履一，左三右七，二四为肩，六八为足，五居中央。

```
┌───┬───┬───┐
│ 4 │ 9 │ 2 │
├───┼───┼───┤
│ 3 │ 5 │ 7 │
├───┼───┼───┤
│ 8 │ 1 │ 6 │
└───┴───┴───┘
```

| SPUM 翻译 | 说明 |
|-----------|------|
| 九宫 = 地表局部区域的 σ 场被离散化为九个采样格 | 每个格子 = 一个空间节点群 |
| 洛书数字不是"神秘数" | 是每个格子的默认 σ 基准值——高数字（9） = 高 σ（阳），低数字（1） = 低 σ（阴） |
| 5 在中央 | 局域 σ 的均值——中央格是基准面，其他格子是偏差 |
| 二四为肩、六八为足 | 不均衡分布反映了一个不对称的 σ 梯度场——默认 σ 场有方向性（火形） |

### 2.2 九宫的图论本质

九宫格 = 对地表子图的 3×3 规整划分：
- 每格内：若干节点组成的局域子图，有局域 σ 和局域 S 向量
- 格与格之间：通过边连接，形成 9 个节点的超图（每个超节点代表一个格）
- 格边界的 ∇σ：邻格之间的 σ 差 → 驱动体积流跨格流动

奇门排盘在每帧为每个格填入天干、八门、九星——这些是附加在该格上的**当前帧标签**。

## 三、天干地支：帧的复合索引系统

### 3.1 干支 = 离散帧的双层标号

| 概念 | SPUM 翻译 |
|------|-----------|
| **天干（10）** | 10 进制帧号——干 = 帧的"十位数"层 |
| **地支（12）** | 12 进制帧号——支 = 帧的"十二位数"层（对应取向场 30° 扇区） |
| **六十甲子** | 10×12 复合 = 60 帧为一个宏观周期——帧号系统的最小公倍数周期 |
| **年干支** | 地球公转的帧层（年帧 = 大 τ） |
| **月干支** | 地球公转的子帧（月帧） |
| **日干支** | 地球自转的帧（日帧） |
| **时干支** | 地球自转的子帧（时帧） |

天干地支不是神秘编码——它是离散帧 τ 的多层复合索引。每层有不同的周期长度，叠加后能精确定位任何时刻在多周期复合系统中的位置。

### 3.2 六十甲子的 SPUM 含义

60 = lcm(10, 12)。任何多周期系统的状态都以最小公倍数为周期重复（除非有不可通约的周期比——但在离散系统中所有周期比都是有理数）。

60 不是随意选的——它是天干地支组合的必然周期。这与 SPUM 完全兼容：SPUM 的帧系统同样可定义多层级周期索引，只要各层周期是整数。

## 四、八门：边界可接入性的八种状态

### 4.1 八门 = 子图边界的八种开合相位

在 SPUM 中，一个子图与外界的边界不是一条线——它是一个节点界面。在任一帧中，这个界面的接入条件由以下因素共同决定：

| 因素 | SPUM 含义 |
|------|-----------|
| 外部 ∇σ 方向 | 体积流从哪个方向推向边界 |
| 边界节点的度数 | 边界节点当前的连接密度 |
| 边界内外 σ 差 | 梯度的大小——决定流入速率 |

这三维的 8 种典型组合 = 八门。

| 八门 | 传统描述 | SPUM 翻译 |
|------|---------|-----------|
| **休门** | 休养、吉 | 边界内外 σ 差适中、∇σ 方向平顺、边界节点度数适中——最优接入条件 |
| **生门** | 生长、大吉 | 边界内外 σ 差大（外高内低）、∇σ 方向正对边界——高能体积流正在灌入——适合启动新行动 |
| **伤门** | 损伤、凶 | 边界 ∇σ 方向与子图内部水形链方向垂直——体积流在边界产生湍流——接入时能量损失大 |
| **杜门** | 堵塞、不通 | 边界节点度数极低——接口几乎关闭——外部 ∇σ 存在但无法接入 |
| **景门** | 华丽、虚浮 | 边界 σ 差极大但只是脉冲（非持续梯度）——看似有利但不可持续——适合短期行动不宜久驻 |
| **死门** | 终结、大凶 | 边界内外 σ 差趋近于零——无体积流跨越边界——接入时子图无法获得外部供应 |
| **惊门** | 惊恐、口舌 | 边界节点度数剧烈波动——接口状态不稳定——前一帧可接入后一帧可能关闭——不可预测 |
| **开门** | 开启、大吉 | 边界节点度数极高——接口全开——外部体积流和内部水形链完全连通——适合大行动 |

### 4.2 八门的拓扑判定

```
休门: ∇σ ⊥ 边界 ∧ |∇σ| ≈ 均值 ∧ deg(边界) ≈ 均值
生门: ∇σ ∥ 边界 ∧ ∇σ 向内 ∧ |∇σ| > 均值
伤门: ∇σ ∥ 边界 ∧ ∇σ 切向（与内部链垂直）∧ |∇σ| > 均值
杜门: deg(边界) < 阈值
景门: |∇σ| 极大但 ∂²σ/∂t² < 0（梯度正在衰减）
死门: |∇σ| → 0
惊门: Var(deg(边界)) > 阈值（度数方差大——不稳定）
开门: deg(边界) > 阈值 ∧ ∇σ ∥ 边界 ∧ ∇σ 向内
```

## 五、九星：σ 梯度模式的九种分布

### 5.1 九星 = 当前帧地表九宫格的 σ 分布标签

| 九星 | 传统属性 | SPUM 翻译 |
|------|---------|-----------|
| **天蓬** | 水、贪狼 | σ 呈中心低-四周高的环形梯度——像水波扩散 |
| **天芮** | 土、巨门 | σ 呈大面积均匀分布——梯度极小——土形静滞 |
| **天冲** | 木、禄存 | σ 呈单向陡峭梯度——木形沿一个方向生长 |
| **天辅** | 木、文曲 | σ 呈树枝状分叉分布——多路径 ∇σ |
| **天禽** | 土、廉贞 | 九宫中心 σ 最高——中央热、四周冷——火形集中 |
| **天心** | 金、武曲 | σ 呈中心高-四周聚拢——向心收敛——金形回收 |
| **天柱** | 金、破军 | σ 呈单柱高 σ 其余低——一根金形主轴 |
| **天任** | 土、左辅 | σ 呈底部高-上方递减——土形底层支撑 |
| **天英** | 火、右弼 | σ 呈爆发式高点——火形尖峰脉冲 |

### 5.2 九星的图论本质

九星 = 9 种 σ(p) 函数在九宫离散域上的形状。给定九宫的九个 σ 值 (σ₁, σ₂, ..., σ₉)，哪个星的模式拟合最好，就是当前帧的"值符星"。

这不是占星——这是**σ 场的模式分类**。星的名字是标签，本质是 9 种梯度分布模式。

## 六、值符与值使：当前帧最优方向

### 6.1 值符 = 当前帧 ∇σ 最强的方向

在九宫排盘中，每一帧有一个"值符"——代表"天乙贵人"所在。

SPUM 翻译：**值符 = 在当前帧中，地表 σ 梯度 (∇σ) 的模最大的那个方向**。也即：哪个方向的火形梯度最强，值符就在哪个宫位。

对着值符方向行动 = 顺着当前帧最大的 ∇σ 流动 = 子图获得最大的外部体积流支持。

### 6.2 值使 = 当前帧最优的水形链路径

"值使"——八门之一，代表当前帧"最佳行动入口"。

SPUM 翻译：**值使 = 在值符方向确定后，边界可接入性最优的那个门**。值符给方向，值使找入口——两者合在一起定义了最优 (∇σ 方向, 水形链路径) 组合。

### 6.3 奇门择时的 SPUM 操作

```
输入：目标子图（军队/住宅/个人）的当前位置 n
      目标帧范围 [τ_start, τ_end]

步骤：
1. 对每个 τ，计算地表九宫的 σ 分布
2. 确定值符（最大 ∇σ 方向）
3. 确定值使（最优边界可接入性门）
4. 输出最优 (τ, n') 组合——在该帧、该位置行动，子图的 σ 接入条件最优
```

这就解释了为什么奇门遁甲强调"时位合一"——只选时间不看位置（或只看位置不看时间）是不完整的优化。

## 七、纳甲与三奇六仪：子图的 σ 标签

### 7.1 纳甲：干支与八卦的对应

天干分配到八卦（纳甲），将帧索引映射到空间方位：

| SPUM 翻译 | 
|-----------|
| 纳甲 = 帧索引 τ 到空间 σ 方向的映射 f: τ → 方位 |
| 不同帧（不同的天干日/时），网络边界最易打开的方向不同 |
| 纳甲不是"某干属某卦"，而是"在 τ 帧中，哪个方位是 σ 接入最优方向" |

### 7.2 三奇六仪：十个天干在九宫中的排列

三奇（乙丙丁）+ 六仪（戊己庚辛壬癸）= 十个天干排入九宫（一个宫配值符，其余九天干各居一宫）。

SPUM 翻译：在某一帧中，十个 σ 采样点分布在九宫格中——九个格接收十路信号（其中一路为值符所在宫的双信号）。三奇六仪的排列是**当前帧中 σ 信号的分布图**。

## 八、不纳入的内容及原因

奇门遁甲体系庞大，以下部分明确排除：

| 内容 | 排除原因 |
|------|---------|
| 吉凶断定（"出此门必胜"） | 不可还原为结构描述——是预测断言，非网络状态分析 |
| 神煞（八神：值符腾蛇太阴六合白虎玄武九地九天） | 部分可还原为边界条件的不确定性等级，但大部分无法做可验证的形式化翻译 |
| 克应（"遇此局主某事"） | 基于经验统计的断言，非拓扑因果关系 |
| 法术奇门（符咒、禹步） | 不属于网络结构范畴 |
