## 四、病机链分析

### 病理链（怒→月经不调→误服→不良反应）

```
═══ 病机链分析 ═══

[一级病机] 长期工作压力 + 情志不遂 → 木形环微郁（S_木↑温和）
           ↓乘土
[二级病机] 木克土过亢 → 土形储备消耗加速（S_土↓↓↓）
  输入：饮食不规律 + 月经消耗 + 带脉不固持续外泄
           ↓不生火
[三级病机] 土不生火 → 火形梯度下降（S_火↓↓）
           ↓不化水
[四级病机] 火不足→水形流速减慢（S_水↓）
              → 血行不畅 → 月经推后量少
              → 带脉约束环失养 → 白带外泄
              → 进一步消耗土形（恶性循环）
           ↓
[临床表现] 月经不调 + 白带过多 + 精神不振

═══ 误用大黄蛰虫丸后的二级病理链 ═══

[误服输入] 大黄蛰虫丸的 ΔS = (木↑, 火↓↓, 土↓, 金↑↑, 水↑↑)
           同时服用的补方 ΔS = (木↓↓, 火↑↑, 土↑↑↑, 金↑, 水↑)
           （两方联用相关信息在第3轮才完整获取）
           ↓
[网络冲突] 两方拓扑操作方向相反：
  补方：ΔS_木↓↓ + ΔS_火↑↑ + ΔS_土↑↑↑（松弛/提升/建立）
  攻方：ΔS_木↑ + ΔS_火↓↓ + ΔS_金↑↑ + ΔS_水↑↑（收紧/压制/摧毁）
           ↓
[网络混乱] 同一网络被两套互逆操作冲击 → 无法收敛到任何稳态
  具体表现：
  1. 火形被同时推拉（补方提升 + 攻方压制）→ 局部过热 + 整体驱动力不足
     → 体表散热通道冲突 → 类中暑症状（闷热气候下放大）
  2. 土形被建立又被冲走（补方补土 + 攻方大黄排空）
     → 胃肠子图无法建立稳态 → 呕吐 + 腹泻
  3. 木形被同时松弛和收紧 → 中枢子图微循环紊乱 → 头晕
```

### 关键鉴别点

与大黄蛰虫丸正治适应症（干血劳）的核心鉴别：
- **干血劳特征**：五劳虚极 + 内有干血 + 肌肤甲错 + 两目黯黑
- **本例缺失**：无肌肤甲错、无两目黯黑——瘀血指征不足
- **结论**：非干血劳证，不能用大黄蛰虫丸

## 七、核心病理机制提炼

### SPUM 关键洞见

1. **怒→经闭的五步病理链**
   - 怒 = 木形环突发暴冲 → 木克土 → 土形被压制 → 木生火异常/火形走窜 → 周期性子图 V⁺ 停滞 → 病理性亚稳态形成

2. **大黄蛰虫丸的适用边界**
   - 正治：干血劳（五劳虚极 + 肌肤甲错 + 两目黯黑 = 金形修剪对象清楚）
   - 误治：虚证夹郁（本例）→ 金形修剪的对象不存在 → 切割正常结构 → 网络损伤

3. **攻补互斥的拓扑本质**
   - 补方 ΔS 与攻方 ΔS 在三个维度上方向相反
   - 同一网络同时执行两套互逆的 V⁺/V⁻ 操作序列 → 网络不可能收敛到任何稳态
   - 不良反应不是巧合——是拓扑混乱的必然结果

4. **闷热气候作为放大器**
   - 体表散热需要火↑↑
   - 攻方黄芩将火形压到临界点以下
   - 补方尝试提升火形但与攻方冲突
   - → 核心热无法排出 → 类中暑症状
