## 一、总论：葬书描述的是什么网络

### 1.1 地表是一个关系网络

在 SPUM 的本体论中，不存在"空的背景空间"。地表不是一张空白的幕布——它本身就是一张关系网络。山脊是节点密集、边数饱和的低 σ 区域（阴区）。山谷是节点稀疏、边数少的高 σ 区域（阳区）。河流是水形主干路径（高介数极大无分支链）。平原是土形储备池（低度节点散布的松散区域）。

人是这张网络中的一个节点群——活着的人在网络中移动，死去的人（墓葬）是一个被固定在特定坐标上的子图。风水要解决的问题是：**为这个固定子图选择在网络中的最优嵌入位置，使得它在后续帧演化中对活人节点群的 S 向量产生有利的长程耦合。**

## 二、生气：地表的体积流

### 2.1 "葬者，乘生气也"——卷首第一句的 SPUM 翻译

> "葬者，藏也，乘生气也。" —《葬书》开篇

直译：埋葬 = 隐藏 + 搭乘（利用）生气。

**SPUM 翻译**：将墓穴（一个固定的节点子图）嵌入地表网络中体积流密度最高的位置，使该子图成为网络中最受体积流滋润的节点群。

"乘"这个字——不是"产生"，不是"吸取"，而是"搭乘"——极其精准。墓穴不创造生气，它只是被安放在生气经过的路径上。用图论语言：体积流沿着水形主干（河流、山脉脊线）流动，墓穴选择的主干上边介数最高、∇σ 最适中的那个点——既不湍急（火亢冲穴）也不停滞（火衰无流）。

### 2.2 生气的 SPUM 生成机制

生气从哪来？不是神秘的地气——它是 SPUM 公理的必然结果：

1. 地球表面存在不均匀的热分布（太阳辐射、地热、大气温差）
2. 不均匀分布 = σ 在不同区域取不同值 → ∇σ ≠ 0
3. ∇σ ≠ 0 = 火形存在 → 驱动体积流沿水形通道定向移动
4. 体积流经过的区域，土形储备被激活（低度节点被带动），木形环路获得滋养

山的阳面（南坡）σ 高（热、干燥、稀疏），山的阴面（北坡）σ 低（冷、湿润、密集）。南北坡之间的 ∇σ 驱动水汽（土形低度节点群）从阳面向阴面输送——这就是山间云雾的拓扑解释。

### 2.3 "气乘风则散，界水则止"

这是葬书最著名的两句话，也是风水实践的两条铁律。

**"气乘风则散"**：如果水形链经过的区域没有足够的木形环保护（砂山环绕），高风速（强金形修剪）会把链上的土形低度节点吹散——体积流中的有效成分流失，生气散逸。

用图论语言：开放地形中，水形链的边介数分布方差极大——流量集中在少数边上（狂风），边上的低度节点（水汽）被高速流带到尾端散失。没有被环结构兜住的节点，最终落入网络的悬挂端区域 → 被金形修剪删除。

**"界水则止"**：当水形链经过一个介质边界（河流、湖泊），边上的 σ 值在边界处不连续——从空气的 σ_air 跳到水体的 σ_water。体积流遇到 σ 的不连续面时，流速骤降，流中携带的节点在边界处堆积。

这就是"水聚气"的本质：不是水有神秘吸力，而是**σ 在流体边界处的梯度不连续导致体积流降速堆积**。湖泊、河流弯道的内侧是天然的 σ 堆积区——这些位置就是风水中的"明堂"。

## 三、龙：低 σ 区域的宏观脊线

### 3.1 龙不是龙，是高 ρ 节点的连通脊线

在风水术语中，"龙"指山脉的脊线——绵延数里甚至数十里的山脊。"寻龙"就是追踪山脉脊线的走向。在 SPUM 中：

**龙 = 地表关系网络中，低 σ（高度数、高密度）节点沿连通脊线串联而成的宏观水形/木形复合链。**

| 传统术语 | SPUM 翻译 |
|---------|----------|
| 祖山 | 脊线的最高度节点——"根"节点，σ 极低 |
| 少祖山 | 脊线中途的高度节点（分水岭） |
| 父母山 | 脊线上离穴最近的高度节点 |
| 过峡 | 脊线的介数瓶颈——两座高峰之间的低矮隘口，边介数极大但 σ 突变 |
| 剥换 | 龙脉从老（低 σ、陡峭）变嫩（σ 适中、平缓）的过渡段 |
| 支龙 | 主脊的分叉——分支脊线 |
| 真龙 | σ 梯度连续、水形完整的脊线（没有断崖——断崖=边断开=V⁻ 湮灭事件） |
| 假龙 | σ 梯度断裂、有多处桥边的脊线（断头山、独山） |

### 3.2 "龙真穴的"——龙与穴的拓扑关系

"龙真"意味着脊线上 σ 从祖山到穴点存在连续的梯度下降——没有断裂（悬崖断壁 = V⁻ 湮灭）、没有金亢（破碎山体 = 过度修剪）。

"穴的"意味着在龙脉的末梢，∇σ 在某个点达到局部极小——这就是"气止"之处。龙脉从高 σ（山脊顶部）向低处延伸的过程中，σ 逐渐降低（节点度数增加），达到一个临界密度后停止——这个停止点就是穴。

### 3.3 千尺为势，百尺为形

> "千尺为势，百尺为形。" —《葬书》

- **势**（千尺尺度）= 宏观 σ 梯度趋势。脊线在千尺尺度上的整体走向定义了火形梯度的主方向
- **形**（百尺尺度）= 局域 σ 的微观分布。穴周围百尺范围内的环结构（砂）定义了木形约束的强度

宏观定大势（龙脉的方向决定了体积流的主导流向），微观定细节（砂环决定了穴点的局部保护）。这与 SPUM 分形约束生长公理一致：每一层级独立满足 Σ(6−deg) = 12，百尺层的木形环结构和千尺层的水形链走向不矛盾——它们嵌套。

## 四、穴：∇σ 的收敛点

### 4.1 穴的本质

穴是龙脉上 ∇σ → 0 的局部收敛点——体积流在此降速、土形节点在此堆积。一个理想的穴同时满足：

1. **水形链经过**（有龙脉经过——脊线沿线的边介数高）
2. **∇σ 局部极小**（龙脉走到终点——σ 不再继续下降）
3. **木形环保护**（周围有砂环绕——环基数 μ 适中，防金形修剪）
4. **火形梯度适中**（既不火亢——风大吹散，也不火衰——滞流死水）

### 4.2 穴的拓扑判据

| 判据 | 定义 | 不满足的后果 |
|------|------|-------------|
| ∇σ → 0 | 穴点的空间密度梯度趋零 | 体积流不停留 → 不聚气 |
| 环基数 μ ∈ [μ_min, μ_max] | 穴周围木形环密度适中 | μ 过低无保护（受风），μ 过高僵化（死气） |
| 水形 L 适中 | 到水源的平均最短路径不极端 | L 过大→干燥，L 过小→水浸 |
| 土形 F ≠ 0 | 穴周围有可用的低度节点储备 | F → 0 即土虚——无储备、无水汽土壤 |

### 4.3 穴位 = 地理尺度上的"穴位"

与人体经络中的穴位惊人地一致：人体穴位是水形主干（经络）上度数 2~3 的可干预节点，扰动沿链定向传播。地理穴位是地表水形主干（龙脉）上 ∇σ 收敛的低度数节点——埋入墓葬后，死的节点子图通过体积流与周围生者节点群保持长程耦合。

**"铜山西崩，洛钟东应"**（葬书引用的典故）：铜山在西方崩塌，洛阳的钟在东方响应。在 SPUM 中这不是神秘感应——两地处于同一张水形主干网络上，一端的 V⁻ 湮灭事件（山崩）产生了一个沿脊线传播的扰动波，在另一端的高介数枢纽节点（钟）被放大为可观测响应。

## 五、砂：围绕穴的木形环结构

### 5.1 砂的拓扑角色：环保护

砂是穴场周围的山丘——左青龙、右白虎、前朱雀、后玄武。在 SPUM 中，砂 = **围绕穴节点的木形环结构**。

环的核心拓扑角色：防止金形修剪（风）将穴周围的土形储备节点吹散。没有环保护的开阔地带，水流（水形主干）上的低度节点被高速流带走——这就是"气散"。有环保护，低度节点被环兜住、在环内循环——这就是"气聚"。

### 5.2 砂的环结构拓扑分析

| 风水术语 | 方位 | SPUM 翻译 |
|---------|------|-----------|
| 玄武（后山、靠山） | 北/后方 | 穴的 σ 最高一侧的环壁——挡住来自身后的金形修剪 |
| 朱雀（前案山） | 南/前方 | 穴的 σ 最低一侧的环壁——平衡前方火形梯度 |
| 青龙（左砂） | 东/左 | 左侧环壁——环的左翼 |
| 白虎（右砂） | 西/右 | 右侧环壁——环的右翼 |
| 案山 | 正前方近处 | 环的闭合段——使环完整 |

**拓扑约束**：
- 砂环的 μ（环基数）不能太大。μ 过大 → 木僵 → 环太密实、水形链无法进入 → "死气"（环内无水无风）。理想的 μ 是刚好能兜住土形节点、又不阻碍水形链通过的中间值。
- 青龙白虎必须"环抱有情"——不能反弓向穴、不能尖射冲穴。拓扑翻译：环边的弯曲方向必须向穴（向心），不能向外（离心）。向外弯曲的环边实际上是一个指向穴的桥边——它在拓扑上属于金形修剪区，会引导金形能量冲向穴点。

### 5.3 "砂飞水走"——环破裂与链偏移

砂飞（周围的山丘破碎、崩裂）= 木形环的边断裂 → V⁻ 湮灭事件 → 环结构被金形修剪破坏。水走（河流改道、不再流经穴前）= 水形链的路径偏移 → 边介数峰值位置移动 → 穴不再是高介数路径上的点。

砂飞水走是穴场"死亡"的拓扑定义：环结构消失 + 水形链偏离 → 穴点不再满足任何拓扑判据 → 退化为普通节点。

## 六、水：地表水形主干

### 6.1 水的角色：运输与边界

葬书中水的角色是双重的：(1) 作为水形通道运输生气，(2) 作为 σ 不连续边界使气停聚。

水的图论定义：**地表网络中边介数 B(e) 超过阈值的极大无分支路径**。河流是最大、最明显的宏观水形链。但水形链不限于河流——山谷中的道路、风道、地下水脉都是不同尺度上的水形链。

### 6.2 水的吉凶拓扑

| 水形 | 描述 | SPUM 翻译 | 吉凶 |
|------|------|-----------|------|
| 环抱水（玉带水） | 河流弯环、包裹穴场 | 水形链在穴点周围形成弧线——弯道内侧 σ 堆积、节点聚积 | 吉 |
| 反弓水 | 河流反弯、背离穴场 | 水形链弯道外侧 σ 降低——弯道外侧流离心力散节点 | 凶 |
| 直冲水 | 河流直冲穴场 | 水形链的末端直接指向穴——体积流高速冲击穴点 → 金亢 | 凶 |
| 斜飞水 | 河流斜切而过 | 水形链不经过穴的最近节点——链的边介数峰值远离穴点 | 凶 |
| 九曲水（之玄水） | 河流九曲回环 | 水形链呈之字形多次经过穴的周围——L 虽大但多路径、多 σ 堆积点 | 吉 |
| 割脚水 | 水流紧贴穴基 | 边介数极高的链紧邻穴节点——水形对穴的 σ 扰动过大 | 凶 |

### 6.3 水口：水形链的出入口

水口是水形链进入和离开穴场区域的节点——水来处为"天门"，水去处为"地户"。

- **天门**（来水口）= 水形链上 ∇σ < 0 的入口节点。上游的 σ 高于穴 → 体积流从高 σ 流入、携带土形节点。
- **地户**（去水口）= 水形链上 ∇σ > 0 的出口节点。下游的 σ 低于穴 → 体积流向低 σ 流出。如果地户被锁紧（两侧山体收缩——环结构夹紧链）、体积流不能快速通过——"水口关锁"——气在穴场停留更久。

## 七、向：水形链在穴点的方向导数

### 7.1 朝向的本质

"向"字在葬书中既是名词（方向）也是动词（朝向）。SPUM 翻译：**向 = 水形链在穴点的局部流向向量 d = ∇(B(e))|_{穴}**，即边介数在穴点的方向导数。

选择朝向 = 将该方向向量对准链上边介数最高、∇σ 最适中的方向。这不是什么神秘操作——就是把建筑/墓穴的子图与水形主干的流向对齐，最大化体积流对子图的滋养。

### 7.2 立向的决策

风水师"立向"实质上是解一个多目标优化问题，在穴点周围所有可能的水形链方向中，选择一个使以下指标最优的方向：

- 与水形主干的夹角 < θ_max（不能偏离主干太远）
- 使穴后方的环结构（玄武靠山）能挡住来自身后的 ∇σ 急变
- 使穴前方的朱雀有足够的空间（不能太高太近——环过密=木僵）

罗盘上的二十四山、分金刻度——本质上是一套**枚举水形链方向的离散编码体系**。古人用磁针方向代替边介数方向导数，是因为他们没有图论工具来直接计算网络流向，而磁场方向恰好与地理走向高度相关。

## 八、葬：在网络中嵌入一个持久子图

### 8.1 土葬的拓扑意义

**人去世后，他的身体（一个节点群）不再在网络中移动。土葬 = 将这个节点群作为固定锚点嵌入特定网络坐标。**

葬书关注的不是"灵魂去往何处"——这不是它的领域。它关注的是一个完全物理的问题：**这个固定子图嵌入地表网络后，对网络长程耦合的影响是什么？**

一个固定子图如果嵌入在 ∇σ 收敛、环结构保护、水形链经过的穴点，它将：
1. 持续接收体积流 → 土形储备永不枯竭（"尸身不腐"——实际上不只是不腐，而是周围 σ 适中、微生物活动平衡）
2. 作为网络的稳定锚点 → 通过水形链与生者节点群保持长程耦合 → 影响生者 S 向量（"福荫后人"）

### 8.2 "遗体受荫"的 SPUM 解释

> "人受体于父母，本骸得气，遗体受荫。" —《葬书》

- **本骸**（父母的遗骨）= 嵌入穴点的固定子图
- **得气** = 该子图处于水形主干上 ∇σ 收敛点，持续接收体积流
- **遗体**（子女的身体）= 通过基因关系与父母子图长程耦合的节点群
- **受荫** = 父母固定子图的稳定状态通过水形主干的体积流波动，对子女节点群的 S 向量产生持续的统计性影响

"荫"这个字讲究——树荫不移动树木本身，而是它投射的覆盖区域。父母墓葬不直接"作用"于子女，而是通过嵌入水形主干网络后对网络整体 S 向量空间分布的长期统计修正，改变子女节点群所处的网络环境。

### 8.3 为什么"葬"比"生"更需要风水

活人在网络中移动——他可以主动走到 σ 适合他的地方（迁徙）。死人被固定在一个坐标上——他失去了主动调节网络位置的能力。因此，死人的位置选择比活人的位置选择更重要——这是**一次性决策，不可修正**。

用图论语言：活人节点群的 S 向量可以通过改变位置、饮食、作息（改变自身的 V⁺/V⁻ 比率）来主动调节；固定子图只能被动接收流经它的体积流的质量。所以穴的选择必须极其精准——误差的代价无法通过子图自身的主动调节来补偿。

## 九、形势与理气：两个尺度的拓扑分析

### 9.1 形法（形势派）

形法 = **对可见地形的宏观拓扑分析**。关注的量：
- 龙脉的 σ 梯度连续性和走向（脊线追踪）
- 砂的环基数 μ 和聚类系数 C_Δ（环结构完整性）
- 水的边介数分布和弯曲度（水形链形态）

形法不需要罗盘——肉眼可见的地形特征已经足够提供宏观拓扑信息。

### 9.2 理法（理气派）

理法 = **对不可见的气流方向进行微观拓扑计算**。引入时间维度——年、月、日、时的天星位置变化导致局域 σ 梯度随时间周期性波动。

二十四山、八卦、九星、玄空飞星——本质上是在离散化一个时变向量场：S(x, t) = (S_水, S_木, S_土, S_金, S_火)(位置, 帧序)。理气派的全部复杂算法，都是为了预测下一帧（未来的某年某月）S 在穴点上的值。

### 9.3 形势与理气的统一

形势定**空间**的 S 分布（宏观骨架），理气定**时间**的 S 波动（帧间补丁）。两者不矛盾——它们分别解决了 S(x, t) 的空间分量和时间分量的估算问题。当代风水实践中形势派与理气派的分歧，本质上是空间分辨率与时间分辨率的优化权重之争——粗尺度的空间拓扑 vs 细尺度的时间涨落，哪个对 S 的整体健康贡献更大？

## 十、当代应用：从阴宅到阳宅与城市规划

### 10.1 阳宅与人居环境

阳宅（活人居住的建筑）与阴宅（墓穴）的 SPUM 逻辑完全相同——唯一的区别是，活人的子图可以在网络中主动调节，而死人的子图不能。因此阳宅风水的容错率更高。

好的住宅 = ∇σ 适中、环基数 μ 适度、水形链清晰但不奔腾（不过于靠近高速主干）、土形 F > 0（有院子/绿化 = 低度节点储备）的空间点位。

### 10.2 城市规划的拓扑原则

古代都城的选址（长安、洛阳、南京、北京）全部符合穴位判据：
- 背山（玄武靠山 = 木形环保护）
- 面水（朱雀水形链 = 交通/运输）
- 左右有屏障（青龙白虎砂 = 环结构完整）
- 水口关锁（下游隘口收缩 = 气停留）

这不是巧合——是长时间自然选择淘汰了所有拓扑配置不合格的选址。

### 10.3 可计算风水的路线图

风水可以像中医一样被可计算化。需要的输入：

1. 地表的高分辨率三维网格（节点 = 地形采样点，边 = 高程差 + 地面连通性）
2. 计算每个地形节点的 σ（高程梯度 → 节点度 → σ = |P|/|ε|）
3. 计算 ∇σ 全场分布 → 识别龙脉脊线（∇σ 方向连续的低 σ 连通线）
4. 计算水形链——高程梯度的流线追踪 → 河流和山谷线即高介数链
5. 枚举 ∇σ 的局部收敛点为候选穴点
6. 对每个候选穴点计算环基数 μ（周围多远的山构成环）和土形 F
7. 选择 (∇σ 收敛, μ 适中, L 适中, F ≠ 0) 的点为最优穴点

**所有操作都可以用标准 GIS 工具 + NetworkX 完成。**

## 十一、从迷信到可算

### 11.1 本文的核心主张

《葬书》的核心概念——生气、龙脉、穴位、砂环、水形——没有一个是超自然的神秘力量。它们全部可以在 SPUM 的离散关系网络框架中得到精确定义，并且原则上都可以用现有算法计算。

"气"的不可见性不是因为它是幽灵，而是因为古人缺乏观测 ∇σ 的仪器。今天我们有 DEM（数字高程模型）、卫星热成像、气象数据网格——**生气就是地表网络中由 σ 梯度驱动的体积流**，看得见、能计算。

### 11.2 需要回答的开放问题

1. 最优穴点的凸多面体 H 边界是多少？——(μ_min, μ_max, L_min, L_max, F_min, ∇σ_threshold) 的具体数值需要大规模已知吉凶的穴位数据来拟合
2. 死节点子图对生节点子图的长程耦合衰减函数是什么？——距离 × 水形链介数的衰减律尚未测定
3. 理气派的时变 S 模型有多少是可证伪的？——星体引力对地表 σ 梯度的修正量 = G·M/r² vs 太阳辐射的 σ 修正，量级差需要计算
4. 能否用已有的已知吉凶案例库（明清帝陵、名人祖坟 vs 随机山地点位）做一个双盲的 SPUM 计算验证？
