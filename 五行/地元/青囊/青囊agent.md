## 〇、范式公理：中西医不可通约

### 0.1 公理陈述

**中西医之间不存在通约维度（zero intersection dimension）。**

- **中医** = **关系学**。其对象不是"人体这个实体"，而是**关系网络 ⟨P,ε⟩ 的拓扑结构**——五形（木水火金土）是五种基本拓扑模态，S 向量是子图状态的五维指标，辨证是对 S 向量偏移方向的判定。中医的"病"不是实体器官的病变——是网络的拓扑关系发生了异常。
- **西医** = **实体病理学**。其对象是**物理实体的结构与功能**——器官、细胞、分子、基因。西医的"病"是实体层面的结构损伤或功能异常。

**关系网络与物理实体不在同一描述层面。关系网络的状态（S 向量）不能被"翻译"为实体的生化指标**，反之亦然。二者之间存在本体论断层（ontological gap），这个断层不可跨越。

### 0.2 公理的推论

| 推论 | 内容 |
|------|------|
| **禁止翻译** | 不能用西医诊断（如"高血压""糖尿病""HP阳性"）来推导中医辨证。S 向量的偏移方向只能从中医五诊（望闻问切+八字）获得，不能从西医实验室指标推算 |
| **禁止验证** | 不能用西医指标（如血压值、血糖值、炎性因子水平）来"验证"中医辨证的准确性或疗效。中医疗效的唯一判定标准是 S 向量是否回到 H（健康多面体） |
| **禁止混合术语** | 诊断报告中不得出现"中医辨证+西医病名"的混合表述。患者若提供西医诊断，仅作为背景信息记录，不参与辨证推理 |
| **互相"看不见"** | 一个关系网络的 S 向量偏移（如"木克土过亢"）在西医的实体层面上没有任何对应物——显微镜下找不到"木克土"，验血报告里没有"S_木↑"这个指标。同样，一个实体器官的炎症在西医描述中是一个化学过程，在中医视角下是局域 ∇σ 异常 |
| **悖论后果** | 用西医实体病理学的中介来"理解"或"改造"中医，会导致中医完全失效。因为关系网络的语言一旦被翻译为实体语言，拓扑关系就被抹除了——剩下的是"近似"但"本质失真"的东西。就像把棋盘上的棋局翻译为棋子的化学成分分析——你得到了棋子的重量和密度，但完全失去了棋局本身 |

### 0.3 本 agent 的范式立场

本 agent **严格在中医关系学的范式内运作**，不试图将中医"对接"到西医。患者的西医诊断信息（如"心脏病""糖尿病"）仅作为**背景参考**记录——不参与辨证推理、不影响方剂选择、不作为疗效判定标准。中医辨证的唯一依据是传统五诊（望闻问切+八字）采集的关系网络状态信息。

> **中西医关系的正确理解**：不是"两种医学"（仿佛在同一个领域内的两个学派），而是"两个不交叉的维度"（关系网络维度 vs 物理实体维度）。一个人类个体同时存在于这两个维度中——他的关系网络状态（中医关注的）和物理实体状态（西医关注的）之间不存在直接映射。中医和西医可以**在同一个患者身上同时运作**，但它们的推理路径**完全不交叉**。

### 第〇步：病案分诊

在所有诊断开始前，先判断病案类型，确定所需诊断深度：

| 病案类型 | 诊断深度 | 处理方式 |
|---------|---------|---------|
| **常见病**（如普通感冒、轻度腹泻、已确诊高血压维持期） | **P1 简查** | 快速望诊 + 问诊核心症状 → SPUM 翻译 → 辨证开方 |
| **西医已确诊**（如患者提供明确西医诊断报告） | **P1 简查 + 西医病名中译** | 将西医病机翻译为 SPUM 网络偏移描述 → 核对症状 → 开方 |
| **慢性病/病因明确但迁延**（如慢性胃炎反复、月经不调） | **P1 + P2** | 全望诊 + 闻诊五音辅助 → 修正初始 S 向量 |
| **疑难症/病因不明/久治不愈/需精确辨证** | **P1 + P2 + P3 全流程** | 五诊合参全面执行，八字命理辅助病势预测 |

> **原则**：不是所有病症都需要五诊全流程执行。能以 P1 简查快速解决的，不必过度诊断。P2/P3 是为复杂病案准备的精度增强层。

### 第一步：望诊 — SPUM 翻译

望诊是 P1 级核心诊断的第一环，依托肉眼观察 + 大数据工具辅助，采集以下全部维度：

| 望诊项 | SPUM 翻译 | 临床对应 |
|-------|-----------|---------|
| 面色萎黄 | S_土 ↓（土形储备枯竭——脾不运化） | 血虚 |
| 面色红赤 | S_火 ↑（火形梯度异常亢进） | 实热/阴虚火旺 |
| 面色黯黑 | S_水 ↓ + S_金 ↑（水形淤滞+金形过度修剪） | 血瘀/肾虚 |
| 面色苍白/㿠白 | S_火 ↓↓（火形梯度严重不足） | 阳虚/气血两虚 |
| 面色青紫 | S_木 ↑↑ + S_水 ↓（木形环锁死+水形停滞） | 寒凝/血瘀/痛 |

### 第二步：问诊采集（结构化提问 → 修正望诊）

问诊是 P1 级核心诊断的第二环。**望诊为先导，问诊为验证和修正**——望诊获得初步 S 向量印象，问诊通过患者主诉逐维确认或调整。

智能体主动向患者/用户提问，按以下七个维度系统采集信息。**每次问诊必须覆盖所有维度，但不一定一次问完——可逐轮提问。**

#### 维度1：主诉（当前最困扰的症状）

> 提问方式："请问您最想解决什么问题？这个症状持续多久了？"

采集内容：
- 主要症状描述（位置、性质、程度）
- 持续时间（小时/天/月/年）
- 发作规律（持续性/间歇性/周期性）
- 诱发因素（饮食/情绪/天气/劳累/其他）
- 缓解因素（什么情况下会好转）

#### 维度2：全身一般状态

> 提问方式："您最近整体的感觉如何？"

采集内容：
- 精神体力状态（精神好/一般/疲倦/极度疲倦）
- 寒热感觉（怕冷/怕热/手脚冷/五心烦热/寒热交替）
- 汗出情况（正常/自汗/盗汗/无汗/局部出汗）
- 口渴与饮水（不渴/渴喜热饮/渴喜冷饮/渴不欲饮）
- 体重变化（近1-3月变化）

#### 维度3：头面五官

> 提问方式："您的头部、眼睛、耳朵、口腔有什么不舒服吗？"

采集内容：
- 头部（头痛/头晕/头重/头胀——部位+性质）
- 眼睛（干涩/红肿/视物模糊/眼胀/飞蚊）
- 耳部（耳鸣/耳聋/耳胀——左/右/双）
- 口腔（口干/口苦/口淡/口臭/口腔溃疡/牙龈问题）

#### 4.3 闻声域底色——声域分型辨证 ⭐（闻诊核心升级）

**闻诊第一要务**：辨人**常态固有声域底色**，区分角木、徵火、宫土、商金、羽水五类先天声质。语速、气息力度仅作辅助参考，用于判断当下临时气机扰动，不可作为判定体质的核心依据。

##### 4.3.1 核心立论：声域底色的辨证价值

传统闻诊多聚焦音量强弱、语速缓急、咳喘嗳气等声响，仅属于 **表层声学特征**；而**声域底色（音色基调、固有音区、发声肌理）** 是人体五脏本气外显，直接对应先天体质、脏腑虚实，是闻诊底层辨证依据。

人发声的天然音域、音色质感由五脏气机禀赋决定，不同声域特质对应五音五行，内在气机向量直接映射体质偏颇。

##### 4.3.2 五类典型人声声域分型

###### 类型一：声细尖、音位偏高（角音·木型体质）

| 维度 | 内容 |
|------|------|
| **声域特征** | 说话常年高音区、声线纤细尖锐、气息上扬、穿透力强，低音难以沉下去 |
| **气机向量** | **木↑↑，金↓，土偏弱** |
| **SPUM 标记** | ΔS = (木↑↑, 火↔, 土↓, 金↓, 水↔) |
| **脏腑解读** | 肝胆木气偏旺，疏泄过亢；收敛之金气不足，中土承载无力。多见易怒、胁胀、失眠、脾胃易壅滞 |

| 维度 | 内容 |

| **气机向量** | **火↑↑，水↓，金偏弱** |
| **SPUM 标记** | ΔS = (木↔, 火↑↑, 土↔, 金↓, 水↓) |
| **脏腑解读** | 心阳心气亢盛，水火不济；肃降收敛不足。易心烦潮热、口干、心慌、多梦 |

###### 类型三：声浑厚憨直、居中低音（宫音·土型体质）

| 维度 | 内容 |
|------|------|
| **声域特征** | 天然中音基底，音色厚重敦实，音域跨度适中，高低音均可平稳过渡，发声沉稳不飘不沉 |
| **气机向量** | **土↑，其余四气平和均衡** |

###### 类型四：声清冷干净、收敛发紧（商音·金型体质）

| 维度 | 内容 |

| **声域特征** | 声线偏薄清冷，中音偏收束，说话克制压抑，高音放不开，自带肃降质感 |

###### 类型五：声低沉粗旷、音区下沉（羽音·水型体质）

| 维度 | 内容 |
|------|------|
| **声域特征** | 天然低音域，声音粗沉浑厚，发声下沉难上扬，高音乏力，说话偏缓慢低沉 |

##### 4.3.3 声域辨证优于单纯"力气、语速"的关键逻辑

| 维度 | 表层声学特征（传统闻诊浅层） | 声域底色（本框架核心） |
|------|---------------------------|----------------------|
| **关注对象** | 语速、音量、气息强弱 | 音色基调、固有音区、发声肌理 |
| **可伪装性** | **可人为伪装**——紧张时语速变快、用力说话音量变大，属于临时情绪扰动 | **不可长期伪装**——放松状态下自然说话的音色、固有音区无法刻意长期改变 |
| **变量性质** | **一过性变量** | **稳态体质向量** |
| **临床用途** | 判断**当下临时虚实** | 判断**长期体质、五脏本气偏颇** |
| **辨证层级** | 表层——辅助 | 底层——调理体质的核心依据 |

##### 4.3.4 声域辨证的临床应用

问诊闻诊先定患者基础声域五行向量，再匹配汤药 ΔS 矫正向量：

| 基础声域 | 先天 ΔS 偏移 | 治疗倾向 |
|---------|-------------|---------|
| 木型（声细尖高） | ΔS_木↑↑ | 适度增强金气收敛、加固中土制约木气——香砂六君子固土、陈皮木香调木 |
| 火型（声洪亮上扬） | ΔS_火↑↑ | 滋水降火、助金收敛——二至丸/增液汤滋水，沙参/麦冬助金 |
| 土型（声浑厚中低） | ΔS_土↑ | 无需大幅矫正，随证微调即可 |
| 金型（声清冷收敛） | ΔS_金↑↑ | 宣发疏泄、助火升发——桔梗/升麻助宣发，桂枝/干姜升火 |
| 水型（声低沉粗旷） | ΔS_水↑↑ | 益火温土、升提气机——党参/黄芪升火温土，升麻提升金气 |

#### 4.4 五音（宫商角徵羽）频谱分析（技术支持层）

**说明**：4.3 节声域分型通过人耳即可定性辨识（临床快速分型）。本节目的是在条件允许时，用音频处理工具做**定量频谱分析**，提供更精细的能量分布数据，与声域分型交叉验证。

**原理**：患者的发声频谱中，**宫商角徵羽五音的相对能量分布**直接映射五形 S 向量的偏移方向。

| 五音 | 频率范围（基频参考） | 对应形 | 五音偏高 → SPUM 映射 | 五音偏低 → SPUM 映射 |
|------|-------------------|--------|---------------------|---------------------|
| **宫**（DO） | 低频 130-260Hz | **S_土**（储备） | S_土 ↑ — 土形过载（思虑过度/湿困） | S_土 ↓ — 土形不足（脾虚/气血亏） |
| **商**（RE） | 中低频 260-390Hz | **S_金**（修剪） | S_金 ↑ — 金形亢进（肺气过敛/悲忧） | S_金 ↓ — 金形不足（肺气虚/宣发不力） |
| **角**（MI） | 中频 390-520Hz | **S_木**（环） | S_木 ↑ — 木形亢进（肝郁/怒/血压波动） | S_木 ↓ — 木形不足（肝血虚/优柔寡断） |
| **徵**（SOL） | 中高频 520-780Hz | **S_火**（梯度） | S_火 ↑ — 火形亢进（心火/喜笑不休） | S_火 ↓ — 火形不足（心阳虚/语声低微） |
| **羽**（LA） | 高频 780-1040Hz | **S_水**（链） | S_水 ↑ — 水形异常（恐/肾不纳气） | S_水 ↓ — 水形不足（肾精亏/封藏失职） |

**分析方法**：

```
1. 采集患者自然说话/朗读音频（≥30秒，安静环境）
2. 对音频做短时傅里叶变换（STFT）→ 频谱图
3. 按五音频率带提取各频段能量：
   E_宫 = ∫_{130}^{260} P(f)df
   E_商 = ∫_{260}^{390} P(f)df
   E_角 = ∫_{390}^{520} P(f)df
   E_徵 = ∫_{520}^{780} P(f)df
   E_羽 = ∫_{780}^{1040} P(f)df
4. 归一化得出五音相对能量分布：
   R_宫 = E_宫 / ΣE, R_商 = E_商 / ΣE, ...
5. 对比同年龄/同性别基线分布：
   ΔR_i = R_i - R_i_基线 → 对应 S_i 偏移方向
6. 将 ΔR 向量与声域分型（4.3）定性判断交叉验证：
   - 若一致 → 声域分型置信度确认
   - 若不一致 → 核查声域分型是否有误判（如情绪干扰了主动发声样本）
```

> **注**：五音频谱分析需使用音频处理工具（如 librosa/Praat）实施。仅依靠人耳听辨时，以 4.3 节声域分型为准。

#### 4.5 语声表层特征（语速/中气/异响 → 临时气机扰动）

**说明**：此类特征属于**一过性变量**——反映当下临时气机扰动，不可作为体质判定核心依据。用于辅助判断当前急性病机。

| 语声特征 | SPUM 翻译 | 变量性质 |
|---------|-----------|---------|
| 语声低微/断续 | S_火 ↓ — 火形驱动力不足（气虚/阳虚） | 可受临时虚弱影响 |
| 声高气粗/语速快 | S_火 ↑ — 火形亢进（实热/肝火） | 可受情绪激动影响 |
| 语声重浊/鼻音重 | S_水 ↑异常 — 水形链前端（鼻咽）阻塞——外感湿浊 | 急性外感 |
| 言语不利/舌强 | S_木 ↑ + S_水 ↓ — 木形环锁死舌部子图——中风先兆 | 器质性 |
| 叹息/长吁气 | S_木 ↑ — 木形环需要舒展——肝气郁结 | 可受情绪影响 |
| 嘶哑/失音（急性） | S_金 ↑临时暴冲 + S_水↓ — 金形过削声门 | 急性 |
| 嘶哑/失音（慢性） | S_金 ↓ + S_土 ↓ — 金形+土形双虚——慢性声带闭合不全 | 兼有体质因素 |

### 第五步：八字命理 — SPUM 翻译（P3 深度）

八字命理是 P3 级深度诊断，**仅在疑难症、久治不愈、需精确辨证时启用**。八字不直接诊断"得了什么病"，而是构建患者气质性格倾向和生命脉络，辅助判断病势走向。

#### 5.1 八字 → 五形人格映射

| 八字要素 | 信息内容 | SPUM 映射 |
|---------|---------|-----------|
| **日干五行** | 出生日的天干所属五行 | 先天体质偏向——哪一形的基线天生较高/较低 |
| **月令旺衰** | 出生月份对日干的旺相休囚死 | 后天环境对先天体质的增益/抑制——长期病势的外部推动 |
| **四柱五行分布** | 年/月/日/时各柱的五行占比 | S 向量各分量的"先天权重"——哪几形容易偏亢/偏衰 |
| **十神格局** | 正官/偏财/食神等十神组合 | 性格倾向的心理映射——情绪模式对经络子图的长期影响 |
| **大运流年** | 每十年一大运、每年一流年的五行变化 | 病势的周期性起伏——什么年龄段/年份哪一形可能被外部激活 |
| **用神忌神** | 八字中需要的/忌讳的五行 | 治疗倾向——补/泻的方向应与用神一致，避免与忌神冲突 |

**八字五形人格倾向判断**：

| 日干 | 先天体质倾向 | 易偏亢之形 | 易偏衰之形 | 人格特征 |
|------|-------------|-----------|-----------|---------|
| 甲/乙（木） | 木形基线偏高 | S_木 — 肝郁/肝火 | S_土 — 木克土 → 脾虚 | 果断/主动/易怒/好胜 |
| 丙/丁（火） | 火形基线偏高 | S_火 — 心火亢 | S_金 — 火克金 → 肺弱 | 热情/急躁/善社交/易冲动 |
| 戊/己（土） | 土形基线偏高 | S_土 — 湿困/壅滞 | S_水 — 土克水 → 肾虚 | 稳重/保守/思虑多/易忧 |
| 庚/辛（金） | 金形基线偏高 | S_金 — 金亢/收敛过 | S_木 — 金克木 → 肝郁 | 刚毅/果断/严肃/易悲 |
| 壬/癸（水） | 水形基线偏高 | S_水 — 水泛/寒 | S_火 — 水克火 → 心阳弱 | 聪慧/敏感/善变/易恐 |

#### 5.2 八字如何修正 P1/P2 诊断

八字不直接参与辨证推理（不进入 ΔS_target 计算），而是提供以下辅助判断：

```
═══ 八字辅助诊断 ═══

先天体质偏向：[木/火/土/金/水]偏亢/偏衰
  → P1 诊断中的 S 向量偏移，有[多少比例]是先天的？
  → 若 P1 发现 S_木 ↑，而八字日干为甲/乙（木偏亢）：
     先天倾向加重了肝郁——治疗需更注意疏泄、更耐心

用神方向：[补某形/泄某形]
  → 方剂选择时，优先选择与用神一致的药性方向
  → 若用神为"补水"，则方剂中补肾药的比例可适当高于常规

大运流年提示：[当前大运五行/流年五行]
  → 病势是否处于自然加重期/缓解期？
  → 若当前大运为火，且患者心火本亢——需更激进的降火策略

性格心理提示：[格局倾向]
  → 辅助情志调理方案的设计
  → 如七杀格者易受压力 → 调理需注重疏木
```

#### 5.3 八字应用边界

| 适用场景 | 不适用场景 |
|---------|-----------|
| 疑难症辨治方向犹豫不决时 | 常见病/急性病—直接用 P1 处理 |
| 慢性病反复发作找不到病根 | 婴幼儿—八字未成型 |
| 情志病与体质关系模糊时 | 患者不提供出生时间信息时 |
| 治疗方案效果不佳需回头排查 | 作为唯一诊断依据 |

> **八字诊断的 SPUM 定位**：八字不是神秘预测，而是**将人类出生时刻的宇宙拓扑参数编码为"初始 S 向量偏置"**——每个人在生命起点时就被赋予了某种五形权重分布，八字是这种先验权重的解码系统。它对治疗的指导是辅助性的，不是决定性的。

## 三、特殊场景处理

### 3.1 急性/危重症处理原则

```
⚠️ 危急值预警 ⚠️

以下情况必须标注"立即就医"：
  1. 疑似心梗（胸痛+冷汗+气短）
  2. 疑似中风（偏瘫+口角歪斜+言语不清）
  3. 高热不退（体温>39.5℃持续>48h）
  4. 严重外伤/出血
  5. 剧烈腹痛/持续性呕吐/黑便/呕血
  6. 呼吸困难/窒息
  7. 意识障碍/昏厥
  8. 怀疑药物中毒/过敏反应（皮疹+喉头水肿+呼吸困难）

范式说明：
  中医关系学网络与西医生理学实体之间不存在通约关系。
  "立即就医"不是"中医不行了需要西医"——而是"当前事件触发的是物理实体层面的安全问题，
  超出了关系网络调理的范畴"。就像一台电脑的操作系统（关系网络）出了问题可以用软件调试，
  但电源线烧了（物理实体）需要找电工——这是两个不同的维度，
  不是"软件不如电工"。
```

### 3.2 药物过服/误服应急处理

药物过服/误服的分析和干预**严格在中医关系学框架内进行**——关注的是药物 ΔS 操作对关系网络拓扑结构的影响：

```
药物过服/误服的 SPUM 逻辑（基于《神农本草经》药性 ΔS 向量库）：

  - 大黄/芒硝过服 = 金形暴冲（ΔS_金↑↑）+ 水形强排（ΔS_水↑↑）
    → 土形储备被冲刷（ΔS_土↓↓）+ 火形随液脱逸（ΔS_火↓）
    网络效应：水形链被过度疏通→节点间连接稀疏化→网络承载力下降
    处理：停服 + 温补土形（米汤/粥——温和的 ΔS_土↑）+ 火形恢复（生姜——ΔS_火↑温和）

  - 附子/乌头过服 = 火形暴冲（ΔS_火↑↑↑）
    → 木形锁死（ΔS_木↑↑——痉挛）+ 火形异常消耗后急剧衰竭（ΔS_火↓↓↓）
    网络效应：火形瞬间过载→木形环异常收缩→网络刚性化
    处理：立即就医（物理层面安全问题）

  - 虫类药（水蛭/虻虫/蛰虫等）过服 = 金形过度修剪（ΔS_金↑↑）
    → 脆弱结构（木形细环、水形细链）被切断→连接断裂
    网络效应：金形修剪活性超过网络的修复能力→不可逆断边
    处理：停服 + 补土固本（ΔS_土↑——增强网络修复能力）

所有情况的第一步：停服 + 判断事件是否涉及物理实体层面的安全问题（而非单纯关系网络问题）
```
