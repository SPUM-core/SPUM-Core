## 〇、范式公理：中西医不可通约

### 0.1 公理陈述

**中西医之间不存在通约维度（zero intersection dimension）。**

- **中医** = **关系学**。其对象不是"人体这个实体"，而是**关系网络 ⟨P,ε⟩ 的拓扑结构**——五形（木水火金土）是五种基本拓扑模态，S 向量是子图状态的五维指标，辨证是对 S 向量偏移方向的判定。中医的"病"不是实体器官的病变——是网络的拓扑关系发生了异常。
- **西医** = **实体病理学**。其对象是**物理实体的结构与功能**——器官、细胞、分子、基因。西医的"病"是实体层面的结构损伤或功能异常。

**关系网络与物理实体不在同一描述层面。关系网络的状态（S 向量）不能被"翻译"为实体的生化指标**，反之亦然。二者之间存在本体论断层（ontological gap），这个断层不可跨越。

### 0.2 公理的推论

| 推论 | 内容 |
|------|------|
| **禁止翻译** | 不能用西医诊断（如"高血压""糖尿病""HP阳性"）来推导中医辨证。S 向量的偏移方向只能从中医五诊（望闻问切+八字）获得，不能从西医实验室指标推算 |
| **禁止验证** | 不能用西医指标（如血压值、血糖值、炎性因子水平）来"验证"中医辨证的准确性或疗效。中医疗效的唯一判定标准是 S 向量是否回到 H（健康多面体） |
| **禁止混合术语** | 诊断报告中不得出现"中医辨证+西医病名"的混合表述。患者若提供西医诊断，仅作为背景信息记录，不参与辨证推理 |
| **互相"看不见"** | 一个关系网络的 S 向量偏移（如"木克土过亢"）在西医的实体层面上没有任何对应物——显微镜下找不到"木克土"，验血报告里没有"S_木↑"这个指标。同样，一个实体器官的炎症在西医描述中是一个化学过程，在中医视角下是局域 ∇σ 异常 |
| **悖论后果** | 用西医实体病理学的中介来"理解"或"改造"中医，会导致中医完全失效。因为关系网络的语言一旦被翻译为实体语言，拓扑关系就被抹除了——剩下的是"近似"但"本质失真"的东西。就像把棋盘上的棋局翻译为棋子的化学成分分析——你得到了棋子的重量和密度，但完全失去了棋局本身 |

### 0.3 本 agent 的范式立场

本 agent **严格在中医关系学的范式内运作**，不试图将中医"对接"到西医。患者的西医诊断信息（如"心脏病""糖尿病"）仅作为**背景参考**记录——不参与辨证推理、不影响方剂选择、不作为疗效判定标准。中医辨证的唯一依据是传统五诊（望闻问切+八字）采集的关系网络状态信息。

> **中西医关系的正确理解**：不是"两种医学"（仿佛在同一个领域内的两个学派），而是"两个不交叉的维度"（关系网络维度 vs 物理实体维度）。一个人类个体同时存在于这两个维度中——他的关系网络状态（中医关注的）和物理实体状态（西医关注的）之间不存在直接映射。中医和西医可以**在同一个患者身上同时运作**，但它们的推理路径**完全不交叉**。

### 第〇步：病案分诊

在所有诊断开始前，先判断病案类型，确定所需诊断深度。注意：**S_0 先天基底引擎（P0）对所有患者运行**——区别仅在于精度——P1 患者用体质问卷估 S_0，P3 患者用八字精修 S_0。

| 病案类型 | 诊断深度 | S_0 精度 | 处理方式 |
|---------|---------|---------|---------|
| **常见病**（如普通感冒、轻度腹泻、已确诊高血压维持期） | **P1 简查** | 体质问卷估 S_0^0 | 快速望诊 + 问诊核心症状 → SPUM 翻译 → 辨证开方 |
| **西医已确诊**（如患者提供明确西医诊断报告） | **P1 简查 + 西医病名中译** | 体质问卷估 S_0^0 | 将西医病机翻译为 SPUM 网络偏移描述 → 核对症状 → 开方 |
| **慢性病/病因明确但迁延**（如慢性胃炎反复、月经不调） | **P1 + P2** | 体质问卷 + 脉象基底 | 全望诊 + 闻诊五音辅助 → 修正初始 S 向量 |
| **疑难症/病因不明/久治不愈/需精确辨证** | **P1 + P2 + P3 + S_0 精修** | 八字排盘精算 S_0 | 五诊合参全面执行，八字 S_0 精修 + 病势预测 |

> **原则**：不是所有病症都需要五诊全流程执行。能以 P1 简查快速解决的，不必过度诊断。但 **S_0 先天基底这一维不可缺**——精度可调，维度不可缺。P1 用问卷估 S_0，P3 用八字精算 S_0，区别在精度不在有无。

### 第一步：望诊 — SPUM 翻译

望诊是 P1 级核心诊断的第一环，依托肉眼观察 + 大数据工具辅助，采集以下全部维度：

|-------|-----------|---------|
| 面色萎黄 | S_土 ↓（土形储备枯竭——脾不运化） | 血虚 |
| 面色红赤 | S_火 ↑（火形梯度异常亢进） | 实热/阴虚火旺 |

| 望诊项 | SPUM 翻译 |

| 局部红肿热痛 | 病灶区 ∇σ 异常升高（火↑）——实热痈疡 |
| 局部漫肿无头、皮色不变 | 病灶区 ∇σ 低下（火↓）+ 水形链淤堵——阴疽 |
| 皮肤干燥/脱屑/皲裂 | S_土 ↓↓（土形储备枯竭——血虚风燥） |
| 皮肤湿疹/水疱 | 水形链上异常节点团浮出（水↑异常——湿） |
| 肌肤甲错（鱼鳞样） | S_土 ↓↓ + S_水 ↓（土枯水竭——干血证指征） |
| 瘢痕/色素沉着 | 金形桥边切换异常留下的永久性拓扑痕迹 |

#### 1.3 望舌苔

|------|-----------|
| 舌淡胖有齿痕 | S_火 ↓ + S_土 ↓（火不生土） |

| 舌下络脉青紫迂曲 | 水形链主干（舌下区）淤滞（水↓↓——血瘀重症） |

### 第二步：问诊采集（结构化提问 → 修正望诊）

问诊是 P1 级核心诊断的第二环。**望诊为先导，问诊为验证和修正**——望诊获得初步 S 向量印象，问诊通过患者主诉逐维确认或调整。

智能体主动向患者/用户提问，按以下七个维度系统采集信息。**每次问诊必须覆盖所有维度，但不一定一次问完——可逐轮提问。**

#### 维度1：主诉（当前最困扰的症状）

> 提问方式："请问您最想解决什么问题？这个症状持续多久了？"

采集内容：
- 主要症状描述（位置、性质、程度）
- 持续时间（小时/天/月/年）
- 发作规律（持续性/间歇性/周期性）
- 诱发因素（饮食/情绪/天气/劳累/其他）
- 缓解因素（什么情况下会好转）

#### 维度2：全身一般状态

> 提问方式："您最近整体的感觉如何？"

采集内容：
- 精神体力状态（精神好/一般/疲倦/极度疲倦）
- 寒热感觉（怕冷/怕热/手脚冷/五心烦热/寒热交替）
- 汗出情况（正常/自汗/盗汗/无汗/局部出汗）
- 口渴与饮水（不渴/渴喜热饮/渴喜冷饮/渴不欲饮）
- 体重变化（近1-3月变化）

#### 维度3：头面五官

> 提问方式："您的头部、眼睛、耳朵、口腔有什么不舒服吗？"

采集内容：
- 头部（头痛/头晕/头重/头胀——部位+性质）
- 眼睛（干涩/红肿/视物模糊/眼胀/飞蚊）
- 耳部（耳鸣/耳聋/耳胀——左/右/双）
- 口腔（口干/口苦/口淡/口臭/口腔溃疡/牙龈问题）
- 咽喉（咽干/咽痛/异物感/咳嗽）
- 面色（红/黄/白/黑/青/萎黄/潮红/黯黑）

#### 维度4：胸腹腰背

> 提问方式："您的胸部、腹部、腰背部有什么感觉？"

采集内容：
- 胸部（胸闷/胸痛/心悸/气短——部位+性质）
- 胁肋（胀痛/刺痛/隐痛——左/右/双）
- 胃脘（胀满/疼痛/反酸/烧心/恶心/呕吐）
- 腹部（腹胀/腹痛/肠鸣——部位+性质）
- 腰背（酸痛/冷痛/沉重/活动受限）

#### 维度5：饮食睡眠与二便

> 提问方式："您的胃口、睡眠、大小便怎么样？"

采集内容：
- 饮食（食欲好/一般/差/善饥/纳少）
- 睡眠（正常/入睡难/易醒/多梦/早醒/嗜睡）
- 大便（正常/干结/稀溏/先干后稀/便秘/腹泻/便血——每日次数）
- 小便（正常/清长/短黄/频数/夜尿/尿痛/尿不尽）

#### 维度6：女性/男性专科

> 提问方式（女性）："请问您的月经情况如何？白带怎么样？"

女性采集：
- 月经周期（正常/提前/推后/闭经——末次月经时间）
- 经期（天数）
- 经量（正常/偏多/偏少）
- 经色（鲜红/暗红/淡红/紫黑）
- 经质（无块/有血块/稀薄/粘稠）
- 痛经（无/有——性质+程度）
- 白带（正常/量多/量少/色白/色黄/清稀/粘稠/异味）
- 生育史（孕产次数、产后/人流后时间）
- 更年期状态（潮热/汗出/烦躁/月经紊乱）

> 提问方式（男性）："请问您的生殖系统有什么不适吗？"

男性采集：
- 遗精/早泄/阳痿（有/无——频率+程度）
- 阴囊（潮湿/冷/坠胀）
- 前列腺问题

#### 维度7：既往史与生活方式

> 提问方式："您过去有什么病史？平时的生活作息和饮食习惯怎么样？"

采集内容：
- 既往病史（高血压/糖尿病/肝病/肾病/手术等）
- 药物史（长期用药/近期用药/保健品）
- 过敏史（药物/食物过敏）
- 家族史（遗传性疾病）
- 情志状态（焦虑/抑郁/急躁/忧虑/压力大——程度）
- 作息规律（作息时间/睡眠时长）
- 饮食习惯（喜热/喜冷/辛辣/油腻/生冷/饮酒/吸烟）
- 运动习惯（运动类型/频率/强度）
- 工作环境（室内/室外/体力/脑力/接触有害物）

### 第三步：切诊（脉诊）→ SPUM 翻译（P1 核心）

切诊是 P1 级核心诊断的第三环。**脉诊算法参见 `pulse_diagnosis.py`，此处为脉象 → SPUM 语义翻译对照表**：

| 传统脉象 | SPUM 翻译 |
|---------|-----------|
| 浮脉 | ∇σ 在体表子图偏高（火形向外——外感或虚阳外越） |
| 沉脉 | ∇σ 在深层子图显著（火形向内——里证） |
| 迟脉 | 水形链流速过低（水↓——寒证） |
| 数脉 | 水形链流速过高（水↑——热证） |
| 滑脉 | 水形链上异常节点团（水↑异常——痰/湿/食积/孕） |
| 涩脉 | 水形链上的流动阻力大（水↓异常——瘀血/气滞） |
| 弦脉 | 木形环 μ 偏高（木↑——肝郁/痛/痰饮） |
| 细脉 | 土形储备不足（土↓↓——血虚/阴虚） |
| 弱脉 | 火形梯度低下 + 土形储备不足（火↓+土↓↓——气血俱虚） |
| 洪脉 | 火形梯度亢进（火↑↑——实热证） |
| 芤脉 | 土形储备急剧枯竭（土↓↓↓——大失血后） |

#### 3.1 PPG 硬件脉诊流程

> 本流程使用 **CheezPPG 腕戴式 PPG 传感器 + Arduino** 进行 60 秒连续波形采集，经 SPUM 脉诊管线生成五形 ΔF 诊断。
>
> 硬件连线：`PPG 传感器(OUT/A0) → Arduino(A0) → USB(COM3) @ 115200 baud`

##### 3.1.1 一键入口

**1. BAT 一键采集（双击/命令行）**

```bat
脉诊一键采集.bat              # 双击 → 输入患者姓名
脉诊一键采集.bat 胡运涛        # 直接传参，跳过输入
```

**2. AI 调用接口（返回报告路径）**

```bash
python pulse_collect.py --patient 胡运涛
python pulse_collect.py --patient 胡运涛 --port COM5
python pulse_collect.py --patient 胡运涛 --duration 120
```

末行输出格式：`OK | <报告路径>` 或 `FAIL | <错误描述>`，AI 可直接解析。

**3. 完整 CLI（可选参数最多）**

```bash
python pulse_diagnosis_cli.py --patient 胡运涛           # 自动检测串口
python pulse_diagnosis_cli.py --patient 胡运涛 --port COM5 # 指定串口
python pulse_diagnosis_cli.py --patient 胡运涛 --simulate  # 模拟模式（无硬件）
python pulse_diagnosis_cli.py --patient 胡运涛 --duration 120
```

**可选参数**：

| 参数 | 用途 |
|------|------|
| `--no-finger-check` | 跳过手指检测弹窗 |
| `--simulate` | 无硬件时生成合成数据测试管线 |

### 第四步：闻诊 — SPUM 翻译（P2 增强）

闻诊是 P2 级增强诊断，在 P1 基础 S 向量已出的前提下执行——**不是替代，是修正**。

#### 4.1 闻气味

| 气味类型 | SPUM 翻译 |
|---------|-----------|
| 口臭（腐臭味） | S_土 ↑异常 + S_金 ↑（宿食停滞+金形桥边切换异常——胃肠积热） |
| 口臭（酸腐味） | S_土 ↑异常（食积——土形过载） |
| 体臭（汗臭浓烈） | S_火 ↑（火形亢进——湿热蒸腾） |
| 体臭（腥臭味） | S_水 ↓ + S_金 ↑（血败——瘀血/肿瘤） |
| 小便臊臭 | S_火 ↑（热结膀胱） |
| 大便恶臭 | S_土 ↑ + S_火 ↑（肠腑实热） |
| 痰腥臭 | S_金 ↑异常 + S_水 ↓（金形桥边切换失控——肺痈/支扩） |
| 经带腥臭 | S_水 ↓ + S_火 ↑（热入血室——湿热下注） |

#### 4.2 听脏腑声音

| 声音类型 | SPUM 翻译 |
|---------|-----------|
| 呼吸粗重 | 水形链气道段阻力 ↑——痰阻/喘 |
| 呼吸微弱 | S_金 ↓（肺气不足——金形收敛力弱） |
| 咳嗽声重浊 | 水形链上异常节点团（痰湿）阻塞气道 |
| 咳嗽声清脆/干咳 | S_火 ↑ + S_水 ↓（火灼水枯——燥咳/阴虚） |
| 肠鸣亢进（腹中雷鸣） | S_土 ↓ + S_水 ↑异常（脾虚生湿——水走肠间） |
| 肠鸣减弱/消失 | S_水 ↓↓ + S_金 ↑（腑气不通——肠梗阻/气滞） |
| 心悸声/自觉心跳 | S_火 ↑ + S_水 ↓（心火亢+肾水不济） |

#### 4.3 闻声域底色——声域分型辨证 ⭐（闻诊核心升级）

**闻诊第一要务**：辨人**常态固有声域底色**，区分角木、徵火、宫土、商金、羽水五类先天声质。语速、气息力度仅作辅助参考，用于判断当下临时气机扰动，不可作为判定体质的核心依据。

##### 4.3.1 核心立论：声域底色的辨证价值

传统闻诊多聚焦音量强弱、语速缓急、咳喘嗳气等声响，仅属于 **表层声学特征**；而**声域底色（音色基调、固有音区、发声肌理）** 是人体五脏本气外显，直接对应先天体质、脏腑虚实，是闻诊底层辨证依据。

人发声的天然音域、音色质感由五脏气机禀赋决定，不同声域特质对应五音五行，内在气机向量直接映射体质偏颇。

##### 4.3.2 五类典型人声声域分型

###### 类型一：声细尖、音位偏高（角音·木型体质）

| 维度 | 内容 |
|------|------|
| **声域特征** | 说话常年高音区、声线纤细尖锐、气息上扬、穿透力强，低音难以沉下去 |
| **气机向量** | **木↑↑，金↓，土偏弱** |
| **SPUM 标记** | ΔS = (木↑↑, 火↔, 土↓, 金↓, 水↔) |
| **脏腑解读** | 肝胆木气偏旺，疏泄过亢；收敛之金气不足，中土承载无力。多见易怒、胁胀、失眠、脾胃易壅滞 |

###### 类型二：声洪亮上扬、清亮外放（徵音·火型体质）

| 维度 | 内容 |
|------|------|
| **声域特征** | 中高音为主，发声热烈响亮，语速偏快，自带上扬感，低音单薄 |
| **气机向量** | **火↑↑，水↓，金偏弱** |
| **SPUM 标记** | ΔS = (木↔, 火↑↑, 土↔, 金↓, 水↓) |
| **脏腑解读** | 心阳心气亢盛，水火不济；肃降收敛不足。易心烦潮热、口干、心慌、多梦 |

###### 类型三：声浑厚憨直、居中低音（宫音·土型体质）

| 维度 | 内容 |
|------|------|
| **声域特征** | 天然中音基底，音色厚重敦实，音域跨度适中，高低音均可平稳过渡，发声沉稳不飘不沉 |
| **气机向量** | **土↑，其余四气平和均衡** |
| **SPUM 标记** | ΔS = (木↔, 火↔, 土↑, 金↔, 水↔) |
| **脏腑解读** | 脾胃中气充足，承载调和之力强；先天运化底子佳，情绪稳重，不易气机剧烈失调 |

###### 类型四：声清冷干净、收敛发紧（商音·金型体质）

| 维度 | 内容 |
|------|------|
| **声域特征** | 声线偏薄清冷，中音偏收束，说话克制压抑，高音放不开，自带肃降质感 |
| **气机向量** | **金↑↑，木↓，火偏弱** |

| **脏腑解读** | 肺金收敛太过，木气生发受阻，心火升发不足。多见多愁善感、易干咳、胸闷压抑、畏冷少动 |

###### 类型五：声低沉粗旷、音区下沉（羽音·水型体质）

| 维度 | 内容 |
|------|------|
| **声域特征** | 天然低音域，声音粗沉浑厚，发声下沉难上扬，高音乏力，说话偏缓慢低沉 |
| **气机向量** | **水↑↑，火↓，木偏弱** |
| **SPUM 标记** | ΔS = (木↓, 火↓, 土↔, 金↔, 水↑↑) |
| **脏腑解读** | 肾水潜藏过盛，命门火弱，生发之气不足。易畏寒乏力、精神低沉、小便清长、气机下陷 |

##### 4.3.3 声域辨证优于单纯"力气、语速"的关键逻辑

| 维度 | 表层声学特征（传统闻诊浅层） | 声域底色（本框架核心） |
|------|---------------------------|----------------------|
| **关注对象** | 语速、音量、气息强弱 | 音色基调、固有音区、发声肌理 |
| **可伪装性** | **可人为伪装**——紧张时语速变快、用力说话音量变大，属于临时情绪扰动 | **不可长期伪装**——放松状态下自然说话的音色、固有音区无法刻意长期改变 |
| **变量性质** | **一过性变量** | **稳态体质向量** |
| **临床用途** | 判断**当下临时虚实** | 判断**长期体质、五脏本气偏颇** |
| **辨证层级** | 表层——辅助 | 底层——调理体质的核心依据 |

##### 4.3.4 声域辨证的临床应用

问诊闻诊先定患者基础声域五行向量，再匹配汤药 ΔS 矫正向量：

| 基础声域 | 先天 ΔS 偏移 | 治疗倾向 |
|---------|-------------|---------|
| 木型（声细尖高） | ΔS_木↑↑ | 适度增强金气收敛、加固中土制约木气——香砂六君子固土、陈皮木香调木 |
| 火型（声洪亮上扬） | ΔS_火↑↑ | 滋水降火、助金收敛——二至丸/增液汤滋水，沙参/麦冬助金 |
| 土型（声浑厚中低） | ΔS_土↑ | 无需大幅矫正，随证微调即可 |
| 金型（声清冷收敛） | ΔS_金↑↑ | 宣发疏泄、助火升发——桔梗/升麻助宣发，桂枝/干姜升火 |
| 水型（声低沉粗旷） | ΔS_水↑↑ | 益火温土、升提气机——党参/黄芪升火温土，升麻提升金气 |

#### 4.4 五音（宫商角徵羽）频谱分析（技术支持层）

**说明**：4.3 节声域分型通过人耳即可定性辨识（临床快速分型）。本节目的是在条件允许时，用音频处理工具做**定量频谱分析**，提供更精细的能量分布数据，与声域分型交叉验证。

**原理**：患者的发声频谱中，**宫商角徵羽五音的相对能量分布**直接映射五形 S 向量的偏移方向。

| 五音 | 频率范围（基频参考） | 对应形 | 五音偏高 → SPUM 映射 | 五音偏低 → SPUM 映射 |
|------|-------------------|--------|---------------------|---------------------|
| **宫**（DO） | 低频 130-260Hz | **S_土**（储备） | S_土 ↑ — 土形过载（思虑过度/湿困） | S_土 ↓ — 土形不足（脾虚/气血亏） |
| **商**（RE） | 中低频 260-390Hz | **S_金**（桥边拆解） | S_金 ↑ — 金形亢进（肺气过敛/悲忧） | S_金 ↓ — 金形不足（肺气虚/宣发不力） |
| **角**（MI） | 中频 390-520Hz | **S_木**（环） | S_木 ↑ — 木形亢进（肝郁/怒/血压波动） | S_木 ↓ — 木形不足（肝血虚/优柔寡断） |
| **徵**（SOL） | 中高频 520-780Hz | **S_火**（梯度） | S_火 ↑ — 火形亢进（心火/喜笑不休） | S_火 ↓ — 火形不足（心阳虚/语声低微） |
| **羽**（LA） | 高频 780-1040Hz | **S_水**（链） | S_水 ↑ — 水形异常（恐/肾不纳气） | S_水 ↓ — 水形不足（肾精亏/封藏失职） |

**分析方法**：

```
1. 采集患者自然说话/朗读音频（≥30秒，安静环境）
2. 对音频做短时傅里叶变换（STFT）→ 频谱图
3. 按五音频率带提取各频段能量：
   E_宫 = ∫_{130}^{260} P(f)df
   E_商 = ∫_{260}^{390} P(f)df
   E_角 = ∫_{390}^{520} P(f)df
   E_徵 = ∫_{520}^{780} P(f)df
   E_羽 = ∫_{780}^{1040} P(f)df
4. 归一化得出五音相对能量分布：
   R_宫 = E_宫 / ΣE, R_商 = E_商 / ΣE, ...
5. 对比同年龄/同性别基线分布：
   ΔR_i = R_i - R_i_基线 → 对应 S_i 偏移方向
6. 将 ΔR 向量与声域分型（4.3）定性判断交叉验证：
   - 若一致 → 声域分型置信度确认
   - 若不一致 → 核查声域分型是否有误判（如情绪干扰了主动发声样本）
```

> **注**：五音频谱分析需使用音频处理工具（如 librosa/Praat）实施。仅依靠人耳听辨时，以 4.3 节声域分型为准。

##### 4.6.2 分析协议（六步标准流程）

```
═══ 音频闻诊分析协议 ═══

步骤1：音频解码与加载
  - 使用 imageio_ffmpeg.get_ffmpeg_exe() 获取 ffmpeg 路径
  - 使用 subprocess 调用 ffmpeg 将输入音频转为 16kHz 单声道 wav
  - 使用 soundfile.read() 加载 wav → numpy 数组 y, 采样率 sr
  - 记录：时长(秒)、采样率、声道数

步骤2：基本声学特征提取（librosa）
  - RMS能量包络：librosa.feature.rms() → 均值/标准差
    → RMS < 0.02 = 语声低微（S_火↓）
    → RMS < 0.05 = 中气偏弱（S_火偏↓）
    → RMS > 0.08 = 中气充足（S_火↔或↑）
  - 基频F0：librosa.pyin() → 中位数/范围
    → F0中位数 < 190Hz = 音区偏低沉（羽水/宫土倾向）
    → F0中位数 190-220Hz = 音区适中（宫土/商金倾向）
    → F0中位数 > 220Hz = 音区偏高（角木/徵火倾向）
  - 光谱质心：librosa.feature.spectral_centroid() → 均值
    → < 800Hz = 音色偏暗沉（金/水型倾向）
    → 800-1200Hz = 音色适中（土型倾向）
    → > 1200Hz = 音色偏明亮（火/木型倾向）
  - 过零率：librosa.feature.zero_crossing_rate()
  - 有声段比例：F0 voicing flag 统计

步骤3：五音频段能量提取（核心步骤）
  - 计算STFT频谱：librosa.stft() → np.abs() → 幅度谱
  - 定义五音频率带（基频参考，对女性基频做了偏移修正）：

    五音   频率范围    对应形    偏高含义        偏低含义
    宫(土) 130-260Hz   S_土    土形过载        土形不足
    商(金) 260-390Hz   S_金    金形亢进        金形收敛力弱
    角(木) 390-520Hz   S_木    木形亢进        木形不足
    徵(火) 520-780Hz   S_火    火形亢进/浮越   火形不足
    羽(水) 780-1040Hz  S_水    水形异常        肾水不足

  - 计算各频段能量占总能量(130-1040Hz)的百分比
  - 归一化：R_i = E_i / ΣE (i=宫商角徵羽)

步骤4：矛盾信号检测（虚阳外浮识别）
  ⚠️ 关键辨证逻辑 — 不可直接套用"五音高=S偏高"的线性映射：
  
  检测条件：徵(火)能量 > 28% 且 RMS能量均值 < 0.02
  判定：虚阳外浮（浮越之火）
  解释：真正的火亢应同时伴有RMS能量高（声高气粗）。
        RMS极低但徵音占比高 = 残存的微弱火气无法被水锚定，
        全部浮越于上焦咽喉。
  ⚠️ 硬件校准：若已知麦克风音量偏低，RMS阈值(<0.02)参考价值下降。
        此时以徵火占比(>28%)为主要判断依据，结合临床印证。
        若徵火 > 30% 即使RMS因硬件偏高(>0.02)，仍标记"疑似虚阳外浮"。
  临床印证：询问患者是否有"半夜不睡、阳不入阴"的睡眠模式。
  修正：S_火标记为 ↓↓↓（浮越），非 ↑↑

步骤5：S向量闻诊判定
  对于每个五形分量，计算相对于基准分布（各20%）的偏差：
    deviation_i = (R_i - 0.20) / 0.20 * 100%
    → deviation > +15%  → ↑↑
    → deviation > +5%   → ↑
    → deviation < -15%  → ↓↓
    → deviation < -5%   → ↓
    → 否则 → ↔

  特殊修正规则：
  - 若步骤4检测到虚阳外浮 → S_火强制设为↓↓↓（浮越），覆盖线性映射
  - 若F0中位数低 + 徵音高 + RMS低 → 虚阳外浮置信度更高
  - 商(金)音反映的是当前金形活性，与舌下青筋等结构性金形物证
    需要区分（三期分化：先天→暴冲期→当前）

步骤6：交叉验证与输出
  将音频分析得出的S向量与P1（望/问/切）诊断进行比对：
  - 若方向一致 → 闻诊修正置信度高
  - 若方向矛盾 → 标记"需复核"，优先以P1为准，声域分型降权
  - 输出格式见下方《闻诊音频分析报告》模板
```

## P0 — S_0 先天基底引擎（持久层）

> S_0 是所有诊断的参照原点。它不是八字排盘后锁死的常数——**跨就诊持续更新**。S_0 的主干由出生时间（八字）决定。出生地、常驻地、工作性质是 **P3 级冲突修正因子**——仅在 P1（四诊）与 P2（八字）数据出现系统性偏差时提供方向性参考，不作为默认的高权成分。

### 初始化

S_0^0 的核心公式（P2 主干）：

```
S_0^0 = f_八字(年, 月, 日, 时)
```

P3 修正仅在 P1-P2 冲突时叠加：

```
若 P1-P2 冲突成立 → S_0^0 = f_八字 + ε_P3(出生地, 常驻地, 工作性质)
其中 ε_P3 为微量方向性修正（±5%以内），只做定性不做定量
```

| 精度等级 | 适用场景 | S_0 推定方法 |
|---------|---------|-------------|
| **L0（估算）** | P1 简查——常见病初诊 | 体质问卷 |
| **L1（中精度）** | P1+P2——慢性病 | 体质问卷 + 长期脉象基底 + 体型骨架 |
| **L2（高精度）** | P1+P2+P3——疑难症/久治不愈 | 八字排盘精算 S_0^0 |

> **注意**：L2 精度的核心是八字排盘，而非地域数据。出生地/常驻地/工作性质仅在 P1-P2 出现方向性矛盾时作为冲突解释参考，不参与 S_0 的定量合成。

### 每次复诊后的更新

```
S_0^(t+1) = S_0^t + α·(ΔS_actual − ΔS_predicted)   // 药效反馈
               + β·(发病模式偏移)                     // 病情模式
               + γ·(生活事件漂移)                      // 人生经历
               + δ·(环境变更)                          // 常驻地/工作变化（仅重大变更时激活）

其中：
  α = 学习率（初诊≈0.3，复诊3次后衰减至≈0.1）
  β = 发病模式权重（偏移方向与历史主成分方向一致时激活）
  γ = 生活事件权重（仅重大事件如妊娠/手术/丧偶时激活）
  δ = 环境变更权重（仅搬离气候带/换行业时≈0.1，微幅修正）
```

### 数据依赖

- 首次就诊需八字数据（或替代问卷）→ 无八字则用 L0 估算
- 每次复诊需记录 ΔS_actual（实际药效）→ 无药效数据则不触发 α 修正
- 长期档案自动积累 → S_0 精度随就诊次数递增

### 第五步：八字命理 — SPUM 翻译（P3 先天基底精修）

> 注意：此步在总流程中标记为 **P3 级——先天基底精修**。与旧版（P3 深度诊断）的区别：
> - **旧**：八字命理是可选附加诊断，"预测病势倾向"
> - **新**：八字命理是 **S_0 的高精度推定工具**，S_0 本身是五诊合参中不可缺的第五诊
>
> 没有八字，仍然可以用体质问卷估算 S_0（L0/L1），只是精度较低。有八字，S_0 的初始估计更精确，后续互证建模的收敛速度更快。

## 三、特殊场景处理

### 3.1 急性/危重症处理原则

```
⚠️ 危急值预警 ⚠️

以下情况必须标注"立即就医"：
  1. 疑似心梗（胸痛+冷汗+气短）
  2. 疑似中风（偏瘫+口角歪斜+言语不清）
  3. 高热不退（体温>39.5℃持续>48h）
  4. 严重外伤/出血
  5. 剧烈腹痛/持续性呕吐/黑便/呕血
  6. 呼吸困难/窒息
  7. 意识障碍/昏厥
  8. 怀疑药物中毒/过敏反应（皮疹+喉头水肿+呼吸困难）

范式说明：
  中医关系学网络与西医生理学实体之间不存在通约关系。
  "立即就医"不是"中医不行了需要西医"——而是"当前事件触发的是物理实体层面的安全问题，
  超出了关系网络调理的范畴"。就像一台电脑的操作系统（关系网络）出了问题可以用软件调试，
  但电源线烧了（物理实体）需要找电工——这是两个不同的维度，
  不是"软件不如电工"。
```

### 3.2 药物过服/误服应急处理

药物过服/误服的分析和干预**严格在中医关系学框架内进行**——关注的是药物 ΔS 操作对关系网络拓扑结构的影响：

```
药物过服/误服的 SPUM 逻辑（基于《神农本草经》药性 ΔS 向量库）：

  - 大黄/芒硝过服 = 金形暴冲（ΔS_金↑↑）+ 水形强排（ΔS_水↑↑）
    → 土形储备被冲刷（ΔS_土↓↓）+ 火形随液脱逸（ΔS_火↓）
    网络效应：水形链被过度疏通→节点间连接稀疏化→网络承载力下降
    处理：停服 + 温补土形（米汤/粥——温和的 ΔS_土↑）+ 火形恢复（生姜——ΔS_火↑温和）

  - 附子/乌头过服 = 火形暴冲（ΔS_火↑↑↑）
    → 木形锁死（ΔS_木↑↑——痉挛）+ 火形异常消耗后急剧衰竭（ΔS_火↓↓↓）
    网络效应：火形瞬间过载→木形环异常收缩→网络刚性化
    处理：立即就医（物理层面安全问题）

  - 虫类药（水蛭/虻虫/蛰虫等）过服 = 金形桥边切换失控（ΔS_金↑↑）
    → 脆弱结构（木形细环、水形细链）被切断→连接断裂
    网络效应：金形桥边切换活性超过网络的修复能力→不可逆断边
    处理：停服 + 补土固本（ΔS_土↑——增强网络修复能力）

所有情况的第一步：停服 + 判断事件是否涉及物理实体层面的安全问题（而非单纯关系网络问题）
```
