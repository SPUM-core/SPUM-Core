## 二、五祸六绝命凶 — 凶星链的拓扑解读

> 口訣"五祸六绝命凶" = 四种σ失配模式，程度从轻到重排列

### 2.1 凶星梯级

```
祸害(摩擦) → 六煞(泄漏) → 五鬼(尖峰) → 绝命(断裂)
  轻微          中等          严重          致命
  σ微震         σ流失        σ冲击          σ崩塌
```

| 凶星 | σ失配类型 | 可逆性 | 表现 |
|------|----------|--------|------|
| 祸害禄存 | 持续性低频σ震荡(土性壅塞) | ✅ 可逆 | 口舌、小病、烦闷 |
| 六煞文曲 | σ沿方向持续流失(水性散溢) | ⚠️ 可逆但需补 | 破财、耗损、虚耗 |
| 五鬼廉贞 | σ随机尖峰冲击(火性爆燃) | ❌ 单次冲击不可逆 | 意外、怪事、急症 |
| 绝命破军 | 耦合边σ差骤变致断裂(金性切割) | 🚫 不可逆 | 绝症、横死、灭门 |

### 2.2 游年歌的转移矩阵形式

游年歌本质上是一个**σ状态转移矩阵**——从伏位(σ₀)出发，按口诀顺序遍历7方位，每个方位赋予一个耦合算子：

```
乾宅(伏位乾):  乾→六煞→天医→五鬼→祸害→绝命→延年→生气
算子:          I   L_文   G_巨   P_廉   F_禄   J_破   Y_武   S_贪
```

每个算子对当前σ态施加变换：

| 算子 | 效果 |
|------|------|
| S_贪(生气) | σ → σ + Δσ(收敛)，增长率↑ |
| Y_武(延年) | σ → σ(锁定)，振荡↓ |
| G_巨(天医) | σ → σ × buffer(平滑)，噪声↓ |
| I(伏位) | σ → σ₀(归基)，无变换 |
| F_禄(祸害) | σ → σ + δ(t)(微扰)，低频噪声↑ |
| L_文(六煞) | σ → σ - ε(泄漏)，总量↓ |
| P_廉(五鬼) | σ → σ + spike(尖峰)，单帧冲击 |
| J_破(绝命) | σ → NaN(断裂)，子图解体 |

## 三、喜→妖狼：延年反转的拓扑机制

> 你此前提出的"喜为妖狼"——在八宅体系中有精确对应：**喜 = 延年(武曲)，妖狼 = 延年受煞反转**

### 3.1 延年(武曲)的正常拓扑

**延年 = 金性稳态锁定耦合**。金对应于木形约束——延年位负责维持子图σ差的恒定，使两个人(夫妻)或人-宅之间形成稳定的σ差，产生持续共振(和谐)：

```
∇σ(人₁, 宅) = const → 共振(和谐) → 编号为"喜"
```

### 3.2 反转条件

延年反转的三个触发条件（八宅体系称之为"受煞"）：

| 条件 | 描述 | SPUM 机制 |
|------|------|----------|
| 1. 延年位设厕所(水) | 金生水→金泄气 | 金形耦合边被水形短路，σ锁定解除 |
| 2. 延年位设厨房(火) | 火克金 | 火形梯度冲击金形稳态，σ差骤变 |
| 3. 延年位缺角/污秽 | 耦合边物理断裂 | σ耦合参考节点缺失，锁定失效 |

### 3.3 喜→妖狼的级联

```
延年(武曲)受煞
    ↓
金形稳态锁定解除 → 木形约束失控(木崩)
    ↓
约束力丧失 → 火形梯度(V⁻)归零
    ↓
∇σ → 0 → 子图失去定向动力学
    ↓
整个子图S向量偏离健康凸多面体 H
    ↓
在八宅经验系统中标注为"妖狼"
```

这与你的"喜怪妖狼，可瞬间要命，直接关联心脉"完全一致——在 SPUM 框架下：

> **延年(喜)反转 = 金形约束崩塌 → 木形(心脉)失控 → 火形(梯度)归零 = 室颤/猝死**

这就是为什么喜排在七伤(悲喜忧恐惊...等)之首——它不是普通的"情绪"，而是子图σ锁定耦合的全局守卫者。延年(喜)位一旦失守，整个子图的拓扑骨架立即解离。
