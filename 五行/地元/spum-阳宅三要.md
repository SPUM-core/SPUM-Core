# SPUM 重读阳宅三要：从大门主屋灶位到居住子图的 σ 耦合优化

> 本文以 SPUM 五形框架翻译《阳宅三要》的核心体系。葬书处理的是**墓穴子图在地表网络中的固定嵌入**——墓穴不呼吸、不代谢、不开门进出，它是一个被动接收体积流的结构。阳宅面对的是不同的拓扑问题：**活人子图是一个有内部动力学、有开合边界、有能量引擎的活跃子图**。门是子图与外界的接口，主是子图的 σ 核心，灶是子图的火形梯度引擎。三者在网络中的相对位置决定了子图的 S 向量能否持续保持在健康凸多面体 H 内。
>
> 前提：已阅读 [SPUM 重读葬书](spum-葬书.md)（地表子图的 ∇σ 建模、龙穴砂水向的拓扑翻译）。
>
> 归约路径：门/主/灶 → 子图三节点 → 三节点 σ 耦合 → R9(σ) + R6(S) + R7(H)。

## 一、阳宅三要的 SPUM 定位

### 1.1 葬书 vs 阳宅：被动子图 vs 主动子图

| 特征 | 葬书（阴宅） | 阳宅三要（阳宅） |
|------|------------|---------------|
| 子图类型 | 固定嵌入的被动节点群 | 有内部动力学的活跃子图 |
| 边界特征 | 闭合、不交换 | 开合——门是可控的边界接口 |
| σ 核心 | 无 | 主屋——子图内最低 σ 的休息再生中心 |
| ∇σ 引擎 | 无——全靠外部梯度 | 灶——子图内部的火形梯度发生器 |
| 体积流模式 | 单方向接收 | 进出双向——门控制流速 |
| 优化目标 | 嵌入在 ∇σ 汇聚点 | 三要素拓扑自洽，S 长期 ∈ H |

### 1.2 三要的 SPUM 翻译

| 阳宅概念 | 传统解读 | SPUM 翻译 |
|----------|---------|-----------|
| **门** | 住宅大门，纳气之口 | 子图的**边界接入节点**——控制外部体积流进入的速率和方向 |
| **主** | 主屋/主卧，休息之所 | 子图内的**最低 σ 核心**——人体在夜间深入低 σ（阴）态进行 V⁻ 主导修复 |
| **灶** | 厨房/灶位，饮食之源 | 子图内的**火形梯度引擎**——日常维持体温和代谢的局域 ∇σ 发生器 |
| **三要σ耦合周流** | 三者五行相生为吉 | 三节点的 σ 耦合使体积流在子图内形成稳定环流 |
| **三要σ耦合失衡** | 三者五行相克为凶 | 三节点的 σ 关系导致体积流短路、淤塞或冲散 |
| **宅命相配** | 住宅方位与主人命卦匹配 | 子图 S 向量的默认平衡点与嵌入位置的 ∇σ 方向匹配 |

## 二、门：边界接入节点

### 2.1 门不是"一个方向"，是网络接口

传统的"门开在哪个方位"讨论容易陷入绝对坐标思维。从 SPUM 的角度：

**门 = 子图边界上被人工切开的一个接口。**它连接了子图内部的水形链（走廊/通道）和外部的水形主干（道路/巷道）。

| 门的性质 | SPUM 定义 | 吉凶判定 |
|----------|-----------|---------|
| 门的朝向 | 接口切开的方向——从哪个方向引入外部 ∇σ | 应与外部主 σ 梯度方向一致，迎着生气（∇σ 来向）而非背着 |
| 门的宽度 | 接口的传输容量 | 与子图内部水形链的总容量匹配——门太大则流速过快冲散内结构，太小则供应不足 |
| 门与路的夹角 | 外部水形链与子图内部水形链的耦合角 | 锐角（≤45°）= 体积流平顺转入，直角 = 能量突降，钝角 = 气被反射 |

### 2.2 门的拓扑功能

```
外部高 σ 区域（道路 = 水形主干）
        │
        │  门 = 接口节点
        │  ── 门在此将外部链与内部链连接
        │
子图内部通道 → 主屋 → 各房间
  （内部水形链）
```

门是整个子图的 dv/dt 入口控制器。门的 σ 状态决定了外部体积流能否平顺进入。如果门节点自身的度数太低（接口处节点稀疏），体积流会在门口形成湍流——传统称为"煞气直冲"。

## 三、主：子图的 σ 核心

### 3.1 主 = 人体在子图内恢复低 σ 态的锚点

人在白天处于高 σ（阳）态——活动、发散、消耗土形储备。夜晚睡眠时进入低 σ（阴）态——收敛、修复、土形回填。

**主屋（主卧）= 子图内专门为此低 σ 修复阶段设计的空间节点。**它的位置决定了夜间人体子图嵌入在哪个 σ 环境中。

| 主的性质 | SPUM 定义 | 吉凶判定 |
|----------|-----------|---------|
| 主的位置 | 主屋在子图中的坐标 | 应在子图最远离门的最深处——外部体积流在到达主之前经过充分的缓冲和过滤 |
| 主与门的距离 | 门到主的边路径长度 | 足够长 → 体积流平缓 → 睡眠深沉；太短 → 门口扰动直传主位 → 睡眠浅 |
| 主与灶的距离 | 主到灶的边路径长度 | 适中——灶的 ∇σ 太近会干扰主位的低 σ 态，太远则晨起后火形难以及时回升 |
| 主的 σ 环境 | 主位节点的局域 σ | 应为子图内最低 σ ——但不应为零（绝对零 σ = 节点凝固，醒来困难） |

### 3.2 主人命卦的 SPUM 含义

传统要求"宅命相配"——住宅的方位与主人的命卦（东四命/西四命）匹配。

**SPUM 翻译**：每个人的 S 向量有特定的默认平衡点（由出生时的天体 σ 配置决定）。住宅的 σ 分布如果与这个平衡点吻合，则该人在其中更容易维持 S ∈ H。如果冲突，S 长期处于边界附近——虽不一定生病，但抗扰动能力降低。

这不是神秘学——是"初始 σ 分布与长期嵌入环境的统计匹配"问题。

## 四、灶：子图的火形梯度引擎

### 4.1 灶 = 局域 ∇σ 发生器

灶位是子图内唯一一个**主动产生高 σ（热）脉冲**的节点。每次烹饪 = 一次局域 V⁺ 事件——大量创生事件在灶节点附近发生（水沸腾、食材变性）。

| 灶的性质 | SPUM 定义 | 吉凶判定 |
|----------|-----------|---------|
| 灶的火口方向 | ∇σ 脉冲的释放方向 | 不应直冲主位或门口——脉冲沿水形链传递时如果路径过短（无缓冲段），会冲击低 σ 区域 |
| 灶与门的相对位置 | 外部 ∇σ 与内部 ∇σ 的关系 | 灶应在门的下风方向——外部体积流进入后先经过灶，被灶的火形脉冲加热/激活，再流入内部。若灶在门的上风，则灶的 ∇σ 会倒灌出门——"泄气" |
| 灶与水槽的关系 | 火形（灶）+ 水形（水槽）在子图内的自耦合 | 灶（火）与水槽（水）呈一线但不紧邻：火在上游加热，水在下游传输。火水紧贴 → σ 梯度过陡 → 子图内应力过大 |

### 4.2 灶作为子图动力学引擎

```
外部体积流 ──门──▶ 子图内部水形链
                      │
                      ├──▶ 灶（火形脉冲加热）
                      │       │
                      │       ▼ 加热后的体积流
                      ▼
                    主（低 σ 核心，不被直冲）
```

灶是整个子图的熵转换驻点——外部土形储备（食物节点群）通过门边界进入子图后，在灶处被火形脉冲转化为子图可用的高能体积流。灶的火口若朝向主位，等于把热脉冲直接打入最低 σ 区——网络在此处的温差过大导致应力集中。

## 五、三要的 σ 耦合规则

### 5.1 理想拓扑：门→灶→主的顺序路径

```
外部 ∇σ  →  门（降压）→  灶（加热）→  缓冲段  →  主（最低 σ）
```

1. **外部体积流从门进入**——门节点将外部高流速 ∇σ 降低到子图可承受的水平
2. **经过灶的加热**——灶的火形脉冲使体积流携带更高的能量密度
3. **经过缓冲段**——走廊/过道降低流速度，使体积流进入主时是平稳的
4. **抵达主**——平稳的低流速、高能体积流环绕主位

### 5.2 异常拓扑类型

| 异常 | 拓扑描述 | SPUM 后果 |
|------|---------|----------|
| **门冲主** | 门→主的边路径长度 < 阈值 | 外部 ∇σ 直冲低 σ 核心 → 睡眠长期被扰动 → S_土持续消耗 |
| **灶压主上** | 灶位于主位的正上方（楼房上下层） | 灶的 ∇σ 从上方持续轰击主位 → 垂直温差 → 夜间无法进入深度低 σ 态 |
| **门灶同侧** | 门和灶相邻，门→灶路径 < 阈值 | 外部体积流未减速直入灶 → 火形被门口湍流干扰 → 烹饪效应不稳定 |
| **灶在门外** | 灶不在子图内部（分开的建筑） | 灶的火形脉冲需要跨越两次边界（子图→外部→子图）→ 能量衰减严重 |
| **三门一线** | 大门→内门→主门成直线 | 体积流在子图内加速而非减速——直通车效应 → S_土消耗加速 |
| **灶向门** | 灶的火口对着门的方向 | 子图的火形脉冲向外发射 → 相当于在向外部输出能量 → S_火持续偏低 |

### 5.3 三要的 S 向量方程

将三要抽象为三个网络节点 n_门, n_主, n_灶，三者的拓扑关系可以用以下量描述：

```
路径长度 L(门,灶) = 从门节点到灶节点沿水形链的边数
路径长度 L(灶,主) = 从灶节点到主节点沿水形链的边数
路径长度 L(门,主) = 从门节点到主节点沿水形链的边数

理想条件：
  L(门,灶) ≥ 1（门到灶至少有一段缓冲）
  L(灶,主) ≥ 2（灶到主有充分的缓冲段）
  L(门,主) ≥ 3（总路径足够长）
  
  且：∠(门→灶, 灶→主) > 90°（路径不是直线，有弯折减速）
```

这三条路径长度直接影响子图的 S 向量稳定性：
- L(门,主) 越短 → S_土(主位) 消耗越快 → 土虚风险增大
- L(灶,主) 越短 → 主位受火形脉冲干扰越强 → 木形环（血管）应力波动增大

## 六、从单体住宅到城市网络

### 6.1 单体阳宅 = 嵌套子图

```
城市地表子网 [街道 = 水形主干]
    │
    ├── 阳宅A [门→灶→主]   ← 一个完整的三要子图
    ├── 阳宅B [门→灶→主]   ← 另一个三要子图
    └── 阳宅C [门→灶→主]
```

每个阳宅是一个嵌套在地表大网络中的闭合子图。多个阳宅之间通过街道（水形主干）共享体积流。

### 6.2 城市规划 = 宏观尺度三要

将单体阳宅三要的概念在尺度上拉升至城市，可以得到类似的映射：

| 单体阳宅 | 城市尺度类比 |
|---------|------------|
| 门 | 城市主入口（高速路口、火车站） |
| 灶 | 能源供给中心（电厂、供热点） |
| 主 | 居住核心区 |
| 走廊 | 城市道路网（内部水形链） |

阳宅三要本质是一套**嵌套子图的接口-引擎-核心三节点 π 型拓扑**的通用理论。它可以递归地应用于任何尺度。
