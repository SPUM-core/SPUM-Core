## 一、范式总纲

### 1.1 什么是"子网"

在 SPUM 中，子网（sub‑network）不是"一个主题文件夹"，而是**一组通过归约链彼此连通的节点集合**——每个节点对应一个被 SPUM 形式化翻译的传统概念，节点间的边对应概念间的推导或映射关系。

**为什么需要子网**：
- 黄帝内经、伤寒论、金匮要略、葬书、周易、奇门遁甲 — 这些经典的术语体系各自独立，表面互不连通
- 传统研究将它们放在各自的历史语境中解读，无法跨领域对话
- 子网的目的：用 SPUM 的统一本体论作为底板，让所有传统概念在同一张网络上定位、比较、连接

### 1.2 子网的四大分区

| 分区 | 经典来源 | 核心对象 | 已构建文件 | 计划纳入 |

### 1.3 归约机制（三级映射）

**任何传统概念进入子网，必须经过三级归约**——禁止直接使用传统术语在 SPUM 语境中做推理。

```
[传统概念]  ──Tier 1──▶  [SPUM 定性定义]
    如"麻黄汤"  ──────▶   "火形脉冲 + 水形疏通 + 木形松解 + 土形缓冲"

[定性定义]  ──Tier 2──▶  [SPUM 形式化表达]
    ΔS = (火↑, 水↑, 木↓, 土↑, 金=0)
    各分量有相对强度标度和方向

[形式化表达] ──Tier 3──▶  [可计算指标]
    S_火 = f(∇σ_体表, t) 的帧序列
    S_木 = dμ_肺区域/dt 的帧序列
    ...
```

每个节点在子网中标明当前归约层级（T1 / T2 / T3），后续工作逐步推到 T3。

### 1.4 五形 vs 五行：术语使用规范

> **背景**：`spum-core.md` 第六节对同一组拓扑结构模式使用了两个名称：**五形**（图论形式化名称）和**五行**（传统名称）。二者指代相同的五种基本网络结构模式，但使用场景有严格区分。此规范消除跨模块术语歧义（对应审查问题 P2-11）。

| 术语 | 语境 | 定义来源 | 使用场景 |
|------|------|----------|----------|
| **五形** | SPUM 本体论（L0） | `spum-core.md` §6.1-6.5 的图论定义 | 内部推理、图论指标计算、S向量分量指称、与其他模块（社会学/经济学等）交叉引用时 |
| **五行** | 传统语境的 SPUM 重命名 | 与五形相同的图论结构，沿用传统名称作为历史锚点 | 本模块标题和传统概念引用（如"五行子网""五行学说"）、与传统经典（黄帝内经、伤寒论等）对话时 |

**核心原则**：
- 在 SPUM 形式化语境中（Tier 2/Tier 3），必须使用**五形**及 S 向量分量名（S_水/S_木/S_土/S_金/S_火）
- 在传统概念对话中（Tier 1 及模块总述），可使用**五行**
- 禁止在同一段落中不加区分地混用两个术语——每次切换必须标注转换原因
- S 向量的五个分量名称（S_水等）是五形式的，不是五行式的——它们直接对应五种拓扑相位的图论指标

## 二、子网的 SPUM 本体论根节点

> **R1-R9 唯一定义来源**：`.trae/rules/spum-root-nodes.md`。以下两表格中的"SPUM 定义"列为摘要，完整定义以中央文件为准。"对应的传统问题域"列为本模块的应用映射。

所有传统概念最终归约到以下 9 个**不可再分解的根节点**。子网中不允许出现不能沿边追溯到根节点的浮空节点。

### 2.1 宇宙本体层（来自 `spum-core.md`）

| 编号 | 根节点 | SPUM 定义 | 对应的传统问题域 |
|------|--------|----------|----------------|
| R1 | **⟨P, ε⟩** | 节点集 + 边集，关系定义存在 | 一切存在论的终极底板 |
| R2 | **V⁺ / V⁻** | 创生事件 / 湮灭事件，全局守恒，局域有净差 | 阴阳、消长、生死、药物作用 |
| R3 | **离散帧 τ** | 网络演化步数，帧内无循环 | 病程阶段（六经传变）、药效时序 |
| R4 | **dv/dt ≤ const** | 单帧关系变化上限 | 病变起源、治疗的安全边界 |
| R5 | **不完美定理** | 每帧必残留悬挂端 | 慢性病根、亚稳态吸引子 |

### 2.2 五形-S向量层（来自 `spum-core.md` 第六节）

| 编号 | 根节点 | SPUM 定义 | 图论指标 |
|------|--------|----------|---------|
| R6 | **S = (S_水, S_木, S_土, S_金, S_火)** | 网络在任何时刻的五维结构健康向量 | 各分量有其可计算指标集 |
| R7 | **健康凸多面体 H** | S 的各分量在合理区间内的 n 维凸区域 | S ∈ H ⇔ 健康 |
| R8 | **ΔS** | 方剂/干预 = 五维位移向量 | 每味药有 ΔS 分量贡献 |
| R9 | **σ = |P|/|ε|** | 空间密度，决定火形梯度 ∇σ | 寒热、温度、能量分布 |

### 2.3 归约流程图

```
传统概念（如"肝气郁结"）
    │
    ▼ Tier 1
SPUM 定性定义：
  "肝区木形环 μ 超过健康区间，环边收缩、弹性丧失"
    │
    ▼ Tier 2
SPUM 形式化：
  S_木(肝区) > H_木_max
  同时 S_火(肝区) ↓（因环锁死阻碍 ∇σ 传导）
    │
    ▼ Tier 3
可计算指标：
  μ_肝区 = 环基数(肝区子图)
  λ2_肝区 = 肝区拉普拉斯矩阵的第二特征值
  若 μ > μ_critical 且 λ2 > λ2_critical → 肝气郁结 T3 确认
```

## 五、跨子网连接：四个子网的统一底板

四个子网不是四个孤立的子网——它们在 SPUM 本体论层面通过共享根节点彼此连通。

### 5.1 共享底板

| 共享根节点 | 中医使用方式 | 风水使用方式 | 易学使用方式 | 时空使用方式 |
|-----------|------------|------------|------------|------------|
| R9 (σ 梯度) | 人体内部的 σ 局域分布与火形梯度 | 地表子图的 σ 空间分布与龙脉走向 | 河图洛书=σ 分布的对称/不对称模板 | 九宫=σ 的 3×3 离散采样 |
| R6 (S 向量) | 人体闭合子图的五维健康向量 | 地理子图的五维宜居向量 | 64卦=6位状态向量；体用生克=子网界面交互判定 | — |
| R2 (V⁺/V⁻) | 药食的创生/湮灭效应，正邪之争 | 地气（V⁺ 源）的方向与强度 | — | — |
| R3 (离散帧 τ) | 病程阶段、方剂时序 | 葬书的选址帧 | 十二消息卦=σ 的 12 帧采样；动爻=帧间度数最大偏移 | 天干地支=τ 双层索引、奇门择时 |
| R5 (不完美定理) | 慢性病根、亚稳态吸引子 | — | 每卦必有动爻=每帧必有悬挂端 | — |
| FS-007 (取向场) | 人体经络的走向 | 龙脉方向，穴的朝向 | — | 值符=当前帧 ∇σ 最强方向 |

### 5.2 核心统一原理

**人体嵌套于地理之中，两者是同一关系网络的子图-母图嵌套**：

- 人体是一个闭合子图（χ=2），嵌入地表这个更大的开放子图
- 地表子图的 σ 分布通过取向场和 ∇σ 影响人体子图的边界 σ 分布
- 好的风水穴位 = 地表 σ 分布使嵌入其中的人体子图的边界在每个时辰都受到最优的取向场支持
- "一方水土养一方人" = 长期嵌入不同地表子图的人体子图，其 S 向量的默认平衡点不同

**中医 + 风水 = 同一张网络的不同尺度观测**。中医研究人体子图内部的 S 调节，风水研究地表子图如何优化它所嵌套的人体子图的边界条件。

## 六、无矛盾原则与冲突消解

### 6.1 无矛盾三定律

| 定律 | 内容 | 违规示例 |
|------|------|---------|
| **归约消解律** | 任何两个传统概念出现表面冲突，必须在归约到 SPUM 根节点后消解——冲突是传统语言的冲突，不是本体的冲突。 | "肝主升" vs "肺主降" 不冲突：肝区的 ∇σ 方向向上（木形环扩展方向），肺区的 ∇σ 方向向下（水形链降逆方向）——它们是同一张网络上不同位置的两个 ∇σ 方向，互补而非矛盾。 |
| **无浮空节点律** | 子网中任何节点必须有至少一条边连接到根节点 R1-R9——不允许"尚未归约，暂时如此"的浮空概念。 | "气"不能停留在传统定义——必须归约到 σ 梯度驱动的体积流（气）或纤维丛取向场（风气）。未归约的气 = 浮空节点，标记为 T0 待归约。 |
| **无外部引入律** | 子网的所有概念必须从 ⟨P, ε⟩ 内部推导——不允许引入"神秘力量"、"先天智慧"、"不可言说的体悟"等外部概念。 | "天人感应" 不是神秘联系——是人体子图与地表-天体环境的 σ 耦合。不需要额外的"感应"机制。 |

### 6.2 冲突消解流程

```
发现两个传统概念表面冲突
    │
    ▼
步骤 1: 分别归约到 SPUM
    ├─ 概念 A → SPUM 节点 A'（注明归约路径）
    └─ 概念 B → SPUM 节点 B'（注明归约路径）
    │
    ▼
步骤 2: 检查 A' 与 B' 是否有图论矛盾
    ├─ 无矛盾 → 冲突消解，传统冲突是语言问题
    └─ 有矛盾 → 进入步骤 3
    │
    ▼
步骤 3: 检查哪一方的归约路径有误
    ├─ A 的归约错误 → 修正 A 的 SPUM 翻译
    ├─ B 的归约错误 → 修正 B 的 SPUM 翻译
    └─ 两者归约均无误但仍有矛盾 → 进入步骤 4
    │
    ▼
步骤 4: 两者中至少一个传统概念本身是错误的
    → SPUM 不做辩护律师（见 黄帝内经 §2.6）
    → 标记错误概念，记录为什么错 + SPUM 的正确版本
```

### 6.3 已知冲突及消解记录

| 传统冲突 | 冲突表述 | SPUM 消解 |
|---------|---------|----------|
| 肝属木 vs 肺属金 | 五行生克：金克木 → 肺克肝 | 不是克制关系——是金形（肺部排泄清理）和木形（肝部环代谢）是同一网络上两个不同功能的五形子相位。它们不"克"，而是通过 S 向量耦合——肺金亢（过度排泄）减少肝区可用的土形储备。 |
| 心属火 vs 肾属水 | 水克火 → 肾克心 | 不是克制——肾区的极低 σ 核心（储能）和心区的 ∇σ 引擎（耗能）是一对 V⁺/V⁻ 耦合。不是"肾灭心火"，是"肾的低 σ 供应控制心的 ∇σ 不至于过冲"。 |
| 麻黄发汗 vs 阳虚禁用 | 同一味药有时用有时不用 | 麻黄操作 S_火 ↑↑——当 S_土 储备充足时安全有效，当 S_土 已枯竭（阳虚）时再提 S_火 会彻底耗尽土形 → 脱证。不是"药性变了"，是"网络的当前状态不同"。 |

## 八、研究规范

### 8.1 新增节点的流程

任何新的传统概念要进入子网，必须走完整流程：

1. **提交**：传统概念名称 + 经典出处 + 传统定义（原文）
2. **T1 翻译**：用 SPUM 根节点 R1-R9 的语言给出定性定义
3. **归约路径验证**：画一条线从新节点连接到最近的已有节点，再从该节点追溯到根节点 R1-R9——路径必须连续、无跳跃
4. **冲突检测**：检查新节点是否与任何已有节点的 SPUM 翻译冲突
5. **注册**：分配节点 ID，写入对应子区（中医/风水），更新本文档

### 8.2 节点的状态标签

| 标签 | 含义 |
|------|------|
| `✅ 已验证` | 归约路径完整，无冲突 |
| `🔄 归约中` | 已有 T1 翻译，T2 形式化进行中 |
| `⚠️ 待归约` | 已识别但尚未翻译（浮空节点警告） |
| `❌ 已排除` | 归约后确认为不可还原/不可区分 → 从子网排除 |
| `🔗 跨子网` | 节点同时属于中医和风水两个子网（如取向场 FS-007） |

### 8.3 禁止事项

- ❌ 在 SPUM 语境中使用未归约的传统术语做推理
- ❌ 引入 SPUM 公理体系外的"解释"（如"这是古人的智慧，我们还不理解"）
- ❌ 将传统概念的冲突标记为"辩证统一"而不做 SPUM 消解
- ❌ 跳过归约链直接从传统概念跳跃到现代科学概念（如"气=ATP"）——必须经过 SPUM 中间层
- ❌ 创建不能追溯到 R1-R9 的浮空节点
