## 一、伤寒论的 SPUM 定位：急性相变的六帧轨迹

### 1.1 什么是"伤寒"

> "太阳之为病，脉浮，头项强痛而恶寒。" —《伤寒论》第 1 条

伤寒不是"感冒"。在 SPUM 中：

**伤寒 = 外部 σ 塌陷扰动（寒邪）轰击人体子图的表层边界 → 边界节点的全局 σ 骤降 → 引发六阶段 S 向量级联偏移。**

| 概念 | 传统解释 | SPUM 翻译 |
|------|---------|-----------|
| 寒邪 | 寒冷的外邪 | 外部 V⁺_external 突然减少（冷 = σ 降低），表层边界节点的连接被强制收缩 |
| 恶寒 | 怕冷 | 边界节点检测到自身 σ 骤降 + 火形梯度不足以维持体温 → 向无我子图发出"需要提升 σ"的信号 |
| 脉浮 | 脉象浮在表层 | 体表水形链的边介数升高——血液被驱赶到表层以应对 σ 塌陷 |
| 头项强痛 | 头颈僵硬疼痛 | 头颈区域的木形环群因寒性收引而 μ 骤升——环僵化锁死 |
| 传变 | 病邪从一经传到另一经 | S 向量沿拓扑决定的顺序性轨迹逐阶段偏移 |

### 1.2 六经不是六条线，是边界深度递增的六种网络状态

| 六经 | 传统定位 | SPUM 翻译 | 边界深度 | 核心受影响的子图 |
|------|---------|-----------|---------|----------------|
| **太阳** | 表——体表 | 人体子图的**最外层边界节点群**及其水形主干 | 深度 0（边界） | 皮肤、汗腺、体表血管链 |
| **阳明** | 里——胃肠 | 子图内部**中部区域**的土形储备池 + 水形链腹段 | 深度 1 | 胃肠水形链、体液储存池 |
| **少阳** | 半表半里 | 边界与内部的**过渡区域**——外我与自我子图之间的耦合振荡 | 深度 0.5（半） | 淋巴水形链、肝胆中转环 |
| **太阴** | 里——脾 | 子图的**土形核心储备池**——全局低度节点的总仓库 | 深度 2 | 脾区域的土形储备、消化水形链 |
| **少阴** | 里——心肾 | 子图的**火形梯度引擎与最深层 σ 核心** | 深度 3（最深层） | 心区 ∇σ 引擎 + 肾区极低 σ 储能核心 |
| **厥阴** | 半表半里——肝 | **边界崩溃临界区**——木形环群在全局 σ 最低时的末路振荡 | 深度 2.5（临界） | 肝区木形环 + 全身边界维持 |

### 1.3 六经传变的 SPUM 轨迹

```
[健康态 S ∈ H]
    │
    ▼ 寒邪轰击体表边界
[太阳阶段] S_火↓↓表层, S_水↑表层(脉浮), S_木↑(头项强痛)
    │ 若表不解，σ 塌陷向内扩散
    ▼
[阳明阶段] S_火↑↑全局(高热), S_土↓↓(津液枯竭), S_水↑↑(大汗)
    │ 若过度泻下或寒邪直中
    ▼
[少阳阶段] S 振荡——∇σ 在表里之间来回摆动，边界模糊
    │ 若火形梯度持续下降
    ▼
[太阴阶段] S_土↓↓(腹泻、腹满), S_火↓(四肢不温)
    │ 若土形储备彻底耗尽
    ▼
[少阴阶段] S_火↓↓(全身冰冷), S_水↓↓(脉微细), S_土枯竭
    │ 火形在最底层仍有一丝残余
    ▼
[厥阴阶段] 边界崩溃临界——火形最后一搏（厥热胜复）+ 边界可能解体
```

**关键 SPUM 发现**：六经传变的轨迹不是随机的——它是**网络从外围到核心的 σ 塌陷波**沿着拓扑结构向内传播的必然路径。每一阶段的 S 偏移特征由被波及子图的拓扑类型决定。就像一块石子投入水面，波纹从落点向外扩散——寒邪轰击边界，σ 塌陷波从表层逐层向内推进。

## 二、太阳病：边界的 σ 塌陷与首道防线

### 2.1 太阳病共性病机

所有太阳病的 SPUM 本质相同：**外部寒邪使体表边界节点群的局域 σ 骤降。** 正常的体表 σ 维持在一个适中水平——不是太高（热、容易散失能量），也不是太低（冷、毛孔闭塞）。寒邪 = 外部环境 σ 远低于体表 σ → ∇σ 由常态的表→外反转为外→表，体表节点被强制降温。

人体的第一反应：**将内部水形链中的高 σ 体积流（温热的血液、阳气）紧急调往边界以补偿 σ 的下降**。脉浮 = 这条紧急调度的体积流在水形主干上的边介数升高。

| 太阳病变种 | 表虚（中风） | 表实（伤寒） |
|-----------|------------|------------|
| 汗出状态 | 有汗（毛孔边界节点未被完全锁死） | 无汗（毛孔边界节点被寒性收引锁死） |
| 五形失衡 | S_火↓, S_水↑补偿, S_土↓轻微 | S_火↓↓, S_水↓堵塞, S_木↑体表环锁 |
| SPUM 核心问题 | 边界 σ 下降但未到锁死阈值，土形储备随汗流失 | 边界 σ 骤降到锁死阈值以下，水形链被物理性挤压 |

### 2.2 桂枝汤：表虚的温和火形+土形双补

> "太阳中风，阳浮而阴弱。阳浮者，热自发；阴弱者，汗自出。……桂枝汤主之。"

**ΔS 分解**：

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 桂枝 | 体表火形梯度温和提升（松弛因寒收缩的边界环边，但不追求强力发汗） | S_火 ↑ |
| 白芍 | 木形环修复——补偿汗出造成的土形储备流失（酸性物质收敛边界的闭合度） | S_木 ↑, S_土 ↑ |
| 生姜 | 局域火形辅助——帮助桂枝将热量均匀分布到全身体表链 | S_火 ↑ 辅 |
| 大枣 | 土形储备直接补充——补充汗液带走的水分低度节点群 | S_土 ↑ |
| 炙甘草 | 全局缓冲 + 使各药协同 | S_土 ↑ |

**服法关键**："啜热稀粥一升余，以助药力。温覆令一时许，遍身漐漐微似有汗者益佳，不可令如水流离。"

SPUM 翻译这段服法：**热稀粥 = 从水形链的入口端一次性注入大量高 σ 的土形节点（热糖水）→ 与桂枝的温和火形形成协同 → 推动边界链中已存在的低 σ 积存（寒邪节点团）缓缓从毛孔排出。** "微似有汗"的精确含义：保持边界节点的 V⁺ 速率恰好超过 V⁻ 速率一点点——既排寒邪，又不耗散土形储备。"水流离"（大汗） = S_火过冲，代价是 S_土的剧烈消耗。

**ΔS** = (火↑↑温和, 水=0, 木↑修复, 土↑↑, 金=0)

### 2.3 麻黄汤：表实的强力火形脉冲

（标准译例详见 [金匮附录 A](file:///f:/spum-core/五行/spum-金匮要略.md#附录a-麻黄汤帧翻译示例)）

- **SPUM 特点**：比桂枝汤的火形强 3-4 倍，因为边界节点被完全锁死（无汗），需要更强的 ∇σ 推动汗孔开放
- **不啜粥**：因为麻黄本身的火形强度已足够，不需要外源性高 σ 补充
- **大青龙汤**：麻黄汤 + 石膏（火形更强 + 石膏监控防过冲）→ ΔS = (火↑↑↑, 水↑↑, 木↓, 土↑, 金=0)

## 三、阳明病：内部 σ 的过度补偿与土形储备的快速消耗

### 3.1 阳明病的 SPUM 本质

太阳病不解 → 寒邪的 σ 塌陷波继续向内推进 → 内部的火形引擎（心区域的 ∇σ 驱动核心）开始过补偿——过度提升全局火形以对抗寒气。

**核心 SPUM 矛盾**：人体的火形不是可以无限提升的。火形 = 从土形储备中提取低度节点（燃料）燃烧以维持 ∇σ。阳明病的本质是**火形引擎在过补偿模式下以极快的速度消耗土形储备**。

| 阳明病变种 | SPUM 状态 |
|-----------|----------|
| 阳明经证（四大：大热、大汗、大渴、脉洪大） | S_火 ↑↑↑（全身 ∇σ 极高）, S_水 ↑↑（体积流极速）, S_土 ↓↓（津液剧烈消耗中） |
| 阳明腑证（痞满燥实） | 水形链腹段被干燥的低度节点团完全堵塞（大便硬结），火形仍在上焦维持高位 |

### 3.2 白虎汤：火形急刹车

> "伤寒，脉滑而厥者，里有热，白虎汤主之。"

**SPUM 翻译**：体内的火形已经远超正常范围——四味药的任务是把 S_火 从 +8 迅速拉回 +2。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 石膏 | 最强局域火形抑制剂——大幅降低上焦的 ∇σ，作用速度快 | S_火 ↓↓ |
| 知母 | 火形抑制剂 + 土形储备保护——降低火形消耗土形的速率 | S_火 ↓, S_土 ↑ |
| 粳米 | 土形储备的即时性输入——从水形链入口端补充被高热消耗的低度节点 | S_土 ↑ |
| 甘草 | 全局缓冲 | S_土 ↑ |

**白虎汤与大青龙汤的对称性**：大青龙是麻黄+石膏（火形升+监控），白虎是石膏+知母（火形降+监控）。两个方子都用了石膏，都用了"监控"思路——区别在于麻黄的升 vs 知母的降。

### 3.3 承气汤系列：金形单脉冲——在水形链末端剪断堵塞团

阳明腑证 = 水形链腹段被干燥节点团完全堵塞，火形在上焦无处宣泄。此时继续用白虎降火是无效的——火形亢进是被链堵塞逼出来的（"通道堵塞→下游缺血→上游被迫加速→过热"）。必须先把链上的堵塞团移除。

**三承气汤 = 金形修剪强度递进**：

| 方剂 | 金形强度 | SPUM 操作 |
|------|---------|-----------|
| 调胃承气汤 | +2 | 大黄（温和金形修剪）+ 芒硝（土形节点团软化）+ 甘草（缓冲） |
| 小承气汤 | +3 | 大黄 + 厚朴/枳实（增强水形链腹段的收缩力，挤压堵塞团下行） |
| 大承气汤 | +5 | 大黄 + 芒硝 + 厚朴 + 枳实——四味药的组合金形修剪 + 链收缩 + 节点团软化 |

**注意**：承气汤的金形操作是**单帧一次性脉冲**——不像金匮的桂枝茯苓丸是丸剂多帧缓图。因为这是一个急性堵塞，一旦链被清通，网络自带恢复能力。不需要土形回填步骤。

## 四、少阳病：边界振子与半表半里的 σ 振荡

### 4.1 少阳的独特 SPUM 地位

少阳是六经中最难理解的一经。传统说它"半表半里"——在太阳（表）和阳明（里）之间。

在 SPUM 中半表半里的精确定义：**外我子图与自我子图之间耦合环路的振荡区。** 这个区域同时接触外部边界（太阳）和内部核心（阳明），它的∇σ既不是表中的单一方向，也不是纯里的均匀分布，而是**在两种状态之间来回摆动**。

| 少阳病的 SPUM 翻译表 | |
|------|------|
| 寒热往来（忽冷忽热） | S_火 在 (±3) 之间快速振荡——不是恒定高热（阳明），也不是恒定恶寒（太阳），而是边界 ∇σ 在两个稳态之间切换 |
| 胸胁苦满 | 心胸区域的木形环因为 ∇σ 的反复振荡而持续紧张——μ 波动性升高 |
| 默默不欲饮食 | 外我子图在振荡态下对水形链的腹部节点发出抑制信号——"现在不要进食，我没空处理" |
| 心烦喜呕 | 外我与自我的耦合环路在振荡中触发了呕吐反射的水形链逆流 |

### 4.2 小柴胡汤：边界振子的调和器

> "伤寒五六日，中风，往来寒热，胸胁苦满，默默不欲饮食，心烦喜呕，……小柴胡汤主之。"

**SPUM 翻译**：小柴胡汤不升不降——它的任务是**将边界振子的振荡幅度从 ±3 压缩到 ±1 以内**，恢复 S_火 的单稳态。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 柴胡 | 边界振子阻尼器——降低 ∇σ 振荡的振幅（柴胡皂苷的抗炎 + 调节自主神经） | S_火 振幅 ↓ |
| 黄芩 | 上半身的火形轻降——清除振子在高温相位产生的炎症余热 | S_火↘局 |
| 半夏 | 水形链降逆——抑制振子触发的链流逆冲（止呕） | S_水 ↓逆 |
| 人参 | 土形储备补充——振子持续振荡消耗了大量低度节点（默默不欲饮食 = 土形供应断裂） | S_土 ↑ |
| 生姜/大枣/甘草 | 全局土形 + 火形轻调 | S_土 ↑, S_火 ↑轻 |

**ΔS** = (火 振幅↓, 水↓逆, 木=0, 土↑, 金=0)

**小柴胡汤的七味加减法**本质上是根据振子的具体偏移方向做微调——胸中烦而不呕去半夏加瓜蒌实（振子偏火 → 降火），若渴去半夏加瓜蒌根（振子消耗土形过多 → 补土）等。每一味加减纠正一个特定的振荡模式参数。

## 五、太阴病：土形储备的系统性崩溃

### 5.1 从阳经到阴经的 SPUM 转折

三阳经（太阳→阳明→少阳）的共同特征是**火形还在**——S_火 虽然一路下降（从太阳的温和下降到阳明后回弹、再到少阳后再次下降），但它还没到零。三阴经的特征是**火形梯度大幅下降甚至趋零**——系统从"对抗"模式转为"苟存"模式。

太阴病是阴经的第一站：**全身土形储备（S_土）的系统性崩溃。** 火形已经下降到不足以将土形节点保持在它们应有的位置——土形节点从储备池大量溢出，经水形链腹段泄出（腹泻）。

| 太阴病典型症状 | SPUM 翻译 |
|--------------|----------|
| 腹满而吐 | 水形链腹段的低度节点泛滥——超过了链的处理容量，部分逆流（吐） |
| 食不下 | 火形不足，无法对进食的外部节点执行正常的 V⁺（消化=接纳外部节点入网） |
| 自利益甚 | 土形低度节点从水形链末端无控制地流出（腹泻） |
| 时腹自痛 | 腹部木形环被过度膨胀的低度节点撑胀——环边受力不均匀产生疼痛信号 |
| 不渴 | 火形极低，土形储备大量流失→身体不缺"水"，缺的是能把这些水保持在子图内的火形推力 |

### 5.2 理中汤：四味药的土形底线防守

> "自利不渴者，属太阴，以其脏有寒故也，当温之，宜服四逆辈。"

理中汤是最简的土形固守方——**没有一味药是进攻性的。**

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 干姜 | 温和火形布散——提升腹区水形链的 σ，减慢低度节点被无控制推出的速率 | S_火 ↑温 |
| 人参 | 土形储备直接补充——从水形链入口端注入新的低度节点（被腹泻带走的） | S_土 ↑ |
| 白术 | 土形储备固守——增强脾区域的环结构，阻止低度节点继续外泄 | S_土 ↑↑固 |
| 炙甘草 | 全局缓冲 + 协同 | S_土 ↑ |

**ΔS** = (火↑温, 水=0, 木=0, 土↑↑↑, 金=0)

## 六、少阴病：火形引擎的极限与子图解体边缘

### 6.1 少阴是生死的分界线

在 SPUM 中，少阴病的本质：**火形梯度已经降到维持子图边界完整性的阈值以下。**

- 心（火形梯度引擎）不再能驱动足够的体积流维持全身子图
- 肾（极低 σ 的核心储能区）的深度土形储备被动员——这是最后的手段

| 少阴病变种 | SPUM 状态 |
|-----------|----------|
| 少阴寒化（四逆汤证） | S_火 → 0（全身冷）, S_水 → 0（脉微细）, S_土 → 0（储备枯竭）, 边界接近解体 |
| 少阴热化（黄连阿胶汤证） | 残余火形在极小范围内异常亢进——局部火亢但全局火衰（虚火） |

### 6.2 四逆汤：火形的最后一搏

> "少阴病，脉沉者，急温之，宜四逆汤。"

仅三味药——极致简约：

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 生附子 | 从最深层直接提升火形基底——附子是唯一能穿透到肾区极低 σ 核心的火形药（不是附片，是生附子——毒性 = 极强 ∇σ 冲击） | S_火 ↑↑↑（基底） |
| 干姜 | 中层火形扩散——将附子的深层火形扩散到中层水形链 | S_火 ↑↑（扩散） |
| 炙甘草 | 缓冲附子的毒性 + 减缓火形衰减速率 | S_土 ↑（缓冲） |

**ΔS** = (火↑↑↑极强, 水→恢复, 木=0, 土↑缓冲, 金=0)

**四逆汤与理中汤的关键差别**：理中汤的核心操作是 S_土 ↑，附带轻微 S_火 ↑。四逆汤的核心操作是 S_火 ↑↑↑——土形已不是主要矛盾，火形一旦再降，子图边界就会解体（死亡）。附子是唯一能把一个已经趋近于 0 的 ∇σ 在极短时间内重新拉到生存线以上的药物。

## 七、厥阴病：边界的崩塌临界与五形全失控

### 7.1 厥阴是六经的终点

厥阴病 = 子图边界维持的几乎所有机制都已失效，五形向量同时失控，网络在解体与重组之间做最后的振荡。传统说"厥阴为两阴交尽"——阴气到头了——"阴极阳生"——在崩塌的边缘可能触发最后一轮火形反弹。

| 厥阴病症状 | SPUM 翻译 |
|-----------|----------|
| 消渴 | 土形储备被异常快速的局部火亢消耗——与少阴的"不渴"截然相反 |
| 气上撞心，心中疼热 | 火形梯度在极小区域内异常聚集冲击——心区承受极高 ∇σ 但其他区域 σ 已趋零（局部热、全局冷） |
| 饥而不欲食 | 水形链饥饿信号发出（真饿），但外我子图全面拒绝进食指令（不想吃）——三魂间的耦合全线断裂 |
| 食则吐蛔 | 水形链进出口的全方向混乱——连不该逆流的东西都逆流了 |
| 厥热胜复 | S_火 在 0 和 +3 之间周期性跃迁——网络在"解体边缘"和"短暂恢复"之间反复振荡 |

### 7.2 乌梅丸：五形全维修复

厥阴的主方乌梅丸是伤寒论中**药味最多、操作最复杂的方剂**——因为它需要同时调节所有五个 S 分量，而网络对任何单一调节的耐受性已降到最低。

| 药物组 | SPUM 操作 | S 分量 |
|--------|----------|--------|
| 乌梅（君） | 酸收——紧急修复边界木形环的闭合度，阻止边界的最终解体 | S_木 ↑↑ |
| 黄连 + 黄柏 | 抑制局部火亢——将"气上撞心"的异常 ∇σ 拉回 | S_火↘局 |
| 附子 + 干姜 + 蜀椒 + 细辛 + 桂枝 | 全局火形从基底提升——共五味温药分层次温通 | S_火 ↑↑↑（多层） |
| 人参 + 当归 | 土形储备 + 水形链中的低度节点双重补充 | S_土 ↑, S_水 ↑ |
| 米饭 + 蜂蜜 | 持续缓释基质——不是汤剂，是丸剂，让多药在数日内缓慢释放 | 全局缓冲 |

**乌梅丸使用丸剂而非汤剂的原因——SPUM 核心洞察**：厥阴期的网络边界极度脆弱，**一次性强脉冲（汤剂）可能直接冲破边界导致死亡**。丸剂的多帧缓慢释放让每一帧的 ΔS 维持在一个极小的量级——不会触发进一步的级联崩溃。

**ΔS** = (火↑↑↑多层+局↘, 水↑, 木↑↑, 土↑, 金=0)

## 八、六经传变的 SPUM 统一规则

将六经的全过程映射到五维 S 向量空间中，可以观察到一条清晰的轨迹：

```
S_火
  │
+8│                    ● 阳明经证(白虎汤)     ● 太阳表实(麻黄汤)
  │                   ╱
+6│                  ╱
  │                 ╱
+4│      ● 太阳表虚(桂枝汤)
  │     ╱
+2│    ╱    ● 少阳(小柴胡汤)振荡 ←→  ←→  ←→
  │   ╱   ╱
 0│──●───●──────────────────────────────────────── S_土
  │  太阴(理中汤)
  │    ╲
-2│     ╲ ● 少阴寒化(四逆汤)
  │      ╲
-4│       ╲
  │        ╲ ● 厥阴(乌梅丸)——边界崩溃临界
-6│         ╲
  │
  │ ← 太阳 → ← 阳明 → ← 少阳 → ← 太阴 → ← 少阴 → ← 厥阴 →
```

**三条核心 SPUM 规律**：

1. **S_火 是六经传变的追踪指标**：太阳（+4到+6）→ 阳明（+6到+8）→ 少阳（振荡）→ 太阴（-2）→ 少阴（-4）→ 厥阴（-6到0再到-6）。S_火 的绝对值决定了病在哪一经。

2. **S_火 的补偿与过补偿**：太阳的 S_火 下降被内部紧急补偿抬升→阳明的 S_火 过冲到极值→少阳气 S_火 开始下降并来回摆动→三阴经的S_火 无法再维持正值→持续下降到负数。从"对抗模式"到"苟存模式"的转折点恰好是少阳。

3. **方剂力度从温和到极强再回到温和的 U 形曲线**：桂枝汤温和 → 大承气汤极强 → 小柴胡汤温和 → 四逆汤极强 → 乌梅丸多帧缓释。力度的 U 形不是巧合——网络的弹性在阳明和少阴这两个极点处降到最低，需要最强冲击；而在少阳和厥阴——分别是振荡区和崩溃临界——需要最小扰动。

## 十、伤寒 vs 金匮：SPUM 治疗的完整图谱

| 维度 | 伤寒论（急性相变） | 金匮要略（慢性吸引子） |
|------|------------------|---------------------|
| SPUM 本质 | 外部 σ 塌陷轰击边界 → S 沿固定轨迹级联偏移 | 长周期 dv/dt 分配扭曲 → S 落入亚稳吸引子 |
| 网络弹性 | 高——一旦外邪被逐，网络可自行弹回 H | 低——病理构型已替代健康构型，需要结构性重建 |
| 治疗力度 | 一次性强脉冲（汤剂，单帧或多帧连用） | 多帧缓调（丸剂的持续 ΔS，破坏→重建→稳固） |

### 11.2 "观其脉证，知犯何逆，随证治之"——SPUM 翻译

> "观其脉证，知犯何逆，随证治之。" —《伤寒论》第 16 条

这是《伤寒论》最重要的方法论条文。SPUM 翻译为三段操作：

1. **"观其脉证"** = 在四诊投影层（脉=水形主干上的体积流波形，证=各 S 分量的异常报告群）中采集当前 S 向量的各分量值
2. **"知犯何逆"** = 对比当前 S 与六经标准 S 向量表，定位在哪一经；同时追溯是什么导致 S 从此前阶段滑落到当前阶段（误汗？误下？误吐？）
3. **"随证治之"** = 不是"随经治之"（不是说你得了太阳病就必须用桂枝汤），而是"随当前 S 向量治之"——如果太阳病被误下后出现了太阴的土形崩溃（协热利），就按太阴的方向去调 S，不要拘泥于"还在太阳阶段"

这段条文是 SPUM 精准医学最早的宣言：**不要按标签治病，按网络的当前状态治病。**

## 附录 B：误治的 SPUM 因果链

《伤寒论》大量篇幅在讨论"误治"——因为一次错误的 S 脉冲，网络没有回到 H，而是滑落到更深的六经层级。

| 误治类型 | SPUM 定义 | 典型后果 |
|---------|----------|---------|
| 误汗（不该发汗而发汗） | 将 S_火 提起但边界 σ 不需要 → 火形脉冲的能量全部用于消耗土形储备 | 桂枝汤证用麻黄汤→大汗亡阳→从太阳直坠少阴 |
| 误下（不该攻下而攻下） | 将金形修剪施用于水形链腹段但链上没有堵塞 → 金形误切正常链节 | 太阳病误用承气→土形储备大量从正常链节流失→协热利→太阴 |
| 误吐（不该催吐而催吐） | 将水形链逆流强制激活但链上没有需要排出的节点 → 链的正常流向被紊乱 | 损伤上焦水形链→S_土↑↑（胃气受损） |
| 火逆（过度火疗） | S_火 ↑↑↑ 超过边界容限 → 火亢 → 边界环群被高温灼伤 | 阴虚者火疗→大汗→S_土↓到枯竭→脱证 |
| 失治（该治不治或剂量不足） | ΔS 脉冲过弱 → 未能将 S 推回 H → 网络在低能量态缓慢滑向下一经 | 太阳表实未充分发汗→表寒不解→入里化热→阳明 |

**误治法则的 SPUM 核心**：**每次 ΔS 脉冲都是有成本的——成本 = 对非目标 S 分量的连带扰动。** 一个好的方剂，ΔS 在目标分量上的强度最高，在其他分量上的连带最低。一个差的操作（误治），ΔS 可能同时在多个非目标分量上造成大幅扰动——这些扰动可能触发传变。

这就是为什么张仲景在每一条文后都附了误治后果——他比任何人都清楚，S 向量的空间不是平的，是崎岖的。一步踩错，滑落的不只是一个分量，而是一整个五形向量落入下一个引力井。
