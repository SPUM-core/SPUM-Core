### 1.2 引用说明

- 所有 `五形` = 木（环）/ 火（梯度）/ 土（储备）/ 金（修剪）/ 水（链）五种拓扑结构
- S 向量 = (S_木, S_火, S_土, S_金, S_水) —— 子图五形状态的五维指标
- H = 健康凸多面体 —— S ∈ H 表示处于健康稳态
- ΔS = 方剂/针灸导致的 S 向量改变
- ∇σ = 火形梯度 —— 驱动体积流的热/能量梯度
- μ = 木形环基数 —— 环的密度/收缩程度

## 二、临床诊断协议（七步全流程）

### 总流程

```
第一步：问诊采集（结构化提问获取患者基本信息）
    ↓
第二步：四诊合参（望闻问切 → SPUM 翻译）
    ↓
第三步：五形 S 向量诊断（输出 S 向量状态）
    ↓
第四步：病机链分析（因果关系推导）
    ↓
第五步：治疗目标确定（ΔS_target 定义）
    ↓
第六步：治疗方案生成（方剂/针灸/生活方式）
    ↓
第七步：预后判断与禁忌（演化预测 + 风险警告）
```

### 第一步：结构化问诊采集

智能体主动向患者/用户提问，按以下七个维度系统采集信息。**每次问诊必须覆盖所有维度，但不一定一次问完——可逐轮提问。**

#### 维度1：主诉（当前最困扰的症状）

> 提问方式："请问您最想解决什么问题？这个症状持续多久了？"

采集内容：
- 主要症状描述（位置、性质、程度）
- 持续时间（小时/天/月/年）
- 发作规律（持续性/间歇性/周期性）
- 诱发因素（饮食/情绪/天气/劳累/其他）
- 缓解因素（什么情况下会好转）

#### 维度2：全身一般状态

> 提问方式："您最近整体的感觉如何？"

采集内容：
- 精神体力状态（精神好/一般/疲倦/极度疲倦）
- 寒热感觉（怕冷/怕热/手脚冷/五心烦热/寒热交替）
- 汗出情况（正常/自汗/盗汗/无汗/局部出汗）
- 口渴与饮水（不渴/渴喜热饮/渴喜冷饮/渴不欲饮）
- 体重变化（近1-3月变化）

#### 维度3：头面五官

> 提问方式："您的头部、眼睛、耳朵、口腔有什么不舒服吗？"

采集内容：
- 头部（头痛/头晕/头重/头胀——部位+性质）
- 眼睛（干涩/红肿/视物模糊/眼胀/飞蚊）
- 耳部（耳鸣/耳聋/耳胀——左/右/双）
- 口腔（口干/口苦/口淡/口臭/口腔溃疡/牙龈问题）
- 咽喉（咽干/咽痛/异物感/咳嗽）
- 面色（红/黄/白/黑/青/萎黄/潮红/黯黑）

#### 维度4：胸腹腰背

> 提问方式："您的胸部、腹部、腰背部有什么感觉？"

采集内容：
- 胸部（胸闷/胸痛/心悸/气短——部位+性质）
- 胁肋（胀痛/刺痛/隐痛——左/右/双）
- 胃脘（胀满/疼痛/反酸/烧心/恶心/呕吐）
- 腹部（腹胀/腹痛/肠鸣——部位+性质）
- 腰背（酸痛/冷痛/沉重/活动受限）

#### 维度5：饮食睡眠与二便

> 提问方式："您的胃口、睡眠、大小便怎么样？"

采集内容：
- 饮食（食欲好/一般/差/善饥/纳少）
- 睡眠（正常/入睡难/易醒/多梦/早醒/嗜睡）
- 大便（正常/干结/稀溏/先干后稀/便秘/腹泻/便血——每日次数）
- 小便（正常/清长/短黄/频数/夜尿/尿痛/尿不尽）

#### 维度6：女性/男性专科

> 提问方式（女性）："请问您的月经情况如何？白带怎么样？"

女性采集：
- 月经周期（正常/提前/推后/闭经——末次月经时间）
- 经期（天数）
- 经量（正常/偏多/偏少）
- 经色（鲜红/暗红/淡红/紫黑）
- 经质（无块/有血块/稀薄/粘稠）
- 痛经（无/有——性质+程度）
- 白带（正常/量多/量少/色白/色黄/清稀/粘稠/异味）
- 生育史（孕产次数、产后/人流后时间）
- 更年期状态（潮热/汗出/烦躁/月经紊乱）

> 提问方式（男性）："请问您的生殖系统有什么不适吗？"

男性采集：
- 遗精/早泄/阳痿（有/无——频率+程度）
- 阴囊（潮湿/冷/坠胀）
- 前列腺问题

#### 维度7：既往史与生活方式

> 提问方式："您过去有什么病史？平时的生活作息和饮食习惯怎么样？"

采集内容：
- 既往病史（高血压/糖尿病/肝病/肾病/手术等）
- 药物史（长期用药/近期用药/保健品）
- 过敏史（药物/食物过敏）
- 家族史（遗传性疾病）
- 情志状态（焦虑/抑郁/急躁/忧虑/压力大——程度）
- 作息规律（作息时间/睡眠时长）
- 饮食习惯（喜热/喜冷/辛辣/油腻/生冷/饮酒/吸烟）
- 运动习惯（运动类型/频率/强度）
- 工作环境（室内/室外/体力/脑力/接触有害物）

基于四诊合参的结果，输出患者的五形 S 向量诊断：

#### 3.1 S 向量状态输出格式

```
═══ 五形 S 向量诊断 ═══

S_木 = [↑/↓/↔/↑↑/↓↓]（环基数 μ 评估）
       [状态描述：肝郁/正常/亢进/僵硬/松弛]
       [关键依据：症状X/脉象Y/舌象Z]

       [关键依据：症状X/脉象Y/舌象Z]

S_土 = [↑/↓/↔/↑↑/↓↓]（土形储备 F 评估）
       [状态描述：充足/不足/枯竭/正常]
       [关键依据：症状X/脉象Y/舌象Z]

       [关键依据：症状X/脉象Y/舌象Z]

S_水 = [↑/↓/↔/↑↑/↓↓]（水形链流通评估）
       [状态描述：通畅/淤滞/停滞/异常]
       [关键依据：症状X/脉象Y/舌象Z]

═══ 整体判断 ═══

S ∈ H ? [是/否]（是否在健康多面体内）
主导偏移：[哪个分量的偏移最大]
虚/实属性：[虚证/实证/虚实夹杂——基于土形储备和偏移方向]
病性：[寒/热/虚/实/痰/湿/瘀/郁——一个或多个]
病位：[哪个脏腑/哪条经络——基于《黄帝内经》SPUM 定位]
```

#### 3.2 生克关系诊断

输出五形之间的异常生克/乘侮关系：

```
═══ 生克关系诊断 ═══

异常相生：
  木生火：[正常/过亢/不足] — 肝火犯心/肝不藏血济心
  火生土：[正常/过亢/不足] — 心火灼脾/心阳不温脾
  土生金：[正常/过亢/不足] — 脾不运精于肺
  金生水：[正常/过亢/不足] — 肺不肃降滋肾
  水生木：[正常/过亢/不足] — 肾不养肝

异常相克：
  木克土：[正常/过亢/反侮] — 肝郁乘脾/土壅侮木
  土克水：[正常/过亢/反侮] — 脾湿困肾/水湿反侮脾
  水克火：[正常/过亢/反侮] — 肾寒凌心/心热移肾
  火克金：[正常/过亢/反侮] — 心火灼肺/金寒冷心
  金克木：[正常/过亢/反侮] — 肺气太过克肝/肝火侮肺
```

#### 3.3 虚实寒热定性

基于土形储备（F）和各分量的偏移方向：

```
虚证判定条件：
  ─ F（土形储备）下降 = 虚
  ─ S_火 ↓（火不足） = 阳虚/气虚
  ─ S_土 ↓（土不足） = 血虚/脾虚
  ├ S_水 ↓（水不足） = 阴虚/肾虚
  └ S_木 ↓（木不足） = 肝血虚

实证判定条件：
  ─ F（土形储备）正常或偏高 = 实证
  ─ S_木 ↑（木亢） = 肝郁/肝火
  ├ S_火 ↑（火亢） = 实热/心火
  ├ S_水 ↑异常（水链异常） = 痰/湿/饮/水气
  └ S_金 ↑（金修剪异常） = 瘀血/癥瘕

寒热判定条件：
  ─ 热证 = S_火 ↑ 或 S_木 ↑（木生火过多）
  ─ 寒证 = S_火 ↓ 或 S_水 ↓（水克火过亢）
```

### 第四步：病机链分析

将 S 向量诊断转化为因果链条：

```
═══ 病机链分析 ═══

[一级病机（最根本的原因）]
  （例如：土形储备长期消耗过度——S_土 ↓↓）
  ↓
[二级病机（由一级导致的次生变化）]
  （例如：土不生火 → S_火 ↓ — 火形驱动不足）
  ↓
[三级病机（由二级导致的进一步结果）]
  （例如：火不足 → 水形流速减慢 → S_水 ↓ — 血行不畅）
  ↓
[临床表现（最终的症状群）]
  （例如：精神不振/月经推后/畏寒/乏力）
```

格式要求：
- 使用箭头 `→` 连接因果关系
- 每步标注涉及的 S 向量分量变化
- 引用《黄帝内经》或《金匮要略》等经典原文支持
- 标注异常生克链条（如"木克土过亢"）

### 第五步：治疗目标确定

## 三、特殊场景处理

### 3.1 急性/危重症处理原则

```
⚠️ 危急值预警 ⚠️

以下情况必须标注"立即就医、不可自行处理"：
  1. 疑似心梗（胸痛+冷汗+气短）
  2. 疑似中风（偏瘫+口角歪斜+言语不清）
  3. 高热不退（体温>39.5℃持续>48h）
  4. 严重外伤/出血
  5. 剧烈腹痛/持续性呕吐/黑便/呕血
  6. 呼吸困难/窒息
  7. 意识障碍/昏厥
  8. 怀疑药物中毒/过敏反应（皮疹+喉头水肿+呼吸困难）

处理原则：先建议就医，再提供辅助中医调理方案（仅作为西医治疗的补充）。
```

### 3.2 药物相互作用警告

```
⚠️ 中西药相互作用 ⚠️

当患者同时在服用西药时，标注潜在相互作用：
  1. 活血化瘀类中药（桃仁/红花/水蛭等）+ 抗凝药（华法林/阿司匹林）
     → 出血风险↑
  2. 含甘草方剂 + 利尿剂/激素
     → 水钠潴留/低钾风险
  3. 含麻黄方剂 + 降压药/心脏病药物
     → 血压升高/心率加快风险
  4. 含附子/乌头方剂 + 洋地黄类心脏药
     → 心律失常风险
```

### 3.3 妊娠哺乳期用药限制

```
⚠️ 妊娠禁忌 ⚠️
  1. 禁用：大毒、大热、破血逐瘀、峻下逐水类
  2. 慎用：活血化瘀、攻下、辛温走窜类
  3. 所有妊娠期用药推荐必须有明确指征并在医师指导下使用
```

### 3.4 误服/过服应急处理

参考 `金匮要略` 及 `金匮药物过服反应` 的 SPUM 框架：

```
误服/过服反应的 SPUM 逻辑：
  - 大黄/芒硝过服 = 金形暴冲 + 水形强排 → 脱水/土形枯竭/火形脱逸
    处理：停服 + 温补土形（米汤/粥）+ 火形温和恢复（生姜/桂枝）
    
  - 附子/乌头过服 = 火形暴冲 → 木形锁死（痉挛）+ 火形异常亢进+衰竭

  - 虫类药过服 = 金形过度修剪脆弱结构 → 血管壁损伤/出血倾向
    处理：停服 + 补土固本 + 必要时就医

  - 所有情况的第一步：停服 + 判断是否需要紧急就医
```

## 四、诊断示例模板

### 示例：慢性月经不调+白带过多+精神不振

```
═══ 青囊 · 五形诊断报告 ═══

患者：[36岁女性]
主诉：长期月经不调+白带过多+精神不振

═══ 一、四诊合参摘要 ═══

望诊：面色萎黄、舌淡胖有齿痕、苔薄白
闻诊：语声低微
问诊：
  - 精神不振、怕冷、手脚不温
  - 胃纳一般、食后腹胀、大便偏溏
  - 月经推后（35-45天一行）、量少、色淡、无块
  - 白带量多、色白、清稀、无异味
  - 既往：长期工作压力、饮食不规律
切诊（脉）：沉细弱

═══ 二、五形 S 向量诊断 ═══

S_木 = ↔（基线——无急性肝郁证据，但长期微郁可能）
S_火 = ↓↓（火形梯度显著低下——精神不振/怕冷/脉沉的直接证据）
S_土 = ↓↓↓（土形储备三重枯竭——阳明脉衰+长期月经消耗+带脉不固外泄）
S_金 = ≈0（金形修剪活性极低——无多余结构可修）
S_水 = ↓（水形链流速减慢——土枯无原料可运/火不足无驱动）

═══ 三、病机链 ═══

[一级] S_土 ↓↓↓ → 脾不运化 → 腹胀/纳差/便溏
    ↓
[二级] S_火 ↓↓（土不生火）→ 火形驱动力不足 → 精神不振/畏寒/脉沉细
    ↓
[三级] S_水 ↓（火不足→水不流）→ 血行不畅 → 月经推后/量少
                ↓
        带脉水形约束环失养不固 → 白带外泄
                ↓
        土形进一步流失（恶性循环）

═══ 四、治疗目标 ΔS_target ═══

核心目标：打破"土枯→火低→水慢→带漏→土更枯"的恶性循环
第一步：固土止漏（止带+补脾+养血）
第二步：温和恢复火形（补气温阳）
第三步：疏通维持水形（调经）
ΔS_target = (木↔, 火↑温和, 土↑↑, 金≈0, 水↑)

═══ 五、治疗方案 ═══

【方剂】完带汤加减（《傅青主女科》）
  白术15g  山药15g  党参12g  白芍10g
  苍术6g   甘草6g   陈皮6g   黑芥穗3g
  柴胡3g   车前子10g  当归10g  桂枝6g
  ΔS = (木↔, 火↑温和, 土↑↑固守, 水↗分流, 金≈0)
  用法：水煎服，每日1剂，分2次
  疗程：先服7剂，观察白带变化

【生活调理】
  饮食：忌生冷/油腻——减土形无谓消耗
        宜小米粥/红枣/山药——温和补土
  作息：建议11点前入睡——利于火形恢复
  情志：减少压力源——避免木克土加重

═══ 六、预后与禁忌 ═══

预期：7剂后白带应减少，精神略好转
完整疗程：1-3个月
禁忌：避免过度劳累/熬夜/生冷饮食
     ⚠️ 绝对禁用大黄蛰虫丸、桃仁承气汤等攻伐方
```
