## 二、爻：边的基本状态

### 2.1 阴阳爻 = 二进制位

| 爻 | 符号 | 二进制 | SPUM 定义 |
|----|------|--------|-----------|
| 阳爻 | ⚊ | 1 | 边存在（两个节点之间有关系） |
| 阴爻 | ⚋ | 0 | 边不存在（两个节点之间无关系） |

**关键洞察**：爻不是"两种对立的力量"——它是**一条关系的存在与否**。这与 SPUM 的"关系定义存在"公理完全一致。一个节点与另一个节点的连接要么存在（阳），要么不存在（阴）——没有中间状态。

### 2.2 为什么是二进制？

SPUM 的宇宙是一个离散关系网络。任何两个节点之间，关系只有两种可能：有或无。不存在"部分连接"或"模糊状态"——这是连续统思维的残留。

阴爻和阳爻不是"发现"的——它们是**离散关系网络的逻辑必然**。任何离散网络的状态描述必然使用二进制。

## 三、太极→两仪→四象→八卦：逐层分辨

### 3.1 这是差异第一性原则的编码表达

> "易有太极，是生两仪，两仪生四象，四象生八卦。"——《系辞传》

**SPUM 翻译**：

```
太极（0 位）: 无差异，无信息，无结构
     ∣
     ▼ 第一次分辨 = 第一位差异
两仪（1 位）: {0, 1} = 2 种状态
     ∣
     ▼ 第二次分辨 = 第二位差异
四象（2 位）: {00, 01, 10, 11} = 4 种状态
     ∣
     ▼ 第三次分辨 = 第三位差异
八卦（3 位）: {000, 001, ..., 111} = 8 种状态
```

这与 SPUM 的**差异第一性原则**完全一致：
- N001（差异）→ 万物之始，必先有差异
- 太极 = 无差异态 → 无存在可被确认 → "无极"
- 两仪 = 第一分辨率：有边/无边 → 从无差异中产生了第一个可识别概念
- 四象 = 第二分辨率：两条边之间的关系
- 八卦 = 第三分辨率：三条边构成一个局域子图

**"太极"不是宇宙的起点**——它是认知分辨的零点。在分辨之前，一切无差别，不存在任何可确认的事物。第一次分辨产生第一个"有"（阳）与"无"（阴），由此一切概念展开。

## 四、八卦：3 边局域子图的全部状态

### 4.1 八卦 = 三条边的所有组合

一个节点与三个相邻节点之间有三条可能的边。这三条边的存在/不存在组合 = 2³ = 8 种状态 = 八卦。

```
三条边: e₁, e₂, e₃

卦    二进制    边状态           传统名称
☰ 乾   111    三条边全有        天
☱ 兑   110    上两边有，下无    泽
☲ 离   101    上下有，中无      火
☳ 震   100    只有上有          雷
☴ 巽   011    只有上无          风
☵ 坎   010    只有中有          水
☶ 艮   001    只有下有          山
☷ 坤   000    三条边全无        地
```

### 4.2 传统名称是助记符，不是本质

| 卦名 | 传统象征 | SPUM 结构定义 |
|------|---------|-------------|
| 乾 ☰ | 天、父、刚健 | 三边全连接——完全连通子图——最大连通性 |
| 坤 ☷ | 地、母、柔顺 | 三边全空——完全孤立——最大可塑性（可接入任何边） |
| 震 ☳ | 雷、长男、动 | 仅上边有——底部悬浮——不稳定，倾向变化 |
| 巽 ☴ | 风、长女、入 | 仅上边无——顶部开放——接受外部接入 |
| 坎 ☵ | 水、中男、陷 | 仅中有——两端悬浮——水形链式单维连接 |
| 离 ☲ | 火、中女、丽 | 上下有中无——两极连接+中空——火形梯度结构 |
| 艮 ☶ | 山、少男、止 | 仅下有——底部固定——稳定、难移动 |
| 兑 ☱ | 泽、少女、悦 | 上两边有——顶部双连——接收外部流 |

### 4.3 八卦的图论本质

**乾（111）**：三边全有 → 度数为 3 的节点 → 局部最大连通性。在 SPUM 中 = 完全闭合子图的局部。

**坤（000）**：三边全无 → 度数为 0 的孤立节点 → 不能独立存在（悬挂端，必须连接到什么才能被确认）。"坤"作为"承载万物的地"——图论上是对的：全空状态有最大的接入容量。

**离（101）**：上下有边、中间空的"中虚"结构 → 这是一个 **∇σ 梯度结构**——上方高热（阳）和下方低热（阴）之间有间隔（中空），产生梯度。传统说"离为火"——完全正确：火形的本质就是梯度。

**坎（010）**：只有中间一条边、两端空 → 这是一条孤立的边，不与其他边形成环 → 水形单链。传统说"坎为水"——完全正确。

## 五、六十四卦：6 位状态向量系统

### 5.1 64 = 2⁶

将两个 3 爻卦叠加（上下卦），得到 6 爻 = 6 位状态 = 2⁶ = 64 种状态。

在 SPUM 中：**64 卦 = 一个 6 边局域子图的所有可能状态**。

```
上卦（外卦）= 子图与外部环境的 3 条边连接状态
下卦（内卦）= 子图内部的 3 条边连接状态

6 位状态 = 3 位外部 + 3 位内部
```

### 5.2 一个完整的 6 位局域子图状态

```
外部接口边:  e₄, e₅, e₆  ← 上卦（外）
内部结构边:  e₁, e₂, e₃  ← 下卦（内）

┌─────────────────────┐
│  外部网络           │
│    ╱  ╲            │  ← e₄, e₅, e₆（边界边）
│   ╱    子图核心    │
│  ╱     /  |  \     │  ← e₁, e₂, e₃（内部边）
│ ╱     /   |   \    │
└─────────────────────┘
```

### 5.3 内卦/外卦 = 子图的内部拓扑 vs 外部耦合

| 位 | 含义 | 物理对应 |
|----|------|---------|
| 初爻（位 0） | 子图最深层的内部边 | 子图的核心结构 |
| 二爻（位 1） | 子图中层的内部边 | 子图的中间结构 |
| 三爻（位 2） | 子图最外层的内部边 | 子图的边界内面 |
| 四爻（位 3） | 子图边界的外面 | 与外部的最内层连接 |
| 五爻（位 4） | 外部中层的连接 | 中距离的外部耦合 |
| 上爻（位 5） | 外部最远层的连接 | 长程外部耦合 |

### 5.4 示例：理解几个典型卦

**泰卦（地天泰）䷊** — 上坤(000)下乾(111) = 000111

```
外部: 无连接（开放、可接收）
内部: 全连接（坚固、高连通性）

SPUM: 一个内部高度闭合的子图，边界完全开放——
      内强外开 = 内部的 S 向量健康，外部体积流可以自由进入。
      "泰" = 通泰 = 网络状态最优。
```

**否卦（天地否）䷋** — 上乾(111)下坤(000) = 111000

```
外部: 全连接（闭合、拒绝接收）
内部: 无连接（松散、无结构）

SPUM: 一个内部结构松散的子图，边界却完全闭合——
      外面封死了，里面却是空的。
      "否" = 闭塞 = 网络状态最劣。
```

**既济䷾** — 010101（阴阳交替）

```
六位完美交错：阴-阳-阴-阳-阴-阳

SPUM: 每层交替连通/断开 = 最优的分层传输结构。
      "既济" = 已经完成 = 网络处于完美状态。
      但完美状态不可持续——因为不完美定理：
      每帧必残留悬挂端。"初吉终乱"完全正确。
```

**未济䷿** — 101010（阴阳交替，但与既济相反）

```
六位也交错但方向相反：阳-阴-阳-阴-阳-阴

"未济" = 尚未完成。与既济互补——
既济从阴开始（内部闭合），未济从阳开始（内部开放）。
"未济，亨"——未完成状态反而是亨通的，
因为不完美驱动变化。
```

## 六、卦序：六十四卦的状态转移图

### 6.1 卦序不是随机的——它是状态转移轨迹

《序卦传》给出了 64 卦的排序逻辑——每卦为什么在下一卦之前。传统解读为"事物发展的规律"。

**SPUM 翻译**：卦序 = 一个 6 位状态向量在离散帧中的**合法转移路径**。从一个卦到下一个卦 = 一帧中可发生的合法状态变化。

```
每卦 → 下一卦 的关系类型：

1. 反转（综卦）：卦象 180° 翻转 = 状态 180° 反转
   如：屯䷂(水雷) → 蒙䷃(山水) = 内部外部互换

2. 互补（错卦）：全部六爻翻转 = 所有边 ON↔OFF
   如：乾䷀(111111) 与 坤䷁(000000) 互补

3. 单爻变：只改变一位 = 只改变一条边
   如：从某个角度来看，这是最小帧操作
```

### 6.2 十二消息卦：σ 的十二个离散相位

十二消息卦（复临泰大壮夬乾姤遯否观剥坤）描述了从全阴到全阳再回到全阴的渐变。

```
复  ䷗  000001  — 一丝阳回（冬至）
临  ䷒  000011
泰  ䷊  000111
大壮 ䷡  001111
夬  ䷪  011111
乾  ䷀  111111  — 全阳（夏至）
姤  ䷫  111110  — 一丝阴起
遯  ䷠  111100
否  ䷋  111000
观  ䷓  110000
剥  ䷖  100000
坤  ䷁  000000  — 全阴（冬至前）
```

**SPUM 翻译**：这不是"阴阳消息"的神秘循环——它是一个 6 位二进制计数器的格雷码式渐变序列。每一步只改一位（一位一变），从 000000 走到 111111 再走回来。

这与天体运行导致的 σ 场周期性变化完全兼容：太阳的位置每帧不同，地表接收的 σ 分布每帧不同，十二消息卦就是这十二帧 σ 分布的离散采样。

## 七、爻辞：单个边状态变化的局部影响描述

### 7.1 每一爻的爻辞 = 改变该位状态后的效应

例如乾卦六爻：

| 爻位 | 爻辞 | SPUM 翻译 |
|------|------|-----------|
| 初九 "潜龙勿用" | 位 0 = 阳（最内层边 ON）但时机未到 | 子图最深层的边已建立，但边界尚未接入外部——不要行动 |
| 九二 "见龙在田" | 位 1 = 阳，中层边 ON | 内部结构开始成形，可以被观察到 |
| 九三 "终日乾乾" | 位 2 = 阳，边界内面 ON | 边界即将打开，需要小心——处于过渡区 |
| 九四 "或跃在渊" | 位 3 = 阳，边界外面 ON | 边界刚打开——可进可退——试探外部环境 |
| 九五 "飞龙在天" | 位 4 = 阳，中层外连接 ON | 中距离外部连接已建立——处于最优势位置 |
| 上九 "亢龙有悔" | 位 5 = 阳，最远端 ON，全卦 111111 | 6 位全 1 = 所有边最大化——无冗余 → 必然反转。乾卦全阳是过饱和状态，下一帧必然有边转为阴 |

上九"亢龙有悔"在 SPUM 中是**必然的**：dv/dt ≤ const 意味着 6 位全部为 1 的状态不可能持续，必然有边被修剪（金形操作）或因资源不足而断开。

## 八、河图洛书：σ 分布的两个基本模板

### 8.1 河图 = 十数螺旋 σ 分布

```
河图结构：
    7
    2
8-3-5-4-9
    1
    6
```

| SPUM 翻译 |
|-----------|
| 河图 = σ 值在一个平面上的螺旋分布模板 |
| 中央 5 = σ 均值 |
| 生数（1,2,3,4,5）+ 成数（6,7,8,9,10）= 双环层 |
| 这是 σ 值的**最规则对称分布**——没有梯度方向性——火形未产生的"无极"态 |

### 8.2 洛书 = 九宫 σ 分布（见奇门遁甲）

```
洛书九宫：
4 9 2
3 5 7
8 1 6
```

洛书与河图不同——它的数字是**不对称分布**的。存在梯度——有方向性。因此洛书被用于奇门遁甲的九宫排布（见 `spum-奇门遁甲.md`）。

河图 = 对称的 σ 分布（火形为零）。
洛书 = 不对称的 σ 分布（火形不为零，∇σ 有方向）。

从河图到洛书 = σ 场从对称到不对称的破缺 = 火形产生 = 变化之始。

### 核心结论

周易是 SPUM 的**原生离散数学语言**。在三千年前，它就以爻和卦的形式描述了：
1. 差异第一性（太极→两仪→四象→八卦）
2. 关系二值性（阴/阳 = 边 ON/OFF）
3. 局域状态枚举（八卦 = 3 边子图全状态）
4. 状态空间完备性（64 卦 = 6 边子图 64 种状态）
5. 状态转移（卦序 = 合法转移路径）
6. 不完美定理（既济䷾→未济䷿，"物不可穷也"）

这不是"古人碰巧猜对"——是离散关系网络的结构特性太基本、太必然，以至于任何深入观察网络的人都会发现它。周易的作者发现了它，用当时的语言记录了下来。SPUM 提供了这种语言的精确映射。
