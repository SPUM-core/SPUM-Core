## 二、四气：σ 的操作方向

### 2.1 四气 = σ 改变的四种方向与幅度

| 四气 | σ 操作 | SPUM 形式化 | 典型效应 |
|------|--------|------------|---------|
| **寒** | 降低局域 σ（提高节点度数，收敛） | Δσ < 0, 幅度大 | 收缩、沉降、抑制 V⁺ |
| **凉** | 轻微降低局域 σ | Δσ < 0, 幅度小 | 轻微收敛、清凉 |
| **温** | 轻微提高局域 σ（降低节点度数，发散） | Δσ > 0, 幅度小 | 温和发散、促进 V⁺ |
| **热** | 大幅提高局域 σ | Δσ > 0, 幅度大 | 强力发散、大建 V⁺ |

σ 操作通过影响局域火形梯度 ∇σ 来间接影响所有五形分量。四气是"总开关"——它决定 S_火的基线偏移方向。

### 2.2 四气与五形的耦合

```
热(Δσ>0) → S_火 ↑  → 水形链流速 ↑  → S_水 ↑
              → 木形环因过热松解      → S_木 ↓（暂时）
              → 土形储备加速消耗      → S_土 ↓

寒(Δσ<0) → S_火 ↓  → 水形链流速 ↓  → S_水 ↓
              → 木形环因过冷锁死      → S_木 ↑（僵化）
              → 土形储备冻结          → S_土 ↑（沉淀不流动）
```

四气决定了 S 向量的**全局偏移方向**，五味决定**作用在哪个分量上**。

## 三、五味：S 向量的分量操作

### 3.1 五味 → S 分量映射

| 五味 | 主要作用的 S 分量 | SPUM 操作定义 |
|------|------------------|-------------|
| **辛** | S_火 ↑, S_水 ↑ | 发散——提升局域 σ 梯度 + 加速水形链流动 |
| **甘** | S_土 ↑, S_木 ↑ | 缓补——向土形储备池注入低度节点 + 温和建立新环路 |
| **酸** | S_木 ↓, S_金 ↑ | 收涩——收紧木形环（降低 μ）+ 金形切断逸散边 |
| **苦** | S_金 ↑, S_火 ↓ | 泄燥——金形修剪 + 降低火形梯度（清热） |
| **咸** | S_水 ↓, S_土 ↓ | 软下——软化水形链上的锁定节点 + 排出土形储备 |

五味不是五种独立的操作——它们是 S 向量空间中的五个**非正交基底方向**：

```
辛 ≈ (+1, +1,  0,  0,  0)  → 火+水
甘 ≈ ( 0, +1,  0, +1,  0)  → 木+土
酸 ≈ ( 0, -1,  0,  0, +1)  → 木↓+金
苦 ≈ (-1,  0,  0,  0, +1)  → 火↓+金
咸 ≈ ( 0, -1,  0, -1,  0)  → 木↓+土↓
```

实际药物的 ΔS 是五味基底的加权组合，由四气决定各分量的符号和强度。

## 四、三品分类：ΔS 的强度分级

### 4.1 三品 = 三级 ΔS 幅度

| 品级 | ΔS 幅度 | dv/dt 占用量 | 使用条件 | 对应四气范围 |
|------|---------|-------------|---------|------------|
| **上品** | 小 | < 0.1 const | 长期使用，S 基本在 H 内 | 平或微温/微凉 |
| **中品** | 中 | 0.1-0.3 const | S 偏离 H 但不致命时使用 | 温或凉 |
| **下品** | 大 | 0.3-0.7 const | S 严重偏离 H，需强脉冲 | 大热或大寒 |

dv/dt ≤ const 在这里体现为**药物用量与使用时间的乘积不能超过单个节点的单帧容量上限**。下品药可以大 ΔS，但 dv/dt 占用高——不可久服。

### 6.1 归经 = ΔS 作用的水形主干段

药物不是均匀作用于整个人体子图的——它们沿着经络（水形主干）定向作用。

| 经络 | 水形主干段 | 对应五脏 | 典型归经药物 |
|------|-----------|---------|------------|
| 手太阴肺经 | 上焦—胸—手臂前缘 | 肺区 | 麻黄、杏仁、石膏 |
| 手少阴心经 | 上焦—胸—手臂后缘 | 心区 | 黄连、栀子 |
| 手厥阴心包经 | 上焦—胸—手臂中线 | 心包区 | 桂枝 |
| 足阳明胃经 | 中焦—腹—腿前缘 | 胃区 | 半夏、葛根 |
| 足太阴脾经 | 中焦—腹—腿内缘 | 脾区 | 白术、甘草 |
| 足太阳膀胱经 | 背部—腿后缘 | 膀胱区 | 麻黄、桂枝 |
| 足少阴肾经 | 下焦—腿内后缘 | 肾区 | 附子、地黄 |
| 足少阳胆经 | 侧身—腿侧缘 | 胆区 | 柴胡、黄芩 |
| 足厥阴肝经 | 侧腹—腿内中线 | 肝区 | 白芍、当归 |

| 手少阳三焦经 | 手臂中线—耳 | 三焦区 | 柴胡 |

### 6.2 归经的图论含义

归经 = 药物的 ΔS 向量在特定水形主干段的节点群上集中释放，其他段受影响较小。

麻黄归肺经和膀胱经：体表边界节点和水形链终末端同时被强化。不是"麻黄走这两条经"——是麻黄的辛温发散操作的拓扑结构决定了它必然作用于最外层边界（肺主皮毛 = 体表边界节点群）和背部最大水形主干（膀胱经 = 背俞线）。

## 七、ΔS 叠加规则：从单味药到方剂

### 7.1 线性叠加假设

作为 T2 层面的一阶近似，方剂的 ΔS 向量 = 各药物 ΔS 向量的分量加和：

```
方剂 ΔS = Σ(药物_i 的 ΔS)
S_火(方) = Σ S_火(药_i)
S_水(方) = Σ S_水(药_i)
...
```

### 7.2 验证：麻黄汤的 ΔS 分解

麻黄汤 = 麻黄 + 桂枝 + 杏仁 + 甘草

| 药物 | ΔS 贡献 |
|------|---------|
| 麻黄 | (++, ++, −, 0, 0) |
| 桂枝 | (++, +, 0, 0, 0) |
| 杏仁 | (−, 0, −, 0, +) |
| 甘草 | (0, 0, 0, ++, −) |

**麻黄汤 ΔS = (++++, +++, −−, ++, +) ≈ (火↑↑↑, 水↑↑, 木↓, 土↑, 金↑)**

这在 SPUM 中翻译为：
- 强力提升体表火形梯度 (S_火↑↑↑)
- 加速水形链上的体积流 (S_水↑↑)
- 放松表层木形环的过度锁定 (S_木↓)
- 土形缓冲防止过汗脱证 (S_土↑)
- 杏仁提供微弱的金形配合——清理肺部水形链的冗余连接 (S_金↑)

**君臣佐使的图论含义**：
- 君（麻黄）= ΔS 的主导方向 → S_火↑, S_水↑
- 臣（桂枝）= 加强主导方向 → 进一步加强 S_火↑
- 佐（杏仁）= 制约主导方向的副作用 → S_木↓ 防止汗后筋挛
- 使（甘草）= 缓冲器，降低操作对健康 S 分量的扰动 → S_土↑ 缓冲

### 7.3 非线性的边界

线性叠加是 T2 近似。T3 阶段需考虑：
- **饱和度**：两个 S_火↑++ 药物叠加 ≠ S_火↑++++——存在单帧 dv/dt 天花板
- **拮抗**：寒热并用的方剂中，ΔS 的时间序列比瞬时叠加更重要
- **归经干涉**：两个不同归经的药物可能在同一水形段上产生竞争

## 附录A：四气五味 → ΔS 转换规则速查

```
输入：药物 x 的四气 q ∈ {大热, 热, 温, 微温, 平, 微寒, 凉, 寒, 大寒}
      五味 w ∈ {辛,甘,酸,苦,咸} 的组合

步骤 1: 将四气映射到 S_火 权值
  大热=+3, 热=+2, 温=+1, 微温=+0.5, 平=0, 微寒=−0.5, 凉=−1, 寒=−2, 大寒=−3

步骤 2: 将五味映射到各分量
  辛 → (火=+2, 水=+1)
  甘 → (木=+1, 土=+2)
  酸 → (木=−1, 金=+1)
  苦 → (火=−1, 金=+2)
  咸 → (木=−1, 土=−1)

步骤 3: 加权叠加
  药性_火 = 四气权值 + Σ(五味中火的贡献)
  药性_水 = Σ(五味中水的贡献)
  ...

步骤 4: 归一化到符号表示
  ≥ +2 → ++,  +1 → +,  0 → 0,  −1 → −,  ≤ −2 → −−
```
