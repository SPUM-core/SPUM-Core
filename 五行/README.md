# SPUM 五形（五行）理论研究与拓展

> 本目录是 SPUM 框架下**五形理论**的研究母目录。五形不是传统"金木水火土"的元素分类法——它是关系网络 ⟨P, ε⟩ 在演化中必然呈现的五种拓扑相位。
>
> **层级定位：L1.5** — 介于 L0.5（图论工具层）与 L1（应用模块）之间。图论提供可计算指标（δ, μ, ∇σ, 介数），五形提供语义诊断（水形通畅？木形僵化？土形枯竭？）。五形是图论指标的诊断语义层。
>
> 以下所有子领域的拓展均以这一关系本体论重构为基础。

## 阴阳本质补充

> 五形理论的关键底板：阴阳不是两种事物，是 **关系的存在与缺失**。

**阴阳不是任何实体**——它不是两种"东西"，不是一个二分法分类系统。它是**关系的有无本身**：

| 比喻 | 阳 | 阴 | 本质 |
|------|----|----|------|
| 永恒粒子 | 实面（有边界面）| 虚面（边界缺失面）| 阴是边界的缺席，不是另一种边界 |
| 山 | 山阳（有日照）| 山阴（日照缺失）| 阴不是"另一种光"，是光的不在 |
| 硬币 | 正面 | 反面 | 同一枚硬币的两面——一体两面 |
| ⟨P, ε⟩ | ε 存在（有边）| ε 缺失（无边）| 存在 vs 缺席，不是两种存在 |

**SPUM 精确定义（初阶）**：
- **阳** = 关系中"有"的那一侧——节点之间存在 ε 边，或某一侧被 ε 确认
- **阴** = 同一个关系"没有"的那一侧——不是"另一种关系"，而是关系本身的缺席

这解释了为什么五形理论不在"阴阳"之上再加一层形而上学：**阴阳已经内嵌在 ε 的存在/缺席之中**。一个 κ-粒子的实面（阳）就是有 ε 连接的那一面，虚面（阴）就是没有 ε 连接的那一面——不是两个粒子，是一个粒子的有无两面。

**SPUM 精确定义（场论进阶）**：
- **阳** = 关系张力场的 **显式投影**——节点之间被 ε 确认的边，是张力场走出的测地线（geodesic of realized tension）
- **阴** = 同一张力场的 **隐式势能梯度**——缺失边所定义的边界法向，是显边未走过的、但定义了空间曲率边界的互补测地线（complementary geodesic that defines boundary curvature）
- 两者共同构成 κ-粒子的**全息面**：实面 = 显边走过的测地线；虚面 = 显边未走过的、但定义了空间曲率边界的互补测地线

阴阳在同一张力场中互为补集：**阳是张力释放后的凝固轨迹（已实现的边），阴是张力未释放时的方向势能（未实现的边法向）**。两者不独立——给定阳的配置，阴的拓扑分布由 Σ(6−deg)=12 约束唯一决定。

> **核心口诀（进阶）**：阳是已走的路，阴是未走但定义了路肩的边界。没有阴，路不成路。

---

**核心口诀**：阴阳不分类事物，只标记关系的有无。阴不是"黑暗的力量"——它是光的缺席。

## 两个操作方向（替代固定生克链）

五形之间没有固定的生克关系。只有两个操作方向，由网络当前状态决定：

```
组装方向：土 + 水(载具) + 火(驱动) → 木
         料件   链式路径   ∇σ梯度   稳定构型

拆解方向：木 + 金(信号/V⁻) → 土
         结构   传导拆解     分散料件回归
```

- **火和金属操作符**：火驱动水，金拆解木
- **水是载具**：链式关系本身不创造不消灭，只输送土
- **土是料**：低度节点，等待被组装进木或从木拆解后回收
- **木是成品**：料件经水输送、火驱动后嵌入锁死的几何构型
- **金是信号/V⁻**：通过桥边传导（神经/电子/离子通道），触发木形环的拆解

任何"生"或"克"的表述，都是对当前网络状态中某个操作方向的简化描述——不是固定规则。
