# SPUM 五形（五行）理论研究与拓展

> 本目录是 SPUM 框架下**五形理论**的研究母目录。五形不是传统"金木水火土"的元素分类法——它是关系网络 ⟨P, ε⟩ 在演化中必然呈现的五种拓扑相位。以下所有子领域的拓展均以这一关系本体论重构为基础。

---

## 核心定位

| | 传统五行 | SPUM 五形 |
|---|---------|----------|
| 本体 | 五种基本元素/物质 | 五种拓扑关系相位 |
| 分类方式 | 实体归属（肝属木…） | 同一实体的五种关系状态共存 |
| 尺度 | 单一层级 | 嵌套自相似，每层五行俱全 |
| 火 | 热 = 心 | 势差 = ∇σ ≠ 0 |
| 生克 | 固定线性循环 | 瞬时雅可比矩阵，每帧可翻转 |
| 驱动力 | 外部/神秘 | 从 ⟨P, ε⟩ 公理自发生成 |

详见：[核心公理第六节](../.trae/rules/spum-core.md#六五形五行离散关系网络的基本结构模式) | [词汇规范中的五形定义](../.trae/rules/spum-vocabulary.md#演化引擎五形五行五种基本拓扑结构模式)

## 五形速查

| 形 | 拓扑相位 | 核心图论指标 | 公理来源 |
|----|---------|-------------|---------|
| **水** | 链式传输 | L, E_glob, 边介数分布 | V⁺ 创生阶段 |
| **木** | 环路骨架 | μ, C_Δ, λ₂ | 拓扑守恒 Σ(6−deg)=12 |
| **土** | 分散储备 | 低度节点占比, F | 悬挂边删除 + 不完美定理 |
| **金** | 修剪切断 | 桥边数, 割集 | 判断→删除第五步 |
| **火** | 密度梯度 | ⟨∇k⟩, Φ | σ = |P|/|ε| 梯度 |

## 耦合闭环

```
火形梯度 → 水形链输送 → 木形环路生长 → μ超临界 → 金形修剪 → 土形储备 → 新∇σ → 火
```
