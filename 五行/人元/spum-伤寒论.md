## 一、伤寒论的 SPUM 定位：急性相变的六帧轨迹

### 1.1 什么是"伤寒"

> "太阳之为病，脉浮，头项强痛而恶寒。" —《伤寒论》第 1 条

伤寒不是"感冒"。在 SPUM 中：

**伤寒 = 人作为移动的晶子集合移入外部 σ 骤降区域（寒邪）→ 内外 σ 梯度差（温差力矩）驱动边界节点的 σ 重新平衡 → 体表边界节点群的局域 σ 骤降 → 引发六阶段 S 向量级联偏移。**

| 概念 | 传统解释 | SPUM 翻译 |
|------|---------|-----------|
| 寒邪 | 寒冷的外邪 | 外部 V⁺_external 突然减少（冷 = σ 降低），表层边界节点的连接被强制收缩 |
| 恶寒 | 怕冷 | 边界节点检测到自身 σ 骤降 + 火形梯度不足以维持体温 → 向无我子图发出"需要提升 σ"的信号 |
| 脉浮 | 脉象浮在表层 | 体表水形链的边介数升高——血液被驱赶到表层以应对 σ 塌陷 |
| 头项强痛 | 头颈僵硬疼痛 | 头颈区域的木形环群因寒性收引而 μ 骤升——环僵化锁死 |
| 传变 | 病邪从一经传到另一经 | S 向量沿拓扑决定的顺序性轨迹逐阶段偏移 |

### 1.2 六经不是六条线，是边界深度递增的六种网络状态

| 六经 | 传统定位 | SPUM 翻译 | 边界深度 | 核心受影响的子图 |
|------|---------|-----------|---------|----------------|
| **太阳** | 表——体表 | 人体子图的**最外层边界节点群**及其水形主干 | 深度 0（边界） | 皮肤、汗腺、体表血管链 |
| **阳明** | 里——胃肠 | 子图内部**中部区域**的土形储备池 + 水形链腹段 | 深度 1 | 胃肠水形链、体液储存池 |
| **少阳** | 半表半里 | 边界与内部的**过渡区域**——外我与自我子图之间的耦合振荡 | 深度 0.5（半） | 淋巴水形链、肝胆中转环 |
| **太阴** | 里——脾 | 子图的**土形核心储备池**——全局低度节点的总仓库 | 深度 2 | 脾区域的土形储备、消化水形链 |
| **少阴** | 里——心肾 | 子图的**火形梯度引擎与最深层 σ 核心** | 深度 3（最深层） | 心区 ∇σ 引擎 + 肾区极低 σ 储能核心 |
| **厥阴** | 半表半里——肝 | **边界崩溃临界区**——木形环群在全局 σ 最低时的末路振荡 | 深度 2.5（临界） | 肝区木形环 + 全身边界维持 |

### 1.3 六经传变的 SPUM 轨迹

```
[健康态 S ∈ H]
    │
    ▼ 人移入外部 σ 骤降区域——内外 σ 梯度差驱动边界网络重平衡
[太阳阶段] S_火↓↓表层, S_水↑表层(脉浮), S_木↑(头项强痛)
    │ 若表不解，σ 塌陷向内扩散
    ▼
[阳明阶段] S_火↑↑全局(高热), S_土↓↓(津液枯竭), S_水↑↑(大汗)
    │ 若过度泻下或寒邪直中
    ▼
[少阳阶段] S 振荡——∇σ 在表里之间来回摆动，边界模糊
    │ 若火形梯度持续下降
    ▼
[太阴阶段] S_土↓↓(腹泻、腹满), S_火↓(四肢不温)
    │ 若土形储备彻底耗尽
    ▼
[少阴阶段] S_火↓↓(全身冰冷), S_水↓↓(脉微细), S_土枯竭
    │ 火形在最底层仍有一丝残余
    ▼
[厥阴阶段] 边界崩溃临界——火形最后一搏（厥热胜复）+ 边界可能解体
```

**关键 SPUM 发现**：六经传变的轨迹不是随机的——它是**网络从外围到核心的 σ 塌陷波**沿着拓扑结构向内传播的必然路径。每一阶段的 S 偏移特征由被波及子图的拓扑类型决定。就像一块石子投入水面，波纹从落点向外扩散——人移入外部低 σ 区域后，σ 梯度差驱动边界节点的重平衡，σ 塌陷波从表层逐层向内推进。

## 二、太阳病：边界的 σ 塌陷与首道边界调节层

### 2.1 太阳病共性病机

所有太阳病的 SPUM 本质相同：**外部寒邪使体表边界节点群的局域 σ 骤降。** 正常的体表 σ 维持在一个适中水平——不是太高（热、容易散失能量），也不是太低（冷、毛孔闭塞）。寒邪 = 外部环境 σ 远低于体表 σ → ∇σ 由常态的表→外反转为外→表，体表节点被强制降温。

人体的第一反应：**将内部水形链中的高 σ 体积流（温热的血液、阳气）紧急调往边界以补偿 σ 的下降**。脉浮 = 这条紧急调度的体积流在水形主干上的边介数升高。

| 太阳病变种 | 表虚（中风） | 表实（伤寒） |
|-----------|------------|------------|
| 汗出状态 | 有汗（毛孔边界节点未被完全锁死） | 无汗（毛孔边界节点被寒性收引锁死） |
| 五形失衡 | S_火↓, S_水↑补偿, S_土↓轻微 | S_火↓↓, S_水↓堵塞, S_木↑体表环锁 |
| SPUM 核心问题 | 边界 σ 下降但未到锁死阈值，土形储备随汗流失 | 边界 σ 骤降到锁死阈值以下，水形链被物理性挤压 |

### 2.2 桂枝汤：表虚的温和火形+土形双补

> "太阳中风，阳浮而阴弱。阳浮者，热自发；阴弱者，汗自出。……桂枝汤主之。"

**ΔS 分解**：

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 桂枝 | 体表火形梯度温和提升（松弛因寒收缩的边界环边，但不追求强力发汗） | S_火 ↑ |
| 白芍 | 木形环修复——补偿汗出造成的土形储备流失（酸性物质收敛边界的闭合度） | S_木 ↑, S_土 ↑ |
| 生姜 | 局域火形辅助——帮助桂枝将热量均匀分布到全身体表链 | S_火 ↑ 辅 |
| 大枣 | 土形储备直接补充——补充汗液带走的水分低度节点群 | S_土 ↑ |
| 炙甘草 | 全局缓冲 + 使各药协同 | S_土 ↑ |

**服法关键**："啜热稀粥一升余，以助药力。温覆令一时许，遍身漐漐微似有汗者益佳，不可令如水流离。"

SPUM 翻译这段服法：**热稀粥 = 从水形链的入口端一次性注入大量高 σ 的土形节点（热糖水）→ 与桂枝的温和火形形成协同 → 推动边界链中已存在的低 σ 积存（寒邪节点团）缓缓从毛孔排出。** "微似有汗"的精确含义：保持边界节点的 V⁺ 速率恰好超过 V⁻ 速率一点点——既排寒邪，又不耗散土形储备。"水流离"（大汗） = S_火过冲，代价是 S_土的剧烈消耗。

**ΔS** = (火↑↑温和, 水=0, 木↑修复, 土↑↑, 金=0)

### 2.3 麻黄汤：表实的强力火形脉冲

（标准译例详见 [金匮附录 A](file:///f:/spum-core/五行/人元/spum-金匮要略.md#附录a-麻黄汤帧翻译示例)）

- **SPUM 特点**：比桂枝汤的火形强 3-4 倍，因为边界节点被完全锁死（无汗），需要更强的 ∇σ 推动汗孔开放
- **不啜粥**：因为麻黄本身的火形强度已足够，不需要外源性高 σ 补充

**ΔS** = (火↑↑↑, 水↑↑, 木↓, 土↑, 金=0)

### 2.4 太阳病补充方证

#### 2.4.1 葛根汤：太阳经输不利——水形链主干僵化

> "太阳病，项背强几几，无汗恶风，葛根汤主之。"

**SPUM 本质**：水形链主干（背部膀胱经沿线）被寒邪收引——链上的节点间距缩短（肌肉紧张、僵硬）。这不是单纯的边界 σ 塌陷，而是水形链沿线的木形环群因寒而度骤升，锁死了链的正常柔韧性。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 葛根 | 水形链主干舒张 + 木形环松弛——解肌（解除表层节点链的僵化） | S_水↑↑舒, S_木↓轻 |
| 麻黄 | 火形脉冲——开放被锁死的体表边界节点 | S_火 ↑↑ |
| 桂枝 | 火形辅助 + 水形协同 | S_火 ↑, S_水 ↑ |
| 白芍 | 木形环修复——防止麻黄桂枝过强损伤环结构 | S_木 ↑修复 |
| 生姜/大枣/甘草 | 土形缓冲 + 全局协同 | S_土 ↑ |

**与桂枝汤的关键差别**：桂枝汤的核心操作是 S_火↑温和 + S_土↑；葛根汤的核心操作是 S_水↑↑舒 + S_火↑↑——先松链，再开表。

**ΔS** = (火↑↑, 水↑↑舒, 木↓轻+↑修复, 土↑, 金=0)

#### 2.4.2 大青龙汤：表实重症——火形极强脉冲 + 监控

> "太阳中风，脉浮紧，发热恶寒，身疼痛，不汗出而烦躁者，大青龙汤主之。若脉微弱，汗出恶风者，不可服之。"

**SPUM 本质**：麻黄汤证基础上出现"烦躁"——这是火形过冲的前兆信号。体表边界完全被锁死，内部火形引擎在尝试冲开边界时已经接近失控边缘。大青龙汤是麻黄汤 + 石膏——火形更强 + 石膏监控防过冲。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 麻黄（六两） | 火形极强脉冲（是麻黄汤的两倍——体表锁死程度严重） | S_火 ↑↑↑ |
| 石膏 | 火形监控——设一个上界，当 S_火 冲开边界后超过安全阈值时，立即抑制 | S_火 ↘限幅 |
| 桂枝 | 火形辅助 | S_火 ↑辅 |
| 杏仁 | 水形链（肺分支）保护——防止火形过强灼伤链的脆弱段 | S_水 ↑护 |
| 生姜/大枣/甘草 | 土形缓冲 | S_土 ↑ |

**关键禁忌**："脉微弱，汗出恶风者不可服"——这不是一条安全提示，而是**帧规则的逻辑强制**。脉微弱（水形链主干体积流不足）+ 汗出（边界节点未被锁死）= 此时 ∇σ 不是太低而是已适度——再用极强火形脉冲会把本就不多的土形储备瞬间烧干，导致 S 从太阳直坠少阴。

**ΔS** = (火↑↑↑+↘限幅, 水↑↑, 木↓, 土↑, 金=0)

#### 2.4.3 小青龙汤：太阳病兼水形链内积水——表寒+内饮双解

> "伤寒表不解，心下有水气，干呕发热而咳……小青龙汤主之。"

**SPUM 本质**：太阳表寒未解（边界 σ 塌陷仍在），同时水形链的中段分支（心下区域）出现积水——这不是正常的体积流输送，而是低温导致水形链分支末端的 σ 异常降低（水气停聚），链上的低度节点无法正常下行排出，积聚成独立的小分量群。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 麻黄 | 火形脉冲——解除体表边界锁死 | S_火 ↑↑ |
| 桂枝 | 火形辅助 + 水形通阳 | S_火 ↑, S_水 ↑通 |
| 干姜 | 局域火形——作用于心下水形链低温区域的 ∇σ 提升 | S_火 ↑局（温化） |
| 细辛 | 微小通道渗透——上达头项、下及水形链末梢，将火形散布到寒水积存的最深处 | S_火 ↑散 |
| 五味子 | 木形环收敛——防止麻黄干姜过散损伤环的闭合度（"散中有收"） | S_木 ↑收 |
| 芍药 | 木形环修复 + 柔和火形 | S_木 ↑, S_火↓柔和 |
| 半夏 | 水形链降逆——抑制水气上冲的逆流（干呕） | S_水 ↓逆 |
| 甘草 | 全局缓冲 | S_土 ↑ |

**核心 SPUM 洞察**：小青龙汤的对称性是**散 vs 收**——麻黄 + 细辛极度向外散（火形 + 微小通道渗透），五味子 + 芍药向里收（木形环维护）。"散"是排出寒邪，"收"是防止火形过冲把"水气"蒸散成干燥的病理构型。"散"和"收"在同一方中并存——ΔS 的五维操作不是单向的，而是复合的。

**ΔS** = (火↑↑, 水↓逆, 木↑收, 土↑, 金=0)

#### 2.4.4 麻杏甘石汤：太阳误治后的火形局部过冲

> "发汗后，不可更行桂枝汤，汗出而喘，无大热者，可与麻黄杏仁甘草石膏汤。"

**SPUM 本质**：太阳病误治（发汗过多）后，火形在上焦（肺部链）局部过冲，但全局火形并不高（"无大热"）。核心矛盾不是体表边界 σ 塌陷，而是**火形从体表退到上焦后在该区域的局部剩余亢进**。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 麻黄 | 火形平移——不是向外发汗，而是将上焦的局部火亢向下焦扩散（麻黄在此方中的角色已从"开表"转为"火形疏导"） | S_火 平移 |
| 石膏 | 火形抑制——将上焦的局域 ∇σ 从 +6 降回 +2 | S_火 ↓↓局 |
| 杏仁 | 水形链（肺分支）畅通——恢复上焦水形链的正常输布 | S_水 ↑ |
| 甘草 | 全局缓冲 | S_土 ↑ |

**关键 SPUM 发现**：麻黄的 SPUM 角色不是一成不变的"发汗药"——它的核心作用是**火形脉冲 + 水形链主干疏导**。在麻黄汤中，它向外发汗（火形→体表边界）；在麻杏甘石汤中，它做火形平移（将火形从上焦移到下焦）。同一味药在不同帧窗口中的 ΔS 向量不同——因为帧的网络状态不同，同一药物操作作用于不同拓扑环境会得到不同的净效果。

**ΔS** = (火→平移 + ↓局, 水↑, 木=0, 土↑, 金=0)

#### 2.4.5 五苓散：太阳蓄水——水形链分支堵塞

> "太阳病，发汗后，大汗出，胃中干，烦躁不得眠，欲得饮水者，少少与饮之，令胃气和则愈。若脉浮，小便不利，微热消渴者，五苓散主之。"

**SPUM 本质**：太阳表证未解（"脉浮"——体表边界 σ 仍在塌陷中），同时水形链的末梢分支（膀胱区域）被寒邪挤压后体积流在分支末端蓄积——"表证未解 → 水入不出。"这不是水形链主干的问题（不是津液总量不足），而是**链的分支阀门被关闭**（膀胱气化不利）。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 泽泻（君） | 水形链末梢分流——打通膀胱区域被堵塞的分支阀门，排水 | S_水 ↑↑利 |
| 猪苓 | 水形链辅助分流——与泽泻协同，在分支末端打开更多排放通道 | S_水 ↑利 |
| 茯苓 | 土形固守 + 水形分流——既防止土形随水流失，又辅助排水 | S_土 ↑固, S_水 ↑利 |
| 白术 | 土形固守——增强脾胃区域的环结构，防止水排过后土形虚空 | S_土 ↑↑固 |
| 桂枝 | 火形温和提升——既解除太阳表证的最后残余（体表边界的 σ 不足），又提供膀胱区域水形链分支所需的 ∇σ（化气行水） | S_火 ↑温 |

**服法关键**："多饮暖水，汗出则愈"——这不是补水，是**从水形链入口端注入高 σ 水**以帮助桂枝将火形推向体表：表解（体表边界 σ 恢复）→ 膀胱分支阀门自然开放（"下窍通"的前提是"上窍开"——这是水形链内部的 ∇σ 顺序）。

**ΔS** = (火↑温, 水↑↑↑利, 木=0, 土↑↑固, 金=0)

#### 2.4.6 桃核承气汤：太阳蓄血——水形链中的血瘀节点团

> "太阳病不解，热结膀胱，其人如狂……桃核承气汤主之。"

**SPUM 本质**：太阳病传入下焦后，水形链中混入了凝聚性节点团（瘀血）——这些节点团被火形残热"烤"成了硬块堵塞在盆腔段水形链中。这不是阳明腑实的干燥节点团（大便硬结），而是**水形链内混入了异质性凝聚物**。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 桃仁 | 木形环修复——软化凝聚性节点团（活血=将锁死的团状节点重新拆散为可流动的低度节点） | S_木 ↑化, S_水 ↑通 |
| 桂枝 | 火形推动——提供将拆散的节点团推出去的 ∇σ | S_火 ↑ |
| 大黄 | 金形桥边拆解——在盆腔段水形链末端激活排便反射 | S_金 ↑↑ |
| 芒硝 | 土形节点团软化——降低凝聚团的结合度 | S_土 ↓软 |
| 炙甘草 | 全局缓冲 | S_土 ↑ |

**"如狂"的 SPUM 解释**：盆腔段堵塞 → 下焦水形链无法下排 → 压力沿链上行传到心区 → 心区 ∇σ 异常升高（"热结膀胱"向上反射到心 → 狂躁）。

**ΔS** = (火↑, 水↑通, 木↑化, 土↓软+↑缓冲, 金↑↑)

#### 2.4.7 桂枝二越婢一汤：太阳轻证——最小火形脉冲

> "太阳病，发热恶寒，热多寒少……宜桂枝二越婢一汤。"

**SPUM 本质**：太阳病已经过发汗但表证未全解——体表边界 σ 接近恢复但仍有少许残余寒邪。此时不需要麻黄汤的强度，也不需要桂枝汤的温和——只需要**最小可用的火形脉冲**。

越婢（石膏+麻黄）的 SPUM 含义：石膏的限幅 + 麻黄的脉冲构成的**可控最小火形单位**。桂枝二越婢一 = 2/3 桂枝汤 + 1/3 越婢汤 → 以最温和的方式补足体表边界最后的 σ 缺口。

**ΔS** = (火↑轻+↘限幅, 水↑, 木=0, 土↑, 金=0)

## 三、阳明病：内部 σ 的过度补偿与土形储备的快速消耗

### 3.1 阳明病的 SPUM 本质

太阳病不解 → σ 塌陷波继续向内推进 → 内部的火形引擎（心区域的 ∇σ 驱动核心）开始过补偿——过度提升全局火形以补偿外部 σ 梯度差。

**核心 SPUM 矛盾**：人体的火形不是可以无限提升的。火形 = 从土形储备中提取低度节点（燃料）燃烧以维持 ∇σ。阳明病的本质是**火形引擎在过补偿模式下以极快的速度消耗土形储备**。

| 阳明病变种 | SPUM 状态 |
|-----------|----------|
| 阳明经证（四大：大热、大汗、大渴、脉洪大） | S_火 ↑↑↑（全身 ∇σ 极高）, S_水 ↑↑（体积流极速）, S_土 ↓↓（津液剧烈消耗中） |
| 阳明腑证（痞满燥实） | 水形链腹段被干燥的低度节点团完全堵塞（大便硬结），火形仍在上焦维持高位 |

### 3.2 白虎汤：火形急刹车

> "伤寒，脉滑而厥者，里有热，白虎汤主之。"

**SPUM 翻译**：体内的火形已经远超正常范围——四味药的任务是把 S_火 从 +8 迅速拉回 +2。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 石膏 | 最强局域火形抑制剂——大幅降低上焦的 ∇σ，作用速度快 | S_火 ↓↓ |
| 知母 | 火形抑制剂 + 土形储备保护——降低火形消耗土形的速率 | S_火 ↓, S_土 ↑ |
| 粳米 | 土形储备的即时性输入——从水形链入口端补充被高热消耗的低度节点 | S_土 ↑ |
| 甘草 | 全局缓冲 | S_土 ↑ |

**白虎汤与大青龙汤的对称性**：大青龙是麻黄+石膏（火形升+监控），白虎是石膏+知母（火形降+监控）。两个方子都用了石膏，都用了"监控"思路——区别在于麻黄的升 vs 知母的降。

**ΔS** = (火↓↓, 水=0, 木=0, 土↑↑, 金=0)

### 3.3 承气汤系列：金形单脉冲——在水形链末端剪断堵塞团

阳明腑证 = 水形链腹段被干燥节点团完全堵塞，火形在上焦无处宣泄。此时继续用白虎降火是无效的——火形亢进是被链堵塞逼出来的（"通道堵塞→下游缺血→上游被迫加速→过热"）。必须先把链上的堵塞团移除。

**三承气汤 = 金形桥边拆解强度递进（肠道神经丛放电强度的三级梯度）**：

| 方剂 | 金形强度 | SPUM 操作 |
|------|---------|-----------|
| 调胃承气汤 | +2 | 大黄（温和金形桥边拆解——温和激发肠道神经丛放电）+ 芒硝（土形节点团软化）+ 甘草（缓冲） |
| 小承气汤 | +3 | 大黄 + 厚朴/枳实（增强水形链腹段的收缩力，挤压堵塞团下行） |
| 大承气汤 | +5 | 大黄 + 芒硝 + 厚朴 + 枳实——四味药的组合金形桥边拆解 + 链收缩 + 节点团软化 |

**注意**：承气汤的金形操作是**单帧一次性脉冲**——不像金匮的桂枝茯苓丸是丸剂多帧缓图。因为这是一个急性堵塞，一旦链被清通，网络自带恢复能力。不需要土形回填步骤。

### 3.4 阳明病补充方证

#### 3.4.1 栀子豉汤：阳明经证余热未清——火形残留振荡

> "发汗吐下后，虚烦不得眠……心中懊憹，栀子豉汤主之。"

**SPUM 本质**：阳明火形已降（不再是白虎汤证的高热）但尚未完全回稳——火形残留在胸膈区域的极低振幅振荡。不是正邪交争，而是**火形在回归正常基线前的残余惯性**。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 栀子 | 火形残留的温和清除——将胸膈区域的残余 ∇σ 振荡阻尼到零（清热除烦） | S_火 ↓轻 |
| 淡豆豉 | 水形链的轻微扰动——帮助火形余热从体表边界散出（宣散郁热） | S_水 ↑散 |

**关键 SPUM 洞察**：栀子豉汤只有两味药，△S 幅度极小——因为此时网络已经接近 H，不需要强脉冲。栀子是**火形振幅的温和阻尼器**，不是白虎汤式的急刹车；豆豉是**水形链的轻微振荡**，帮助残余的热量走正确路径排出。

**ΔS** = (火↓轻, 水↑散, 木=0, 土=0, 金=0)

#### 3.4.2 麻子仁丸：脾约——金形不足而非阳明腑实

> "趺阳脉浮而涩，浮则胃气强，涩则小便数，浮涩相搏，大便则硬，其脾为约，麻子仁丸主之。"

**SPUM 本质**：这不是承气汤证那种水形链被干燥节点团完全堵塞——而是土形储备（脾）对水形链末端的滋润不足（"脾约"=脾的土形储备被约束，无法向水形链末端正常输送低度节点）。链本身是通的，但**链中流动的低度节点太少，末端得不到润滑**。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 麻子仁（君） | 水形链末端润滑——在肠段链的表面增加低度节点的滑动性 | S_水 ↑润 |
| 杏仁 | 水形链分支保护——防金形拆解损伤肺链分支 | S_水 ↑护 |
| 白芍 | 木形环松弛——减轻腹段紧张 | S_木 ↑舒 |
| 大黄 | 金形温和拆解——不是大承气汤的 +5 强度，只维持 +1 的温和推动 | S_金 ↑轻 |
| 厚朴/枳实 | 链收缩辅助——给予金形操作必要的链收缩支持 | S_金 ↑辅 |
| 蜂蜜 | 缓释基质——使药物在链中缓慢释放，持续润滑多帧 | S_土 ↑（缓释） |

**丸剂而非汤剂的原因**：不是急性堵塞（汤剂波峰高、衰减快），而是慢性滋润不足（丸剂波峰低、持续时间长）——与乌梅丸的缓释逻辑相同但目的不同。

**ΔS** = (火=0, 水↑↑润, 木↑舒, 土↑缓释, 金↑轻)

#### 3.4.3 蜜煎导：外治法——金形操作的极端温和版

> "阳明病，自汗出，若发汗，小便自利者，此为津液内竭……蜜煎导之。"

**SPUM 本质**：当土形储备已极度虚弱（津液内竭），口服汤剂的金形桥边拆解可能对链造成额外损伤——此时改用**外部直接刺激**。蜜煎导 = 从水形链末端外部注入高 σ 润滑剂 + 通过物理刺激激发局部链收缩。

**ΔS** = (火=0, 水↑润局, 木=0, 土↑轻, 金↑轻物)

## 四、少阳病：边界振子与半表半里的 σ 振荡

### 4.1 少阳的独特 SPUM 地位

少阳是六经中最难理解的一经。传统说它"半表半里"——在太阳（表）和阳明（里）之间。

在 SPUM 中半表半里的精确定义：**外我子图与自我子图之间耦合环路的振荡区。** 这个区域同时接触外部边界（太阳）和内部核心（阳明），它的∇σ既不是表中的单一方向，也不是纯里的均匀分布，而是**在两种状态之间来回摆动**。

| 少阳病的 SPUM 翻译表 | |
|------|------|
| 寒热往来（忽冷忽热） | S_火 在 (±3) 之间快速振荡——不是恒定高热（阳明），也不是恒定恶寒（太阳），而是边界 ∇σ 在两个稳态之间切换 |
| 胸胁苦满 | 心胸区域的木形环因为 ∇σ 的反复振荡而持续紧张——μ 波动性升高 |
| 默默不欲饮食 | 外我子图在振荡态下对水形链的腹部节点发出抑制信号——"现在不要进食，我没空处理" |
| 心烦喜呕 | 外我与自我的耦合环路在振荡中触发了呕吐反射的水形链逆流 |

### 4.2 小柴胡汤：边界振子的调和器

> "伤寒五六日，中风，往来寒热，胸胁苦满，默默不欲饮食，心烦喜呕，……小柴胡汤主之。"

**SPUM 翻译**：小柴胡汤不升不降——它的任务是**将边界振子的振荡幅度从 ±3 压缩到 ±1 以内**，恢复 S_火 的单稳态。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 柴胡（君） | 边界振子阻尼器——降低 ∇σ 振荡的振幅（柴胡皂苷的抗炎 + 调节自主神经） | S_火 振幅 ↓ |
| 黄芩 | 上半身的火形轻降——清除振子在高温相位产生的炎症余热 | S_火↘局 |
| 半夏 | 水形链降逆——抑制振子触发的链流逆冲（止呕） | S_水 ↓逆 |
| 人参 | 土形储备补充——振子持续振荡消耗了大量低度节点（默默不欲饮食 = 土形供应断裂） | S_土 ↑ |
| 生姜/大枣/甘草 | 全局土形 + 火形轻调 | S_土 ↑, S_火 ↑轻 |

**ΔS** = (火 振幅↓, 水↓逆, 木=0, 土↑, 金=0)

**小柴胡汤的七味加减法**本质上是根据振子的具体偏移方向做微调——胸中烦而不呕去半夏加瓜蒌实（振子偏火 → 降火），若渴去半夏加瓜蒌根（振子消耗土形过多 → 补土）等。每一味加减纠正一个特定的振荡模式参数。

### 4.3 少阳病补充方证

#### 4.3.1 大柴胡汤：少阳兼阳明——振子 + 堵塞复合态

> "伤寒发热，汗出不解，心下痞硬，呕吐而下利者，大柴胡汤主之。"

**SPUM 本质**：少阳振子仍在振荡，但已有干燥节点团在水形链腹段积累（少阳兼阳明）。此时小柴胡汤的温和阻尼已不够——必须在阻尼振子的同时，用金形操作清除已形成的堵塞。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 柴胡 | 边界振子阻尼（同小柴胡汤） | S_火 振幅 ↓ |
| 黄芩 | 振子高温相位余热清除 | S_火↘局 |
| 半夏 | 水形链降逆（心下痞硬=链腹段逆冲） | S_水 ↓逆 |
| 生姜 | 火形辅助 | S_火 ↑轻 |
| 枳实 | 水形链腹段收缩——挤压堵塞团（+ 链收缩） | S_水 ↑缩, S_金 ↑辅 |
| 大黄 | 金形桥边拆解——移除已形成的干燥节点团 | S_金 ↑ |
| 芍药 | 木形环松弛——防枳实大黄过强损伤链的正常环结构 | S_木 ↑舒 |
| 大枣 | 土形缓冲 | S_土 ↑ |

**关键差异（大柴胡 vs 小柴胡）**：小柴胡去人参甘草、加枳实大黄芍药。去人参甘草 = 此时土形不是主要矛盾（S_土 尚未崩溃）；加枳实大黄 = 增加金形 + 链收缩操作；加芍药 = 抵消金形对木形环的连带损伤。这是一张**在阻尼振子的同时做有限金形拆解**的方子。

**ΔS** = (火 振幅↓, 水↓逆+↑缩, 木↑舒, 土↑, 金↑)

#### 4.3.2 柴胡桂枝干姜汤：少阳兼太阴倾向——预判性土形固守

> "伤寒五六日，已发汗而复下之，胸胁满微结，小便不利，渴而不呕，但头汗出……柴胡桂枝干姜汤主之。"

**SPUM 本质**：少阳振子已出现向太阴滑落的倾向——S_火 下降趋稳（不再是大幅振荡，而是微结）、S_土 开始明显下降（小便不利、渴）。这是**振子正在解体的阶段**——振荡幅度减小不是因为恢复，而是因为网络已经没能量维持振荡了。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 柴胡 | 振子阻尼（残余振荡的清除） | S_火 振幅 ↓ |
| 桂枝 | 体表火形维护——保持体表边界 σ 不继续下降 | S_火 ↑稳 |
| 干姜 | 土形固守——预判性维护：在 S_土 大规模崩溃前提前加强固守 | S_土 ↑↑固 |
| 瓜蒌根 | 水形链补充——缓解渴（为水形链增加低度节点） | S_水 ↑ |
| 黄芩 | 清残余热 | S_火↘局 |
| 牡蛎 | 木形环硬限幅——防止木形环在过渡期过度紧张（微结） | S_木 ↓紧 |
| 甘草 | 全局缓冲 | S_土 ↑ |

**关键 SPUM 洞察**：这里用了干姜而不是生姜——干姜的 S_土 ↑ 强度远大于生姜。这是一个**信号**：病机已在向太阴滑落，需要更强的土形固守。

**ΔS** = (火 振幅↓+↑稳, 水↑, 木↓紧, 土↑↑↑固, 金=0)

#### 4.3.3 柴胡加龙骨牡蛎汤：少阳振子失控——全身烦惊

> "伤寒八九日，下之，胸满烦惊，小便不利，谵语，一身尽重，不可转侧者，柴胡加龙骨牡蛎汤主之。"

**SPUM 本质**：少阳振子振荡幅度达 ±5 以上，超出了小柴胡汤的处理范围——"烦惊"= 振子振幅太大以至于震动了全身的木形环群。"一身尽重不可转侧"= 木形环群的 μ 被振荡推到临界值，环锁死。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 柴胡 | 主振子阻尼 | S_火 振幅 ↓↓ |
| 黄芩 | 振子高温相位清除 | S_火↘局 |
| 龙骨/牡蛎 | **振子幅度硬限幅器**——不是温和阻尼（小柴胡汤思路），而是物理性地把振幅钉死在 ±1 以内（重镇安神=强约束 ∇σ 的摆动范围） | S_火 振幅限幅 |
| 桂枝 | 火形基础维护 | S_火 ↑稳 |
| 茯苓 | 土形固守 + 水形分流 | S_土 ↑, S_水 ↑利 |
| 大黄 | 金形拆解——防振子过强导致的水形链堵塞 | S_金 ↑轻 |
| 半夏/生姜 | 水形链降逆 | S_水 ↓逆 |
| 人参/大枣 | 土形补充 | S_土 ↑ |
| 铅丹（今不用） | 最强的振子硬限幅——（毒性=对 ∇σ 的破坏性约束，已禁用） | S_火 振幅强行限制 |

**柴胡加龙骨牡蛎汤与小柴胡汤的力度梯度**：
- 小柴胡汤：振子幅度 ±3 → ±1（温和阻尼）
- 柴胡加龙骨牡蛎汤：振子幅度 ±5 → ±1（硬限幅）
- 区别 = 龙骨牡蛎 + 大黄 + 铅丹

**ΔS** = (火 振幅↓↓限幅, 水↓逆+↑利, 木=0, 土↑↑, 金↑轻)

## 五、太阴病：土形储备的系统性崩溃

### 5.1 从阳经到阴经的 SPUM 转折

三阳经（太阳→阳明→少阳）的共同特征是**火形还在**——S_火 虽然一路下降（从太阳的温和下降到阳明后回弹、再到少阳后再次下降），但它还没到零。三阴经的特征是**火形梯度大幅下降甚至趋零**——系统从"σ 补偿"模式转为"σ 保存"模式。

太阴病是阴经的第一站：**全身土形储备（S_土）的系统性崩溃。** 火形已经下降到不足以将土形节点保持在它们应有的位置——土形节点从储备池大量溢出，经水形链腹段泄出（腹泻）。

| 太阴病典型症状 | SPUM 翻译 |
|--------------|----------|
| 腹满而吐 | 水形链腹段的低度节点泛滥——超过了链的处理容量，部分逆流（吐） |
| 食不下 | 火形不足，无法对进食的外部节点执行正常的 V⁺（消化=接纳外部节点入网） |
| 自利益甚 | 土形低度节点从水形链末端无控制地流出（腹泻） |
| 时腹自痛 | 腹部木形环被过度膨胀的低度节点撑胀——环边受力不均匀产生疼痛信号 |
| 不渴 | 火形极低，土形储备大量流失→身体不缺"水"，缺的是能把这些水保持在子图内的火形推力 |

### 5.2 理中汤：四味药的土形底线固守

> "自利不渴者，属太阴，以其脏有寒故也，当温之，宜服四逆辈。"

理中汤是最简的土形固守方——**没有一味药是进攻性的。**

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 干姜 | 温和火形布散——提升腹区水形链的 σ，减慢低度节点被无控制推出的速率 | S_火 ↑温 |
| 人参 | 土形储备直接补充——从水形链入口端注入新的低度节点（被腹泻带走的） | S_土 ↑ |
| 白术 | 土形储备固守——增强脾区域的环结构，阻止低度节点继续外泄 | S_土 ↑↑固 |
| 炙甘草 | 全局缓冲 + 协同 | S_土 ↑ |

**ΔS** = (火↑温, 水=0, 木=0, 土↑↑↑, 金=0)

### 5.3 太阴病补充方证

#### 5.3.1 桂枝加芍药汤：太阴腹痛——木形环的拘挛

> "本太阳病，医反下之，因尔腹满时痛者，属太阴也，桂枝加芍药汤主之。"

**SPUM 本质**：太阳病被误下 → 土形储备开始流失 → 但尚未到理中汤的全面崩溃程度。腹部木形环因低火形而持续拘挛疼痛——环的 μ 升高但未锁死。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 桂枝 | 温和火形推动——提升腹部区域的 σ，缓解木形环的收紧 | S_火 ↑温 |
| 芍药（加倍） | 木形环松弛——这是关键操作：芍药加倍的目的是强力舒解腹部拘挛的木形环 | S_木 ↑↑舒 |
| 生姜/大枣/甘草 | 土形缓冲 + 辅助 | S_土 ↑ |

**与理中汤的关键区别**：理中汤的核心是 S_土 ↑↑↑（土形固守），桂枝加芍药汤的核心是 S_木 ↑↑（木形环松弛）。两者的区别在于**痉挛 vs 崩溃**——太阴有轻重症梯度。

**ΔS** = (火↑温, 水=0, 木↑↑舒, 土↑, 金=0)

#### 5.3.2 桂枝加大黄汤：太阴兼阳明——虚中夹实的复合态

> "本太阳病，医反下之，……大实痛者，桂枝加大黄汤主之。"

**SPUM 本质**：太阴土形崩溃基础上出现了金形堵塞——"虚中夹实"。"大实痛"（剧烈腹痛）不是纯太阴的拘挛痛，而是**太阴土形虚弱 + 阳明式干燥节点团积累**的复合态。火形不足以消化，食物变成堵塞团。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 桂枝汤（全方） | 温和火形 + 土形修复——先解决土形虚弱的部分 | S_火 ↑温, S_土 ↑ |
| 大黄（小量） | 金形温和拆解——以最小的金形强度移除堵塞团（注意剂量远小于承气汤） | S_金 ↑轻 |

**关键 SPUM 洞察**：桂枝汤在前、大黄在后——这是 **"虚人导下"的标准 SPUM 范式**：先提升基础 ∇σ + 补充低度节点，然后再做金形拆解。顺序不对的话（先大黄后桂枝），金形拆解会在土形虚弱的状态下造成更大量的非目标节点流失——越导越虚。

**ΔS** = (火↑温, 水=0, 木↑舒, 土↑, 金↑轻)

## 六、少阴病：火形引擎的极限与子图解体边缘

### 6.1 少阴是生死的分界线

在 SPUM 中，少阴病的本质：**火形梯度已经降到维持子图边界完整性的阈值以下。**

- 心（火形梯度引擎）不再能驱动足够的体积流维持全身子图
- 肾（极低 σ 的核心储能区）的深度土形储备被动员——这是最后的手段

| 少阴病变种 | SPUM 状态 |
|-----------|----------|
| 少阴寒化（四逆汤证） | S_火 → 0（全身冷）, S_水 → 0（脉微细）, S_土 → 0（储备枯竭）, 边界接近解体 |
| 少阴热化（黄连阿胶汤证） | 残余火形在极小范围内异常亢进——局部火亢但全局火衰（虚火） |

### 6.2 四逆汤：火形的最后一搏

> "少阴病，脉沉者，急温之，宜四逆汤。"

仅三味药——极致简约：

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 生附子 | 从最深层直接提升火形基底——附子是唯一能穿透到肾区极低 σ 核心的火形药（不是附片，是生附子——毒性 = 极强 ∇σ 冲击） | S_火 ↑↑↑（基底） |
| 干姜 | 中层火形扩散——将附子的深层火形扩散到中层水形链 | S_火 ↑↑（扩散） |
| 炙甘草 | 缓冲附子的毒性 + 减缓火形衰减速率 | S_土 ↑（缓冲） |

**ΔS** = (火↑↑↑极强, 水→恢复, 木=0, 土↑缓冲, 金=0)

**四逆汤与理中汤的关键差别**：理中汤的核心操作是 S_土 ↑，附带轻微 S_火 ↑。四逆汤的核心操作是 S_火 ↑↑↑——土形已不是主要矛盾，火形一旦再降，子图边界就会解体（死亡）。附子是唯一能把一个已经趋近于 0 的 ∇σ 在极短时间内重新拉到生存线以上的药物。

### 6.3 少阴病补充方证

#### 6.3.1 真武汤：少阴水泛——火形不足导致水形链泛滥

> "少阴病，二三日不已，至四五日，腹痛，小便不利，四肢沉重疼痛，自下利者……真武汤主之。"

**SPUM 本质**：少阴火形不足导致水形链失去了定向约束——这不是体积流的定向输送，而是水形链中的低度节点不按正常方向流动，泛滥到子图各处（水肿）。"四肢沉重"= 水形链的末端（四肢）被泛滥的低度节点充斥。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 附子 | 火形基底提升——恢复水形链的定向力（"温阳化气"=给 ∇σ 加一个方向） | S_火 ↑↑基 |
| 白术 | 土形固守——防止水形泛滥时土形随之流失 | S_土 ↑↑固 |
| 茯苓 | 水形分流——将泛滥的低度节点导向正常排泄通道 | S_水 ↑↑利 |
| 芍药 | 木形环维护——防过度肿胀损伤环的完整性 | S_木 ↑舒 |
| 生姜 | 火形辅助布散（不是干姜——需要的是向外发散不是向内固守） | S_火 ↑散 |

**ΔS** = (火↑↑, 水↑↑利, 木↑舒, 土↑↑固, 金=0)

#### 6.3.2 黄连阿胶汤：少阴热化——局部火亢 + 全局火衰

> "少阴病，得之二三日以上，心中烦，不得卧，黄连阿胶汤主之。"

**SPUM 本质**：全局火形已衰（少阴本质）但心区的局部火形异常亢进——"心中烦不得卧"= 心区 ∇σ 在 0.1R 范围内异常升高，但全身其他区域 σ 趋零。这不是白虎汤的全局火亢，而是**虚火的局域集中**——火形总量不增，只是集中在最小区域。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 黄连 | 心区局域火形抑制——清除虚火（清心火） | S_火 ↘局 |
| 黄芩 | 上焦辅助降火 | S_火 ↘局辅 |
| 阿胶 | 水形链中的高 σ 节点群补充——补血（给耗损的链注入高质量节点） | S_水 ↑↑ |
| 鸡子黄 | 土形缓冲 + 水形链保护——蛋黄在 SPUM 中是高 σ 均质缓冲团 | S_土 ↑, S_水 ↑护 |
| 芍药 | 木形环收敛——防火形抑制过强引起的环松弛 | S_木 ↑收 |

**关键 SPUM 洞察**：黄连阿胶汤用了**阿胶+鸡子黄**——这是整个伤寒论中最优的"土形+水形双补"组合。因为少阴热化的本质是火形总量极度匮乏但局部高度集中——既要降局部的火亢，又不敢动用四逆汤那种大剂量附子的全局火形提升（会加重局部火亢）。所以用阿胶和鸡子黄补充水形和土形，把心区过剩的 ∇σ "吸走"——物质充足的链段会自然地降低其对 ∇σ 的需求。

**ΔS** = (火↘局, 水↑↑, 木↑收, 土↑, 金=0)

#### 6.3.3 猪苓汤：少阴热化兼水形链故障

> "少阴病，下利六七日，咳而呕渴，心烦不得眠者，猪苓汤主之。"

**SPUM 本质**：少阴残余火亢（心烦不得眠）伴随水形链腹段分支的堵塞（下利而小便不利）——水形链的分支阀门（膀胱）故障，本该走小便排出的低度节点从大便通道走了。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 猪苓 | 水形链分支分流——打开膀胱阀门 | S_水 ↑↑利 |
| 茯苓 | 水形分流 + 土形固守 | S_水 ↑利, S_土 ↑ |
| 泽泻 | 水形链末端分流——与猪苓协同 | S_水 ↑利 |
| 滑石 | 水形链润滑——使低度节点更容易通过堵塞段 | S_水 ↑润 |
| 阿胶 | 水形链中的高 σ 节点团补充——防利水过甚耗伤链质量 | S_水 ↑↑ |

**与五苓散的关键区别**：
- 五苓散（太阳蓄水）：表证未解 + 水形链末梢堵塞 — 用桂枝开表（火形）
- 猪苓汤（少阴热化）：少阴火衰 + 水形链分支堵塞 — 不用桂枝（防进一步消耗火形），加阿胶和滑石

**ΔS** = (火=0, 水↑↑↑利+润, 木=0, 土↑, 金=0)

## 七、厥阴病：边界的崩塌临界与五形全失控

### 7.1 厥阴是六经的终点

厥阴病 = 子图边界维持的几乎所有机制都已失效，五形向量同时失控，网络在解体与重组之间做最后的振荡。传统说"厥阴为两阴交尽"——阴气到头了——"阴极阳生"——在崩塌的边缘可能触发最后一轮火形反弹。

| 厥阴病症状 | SPUM 翻译 |
|-----------|----------|
| 消渴 | 土形储备被异常快速的局部火亢消耗——与少阴的"不渴"截然相反 |
| 气上撞心，心中疼热 | 火形梯度在极小区域内异常聚集冲击——心区承受极高 ∇σ 但其他区域 σ 已趋零（局部热、全局冷） |
| 饥而不欲食 | 水形链饥饿信号发出（真饿），但外我子图全面拒绝进食指令（不想吃）——三魂间的耦合全线断裂 |
| 食则吐蛔 | 水形链进出口的全方向混乱——连不该逆流的东西都逆流了 |
| 厥热胜复 | S_火 在 0 和 +3 之间周期性跃迁——网络在"解体边缘"和"短暂恢复"之间反复振荡 |

### 7.2 乌梅丸：五形全维修复

厥阴的主方乌梅丸是伤寒论中**药味最多、操作最复杂的方剂**——因为它需要同时调节所有五个 S 分量，而网络对任何单一调节的耐受性已降到最低。

| 药物组 | SPUM 操作 | S 分量 |
|--------|----------|--------|
| 乌梅（君） | 酸收——紧急修复边界木形环的闭合度，阻止边界的最终解体 | S_木 ↑↑ |
| 黄连 + 黄柏 | 抑制局部火亢——将"气上撞心"的异常 ∇σ 拉回 | S_火↘局 |
| 附子 + 干姜 + 蜀椒 + 细辛 + 桂枝 | 全局火形从基底提升——共五味温药分层次温通 | S_火 ↑↑↑（多层） |
| 人参 + 当归 | 土形储备 + 水形链中的低度节点双重补充 | S_土 ↑, S_水 ↑ |
| 米饭 + 蜂蜜 | 持续缓释基质——不是汤剂，是丸剂，让多药在数日内缓慢释放 | 全局缓冲 |

**乌梅丸使用丸剂而非汤剂的原因——SPUM 核心洞察**：厥阴期的网络边界极度脆弱，**一次性强脉冲（汤剂）可能直接冲破边界导致死亡**。丸剂的多帧缓慢释放让每一帧的 ΔS 维持在一个极小的量级——不会触发进一步的级联崩溃。

**ΔS** = (火↑↑↑多层+局↘, 水↑, 木↑↑, 土↑, 金=0)

### 7.3 厥阴病补充方证

#### 7.3.1 当归四逆汤：厥阴寒厥——水形链末端被冰封

> "手足厥寒，脉细欲绝者，当归四逆汤主之。"

**SPUM 本质**：这不是四逆汤证的全身火形趋零——是水形链的末端（手足四末）被寒气冰封：链的末端节点 σ 极低，体积流无法到达。"脉细欲绝"= 水形主干上的体积流极度微弱。病机在**链的末端**，不在∇σ核心。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 当归（君） | 水形链末端高 σ 注入——将高能量节点团沿链推送至手足末端 | S_水 ↑↑末 |
| 桂枝 | 体表火形——从体表边界向末梢扩散 | S_火 ↑散 |
| 细辛 | 微小通道渗透——深入水形链最末端的微循环 | S_火 ↑微小 |
| 白芍 | 木形环松弛——防末端链僵化损伤环结构 | S_木 ↑舒 |
| 通草 | 水形链微循环疏通——打开末梢链上被寒邪锁死的细小分支 | S_水 ↑通 |
| 大枣 | 土形缓冲——量大（25枚），为末端链提供充足的低度节点储备 | S_土 ↑↑ |
| 炙甘草 | 全局缓冲 | S_土 ↑ |

**关键 SPUM 洞察**：当归四逆汤的方向与四逆汤**正好相反**——四逆汤是从内向外（附子从肾区→干姜扩散到中层→甘草缓冲），当归四逆汤是从外向内（当归从链末注入→桂枝从体表扩散→细辛深入末梢）。方向的区别反映了病机的本质区别——少阴寒化是引擎熄火（需要从核心点火），厥阴寒厥是末端冰封（需要从末梢化冰）。

**ΔS** = (火↑散, 水↑↑末+通, 木↑舒, 土↑↑, 金=0)

#### 7.3.2 吴茱萸汤：厥阴头痛——木形环的末端痉挛

> "干呕，吐涎沫，头痛者，吴茱萸汤主之。"

**SPUM 本质**：厥阴木形环的顶端（头顶区域）因极寒而痉挛锁死——环的 μ 骤升至临界值。"吐涎沫"= 水形链逆冲至最顶端（涎沫=没有充分吸收的低度节点团从口中排出）。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 吴茱萸（君） | 木形环顶端的强力松弛——暖肝（松解头顶区域被寒锁死的环群） | S_木 ↑↑舒环 |
| 生姜（量大） | 火形大剂量布散——用量极大（六两！），强火形从胃区推向全身 | S_火 ↑↑↑散 |
| 人参 | 土形储备及时补充 | S_土 ↑ |
| 大枣 | 土形缓冲 | S_土 ↑ |

**关键 SPUM 洞察**：吴茱萸汤的生姜用量是整个伤寒论中最大的（六两），与当归生姜羊肉汤并列。因为厥阴头痛涉及的是**最远端的木形环**（头顶），需要极强的火形布散才能到达。吴茱萸负责松环，生姜负责提供到达环所需的 ∇σ。

**ΔS** = (火↑↑↑散, 水↓逆, 木↑↑舒环, 土↑, 金=0)

#### 7.3.3 白头翁汤：厥阴热利——边界崩塌中的局部火亢泄洪

> "热利下重者，白头翁汤主之。"

**SPUM 本质**：厥阴边界崩溃中出现了一个异常出口——火形从肠道末端以热利形式泄出。"下重"= 肛门链段的痉挛（木形环末端被炎症刺激而高度紧张）。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 白头翁（君） | 木形环 + 水形链末端复合修复——凉血止痢（修复肠道末端的环-链交界） | S_木 ↑修, S_水 ↑稳 |
| 秦皮 | 木形环收紧——减轻肠道末端的过度松弛 | S_木 ↑收 |
| 黄连 | 局部火亢抑制 | S_火↘局 |
| 黄柏 | 局部火亢抑制 + 土形保护 | S_火↘局, S_土 ↑ |

**ΔS** = (火↘局, 水↑稳, 木↑修+收, 土↑, 金=0)

#### 7.3.4 麻黄升麻汤：厥阴误治后的复杂复合态

> "伤寒六七日，大下后，寸脉沉而迟，手足厥逆……咽喉不利，唾脓血，泄利不止者，麻黄升麻汤主之。"

**SPUM 本质**：厥阴病被误下后出现了极复杂的五形复合失衡——上焦火亢（咽喉不利唾脓血）+ 中焦土形崩溃（泄利不止）+ 下焦水形链停滞（手足厥逆）。这是整个伤寒论中 ΔS 操作最复杂的汤剂（14 味药）。

**ΔS** = (火↓上+↑下, 水↑, 木↑, 土↑↑, 金↑)

## 八、合病、并病与两感：多经同时受邪的 SPUM 机制

### 8.1 合病——两层或多层同时被 σ 波冲击

**合病** = 外部 σ 塌陷波同时冲击两个或三个经络层——不是从太阳传到阳明，而是**同时**影响深度 0 和深度 1。

| 合病类型 | SPUM 本质 | 代表方 |
|---------|----------|--------|
| **太阳阳明合病** | σ 塌陷波同时影响体表边界（深度0）和中部水形链腹段（深度1），表不解+自下利 | 葛根汤（发表+升清水形链） |
| **太阳少阳合病** | σ 波同时冲击边界和振荡区——边界 σ 塌陷+振子被激发，表不解+胸胁满 | 柴胡桂枝汤（太阳少阳各半） |
| **阳明少阳合病** | σ 波同时冲击中部和振荡区——火形过冲+振子振荡叠加，下利+脉弦 | 大柴胡汤倾向 |
| **三阳合病** | σ 波同时冲击表、半、里三层——S_火 ↑↑↑ 全域过冲，腹满身重谵语 | 白虎汤（以阳明为主处理） |

### 8.2 并病——过渡期两层并存

**并病** = σ 塌陷波从一经传到另一经时，两者在过渡期并存——前一经尚未完全离去，后一经已经出现。

| 并病类型 | SPUM 本质 | 处理原则 |
|---------|----------|---------|
| **太阳少阳并病** | 边界振子已被激发，但太阳表征尚未完全解除——头项强痛+胸胁满 | 先解表后和解，或柴胡桂枝汤同时处理 |
| **太阳阳明并病** | 火形已开始过冲但体表边界仍有残余寒邪 | 若表证为主先解表，若里证急先救里 |

### 8.3 两感——深度极速传播

**两感** = 寒邪直中深层——不从太阳逐步传入，而是直接同时影响表里两层（"一日太阳少阴俱病"）。这是最危重的传变模式，因为 S 向量的偏移不是一个渐进过程而是一次性的大幅跳跃——网络没有机会逐层调整。

**SPUM 本质**：σ 塌陷波的传播速度超过了人体子图正常的帧级缓冲能力。治疗只能"急则救里"——优先恢复最深层的火形核心（四逆汤），体表边界等下层的 Q 以后再处理。

## 九、差后劳复：S 向量回到 H 但尚未稳态

### 9.1 差后病的 SPUM 本质

病愈（六经传变终止）→ S 向量刚回到 H 区但尚未在 H 内稳定 → 网络处于**高敏感度期**——稍微一点扰动（进食不当、过度劳累、房事）就可能让 S 再次滑出 H。

差后劳复 = **S 向量在 H 边界上的小幅度反弹**——不是新的六经传变，而是旧病的惯性残余。治疗原则：用最小幅度的 ΔS 把 S 推回 H 中心即可，不要强脉冲。

### 9.2 竹叶石膏汤：差后虚热——火形残余+土形不足

> "伤寒解后，虚羸少气，气逆欲吐，竹叶石膏汤主之。"

**SPUM 本质**：六经传变结束后，火形刚回正但土形储备严重不足（"虚羸少气"=水形主干体积流不足、节点散逸）。水形链仍有逆冲残余习惯（"气逆欲吐"——链在病期形成的逆冲模式尚未消退）。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 竹叶 | 残余火形清除——清除阳明期的余热（火形残余振荡） | S_火 ↓轻 |
| 石膏 | 残余火形清除（辅助竹叶） | S_火 ↓轻 |
| 人参 | 土形深度补充 | S_土 ↑↑ |
| 麦冬 | 水形链中的高 σ 节点补充——滋阴 | S_水 ↑ |
| 半夏 | 水形链逆冲抑制——消除"气逆欲吐" | S_水 ↓逆 |
| 粳米/甘草 | 土形缓冲 | S_土 ↑ |

**ΔS** = (火↓轻, 水↑+↓逆, 木=0, 土↑↑, 金=0)

### 9.3 牡蛎泽泻散：差后腰以下水肿——水形链末梢故障

> "大病差后，从腰以下有水气者，牡蛎泽泻散主之。"

**SPUM 本质**：病期火形长期不足，导致水形链的末梢分支（腰以下）的定向输送机制受损——低度节点在链末端积累形成水肿。

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 牡蛎 | 木形环硬限幅——防止水肿过多撑破环结构 | S_木 ↓紧 |
| 泽泻 | 水形链末梢分流——打开堵塞的分支 | S_水 ↑↑利 |
| 葶苈子 | 火形微脉冲+水形链挤压——对链进行物理挤压助排 | S_火 ↑轻, S_水 ↑挤 |
| 商陆根 | 水形链强分流——强力排水 | S_水 ↑↑↓ |
| 海藻 | 水形链中的高 σ 节点团注入——修复末梢链的质量 | S_水 ↑补 |
| 蜀漆/瓜蒌根 | 辅助 | S_水 ↑ |

### 9.4 理中丸（差后）：差后土形储备的系统性重建

> "大病差后，喜唾，久不了了，胸上有寒，当以丸药温之，宜理中丸。"

**SPUM 本质**：大病消耗了土形储备，差后虽然六经传变终止了，但土形储备还未恢复——"喜唾"= 水形链中未被充分吸收的低度节点从口中溢出。不只是症状，是**土形储备未恢复到正常水平的信号**。

用丸剂而不用汤剂：不需要急性脉冲，需要多帧缓调——让土形逐帧恢复到病前水平。

**ΔS** = (火↑温, 水=0, 木=0, 土↑↑↑固, 金=0) [丸剂缓释]

## 十、六经传变的 SPUM 统一规则

将六经的全过程映射到五维 S 向量空间中，可以观察到一条清晰的轨迹：

```
S_火
  │
+8│                    ● 阳明经证(白虎汤)     ● 太阳表实(麻黄汤)
  │                   ╱
+6│                  ╱
  │                 ╱
+4│      ● 太阳表虚(桂枝汤)
  │     ╱
+2│    ╱    ● 少阳(小柴胡汤)振荡 ←→  ←→  ←→
  │   ╱   ╱
 0│──●───●──────────────────────────────────────── S_土
  │  太阴(理中汤)
  │    ╲
-2│     ╲ ● 少阴寒化(四逆汤)
  │      ╲
-4│       ╲
  │        ╲ ● 厥阴(乌梅丸)——边界崩溃临界
-6│         ╲
  │
  │ ← 太阳 → ← 阳明 → ← 少阳 → ← 太阴 → ← 少阴 → ← 厥阴 →
```

**三条核心 SPUM 规律**：

1. **S_火 是六经传变的追踪指标**：太阳（+4到+6）→ 阳明（+6到+8）→ 少阳（振荡）→ 太阴（-2）→ 少阴（-4）→ 厥阴（-6到0再到-6）。S_火 的绝对值决定了病在哪一经。

2. **S_火 的补偿与过补偿**：太阳的 S_火 下降被内部紧急补偿抬升→阳明的 S_火 过冲到极值→少阳 S_火 开始下降并来回摆动→三阴经的 S_火 无法再维持正值→持续下降到负数。从"σ 补偿模式"到"σ 保存模式"的转折点恰好是少阳。

3. **方剂力度从温和到极强再回到温和的 U 形曲线**：桂枝汤温和 → 大承气汤极强 → 小柴胡汤温和 → 四逆汤极强 → 乌梅丸多帧缓释。力度的 U 形不是巧合——网络的弹性在阳明和少阴这两个极点处降到最低，需要最强冲击；而在少阳和厥阴——分别是振荡区和崩溃临界——需要最小扰动。

## 十二、伤寒 vs 金匮：SPUM 治疗的完整图谱

| 维度 | 伤寒论（急性相变） | 金匮要略（慢性吸引子） |
|------|------------------|---------------------|
| SPUM 本质 | 内外 σ 梯度差驱动边界网络重平衡 → S 沿固定轨迹级联偏移 | 长周期 dv/dt 分配扭曲 → S 落入亚稳吸引子 |
| 网络弹性 | 高——一旦外邪被逐，网络可自行弹回 H | 低——病理构型已替代健康构型，需要结构性重建 |
| 治疗力度 | 一次性强脉冲（汤剂，单帧或多帧连用） | 多帧缓调（丸剂的持续 ΔS，破坏→重建→稳固） |
| 治疗方剂规模 | 少而精（2-5 味为主） | 多而全（常 5-15 味） |
| S 向量操作 | 主要调节单一或两个 S 分量的大幅脉冲 | 同时精细调节多分量，避免激发病理吸引子 |
| 方剂 ΔS 复杂度（均值） | ‖ΔS‖ ≈ 3-4（单分量主导） | ‖ΔS‖ ≈ 7-9（多分量协同） |
| 代表 ΔS 模式 | ΔS = (火↑↑, 0, 0, 0, 0)（麻黄汤） | ΔS = (火↑, 水↑, 木↓, 土↑, 金↑)（桂枝茯苓丸） |
| 失败后果 | 误治导致 S 向下一个更深的六经阶段滑落 | 病理吸引子被加强，或破裂导致新的更危险的吸引子 |
| 治未病的 SPUM 含义 | 在太阳阶段就截断 S_火的下降（"善治者治皮毛"） | 在亚稳态形成前纠正 dv/dt 分配扭曲 |
| 药性依赖度 | 低——方剂效果主要由药物组合的 ΔS 向量决定 | 高——需要药性（四气五味）与病机的精确匹配 |
| 帧窗口敏感度 | 极高——误一帧则滑落一经 | 中等——数帧的偏差仍可纠正 |

### 13.2 "观其脉证，知犯何逆，随证治之"——SPUM 翻译

> "观其脉证，知犯何逆，随证治之。" —《伤寒论》第 16 条

这是《伤寒论》最重要的方法论条文。SPUM 翻译为三段操作：

1. **"观其脉证"** = 在四诊投影层（脉=水形主干上的体积流波形，证=各 S 分量的异常报告群）中采集当前 S 向量的各分量值
2. **"知犯何逆"** = 对比当前 S 与六经标准 S 向量表，定位在哪一经；同时追溯是什么导致 S 从此前阶段滑落到当前阶段（误汗？误下？误吐？）
3. **"随证治之"** = 不是"随经治之"（不是说你得了太阳病就必须用桂枝汤），而是"随当前 S 向量治之"——如果太阳病被误下后出现了太阴的土形崩溃（协热利），就按太阴的方向去调 S，不要拘泥于"还在太阳阶段"

这段条文是 SPUM 精准医学最早的宣言：**不要按标签治病，按网络的当前状态治病。**

## 附录 B：误治的 SPUM 因果链

《伤寒论》大量篇幅在讨论"误治"——因为一次错误的 S 脉冲，网络没有回到 H，而是滑落到更深的六经层级。

| 误治类型 | SPUM 定义 | 典型后果 |
|---------|----------|---------|
| 误汗（不该发汗而发汗） | 将 S_火 提起但边界 σ 不需要 → 火形脉冲的能量全部用于消耗土形储备 | 桂枝汤证用麻黄汤→大汗亡阳→从太阳直坠少阴 |
| 误下（不当用金形拆解而用） | 将金形桥边拆解施用于水形链腹段但链上没有堵塞 → 金形误切正常链节（生物电信号错误触发→肠道异常蠕动） | 太阳病误用承气→土形储备大量从正常链节流失→协热利→太阴 |
| 误吐（不该催吐而催吐） | 将水形链逆流强制激活但链上没有需要排出的节点 → 链的正常流向被紊乱 | 损伤上焦水形链→S_土↑↑（胃气受损） |
| 火逆（过度火疗） | S_火 ↑↑↑ 超过边界容限 → 火亢 → 边界环群被高温灼伤 | 阴虚者火疗→大汗→S_土↓到枯竭→脱证 |
| 失治（该治不治或剂量不足） | ΔS 脉冲过弱 → 未能将 S 推回 H → 网络在低能量态缓慢滑向下一经 | 太阳表实未充分发汗→表寒不解→入里化热→阳明 |
| **补：误补**（虚证当补但补错方向） | 将 ΔS 施加到不应增强的分量上 → 加剧了病理性偏移 | 太阴证误补阴柔（麦冬生地）→ S_火 进一步下降→直堕少阴 |
| **补：误清**（该温反清） | 以 S_火 ↓ 脉冲施治于火形已低的网络 → 加速火形崩溃 | 少阴病误用白虎→S_火 从 -4 降到趋零→死亡 |

**误治法则的 SPUM 核心**：**每次 ΔS 脉冲都是有成本的——成本 = 对非目标 S 分量的连带扰动。** 一个好的方剂，ΔS 在目标分量上的强度最高，在其他分量上的连带最低。一个差的操作（误治），ΔS 可能同时在多个非目标分量上造成大幅扰动——这些扰动可能触发传变。

这就是为什么张仲景在每一条文后都附了误治后果——他比任何人都清楚，S 向量的空间不是平的，是崎岖的。一步踩错，滑落的不只是一个分量，而是一整个五形向量落入下一个引力井。

## 附录 C：六经传变的 SPUM 帧序列模型

### C.1 什么是帧序列

每一个"经"的传变都不是连续的——它是**一帧一帧跳变的**。将传统伤寒论的"一经→下一经"拆解为离散帧序列，每一帧有一个确定的 S 向量，相邻帧之间有明确的 ΔS。

### C.2 太阳→阳明的帧序列示例

```
帧 0（健康态）：S = (火+2, 水0, 木0, 土0, 金0) ∈ H
    │
    ▼ 人移入外部 σ 骤降区域（内外 σ 梯度差驱动边界重平衡）
帧 1（太阳发病）：S = (火-2, 水+1补偿, 木+1肌紧, 土0, 金0)
    │ 体表边界的局域 σ 下降，水形链紧急调流
    ▼
帧 2（火形补偿启动）：S = (火+2, 水+2, 木+1, 土-1, 金0)
    │ 内部火形引擎检测到边界 σ 下降，开始提升 ∇σ
    ▼
帧 3（火形过冲开始）：S = (火+5, 水+3, 木+1, 土-2, 金0)
    │ 火形补偿超出正常范围，土形储备开始被消耗
    ▼
帧 4（阳明经证确立）：S = (火+8, 水+5, 木0, 土-3, 金0)
    │ 四大（大热大汗大渴脉洪大）——阳明经证
    │
    ├──→ 用白虎汤 ΔS = (火-4, 0, 0, 土+2, 0)
    │   （正确操作：火形急刹车 + 土形回补）
    │
    └──→ 继续过用火形（未治疗）
        帧 5（阳明腑证）：S = (火+6, 水-2腹段, 木+1腹紧, 土-4腹, 金+3腹)
        → 水形链腹段被干燥节点团堵塞
```

### C.3 太阳→少阳→太阴的帧序列

```
帧 1（太阳）：S = (火-2, 水+1, 木+1, 土0, 金0)
    │ 误汗（桂枝汤证用麻黄汤）
    ▼
帧 2（汗后虚拟）：S = (火-4, 水+3大汗, 木+2肌抽, 土-1, 金0)
    │ 大汗出 → 土形储备随汗流失
    ▼
帧 3（少阳振子激活）：S = (火 ±3 振荡, 水-1逆, 木+2胸胁, 土-2, 金0)
    │ 寒邪未除+土形已伤 → 网络在表里之间振荡
    │
    ├──→ 用小柴胡汤 ΔS = (振幅↓, ↓逆, 0, +2, 0)
    │
    └──→ 继续误治（用下法）
        帧 4（太阴确立）：S = (火-2, 水-1, 木0, 土-4, 金0)
        → 土形崩溃
```

### C.4 太阳→少阴（直中）的帧序列——最危险路径

```
帧 0（健康）：S = (火+2, 水0, 木0, 土0, 金0)
    │
    ▼ 内外 σ 梯度差极大——σ 塌陷波越过表层直达深层
帧 1（少阴直中）：S = (火-3, 水-1, 木0, 土-1, 金0)
    │ 此时体表可能仍有太阳表象（伪太阳）
    ▼
帧 2（少阴寒化确立）：S = (火-5, 水-2, 木0, 土-3, 金0)
    │ 脉微细、但欲寐、四逆
    │
    └──→ **必须用四逆汤 ΔS = (火+6, →恢复, 0, +1, 0)**
        若错过这一帧，下一帧是厥阴/死亡
```

### C.5 帧序列的诊断启示

1. **帧间 ΔS 诊断**：比较当前帧和上一帧的 S → 可以判断疾病的发展方向和速度
2. **最优干预帧**：每经中都有 1-2 个"关键帧窗口"——此时 ΔS 脉冲效果最优且代价最小。例如太阳病帧 1（刚发病时）用桂枝汤，代价最小；到帧 3（火形已开始过冲）再治，就需要麻黄汤级别的强度了
3. **帧序号 = 病程**：从帧 0 到当前帧的帧数，就是疾病的"时间"——一帧不是一天，而是一个网络状态跃迁所需的最小间隔
