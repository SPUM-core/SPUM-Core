[六级病机——木亢终局] S_木 悖论态（↑活性 + ↓内容物）
   → 凌晨3时醒（肝经时，木环异常节律）
   → 百会痛（肝经上巅顶，血不达+气亢逆）
   → 思维不停（木环锁死，无法放松进入睡眠模式）
           ↓

[恶性循环] 百会痛+失眠 → 思虑更重 → S_木↑ → 木克土 → S_土↓↓ 更严重
           ↓
[竹叶青打破循环] 竹叶青 ΔS ≈ (火↑, 木↓↓, 土↑, 水↔拮抗态)
   → 酒基火↑ + 竹叶/栀子火↓↓ = 火亢被部分对冲
   → 木香/檀香/陈皮/菊花木↓↓↓ = 强效松木→百会痛缓解
   → 砂仁/当归/陈皮土↑ = 温和补土
   → 当归/竹叶水↑ = 部分对冲酒基的暗耗
   → 两年临床观察：这不是"借债"，是粗制但有效的**成药维持方案**
```

═══ 治疗目标 ΔS_target ═══

核心策略：虚劳范式（金匮"缓中补虚"——不可急攻，多靶点慢调）

八字指导：用神火（暖土）+ 水（滋土）
          忌金（再增金→双酉泄土更甚）

S'_水 = ↑↑（从先天极弱回到能涵木制火的程度）
S'_火 = ↔（基线回到正常，虚浮消失）
S'_木 = ↔（活性回落到正常基线，环内容物↑）
S'_金 = ↑（卫气恢复固表能力）

ΔS_target = (土↑↑↑核心, 水↑↑, 火基↑+虚浮↓, 木活性↓+内容↑, 金↑)

治疗总原则：补土建中为主，滋水涵木为辅，潜降虚火为佐。
           ⚠️ 绝对避免苦寒直折虚火——火是虚的，不是实的。
             苦寒会进一步伤 S_土，让问题更严重。
           ⚠️ 避免再增金气（桔梗/贝母/麦冬→双酉泄土更甚）

操作先后顺序：
  第一步：恢复土形储备（健脾胃）—— 脾不运化则一切补益无法承载
  第二步：滋肾养阴（补水）—— 补先天极弱之水
  第三步：潜降虚火（安神）—— 虚火不扰则睡眠恢复
  第四步：疏木养血（养肝）—— 睡眠恢复后肝血自生，木亢自平
  第五步：益肺固表（收尾）—— 巩固卫气，止盗汗
```

**加减化裁**：
- 盗汗重：加 **煅牡蛎 30g**（S_金↑固涩）
- 五心烦热甚：加 **地骨皮 12g**（S_水↑凉降虚热，不害土）

- 胃脘胀满：减龙眼肉/大枣用量

**服用方法**：
- 汤剂，每日1剂，加水约800ml，煎至400ml，分早晚2次温服

**疗程预估**：
- **7剂后**：睡眠应有初步改善，精神稍好转
- **14剂后**：胃口开、五心烦热减轻、百会麻木间隔延长
- **1-3个月**：逐步回到 S ∈ H 区域

竹叶青不是需要戒除的对象——它是您自主发现的有效维持方案。

## 关键诊断总结

|------|---------|------|
| **S_土** | **↓↓↓ 纯虚枯竭**（与大黄蛰虫丸案的"因壅致虚"本质不同） | 八字己土日干+声域宫音→先天土型好底子，被双酉泄+木克+水竭掏空。**腹部消瘦而非赘肉 = 证实纯虚** |
| **S_水** | **↓↓↓ 先天极弱** | 八字全局仅一癸水藏支——八字最严重短板。当前癸亥大运=治疗窗口 |
| **S_火** | 基线↓↓ + 虚浮↑ 悖论态 | 怕冷(↓↓) + 五心烦热/盗汗(虚浮↑) |
| **S_木** | ↑活性 + ↓内容物 悖论态 | 思维不停/3时醒(↑) + 发细/脉细(↓) |
| **S_金** | ↓ 卫气不固 | 盗汗/发细/甲竖纹 |
| **治疗策略** | **直接补益**（无需先疏壅） | 补土建中（归脾汤）+ 滋水涵木（酸枣仁汤）+ 潜降虚火 |
