## 第八步：治疗目标 ΔS_target

```
═══ 治疗目标 ΔS_target ═══

核心策略：护木生火（救丁火生源）→ 补水制浮火（治消渴之本）

  - 丁火弱——不可苦寒直折（黄连大量→火灭）
  - 木被金克——不可再伤木气（忌辛散/收敛过度）
  - 金极旺——不可再增金气（忌贝母/桔梗/麦冬/五味子等金味）
  - 水竭——需补水但不可寒凝（忌石膏/知母大量）

  第一步（1-2周）：稳定当前状态 + 确认情志改善
  第二步（2-8周）：补水制浮火（兼顾火弱体质）
  第三步（巩固）：护木为主，长期维护

S'_水 = ↑（从↓↓↓回到↓↓——不可能完全恢复，但可改善）
```

## 第九步：治疗方案（重建版）

### 核心用药原则

| 原则 | 原因 |
|------|------|
| **禁用苦寒直折** | 丁火弱，黄连/黄芩大量→火灭→虚火更浮 |
| **禁用温补** | DKA史（已付代价），附子/肉桂/红参→火暴冲 |
| **禁用滋腻碍胃** | 土已耗损，熟地/阿胶大量→土更不运 |
| **优先食补** | 本案体质极度敏感，药补先以食补过渡 |

### 【第一步：稳定期（第1-2周）】

**目标**：确认情志状态，以食补为主、药补为辅。

**百合地黄汤轻剂加减**：

|------|------|-----------|
| **百合** | 12g | S_金↔ + S_火↘ — 宁心润肺（金药但不助金旺） |
| **生地黄** | 10g | S_水↑温和 + S_火↘ — 滋阴不寒凝 |
| **酸枣仁** | 12g | S_水↑ + S_火↘ — 养心安神 |
| **山药** | 15g | S_土↔ — 平补不壅 |
| **茯苓** | 10g | S_水↔ — 利水不伤阴 |

> 此期剂量均从轻——"试水"，观察患者对该方向的反应。

### 【第二步：补水制浮火（第2-8周）】

| 知母 | 6g | S_火↘ + S_水↔ | 退虚热 |

> **黄柏仅3g**（原案6g）。辛酉大运金已极旺，黄柏虽降火但也属金味，不可多用。

### 【食疗方案（核心）】

本案体质敏感，食疗优先于药疗。食药同源=最安全的ΔS操作。
