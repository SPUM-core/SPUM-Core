# 玄空飞星卦组合化解方法

> 整理自《风水师随身手册》玄空飞星部分，按书页顺序完整收录两数字组合代表的飞星配对卦象，分「当旺」吉性、「失运」凶灾两部分，附带对应化解操作。
>
> 已实证为有效治病风水调理方案，纳入人元子网作为参考。

## 通用化解工具汇总

| 工具类别 | 具体物品 | 五行作用 |
|----------|----------|----------|
| 五形植物 | 观音竹 4 枝 | 水形链扩展支持木形骨架 |
| 金形铜钱 | 5 枚、6 枚、7 枚 | 金形拆解加速 |
| 红色系 | 红地毯、红灯、红电灯 | 生火、调和木火 |
| 青色/绿色 | 绿植、青色摆件 | 金形拆解释放节点 → 水形路径扩展 |
| 黑色深蓝 | 黑色摆件、深蓝色装饰 | 金生水 |
| 金属钟铃 | 圆钟、五层风铃 | 泄土煞、化五黄 |
| 鱼缸 | 圆形鱼缸养黑鱼 6 条（不加水泵） | 补水化土 |
| 黄色石蛋盒 | 黄盒 + 八粒石蛋加水 | 火形驱动水形输送土形 |
