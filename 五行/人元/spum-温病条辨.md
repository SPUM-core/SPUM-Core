## 一、温病条辨的 SPUM 定位

### 1.1 伤寒 vs 温病：同一网络的两种对称扰动

| 维度 | 伤寒论 | 温病条辨 |
|------|--------|---------|
| 外部扰动 | σ 塌陷（寒）——外界 V⁺ 骤降 | σ 过冲（热）——外界 V⁺ 骤升 |
| 边界反应 | 收缩——边界节点度数急剧降低，封闭接口 | 扩张——边界节点度数急剧升高，接口过开 |
| 传播方向 | 从外向内逐层压缩 | 从外向内逐层灼烧 |
| 核心受损模式 | 深层 σ 核心被冻结（水形停滞） | 深层 σ 核心被耗干（土形枯竭） |
| 治则总纲 | 温阳散寒 = 提升 σ | 清热存阴 = 降低 σ + 保护土形 |
| 禁用 | 寒凉（会加剧 σ 塌陷） | 辛温发汗（会加速 σ 过冲扩散） |
| SPUM 轨迹 | 六经深度收缩 | 卫气营血四层灼穿 |

### 1.2 温病的 SPUM 定义

> "温病者，有风温、有温热、有温疫、有温毒、有暑温、有湿温、有秋燥、有冬温、有温疟。" —《温病条辨》上焦篇

**SPUM 翻译**：温病 = 外部 σ 场持续处于偏高水平，使人体子图边界长期受到 ∇σ 从外向内的强定向压力——边界节点被迫保持高度数（开放），体积流不断被吸入，内部 σ 持续攀升，土形储备被加速消耗。温病不是"一种病"——它是 σ 过冲导致的一系列 S 向量偏移的总称。

### 1.3 核心概念的 SPUM 翻译

| 温病概念 | 传统解读 | SPUM 翻译 |
|----------|---------|-----------|
| **温邪** | 温热病邪 | 外部 ∇σ 过强且方向内指——高 σ 体积流从边界强行灌入 |
| **卫气营血** | 四个病变深度层次 | σ 过冲波向内穿透的四层深度——子图从边界到核心的四层防御 |
| **上中下三焦** | 三个病变部位 | σ 过冲在子图的三个垂直区域的表现——上焦(边界层)/中焦(中层)/下焦(深层核心) |
| **清热** | 清除热邪 | 降低局域 σ——金形修剪 + 火形抑制 |
| **存阴** | 保存阴液 | 保护土形储备（津液）不被过冲消耗殆尽 |
| **透热转气** | 将营分热邪透出到气分 | 将深层 σ 过冲的能量通过水形链接力传导到浅层——梯度逆转 |
| **凉血散血** | 凉血 + 活血 | 在止血（金形修剪断裂血管环）的同时维持微循环（水形链不断流） |

## 二、卫气营血：σ 过冲的四层深度

### 2.1 四层 = 从边界到核心的四层穿透

伤寒的六经是 σ 塌陷的六层收缩——从外向内逐层降低 σ。温病的卫气营血是 σ 过冲的四层灼穿——从外向内逐层提升 σ 至危险水平。

| 层次 | 传统定位 | SPUM 定义 | 边界深度 | 核心事件 |
|------|---------|-----------|---------|---------|
| **卫分** | 表——皮毛 | 子图最外层边界节点群受到 σ 过冲的第一波冲击 | 深度 0（边界） | 边界节点被迫过度开放——发热、微恶风寒 |
| **气分** | 里——肺胃 | σ 过冲进入子图中层——水形链中段被高热冲击 | 深度 1 | 体积流被加热到超出水形链的散热能力——高热、大汗、大渴 |
| **营分** | 里——心营 | σ 过冲穿过中层深入深层——开始触及子图的土形核心储备 | 深度 2 | 深层基质被热灼——土形储备开始枯竭——神昏、斑疹 |
| **血分** | 里——肝肾 | σ 过冲到达子图最深处——核心 σ 被迫无法降回低 σ 态 | 深度 3（最深） | 底层结构被热破坏——木形环断裂(出血)、土形储备枯竭(亡阴) |

### 2.2 卫气营血 vs 六经：深度对应

```
伤寒(σ塌陷):          温病(σ过冲):
  太阳(边界收缩)  ←→  卫分(边界开放过度)
  阳明(中层高热)  ←→  气分(中层灼热)
  少阳(边界-内部) 
  太阴(土形核心)  ←→  营分(土形开始枯竭)
  少阴(最深核心)  ←→  血分(核心被破坏)
  厥阴(临界崩溃)
```

伤寒六层（6 步）vs 温病四层（4 步）——因为 σ 过冲（热）的传播速度通常快于 σ 塌陷（寒），层数更少。这与网络物理一致：高 σ = 边界开放 = 传播加速；低 σ = 边界封闭 = 传播减速。

### 2.3 传变路径

```
[健康态 S ∈ H]
    │
    ▼ 外部 σ 过冲（温邪）轰击边界
[卫分] S_火↑↑ 边界, S_水↑ 边界(发热), S_木↓ 边界(边界环被热软化)
    │ 若不解，σ 过冲穿透边界
    ▼
[气分] S_火↑↑↑ 全局(高热), S_土↓↓(大量出汗消耗津液), S_水↑↑(加速循环散热)
    │ 若不解，σ 过冲灼入深层
    ▼
[营分] S_土↓↓↓(深层储备被灼耗), S_火↑↑ 深层, 神昏(核心自指子图被热干扰)
    │ 若不解，σ 过冲到达最深
    ▼
[血分] S_木↓ 出血(木形环断裂), S_土↓↓↓↓(亡阴=土形耗尽)
    │
    ▼
[S ∉ H 不可挽回 → 脱证——网络解体]
```

## 三、上中下三焦：σ 过冲的垂直区域分布

### 3.1 三焦 = 子图的三个垂直功能带

| 三焦 | 传统定位 | SPUM 定义 | 对应层次 |
|------|---------|-----------|---------|
| **上焦** | 心肺、头面 | 子图的顶层——最接近边界、火形主导 | 卫分→气分初 |
| **中焦** | 脾胃 | 子图的中层——土形核心、水形链腹段 | 气分→营分初 |
| **下焦** | 肝肾 | 子图的底层——最深 σ 核心、土形终极储备 | 营分→血分 |

### 3.2 垂直传播

σ 过冲不仅仅向内穿透——它同时从上向下沉降。热空气在上方积聚，向下辐射热量。

```
上焦(最接近边界) ─→ 最先受冲击，症状最急
  ↓ σ 过冲向下沉降
中焦(中间层) ───→ 中期受冲击，水形链腹段受损
  ↓
下焦(最深) ────→ 后期受冲击，核心被热破坏
```

## 四、温病方剂的 ΔS 向量

### 4.1 伤寒方 vs 温病方：镜像 ΔS

| 阶段 | 伤寒方 | 伤寒 ΔS | 温病方 | 温病 ΔS |
|------|--------|---------|--------|---------|
| 表证 | 麻黄汤 | S_火↑↑↑, S_水↑ 发汗提升σ | 银翘散 | S_火↓, S_水↑ 清散热+疏通风道 |
| 表虚 | 桂枝汤 | S_火↑, S_土↑ 温和提火+补土 | 桑菊饮 | S_火↓, S_水↑ 微清+宣肺 |

**镜像关系**：伤寒用麻黄将 S_火 向上推 3 级——对抗 σ 塌陷。温病用银翘连翘将 S_火 向下拉——抑制 σ 过冲。麻黄汤发汗是"从内向外推"体积流；银翘散是"打开顶部排热口"让过冲的 σ 自然散热。

### 4.2 卫分方剂——银翘散、桑菊饮

**银翘散** = 金银花 + 连翘 + 桔梗 + 薄荷 + 竹叶 + 荆芥 + 淡豆豉 + 牛蒡子 + 芦根 + 甘草

| 药物 | ΔS 贡献 | 作用 |
|------|---------|------|
| 金银花 | (−, 0, 0, 0, +) | 金形轻清修剪——清除边界被热灼产生的冗余碎边 |
| 连翘 | (−−, 0, 0, 0, +) | 强力清热+金形——主攻 S_火↓ |
| 薄荷 | (−, +, 0, 0, 0) | 透表——边界微微开放散热(水+)但不提升 S_火 |
| 桔梗 | (0, 0, 0, 0, +) | 金形向上——引导热从顶部排出（"载药上行"） |
| 甘草 | (0, 0, 0, ++, −) | 土形缓冲 |

**银翘散 ΔS = (−−−, +, 0, ++, ++)** ≈ S_火↓↓↓, S_水↑, S_土↑↑, S_金↑↑

SPUM 翻译：强力清热 + 顶部金形排热 + 微开边界散热 + 土形缓冲防止过度。

**对比麻黄汤 ΔS = (+++, +++, −−, ++, +)**：麻黄汤是向上大力推火+水；银翘散是向下拉火+轻开水。方向完全相反。

### 4.3 气分方剂——白虎汤、承气汤

**白虎汤** = 石膏 + 知母 + 甘草 + 粳米

| 药物 | ΔS 贡献 |
|------|---------|
| 石膏 | (−−−−, 0, 0, 0, 0) |
| 知母 | (−−, 0, 0, +, 0) |
| 甘草 | (0, 0, 0, ++, −) |
| 粳米 | (0, 0, 0, +, 0) |

**白虎汤 ΔS = (−−−−−−, 0, 0, +++, −)** ≈ S_火↓↓↓↓↓↓, S_土↑↑↑

SPUM 翻译：极强力清热——相当于在网络中层泼一盆冰水。四大症（大热大渴大汗脉洪大）= 气分的 S_火 超标 + S_土 正在被大量消耗。白虎汤是气分的最强清热方——作用单一但极度集中。

**伤寒的阳明用白虎汤的可能**：伤寒的阳明阶段也是高热——σ 虽然从初始塌陷开始，但阳明化热后网络自身 V⁺ 过度补偿导致 σ 反弹过高。伤寒的阳明 = 网络的 σ 从过低弹到过高——与温病气分在 σ 过冲这点上是相同的状态。因此白虎汤在伤寒和温病中都用于高热阶段——底层的 S 状态相同。

### 4.4 营分方剂——清营汤

**清营汤** = 犀角(水牛角) + 生地 + 元参 + 竹叶 + 麦冬 + 丹参 + 黄连 + 银花 + 连翘

| 药物 | ΔS 贡献 | 作用 |
|------|---------|------|
| 犀角(水牛角) | (−−−, 0, 0, ++, +) | 深入营分清热 + 补充土形 |
| 生地 | (−, 0, 0, +++, 0) | 大量补充土形（深层津液） |
| 元参 | (−, 0, 0, ++, 0) | 清热+补土 |
| 黄连 | (−−, 0, 0, 0, +) | 金形深度清热 |
| 银花连翘 | (−−, +, 0, 0, ++) | 透热转气——将深层 σ 过冲引出到表层 |

**清营汤 ΔS = (−−−−−, +, 0, +++++, ++++)** ≈ S_火↓↓↓↓↓, S_水↑, S_土↑↑↑↑↑, S_金↑↑↑↑

**"透热转气"的 SPUM 含义**：营分的热在深层——直接用白虎汤式强力清热会冲击过深。清营汤的策略是：
1. 金形修剪——清除深层被热灼产生的冗余边（银花连翘黄连）
2. 土形补充——修复被热耗尽的深层储备（犀角生地麦冬）
3. **透热转气**——利用银花连翘的轻清金形操作，将深层的热量沿着水形链向表层传导（"透"），转化为气分的热后再通过常规散热排出（"转气"）

这相当于把深层的一个高 σ 包块"剥开"引导到表面——是一种梯度逆转操作。

### 4.5 血分方剂——犀角地黄汤

**犀角地黄汤** = 犀角 + 生地 + 芍药 + 丹皮

| 药物 | ΔS 贡献 | 作用 |
|------|---------|------|
| 犀角 | (−−−, 0, 0, ++, +) | 深度清热+补土 |
| 生地 | (−, 0, 0, +++, 0) | 大量深层补土 |
| 芍药 | (−, 0, −, 0, +) | 金形收缩+木形软化——止血（金形剪断出血环） |
| 丹皮 | (−, 0, 0, 0, +) | 金形+轻清热 + 微活血（维持微循环不中断） |

**犀角地黄汤 ΔS = (−−−−−, 0, −, +++++, +++)** ≈ S_火↓↓↓↓↓, S_木↓, S_土↑↑↑↑↑, S_金↑↑

SPUM 翻译：这是血分的最深层急救——子图的最深核心正在被热破坏。四个操作同时进行：
1. S_火↓↓↓↓↓ —— 强力制止核心的 σ 继续攀升
2. S_土↑↑↑↑↑ —— 大量补充核心的土形储备（亡阴急救）
3. S_木↓ —— 金形剪断正在断裂出血的木形环（"凉血止血"）
4. 但 S_木 不能降为零——必须维持微循环（"散血"——丹皮保证不全部剪断）

## 五、温病的治疗禁忌

### 5.1 禁汗——温病不可用麻黄汤

> "太阴温病，不可发汗。发汗而汗不出者，必发斑疹……汗出过多者，必神昏谵语。"

| SPUM 翻译 |
|-----------|
| 温病时边界已经 σ 过高、过度开放 |
| 再用麻黄类辛温发汗 = 在过开的边界上继续推高 S_火 + S_水 |
| 结果：σ 过冲加速向内渗透——直接跳过卫分进入营分/血分 |
| "发斑疹" = 深层木形环在高温下断裂——皮下出血 |
| "神昏谵语" = σ 过冲直入核心——干扰自指子图（心神） |

### 5.2 禁下——温病初期不可承气汤

> "阳明温病，下之不通……"

SPUM 翻译：温病气分时确实可能有大便不通——但这是因为高热消耗了肠道水形链上的体积流（津液），链因缺少润滑而堵塞。这不是阳明腑实的"实堵"（有形堵塞），而是"燥堵"（缺水堵塞）。用承气汤（金形强修剪+水形强冲刷）只会加速水形链上的剩余津液流失 → "下之不通"。

### 5.3 三禁原则的 SPUM 统一解释

| 禁忌 | 传统 | SPUM |
|------|------|------|
| 禁汗 | 温病不可辛温发汗 | 边界已过度开放，再推 S_火↑ → σ 过冲直接击穿 |
| 禁下 | 初期不可攻下 | 水形链已缺水，再金形强剪 → 链断裂 |
| 禁利小便 | 不可淡渗利湿 | 土形储备已在消耗，再加速排水 → 土形耗尽 |

三条禁忌的SPUM统一逻辑：**σ 过冲的各阶段，被冲击最深的 S 分量不可再受同一方向的 ΔS 操作——否则叠加效应超出 dv/dt ≤ const 天花板。**
