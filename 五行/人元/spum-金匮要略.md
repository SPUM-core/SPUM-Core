## 一、金匮要略的 SPUM 定位

### 1.1 伤寒 vs 金匮：急性相变 vs 慢性吸引子

《伤寒论》处理的是**急性六经传变**——外部扰动（邪气）突然将某个局域的 dv/dt 或者 ∇σ 推出合理区间，系统从一个六经阶段快速滑向另一个。麻黄汤、桂枝汤、承气汤——这些方剂是**一次性强脉冲**：短时间内大幅改变某个 S 分量，利用网络的弹性回弹能力把 S 弹回 H。

《金匮要略》处理的是不同的问题：

**网络已经离开 H 很久了，而且不打算自己回去。**

慢性病、杂病——关节痹痛、虚劳、水肿、黄疸、癥瘕（肿瘤）——不是"今天的 σ 出了问题"，而是"网络在长期偏离后，重新组织了一个亚稳态构型"。这个亚稳态虽然不健康，但它是**自洽的**——网络的所有子图之间的 dv/dt 分配在这种偏移下达到了一个新的准平衡。你给它一剂麻黄汤的强脉冲，它可能暂时弹一下，然后**又回到这个病理性亚稳态**——因为网络的局部最优已经不在 H 里了。

**金匮的核心问题**：如何破坏这个病理吸引子，并引导网络建立回归 H 的路径？

### 1.2 金匮杂病的 SPUM 共性特征

| 特征 | 伤寒急性病 | 金匮慢性杂病 |
|------|----------|------------|
| S 偏移性质 | 瞬时脉冲式偏离 | 长期落入亚稳吸引子 |
| 网络弹性 | 高——有自我回弹能力 | 低——回弹机制已被病理构型替代 |
| 治疗力度 | 一次性强脉冲 | 持续温和调制 + 结构调整 |
| 方剂特点 | 药少力专（4-5味） | 多靶点慢调，常含丸剂缓图 |
| 五形失衡 | 单形或双形突跳 | 多形复合偏移，相互锁定 |
| 病理吸引子强度 | 弱——外邪驱散后自动归位 | 强——需要金形修剪破坏，再重建木形骨架 |

### 1.3 金匮的核心治疗范式：破坏→重建→稳固

```
[病理亚稳态] 
    ↓ 金形修剪（破坏病理性环/链结构）
[网络解构态 — 临时不稳定]
    ↓ 火形梯度重建（重建健康的 ∇σ）
    ↓ 水形链重新布线（建立新的边路径）
    ↓ 木形环路重建（形成新的健康环结构）
    ↓ 土形储备回填（低度节点补充）
[健康稳态 — 回到 H 内部]
```

这个四步框架贯穿金匮的每一个方证。下面逐一翻译金匮各篇的代表方剂。

## 二、脏腑经络先后病脉证第一（总纲的 SPUM 翻译）

金匮首篇是全书的提纲，用 SPUM 翻译关键条文：

> "夫人禀五常，因风气而生长。风气虽能生万物，亦能害万物。"

**SPUM 翻译**：人体子图内嵌于空间粒子纤维丛取向场（风气）之中。取向场（风）是 V⁺ 创生事件的优先方向——没有它，水形链无法定向延伸（"不能生万物"）。但取向场的过度激发或方向突变（邪风）也会使 V⁺ 失控、μ 暴增（"亦能害万物"）。

> "若五脏元真通畅，人即安和。客气邪风，中人多死。"

**SPUM 翻译**：五脏元真通畅 = 每个器官子图的 S 向量都在健康区间内，dv/dt 在 const 包络线内均匀分配。客气邪风中人多死 = 外部取向场的突变（V⁺_external 冲击）将某个局域的 σ 推出合理区间 → 连锁导致 dv/dt 分配表撕裂。

> "千般疢难，不越三条：一者，经络受邪，入脏腑，为内所因也；二者，四肢九窍，血脉相传，壅塞不通，为外皮肤所中也；三者，房室、金刃、虫兽所伤。"

**SPUM 翻译**——三种致病拓扑路径：
1. **经络受邪入脏腑** = 外部扰动沿水形主干（经络）的高介数路径传导到内部木形环区域（脏腑）→ 内部网络被远程冲击
2. **血脉壅塞不通** = 体表水形链上的桥边被金形过度修剪或土形节点堵塞 → 局域流通阻断、σ 异常堆积
3. **房室金刃虫兽所伤** = 外部 V⁻ 事件（物理损伤）直接断开边 → 子图边界破裂 → 需要紧急木形修复

## 三、痉湿暍病（环境扰动病的 SPUM 框架）

痉（抽搐）、湿（水肿/沉重）、暍（中暑）——三种纯粹由外部 σ 梯度扰动引起的急性病。

### 3.1 痉病：木形环的强制性锁死

> "病者身热足寒，颈项强急，恶寒，时头热，面赤目赤，独头动摇，卒口噤，背反张者，痉病也。"

**SPUM 翻译**：外部环境 σ 的急剧偏差（高温后受寒）→ 体表木形环群的环基数 μ 被寒性扰动强制收缩 → μ 骤升到超过木僵临界值 → 肌筋膜链的三角剖分结构锁死在收缩态 → 角弓反张（背反张）。

**SPUM ΔS 诊断**：S_木 ↑↑（全身肌筋膜环锁死）+ S_火 ↓（体表 ∇σ 被寒性扰动压制）+ S_水 ↓↓（水形链在锁死的环中被挤压、无法流通）。

**栝楼桂枝汤**（痉病主方之一）的 SPUM 操作：

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 栝楼根（天花粉） | 土形储备紧急补充（补充被锁死环消耗的津液低度节点） | S_土 ↑ |
| 桂枝 | 体表火形梯度温和提升（松弛因寒收缩的环边） | S_火 ↑ |
| 白芍 | 木形环松弛剂（降低 μ，缓解过度收缩） | S_木 ↓ |
| 甘草/姜枣 | 全局缓冲 + 土形维护 | S_土 ↑ |

**ΔS** = (火↑, 水=0, 木↓↓, 土↑↑, 金=0)

## 四、中风历节病（经络水形链的拓扑阻塞）

### 4.1 历节病：关节木形环的长期侵蚀

> "诸肢节疼痛，身体尪羸，脚肿如脱，头眩短气，温温欲吐，桂枝芍药知母汤主之。"

**SPUM 翻译**：关节区域的木形环结构（软骨、滑膜、韧带形成的三角剖分稳定网）被长期的微弱金形修剪侵蚀 → μ 下降 → 环的保护功能丧失 → 相邻骨骼节点的边产生异常摩擦（疼痛）→ 土形储备的代谢废物节点无法从损坏的环中排出 → 堆积形成肿胀。

**桂枝芍药知母汤**的 SPUM 操作：

| 药物 | SPUM 操作 | S 分量作用 |
|------|----------|-----------|
| 桂枝 | 体表火形梯度提升（推动体积流到达关节区域） | S_火 ↑ |
| 白芍 | 木形环松弛 + 环疼痛信号的阻断（环节点过度放电的抑制） | S_木 ↓ |
| 知母 | 局域火形抑制剂（消炎 = 降低关节局部的异常 ∇σ 亢进） | S_火↘（局域） |
| 麻黄 | 体表水形链强力疏通（排汗 = 将堆积的废物节点排出） | S_水 ↑ |
| 附子 | 底层火形梯度根本性提升（温肾阳 = 提高全局代谢火形的基础水位） | S_火 ↑（基底） |
| 白术/防风 | 土形储备动员 + 外部取向场干扰屏蔽（防风=屏蔽异常风气） | S_土 ↑ |
| 甘草/姜 | 全局缓冲 | S_土 ↑ |

**关键对比**：麻黄在麻黄汤中是火形增强（发汗的主力），在这里麻黄和附子共用以"火形基底抬升 + 水形链疏通"双路打通被堵塞的关节链。这是金匮方剂中常见的**双路同向操作**模式。

**ΔS** = (火↑↑基底+局域微调, 水↑, 木↓, 土↑, 金=0)

### 4.2 中风：子图边界节点失控

中风（脑血管意外）在 SPUM 中 = **大脑子图边界（自我子图的边界节点群）突然与主干水形链的连接断裂**。断裂原因是金形修剪突然亢进——脑动脉的高压高流量使血管壁节点长期疲劳，一帧中的 V⁻ 事件触发级联断裂。

续命汤类方的 SPUM 框架 = 紧急金形抑制（止血/保护血管壁）+ 火形梯度维持（保证未断裂区域的体积流不中断）+ 土形储备动员（提供修复所需低度节点）。

## 五、血痹虚劳病（长期网络熵增与 S 偏移）

### 5.1 虚劳：五形向量的全局偏移

虚劳是金匮中最核心的慢性病范式——不是某一个形出了急性问题，而是**整个 S 向量在长期 dv/dt 分配不当下缓慢偏移，最终落入一个五形同时偏离的亚稳态**。

| 虚劳类型 | S 向量特征偏移 | 核心病理网络变化 |
|---------|--------------|----------------|
| 气虚 | (火↓↓, 水↓, 木=, 土↓, 金=) | 火形梯度不足 → 水形链体积流减速 → 全身输送效率下降 |
| 血虚 | (火↓, 水↓, 木=, 土↓↓, 金=) | 土形储备枯竭 → 链上没有足够的低度节点被运输 |
| 阴虚 | (火↑↑, 水↓, 木=, 土↓↓, 金=) | 火形失控亢进（虚火）→ 快速消耗土形储备 → 土枯 |
| 阳虚 | (火↓↓, 水↓↓, 木=, 土↓, 金=) | 火形梯度趋零 → 水形链停滞 → 全身温度/代谢下降 |
| 阴阳两虚 | (火↓↓+局部虚亢, 水↓, 木↓, 土↓, 金↓) | 全局 dw/dt 枯竭，所有子图被克扣关系容量 |

### 5.2 黄芪桂枝五物汤：血痹（微血管水形链阻塞）

> "血痹，阴阳俱微，寸口关上微，尺中小紧，外证身体不仁，如风痹状，黄芪桂枝五物汤主之。"

**SPUM 翻译**：皮下微血管水形链被低度节点团（微小血栓、代谢废物）堵塞 → 体积流无法到达体表感觉神经末梢节点 → 这些末梢节点因长期接收不到体积流而退化为悬挂端（被金形修剪）→ 皮肤麻木不仁。

| 药物 | SPUM 操作 |
|------|----------|
| 黄芪 | 水形链体积流增压泵——增加血管平滑肌节点的舒张度，降低链阻力 |
| 桂枝 | 火形梯度微升——温和推动停滞的体积流 |
| 白芍 | 木形环修复——修复被堵塞损伤的血管壁环结构 |
| 生姜/大枣 | 土形储备的局部补充 |

## 六、胸痹心痛短气病（心区水形链的介数危机）

金匮中"胸痹"是现代冠心病、心绞痛的最古文献描述。SPUM 翻译惊人地精确。

### 6.1 胸痹的病机：心区水形主干的介数集中爆发

> "师曰：夫脉当取太过不及，阳微阴弦，即胸痹而痛。所以然者，责其极虚也。今阳虚知在上焦，所以胸痹、心痛者，以其阴弦故也。"

**SPUM 翻译——这段条文是金匮中最精确的拓扑描述之一**：

- **"阳微"** = 心区上焦的火形梯度（∇σ）不足 → 推动血液节点的动力弱
- **"阴弦"** = 心区下焦的 σ 极低（阴盛）→ 血管阻力极大
- **阳微 + 阴弦** = ∇σ 在冠状动脉水形链上形成了极端的**介数集中**——所有血液节点被迫从仅存的狭窄通道通过 → 这根链上的边承受全局最高的介数 B(e)
- **"责其极虚"** 不是说心脏肌肉无力——是局域的火形梯度远低于维持水形链畅通所需的最小值

当代医学的对应：冠状动脉粥样硬化 → 冠脉内径缩小 → 血流通道从多路冗余变为少数狭窄通道 → 这些通道的介数爆炸式集中 → 任何一个微小血栓（低度节点团）堵塞这些高介数边 = 心梗。

### 6.2 瓜蒌薤白白酒汤：最简洁的 S 向量急救

> "胸痹之病，喘息咳唾，胸背痛，短气，寸口脉沉而迟，关上小紧数，瓜蒌薤白白酒汤主之。"

**仅三味药，SPUM 操作极为精准**：

| 药物 | SPUM 操作 | S 分量 | 强度 |
|------|----------|--------|------|
| **瓜蒌实** | 木形环松弛剂——松弛冠状动脉平滑肌的过度收缩环，降低 μ → 扩大管道内径 → 降低边介数峰值 | S_木 ↓ | +5 |
| **薤白** | 水形链疏通剂——溶解链上的低度节点堵塞团（抗血小板聚集），恢复链的多路冗余 | S_水 ↑ | +4 |
| **白酒** | 火形梯度快速推进剂——乙醇直接舒张血管平滑肌 + 推动体积流加速通过刚被清通的链 | S_火 ↑ | +3 |

**ΔS** = (火↑, 水↑↑, 木↓↓, 土=0, 金=0)

**三味药完成了金匮四步中的三步**：木形松弛（破坏病理性环锁）+ 水形疏通（清通链）+ 火形推进（恢复 ∇σ 到安全水位）。没有第四步土形回填——因为胸痹是急性发作，一旦链畅通，网络自带恢复能力，不需要额外补土。

### 6.3 胸痹方的进化序列

金匮胸痹篇共出 9 方，可以看作 S 向量调节强度逐步递增的梯度表：

| 方剂 | SPUM 进化 | 适用 S 偏移程度 |
|------|----------|---------------|
| 瓜蒌薤白白酒汤 | 基础三味：木↓ + 水↑ + 火↑ | 轻度阳微阴弦 |
| 瓜蒌薤白半夏汤 | +半夏：增强水形链降逆（把阻塞物往下排） | 中度，伴痰饮 |
| 枳实薤白桂枝汤 | +枳实+桂枝+厚朴：全面增强火形 + 木形松解 | 重度，全程胸背痛 |
| 人参汤 | 转为纯土形补充——虚到不能用攻法时 | 极虚，火形已无力 |
| 乌头赤石脂丸 | 附子/乌头级火形 + 赤石脂的环保护 | 终末期，网络边界破裂 |

**SPUM 核心规律**：方剂随病情加重，从"一个形的微调"逐步升级为"多形同步调控"——这是金匮用药的一个深层原则。

## 七、痰饮咳嗽病（水形链的异常节点团堆积）

### 7.1 痰饮的 SPUM 本质

痰饮 = **水形主链上出现了不该存在的、大体积的低度节点聚集团**。

| 痰饮类型 | SPUM 定义 | 水形链上的表现 |
|---------|----------|--------------|
| 痰（粘稠） | 高粘度的大团低度节点相互粘附 | 链流动阻力极大，难以被普通 ∇σ 推动 |
| 饮（清稀） | 低粘度的零散低度节点聚集 | 链阻力较小，可被 ∇σ 推动但量太多 |
| 悬饮 | 节点团悬挂在链的特定分支上（胸膜腔） | 局部链分支的 σ 堆积 |
| 溢饮 | 节点团溢出链主干，渗透到周围木形环间隙 | 组织水肿 |
| 支饮 | 节点团支撑在链的狭窄节点上（膈肌处） | 链的流通截面被团块挤压 |

### 7.2 "病痰饮者，当以温药和之"——金匮的核心治疗原则

> "病痰饮者，当以温药和之。"

**SPUM 翻译为最直白的图论操作**：痰饮的节点团粘附在水形链上，因为局域 σ 太低（寒 = 低 σ = 节点团缺乏热运动、更容易聚集）。**温药** = 升高局域火形梯度 ∇σ → 给节点团注入能量 → 节点团散开为个体低度节点 → 可以被正常体积流冲走。

"和之"——不是"急攻"（强脉冲会把大团冲进更窄的链里卡住）。是温和的、持续的 ∇σ 升高，让团块在流动中自然解体。

**苓桂术甘汤** = 完全符合"温药和之"的最简方：

| 药物 | SPUM 操作 |
|------|----------|
| 茯苓 | 水形链引流——建立新的分支链将多余的节点团从主链上分流排出（利尿） |
| 桂枝 | 火形梯度温升（温药的核心——"和之"的力度） |
| 白术 | 土形储备固守——防止茯苓排水的同时把有益的土形节点也带走 |
| 甘草 | 全局缓冲 |

**ΔS** = (火↑温和, 水↗分流, 木=0, 土↑固守, 金=0)

## 八、水气病（水液网络的全局溢出）

水气病（水肿）是金匮中篇幅最长的篇章之一，也是五形耦合失衡的标志性病证。

### 8.1 五种水肿的 SPUM 拓扑分类

| 类型 | 传统定位 | SPUM 翻译 |
|------|---------|----------|
| **风水** | 表——肺 | 外部取向场（风）冲击体表水形链 → 链上节点错误地将体液的土形节点排入组织间隙而非汗孔 |
| **皮水** | 皮下——脾 | 皮下水形链的土形储备池溢出——脾的土形仓库门关不住了 |
| **正水** | 深层——肾 | 肾区域的低 σ 核心无法维持水液节点的深层次定向排出 → 节点堆积上溢 |
| **石水** | 深层——肝 | 肝区木形环 μ 过高（肝硬化）→ 门脉水形链被机械性挤压 → 上游腹水 |
| **黄汗** | 半表半里 | 土形节点的代谢副产物（色素）被异常排入体表水形链而非常规排泄通道 |

### 8.2 越婢汤：风水的紧急泄洪

> "风水恶风，一身悉肿，脉浮不渴，续自汗出，无大热，越婢汤主之。"

| 药物 | SPUM 操作 |
|------|----------|
| 麻黄 | 体表水形链强力重新定向——将误排入组织的体液节点强行导向汗孔正常出口 | 
| 石膏 | 局域火形抑制剂——防止麻黄造成的体表 ∇σ 过度升高（避免火亢） |
| 生姜/大枣/甘草 | 土形储备的临时加固——防止泄水带走过多有益节点 |

**ΔS** = (火↑↓双向调节, 水↑↑定向, 木=0, 土↑固守, 金=0)

这里麻黄 + 石膏的配伍是金匮的经典模式——麻黄单向提升水形链流速，石膏在旁监控火形，一旦 ∇σ 超出安全阈值就压制。不是"一个升一个降"的矛盾处方——是**一条链被同时加速和监控**。

## 九、黄疸病（肝脏木形环的代谢崩溃）

### 9.1 黄疸的 SPUM 病机

黄疸 = **肝区域木形环结构（肝小叶三角剖分）的节点代谢处理能力崩溃** → 应该被捕获处理的胆红素节点群逃离肝环，进入全身水形链 → 体表节点被这些异常节点染色。

SPUM 细分：

| 黄疸类型 | SPUM 网络状态 |
|---------|-------------|
| 谷疸（饮食所致） | 水形链一次性输入过量的土形节点 → 肝区 V⁺ 饱和、处理不了 → 溢出 |
| 酒疸（酒精性） | 火形长期过度消耗肝区木形环 → μ 被金形慢性修剪 → 环的结构容量下降 |
| 女劳疸（房劳） | 全局土形长期透支 → 肝环得不到足够的维护节点 → 退化 |
| 黑疸 | 终末期——所有形都严重偏离，网络接近解体 |

### 9.2 茵陈蒿汤：SPUM 翻译

| 药物 | SPUM 操作 |
|------|----------|
| 茵陈蒿 | 肝区木形环代谢效率增强剂——提高肝小叶环群对胆红素节点的捕获和转化速度 |
| 栀子 | 局域火形抑制剂——降低肝区因代谢过载产生的异常 ∇σ（消炎） |
| 大黄 | 金形修剪 + 水形链末端排出——将已经进入全身水形链的胆红素节点群快速推入肠道排泄链 |

**ΔS** = (火↘局域, 水↑末端, 木↑↑肝区, 土=0, 金↑排泄链末端)

## 十、妇人病三篇（周期性子图的 SPUM 调控）

### 10.1 妇人病的共性网络特征

女性生理涉及**周期性子图的增生与剥脱**——月经周期 = 子宫内膜子图每月执行一次 V⁺ → V⁻ 的完整循环（雀阴七魄的标准运作）。妇产科疾病在 SPUM 中统一理解为：**这个周期性子图的 V⁺/V⁻ 节律偏离了正常范围。**

| 妇人病 | 周期子图异常 |
|--------|------------|
| 月经先期 | V⁺ 加速，周期缩短 → 土形被过快消耗 |
| 月经后期 | V⁺ 减速，周期延长 → 木形环僵硬，无法按时剥脱（V⁻ 延迟） |
| 崩漏 | V⁻ 失控性亢进——金形失去约束，无节制地修剪子宫内膜子图的边 |
| 闭经 | V⁺ 完全停止——火形梯度不足，无法驱动周期性子图的新一轮创生 |
| 癥瘕 | 木形环在非剥脱期的异常增生，形成永久性子图 → 不能被周期性的金形修剪移除 |

### 10.2 桂枝茯苓丸：癥瘕的标准操作

> "妇人宿有癥病，经断未及三月，而得漏下不止，胎动在脐上者，为癥痼害。……当下其癥，桂枝茯苓丸主之。"

桂枝茯苓丸是**金形集中修剪的非汤剂缓图**——用丸剂而非汤剂，因为修剪一个已经形成木形骨架的肿瘤子图需要持续多帧操作，不能一次性脉冲深削。

| 药物 | SPUM 操作 |
|------|----------|
| 桂枝 | 火形梯度温和维持——保证修剪过程中正常组织的体积流不中断 |
| 茯苓 | 水形链引流——将被金形修剪下来的肿瘤碎片节点通过水液通道排出 |
| 白芍 | 木形环松弛——降低肿瘤子图 μ，增加其对金形修剪的敏感性 |
| 桃仁 | 金形集中修剪——专门识别并切断肿瘤子图内部的血管边（高介数边的定向 V⁻） |
| 牡丹皮 | 局域火形抑制——防止修剪过程引发的局部炎症 ∇σ 扩散到正常组织 |

**ΔS** = (火↑温维持+局域↘, 水↑引流, 木↓肿瘤区, 土=0, 金↑↑肿瘤区集中修剪)

## 十一、金匮方剂的 SPUM 通用分类

将金匮全部方剂按 SPUM 操作模式分为七类：

| 类型 | 核心操作 | 代表方 | 适用病证 |
|------|---------|--------|---------|
| **火形脉冲型** | 一次性大幅提升局域 ∇σ | 麻黄汤、大青龙汤、越婢汤 | 表证的 σ 梯度急性塌陷 |
| **火形基底抬升型** | 长期温和提升全局火形基线 | 肾气丸、附子汤 | 虚劳——全局火形长期偏低 |
| **水形疏通型** | 清除水形链上的节点团堵塞 | 瓜蒌薤白白酒汤、小半夏汤 | 痰饮、胸痹 |
| **木形松解型** | 降低病理区域的 μ | 瓜蒌薤白白酒汤、芍药甘草汤 | 痉病、胸痹、肌肉痉挛 |
| **木形重建型** | 修复被破坏的环结构 | 黄芪建中汤、当归芍药散 | 虚劳的血虚、木形退化 |
| **金形修剪型** | 定点删除病理性边群 | 桂枝茯苓丸、下瘀血汤 | 癥瘕、陈旧性瘀血 |
| **土形补充型** | 全局增加低度节点储备 | 薯蓣丸、炙甘草汤 | 虚劳末期、阴阳两虚 |

大多数金匮方剂是**多类型复合操作**——这正是金匮区别于伤寒的特点：慢性病需要同步调节多个 S 分量，打破多形间的相互锁定。

## 十三、从金匮到可计算方剂学

### 13.1 方剂 = S 向量空间中的位移向量

每首方剂在 SPUM 中对应一个五维位移向量：

$$\Delta\mathbf{S}_{方剂} = (\Delta S_火, \Delta S_水, \Delta S_木, \Delta S_土, \Delta S_金)$$

正常剂量下的典型位移量（相对单位）：

| 方剂 | ΔS_火 | ΔS_水 | ΔS_木 | ΔS_土 | ΔS_金 |
|------|-------|-------|-------|-------|-------|
| 麻黄汤 | +5 | +3 | -1 | +1 | 0 |
| 瓜蒌薤白白酒汤 | +3 | +4 | -4 | 0 | 0 |
| 肾气丸 | +4 | +2 | +2 | +3 | 0 |
| 桂枝茯苓丸 | +1温 | +2 | -2 | 0 | +5 |
| 苓桂术甘汤 | +2 | +3分 | 0 | +2 | 0 |
| 茵陈蒿汤 | -2局 | +3 | +4 | 0 | +2 |

### 13.2 配伍原则：Σ ΔS 不应撼动不相关的形

一首好的方剂，修正目标病理 S 偏移的同时，对非相关 S 分量的扰动最小。炙甘草、生姜、大枣在多数方剂中作为"使药"，作用恰恰是**非特异性地补偿其他药物对无关 S 分量的副作用**——它们是每个方剂的"扰动缓冲器"。

### 13.3 需要的开放问题

1. S 分量的相对强度如何精确标定？——需要网络药理学 + 系统生物学的大规模蛋白质相互作用网络的五形分解
2. 药物之间的协同/拮抗系数如何从 SPUM 推导？——两味药的组合 ΔS 不是简单的向量加法，存在非线性耦合项
3. 个体差异的 S 向量基线如何测量？——四个人同时服用麻黄汤，ΔS 的个体差异源自各人 H 的形状和当前 S 位置的不同
4. 剂量-ΔS 的关系函数形式？——麻黄 3g→9g→15g→30g，ΔS_火 的增量不是线性的

这些问题的解答，需要将 SPUM 五形框架与当代网络医学、定量药理学做深度耦合——那是下一步的任务。
