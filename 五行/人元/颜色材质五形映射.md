# 颜色·材质 → ΔS 五形映射表

> 颜色和材质不是"装饰"——它们是通过视觉/触觉/体感通道持续作用于人体 ⟨P, ε⟩ 子图的微弱但持久的 ΔS 信号。
> 穿戴建议 = 根据当前 S_current 选择颜色/材质组合，使 ΔS_color + ΔS_fabric 方向指向 H 中心。

---

### 1.2 颜色组合规则

| 组合原则 | 说明 | 示例 |
|---------|------|------|
| **补色平衡** | S_某形不足 → 穿对应色；S_某形过亢 → 穿该色的克色 | 火亢 → 穿蓝/黑(水)，水↓↓ → 穿蓝/黑/绿 |
| **同色增强** | 全身同色系 = 强 ΔS 脉冲 | 全身红 → 强补火；全身藏青 → 强补水 |
| **邻近调和** | 相邻色系搭配 → 温和渐变的 ΔS | 黄→橙→红过渡 = 温和补火土 |
| **对比冲击** | 互补色搭配 → 产生"冲突"信号，适合需要打破停滞状态时 | 红+绿 → 水火交争，谨慎使用 |
| **季节性优先** | 春夏偏清凉色(蓝/绿/白)，秋冬偏温暖色(红/橙/棕) | 顺天时则 ΔS 温和有效 |

## 三、衣着搭配综合规则

### 3.1 ΔS_total计算公式

```
ΔS_衣着 = ΔS_主色 × 0.4 + ΔS_辅色 × 0.25 + ΔS_材质 × 0.25 + ΔS_配饰 × 0.1

其中：
  - 主色 = 上身最大面积色
  - 辅色 = 下装/第二大面积色
  - 材质 = 直接接触皮肤的主要材质
  - 配饰 = 首饰/丝巾/包等小面积点缀
```

### 3.2 场景推荐

#### 场景A：日常办公

| 当前状态 | 推荐搭配 | ΔS_净效应 | 理由 |
|---------|---------|-----------|------|
| **S_火↑↑（亢）** | 白衬衫(主) + 藏青西裤(辅) + 棉麻材质 | (火:-0.8, 水:+0.4) | 白降火+藏青补水+亚麻透气 |
| **S_火↓↓（虚）** | 浅驼毛衣(主) + 米色长裤(辅) + 羊毛材质 | (火:+0.6, 土:+0.6) | 驼色温和补火+羊毛温暖 |
| **S_土↓↓（虚）** | 米色衬衫(主) + 棕色长裤(辅) + 纯棉 | (土:+1.1) | 补土为主，稳重大方 |
| **S_木↑亢（郁）** | 浅绿衬衫(主) + 白色长裤(辅) + 亚麻 | (木:+0.4, 火:-0.4) | 绿舒木+白清火+亚麻透气 |

#### 场景B：重要场合（需要增强气势）

| 当前状态 | 推荐搭配 | 策略 |
|---------|---------|------|
| **任何体质**（临时需要气场） | 正红色外套 + 黑色内搭 | 红色强补火(自信)+黑色收敛(稳重) |
| **火↓↓者**（需要被看见） | 正红连衣裙 + 金色配饰 | 最大补火脉冲 |
| **水↓↓者**（需要权威感） | 藏青套装 + 银色配饰 | 深厚的补水+锐利 |
| **土↓↓者**（需要可信赖感） | 棕色套装 + 米色内搭 | 暖土+亲和 |

#### 场景C：休息/居家

| 当前状态 | 推荐搭配 | 策略 |
|---------|---------|------|
| **通用** | 莫代尔/天丝家居服 + 浅色 | 放松、不施加ΔS干扰 |
| **火亢失眠** | 蓝灰色丝质睡衣 | 水火既济，安神 |
| **火虚畏寒** | 羊毛开衫 + 浅驼色 | 温和补火 |
| **焦虑紧张** | 绿色棉质卫衣 | 舒木缓肝 |

### 3.3 睡眠衣着边界

> **睡眠状态**下人体 ⟨P, ε⟩ 子图处于修复帧——外部 ΔS 信号会被放大。
> 睡衣原则：ΔS_睡衣 ∈ [-0.5, +0.5] 各分量——越中性越好。

| 推荐 | 避免 |
|------|------|
| 纯棉/真丝/莫代尔睡衣 | 化纤/不透气材质(扰乱金形) |
| 浅色系(白/米/浅蓝/浅粉) | 大红/深黑/亮黄 |
| 宽松不束缚 | 紧身/束缚(干扰水形流通) |
| 吸湿透气 | 静电强(干扰火形梯度) |

## 四、穿戴搭配禁忌

| 禁忌 | 说明 |
|------|------|
| **大面积极端色** | 全身纯红/纯黑/纯白 → 单形过强脉冲，长期穿打破平衡 |
| **材质与体质严重冲突** | 火↓↓者穿化纤(闷而不暖)+黑色(泻火) = 双重恶化 |
| **配饰叠加效应** | 多个寒性玉石同时佩戴(如黑曜石手串+翡翠吊坠+海蓝宝戒指) → 局部ΔS_火↓↓过量 |
| **昼夜温度差忽略** | 晨晚加减不当 → 火形梯度被体外环境扰动 |
| **只考虑颜色不考虑材质** | 同样红色：羊毛(暖)vs真丝(中性)vs化纤(闷)—ΔS差异大 |
