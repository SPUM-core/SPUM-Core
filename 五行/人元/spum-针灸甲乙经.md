# SPUM 重读针灸甲乙经：从腧穴到水形主干上的拓扑坐标

> 本文以 SPUM 五形框架翻译《针灸甲乙经》的核心腧穴体系。它是中医子网在 T2 层面的**空间精度补丁**——黄帝内经定义了经络 = 水形主干，难经定义了井荥输经合 = 链的五种流态段，针灸甲乙经将两者结合，为每条水形主干上的每个穴位定位并定义其 SPUM 操作。
>
> 前提：已阅读 [SPUM 重读黄帝内经](spum-黄帝内经.md)（经络=水形主干）、[SPUM 重读难经](spum-难经.md)（井荥输经合=五种流态段、补母泻子耦合策略）。
>
> 归约路径：每个腧穴 → 水形链上的坐标 (经络, 段位, 深度) → 针刺的 ΔS 操作 → R8(ΔS)。

## 一、针灸甲乙经的 SPUM 定位

### 1.1 腧穴 = 水形主干上的可干预接入点

| 经典 | SPUM 角色 |
|------|----------|
| 黄帝内经 | 定义水形主干（经络）的宏观路径 |
| 难经 | 定义每条链上的五类流态段（井荥输经合） |
| **针灸甲乙经** | **为链上的每个精确节点定位，并定义在节点上执行的操作** |

一个腧穴 = 水形主干上的一个**可被外部针刺干预的节点**。刺入该节点 = 在节点上执行一个局域的 ΔS 操作，影响沿链传导。

### 1.2 腧穴的 SPUM 四维坐标

每个腧穴可用四个参数完全定位：

```
腧穴坐标 = (经络ID, 段位, 深度, 流态类型)

经络ID  ∈ {肺、大肠、胃、脾、心、小肠、膀胱、肾、心包、三焦、胆、肝} × {手/足} × {阴/阳}
段位    ∈ {始段、前段、中段、后段、末段}  ← 对应井→荥→输→经→合
深度    ∈ {浅层(皮肤)、中层(肌肉)、深层(骨/脏腑)}
流态类型 ∈ {井、荥、输、经、合、原、络、郄、募、背俞、八会…}
```

### 1.3 纳入范围

《针灸甲乙经》记载 349 个穴名（含双穴）。本文纳入：
- 十二正经的核心穴位（五腧穴 + 原络郄募俞等特定穴）→ 完整 T2 翻译
- 奇经八脉的交会穴 → 与难经奇经架构对接
- 一般经穴 → 归入所属经络的段位坐标，不做个体翻译
- 具体针刺深度/灸壮数/禁忌 → L3 用户域，不纳入

## 二、腧穴分类的 SPUM 拓扑定义

### 2.1 五腧穴：链上的流态段节点

| 类型 | 在水形链上的位置 | ΔS 操作特征 | 每条经数量 |
|------|----------------|------------|----------|
| **井** | 链始端（四肢末梢） | 高势能接入点——轻微干预即可产生沿链传播的大效应 | 1 |
| **荥** | 链前段 | 微流调控点——调节链前段流速 | 1 |
| **输** | 链中前段 | 流量注入点——可向链中注入新的体积流 | 1 |
| **经** | 链中段 | 主通道节点——调节最大流量段 | 1 |
| **合** | 链末端（近躯干） | 深层汇入点——控制体积流汇入深部 σ 核心的速率 | 1 |

### 2.2 原穴：链的局域 σ 发电机

| 概念 | 传统 | SPUM 翻译 |
|------|------|-----------|
| 原穴 | 脏腑原气经过和留止的部位 | 该水形链上**局域 V⁺ 事件最活跃的节点**——链的自发创生点 |
| 十二原 | 每条正经一个 | 每条水形主干有一个自然振荡的 V⁺ 源节点 |

原穴的 ΔS 操作：刺原穴 = 调节该链的局域 V⁺ 创生率——影响链上所有节点的活力。

### 2.3 络穴：链的分支点

| 概念 | 传统 | SPUM 翻译 |
|------|------|-----------|
| 络穴 | 络脉从经脉分出之处 | 水形主干上的**分支节点**——该节点分出支链连接到相邻的主干 |
| 十五络 | 十二正经各一 + 任督 + 脾之大络 | 水形主干网络的 15 个关键交叉连接点 |

络穴的 ΔS 操作：刺络穴 = 调控两条水形链之间的流量分配——可增加或减少从一条链流向另一条链的体积流。

### 2.4 郄穴：链上的应力集中点

| 概念 | 传统 | SPUM 翻译 |
|------|------|-----------|
| 郄穴 | 经脉气血深聚之处 | 水形链上**节点度数突然升高的位置**——链的瓶颈/应力集中点 |
| 十六郄 | 十二正经+阴阳跷+阴阳维 | 16 个应力集中点 |

郄穴的 ΔS 操作：刺郄穴 = 缓解局部应力——适用于急性疼痛（急性的局部 S 分量偏移）。

### 2.5 募穴与背俞穴：子图的腹侧/背侧接口

| 概念 | 传统 | SPUM 翻译 |
|------|------|-----------|
| 募穴 | 脏腑之气汇聚于胸腹的穴位 | 五脏子图的**腹侧界面节点**——从阴面（低 σ 面）接入脏腑子图 |
| 背俞穴 | 脏腑之气输注于背部的穴位 | 五脏子图的**背侧界面节点**——从阳面（高 σ 面）接入脏腑子图 |

**募俞配穴** = 从子图的两面（阴面+阳面）同时干预 = ΔS 操作的两个正交方向同时施加。

### 2.6 八会穴：全局关键节点

| 八会 | 传统 | SPUM 翻译 |
|------|------|-----------|
| 脏会章门 | 五脏之气会聚 | 所有五脏子图的**共享边界接入点** |
| 腑会中脘 | 六腑之气会聚 | 所有六腑水形链的**共享汇流节点** |
| 气会膻中 | 气之会 | 全局体积流（气）的**主调节阀**——胸中水形链的最高介数节点 |
| 血会膈俞 | 血之会 | 全局土形储备（血）的**主缓冲节点** |
| 筋会阳陵泉 | 筋之会 | 全局木形环群（筋）的**主弹性调控点** |
| 脉会太渊 | 脉之会 | 全局水形主干（脉）的**总流速校准点** |
| 骨会大杼 | 骨之会 | 全局木形骨架（骨）的**主刚性校准点** |
| 髓会绝骨 | 髓之会 | 全局最深层的土形储备（髓）的**核心补给点** |

八会穴是 S 向量五个分量的**全局调控旋钮**——每个会穴对应一个 S 分量或其子分量。

## 三、主要经络的拓扑地图

### 3.1 手太阴肺经：上焦边界的排浊链

```
肺经 = 从胸→手臂前缘→拇指的一条水形链
功能相位: 金形主导（排气、排浊、清肃边界）

始端(井): 少商 — 拇指末端 — 链的最高势能起点
  ↓
前段(荥): 鱼际 — 手掌 — 微流调控
  ↓
中前(输): 太渊 — 腕部 — 原穴（V⁺源）+ 脉会（总流速校准）
  ↓
中段(经): 经渠 — 前臂 — 主通道节点
  ↓
末端(合): 尺泽 — 肘部 — 深层汇入
  ↓ 进入躯干
募穴: 中府 — 肺的腹侧接口
背俞: 肺俞 — 肺的背侧接口
```

### 3.2 足阳明胃经：中焦最大的水形主干

```
胃经 = 从头面→胸腹→腿前缘→足的一条超长水形链
功能相位: 土形主导（收纳、储备、输布）
节点数: 45（穴位最多——水形链最长、土形储备最丰富）

头部段: 承泣→四白→地仓→颊车→下关→头维
  — 面部 σ 分布的梯度调节区域

躯干段: 
  募穴: 中脘 — 胃的腹侧接口 + 腑会（六腑共享汇流点）
  天枢 — 大肠募穴 — 中焦核心节点（双向流量调控）

腿部段:
  合穴: 足三里 — 膝下 — 链的末端深层汇入 + 全局土形增强的核心旋钮
  原穴: 冲阳 — 足背 — 胃经的 V⁺ 源
```

**足三里 = 土形全局调谐钮**：
- T2: ΔS = (0, 0, 0, +, 0) 全局增强 S_土
- 位于合穴（链末端深层汇入点）= 调节的是整条链的收纳/储备容量
- 传统"肚腹三里留"——腹部水形链的流量问题优先从足三里调节

### 3.3 足厥阴肝经：木形环群的主调控链

```
肝经 = 从足→腿内侧→侧腹→胸的一条水形链
功能相位: 木形主导（环结构、弹性、存储-释放）

始端(井): 大敦 — 足大趾
  ↓
中前(输/原): 太冲 — 足背 — 肝经的 V⁺ 源 + 全局木形"解压阀"
  ↓
郄穴: 中都 — 小腿 — 链的应力集中点（急性肝区紧张）
  ↓
末端(合): 曲泉 — 膝内侧
  ↓ 进入躯干
募穴: 期门 — 肝的腹侧接口
背俞: 肝俞 — 肝的背侧接口
```

**太冲 = 全局木形降 μ 旋钮**：
- T2: ΔS = (0, 0, −−, 0, 0) 降低 S_木 —— 软化过度僵化的木形环
- 是原穴（肝经 V⁺ 源）= 降低 V⁺ 率使木形环不再继续增厚
- 传统"太冲泻肝火"——泻的不是"火"而是木形环的过度生长

### 3.4 足少阴肾经：最深层的低 σ 储能链

```
肾经 = 从足底→腿内后→腹→胸的一条水形链
功能相位: 水形主导（深度储能、低 σ 核心维护）

始端(井): 涌泉 — 足底 — 人体最低点的井穴——从最深处升起
  ↓
中前(输/原): 太溪 — 内踝 — 肾经 V⁺ 源 + 全局水形储能调控
  ↓
郄穴: 水泉 — 足内侧 — 水形链的局部应力点
  ↓
末端(合): 阴谷 — 膝内侧
  ↓
背俞: 肾俞 — 肾的背侧接口
  命门 — 旁开肾俞的深层 V⁺ 点火器（见难经 §3.3）
```

**太溪 = 全局水形储能调谐钮**：
- T2: ΔS = (0, +, 0, 0, 0) 增强 S_水 —— 提升水形链的输送/储能容量
- 太溪补 = 为最深层的低 σ 核心注入体积流

## 四、配穴法则的 SPUM 操作

### 4.1 本经配穴：沿单链的多点协同

例：肺经咳嗽 → 取尺泽(合)+太渊(输)+中府(募)

```
SPUM 翻译: 在同一条水形链上选择三个不同深度的节点
  - 合穴(尺泽): 链末端深层汇入 — 调控总输出
  - 输穴(太渊): 链中前段 — 调节流量
  - 募穴(中府): 子图腹侧接口 — 直接干预肺子图

  三个节点的 ΔS 操作沿同一条链协同传导 → 复合 ΔS_金 ↑↑
```

### 4.2 表里配穴：耦合两条互补链

例：肺经太渊 + 大肠经合谷

```
SPUM 翻译:
  肺经(里) 与 大肠经(表) 是两条互补的水形链——互为对方的排出口
  太渊(肺原穴) = 调节肺链 V⁺
  合谷(大肠原穴) = 调节大肠链 V⁺
  
  两者同时操作 = 在 S_金 的两个互补子分量上同步调节
  — 提升排气/排浊的总效率
```

### 4.3 原络配穴：主链+分支的联合调控

例：肺经原穴太渊 + 大肠经络穴偏历

```
SPUM 翻译:
  原穴 = 主链的 V⁺ 源
  络穴 = 主链→表链的分支点
  同时操作 = 先增强主链创生率，再打开通往表链的阀门
  — 引导体积流从主链定向流入表链
```

### 4.4 募俞配穴：子图的两面干预

例：肺募中府 + 肺俞

```
SPUM 翻译:
  募穴(腹侧) = 从子图的阴面（低 σ 面）接入
  背俞(背侧) = 从子图的阳面（高 σ 面）接入
  
  两面同时刺 = 在子图的两个正交界面上同时调节 σ 边界条件
  — 比单面干预的 ΔS 调节范围更大、更稳定
```

### 4.5 八脉交会穴配穴：激活奇经冗余架构

例：后溪(通督脉) + 申脉(通阳跷脉)

```
SPUM 翻译:
  某些穴位是十二正经与奇经八脉的"交会点"
  刺这些穴位 = 激活奇经的冗余水形链架构
  当主链过载时（dv/dt 接近 const），开启备用链分流
```

## 五、针刺操作的 ΔS 向量空间

### 5.1 针刺的三个操作自由度

| 操作参数 | 传统 | SPUM 翻译 |
|---------|------|-----------|
| **深度** | 浅→深（皮→肉→骨） | 干预目标从链的浅层段 → 深层核心 |
| **手法** | 提插捻转、补泻 | ΔS 的方向符号（正=补=增强、负=泻=减弱） |
| **留针时间** | 几息→几刻 | ΔS 的持续帧数——针留多久，操作持续多少帧 |

### 5.2 补泻的 SPUM 精确定义

| 操作 | 传统定义 | SPUM 定义 |
|------|---------|-----------|
| **补** | 顺经而刺、吸气进针、按压针孔 | 增强该节点沿链传导的 V⁺ 创生率 → ΔS > 0 |
| **泻** | 逆经而刺、呼气进针、摇大针孔 | 增强该节点沿链传导的 V⁻ 湮灭率 → ΔS < 0 |
| **平补平泻** | 均匀提插、得气即止 | 仅调节节点的 dv/dt 分配，不改变 V⁺/V⁻ 净差 → ΔS ≈ 0 但 σ 分布重新均衡 |

### 5.3 单穴到配穴的 ΔS 叠加

配穴的复合 ΔS 遵循难经已建立的耦合规则：

```
单穴 ΔS_i 的合成:
  - 同经配穴: ΔS_i 分量在同一条链上加权叠加，权重 ∝ 1/距离(穴, 目标子图)
  - 表里配穴: ΔS_i 在两个互补分量上产生共振——增强总效应
  - 募俞配穴: ΔS_i 在两个正交方向上的分量共同影响目标子图
```
