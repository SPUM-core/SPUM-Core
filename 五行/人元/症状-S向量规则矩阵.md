# 症状 → S 向量规则矩阵

## 格式说明

### 向量编码

每条症状映射为一个五维 S 向量 **s = (木, 火, 土, 金, 水)**，每个分量取值：

| 数值 | 原标注 | 意义 |
|------|--------|------|
| -3 | ↓↓↓ | 严重不足/枯竭 |
| -2 | ↓↓ | 明显不足 |
| -1 | ↓ | 轻度不足 |
| 0 | ↔ | 正常/无影响 |
| +1 | ↑ | 轻度亢进/有余 |
| +2 | ↑↑ | 明显亢进/壅盛 |
| +3 | ↑↑↑ | 极度过剩/暴冲 |

### 特殊修饰符

某些映射需要附加修饰符以区分性质不同的同类偏移：

| 修饰符 | 意义 | 示例 |
|--------|------|------|
| `虚浮` | 表面上亢但本质因虚 | S_火=+1虚浮（虚火） |
| `壅滞` | 量过多但通路堵塞 | S_土=+2壅滞（土太多堵住） |
| `异常` | 偏亢但属病理性（非正常增强） | S_水=+1异常（痰湿/水饮） |
| `悖论` | 并非简单亢/弱，而是结构矛盾 | S_木=+1悖论（环亢但内容空虚） |
| `代偿` | 看似正常/偏亢但本质是代偿 | S_土=+1代偿（土貌似旺实则累） |
| `暴冲` | 急性剧烈偏移后可能崩塌 | S_火=+3暴冲（DKA机制） |
| `后遗` | 急性事件后遗留的偏移 | S_金=+2后遗（虫类药切割后） |
| `淤滞` | 通路阻塞但量不一定少 | S_水=-1淤滞（水链堵而非空） |

### 编码优先级

当同一条症状在不同病案中出现不同映射时，规则矩阵取**最高置信度的映射**，并在备注中注明变异来源。

## 复合症状权重规则

多条症状同时出现时，S 向量按加权投票计算。以下为四份病案验证过的复合模式：

### 模式 P-01：因壅致虚（CASE-001 核心模式）

```
必现组合：
  S-A05 精神不振          → 火=-2
  S-A07 胃纳一般/腹胀     → 土=-2
  S-B04 腹部赘肉          → 土=+2壅滞  ← 关键鉴别点
  S-B05 舌下青筋          → 金=+2后遗, 水=-1淤滞

加权结果：
  火 = -2（单一来源）
  土 = (-2 + -2 + +2壅滞) / 3 → 均数 ≈ -0.67
       但壅滞修饰符标记 + S-B04 物理证据
       → 最终判定：壅滞性↓↓↓（非单纯枯竭）
  金 = +2（单一来源）
  水 = -1（单一来源）

鉴别诊断：
  - 无 S-B08 消瘦（BMI正常或偏胖）           → 排除纯虚枯竭
  - 有 S-B04 腹部赘肉                        → 确认壅滞
```

### 模式 P-02：纯虚枯竭（CASE-002 核心模式）

```
必现组合：
  S-A11 食欲不振/无食欲     → 土=-3
  S-A12 饥饿但早饱          → 土=-3      ← 核心鉴别点
  S-B08 消瘦（BMI≤18.6）    → 土=-3      ← 物理投影
  S-A05 精神不振            → 火=-2
  S-A15 凌晨3时醒           → 木=+1悖论

加权结果：
  土 = (-3 + -3 + -3) / 3 = -3（一致枯竭）
  火 = -2
  木 = +1悖论

鉴别诊断：
  - 有 S-B08 消瘦（BMI≤18.6）               → 确认纯虚
  - 无 S-B04 腹部赘肉                        → 排除壅滞
  - 无 S-B05 舌下青筋                        → 排除淤滞
```

### 模式 P-03：实壅（CASE-003 核心模式）

```
必现组合：
  S-B11 肥胖（BMI≥30）       → 土=+2壅盛  ← 核心鉴别点
  S-A23 打鼾极响/窒息        → 土=+2壅, 水=+1异常
  S-A28 胃口好不挑食         → 土=+1代偿
  S-B12 面色灰暗             → 水=-2, 火=-1

加权结果：
  土 = (+2 + +2 + +1代偿) / 3 ≈ +1.67 → ↑↑壅盛
  水 = (+1异常 + -2) / 2 = -0.5 → 被土困
  火 = -1
  木 = 0（无直接症状但八字显示↓↓↓）

鉴别诊断：
  - S-B11 BMI≥30                           → 确认实壅
  - S-A28 胃口好                           → 代偿功能尚可（非虚）
  - 无 S-B08 消瘦                          → 排除纯虚
```

### 模式 P-04：阴虚火旺+医源性创伤（CASE-004 核心模式）

```
必现组合：
  S-A38 长期糖尿病史          → 水=-2
  S-A34 怕热                 → 火=+1虚亢
  S-A39 急躁/过度敏感         → 木=+1郁, 火=+1虚亢
  S-A40 DKA史（温补诱发）     → 火=+3暴冲史, 水=-2

加权结果：
  水 = (-2 + -2) / 2 = -2
  火 = (+1虚亢 + +1虚亢) / 2 = +1虚亢（叠加暴冲史警告）
  木 = +1郁

鉴别诊断：
  - S-A40 DKA史（温补诱发）                 → 关键鉴别：禁用温补
  - 无 S-B04 腹部赘肉                      → 排除壅滞
  - 无 S-B11 肥胖                          → 排除实壅
  - 无 S-B08 消瘦                          → 排除纯虚枯竭
```

## 使用说明

### 正向推理（症状→S向量）流程

```
输入：症状集合 {s₁, s₂, ..., sₙ}
   ↓
Step 1：逐条查表，获取每个症状的 sᵢ 向量
   ↓
Step 2：按类别内置信度加权平均（置信度：极高×1.0 / 高×0.8 / 中×0.5 / 低×0.2）
   ↓
Step 3：跨类别按固定权重融合
  问诊类别平均 × 0.40
+ 望诊类别平均 × 0.30
+ 切诊类别平均 × 0.20
+ 闻诊类别平均 × 0.10
= 最终 S 向量
   ↓
Step 4：检查复合模式匹配（P-01~P-04）
  → 若匹配某模式 → 按该模式修饰符修正最终向量
   ↓
输出：S = (木, 火, 土, 金, 水) + 修饰符标记
```

### 反向推理（S向量→预期症状）

1. 输入：当前 S 向量
2. 查找各分量显著偏离（|分量| ≥ 2）对应的模式
3. 输出：该 S 向量下最可能出现的症状集
4. 用于：预警系统（S 偏离→预测即将出现的症状）

### 规则扩展协议

- 每经一份新病案验证后，将新规则追加到对应类别末尾
- 已有规则如有冲突，新规则作为"变异分支"标注，不覆盖原规则
- 规则达到 200 条时需进行一致性审核（生克关系自洽性检查）

### 逐分量计算

**S_木**：所有规则中均无木偏移 → **0 (↔)**

**S_火**：
- 问诊：A05(-2) + A06(-2) + A10(-1) → 均值 = -1.67

- 闻诊：无 → 0
- 融合：-1.67×0.4 + -1.0×0.3 + -1.5×0.2 + 0×0.1 = **-1.27 → ↓↓** ✓

**S_土**：
- 问诊：A01(-2) + A07(-2) + A08(-1) → 均值 = -1.67
- 望诊：B01(-2) + B02(-1) + B04(+2壅滞) → 均值 = -0.33（含壅滞修饰符）
- 切诊：C02(-2) + C03(-1) → 均值 = -1.5

  → 匹配 P-01 模式（有腹部赘肉 B04 = 壅滞标志）
  → 最终判定：**壅滞性↓↓↓** ✓

**S_金**：
- 望诊：B05(+2后遗) → 2.0
- 融合：2.0×0.3 = **0.6 → ↑↑** ✓

**S_水**：
- 问诊：A01(-2) + A03(+1异常) + A08(+1异常) → 均值 = 0
- 望诊：B03(+1异常) + B05(-1淤滞) → 均值 = 0
- 切诊：C02(-1) → 均值 = -1.0
- 融合：0×0.4 + 0×0.3 + -1.0×0.2 = **-0.2**
  → 但修饰符标记（异常+淤滞）提示并非"正常"
  → 综合判定：**↓↓ + 局部淤滞** ✓

### 验证结论

| 分量 | 规则矩阵输出 | 原始诊断 | 匹配 |
|------|------------|---------|------|
| S_木 | ↔ | ↔/↑突发（生气时） | ✓（基线一致） |
| S_火 | -1.27 → ↓↓ | ↓↓ | ✓ |
| S_土 | 壅滞性↓↓↓（P-01模式匹配） | 壅滞性↓↓↓ | ✓ |
| S_金 | +2后遗 → ↑↑ | ↑↑ | ✓ |
| S_水 | ↓↓ + 局部淤滞 | ↓↓ + 局部淤滞 | ✓ |

**回测通过。** 规则矩阵可完整还原 CASE-001 的五维 S 向量诊断。
修饰符系统（壅滞/后遗/异常/淤滞）对鉴别诊断至关重要——纯数值融合不足以区分"壅滞性↓↓↓"与"纯虚↓↓↓"。
