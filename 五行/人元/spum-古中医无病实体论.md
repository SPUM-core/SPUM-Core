- 营养物质循环通畅
- 系统有自我修复能力
- 偶尔有外来物种进入，但被稳态系统自然排出

失衡 = 生态被破坏。在这个状态下：

- 某一种群过度繁殖（比如炎症因子失控）

- 食物链断裂（比如脏腑生克失常）
- 外来物种趁虚而入（比如病原体在弱态宿主身上致病）

**关键区别来了：**

## 五、西医和中医，到底差在哪里？——一个"抓东西"，一个"看状态"

### 5.1 西医的思维：先找到那个"东西"

```
看见症状 → 检查 → 发现一个"东西"（肿瘤、细菌、炎症、指标异常）→ 给这个"东西"取个名字 → 用药物或手术把这个"东西"干掉
```

核心就一句话：**所有的病，都是一个"东西"。** 这个"东西"在你身体里，医生的工作就是找到它、消灭它。

但问题来了：当这个思维被搬到慢性病、代谢病、免疫病上的时候，它悄悄地从"发现实体"变成了**"发明实体"**。

**"疾病实体"不是科学发现——它是制药工业运转的前提假设。** 没有"实体"，就没有"靶点"；没有"靶点"，就没有"专利药"；没有"专利药"，就没有利润。整个现代医疗体系的商业闭环，建立在"每一种不舒服背后都有一个对应的'东西'"这个假设上。


**先有失衡，后有症状，最后才有"病名"。病名只是标签，不是本体。**

```
假设存在一个"病实体"（如"高血压"）
→ 招募一群被诊断为"高血压"的患者
→ 随机分为两组，一组用药一组用安慰剂
→ 测量血压变化
→ 得出结论：药物 A 对"高血压"有效
```

这条链条的逻辑是自洽的——如果"高血压"真的是一个同质群体的话。

现在把中医放进这套体系：

```
中医认为：不存在"高血压"这个同质群体，只有肝阳上亢型S_火↑↑、阴虚阳亢型S_水↓↓S_火↑、痰湿中阻型S_土壅……多种不同的失衡状态
→ 按中医的标准，应该先按证型分组，每个证型单独验证
→ 但问题是：没有人给"证型分组"开发过标准化工具
→ 没有标准化的证型定义 → RCT 无法入组 → 中医通不过
```

**RCT 不是"错了"——它是不适用于中医的验证需求。** 就像一把手术刀，用来切肿瘤很好，但你不能用它来种花。

这就好比：修理工有一把扳手，园丁需要一把铲子。修理工的扳手很好用——拧螺丝又快又准。但你让园丁也用扳手种花——园丁种不了不是扳手的问题，是工具和场景不匹配的问题。

**中医需要的不是一个"替代RCT"的东西——它需要一套与自己的范式匹配的验证方法论。** SPUM 的 S 向量系统（§8）就是在做这件事：给每个证型一个可记录的数值坐标，让"按证入组"第一次有了可操作的定义。

### 6.2 "八字"还没有进入监管的编码体系——不是因为它是错的

SPUM 的青囊临床体系，有一条核心输入：**排八字算 S₀**。

如果你出生在乙木日干、辛未月、双未土埋木——SPUM 系统会告诉你：你的 S_木先天偏弱，在土旺的流年容易出现壅虚共轭的失衡。

这套逻辑在 SPUM 框架内是确定性的：输入出生时间 → 推出五行分布 → 映射为 S₀ 向量 → 进入体质坐标系统。每一步都是可计算、可复现的。

但现实是：这套流程在现行的监管体系里找不到任何对应编码。"排八字"在目前的医疗分类里是空白的——不是因为它被定性为"封建迷信"，而是因为**监管体系从来没有为"基于生辰的体质分类"设计过任何通道。**

两件事做的是一样的：
- **排八字** = 根据出生时间计算天干地支五行分布 → 古典体质分类学
- **种族/年龄/BMI/家族史** = 根据人口统计学计算疾病风险 → 现代循证医学

只不过一套用了天干地支作为编码体系，一套用了人口统计学变量。区别不在于哪个"更科学"——在于哪个已经被编码进了现有的监管体系。**一个没有被编码的变量，在系统中就不存在。这不是偏见——这是系统的不完整。**

### 6.3 现行监管体系下的不对位

当前中国对中医药的管理，面临的核心问题不是"压制"，是"不对位"：

| 监管环节 | 现有要求 | 对中医的影响 |
|---------|---------|------------|
| 药品注册 | 按 RCT 提供临床有效性证据 | 中药被迫按"病名"做试验，证型灵活性被简化 |
| 医院评审 | 按西医科室设置标准考核 | 中医诊断难以纳入现有科室编码 |
| 职称评审 | 论文要求（SCI 优先） | 中医师发表的大部分中医论文不被认可 |
| 医保目录 | 按"病种"报销 | 中医"调态"服务无法编码为可报销项目 |
| 教育体系 | 中西医课程7:3 | 中医本科生花了70%时间学西医 |
| 法律地位 | 非主流认知没有分类通道 | 八字、五运六气、择时服药等没有注册路径 |

这个表反映的不是"有人在消灭中医"——**它反映的是一个不争的事实：现有的医疗管理体系，从底层编码逻辑开始，就是为"疾病实体"范式设计的。** 中医的"状态范式"在这里找不到对应的接口。

这就好比你有一套为 MP3 设计的播放系统——它播 MP3 播得很好。但你现在想播 FLAC 格式。FLAC 本身没有错，MP3 系统也没有错——错的是没有人给这套系统装一个 FLAC 解码器。

### 6.4 为什么不能把 RCT 当作唯一标准

这不是在否认双盲实验的价值——它在验证特定化学分子对特定生理指标的效果上，是一个有效的工具。

但"一个好工具"和"唯一的金标准"之间，差了一个关键的认知跳跃：

- **工具**：RCT 能回答"这个药对某个指标有没有影响"
- **唯一标准**：暗示"只有能通过 RCT 验证的治疗才是有效的"

那个跳跃就是——把一个特定范式下的验证工具，提升为所有范式的通用标准。问题不出在 RCT 本身——出在它是**唯一**的标准。

如果说服不了你，看这个逻辑：如果"五行"不是真实存在的网络拓扑，SPUM 的 135 个测试不可能全部通过（90%以上逻辑覆盖率）。一个"封建迷信"的概念，不可能在确定的数学框架下产生可复现的结果。这至少说明：**中医的范式可以在自身框架内被严谨地验证——只是这个验证方式和 RCT 不一样。**

### 6.5 必须承认：中医确实没有清晰的标准——这是它自己的短板

（此节保持原内容不变——它说的是真话，调性也是建设性的自省）

中医没有标准化的诊疗规范。这不是监管体系加的——这是中医自身几千年没有解决的问题。同一个患者，给三个不同的中医师看，可能开出三张完全不同的方子。有时候这三张方子都是对的（同病异治，殊途同归），但更多时候其中确实有两张是错的。因为没有统一的标准，错的也无法被界定。

更致命的是法律层面：没有标准，就没有医疗事故的判定依据。一个西医如果误诊，有明确的操作规范可以对照——有没有按指南做、有没有该检查没检查。中医呢？同一个证，张医师说用麻黄汤，李医师说用桂枝汤——谁是对的？没人能回答。**不是"中医不能判断对错"——是"判断对错的标准没有建立"。**

这是中医复兴路上必须自己跨过的一道坎。你不能一边要求监管体系承认你，一边连"什么是对的"都说不清楚。

SPUM 的 S 向量就是在尝试回答这个问题——给中医一套可记录、可对比、可复现的描述语言，让"判断一个医师做对了还是做错了"这件事，第一次有了一个可以讨论的基础。不是替代中医的辨证思维，而是给辨证思维一个能被"看到"的形式。

### 6.6 以上说了这么多——核心只有一句话

**体系没有错，错的是没有更好的体系。**

现有的医疗管理体系对它的范式来说，运作得非常好。RCT、药品注册、医保编码——在一套"疾病实体"的前提下，它们是有效的。

问题是：当我们需要一个不同的范式时，没有人给这个新范式修过路。

## 七、正本清源——古中医的五个核心回归

批判不是目的。看清了问题，接下来是重建。古中医从来不缺智慧，缺的是把它从历史的灰尘中重新拿出来、用当代人听得懂的语言说清楚。

下面五条，是古中医回归正道的核心路径。每一条都不需要发明新理论——只需要找回已经被遗忘的东西。

### 7.1 回归气化：从"病名"回到"失衡"

古中医的道，不是按照病名来治病的。它是看气——看你的气是往上冲还是往下陷，是往里郁还是往外散。气顺了，一切症状自然消失。

但现在的临床现实是：一个患者走进诊室，先说"我得了慢性胃炎"，医生就开始想"治胃炎的方子"。这已经不是在看病了——这是在套答案。

**回归气化的做法其实很简单：**
- 不问"你得了什么病"，问"你哪里不舒服、什么时候加重、什么情况下缓解"
- 不看西医的诊断报告开药，看舌苔、摸脉象、问二便、察神色
- 把"炎症"放一边，看是湿热还是虚寒——一个胃炎可能有十种气化状态，十种治法完全不同

这不是高深的理论——这是古中医每天在做的事情，只是被遗忘了。

### 7.2 回归整体：从"局部病灶"回到"全身联动"

人体没有一个器官是独立工作的。你以为是胃病，根可能在肝（木克土）；你以为是头痛，根可能在肾（肾精不能上充于脑）。割裂地看一个器官，是西医解剖学的思维，不是古中医的。

**回归整体的做法：**
- 治胃不忘调肝：因为肝气犯胃是最常见的胃病根源
- 治肺不忘顾肾：因为金生水，肺病日久必伤肾气
- 治上不忘察下：因为上热下寒、上实下虚，是当代人最常见的体质

一个简单而深刻的道理：**人体是一个系统，不是一堆零件的集合。治好一个零件，不等于修好了系统。**

### 7.3 回归自愈：从"替代身体"回到"支持身体"

这是最根本的回归。西医的逻辑是替代——血压高了，用药物替代身体的调节功能去降压；血糖高了，用药物替代胰腺的功能去降糖。替代得越多，身体自身的能力退化得越快。这就是为什么停药就反弹——不是药停了病复发，而是身体已经不会自己调了。

古中医的逻辑是支持——你的身体知道自己该怎么调，它只是暂时没有力量。中医要做的，是推它一把，给它一个方向，然后退后，让它自己走。

**回归自愈的做法：**
- 能调饮食就不用药，能让身体自己恢复就不用外力干预
- 用药只是"点火"，火着了就撤，让身体继续自己燃烧
- 治疗的终点不是"指标正常"，而是"停药后身体能维持平衡"

这就是为什么古中医有"中病即止"的原则——不是"治好为止"，是"身体自己开始好转就停"。药只是拐杖，不是腿本身。该扔拐杖的时候不扔，腿就废了。

### 7.4 回归个性：从"标准化"回到"每个人都不一样"

西医的终极理想是"标准化治疗"——同一种病，同一种药，同样的剂量。这个理想在流水线上有效，在人体上却是灾难。因为世界上没有两个完全一样的人——先天体质不同、后天环境不同、情志习惯不同、气血状态不同。

**回归个性的做法：**
- 同一张方子，不同体质的人用起来效果可能完全相反
- 同一味药，在不同人身上作用的方向都不一样——黄芪在气虚的人身上是补气，在气滞的人身上是壅气
- 治疗的起点不是"这个病用这个方"，而是"你这个人在当前状态下需要什么"

"同病异治"和"异病同治"，不是中医的玄学——是因为标签一样的人，身体状态完全不一样。承认个体差异，才是真正的医学。

### 7.5 回归医理：从"方药"回到"辨证"

当今中医最大的病灶在临床上：中医师开的是中药，治的是西医的病，背后没有任何中医辨证的推理过程。方子背得滚瓜烂熟，药性讲得头头是道，但问到"这个患者当前是什么证、为什么是这个证"，卡住了。

这不是中医师的问题——是整个教育体系和临床环境把"方"和"证"剥离开了。

**回归医理的做法：**
- 方子永远是第二位的，辨证才是第一位的
- 开方之前，先问自己三个问题：患者的核心失衡是什么？失衡的方向是什么？如何用药物把失衡推回平衡？
- 如果答不出这三个问题，背一千个方子也只是个草药仓库管理员

古中医不需要发明新东西。五条回归，每一条都在经典里写得明明白白。需要的是**停下来、回头看、把断掉的那根线重新接上**。

以下两节，我们用 SPUM 体系和临床实证来展示：古中医的回归不是只有情怀，它同样拥有现代数理表达和可复现的临床验证。

## 八、SPUM 体系——古中医的现代化数理语言

古中医的智慧不需要证明——两千年的临床验证就是最好的证明。但古中医有一个致命的问题：**它的语言太古老了。**

阴阳、五行、气血、升降出入——这些概念在经典里表达得清清楚楚，但现代人听起来像天书。更糟糕的是，因为没有一套标准化的描述语言，同一个证在不同中医师手里可能有完全不同的解读。这不是中医的问题——这是任何古老知识体系在现代化过程中都会遇到的"翻译困境"。

SPUM 要解决的，不是"中医对不对"——而是"怎么让中医的智慧变成一种可以被记录、被分析、被传承的现代语言"。

### 8.1 五形向量：给每个人的身体一个"坐标"

SPUM 的核心想法极其简单：既然古中医看的是"五行生克"的状态，那就把每个人的身体状态用一个五维向量来表示：

$$S = (木, 火, 土, 金, 水)$$

每一个分量代表对应五形在当前身体中的相对强度。健康不是某一个分量的绝对数值——健康是五个分量之间的**平衡关系**。

- 木太旺 → 肝气上冲 → 容易头痛、易怒、血压偏高
- 火太弱 → 心阳不足 → 容易怕冷、乏力、循环差
- 土过壅 → 脾胃运化失常 → 痰湿、肥胖、消化不良
- 金亢 → 肺气不降 → 皮肤干燥、便秘、容易过敏
- 水不足 → 肾精亏虚 → 腰膝酸软、记忆力下降、衰老加速

这五个分量不是独立变化的——它们之间存在着确定的生克关系。木生火、火生土、土生金、金生水、水生木——这是一条"促进"的链条；木克土、土克水、水克火、火克金、金克木——这是一条"制约"的链条。

**一个人的身体状态，就是这五个分量在这两组关系中不断博弈的结果。**

为什么 SPUM 比传统说法更有用？因为它给了一个**可记录、可追踪、可对比**的健康描述方式。今天的 S 是什么，一个月的 S 是什么，三个月后 S 有没有向好的方向移动——这不是"感觉"，这是可以测量和记录的数据。

### 8.2 S_0：每个人的出厂设置

SPUM 揭示了一个被现代医学完全忽略的事实：**每个人出生的时候就带着一个独特的 S_0 基底。**

这个 S_0 决定了你一生的健康倾向——不是宿命，而是"体质坐标系"。同一个环境、同一种饮食、同一个病毒，不同 S_0 的人反应完全不同。

- CASE-001 的 S_0 是"水旺火弱"——一生最大的风险是阳气不足、寒湿内生
- CASE-002 的 S_0 也是"水旺火弱"——但比 CASE-001 更极端，肾脏负荷是致命短板

认识自己的 S_0，意味着你可以**提前知道**自己的体质短板在哪里，而不是等"病"出现了再倒推。

S_0 不是秘密。排八字、看先天五行的偏性，是古中医几千年来一直在做的事。SPUM 做的事情只是把这些经验数据化、系统化、可传递化。

### 8.3 四大公理：简洁、完整、可验证

SPUM 框架只需四条公理：

1. **状态公理**：人体状态由五维向量 $S = (木,火,土,金,水) \in \mathbb{R}^5$ 唯一描述
2. **健康公理**：存在一个平衡区间 $H \subset \mathbb{R}^5$，$S \in H$ 即为健康
3. **疾病公理**：所谓"疾病"，是 $S \notin H$ 的状态，不存在任何独立于 $S$ 之外的"病实体"
4. **治疗公理**：一切治疗行为都是 $\Delta S$ 操作——将 $S$ 推回 $H$ 边界内

推论1：抗"病"治疗不存在。一切治疗都是重新调态。
推论2：针对"病名"的固定方药必然无效——因为它不是在修 $S$，而是在修一个不存在的实体。
推论3：手术切除"病灶"而不调 $S$，复发是拓扑必然——因为促成该"病灶"的 $\Delta S$ 向量仍然存在。

这套语言的好处是：**它不需要你懂中医，也能理解治疗的底层逻辑。** 一个人发烧了 → 中医师看到的是 $S\_火\uparrow\uparrow$（火形过亢）→ 判断方向是"热者寒之" → 选择能降 $S\_火$ 的药物 → 烧退 → 停药观察。

每一个步骤都是确定的、可追溯的、可复现的。这不是"玄学"——这是可操作的关系工程。

## 九、临床实证——调态治本的完整示范

理论说得再好，不如看一个真实案例。以下两个病例展示：当治疗完全对准 $S$ 向量而非"病名"时，会发生什么。

### 9.1 CASE-004 壅虚共轭——先疏壅再补虚的调态路径

37岁女性，长期月经稀发（3-4月一行），白带过多，精神不振。八字乙木日干+辛未月+双未土埋木，壅虚共轭。

**常规思路（实体思维）**：月经稀发 = 血瘀 → 活血化瘀 → 大黄蛰虫丸。结果：剧痛、舌下青筋怒张——虫类药的剧烈切割力在壅虚共轭体质中直接攻击了最薄弱的血管壁节点。

**SPUM调态思路**：先判断壅虚共轭的两个方向——壅是表象（气压高但弹性差），虚是底色（气压高但容量小）。先疏壅 → 再补虚。

- 第一步：补中益气丸。3周后脉象从沉细弱开始改善——说明壅塞开始松动
- 第二步：五子衍宗丸新加。在壅已疏的基础上，补虚才能被吸收
- 全程目标：未对准"月经稀发"这个病名——只对准 $S\_{土\downarrow\downarrow}$ + $S\_{木\uparrow}$ 这个失衡态

**结果**：月经周期逐渐恢复，精神转佳。治疗的不是"多囊卵巢综合征"——是把身体状态从壅虚共轭推回了平衡区间。

**关键教训**：壅虚共轭体质的治疗顺序不可逆——先壅后虚。顺序错了，补药变成堵药、攻药变成毒药。这不是用药错误，是方向判断错误。

### 9.2 CASE-003 五药叠加——在有西药干扰的前提下调态

68岁男性，5土围壬，全局0木。BMI 31.4，打鼾窒息，胃出血史。

**现状**：已经吃了多年西药——倍他乐克（降压）+ 阿司匹林（抗凝）+ 其他控制用药。这些药物已经在人体网络中形成稳定的 $\Delta S$ 扰动。

**SPUM调态思路**：不幻想"停掉所有西药"。现实是在既有 $\Delta S$ 扰动的前提下，把 $S$ 重新推进 $H$。

- 核心方向：疏土——因为0木之人，土壅是一切问题的根源
- 辅助方向：扶木——补最短板，哪怕只有一点点生长
- 协同方向：助金——化土生水，打通金水相生的通道
- 西药管理：倍他乐克维持原量（不可骤停），阿司匹林换为氯吡格雷（与西医沟通）

**关键认知**：中医不是要"替代"西药。中医是要在所有 $\Delta S$ 扰动都存在的前提下，仍然找到把 $S$ 推回 $H$ 的路径。这是调态比"治病"高明的地方——不要求环境完美，只要求方向上正确。

### 9.3 两个案例的共同启示

1. **治疗从未对准任何一个"病名"** — CASE-004 不是"治多囊卵巢"，是调壅虚；CASE-003 不是"治高血压"，是疏土扶木
2. **方向比方法重要** — 壅虚共轭先疏后补的顺序错了，再好的药也是毒
3. **不理想化现实** — CASE-003 带着西药照样调态，不需要"完全停药"的极端条件
4. **S 向量比指标重要** — 血压数值只是 $S$ 的投影之一，$S$ 本身回正才是真恢复

这些案例不是"中医治好了西医治不好的病"——而是"当治疗方向对准了系统的真实状态，身体自己会找到恢复的路径"。

## 十、普通人怎么走这条路——健康自主的四个台阶

前面讲了那么多理论和案例，最后落回到一个问题：**一个普通人，在今天这个被西医定义了一切"健康标准"的世界里，怎么开始走自己的路？**

不需要成为中医大师，不需要背《伤寒论》。四个台阶，每一步都不难，但每一步都是夺回身体主权的关键。

### 10.1 第一阶：认识你的 S₀

这是最基本的一步。你的先天体质是什么？你的短板在哪里？不是等"病了"再去医院查——是在一切正常的时候，先搞清楚自己的身体。

具体怎么做？三种方法互相印证：

1. **排八字，不是算命——是看清自己的第一步。** 外界对"八字"的标签化认知是：这是算命先生用来骗钱的。但在 SPUM 的框架里，八字就是一个人的**出厂设置编码**。

你的出生年份、月份、日期、时辰，对应天干地支——一套比公历更精确的时空编码系统。天干地支五行分布的推算结果是确定性的：同样的输入，永远得到同样的输出。把这套分布映射到 S₀ 坐标系，你就得到了一个体质坐标的基线。

**这就好比汽车出厂时有一个"车身结构参数"——承载式车身还是非承载式、前驱还是四驱、发动机排列方式。** 它不决定你会不会"坏"，但它决定了你在哪些路况下更容易出问题。一台跑车在赛道上如鱼得水，去越野可能连底盘都托不住——不是跑车坏了，是它被放在了不适合自己的路况上。

八字干的事情是一样的。它不是预测你什么时候"得什么病"——**它是告诉你：你的身体在哪些季节、哪些环境条件下，更容易出现什么方向的失衡。** 火弱的人冬天要注意保暖不单是"别感冒"——是寒邪会直接削弱你的心阳。木旺的人在春天容易焦虑不单是"脾气不好"——是春季木气的生发本就顺势，你的 S_木会直接冲上边际。

**知道这些，你就不会在每年春天焦虑的时候怀疑自己"是不是抑郁了"——你知道那是你的 S₀ 在特定季节的正常偏移。不需要吃药，调整一下作息和饮食结构就好。**

具体怎么做？三个步骤，互相印证：

1. **排八字**（如上）：用在线工具或找靠谱的中医师，排出日干和五行分布
2. **看自己的"历史"**：从小到大，你最容易出问题的是哪个系统？消化（土）、呼吸（金）、循环（火）、泌尿生殖（水）、还是肝胆（木）？这不是偶然——是你的 S₀ 在用症状告诉你它的短板在哪里
3. **五诊验证**：望闻问切，当面确认

**认识 S₀ 的意义**：你终于知道，自己所谓的"病"，不过是 S₀ 在特定时间窗口的正常展开。越野车跑不过跑车不是越野车有病——只是底盘不一样。一个人因为先天火弱而比别人怕冷，不是"阳虚证"需要终身补药——是他的出厂设置就是这样，知道这个就够了。

### 10.2 第二阶：学会看自己的身体状态

不需要学会摸脉。三件事，每个人都能做：

**看精神状态**：早上醒来是清醒还是昏沉？饭后是精力充沛还是昏昏欲睡？下午三四点是还能集中注意力还是已经崩溃？精神状态是你身体整体状态的晴雨表。

**看二便**：大便成形还是溏稀？每天一次还是几天一次？颜色、气味、排便感觉——这是消化系统（土）最直接的反馈。小便颜色、频率——这是水液代谢（水）的实时报告。

**看睡眠**：入睡困难还是容易醒？做梦多还是少？早上起床是自然醒还是闹钟炸醒？睡眠质量直接反映心肾相交（火和水）的状态。

这三件事，每天花三分钟，持续记录一个月，你对身体的了解比任何体检报告都真实。**因为数据是平均值，你是自己。** 西医的正常值范围是从几万人身上统计出来的，但你的身体只认自己的平衡点。

### 10.3 第三阶：做一个清醒的用药者

每一味药——无论中药西药——进入你的身体，都在改变你的 S 向量。在服药之前，问自己三个问题：

1. 我当前处于什么失衡状态？（哪里的平衡被打破了？）
2. 这味药会怎样改变我的平衡？（它会把 S 推向哪个方向？）
3. 叠加了这味药之后，我的 S 是更接近平衡了，还是更远了？

这不是"反对西医"——这是**做一个清醒的健康管理者**。降压药该吃的时候要吃，但同时要知道：它压的是你的火（心阳），长期吃需要配合一些护阳的方法。抗生素该用的时候要用，但同时要知道：它在轰炸肠道菌群，用完后要有意识地修复。

**最危险的不是吃药——是不知道在吃什么，也不知道吃完之后发生了什么。**

### 10.4 第四阶：找到那个"看状态"的医生

不是所有穿白大褂的、开中药的都是中医。真正的古中医，问诊的时候不会先问"你得了什么病"——他会问：

- "你哪里不舒服？什么时候开始的？什么时候加重？什么时候缓解？"
- "你怕冷还是怕热？出汗多不多？口干不干？喝水什么感觉？"
- "大便怎么样？小便怎么样？睡眠怎么样？"

如果医生坐下来先看你的西医诊断报告，然后根据报告开方——他是在用中医的方式执行西医的方案。他不是中医，他是草药操作员。

**怎么判断？** 看完第一次，问自己一个问题：这个医生说的"你是什么问题"，我听得懂吗？如果他说的全是气血、运化、升降、寒热这些状态描述——他懂中医。如果他说的全是病名——换个医生。

>
> 古中医核心要义：**人体无病，唯有失和；方药无治，唯有调衡。**
>
> **真正的治愈不是消灭"疾病"——是让水重新平静下来。**
