# Pulsesensor 脉搏传感器

> 来源：[启思·脉搏传感器](https://cheez.yuque.com/org-wiki-cheez-zg5o1a/cheez-sensor/bdb7mcsoqr5mifnt)

---

## 一、简介

Pulsesensor 是一款低功耗即插即用心率传感器，适用于 Arduino、STM32、树莓派 Pico 等单片机。通过检测手指血管中血流量的变化来测量心率。采用 **光电容积脉搏波（PPG）** 技术，可实时获取心跳信息。传感器直接接入单片机 ADC 引脚。

> ⚠ **注意**
> - 此为 **静态心率传感器**，测量时请勿随意移动，也勿按压过紧。
> - 本品并非专业医疗仪器，不能作为辅助配件参与诊断和治疗。

## 四、工作原理

动脉血中的含氧血红蛋白具有 **吸收绿光** 的特性。血液越红（血红蛋白含量越高），吸收的绿光就越多。当血液在每次心跳时通过手指泵送时，反射光的量会发生变化，从而在光电传感器的输出端产生变化的波形。

来自光电传感器的信号通常很小且噪声很大，信号通过 **R/C 滤波器网络**，然后使用运算放大器放大，以产生更大、更干净、更易于检测的信号。

这种通过光进行脉冲检测的方法称为 **光电容积脉搏波图（PPG）**。

## 八、腕戴式 PPG 脉搏传感器模块（进阶）

> 适用于 **PulseSensor 脉搏传感器 HRV 心率监测蓝牙套件 (Arduino)**

这是启思推出的进阶版 PPG 模块，与基础版指尖传感器不同，采用 **XH2.54-4P 接口**，自带腕带固定，支持 **HRV (SDNN) 原生输出**，可搭配蓝牙套件无线传输。

### 与指尖版对比

| 特征 | 基础版（指尖） | 进阶版（腕戴 PPG 模块） |
|------|--------------|----------------------|
| **尺寸** | ∅ 15.8mm | 26mm × 26.4mm |
| **接口** | 3 引脚排针 | XH2.54-4P（4 针座） |
| **输出** | 仅模拟 (0–Vin) | **模拟 + 数字方波** 双输出 |
| **Arduino 库** | PulseSensor 库 | **CheezPPG 库**（专用） |
| **采样率** | 可设（通常 500Hz） | **125 Hz**（库内置定时） |
| **HRV** | 需自行计算 | **原生输出 SDNN** |
| **佩戴** | 手指按压 | **腕带固定**，解放手部 |
| **配件** | 传感器本体 | 含腕带 + 4P 杜邦线 + **蓝牙可选** |

### 引脚说明（XH2.54-4P）

| 引脚 | 线色 | 说明 |
|------|------|------|
| 1 (GND) | 黑色 | 电源地 → GND |
| 2 (VCC) | 红色 | 电源正 → 5V |
| 3 (AO) | 黄色 | 模拟输出 → A0 |
| 4 (DO) | 绿色 | 数字方波输出（可选） |

### 固件 [`ppg_wrist_cheez.ino`](pulsesensor_arduino/ppg_wrist_cheez.ino)

使用 CheezPPG 库，串口输出 6 通道 CSV @ 125 Hz：

```
raw, smooth, filtered, peak, HR, HRV(SDNN)
```

| 通道 | 说明 |
|------|------|
| `raw` | 原始 ADC 值 (0–1023) |
| `smooth` | 滑动平均平滑后的 PPG 波形 |
| `filtered` | 带通滤波后的 PPG (0.5–5 Hz) |
| `peak` | 搏动检测标记 (0 或 1) |
| `HR` | 实时心率 (BPM) |
| `HRV` | HRV SDNN (ms) |

### 使用方式

#### 有线模式（Arduino USB 直连）

```bash
# 采集 60 秒数据，保存为 6 个通道文件
python ppg_acquisition.py --cheez -d 60 -s rec_001

# 保存后会生成:
#   rec_001_raw.npy, rec_001_smooth.npy, ..., rec_001_HRV.npy
#   rec_001_all.csv (合并)
```

#### 蓝牙模式

蓝牙套件（HC-05/HC-06）连接后，可用 PC 蓝牙适配器接收，通过虚拟串口读取同样格式的 CSV 数据：

```bash
python ppg_acquisition.py --cheez -p COM5 -d 120
```

### 综合管道（从采集到辨证）

```python
# 从保存的 smooth 通道数据走完整辨证流水线
from ppg_to_wuxing_bridge import PpgToWuxingBridge
import numpy as np

bridge = PpgToWuxingBridge(fs=125)
ppg_signal = np.load('rec_001_smooth.npy')
result = bridge.pipeline(ppg_signal)
print(result['summary'])
```
