# SPUM 面相宅舍 — 面相与地元（环境维度）的桥接

> 传统相学有"宅舍相"的概念——人的面相反映其居住环境，反过来居住环境也会影响面相。在 SPUM 中，这是**环境的 ⟨P_env⟩ 与人体的 ⟨P_body⟩ 之间的边界耦合**。

---

## 一、宅舍的 SPUM 定义

### 1.1 人-宅耦合

**人（⟨P_body⟩）不是孤立的网络。** 它嵌入在更大的环境网络 ⟨P_env⟩（住宅/办公室/城市）中。两者在边界面上产生 σ 耦合：

```
⟨P_env⟩（住宅σ场）
     ↕  σ 梯度耦合（通过门、窗、墙体接口）
⟨P_body⟩（人体σ场）
     ↓  S 向量漂移
面部边界投影变化 → 面相变化
```

**定理 2（宅舍耦合）**：当人长时间处于一个 ⟨P_env⟩ 中，人体的 S 向量会向 ⟨P_env⟩ 的 σ 分布方向漂移。这个漂移最终在面部边界上可见。

### 1.2 典型耦合模式

| 耦合类型 | 环境 σ 特征 | 人体 S 漂移方向 | 面相变化 |
|---------|------------|----------------|---------|
| **火亢宅** | 南向+红色为主+干燥→σ_火↑↑ | S_火↑（浮越） | 面部潮红、皮肤干燥 |
| **土滞宅** | 中心区杂乱+黄色为主→σ_土不均匀 | S_土滞↑ | 面色晦暗、法令纹加深 |
| **水湿宅** | 北向+潮湿+黑色为主→σ_水↑↑ | S_水浮↑（滞留） | 面部浮肿、眼眶湿润 |
| **金枯宅** | 西向+空旷+白色为主→σ_金↓↓ | S_金↓↓（传导受阻） | 面色惨白、皮肤干裂 |
| **木僵宅** | 东向+封闭+绿植过多→σ_木↑（僵） | S_木↑（紧张） | 眉间悬针纹深、左颧骨突 |

## 二、传统"宅舍相"在 SPUM 中的翻译

### 2.1 "宅舍入相"

| 传统说法 | SPUM 翻译 |
|---------|-----------|
| "人面如宅，额为门面" | 额部（S_火投影）为人-宅耦合的最敏感区域——开门见火 |
| "鼻如中堂" | 鼻为中岳（S_土），是宅舍中心区的投影 |
| "眼如门户" | 眼睛是 S_木+水的联合投影——宅内通风采光的质量 |
| "耳如双峰" | 耳为 S_水投影——宅周围环境的静谧/嘈杂反映在耳色/耳形 |
| "胡运涛住哪面相会变" | 更换住宅 ⟨P_env⟩ → σ 耦合改变 → S 向量漂移 → 面相帧间变化 |

### 2.2 选宅的面相参考

从面相读取当前的人-宅耦合状态，辅助选宅/调宅：

| 面相信号 | 当前人-宅耦合问题 | 选宅建议 |
|---------|-----------------|---------|
| 面部长期浮肿（非病理性） | S_水↑↑（宅湿气与人体耦合过强） | 择高爽通风之宅，避一楼/近水 |
| 面色晦暗无改善 | S_土滞↑（宅中心区σ堵塞） | 重整宅中心（客厅），引入火形（灯光/暖色） |
| 两太阳穴凹陷 | S_火长期被压（宅采光不足或南向受阻） | 增加南向采光，南面开窗/装灯 |
| 法令纹不对称 | S_金+水链式传导两侧不均衡（宅左右σ不对称） | 调整床/沙发方向，使左右σ均衡 |
| 面色潮红不退 | S_火浮越（宅火亢） | 减少红色装饰，增加水色（黑/蓝色） |

## 三、与青囊总纲 P3 双模式的桥接

[青囊总纲](../spum-青囊（中医）总纲.md) 的 P3 双模式中：

- **P3 普通模式**：面部健康投影 + 生活方案调整 → 面相帧间改善
- **P3 生命导航模式**（含姓名+选宅）：相面上的"宅舍耦合信号"输入到选宅决策中，选择 σ 更匹配的 ⟨P_env⟩

```
面相观察 → 发现人-宅耦合问题（浮肿/晦暗/潮红）
  → 地元选宅指南
  → 更换/调整 ⟨P_env⟩
  → σ 耦合改善
  → 人体 S 向量漂移改正
  → 面相帧间恢复正常投影
```

## 四、与传统宅舍相的分界

| 传统 | SPUM |
|------|------|
| "宅舍入相 = 命运印记" | 宅-人σ耦合的边界投影，非定数 |
| "宅相如面相，不可改" | ⟨P_env⟩ 可以调整 → 面相随之帧间改变 |
| 宅舍相与风水无关 | 直接桥接地元风水——宅舍相是活的风水诊断工具 |
| 断言吉凶（发财/官非） | 不做事象断言——只做健康/状态的边界耦合分析 |
