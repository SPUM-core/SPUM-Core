# SPUM 面相流年 — 面相与天元（时间维度）的桥接

> 传统面相流年推定将时间划分为"运"、对应面部不同区域。本文档将这些信息翻译为 SPUM 框架：面相是 ⟨P_body⟩ 的边界投影，随时间的变化 = ⟨P_body⟩ 帧演化的边界读数差分。

---

## 一、流年的 SPUM 定义

### 1.1 第一定义

**流年不是时间之流**——是 ⟨P_body⟩ 在帧演化中 S 向量的步进轨迹在面部边界上的投影序列。

```
传统："流年运势"
SPUM ：S_t → S_{t+1} → S_{t+2} → ... 每一帧 S 向量在面部边界上的重投影
```

每过一年，⟨P_body⟩ 经历过约 365 × (睡眠帧数) 帧演化。帧演化中的 S 漂移累积在面部边界上，形成可观测的面相变化。

### 1.2 面部的时间标记

面部不同区域对不同年龄段的 S 向量变化最敏感：

| 年龄段 | 主导帧类型 | 面部最敏感区域 | SPUM 解释 |
|-------|-----------|---------------|-----------|
| **1-20岁** | 组装帧（土→木） | **额部轮廓** | S_火在少年期最活跃→决定额发育 |
| **21-30岁** | 组装+拆解平衡 | **左颧→右颧** | S_木→S_金方向建立→颧部变化 |
| **31-40岁** | 拆解帧逐渐主导 | **鼻→法令纹** | S_土开始被消耗→鼻/唇/法令纹 |
| **41-50岁** | 金形活跃期 | **右颧→眼** | S_金消耗加速→纹理/斑 |
| **51-60岁** | 水形衰减期 | **下巴→耳** | S_水衰减→下颌/耳形态变化 |
| **60+** | 全面衰减 | **全部区域** | 所有分量衰减的边界投影 |

## 二、传统流年 = 帧演化轨道预测

### 2.1 流年部位图

传统流年将面部划分为若干"运区"（额管少年运、鼻管中年运、下巴管晚年运）。在 SPUM 框架中，这相当于：

```
"额运好" = 少年期（0-20帧S_火主导）S_火 ∈ H（健康域）
"鼻运好" = 中年期（20-40帧S_土主导）S_土 ∈ H
"地阁好" = 老年期（40+帧S_水主导）S_水 ∈ H
```

每个"运"不是命中注定的——它是当前 S 分量在该年龄段处于健康域与否的预测。调整 S 向量，流年面相也会变。

### 2.2 "不好的流年"在 SPUM 中是？

传统认为"某年流年不好"（法令纹断开、鼻梁现青筋等），在 SPUM 中是：

```
外部事件（环境 σ 变化 / 情绪 ΔS / 外伤）
  → 内部 ⟨P_body⟩ 该年的帧演化轨迹偏离 H 域
  → 边界面投影出现偏离信号
  → 被解释为"相变"
```

SPUM 不做"流年注定"的断言，而是做：**"当前 S 向量 + 已知 Σσ_ext（环境σ扰动）→ 预测下一帧 S 在哪个区域"**。

## 四、与天元的桥接

传统流年计算涉及干支、五行方位等天元概念。在 SPUM 中，这是**天元的时间帧运算与人元的边界投影之间的桥接**：

| 天元概念 | SPUM 翻译 | 与面相的桥接 |
|---------|-----------|-------------|
| 流年干支 | 外部 σt（年运索引帧） | 年运→影响人体整体 σ →面部投影调整 |
| 大运 | 人体 σ_t 在时间维度上的分段常数 | 每个运段的 S 基线偏移→面相帧间漂移方向 |
| 小运 | 连续两帧之间的 ΔS 变化 | 数月内的面相短期变化 |
| 流月 | 帧级 σ 调节 | 一个月内的面部临时变化（面色/光泽） |
| 流日 | 单帧扰动 | 一天内的面色变化 |

## 五、与传统流年的分界

| 传统 | SPUM |
|------|------|
| "你 41 岁山根会断，是命运" | 41 岁前后 S_土 ↓ + S_金 ↓ 使鼻梁边界投影出现变化——调整 ΔS_土/金可避免 |
| "额低少年运不好" | 额是 S_火的边界投影——额低=少年时心血不足（非"命不好"） |
| 推断事象（发财/升官/破财） | 不做——面相是 ⟨P_body⟩ 的健康边界投影，不是社会事件预测器 |
| 时间刀切（精确到年/月） | 帧演化按帧步进行——年/月是大致分段，不是精确时间点 |
