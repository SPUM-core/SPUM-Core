# SPUM 面相总则 — σ_boundary 投影定理

> 面相不是"命运写在脸上"——是内部关系网络 ⟨P_body, ε_body⟩ 在体表边界面上的 L1 可观测投影。

---

## 一、核心公理

### 1.1 面相是边界投影

人体的内部关系网络不是封闭的——每一个 κ-粒子（细胞、组织、器官）都通过边连接到体表。体表就是人体的边界曲面 ∂⟨P_body⟩。在这个边界面上：

```
内部 S 向量         体表投影
─────────────────────────────
S_木（肌腱/筋膜张力） → 轮廓线/骨架形态
S_火（循环/灌注）    → 颜色/光泽/温度
S_土（肌/脂肪储备）  → 饱满度/弹性
S_金（神经/传导）    → 纹理/皱纹/斑
S_水（深层体液）     → 湿/润/浮肿
```

**定理 1（σ_boundary）**：体表边界的局部 σ 值 = 该位置下方子图 σ 值的投影。面部各"岳"的形态直接反映对应脏器的内部 σ 值。

### 1.2 面不是独立实体

面相不是一种"神秘学"——它是望诊的一部分。与脉诊、闻诊、问诊同级，区别只在于：

| 诊法 | 观测边界 | 数据形式 |
|------|---------|---------|
| 脉诊 | 桡动脉边界 | σ 时序波动 |
| 面相 | 面部表皮边界 | σ 空间分布 |
| 闻诊 | 发声产出边界 | σ 频率分布 |
| 问诊 | 语言输出边界 | σ 语义分布 |
| 舌诊 | 舌面边界 | σ 空间分布 |

五形态共享同一个内部 ⟨P_body⟩——只是投影到不同的边界面上。

### 1.3 时间维度的投影

面相随时间变化 = 内部 ⟨P_body⟩ 帧演化的边界读数变化：

```
一帧内：内部 ΔS → 面部颜色/光泽/湿度瞬时变化（秒-分钟级）
帧间  ：内部 ΔS 累积 → 面部轮廓/纹理/斑的缓慢变化（月-年级）
```

少年面相 = S 向量早年状态的投影
老年面相 = S 向量多年漂移后的投影
——不是"命运使然"，是 ⟨P_body⟩ 帧演化在边界的忠实记录。

## 二、面相的 SPUM 方法论

### 2.1 读相即读 S

读相不是"看五官摆什么"，是读 S 向量的五个分量在面部五个区域上的投影强度：

```
对应关系（基础版）：
  额（南岳）     → S_火投影（心/循环）
  左颧（东岳）   → S_木投影（肝/筋膜）
  鼻（中岳）     → S_土投影（脾/肌肉）
  右颧（西岳）   → S_金投影（肺/皮肤）
  颐/下巴（北岳）→ S_水投影（肾/骨）
```

详细映射表见 [spum-面相五形映射.md](spum-面相五形映射.md)。

### 2.2 异常态识别

| 面部信号 | S 分量 | 异常态 | 可能病机 |
|---------|--------|--------|---------|
| 额部晦暗/色斑 | S_火↓↓ | 火形虚衰 | 心血不足 |
| 额部潮红 | S_火虚浮↑ | 火形浮越 | 虚火上浮 |
| 左颧骨突/筋结 | S_木↑↑ | 木形僵化 | 筋膜紧张 |
| 鼻头瘦削/凹陷 | S_土↓↓ | 土形枯竭 | 脾胃虚弱 |
| 右颧皮肤干枯/斑 | S_金↓↓ | 金形传导受阻 | 肺气不宣 |
| 下巴后缩/削尖 | S_水↓↓ | 水形枯竭 | 肾精亏损 |
| 法令纹过深/不对称 | 水形+金形耦合 | 链式传导长期扭曲 | 整体失衡 |

### 2.3 相不为相

**这与人元的 P3 生命导航协议完全兼容**——面相信息可以直接输入 S_current 向量，通过 ΔS 微调操作实现面部状态的帧演化优化：

```
面相观察 → 识偏 → S_current 更新 → ΔS 操作 → 反馈
                                              ↓
                                        身体改善 → 面相改善（帧间投影刷新）
```

> **SPUM 面相的基本原则**：相不是不可更改的——它是 ⟨P_body⟩ 当前状态的边界投影。调整内部 S 向量，面相自然会在帧演化中刷新。

## 三、与传统相术的分界

| 传统相术 | SPUM 面相 |
|---------|-----------|
| "天庭饱满"是好命 | 额部对应 S_火——饱满表示心血充足，是 ⟨P_body⟩ 的健康状态投影 |
| "面相注定命运" | 面相是局部拓扑边界投影，不暗示任何形而上的"命运" |
| "改运"需做法事/改名 | 面相通过内部 S 向量调整而改变——调土/金/水等手段 |
| 静态结论（一生不变） | 帧间动态演化——面相随内部 ⟨P_body⟩ 逐帧更新 |
