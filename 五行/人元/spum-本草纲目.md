# SPUM 规约本草纲目：从物态分类到地炁构型数据集

> 本文以 SPUM 五形框架翻译《本草纲目》的核心贡献。目标不是另起炉灶重写药性理论——神农本草经的 ΔS 归约协议已在 `spum-神农本草经.md` 中建立。本草纲目的价值不在新理论，而在**将药性知识从 365 味扩充到 1892 味，并以 16 部 60 目的物态分类体系取代三品分类，为"地炁构型"提供了一个自然形态学的索引系统**。
>
> 前提：已阅读 [spum-神农本草经.md](spum-神农本草经.md)（ΔS 五维向量框架、植物-晶体同构、四气五味归经的 T2 翻译）。
>
> **核心论断**：李时珍的 16 部分类是 SPUM 物态拓扑分类的直观先声——不是"按自然形态分类"，而是**按地炁 VSPT 场在何种物相基底上结晶来分类**。水部药物藏纳的是水相中的 VSPT 场构型，金石部药物藏纳的是晶相中的 VSPT 场构型，草部药物藏纳的是植物模板结晶中的 VSPT 场构型。

## 二、16 部 = 16 种物相结晶基底

### 2.1 结晶基底三维分类空间

每一味药所属的"部"由三个维度决定：

| 维度 | 取值 | 对应 16 部 |
|------|------|-----------|
| **基底物态** | 液态 / 固态晶格 / 松散固态 / 生物模板 / 人工加工 | 水(液态)；金石(晶格)；土(松散)；草谷菜果木虫鳞介禽兽人(生物模板)；服器(人工) |
| **模板存在** | 无模板 / 有模板 | 水火土金石(无模板，VSPT 直接结晶)；草谷菜果木虫鳞介禽兽人(有模板，VSPT 经模板引导) |
| **模板复杂度** | 无 / 单细胞 / 植物 / 动物 / 人 | 水火土金石(无)；草谷菜果木(植物模板)；虫鳞介禽兽(动物模板)；人(人模板) |

### 2.2 无模板部：VSPT 场直接结晶

水、火、土、金石四部的药物不是生物——地炁 VSPT 场**直接**在非生物基底上结晶形成：

| 部 | 结晶基底 | VSPT 场构型特征 | 典型 ΔS 特征 |
|----|---------|---------------|-------------|
| **水部** | 液态 ⟨P,ε⟩ ——水分子网络的动态连接 | VSPT 场在水分子网络的动态边中传播——构型随温度/流动状态变化 | 水性无定形，ΔS 幅度小，多归经（随水形链全身流动） |
| **火部** | 纯 σ 梯度场——燃烧释放的 V⁺/V⁻ 事件簇 | VSPT 场在火形梯度中直接暴露——构型 = 极端 ∇σ 的爆发态 | ΔS_火↑↑↑，S_水↓↓，S_金↑——强度极大但极不稳定 |
| **土部** | 松散 ⟨P,ε⟩ ——土壤矿物的不饱和节点群 | VSPT 场在松散基底中弥散——构型均匀、无定向 | ΔS_土↑，其他分量接近 0——温和、广谱、低强度 |
| **金石部** | 刚性晶格 ⟨P,ε⟩ ——矿物晶体的高度数锁定节点 | VSPT 场在刚性晶格的间隙（虚面）中传播——构型由晶格对称性决定，极稳定 | ΔS 幅度大且持久，分量分布由晶格对称性决定——金石药性"重、镇、降" |

**金石部的拓扑含义**：金石类药物（石膏、朱砂、磁石、芒硝）的 ΔS 之所以"重坠"，是因为它们的 VSPT 场结晶基底是**度数饱和、边数锁定的刚性晶格**——这种基底的 σ 极低（节点密度极高），对应于"重"的直觉。进入人体后，这类药物的 ΔS 向量在人体网络中产生的效果类似于"将一个低 σ 晶格嵌入高 σ 组织中"——即沉降、收摄、镇惊。

### 2.3 植物模板部：VSPT 场经基因模板引导结晶

草、谷、菜、果、木五部共享"植物模板"但结晶部位和生命周期不同：

| 部 | 结晶部位 | 生命周期 | VSPT 场结晶特征 | ΔS 特征对比 |
|----|---------|---------|---------------|------------|
| **草部** | 全株（根茎叶花） | 一年生/多年生草本 | VSPT 场沿维管束从根向茎叶结晶——地上部分 VSPT 梯度最大 | ΔS 幅度中等，分量全（四气五味最全）——"全息"结晶 |
| **谷部** | 种子（胚乳+胚） | 一年生 | VSPT 场集中结晶于种子——极度压缩、高土形储备态 | ΔS_土↑↑，其他分量弱——"储备池"的纯态 |
| **菜部** | 嫩茎叶 | 短期（月级） | VSPT 场结晶时间短——构型浅、强度低 | ΔS 幅度小，温和——日常微调，非治疗强度 |
| **果部** | 果实（种子+果肉） | 多年生木本 | VSPT 场经树体多年结晶后浓缩于果实——木形骨架积累的 VSPT 场在果实中释放 | ΔS_木↑↑，S_土↑——"木形储备的果实释放" |
| **木部** | 全株（根/皮/枝/树脂） | 多年生木本 | VSPT 场在木质化水形主干中长期结晶——积累强化、分层 | ΔS 幅度大，S_水↑↑、S_木↑↑——木形+水形的长期累积 |

### 2.4 动物模板部：VSPT 场经动物模板引导结晶

虫、鳞、介、禽、兽五部对应 VSPT 场在动物模板中的结晶。动物模板比植物模板更复杂——动物有闭合子图（类似人体），因此动物药的 ΔS 有"选择性归经"特性：

```
动物模板中 VSPT 场结晶的特征：
  VSPT 场在动物体中的结晶 ≠ 在植物中的结晶
  因为动物体本身就是一个 ⟨P,ε⟩ 闭合子图
  → VSPT 场结晶会优先在动物体内与该动物习性相关的功能子图中积累
  → 服用动物药 = 摄入另一个闭合子图中已结晶的特定构型
  → 导致归经高度特异性（如：鹿茸归肾经，因鹿茸是哺乳动物最旺盛的生长点）
```

| 部 | 模板特征 | VSPT 场结晶特点 | 归经模式 |
|----|---------|---------------|---------|
| **虫部** | 无脊椎，开放式循环 | VSPT 场在开放体系中结晶——构型分散、无强烈定向 | 归经范围广，多入络 |
| **鳞部** | 有鳞，冷血 | VSPT 场在鳞甲覆盖的边界层中结晶——构型偏收敛、封闭 | 多入肝胆（木形收敛） |
| **介部** | 甲壳外骨骼 | VSPT 场在硬壳（刚性晶格）与软组织界面结晶——构型"介导" | 多入肾、肝（重镇潜阳） |
| **禽部** | 恒温，飞翔 | VSPT 场在高速代谢+飞行肌中结晶——构型偏发散、升扬 | 多入肺、表（轻宣发散） |
| **兽部** | 恒温，哺乳，与人体子图结构最相似 | VSPT 场在哺乳动物闭合子图中结晶——构型与人体最接近 | 归经高度特异性，入脏 |

### 2.5 人部：自身模板的自我映射

人部是 16 部中唯一以人体自身组织入药的类别（发、乳、血、胎、尿等）。在 SPUM 中：

```
人部的拓扑特殊性：
  药物 = 从人体某子图（一个闭合子图）中提取的 VSPT 场结晶
  服用者 = 另一个人体子图
  两个子图的模板同构
  → ΔS 的"适配度"最高，但"排异性"也最高（拓扑自免疫）
```

这就是人部药物**要么极效、要么极险**的拓扑原因——同名模板的 VSPT 场耦合最强，但若结晶构型与受体不匹配，两个同构子图之间的拓扑冲突也最剧烈。

## 三、炮制（修治）：对已结晶地炁的后处理工程

### 3.1 炮制的 SPUM 定义

炮制不是"加工药材"——它是**对已经结晶在地植物体中的 VSPT 场构型进行 V⁺/V⁻ 后处理操作，改写其 ΔS 向量**。

```
未炮制植物体 = VSPT 场经基因模板结晶的原始态
炮制操作   = 以热/水/酒/醋/火等引入额外 V⁺/V⁻ 事件
炮制后植物体 = 原始 VSPT 构型 + 后处理 V⁺/V⁻ 修改 = 改写后的 ΔS
```

### 3.2 六类炮制操作的 SPUM 翻译

| 炮制方法 | 物理操作 | SPUM 操作 | 对 ΔS 的影响 |
|---------|---------|-----------|-------------|
| **炒**（干热） | 加热至特定温度 | 向已结晶 VSPT 场注入 Δσ > 0 → 部分低强度边松弛 | 降低 S_金（抑制金形桥边过度切换），提升 S_火（温和活化） |
| **炙**（加辅料炒） | 蜜/酒/醋/盐水伴炒 | 引入辅料中的 VSPT 构型与药材 VSPT 场混合 | 辅料的 ΔS 分量叠加到药材的 ΔS 上 |
| **煅**（高温烧） | 直接火烧至红透 | 大幅 Δσ > 0 → 破坏植物模板的全部有机 VSPT 结构 → 只保留最稳定的矿相 VSPT | 消去所有 S_木、S_水（有机结构销毁），保留 S_金石形态 |
| **蒸/煮**（湿热） | 水蒸气/水煮 | 向 VSPT 场注入 S_水分量（水形链浸透） | 增加 S_水，降低 S_火——"减燥"的拓扑含义 |
| **酒制** | 黄酒浸泡/蒸 | 引入酒（发酵谷物的 VSPT 场 + 乙醇的 σ 梯度效应） | 增加 S_火↑ + S_水↑（辛散+升提）——"引药上行" |
| **醋制** | 米醋浸泡/蒸 | 引入醋（发酵谷物的 VSPT 场 + 酸味收敛效应） | 增加 S_木↓ + S_金↑（收敛+入肝）——"引药入肝" |

### 3.3 炮制的 ΔS 改写公式（T2 近似）

```
ΔS_炮制后 = ΔS_生品 + ΔS_炮制操作

例：何首乌
  生何首乌 ΔS = (S_火↑, S_水↑, S_木0, S_土0, S_金0)  // 解毒、消痈、润肠
  蒸/煮操作  → 增加 S_土↑↑ + 降低 S_火↓
  制何首乌 ΔS = (S_火0, S_水↑, S_木0, S_土↑↑, S_金0)  // 补肝肾、益精血
```

这正是为何同一味药生用和制用功效截然不同的拓扑原因——炮制不是"减毒"这么简单，而是**用 V⁺/V⁻ 事件改写了已结晶 VSPT 场的分量分布**。

## 四、附方：ΔS 叠加的数据验证集

### 4.1 11000+ 附方的 SPUM 价值

本草纲目的附方不是"用药经验集"——在 SPUM 框架中，它是一个**ΔS 叠加规则的经验验证数据集**：

```
每条附方 = 一个 ΔS 叠加实验的记录
  输入：N 味药，各药有 ΔS_i
  输出：某症状 S_out（S 向量从 S_before 移动到 S_after）
  隐含假设：ΔS_total = Σ ΔS_i + 非线性修正
  验证条件：S_after = S_before + Σ ΔS_i ∈ H（症状消除 = S 回到 H 内）
```

**数据规模**：11000+ 条附方 = 11000+ 个 ΔS 叠加的实验数据点——这是任何其他传统药学体系无法比拟的数据集规模。

### 4.2 附方能验证什么

| 验证内容 | 附方中的体现 | SPUM 意义 |
|---------|------------|----------|
| **线性叠加的有效范围** | 多味药方剂 ≈ 各药单味功效之和 | T2 线性近似在多数场景下成立 |
| **非线性边界** | 十八反、十九畏 | 某些药物的 ΔS 叠加不是 ∑ΔS_i——可能是 ∠(ΔS_i, ΔS_j) > 阈值时的拮抗 |
| **归经干涉** | 引经药（如桔梗载药上行） | 某些药物的 ΔS 主要效应是改变其他药物的归经而非直接产生 S 位移 |
| **剂量-响应曲线** | 同一方剂不同剂量的效果差异 | dv/dt ≤ const 的临床验证 |
| **时序效应** | 先煎后下的区别 | ΔS 的帧时序释放顺序影响最终效果 |

### 4.3 一个 SPUM 研究项目

11000+ 条附方构成了一个理想的**统计验证数据集**——给定药味组合和主治症状，可以用 SPUM 框架训练一个"ΔS_total → S_after"的预测模型。这不是本书当前 T2 阶段的任务，但值得在后续推进中标注为 T3 候选项目。

## 五、发明：古人的药性力学推理

### 5.1 "发明"条目的 SPUM 解读

本草纲目每药末尾的"发明"条目是李时珍（及引用诸家）的药理讨论。在 SPUM 框架中，这些讨论本质上是在描述：

```
"某药的 ΔS 向量 → 在人体子图中产生的 S 位移过程"
```

传统语言（"某药入某经、某药引某气上行"）→ SPUM 翻译（"某药的 ΔS_火分量改变某水形干段的 ∇σ → 驱动体积流向头部方向"）。

### 5.2 发明实例的 SPUM 翻译

```
李时珍论麻黄：
  "麻黄乃肺经专药...虽为太阳发汗之重剂...然诸药皆以麻黄为君"

SPUM 翻译：
```

## 六、正误：拓扑分类的纠错

### 6.1 "正误"的 SPUM 含义

本草纲目各药末的"正误"条目纠正了前人分类错误。在 SPUM 中，分类错误意味着：

```
某药被归入部 X → 意味着 VSPT 场在基底 X 中结晶
若实际是在基底 Y 中结晶 → 分类错误 → ΔS 预测会出错
```

李时珍的"正误"实质上是在做**物态拓扑分类的纠错**——纠正前人对 VSPT 场结晶基底的误判。

### 6.2 正误实例

```
李时珍正误：水银
  《本经》列上品，言久服神仙
  李时珍纠正："大明言其无毒，本经言其久服神仙...水银乃至阴毒物"
  
SPUM 翻译：
  水银 = 液态金属（液态晶格基底 → 金石部）
  ΔS = (火0, 水0, 木0, 土↓, 金↑↑↑) — 极强金形桥边切换（过度放电）
  归上品（ΔS 幅度小？）→ 分类错误
  实际 ΔS 幅度极大，应为下品
  → dv/dt 占用极高，不可久服
  → 久服 → 金形桥边切换失控（生物电异常高频） → 水形链断裂（汞中毒的拓扑描述）
```
