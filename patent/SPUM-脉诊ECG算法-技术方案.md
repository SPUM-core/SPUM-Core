# 技术方案：基于 ECG 信号分析的 SPUM 五形脉诊算法

> **目标**：通过心电图（ECG）信号处理提取脉象特征，自动映射到五形 S 向量分量，与现有辨证系统无缝集成。
> **关系**：本方案是对专利《基于多维拓扑特征量的中医辨证辅助方法及系统》中 S1 步骤（症状编码器）的**脉诊子模块**的完整技术实现——将 R-P-01~R-P-08 规则从"手动输入脉象"升级为"实时 ECG 信号自动分类 + 五形耦合"。
> **传感器**：以单导联 ECG 为最低硬件要求，兼容多导联 ECG 和可穿戴 PPG 传感器（增强模式）。
> **版本**：v1.0 / 2026-06-24

## 二、Layer 1：信号预处理

### 2.1 输入规格

| 参数 | 规格 |
|------|------|
| 信号源 | 单导联 ECG（推荐 Lead I 或 CM5） |
| 采样率 | ≥ 250 Hz（推荐 500 Hz） |
| 幅度范围 | ±5 mV（经前端放大后） |
| 采集时长 | ≥ 30 秒（推荐 60 秒，含 2 个呼吸周期以上） |
| 增强模式 | 可选加入 PPG 信号（波长 940nm，采样率 ≥ 100 Hz） |

### 2.2 预处理流水线

```
raw_signal(t)
    │
    ├─ 步骤 1：带通滤波 (Butterworth 4阶, 0.5–45 Hz)
    │   去除基线漂移 (<0.5Hz) 和高频噪声 (>45Hz)
    │
    ├─ 步骤 2：自适应工频陷波 (50Hz / 60Hz 根据地区)
    │   Notch filter, Q=30
    │
    ├─ 步骤 3：信号质量评估 (SQI)
    │   指标：信噪比 SNR、R 峰检测率、伪影比例
    │   判定：PASS / WARNING / REJECT
    │   IF SQI = REJECT THEN 要求重新采集
    │
    └─ 步骤 4：R 峰检测 (改进 Pan-Tompkins 算法)
         输出：R_peaks = [t₁, t₂, ..., tₙ]
         RR_intervals = [t₂−t₁, t₃−t₂, ..., tₙ−t_{n−1}]
```

### 2.3 信号质量评估（SQI）算法

```
SQI 指标构成（加权综合评分 0–1.0）：

1. 信噪比指标 (weight 0.4)：
   SNR = 10·log₁₀(P_signal / P_noise)
   SQIsnr = min(SNR / 20, 1.0)    # SNR ≥ 20dB 计满分

2. R 峰检测率 (weight 0.3)：
   detection_rate = detected_R_count / expected_R_count
   SQIrate = min(detection_rate / 0.95, 1.0)

3. 伪影比例 (weight 0.3)：
   artifact_ratio = artifact_segments / total_segments
   SQIart = max(1.0 − artifact_ratio × 2, 0.0)

SQI_total = 0.4·SQIsnr + 0.3·SQIrate + 0.3·SQIart

判定：
  SQI_total ≥ 0.8 → PASS
  0.5 ≤ SQI_total < 0.8 → WARNING（结果降置信度输出）
  SQI_total < 0.5 → REJECT（提示重新采集）
```

## 三、Layer 2：特征提取

### 3.1 2A：时域特征

从预处理后的 ECG 信号和 R 峰序列提取以下时域特征：

#### (a) 基本心率统计

| 特征 | 计算公式 | 生理对应 |
|------|---------|---------|
| HR_mean | 60 / mean(RR) (bpm) | 平均心率 |
| HR_min | 60 / max(RR) (bpm) | 最小心率 |
| HR_max | 60 / min(RR) (bpm) | 最大心率 |
| HR_std | std(60/RR_i) (bpm) | 心率变异性粗指标 |

#### (b) 心率变异性（HRV）特征

| 特征 | 计算公式 | 生理对应 |
|------|---------|---------|
| SDNN | std(RR_intervals) (ms) | 总体 HRV——自主神经总调节能力 |
| RMSSD | sqrt(mean(ΔRR²)) (ms) | 副交感神经活性（迷走神经张力） |
| pNN50 | count(ΔRR > 50ms) / N × 100% | 副交感神经活性的另一指标 |
| SDSD | std(ΔRR) (ms) | 短时 HRV |

#### (c) QRS 形态特征

| 特征 | 提取方法 | 临床对应 |
|------|---------|---------|
| QRS_amplitude | 每个 beat 的 R 峰到基线幅度均值 (mV) | 脉势——洪/细判定依据 |
| QRS_duration | QRS 起始到结束的平均宽度 (ms) | 心室传导状态 |
| T_amplitude | T 波峰值幅度均值 (mV) | 复极状态——心肌能量恢复 |
| QT_interval | Q 波起始到 T 波结束均值 (ms) | 心室电收缩总时长 |
| QTc | QT / √(RR) 校正值 (ms) | 心率校正后的复极时间 |

#### (d) 呼吸耦合特征

| 特征 | 提取方法 | 临床对应 |
|------|---------|---------|
| RSA_depth | 吸气相 RR 减呼气相 RR 均值 (ms) | 呼吸性窦性心律不齐——迷走神经功能 |
| E_I_ratio | 呼气相最长 RR / 吸气相最短 RR | 自主神经平衡指标 |

### 3.2 2B：频域特征

将 RR 间期序列通过 Lomb-Scargle 周期图（适用于非均匀采样）进行频谱分析：

| 频段 | 范围 | 特征 | 生理对应 |
|------|------|------|---------|
| VLF | 0.0033–0.04 Hz | VLF_power (ms²) | 体温调节、肾素-血管紧张素系统 |
| LF | 0.04–0.15 Hz | LF_power (ms²) | 交感+副交感混合（以交感为主） |
| HF | 0.15–0.40 Hz | HF_power (ms²) | 副交感/迷走神经 |
| Total | 0.0033–0.40 Hz | TP (ms²) | 总功率——自主神经总活性 |
| — | — | LF/HF_ratio | 交感/副交感平衡指数 |
| — | — | LF_nu | LF/(LF+HF) 归一化值 |

### 3.3 2C：波形形态特征（增强模式：需 PPG）

仅在 ECG + PPG 双模态下启用，用于识别传统脉诊中需要波形形态学分析的脉象：

```
同步采集 ECG 和 PPG 信号后：

1. 脉搏波传导时间 (PTT)：
   PTT = PPG_onset_time − ECG_R_peak_time
   反映动脉硬度和血管张力（弦脉/紧脉的关键指标）

2. 脉搏波形态学特征（PPG 单周期波形分析）：
   ┌────────────────────────────────────────────────┐
   │             PPG 波形参数                       │
   │  ├─ 主波幅度 (A₁)                             │
   │  ├─ 重搏波幅度 (A₂)                          │
   │  ├─ 反射波增强指数 (AIx = A₂/A₁)            │
   │  ├─ 上升时间 (T_rise, 峰值的 10%→90%)       │
   │  ├─ 下降时间 (T_fall, 峰值→基线)            │
   │  └─ 波形面积比 (Area_systolic / Area_total)  │
   └────────────────────────────────────────────────┘
```

## 四、Layer 3：脉象分类器

### 4.1 分类体系

根据传统中医二十八脉，按四个维度分类，每类输出一个脉象标签和置信度。

#### 4.1.1 位（深度）分类：浮/沉/中

| 脉象 | 分类特征 | ECG 特征指标 | 判定规则 |
|------|---------|-------------|---------|
| 浮脉 | 轻取即得，重按反减 | HRV 中 HF 升高、RSA 增强 | HF_power > 阈值 + RSA_depth > 阈值 |
| 沉脉 | 轻取不应，重按始得 | HRV 中 LF/HF 升高、QRS 幅度偏低 | LF/HF > 2.0 + QRS_amp < 阈值 |
| 中取 | 不轻不重 | 介于两者之间 | 以上均不满足 |

> **注意**：ECG 单独对深度（浮/沉）的分类置信度较低（约 60–70%）。输出的"浮/沉"判定应附带置信度标签。

#### 4.1.2 数（速率）分类：迟/缓/数/疾

| 脉象 | 心率范围 (bpm) | ECG 特征 | 判定规则 |
|------|---------------|---------|---------|
| 迟脉 | < 60 | HR_mean < 60 | 简单阈值 |
| 缓脉 | 60–75 | 60 ≤ HR_mean ≤ 75 | 简单阈值 |
| 数脉 | 75–100 | 75 < HR_mean ≤ 100 | 简单阈值 |
| 疾脉 | > 100 | HR_mean > 100 | 简单阈值 |

**置信度**：> 95%——心率的 ECG 检测是金标准。

#### 4.1.3 形（形态）分类：洪/细/弦/滑/涩

| 脉象 | 触感描述 | ECG+PPG 特征指标 | 判定规则（增强模式） |
|------|---------|-----------------|-------------------|
| 洪脉 | 来盛去衰，波涛汹涌 | QRS_amplitude 高 + PPG_A₁ 高 + T_rise 快 + AIx 低 | QRS_amp > P90 + A₁ > P90 + AIx < 0.3 |
| 细脉 | 脉细如线，应指明显 | QRS_amplitude 低 + PPG_A₁ 低 | QRS_amp < P10 + A₁ < P10 |
| 弦脉 | 端直以长，如按琴弦 | 仅 ECG：HRV_LF/HF 升高 + QTc 延长；增强：AIx 高 + PTT 短 | AIx > 0.6 + PTT < 阈值 + LF/HF > 2.5 |
| 滑脉 | 往来流利，如珠走盘 | HRV 正常 + QRS 形态规则 + PPG 上升支陡峭 | 增强：T_rise < 阈值 + AIx 中等 + HRV 正常 |
| 涩脉 | 往来艰涩，如刀刮竹 | HRV 异常升高 + RR 间期高度不规则 + PPG 波形变异大 | 仅 ECG：RMSSD > P95 + SDSD > P95 + 波形变异系数 > 阈值 |

**ECG-only 模式下的形分类**：

| 脉象 | ECG-only 可用特征 | 置信度 |
|------|-----------------|--------|
| 洪脉 | QRS_amplitude 高 + HR 正常或偏高 | 中 (70%) |
| 细脉 | QRS_amplitude 低 + HR 正常或偏低 | 中 (70%) |
| 弦脉 | LF/HF 高 + QTc 延长 + HRV 降低 | 低 (60%) |
| 滑脉 | HRV 正常 + QRS 形态规则 | 低 (55%) |
| 涩脉 | HRV 异常高 + RR 不规则 | 中 (65%) |

#### 4.1.4 律（节律）分类：结/代/促/涩

| 脉象 | 节律特征 | ECG 特征指标 | 判定规则 |
|------|---------|-------------|---------|
| 结脉 | 缓而时止，止无定数 | RR 间期偶尔出现长间歇，平均 HR < 75 | HR < 75 + RR_outliers 比例 > 2% + 无固定模式 |
| 代脉 | 缓而时止，止有定数 | RR 间期有规律地出现长间歇（如每 3 跳 1 停） | RR 模式周期性检测（自相关分析） |
| 促脉 | 数而时止，止无定数 | RR 间期偶尔出现长间歇，平均 HR > 90 | HR > 90 + RR_outliers 比例 > 2% |
| 涩脉 | 三五不调，散乱无章 | RR 间期极度不规则，无任何模式 | RMSSD > P95 + 熵分析（SampleEn > 阈值） |

### 4.2 脉象组合输出

一个患者可能同时表现出多种脉象（如"脉沉细"、"脉浮数"），分类器输出为：

```json

    "LF/HF": 2.8,
    "RMSSD": 22,
    ...
  }
}
```

## 五、Layer 4：五形耦合映射

### 5.1 基础映射表（扩展专利规则 R-P-01~R-P-08）

将每个已分类的脉象映射到五维特征空间的偏移量。此为专利中 R-P 规则集的**自动检测版**——输入不再来自手动选择，而是来自 Layer 3 的分类结果。

| 脉象 | 五形耦合公式 | 临床含义（SPUM 翻译） |
|------|------------|-------------------|
| **浮脉** | Δf₂ += +1.0 × conf | 火形向体表偏移，体表水形链 σ 升高 |
| **沉脉** | Δf₂ −= 1.5 × conf | 水形体积流被拉入深层低 σ 区域（阴盛/里证） |
| **迟脉** | Δf₂ −= 1.0 × conf | 火形梯度整体低下（寒证/阳虚） |
| **缓脉** | 无显著偏移，Δf₂ −= 0.3 × conf（温和标记） | 生理状态或轻微湿困 |
| **数脉** | Δf₂ += 1.5 × conf | 火形梯度亢进（热证） |
| **疾脉** | Δf₂ += 2.5 × conf | 火形梯度极度亢进（实热/亡阴） |
| **洪脉** | Δf₂ += 1.5 × conf, Δf₄ += 0.5 × conf | 火亢+储备充足（实证/热盛） |
| **细脉** | Δf₃ −= 2.0 × conf, Δf₂ −= 0.5 × conf | 土形储备不足+火形轻度低下（虚证/血虚） |
| **弦脉** | Δf₁ += 2.0 × conf, Δf₅ −= 1.0 × conf | 木形环过紧约束水形链——弹性下降（气郁/痛证） |
| **滑脉** | Δf₅ += 1.0 × conf | 水形流速增加但有序（痰湿/孕脉） |
| **涩脉** | Δf₅ −= 2.0 × conf, Δf₃ −= 0.5 × conf | 水形链中碎片化阻塞（血瘀/精亏） |
| **结脉** | Δf₂ −= 1.0 × conf, Δf₅ −= 1.0 × conf | 火形不足导致间歇性流通中断（虚寒+瘀） |
| **代脉** | Δf₁ += 1.0 × conf, Δf₅ −= 1.5 × conf | 木形环固定节律性地卡顿（脏气衰微） |
| **促脉** | Δf₂ += 1.5 × conf, Δf₅ −= 1.0 × conf | 火亢但流通不畅——热盛兼瘀 |
| **弱脉** | Δf₂ −= 1.5 × conf, Δf₃ −= 1.5 × conf | 火形+土形双重低下（气血两虚） |
| **紧脉** | Δf₁ += 2.0 × conf, Δf₂ −= 1.0 × conf | 木形环紧束+火形受抑（寒凝+气郁） |

其中 `conf` 为 Layer 3 输出的分类置信度 ∈ [0, 1]。

### 5.2 复合脉象处理

当多个脉象同时存在时（如"沉细弦"），采用加权叠加规则：

```
ΔF_pulse = Σ (w_i × ΔF_i × conf_i) / Σ w_i

其中 w_i = 各脉象在复合脉中的权重
默认权重：位=0.3, 数=0.3, 形=0.3, 律=0.1
```

**示例**：脉沉细弦

```
ΔF_沉  = (0, −1.5, 0, 0, 0) × 0.82 × 0.3
ΔF_细  = (0, −0.5, −2.0, 0, 0) × 0.78 × 0.3
ΔF_弦  = (+2.0, 0, 0, 0, −1.0) × 0.70 × 0.3

叠加：
Δf₁ = (0 + 0 + 2.0×0.7×0.3) / 0.9 = 0.47
Δf₂ = (−1.5×0.82×0.3 + (−0.5)×0.78×0.3 + 0) / 0.9 = −0.54
Δf₃ = (0 + (−2.0)×0.78×0.3 + 0) / 0.9 = −0.52
Δf₅ = (0 + 0 + (−1.0)×0.70×0.3) / 0.9 = −0.23

ΔF_pulse = (+0.47, −0.54, −0.52, 0, −0.23)
```

### 5.3 与现有 S1 步骤的集成

脉诊模块的输出直接输入到专利中定义的 S1 症状编码器：

```
F_current_pulse = F_current_baseline + ΔF_pulse

原 S1 聚合算法（第 3.1.3 节）增加一行：
  3. 脉诊子模块输出 ΔF_pulse，累加到 F_current
```

这使得在最终 F_current 中，脉诊贡献与其他三诊（望/闻/问）的贡献在同一五维空间中线性叠加，无缝参与 S2 步骤的健康凸多面体判定。

## 六、算法流程伪代码

```python
# ============================================================
# SPUM 五形脉诊算法 — ECG 信号处理 + 脉象分类 + 五形耦合
# 输入：ECG raw signal (np.array, 采样率 fs)
# 输出：ΔF_pulse (五维修正向量) + 脉象诊断报告
# ============================================================

def spum_pulse_diagnosis(ecg_signal, fs=500.0, ppg_signal=None):
    """
    主入口函数
    参数：
        ecg_signal: 1D array, ECG 原始信号 (≥30s @ ≥250Hz)
        fs: 采样率 (Hz)
        ppg_signal: 可选, PPG 信号 (增强模式)
    返回：
        pulse_report: dict, 包含脉象诊断结果和 ΔF_pulse
    """
    # ── Layer 1：信号预处理 ──
    clean_ecg = preprocess_ecg(ecg_signal, fs)
    r_peaks, sqi = detect_r_peaks(clean_ecg, fs)
    
    if sqi < 0.5:
        return {"error": "信号质量不足，请重新采集", "sqi": sqi}
    
    rr_intervals = np.diff(r_peaks) / fs  # 单位：秒
    
    # ── Layer 2：特征提取 ──
    # 2A 时域特征
    hr_mean = 60.0 / np.mean(rr_intervals)
    sdnn = np.std(rr_intervals) * 1000  # ms
    rmssd = np.sqrt(np.mean(np.diff(rr_intervals * 1000) ** 2))
    qrs_amp = extract_qrs_amplitude(clean_ecg, r_peaks, fs)  # mV
    
    # 2B 频域特征
    lf_hf_ratio = compute_lf_hf_ratio(rr_intervals)
    hf_power = compute_hf_power(rr_intervals)
    
    # 2C 增强模式特征（可选）
    if ppg_signal is not None:
        ppt = compute_pulse_transit_time(clean_ecg, ppg_signal, r_peaks, fs)
        aix = compute_augmentation_index(ppg_signal, fs)
        ppg_amp = extract_ppg_amplitude(ppg_signal, fs)
    
    # ── Layer 3：脉象分类 ──
    # 3.1 位分类（深度）
    depth_class, depth_conf = classify_depth(
        lf_hf_ratio, hf_power, 
        ppt if ppg_signal is not None else None,
        aix if ppg_signal is not None else None
    )
    
    # 3.2 数分类（速率）
    rate_class, rate_conf = classify_rate(hr_mean)
    
    # 3.3 形分类（形态）
    shape_class, shape_conf = classify_shape(
        qrs_amp, sdnn, rmssd, lf_hf_ratio,
        ppt if ppg_signal is not None else None,
        aix if ppg_signal is not None else None,
        ppg_amp if ppg_signal is not None else None
    )
    
    # 3.4 律分类（节律）
    rhythm_class, rhythm_conf = classify_rhythm(rr_intervals, rmssd, hr_mean)
    
    # ── Layer 4：五形耦合 ──
    delta_F = np.zeros(5)  # (f1, f2, f3, f4, f5)
    weight_sum = 0.0
    
    # 查找各脉象的五形映射
    pulse_mappings = {
        "depth": PULSE_MAP_DEPTH.get(depth_class, np.zeros(5)),
        "rate": PULSE_MAP_RATE.get(rate_class, np.zeros(5)),
        "shape": PULSE_MAP_SHAPE.get(shape_class, np.zeros(5)),
        "rhythm": PULSE_MAP_RHYTHM.get(rhythm_class, np.zeros(5)),
    }
    
    confidences = {
        "depth": depth_conf,
        "rate": rate_conf,
        "shape": shape_conf,
        "rhythm": rhythm_conf,
    }
    
    weights = {"depth": 0.3, "rate": 0.3, "shape": 0.3, "rhythm": 0.1}
    
    for key in weights:
        delta_F += pulse_mappings[key] * confidences[key] * weights[key]
        weight_sum += weights[key]
    
    delta_F /= weight_sum
    
    # ── 输出 ──
    pulse_report = {
        "脉象诊断": {
            "位": {"label": depth_class, "confidence": depth_conf},
            "数": {"label": rate_class, "confidence": rate_conf},
            "形": {"label": shape_class, "confidence": shape_conf},
            "律": {"label": rhythm_class, "confidence": rhythm_conf},
            "综合": f"{depth_class}{rate_class}{shape_class}{rhythm_class}" if rhythm_class != "无异常" else f"{depth_class}{rate_class}{shape_class}脉"
        },
        "五维修正向量 ΔF": {
            "f1_约束": round(delta_F[0], 3),
            "f2_梯度": round(delta_F[1], 3),
            "f3_储备": round(delta_F[2], 3),
            "f4_修剪": round(delta_F[3], 3),
            "f5_流通": round(delta_F[4], 3),
        },
        "信号质量 SQI": round(sqi, 2),
        "模式": "增强(ECG+PPG)" if ppg_signal is not None else "标准(ECG-only)",
    }
    
    return pulse_report

def classify_rate(hr_mean):
    """数分类：迟/缓/数/疾"""
    if hr_mean < 60:
        return "迟", 0.95
    elif hr_mean <= 75:
        return "缓", 0.90
    elif hr_mean <= 100:
        return "数", 0.90
    else:

def classify_depth(lf_hf_ratio, hf_power, ppt=None, aix=None):
    """
    位分类：浮/沉/中
    仅 ECG 模式使用 LF/HF + HF_power 估计
    增强模式使用 PTT + AIx 提高精度
    """
    if ppt is not None and aix is not None:
        # 增强模式：较高精度
        if ppt < 200 and aix > 0.5:     # PTT 短 + AIx 高 → 血管张力高 → 沉
            return "沉", 0.85
        elif ppt > 280 and aix < 0.3:   # PTT 长 + AIx 低 → 血管松弛 → 浮
            return "浮", 0.82
        else:
            return "中取", 0.70
    else:
        # ECG-only 模式：较低精度
        if lf_hf_ratio > 2.5:
            return "沉", 0.65
        elif hf_power > np.percentile(hf_power, 75):
            return "浮", 0.60
        else:
            return "中取", 0.55


def classify_shape(qrs_amp, sdnn, rmssd, lf_hf_ratio, 
                   ppt=None, aix=None, ppg_amp=None):
    """形分类：洪/细/弦/滑/涩"""
    # 使用决策树或规则引擎
    if ppg_amp is not None and qrs_amp > np.percentile(qrs_amp, 85):
        if aix is not None and aix < 0.3:
            return "洪", 0.80
    if qrs_amp < np.percentile(qrs_amp, 15):
        return "细", 0.75
    if aix is not None and aix > 0.6 and lf_hf_ratio > 2.5:
        return "弦", 0.78
    if rmssd > np.percentile(rmssd, 90) and sdnn > np.percentile(sdnn, 90):
        return "涩", 0.70
    if lf_hf_ratio > 1.5:  # 高均值附近规则
        return "滑", 0.55
    return "平脉", 0.50


def classify_rhythm(rr_intervals, rmssd, hr_mean):
    """律分类：结/代/促/涩/正常"""
    # 自相关分析检测周期性停顿
    autocorr = np.correlate(rr_intervals, rr_intervals, mode='full')
    # 检测异常 RR 间隔
    rr_outliers = detect_rr_outliers(rr_intervals)
    outlier_ratio = len(rr_outliers) / len(rr_intervals)
    
    if outlier_ratio > 0.1 and rmssd > np.percentile(rmssd, 95):
        return "涩", 0.80
    if outlier_ratio > 0.02:
        if has_periodic_pattern(rr_intervals):
            return "代", 0.75
        elif hr_mean > 90:
            return "促", 0.75
        else:
            return "结", 0.75
    return "无异常", 0.90
```

- **混合模式**：系统自动分类 + 医师复核确认后，再进入 S2 诊断步骤
