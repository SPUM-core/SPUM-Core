# SPUM 几何学归约

> 几何不是本体——是 ⟨P, ε⟩ 关系网络在认知投影中的涌现产物。L0 无几何（纯组合整数旋转系统），几何自 L1 局部投影起。
>
> **核心原则**：关系→节点→点→线→面→体→维度→距离→角度→曲率→π——每个几何概念都有拓扑原型，发生顺序不可跳跃。π 是认知投影因子，不是宇宙常数。12 是欧拉恒等式的强制解，不含 π。
>
> **导航 Skill**：[skill.md](skill.md) — 38 节点、7 种加载策略、范式总纲。
