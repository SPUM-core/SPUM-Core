## 一、八条公理

### GEO-001 几何投影公理

几何不是宇宙的先验结构。几何概念（点、线、面、体、维度、距离、角度、曲率、π）是 ⟨P, ε⟩ 关系网络在认知投影中的必然涌现产物。L0 本体层无几何——只有整数下标的旋转系统 `rot[v]`。几何自 L1 局部投影起。

### GEO-002 关系先于几何

几何概念的发生顺序不可跳跃：

```
关系 → 节点 → 点 → 线 → 面 → 体 → 维度 → 距离 → 面积 → 体积 → 角度 → π
```

每个几何概念有拓扑原型。"直" = 拓扑最短路径的投影。"平" = 度数均匀的投影。"曲" = 度数非均匀的投影。不能跳过"关系"直接用"距离"——距离是路径跳数的连续粗粒化。

### GEO-003 离散优先

离散帧 τ 是时间基底。dt = τ（一个确定的帧步长），不是无穷小。连续几何是大尺度粗粒化的统计投影——模拟不是模仿，是还原。微积分是离散统的原生语言：dv/dt ≤ const 读作"每帧的变化量"，不是"瞬时变化率"。

### GEO-004 π 降级定理

π 不是宇宙固有常数。它是人类以六方向直角坐标认知各向同性球体时引入的认知压缩因子。在纯组合路径中（欧拉恒等式 Σ(6−deg)=12），π 完全不出现。12 是拓扑强制解，不依赖任何几何假设。

**双路径锁定**：
- 路径一（几何容量）：D_max = 4κ → S = πD² → N_max = 16π → k₀ ≤ 12
- 路径二（纯组合）：Σ(6−deg(v)) = 12 → π 不出现

### GEO-005 维度发生学

三维不是背景容器——是描述闭合子图（正二十面体 12/30/20）节点位置所需的最简独立参数个数。不存在名为"三维"的容器。维度只是坐标语法——要最经济地描述球形粒子构成网络中的节点位置，恰好需要三个数字。

### GEO-006 球体逻辑必然性

各向同性是混沌基底的唯一可能状态。在毫无约束的混沌中，没有任何理由使某一方向与其他不同。球体是各向同性的几何等价物。任何非球体都意味着对某些方向的偏爱——需要外部约束来解释，而混沌中不存在这样的原因。

**分层澄清**：在 L0.5 图论层，关系张力场是源头，球体是等势面的形状——用球体解释张力场是反向的。但到达 L3 物质层，关系已结晶为球体——此时球体几何是直接本体，不是隐喻。

### GEO-007 投影不变式三分

几何量按投影层级分三类：

| 类 | 符号 | 定义 | 示例 |
|----|------|------|------|
| 刚性不变量 | R | 帧间不变的拓扑量，可独立验证 | V, E, F, χ, Σ(6−deg) |
| 投影依赖量 | P | 依赖嵌入/标架选择 | 坐标、距离、角度、曲率 |
| 连续几何量 | C | 离散结构的连续粗粒化 | π, 积分、微分 |

拓扑层（R）与几何层（P/C）边界锐利：R 量不依赖嵌入，P/C 量依赖嵌入。不可用 P/C 量推导 R 量——那是用投影约束本体。

### GEO-008 五层几何角色

OpenSPUM L0→L4 五层中，每层有明确几何角色，不可越界：

| 层 | 几何角色 | 有/无几何 | 关键量 | 代码 |
|----|---------|----------|--------|------|
| L0 | 纯组合旋转系统 | **无** | rot[v] 环序、dart、整数下标 | `combinatorial_proto.py` |
| L1 | 局部标架投影 | 局部 | 局部 σ、角亏 2π−A_v、球面码 | `l1_projection.py` |
| L2 | 全局嵌入工件 | 全局 | Finsler 度量、∇σ、红移代理 | `l2_projection.py` |
| L3 | 帧间几何 | 跨帧 | d_topo、Δμ、σ_global | `l3_projection.py` |
| L4 | 事件分区 | 纯组合 | 度数三分 over/flat/under | `l4_evolution.py` |

**关键约束**：坐标永不回写 L0。L2 的嵌入坐标只用于显示和计算投影读数（红移、度量），不参与 L0 的演化规则。

## 二、L0→L4 五层几何角色形式化

### 2.1 L0：无几何层

L0 是纯组合旋转系统。节点是整数 id，边是 `(a,b)` 对，三角面由 dart 环导出。**没有坐标、没有角度、没有 π、没有曲率。**

核心数据结构（[combinatorial_proto.py](../openSPUM/src/l0/combinatorial_proto.py)）：

```python
class RotNet:
    rot: dict[int, list[int]]  # 环序邻居表——每个节点的邻居按逆时针排列
    # 边由 rot 诱导：a 的环序中出现 b ⇔ 边 (a,b)
    # 面由 dart 环导出：(a→b) 的后继 = rot[b][rot[b].index(a)+1) mod deg(b)]
```

几何角色：**无**。L0 只回答"谁连着谁"和"环序如何"。它不回答"在哪里"或"多远"。

冻结读数（2026-09-15）：
- `seed_icosa`: 12/30/20，全 deg5，Σ(6−deg)=12，χ=2
- `seed_patch(R=1)`: 7/12/7，中心 deg6 外围 deg3，六边形洞
- 穿刺再生：删 deg5 点 → 5 边形洞 → 新点 id=12 补洞 → 回到 12/30/20

### 2.2 L1：局部标架层

L1 给每个节点建立**局部坐标系**——基于该节点的环序邻居在球面上的排列。

核心操作（[l1_projection.py](../openSPUM/src/l1/l1_projection.py)）：
- **球面码**：度数 d 的节点，其 d 个邻居在半径 f(σ) 的球面上按最优 d-码排列
- **步长**：f(σ) = (σ₀/σ)^{1/3}——高 σ 区域步长缩短（嵌入压缩）
- **角亏**：2π − A_v，其中 A_v = Σ(三角面内角)——局部曲率的离散度量

几何角色：**局部几何**。L1 回答"这个节点的邻居在它的什么方向"。不回答全局位置。

### 2.3 L2：全局嵌入层

L2 把局部标架拼接成**全局坐标工件**——通过 BFS 平行移动 + 松弛。

核心操作（[l2_projection.py](../openSPUM/src/l2/l2_projection.py)）：
- `aligned_tree`：BFS 树 + 局部标架传播
- `relax`：Gauss-Seidel 松弛（迭代消解冲突）
- `holonomy`：环路闭合残差（曲率的离散度量）
- `redshift_proxy`：σ 路径积分代理

**本模块核心贡献**：L2 的嵌入度量应采用 **Finsler/Randers 度量**（GEO-021~033），而非 Riemannian。理由见 [Finsler几何/](Finsler几何/)。

几何角色：**全局工件**。L2 回答"整个网络的坐标嵌入是什么样"。坐标是工件——只用于显示和计算投影读数，永不回写 L0。

### 2.4 L3：帧间几何层

L3 计算**跨帧的几何指标**——不依赖坐标嵌入的拓扑距离。

核心操作（[l3_projection.py](../openSPUM/src/l3/l3_projection.py)）：
- `d_topo` = |E_τ Δ E_{τ+1}| / max(|E_τ|, |E_{τ+1}|)：帧间拓扑距离
- `Δμ`：锚点漂移率——张力场重分布导致的认知漂移
- `σ_global`：全局空间密度

几何角色：**帧间几何**。L3 回答"这一帧到下一帧，网络变了多少"。不回答"坐标在哪里"——Δμ 和 d_topo 是坐标无关的。

### 2.5 L4：事件分区层

L4 把每帧的节点按度数变化分入三类事件区——纯组合，无几何。

核心操作（[l4_evolution.py](../openSPUM/src/l4/l4_evolution.py)）：
- **core**（过度饱和）：deg 上升的节点——闭合子图净湮灭区
- **shell**（稳定）：deg 不变的节点——饱和壳层
- **bg**（欠饱和）：deg 下降的节点——背景活跃区

几何角色：**事件分区**。L4 回答"每个节点在这一帧扮演什么角色"。度数三分是纯组合分类，无几何量。

## 三、与图论模块的分层关系

| 层 | 模块 | 回答的问题 | 语言 |
|----|------|-----------|------|
| L0.5 拓扑层 | `图论/` GT-001~026 | 结构合法？（整数不变量） | 张力场 |
| L0.5 计数层 | `图论/` C1~C9 | 整数审计？（Σ(6−deg)=12） | 计数 |
| L2 Finsler 层 | **本模块** GEO-021~033 | 嵌入度量是什么？（方向依赖） | Finsler |
| L3 球体几何层 | `图论/` GT-027~032 | 结构怎么动？（角度自由度） | 球体 |

**不可互推**：拓扑层给出"可行域"（哪些构型合法），Finsler 层给出"嵌入度量"（方向依赖距离），球体层给出"唯一解"（具体角度值）。三层的答案集不同。
