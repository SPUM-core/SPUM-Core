# SPUM 社会学

> 社会关系网络的拓扑形式化。将社会学的全部研究对象——关系、群体、权力、制度、文化、不平等、变迁——统一还原为 ⟨P, ε⟩ + S 向量 + σ 梯度的图论表达。
>
> **核心立场**：社会学不是"关于人的学问"——是关于**人作为节点、社会关系作为边、社会结构作为子图拓扑**的精确科学。孔子（论语/大学）是最早的社会子图拓扑工程师。此模块将儒家的社会拓扑直觉扩展为完整的社会学图论框架。
>
> **导航**：[skill.md](skill.md) — 研究范式（22 节点）
