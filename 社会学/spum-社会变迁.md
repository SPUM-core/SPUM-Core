# SPUM × 社会变迁

> 归约路径：旧边 V⁻ 累积 → 新边 V⁺ 涌现 → 旧制度子图悬挂 → 新制度子图形成 → σ 分布整体重构
> 革命不是"爆发"的——是 V⁻ 在一帧一帧中累积，直到某帧度数检查触发级联修剪。

---

## 核心命题

**社会变迁 = 社会子图在足够多帧中积累了足够多的 V⁻/V⁺ 变化，使得子图的整体 σ 分布、连通分量结构、或制度子图构型发生了不可逆的重构。** 慢变迁 = 逐帧 V⁺ 新模式的积累。快变迁（革命）= 长期积累的悬挂端在某帧触发级联 V⁻。

---

## 一、变迁的 SPUM 基础

### 1.1 变迁永不停止

不完美定理（R5）的社会版本：**社会子图在任何时刻都不处于"稳定态"——每帧必然产生新的悬挂端（未解决的矛盾、被边缘化的群体、失效的制度边）。** 这些悬挂端是下一帧变迁的起点。变迁不是社会的"特殊状态"——**变迁是社会子图永远在发生的事情，只有速度差异，没有有无之分。**

### 1.2 慢变迁 vs 快变迁

| 维度 | 慢变迁（演化） | 快变迁（革命） |
|------|--------------|--------------|
| V⁺/V⁻ 速率 | 单帧变化小——符合 dv/dt ≤ const | 单帧变化大——级联效应暂时突破 dv/dt 约束 |
| 触发机制 | 新 V⁺ 模式的逐帧累积 | 悬挂端率 δ 超过临界值 → 级联 V⁻ |
| 制度变化 | 制度子图逐步调整——边被替换而非删除 | 旧制度子图被整体拆除 |
| 可逆性 | 部分可逆——旧边可恢复 | 基本不可逆——旧子图已被彻底修剪 |
| 时间跨度 | 数十到数百帧 | 一帧到数帧 |

## 二、快变迁（革命）的级联机制

### 2.1 革命不是"爆发"——是度数检查

```
正常帧：
  悬挂端率 δ 在可接受范围内
  → 金形修剪少量悬挂边
  → 修剪产生的新悬挂端数量可控
  → 下一帧正常处理

临界帧（δ > δ_critical）：
  悬挂端率超过阈值
  → 金形修剪触发级联 V⁻
  → A 边被删 → B 节点度数从 2 降至 1 → B 的剩余边也被删
  → C 节点度数从 3 降至 1 → C 的边也被删
  → ...级联扩散
  → 整块子图在单帧内碎裂
```

在政治社会学术语中：
- δ_critical = 革命阈值——社会矛盾积累到无法被常规机制处理的临界点
- 金形修剪 = 革命事件——长期积累的"无效制度边"在一帧内被集体删除
- 级联 V⁻ = 革命的扩散——国王倒台 → 贵族被清算 → 地方权力真空 → 整个旧制度子图崩塌

### 2.2 革命的不可逆性

革命后"回到过去"不可能的拓扑原因：

```
革命前：子图结构 A
革命中：大量 V⁻ 级联 → 子图结构 A 的大部分边被删除
革命后：子图结构 B

要"回到 A"，需要在 B 上执行与革命中 V⁻ 数量相等的 V⁺
但：
  1. dv/dt ≤ const → 单帧不能执行太多 V⁺
  2. V⁺ 比 V⁻ 便宜（MATH-009）→ 但从零重建仍需要大量帧
  3. 旧结构的许多节点已经消失或度数归零 → 重建目标不复存在
```

**革命是一帧内撕裂的社会子图——修复需要千帧。** 这解释了为什么革命后的社会需要漫长重建，且重建后的社会永远不同于革命前。

## 三、技术变迁：新 V⁺ 通道的出现

### 3.1 技术 = 新型 V⁺ 操作符

新技术本质上是一种**之前不存在的边创建方式**：

| 技术 | SPUM 操作 |
|------|----------|
| 文字 | 跨时间 V⁺——与过去/未来节点建立概念边 |
| 印刷术 | 一对多 V⁺——单节点以极低成本向大量节点同时传递信号 |
| 互联网 | 全域 V⁺——任意两节点之间可以以极低 dv/dt 成本建立边 |
| AI | 自动 V⁺/V⁻——非人类节点可以在社会子图中执行 V⁺/V⁻ |

### 3.2 技术如何改变社会子图

```
新 V⁺ 操作符出现
  → V⁺ 成本降低 → 边密度上升 → σ 下降（更稠密社会）
  → 旧 V⁺ 通道（面对面、书信）萎缩——被低成本的替代
  → 拥有新操作符的节点度数暴增——新权力中心形成
  → 度数分布重构——旧度数排列被颠覆
  → 制度子图需要适配新度数分布——政治制度变迁
```

**印刷术摧毁了教会的介数权力**——因为《圣经》可以被每个节点直接阅读，不再需要神父作为中介节点。**互联网摧毁了传统媒体的介数权力**——因为信息可以在节点间直接传递，不再需要报纸/电视台作为守门人。

每一次重大的技术革命，本质上都是**一种新的 V⁺ 操作符**，它改变了社会子图中边的创建成本。当边创建成本大幅下降时，旧度数分布瓦解，旧制度跟随瓦解。

## 四、全球化：子图合并

### 4.1 全球化 = 多个社会子图之间的桥接边激增

```
全球化前：
  社会子图 A、B、C 各自相对独立
  跨子图边稀疏——∇σ_AB、∇σ_BC、∇σ_AC 大

全球化中：
  跨子图 V⁺ 操作符出现（航运、通信、互联网）
  → 跨子图边密度激增
  → ∇σ 在子图间趋于零
  → σ 分布整体趋向均匀
  → 各子图内部的制度需要与外部子图 σ 匹配
```

### 4.2 全球化的反冲

全球化使 ∇σ 趋零，但也产生反冲：

```
1. 局部 σ 同构被稀释——旧文化边界被跨国 V⁺ 打破
2. 某些节点的度数暴增（全球化受益者），某些节点的度数停滞（全球化受损者）
3. 旧制度子图（国家法律、本地习俗）与全球 σ 分布不兼容 → 制度张力
4. 受损节点联合切断跨子图边 → 退全球化（重新增大 ∇σ）
```

## 五、社会变迁的 SPUM 政策原理

### 5.1 变迁只能顺应 σ 漂移——不能逆流

任何试图"回到过去"的政策在拓扑上是不可能的——因为社会子图的 σ 分布已经发生了不可逆的漂移。政策能做的是：

| 能做的 | 不能做的 |
|--------|---------|
| 减缓 σ 漂移速度（保守主义） | 逆转 σ 漂移方向 |
| 加速新 V⁺ 通道的建设（进步主义） | 跳过 dv/dt 约束——单帧不能完成跨越多帧的变迁 |
| 缓冲级联 V⁻（社会保障） | 完全消除悬挂端——不完美定理禁止 |

### 5.2 健康的变迁 = ∇σ 在 H_social 内波动

社会子图有一个健康多面体 H_social。在 H_social 内部，∇σ 的波动是健康的——变迁发生但不撕裂子图。当 ∇σ 超出 H_social 边界，社会子图进入病态：

- ∇σ 过低：社会完全僵化——没有流动，没有创新，制度木僵
- ∇σ 过高：社会撕裂——连通分量可能分离，级联 V⁻ 风险急剧上升

**最好的社会政策不是"阻止变化"或"加速变化"——是让 ∇σ 保持在 H_social 内部。**

## 可计算化指标

### C7.1 异常比 δ（快变迁触发器）

```
δ = |ΔS_social| / S_social_base       —— 单帧结构变化量与基线的比值

其中:
  ΔS_social = S_social(t) − S_social(t−1) （当前帧 vs 前一帧的健康向量差）
  S_social_base = 该社会子图的长期平均 S_social

δ 阈值的经验范围:
  δ < 0.05: 逐渐变迁——社会在缓慢演化
  δ ∈ [0.05, 0.15]: 加速变迁——政治/经济改革的典型范围
  δ > 0.15: 临界区——制度边正在级联 V⁻（金形修剪激活）
  δ > 0.25: 快变迁/革命触发——社会子图正在重构
```

### C7.2 级联 V⁻ 概率 P_cascade

```
P_cascade = 1 − exp(−λ · δ · κ)

其中:
  κ = 度数集中度——关键节点的等效 deg / ⟨deg⟩
        （度量"大而不倒"的程度——κ 越大，一个节点的倒塌可触发更大的级联）
  λ = 制度韧性系数（制度子图的锁定强度 L_lock 越大，λ 越小）

P_cascade 判断:
  < 0.1: 社会可吸收冲击——制度韧性足
  ∈ [0.1, 0.4]: 局部危机——单个领域出问题
  ∈ [0.4, 0.7]: 系统性风险——可能全领域扩散
  > 0.7: 高度可能级联——革命在 k 帧内预计发生
```

### C7.3 社会碎片化指数 F

```
F = 1 − |V_largest_component| / N

其中 |V_largest_component| = 最大连通分量的节点数

F 的变迁轨迹:
  F → 0: 社会全连通——所有人在同一个连通分量（"大一统"社会）
  F → 1: 社会完全碎片化——所有人都孤立

变迁过程中的临界值:
  F < 0.1: 一体化社会
  F ∈ [0.1, 0.3]: 多元社会——存在多个连通分量但主流分量仍是多数
  F ∈ [0.3, 0.5]: 分裂社会——裂痕明显
  F > 0.5: 社会解体——没有主流分量
```

### C7.4 ∇σ 梯度幅度（社会张力）

```
|∇σ| = (1/|E|) · Σ_{(u,v)∈E} |σ(u) − σ(v)|

健康范围: |∇σ| ∈ [0.01, 0.15]

  |∇σ| < 0.01: σ 过于均匀——社会静止，无创新动力（火衰）
  |∇σ| ∈ [0.01, 0.10]: 健康梯度——有差异化驱动力但不撕裂
  |∇σ| > 0.15: 社会撕裂——不同群体间 σ 差距过大
  |∇σ| > 0.30: 临界——结构性断裂即将发生（→ δ_crit 逼近）
```

### C7.5 技术变迁冲击 T_impact

```
T_impact = Δ(Cost_per_V⁺) / Cost_per_V⁺_old

新技术使 V⁺_social 成本降低的幅度

T_impact > 0.2: 颠覆性技术——社会 V⁺ 模式正在重构
                （印刷术、互联网、社交媒体的 T_impact ≈ 0.5~0.8）
T_impact < 0.05: 渐进改良——现有社会结构不变
```

### C7.6 全球化度 G_global

```
G_global = |E_cross_border| / |E_social_total|

跨境社会边 / 总社会边

G_global → 0: 封闭社会——无跨境连接
G_global → 1: 完全全球化——所有边都是跨境的（物理上不可能）

当前实测: 互联网 G_global ≈ 0.3（30%的在线连接跨越国界）
```
