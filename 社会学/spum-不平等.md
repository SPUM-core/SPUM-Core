# SPUM × 不平等

> 归约路径：σ 分布不均匀 → 度数差异 → 信息不对称 → 资源不对称 → 社会分层
> 不平等不是"社会问题"——是 σ 梯度的必然后果。问题不是"有没有不平等"（一定有），而是"∇σ 是否过大导致社会子图碎裂"。

---

## 核心命题

**社会不平等 = 社会子图中 σ 分布的不均匀性 = 不同区域的节点度数和聚类系数的系统性差异。** 不平等的底层不是"资源分配不均"——资源分配是 σ 不均匀的**结果**，不是原因。原因是：**在有限帧的演化中，σ 分布从不均匀。**

不完美定理的社会版本：任何社会子图在任何时刻，σ 分布不可能完全均匀——必然存在某些区域的度数显著高于其他区域。

---

## 一、不平等的拓扑根源

### 1.1 为什么不平等必然存在

```
不完美定理（R5）：每帧必残留悬挂端。
  → 悬挂端集中于某些区域（度数低的节点群）
  → 这些区域的 σ 升高（节点多边少）
  → 其他区域（度数高的节点群）σ 降低
  → σ 梯度形成

结构重构能量不等式（MATH-009）：V⁺ < V⁻。
  → 高 σ 区域的节点倾向于向低 σ 区域流动（寻求连接）
  → 低 σ 区域的节点获得更多 V⁺ → 度数更高 → σ 更低
  → 马太效应：度数高的越高，度数低的越低
  → σ 梯度自我强化
```

### 1.2 σ 梯度的三个维度

| 维度 | σ 含义 | 不平等体现 |
|------|--------|-----------|
| **连接不平等** | 不同节点的 deg(v) 差异 | 有些人连接广泛，有些人孤立 |
| **信息不平等** | 不同节点可访问的信息量差异 | 枢纽节点掌握更多信息 |
| **认知不平等** | 不同认知子网对 σ 分布的压缩程度差异 | 不同阶层的"世界观"差异——σ 越不同，彼此的认知投影越无法同构 |

**认知不平等是最深层的、最被忽视的不平等。** 富人和穷人不仅资源不同——他们生活在完全不同的 σ 区域中，对世界的认知投影差异大到"不可翻译"。他们的拓扑位置使得他们看到的"现实"本身就是两张不同的子图。

## 二、不平等的累积机制

### 2.1 拓扑马太效应

```
第 τ 帧：
  A 的 deg = 10（高度数）
  B 的 deg = 2（最低安全值）

第 τ + 1 帧：
  A 因高度数 → 更多 V⁺ 候选（更多人想连接 A）
  B 因低度数 → 仅有的 V⁺ 候选是维持现状

第 τ + k 帧：
  deg(A) → deg_max（接近饱和）
  deg(B) → 仍在低位徘徊（没有额外 V⁺ 来源）

原因：V⁺ 事件不是随机的——是 σ 梯度驱动的。
      低 σ 节点（高度数）吸引更多 V⁺——正反馈。
      高 σ 节点（低度数）只能依赖自己主动发起 V⁺——但 dv/dt ≤ const 限制单帧可发起的连接数。
```

### 2.2 代际传递

不平等的代际传递 = σ 分布的跨帧继承：

```
父母的子图结构 → 子女的初始子图结构
  → 高度数父母的子女继承了高度数的邻域
  → 低度数父母的子女继承了低度数的邻域
  → 初始 σ 差异在子女的后续帧中自我放大
```

子女的初始社会子图不是"白纸"——他们从父母子图中继承了第一组边。这组边的度数和 σ 位置在很大程度上决定了他们未来 V⁺ 事件的方向。

## 三、社会流动性：∇σ 驱动的节点迁移

### 3.1 流动的拓扑定义

```
社会流动 = 节点从高 σ 区域向低 σ 区域的迁移
         = deg 从低值向高值的提升
         = 在 σ 梯度上的位置变化
```

一个人的社会流动，本质上是他在 σ 分布上的位置变化。从一个高 σ（连接稀、信息少）的区域移动到一个低 σ（连接密、信息多）的区域 = 社会上升。

### 3.2 流动的瓶颈

| 瓶颈 | 拓扑原因 |
|------|---------|
| 初始度数低 | 从低度数位置发起 V⁺ 的成本高于从高度数位置——因为需要逐帧累积 |
| 认知投影限制 | 高 σ 区域的人对低 σ 区域的认知投影压缩严重——"看不见机会" |
| 桥接缺失 | 高 σ 区域和低 σ 区域之间缺少桥接边（高介数边）——两个区域信息不连通 |
| dv/dt 约束 | 单帧变化上限——即使找到机会，也不能一帧内建立太多新连接 |

### 3.3 社会流动的 SPUM 策略

| 策略 | 拓扑操作 |
|------|---------|
| 桥接建立 | 与低 σ 区域的节点建立第一条跨区域边——"贵人"或"机会" |
| 认知校准 | 通过跨区域 V⁺ 获取低 σ 区域的 σ 分布样本——校正对目标区域的认知投影 |
| 逐帧累积 | 在 dv/dt 约束下，每帧建立一条新边——持续且方向一致（不完美定理：前帧的努力是后帧的起点） |
| σ 同构迁移 | 当自身 σ 与目标区域 σ 趋同时，水形链自然拉入——"你已经变成了那个圈子的人" |

## 四、不平等的"可接受"阈值

SPUM 给出的不是"如何消除不平等"——因为拓扑学告诉我们不平等不可消除。给的是**不等式**：

```
∀ 社会子图，
  σ_max / σ_min ≤ H_social  是健康的
  σ_max / σ_min > H_social  需要干预

H_social = 社会子图的 H 多面体边界
```

当最富裕区域的 σ 与最贫困区域的 σ 比值超过某个阈值，社会子图进入不稳定态：

- 认知撕裂：σ 差异太大 → 两端的认知投影不可翻译 → 无法达成共识
- 连通性危机：高 σ 区域和低 σ 区域之间的边完全断裂 → 形成两个独立连通分量
- V⁻ 级联风险：高 σ 区域集体切断与低 σ 区域的边 → 或反之——革命

**平等不是目标，稳定是目标。** 而稳定要求 σ 差异不超出社会子图的 H 多面体容纳范围。
