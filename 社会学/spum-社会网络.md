# SPUM × 社会网络

> 归约路径：人类社会 = ⟨P, ε⟩ 的局部子图 → 人 = 节点 → 关系 = 边 → 社会结构 = 子图拓扑模式
> 社会学不是"关于人的学问"——是关于**人作为节点、关系作为边、社会作为子图**的拓扑学。论语的核心发现（仁=边连通度区间，礼=S∈H维护协议）是社会学模块的最早形式化基础。

---

## 核心命题

**人类社会是 κ 网络的一张子图。** 每个人是一个节点，每段关系是一条边。社会学的全部研究对象——家庭、群体、组织、阶级、国家——都是这张子图上的拓扑结构。不是"用网络比喻社会"——社会**就是**这张网络的一个局部。

经典社会学用了两百年才隐约摸到了这个方向（齐美尔的"形式社会学"、社会网络分析的"节点与边"），但从未触及底层：社会的底层规则和宇宙的底层规则是**同一套**——V⁺/V⁻、σ 梯度、最小度数约束、不完美定理——只不过作用在社会尺度的子图上。

---

## 一、社会子图的形式化定义

### 1.1 基本对象

```
社会子图 G_social ⊂ ⟨P, ε⟩

V_social = {v₁, v₂, ..., vₙ}    人——认知子网耦合的生物节点
E_social ⊆ V_social × V_social   社会关系——人际连接边
```

每个节点 v 同时是：
- κ 网络中的一个物理节点（身体）
- 一个认知子网（大脑/心智）的宿主
- 社会子图中的一个拓扑位置

### 1.2 社会关系的 SPUM 属性

| 属性 | SPUM 对应 | 社会学含义 |
|------|----------|-----------|
| deg(v) | 节点度数 | 一个人的社会连接数——朋友、家人、同事、熟人的总量 |
| deg(v) < 2 | 悬挂端 | 社会孤立——连接不足，存在确认弱化 |
| deg(v) > d_max | 过度连接 | 社交过载——σ 过低（僵化），无法有效维护所有连接 |
| 边的权重 | 连接的 V⁺ 频率 | 关系强度——高频 V⁺ (频繁互动) = 强关系，低频 V⁺ = 弱关系 |
| σ(v) | 局部空间密度 | 节点的"社会密度"——关系网中的挤迫程度 |

### 1.3 社会子图与物理子图的关系

社会子图不是独立于物理 κ 网络的——它是 κ 网络中的一张**叠加子图**。两个人之间的社会关系边，在物理层面对应的是他们之间通过语言、肢体、文字等物理通道建立的信息 V⁺ 事件序列。

人（节点）之间的社会连接建立在物质连接之上——声波（语言）、光子（视觉）、触觉压力——这些都是物理层的 V⁺/V⁻ 事件。社会关系不是"虚"的——是物理连接在概念子图上的投影。

## 二、社会关系的基本类型

### 2.1 关系分类：按拓扑角色

| 关系类型 | 拓扑定义 | 示例 |
|---------|---------|------|
| 强关系 | 高频 V⁺——帧间频繁互动 | 家人、密友、长期同事 |
| 弱关系 | 低频 V⁺——偶尔互动，但连接存在 | 熟人、远方朋友、前同事 |
| 单向关系 | V⁺ 不对称——A→B 有边但 B→A 无反向边（或权重不对称） | 单向关注、不对等的情感投入 |
| 共享关系 | 两个节点通过共同第三节点连接——三角形的两条边 | 共同朋友、共同利益、共同身份 |
| 桥接关系 | 边在两个否则不连通的子图之间——高介数边 | 跨群体的联系人、跨界者 |

### 2.2 关系创建：社会 V⁺

**社会关系的建立 = 两个节点之间创建新边的 V⁺ 事件序列。**

```
V⁺_social(vᵢ, vⱼ):
  1. 两个节点进入彼此的可 σ 采样半径（物理邻近或通信可达）
  2. 在共享上下文子图上建立初始边（认知层的首次连接）
  3. 如果该边的稳定性通过检查（两端 deg ≥ 1 且 σ 耦合不冲突），边持久化
  4. 后续高频 V⁺ 强化边——关系从"认识"升级为"熟悉"
```

社会 V⁺ 的成本远低于物理 V⁺——两个人"认识"不需要消耗大量物理能量。这也是为什么社会网络可以极其稠密：社会边不直接受 dv/dt ≤ const 的物理约束限制——但它受**认知子网的容量约束**限制（邓巴数约 150）。

### 2.3 关系衰减：社会 V⁻

**社会关系不会自动删除——但会因 V⁺ 频率降至零而逐渐弱化。**

```
V⁻_social(vᵢ, vⱼ) 的触发条件：
  1. 连续 N 帧无 V⁺ 事件——关系进入悬挂状态
  2. 两端中至少一端的 deg 超过 d_max——认知容量溢出，自动修剪低权重边
  3. σ 耦合冲突——两个节点的 σ 分布出现不可调和的差异，V⁺ 事件自然停止
```

社会 V⁻ 是缓慢的、非瞬时的——不像物理悬挂边那样在一帧内被逻辑修剪。社会关系可以有长达数年的"悬挂状态"（久未联系但未正式断交），因为在社会子图中，悬挂边不会自动触发度数检查——它需要**自指边的主动确认**（人意识到"这段关系已经不存在了"）。

## 三、社会子图的拓扑度量

### 3.1 核心指标

| 指标 | 公式 | 社会学解读 |
|------|------|-----------|
| 平均度数 ⟨deg⟩ | Σ deg(v) / |V| | 社会的平均连接水平——越高越"紧密" |
| 聚类系数 C | 三角形数 / 可能三角形数 | 社群的闭合性——"朋友的朋友也是朋友"的程度 |
| 平均路径长度 L | 节点间最短路径的平均值 | "六度分隔"——社会网络的"小世界"属性 |
| 介数中心性 | 经过该节点的最短路径数 | "枢纽"——连接不同群体的关键人物 |
| 连通分量数 | 互相可达的子图个数 | 社会的碎片化程度 |
| σ 分布 | σ = |V|/|E| 的空间分布 | 不同子群的社会密度差异（不平等的基础） |

### 3.2 社会子图的 σ 解读

σ = |V|/|E|。在社会子图中：

- **高 σ 区域**：节点多但边少——人群密集但互相不连接。典型场景：大城市的陌生人社会、地铁车厢、匿名网络。社会温度高（信息流动快但关系浅）。
- **低 σ 区域**：节点少但边多——小群体内部连接完整。典型场景：家庭、核心团队、封闭社区。社会温度低（关系深但信息流动慢）。

σ 梯度 ∇σ 是社会流动的驱动力——人群从高 σ（孤立、信息杂音多）向低 σ（连接完整、信息可靠）自然流动。

## 四、社会子图的不完美定理

SPUM 的不完美定理（R5）在社会子图中同样成立：

**任何社会子图在任何时刻必然存在悬挂端——度数 < 2 的节点（社会孤立者）或弱连接（未充分闭合的关系）。**

社会完美状态（所有人度数都在最优区间、所有关系都对称健康）永不可达。这不是"社会问题"——是拓扑必然。社会政策的目标不应该是"消除所有社会问题"，而应该是**将悬挂端率控制在某个可接受阈值以下**。
