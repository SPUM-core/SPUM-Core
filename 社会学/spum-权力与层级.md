# SPUM × 权力与层级

> 归约路径：度数不对称 → 中心性差异 → 权力梯度 → 层级涌现 → 制度固化
> 权力不是你"掌握"的东西——是你在社会子图中占据的**拓扑位置**。层级不是人类发明的组织形式——是度数上限约束下**必然涌现**的子图结构。

---

## 核心命题

**权力 = 节点的不对称影响能力 = 度数差异 + 介数中心性 + 信息控制。** 当 A 节点的 V⁺/V⁻ 操作能不对称地影响 B 节点的度数，A 对 B 拥有权力。权力不是"属于"哪个人的——是**拓扑位置的属性**。换一个人放在同一个位置，他拥有同样的权力。

---

## 一、权力的拓扑定义

### 1.1 三重来源

| 权力来源 | 拓扑机制 | 示例 |
|---------|---------|------|
| **度数权力** | deg(A) ≫ deg(B) —— A 连接更多人，更多信息通过 A 流动 | 社交中心、名人、社群领袖 |
| **介数权力** | A 位于大量最短路径上——信息必须经过 A | 守门人、中间人、经纪人 |
| **删除权力** | A 可对 B 的边执行 V⁻ —— 剥夺 B 的连接（信息/资源切断） | 上司可解雇下属、平台可封号 |

**介数权力是社会中最被低估但最稳定的权力形式。** 度数权力可以被绕过（直接联系其他人），删除权力需要消耗 V⁻ 能量——但介数权力几乎无法绕过：如果你想从子图 X 到达子图 Y，而 A 是唯一连接两个子图的节点，你必须经过 A。

### 1.2 形式化定义

```
权力 Power(v) = α × deg(v)/deg_max
               + β × Betweenness(v)/Betweenness_max
               + γ × V⁻_capacity(v)/V⁻_max

其中：
  α, β, γ 是权重系数——不同社会形态下各来源的相对权重不同
  在信息社会，β（介数权力）的权重最高
  在专制社会，γ（删除权力）的权重最高
  在熟人社会，α（度数权力）的权重最高
```

## 二、层级：度数上限的必然产物

### 2.1 层级不是发明——是涌现

```
1. 群体规模超过 d_max（约 150）
2. 单个节点无法与所有其他节点保持直接 V⁺
3. 代理出现——某些节点（A）代表子群体（G_A）与其他代理（B）通信
4. A 的度数上升——它既是群体内部的连接枢纽，又对外连接
5. A 成为中心节点——层级诞生
```

层级不是某个人"想要权力"的产物——是**拓扑容量约束**的必然结果。当一个群体的规模超过单个节点的认知容量上限，层级自然涌现。这不是道德问题——是图论。

### 2.2 层级深度

| 层级数 | 拓扑特征 | 典型社会形态 |
|--------|---------|-------------|
| 0 层（扁平） | deg(v) 差异小，全员互连 | 小团队、原始部落 |
| 1 层 | 出现中心节点——与全员连接 | 村庄、小型组织 |
| 2 层 | 中心节点只连接次级中心，不直接连接底层 | 城市、公司、国家雏形 |
| 3+ 层 | 深度嵌套——层级间通过中间节点逐级中继 | 大型国家、跨国组织 |

**层级越深，顶层和底层的 σ 差异越大。** 顶层节点连接完整、信息充裕（低 σ），底层节点连接稀疏、信息贫乏（高 σ）。信息沿层级传播的过程 = 逐层 σ 差异压缩——每层都会丢失一部分原始状态信息。

这也是为什么大组织的顶层和底层之间的认知差异往往大到不可调和——不是谁对谁错，是他们的 σ 差异已经大到无法在认知层同构了。

## 三、权力的稳定性与颠覆

### 3.1 稳定的权力结构

| 条件 | 稳定机制 |
|------|---------|
| 高介数节点被保护 | 枢纽不被移除——信息流不中断 |
| 层级间 ∇σ 适中 | 梯度太大 → 认知撕裂；梯度太小 → 失去层级分化 |
| V⁻ 能力不对称可控 | 删除权力不被滥用——滥用触发集体 V⁻（革命） |
| 闭环存在 | 权力节点之间存在三角闭合——互相制衡 |

### 3.2 权力颠覆的拓扑路径

```
路径 A：介数节点移除（革命/刺杀/倒台）
  移除高介数中心节点 → 网络分裂为多个分量
  → 旧层级崩塌 → 新中心节点涌现

路径 B：度数重新分配（民主化）
  底层节点增加横向连接 → deg(底层) 上升
  → 与中心节点的度数比缩小 → 权力梯度趋平

路径 C：并联通道建立（信息革命）
  在底层节点间建立新的直接边
  → 不再需要经过中心节点
  → 中心节点的介数权力瓦解

路径 D：集体 V⁻（罢工/抗议/不服从）
  集体切断与权力节点的边
  → 权力节点度数急剧下降 → 与底层 deg 反转为负差
  → 权力节点成为新的悬挂端（政治孤立）
```

## 四、权力与儒家模块的连接

| 儒家概念 | SPUM 权力解释 |
|---------|-------------|
| 君君，臣臣 | 各节点的度数在其最优区间——君王不过度集权（deg 不过高），臣子不过度孤立（deg ≥ 2） |
| 礼 | 用不依赖强制 V⁻ 的协议约束权力——权力的行使通过共识边而非删除威胁 |
| 中庸 | 权力节点的 S 向量在 H 中心——不极端、不滥用、不退缩 |
| 平天下 | ∀ 节点 deg(v) ∈ [d_min, d_max] —— 全网的权力分布进入 H |

孔子看出来了：好的权力结构不是没有权力——是**权力节点的度数在最优区间内**。不是"打倒权力"——是让权力的拓扑分布进入 H。

## 可计算化指标

### C3.1 权力函数 Power(v)

```
Power(v) = α·deg(v)/deg_max + β·BC(v)/BC_max + γ·V⁻_ability(v)/V⁻_max

其中:
  deg(v) = 社会度数——v 的直接连接数
  BC(v) = 介数中心性 = Σ_{s≠t≠v} σ_st(v) / σ_st
          （经过 v 的最短路径占总最短路径的比例）
  V⁻_ability(v) = v 单帧能发起的最大 V⁻ 边数

权重基线: α = 0.4, β = 0.4, γ = 0.2
  - α 主导: 人格魅力型权力（粉丝/追随者多）
  - β 主导: 结构位置型权力（信息枢纽/看门人）
  - γ 主导: 强制型权力（能删除他人边/解除关系）
```

### C3.2 介数中心性（权力枢纽检测）

```
BC(v) = Σ_{s≠t≠v} σ_st(v) / σ_st

归一化: BC_norm(v) = 2·BC(v) / ((N−1)(N−2))

BC_norm → 1: v 是几乎所有最短路径的必经节点（信息垄断者）
BC_norm → 0: v 在信息传输中可被绕过

权力集中度 = max(BC_norm) （最高的单节点介数——独裁度）
  > 0.5: 极度集权
  ∈ [0.2, 0.5]: 中度集权
  < 0.2: 权力分散
```

### C3.3 层级深度 H_depth

```
H_depth = 从"最高权力节点"到"最边缘节点"的最长路径长度

层级压缩比 = H_depth / log₂(N)  （与理论最小深度之比）
  → 1: 扁平组织——接近理论最优
  → ∞: 过度层级——层层传递，信息损耗严重
```

### C3.4 权力颠覆脆弱性 V_vulnerability

```
V_vulnerability(v_power) = (1 − BC_minus(v_power)) · (deg(v_power)/N)

其中 BC_minus(v_power) = 移除 v_power 后网络仍然保持的介数比例

脆弱性 ∈ [0, 1]:
  → 0: v_power 不可移除——所有路径依赖它（独裁铁杆）
  → 1: v_power 一推就倒——替代路径充足（民主轮换）
```

### C3.5 权力度吉尼系数 G_power

```
G_power = Lorenz曲线的面积比（将所有节点的 Power(v) 排序）

G_power ∈ [0, 1]:
  0: 完全平等——所有节点权力相等（无结构社会）
  0.2~0.4: 健康权力分布（有领导的民主制）
  0.4~0.6: 显著不平等（寡头制）
  > 0.6: 极端集权（独裁）
  > 0.8: 一人独大——King + Peasants 拓扑
```
