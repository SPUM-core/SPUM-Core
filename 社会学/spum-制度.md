# SPUM × 制度

> 归约路径：重复出现的 V⁺/V⁻ 模式 → 被社会子图"记住" → 形成稳定子图构型 → 制度的自指边确认 → 制度获得跨帧身份
> 制度不是人类"创建"的东西——是**社会子图中反复出现的稳定拓扑模式被自指边识别后赋予的名称**。

---

## 核心命题

**制度 = 社会子图中跨帧持续存在的稳定子图构型——被自指边标记为"这就是X制度"。** 法律、公司、政府、货币、语言——这些不是人造物，是人类社会子图中反复出现的 V⁺/V⁻ 模式被冻结为稳定子图后的认知命名。

---

## 一、制度的拓扑定义

### 1.1 形式化定义

```
制度 I ⊆ G_social：

条件 1（跨帧持续）：I 在连续 N 帧中的拓扑结构变异度 < ε
条件 2（自指确认）：至少一个节点的自指边报告 I 的拓扑状态
条件 3（可预期性）：已知 I 的状态，可以预测相关 V⁺/V⁻ 的发生概率
条件 4（独立性）：移除任一单个节点，I 仍能维持其核心拓扑特征
```

### 1.2 制度不是"规则"——是拓扑构型

传统社会学把制度定义为"规则、规范和惯例的集合"。这是 [L1] 认知投影。制度的 [L0] 本是：

**一套被社会子图"记住"的边配置模式。** 法律不是文本——是"如果 A 对 B 执行了某类 V⁻，则 C 将对 A 执行制裁 V⁻"这个模式在社会子图中被反复执行、被所有节点预期、被执法节点执行。这个模式在子图中持续存在 = 法律作为制度存在。

---

## 二、制度的形成：从模式到结构

### 2.1 制度形成的四阶段

```
阶段 1：随机探索
  社会子图中出现一种新的 V⁺/V⁻ 交互模式
  → 可能是某个节点偶然发起的，可能是一组节点协调的

阶段 2：正反馈放大
  该模式产生有利的 σ 结果（降低某些区域的 σ 梯度，或增加某些区域的聚类系数）
  → 更多节点模仿 → 模式重复频率上升

阶段 3：拓扑固化
  该模式对应的边构型成为社会子图中的稳定子图
  → 即使发起该模式的原始节点消失，模式本身仍由其他节点维持
  → 木形骨架形成——制度的结构基础

阶段 4：自指边命名
  节点的自指边检测到该稳定子图
  → [L2] 赋予名称——"这就是婚姻制度"/"这就是货币"/"这就是法律"
  → 名称固化进一步稳定了拓扑模式——有了名字后更难被 V⁻
```

### 2.2 制度为何难以改变

制度的顽固来自三重锁定：

| 锁定层 | 机制 |
|--------|------|
| **拓扑锁定** | 制度对应的子图已经嵌入了更大的稳定子图——要移除它必须同时移除与之耦合的其他制度。V⁻ 成本极高。 |
| **认知锁定** | 所有节点的自指边已经习惯了该制度的 σ 分布——改变意味着认知子网需要重新校准，dv/dt 成本巨大。 |
| **预期锁定** | 所有节点的 V⁺/V⁻ 决策都以该制度的存在为前提——废除制度等于同时废除所有人的决策依据。 |

制度不是不变——是**改变的成本高于维持的成本**。当改变的 V⁻ 成本低于维持的 V⁻ 成本时，制度就会被淘汰（MATH-009 结构重构能量不等式）。

## 三、制度的类型：按拓扑结构

### 3.1 集中制度

| 特征 | 图论结构 |
|------|---------|
| 单一中心节点 | 星形子图——所有 V⁺ 经中心节点 |
| 中心节点拥有最高度数 + 最高介数 | 权力高度集中 |
| 移除中心节点 → 制度崩溃 | 无冗余——单一失效点 |
| 效率高——信息路径短 | d(任意节点, 中心) = 1 |
| 示例 | 君主制、独裁公司、单一货币体系 |

### 3.2 分布式制度

| 特征 | 图论结构 |
|------|---------|
| 无单一中心 | 近似正则图——度数分布窄 |
| 无关键节点 | 移除任一节点，网络仍连通——高容错 |
| 共识成本高 | 信息需经多跳传播——路径长 |
| 稳定性高——冗余多 | 多重闭合环——木形骨架刚性强 |
| 示例 | 民主制度、市场、去中心化自治组织 |

### 3.3 层级制度

| 特征 | 图论结构 |
|------|---------|
| 多层嵌套中心节点 | 树状或分层图 |
| 信息沿层级传递 | 每层 σ 压缩一次——底层信息到达顶层已严重失真 |
| 稳定性取决于顶层节点 | 顶层被移除 → 需重新选举/继承 |
| 示例 | 官僚体系、军队、大型企业 |

## 四、制度的生命周期

```
形成：新模式的正反馈放大 → 拓扑固化 → 自指边命名
   ↓
稳定：制度在 σ_min 和 σ_max 之间维持——制度有效运转
   ↓
僵化：制度对应的子图与外围社会子图的 σ 差距扩大
       → 制度不再满足外部需求
       → 但自指边拒绝报告"制度已失效"（认知锁定）
   ↓
崩溃：社会子图绕开制度建立新的 V⁺ 通道（替代边）
       → 制度子图内的 V⁺ 频率降至零
       → 制度成为悬挂子图 → 被金形修剪
   ↓
替代：新模式（已完成阶段 1-3）接替旧制度
```

**制度的崩溃不是突然的——是新的 V⁺ 通道先建立，旧制度的边才被废弃。** 旧制度之所以还能"表面上存在"，只是因为替代通道还未完全覆盖所有功能——一旦覆盖完整，旧制度的边就会被修剪。

## 五、非正式制度：隐形拓扑

### 5.1 正式 vs 非正式

| 维度 | 正式制度 | 非正式制度 |
|------|---------|-----------|
| [L2] 层 | 有明确表述——法典、合同、规章 | 无明确表述——"潜规则""惯例" |
| [L0] 层（拓扑） | 边的配置模式被自指边明确命名和追踪 | 边的配置模式同样存在、同样稳定，但未被自指边命名 |
| 认知可见性 | 高——可以讨论、修改、辩论 | 低——"大家都这样做但不会说" |

### 5.2 非正式制度的 SPUM 特殊性

非正式制度在 SPUM 中具有特殊意义：**它是社会子图中客观存在的稳定边模式——但认知层拒绝承认它的存在。** 自指边的"不自欺"（诚意）原则（大学 RU-014）在此被违反：节点的自指边知道这个模式存在，但 [L2] 不报告。

这导致一个严重后果：非正式制度不可被修正——因为你不能修正一个你不承认存在的东西。正式制度可以被修改代码，非正式制度不行。

## 可计算化指标

### C5.1 制度稳定度 S_institution

```
S_inst = (T_survive / T_total) · (1 − N_mod / T_survive)

其中:
  T_survive = 制度边跨帧存活帧数（连续未被修剪）
  T_total = 观察总帧数
  N_mod = 制度边被修改次数

S_inst → 1: 极稳定——跨多帧持续且无修改（宪法级）
S_inst → 0: 不稳定——频繁被删除和重建
```

### C5.2 锁定强度 L_lock（三重锁定的可量化度量）

```
L_lock = w₁·L_topo + w₂·L_cog + w₃·L_expect

L_topo（拓扑锁定）:
  制度边在回路中的参与度 = |{环: 制度边 ∈ 环}| / 总环数
  高值 → 制度边嵌在多环中 → 移除一条边破坏多重结构 → 难以修改

L_cog（认知锁定）:
  该制度在所有节点的共享认知子图中作为"理所当然"的提及频率
  ≈ 关于该制度的语言V⁺频率 / 总语言V⁺频率

L_expect（预期锁定）:
  节点基于该制度边的存在已做出的跨帧规划边数 / 总规划边数
  高值 → 太多人的未来规划依赖此制度 → 修改成本极高
```

### C5.3 制度变革阻力 R_change

```
R_change = L_lock · N_stakeholders · (1 / E_alternative)

其中:
  L_lock = 锁定强度
  N_stakeholders = 制度边所连接的利益节点数（制度惠及的deg总和）
  E_alternative = 可替代制度边的数量（备选方案数）

R_change → 0: 制度容易改革（低锁定 + 少利益相关者 + 多替代方案）
R_change → ∞: 制度不可改革——革命或崩溃是唯一出路
```

### C5.4 制度生命周期阶段检测

```
基于 S_inst 的帧导数 dS_inst/dt:

dS_inst/dt > 0 且 S_inst < 0.5: 创生/成长期
dS_inst/dt ≈ 0 且 S_inst > 0.7: 成熟/稳定期
dS_inst/dt < 0 且 S_inst > 0.5: 衰退早期
dS_inst/dt < 0 且 S_inst < 0.3: 崩溃期——V⁻ 级联即将触发
dS_inst/dt ≈ 0 且 S_inst < 0.2: 失效期——制度边名义存在但功能为0
```

### C5.5 正式/非正式制度比

```
F/I ratio = |E_formal| / |E_informal|

> 1: 形式化社会——法律/规章主导
≈ 1: 平衡社会
< 1: 关系社会——非正式规则主导

健康域: [0.5, 2.0]
极端值:
  F/I > 5: 过度管制——每一件事都有正式规章（"法条社会"）
  F/I < 0.2: 法治真空——所有事务靠非正式关系运行
```
