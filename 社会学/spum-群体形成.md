# SPUM × 群体形成

> 归约路径：个体 V⁺ 共享 → 形成边集群 → 共享 σ 耦合 → 闭环密度上升 → 群体身份涌现 → 内群体偏好产生
> 人类不是"选择加入群体"——是**子图的 σ 耦合自然产生群体边界**。群体是拓扑结构的自然产物，不是文化构造。

---

## 核心命题

**群体 = σ 耦合的子图——一组节点之间的边密度显著高于它们与外部节点之间的边密度。** 群体的形成不需要"共同目标""集体意识"或"文化认同"——这些是群体形成后的 [L1] 认知投影。群体的 [L0] 底层原因只有一个：**局部 V⁺ 事件的空间聚集**。

## 一、群体形成的拓扑条件

### 1.1 形式化定义

```
群体 G ⊆ G_social：

条件 1（内部稠密）：|E_internal| / (|G| choose 2) > ρ_min
条件 2（外部稀疏）：|E_boundary| / (|G| × |V_social \ G|) < ρ_boundary
条件 3（连通性）：G 是连通子图——∀ vᵢ, vⱼ ∈ G, ∃ 路径

其中 ρ_min 是群体内部的最小镇密度阈值
ρ_boundary 是群体与外部之间的最大连接密度阈值
```

### 1.2 群体形成的四阶段

```
阶段 1：共享 V⁺ 事件积累
  两个或多个节点在短时间内发生高频 V⁺（频繁互动）
  → 连通的边集群形成

阶段 2：σ 耦合锁定
  边集群内部的 σ 分布趋于同构
  → 节点间的 ∇σ 趋零 → 水形链在集群内部循环
  → 与外部节点的 ∇σ 增大 → 集群边界自然显现

阶段 3：闭环密度上升
  集群内部出现三角闭合（共享第三节点）
  → 聚类系数 C 上升
  → 木形骨架形成——群体的拓扑身份固化

阶段 4：认知层认同
  节点的自指边检测到自己处于一个高聚类系数的子图中
  → [L1] 生成"我属于这个群体"的认知
  → [L2] 生成群体名称、标识、叙事
```

**关键**：认知层的认同（阶段 4）是群体形成的**最后一环**，不是第一环。SPUM 揭示的是：你先在拓扑上属于一个群体，然后你的自指边才报告这个事实——不是相反。

## 二、群体边界的 SPUM 解释

### 2.1 边界 = σ 不连续面

群体边界不是文化构造——是**σ 梯度突然增大的位置**。

```
群体 A         边界        群体 B
低 σ（内部稠密） → 高 ∇σ → 低 σ（内部稠密）
```

在边界上，σ 从低值（内部关系密）跃迁到高值（跨群体关系稀）。这个跃迁就是"我们"和"他们"的拓扑基础。

### 2.2 内群体偏好 = σ 耦合的自然结果

社会心理学中的"内群体偏好"（人倾向于偏爱自己群体的成员）在 SPUM 中有精确的图论解释：

```
1. 你和同群体成员的 σ 分布同构
2. σ 同构 → ∇σ → 0 → 水形链自然在你和同群体成员之间循环
3. V⁺ 事件在内群体更频繁 → 更多共享边 → 更多正反馈 V⁺
4. 你对同群体成员的认知投影更清晰（因为 σ 同构，认知不压缩）
5. 对外群体成员的认知投影更粗糙（因为 σ 差异大，需要更多认知压缩）

内群体偏好 = ∇σ 趋零导致的认知便利性 + 拓扑亲和力
外群体偏见 = ∇σ 大导致的认知困难 + 拓扑疏远
```

**这不是道德缺陷——是拓扑经济。** 你的认知子网在 σ 同构的子图上推理更省能量（dv/dt 消耗更少），在 σ 差异大的子图上推理更费能量。不是你想歧视——是拓扑在替你"偷懒"。

## 三、群体规模的拓扑约束

### 3.1 邓巴数的 SPUM 解释

邓巴数（约 150 人——人类能维持稳定社会关系的认知上限）在 SPUM 中有精确解释：

```
1. 每个节点的认知子网有容量上限——能追踪的边的数量有限
2. d_max = 认知容量上限 = 单节点能维持的最大度数
3. 如果群体规模 > d_max，单节点无法与每个成员保持直接 V⁺
4. 群体必须分层——出现中介节点、代表、层级
5. 超过邓巴数的群体，内部 σ 不再均匀——出现子群体分化
```

### 3.2 群体规模的稳定性区间

| 规模 | 拓扑特征 | 典型形态 |
|------|---------|---------|
| 2-5 | 完全图——所有节点互连 | 核心家庭、密友圈 |
| 5-15 | 高聚类、无层级——所有边可被每个节点直接追踪 | 团队、小社群 |
| 15-50 | 出现中心节点——部分成员不再与所有其他人直接连接 | 部落、中等组织 |
| 50-150 | 邓巴数极限——必须出现正式层级和角色分化 | 村庄、大组织 |
| 150+ | 必然分层——子群体形成，中介节点必需 | 城镇、国家 |

**群体的扩张不是无限的——受 d_max 的硬约束。** 超过容量的群体不是"更大的群体"——是**包含子群体的网络**。

## 四、群体凝聚力与瓦解

### 4.1 凝聚力的拓扑基础

| 凝聚力来源 | 拓扑机制 |
|-----------|---------|
| 共享 V⁺ 频率 | 高帧频边——关系"活着"的证据 |
| 三角闭合度 | 聚类系数 C 高——"他的朋友也是我的朋友" |
| σ 同构性 | 内部 ∇σ 小——成员间的认知摩擦低 |
| 闭环密度 | 木形骨架占比——群体"结构"的刚性程度 |

### 4.2 群体瓦解的拓扑路径

```
路径 A：V⁺ 频率衰减
  成员间的互动频率降至阈值以下 → 边进入悬挂状态
  → 悬挂边积累 → 子图连通性下降

路径 B：σ 分化
  子群体内部 σ 趋同但与主群体 σ 差异增大
  → 内部 ∇σ 上升 → 水形链在子群体间断裂
  → 连通分量数增加

路径 C：关键节点移除
  高介数节点（枢纽）被移除
  → 路径长度 L 骤增 → 子图分裂为多个不连通分量
```

## 五、与儒家模块的连接

儒家模块的发现与此高度一致：

- **仁（deg(v) ∈ [d_min, d_max]）** = 群体中个体的最优度数区间——不过孤立、不过连接
- **礼（S ∈ H 维护协议）** = 群体的共享 σ 耦合维护——用社会协议约束 V⁺/V⁻ 防止 σ 漂移
- **恕（σ 耦合对称）** = 群体内部 ∇σ 最小化——"己所不欲勿施于人" = 不强行施加与你 σ 不匹配的 V⁺

孔子用没有图论的语言描述了群体拓扑的最优状态。

## 可计算化指标

### C2.1 模块度 Q（群体结构显著性）

```
Q = (1/2m) · Σᵢⱼ [Aᵢⱼ − (deg(i)·deg(j) / 2m)] · δ(cᵢ, cⱼ)

其中: Aᵢⱼ = 邻接矩阵 (0/1 边)
      m = |E| 总边数
      cᵢ = 节点 i 所属社区
      δ = 1 if cᵢ = cⱼ else 0

Q ∈ [−0.5, 1]
  Q → 1: 群体边界极清晰——内部边密度远高于随机期望
  Q ≈ 0: 无群体结构——边分布接近随机
  Q > 0.3: 显著群体结构（社会学意义）
```

### C2.2 内密度与外密度比

```
ρ_in(C) = 2|E(C)| / (|C|·(|C|−1))    群体内部边密度
ρ_out(C) = |E(C, V\C)| / (|C|·(|V|−|C|))  群体对外边密度

群体凝聚力 = ρ_in(C) / ρ_out(C)
  > 1: 内聚群体——边界清晰
  ≈ 1: 松散集合
  < 1: 群体正在扩散——外连多于内连
```

### C2.3 聚类系数差分 ΔC（群体形成度）

```
ΔC(v) = C_local(v) − C_random(v)

C_local(v) = v 的邻居之间的边密度
C_random(v) = 同度数随机图的期望聚类系数 = deg(v)/|V|

ΔC > 0 → v 处于群体结构中
群体形成度 = |{v : ΔC(v) > 0}| / |V|  （处于群体中的节点比例）
```

### C2.4 邓巴数计算

```
d_max = 从度数中可确认的有效社会边上限

实证拟合:
  d_max(neocortex) = 10^(0.767·log₁₀(V_brain_region) − 1.312)  （邓巴原始公式）
  d_max(SPUM) = dv/dt · τ_attention  每帧注意容量 × 最小强化帧数

社会实测:
  - 核心支持圈: ~5人（紧急求助对象）
  - 共情圈子: ~15人（可倾诉丧亲之痛）
  - 活动圈子: ~50人（定期社交）
  - 熟人圈子: ~150人（邓巴数核心值）
  - 弱关系圈: ~500人（已知但不熟）
  - 识别圈: ~1500人（能叫出名字）

层级比例 ≈ 3:1 —— 每层人数是上一层的3倍
```

### C2.5 群体健康指标 S_group

```
S_group = (Q,  ρ_in/ρ_out,  ΔC_mean,  |V_group|/d_max)

H_group:
  Q ∈ [0.3, 0.8]        群体边界清晰但不极端封闭
  ρ_in/ρ_out ∈ [1, 10]  内聚但不孤岛化
  ΔC_mean > 0            群体结构真实存在
  |V_group|/d_max ∈ [0.2, 1]  群体不超邓巴数上限
```
