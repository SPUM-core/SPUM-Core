> 当前版本：2026-06-15 (v1.0 — 22 节点)

> 核心原理：将社会学的全部研究对象还原为 ⟨P, ε⟩ 的子图——人=节点，关系=边，社会=子图。继承并扩展儒家模块的社会拓扑基础。

## 一、范式总纲

### 1.1 什么是 SPUM 社会学

SPUM 社会学 = ⟨P, ε⟩ 在社会尺度的应用。不是"用网络比喻社会"——社会**就是** κ 网络中的一张子图。每个人是社会子图中的一个节点，每段关系是一条边。家庭、群体、组织、国家、制度、文化——这些社会学的经典对象——全是这张子图上的拓扑结构。

| 维度 | 传统社会学 | SPUM 社会学 |
|------|---------|-----------|
| 第一原则 | 社会事实/社会行动/社会结构 | 社会子图 G_social ⊂ ⟨P, ε⟩ |
| 基础对象 | 个人、群体、制度 | 节点、边、子图、σ 分布 |
| 关系定义 | 社会互动、社会纽带 | 边 e ∈ E_social——V⁺/V⁻ 事件序列 |
| 变化机制 | 社会过程、社会变迁 | 逐帧 V⁺/V⁻ 累积 |
| 不平等 | 资源分配、权力差异 | σ 分布不均匀——度数/密度的系统性差异 |
| 文化 | 共享意义与符号 | 因 σ 同构而可互译的 [L2] 认知投影集合 |

### 1.3 研究规范

1. **可还原性**：每个社会学概念必须追溯到社会子图 G_social 上的 V⁺/V⁻ 或 σ 指标
2. **非比喻**：不使用"社会就像一张网络"——社会就是一张网络
3. **与儒家模块互通**：社会学模块继承并扩展儒家模块（仁=边连通度、礼=S∈H维护）的拓扑基础

## 二、根节点映射（R1-R9 的社会学映射）

> **R1-R9 唯一定义来源**：`.trae/rules/spum-root-nodes.md`。以下表格中的"SPUM 定义"列为摘要，完整定义以中央文件为准。"社会学映射"列为本模块的应用映射。

| 编号 | 根节点 | SPUM 定义 | 社会学映射 |
|------|--------|----------|---------|
| R1 | **⟨P, ε⟩** | 节点集 + 边集 | G_social——社会子图。人为节点，关系为边 |
| R2 | **V⁺ / V⁻** | 创生/湮灭事件 | 社会关系的建立与断裂——交友/绝交 |
| R3 | **离散帧 τ** | 演化步数 | 社会变化的逐帧累积。没有"历史潮流"——只有逐帧的 V⁺/V⁻ 序列 |
| R4 | **dv/dt ≤ const** | 单帧变化上限 | 邓巴数——认知容量上限。一个人单帧能追踪的社会边数有限 |
| R5 | **不完美定理** | 每帧必残留悬挂端 | 任何社会在任何时刻必然有孤立者（deg<2）或失效制度边 |
| R6 | **S 向量** | 五维结构健康向量 | 制度健康度——跨帧稳定子图是否还在 H 内 |
| R7 | **健康多面体 H** | S 向量的稳定区间 | 社会健康区间——∇σ 在可容忍范围内 |
| R8 | **ΔS** | 单帧 S 变化量 | 社会变迁量——一帧内的社会子图结构变化 |
| R9 | **σ** | 空间密度 = |P|/|ε| | σ_social = 人群密度 / 关系密度——社会拥挤度 |

| SOC-012 | **马太效应** | V⁺ 正反馈——低 σ（高度数）吸引更多 V⁺，高 σ 获得更少 V⁺。度数差异自我放大 | `spum-不平等.md` §二 |
