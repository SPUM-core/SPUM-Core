# SPUM × 句法与结构

> 归约路径：句法 = 信号V⁺序列中的组合约束规则 → 短语 = 子图 → 句子 = 闭合子图 → 递归 = 自指V⁺嵌入
> 句法不是"语言的结构规则"——是**概念子图的拓扑关系如何被线性化编码为信号V⁺序列的组合约束**。乔姆斯基的"普遍语法"=所有人类认知子图共享的最小信号组合约束集。

---

## 核心命题

**句法 = 将概念子图的拓扑关系线性化为信号V⁺序列的组合约束规则集。** 概念子图中的"猫"和"追"和"老鼠"三者之间的拓扑关系（猫→追→老鼠）是一个三角形的网络结构。线性编码必须把这个三角形**序列化**——[猫, 追, 老鼠] 或 [老鼠, 被, 猫, 追]。不同语言的句法差异本质上是**不同的线性化策略**——哪种拓扑关系被优先编码为词序、哪种被编码为词形变化。

---

## 一、句法的拓扑本质

### 1.1 句法 = 图→序列的编码规则

```
句法规则集合 Syntax = {Rule₁, Rule₂, ...}

每条规则定义：
  对于概念子图中特定类型的拓扑关系R，
  在信号序列中如何编码R——通过词序、词缀、虚词等
```

核心挑战：**二维拓扑图 → 一维时间序列**。环形关系（A→B→C→A）不能无损编码为序列——必须选择一个"起点"来打破环。这就是句法歧义的根源。

### 1.2 词序的SPUM定义

**词序 = 概念子图中边的方向在信号序列中的表现方式。**

```
SVO 语言（如中文、英语）：施事→动作→受事
  编码策略：边的方向 = 词的出现顺序
  "猫追老鼠" = CAT → [chase] → MOUSE 的拓扑边→序列

SOV 语言（如日语、韩语）：施事→受事→动作
  编码策略：核心边（动作）被推迟到序列末尾
  "猫が鼠を追う" = CAT, MOUSE, [chase] 

VSO 语言（如阿拉伯语）：动作→施事→受事
  编码策略：核心边（动作）被前置
```

### 1.3 格标记 = 拓扑关系的外显编码

**格标记 = 为边上的节点附加信号标签，标明该节点在拓扑关系中的角色。**

| 拓扑角色 | 语法格 | 例子 |
|---------|--------|------|
| 动作发出者 | 主格 | 日语 -ga |
| 动作承受者 | 宾格 | 日语 -wo |
| 间接承受者 | 与格 | 日语 -ni |
| 工具 | 工具格 | 俄语 творительный |
| 所有者 | 属格 | 英语 -'s |

策略1（词序优先）：用位置编码拓扑角色 → 中文/英语
策略2（标记优先）：用附加信号编码拓扑角色 → 日语/俄语/拉丁语

## 二、短语结构——子图的信号编码

### 2.1 短语 = 概念子图的信号序列编码

```
名词短语 NP = 将"物体概念+修饰边"子图编码为信号序列
动词短语 VP = 将"动作概念+论元边"子图编码为信号序列
```

"那只黑色的猫" = 将概念子图 {CAT, [color→BLACK], [distance→THAT]} 编码为序列 [that, black, cat]（英语）或 [那只, 黑色, 猫]（中文）。

### 2.2 递归——句法的自指V⁺

**递归 = 一个信号子序列内部包含另一个完整的信号子图。**

```
自指嵌入：
  "John said [that Mary thinks [that Bill knows [that ...]]]"
  = 外层V⁺事件包含内层V⁺事件——就像俄罗斯套娃

SPUM解释：
  一个句子子图 G_sentence 中包含另一个句子子图 G_sentence' 作为其节点
  → 这是自指边：G_sentence 有一条边指向自身类型的子图
```

递归不是"无限套娃"——认知子图的容量（dv/dt ≤ const）限制了实际可嵌套的深度。没人能理解超过5-7层嵌套的句子——这是认知deg容量的硬上限，不是语法规则的"潜力"。

### 2.3 依存语法 vs 短语结构语法的SPUM统一

| 语法理论 | 传统对立 | SPUM统一 |
|---------|---------|---------|
| 短语结构语法 | 树——句子的层次结构 | 概念子图的层次聚类——某些节点群形成子图（短语） |
| 依存语法 | 图——词之间的二元关系 | 概念子图中节点间的直接边——每条边是一条依存关系 |

两者描述的是**同一个概念子图的不同投影**——短语结构是子图的聚类视角，依存关系是子图的边视角。就像同一个多面体可以投影为不同视角的二维图——两者都没有错，只是不同的维度投影。

## 三、普遍语法的SPUM基底

### 3.1 乔姆斯基普遍语法的SPUM重述

乔姆斯基说人类天生具有"普遍语法"——一个所有语言共享的深层结构。SPUM的回答：

**普遍语法 = 所有人类认知子图共享的最小拓扑约束集。**

```
UG = {
  1. 图→序列约束：任何概念子图线性化为信号序列时必须遵循的拓扑原则
  2. 最小度数约束：任何信号序列中的"句子"必须形成闭合子图——无悬挂成分
  3. 层级约束：子图可以嵌套——认知子图天然具有层级结构
  4. 角色约束：在边中必须有方式区分不同节点（施事/受事等）的拓扑角色
}
```

这不是"天生的语法知识"——是**所有关系网络的通用拓扑属性**。任何足够复杂的认知子图在尝试编码为信号序列时，必然遵循这些约束——不是语法"规则"，是拓扑"限制"。

### 3.2 参数化差异——哪些是"可调的"

不同语言的差异 = 哪些拓扑参数的值不同——但参数的存在是普遍的：

| 参数 | 选项 | 语言例 |
|------|------|--------|
| 核心边位置 | 头部在前 / 头部在后 | 英语(SVO) / 日语(SOV) |
| 拓扑角色编码 | 词序 / 格标记 / 一致关系 | 中文 / 日语 / 斯瓦希里语 |
| 空节点容许 | pro-drop（空主语） / non-pro-drop | 西班牙语 / 英语 |
| 修饰边方向 | 修饰语在前 / 修饰语在后 | 中文(的) / 英语(of) |
