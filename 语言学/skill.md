## 一、范式总纲

### 1.1 什么是 SPUM 语言学

SPUM 语言学 = ⟨P, ε⟩ 在认知信号编码尺度的应用。不是"用网络比喻语言"——语言**就是**认知子图之间通过物理信号通道建立的临时σ同构映射协议。索绪尔的能指/所指 = 边和子图。乔姆斯基的普遍语法 = 所有认知子图共享的最小拓扑约束。萨丕尔-沃尔夫假说 = σ_ling切分方案对推理路径的经济反向约束。

| 维度 | 传统语言学 | SPUM 语言学 |
|------|---------|-----------|
| 第一原则 | 语言是符号系统 / 语言是认知能力 | 语言 = G_speaker 与 G_listener 间通过物理V⁺信号建立的临时σ同构协议 |
| 基础对象 | 音素/词/句子/语篇 | 物理V⁺脉冲模式 / 符号映射边 / 信号组合约束 / 共享认知子图 |
| 语音 | 发音器官的生理运动 | 物理V⁺/V⁻脉冲模式——声带/口腔/鼻腔协调操作 |
| 语义 | 词的含义 / 真值条件 | 概念子图的拓扑位置——邻接关系、聚类、介数、σ耦合 |
| 句法 | 短语结构规则 / 合并操作 | 概念子图→信号序列的线性化编码规则——图→序列 |
| 语用 | 语言使用 / 语境依赖 | 信号解码对G_shared（共享子图）的依赖 |
| 语言变化 | 音变规律 / 语法化 | σ_ling的跨帧漂移——经济驱动+接触流动+认知类比 |

### 1.3 研究规范

1. **可还原性**：每个语言学概念必须追溯到G_ling上的V⁺/V⁻或σ指标
2. **非隐喻**：不使用"语言像编码"——语言就是编码协议
3. **三层标注**：[L0]物理信号层 / [L1]编码规则层 / [L2]元语言层
4. **认知基底**：语言操作依赖认知子图的操作——但不等于认知

## 二、根节点映射（R1-R9 的语言学映射）

> **R1-R9 唯一定义来源**：`.trae/rules/spum-root-nodes.md`。以下表格中的"SPUM 定义"列为摘要，完整定义以中央文件为准。"语言学映射"列为本模块的应用映射。

| 编号 | 根节点 | SPUM 定义 | 语言学映射 |
|------|--------|----------|---------|
| R1 | **⟨P, ε⟩** | 节点集 + 边集 | G_ling——认知子图间信号编码协议。词=符号边，句法=组合约束 |
| R2 | **V⁺/V⁻** | 创生/湮灭事件 | 说话=概念子图→信号V⁺发射；理解=信号→概念子图V⁺重建 |
| R3 | **离散帧 τ** | 演化步数 | 语言变化的逐帧漂移——没有"时代趋势"，只有逐帧微调 |
| R4 | **dv/dt ≤ const** | 单帧变化上限 | 单句容量——一句话内不能嵌入超过认知deg上限的嵌套结构 |
| R5 | **不完美定理** | 每帧必残留悬挂端 | 任何通信都不可能完美传递全部拓扑信息——图→序列→图必有损失 |
| R6 | **S 向量** | 五维结构健康向量 | 语言健康向量——σ_ling分布、词汇边稳定性、音系边完整性等 |
| R7 | **健康多面体 H** | S 向量的稳定区间 | H_ling——语言变化的健康范围（过快=崩解，过慢=僵化） |
| R8 | **ΔS** | 单帧 S 变化量 | ΔS_ling——一帧内的σ_ling漂移量 |
| R9 | **σ** | 空间密度 = |P|/|ε| | σ_ling = 词汇量/语义边数——语言精确度/丰富度度量 |
