# SPUM × 语音与音系

> 归约路径：语音 = 物理层V⁺/V⁻脉冲模式 → 音素 = 最小可区别的信号脉冲单元 → 音系 = 信号脉冲的组合约束系统 → 音变 = σ_phon漂移
> 语音不是"声音"——是**认知子图用来编码概念信息的物理V⁺/V⁻信号脉冲的离散化模式**。国际音标(IPA)是对全人类语音信号空间的完整采样网格。

---

## 核心命题

**语音是物理V⁺/V⁻信号脉冲的离散化。** 人类的发音器官是一个物理V⁺/V⁻信号发生器——声带振动（周期性V⁺）、气流阻断（脉冲式V⁻）、口腔共鸣腔形变（信号频谱的调制）。这些物理信号被听话者的听觉子图采样、离散化、匹配到认知子图中预先存储的"音素模板"上。

---

## 一、语音的物理基底

### 1.1 发音 = 物理V⁺/V⁻事件

```
发音的SPUM定义：
  声带振动 = 周期性V⁺/V⁻ —— 空气被周期性压缩/释放
  爆破音 = 突然V⁺（气压释放）——单次脉冲边
  摩擦音 = 连续的高频V⁺/V⁻ —— 湍流噪声
  鼻音 = 旁路V⁺ —— 气流从鼻腔释放
```

每一个音素是**一个特定的物理V⁺/V⁻模式**。发音器官的配置（舌位、唇形、软腭位置）定义了V⁺/V⁻的频谱特征。

### 1.2 语音特征的SPUM编码

| 语音特征 | SPUM 物理对应 |
|---------|-------------|
| 清/浊 | 是否有周期性V⁺（声带振动）叠加——有=浊，无=清 |
| 送气/不送气 | V⁺事件的持续时长——送气音有延长的V⁺尾 |
| 调音部位 | V⁺/V⁻事件的空间位置——在口腔中的哪个位置产生扰动 |
| 调音方式 | V⁺/V⁻的模式——爆破（单脉冲）、摩擦（连续）、鼻音（旁路） |
| 音高（声调） | 周期性V⁺的基本频率——声带振动的基础频率 |
| 音长 | V⁺事件的持续时间 |

### 1.3 语音采样——从连续到离散

听话者的听觉子图对物理语音信号进行**离散化采样**：

```
[L0] 连续声波 → 耳蜗频谱分析 → 听觉神经V⁺脉冲序列
                                     ↓
[L1] 认知子图模式匹配 → "这是/p/"、"/b/"还是"/pʰ/"？
```

这个匹配是离散化的关键——听话者将连续的声学空间**切分为离散的音素类别**。不同语言有不同的切分方案（这就是为什么日本人分不清/r/和/l/——其认知子图中这两个音素共享一个类别节点）。

## 二、音系——信号的组合约束

### 2.1 音系 = 语音V⁺/V⁻信号的合法组合规则

```
音系规则 = E_phon 上的合法边组合约束

合法序列：信号sᵢ之后可以出现信号sⱼ —— 存在组合边 (sᵢ, sⱼ)
非法序列：信号sᵢ之后不能出现信号sⱼ —— 无组合边
```

例如：英语中 /ŋ/ 只能出现在音节末尾（"sing"），不能出现在音节开头（*"nging"）。这不是"规则"——是英语使用者的认知子图中**没有从∅到/ŋ/的合法V⁺起始边**。

### 2.2 音系规则的SPUM分类

| 规则类型 | SPUM 定义 | 例子 |
|---------|----------|------|
| 音位配列 | 合法的音素V⁺序列模板 | CV结构——辅音+元音 |
| 同化 | 相邻音素的V⁺/V⁻特征互相传递——边权重扩散 | "impossible" ← "in" + "possible"（/n/ → /m/） |
| 异化 | 相邻音素的特征主动区分——避免自指混淆 | 两个相同声调不能相邻（部分汉语方言） |
| 删除 | 在特定组合边上下文中，某个音素的V⁺事件被省略 | "gonna" ← "going to" |
| 插入 | 在两个本无法连接的音素间插入过渡V⁺——新边创建 | "athlete" → /æθəlit/（插入/ə/） |

### 2.3 音系与墨子的发现

**墨子是历史上第一个触及音系σ约束的人。** "声无常态，因变而名"——声音没有固定模式，是因变化（V⁺/V⁻序列的差异）而产生区别（离散化类别节点）。

## 三、音变——语音σ的漂移

### 3.1 音变的SPUM机制

```
音变 = σ_phon 分布在时间（帧序列）上的缓慢漂移

机制：
1. 发音经济性：发音者为减少deg消耗（省力），将复杂V⁺模式简化为简单模式
2. 感知混淆：听话者将两个临近的音素类别节点合并——σ_phon分布的重心漂移
3. 群体扩散：简化后的发音模式通过社交V⁺在群体中传播——∇σ趋零
```

### 3.2 经典音变的SPUM解读

| 音变类型 | 传统解释 | SPUM 解释 |
|---------|---------|----------|
| 格里姆定律（日耳曼音变） | p→f, t→θ, k→h | 爆破音（单脉冲V⁺）→ 摩擦音（连续V⁺）——发音deg消耗降低 |
| 元音大推移 | 长元音逐级升高 | 元音空间中的σ重心系统性漂移——一步漂移触发相邻音素的重定位 |
| 腭化 | k→tʃ/_i | 在后续高元音的σ耦合下，调音部位向前移动——V⁺事件的位置漂移 |
