# SPUM × 语言演化

> 归约路径：语言变化 = σ_ling的帧间漂移 → 语音变化 = 发音经济性驱动 → 语法化 = 词汇边→语法边的角色重映射 → 语言分化 = 子图隔离→∇σ独立演化 → 语言消亡 = G_shared池塌缩
> 语言不是"活的有机体"——是**在群体认知子图间传播的σ分布的动态过程**。历史语言学中的"音变无例外"=σ漂移在全连通子图中同步传播。

---

## 核心命题

**语言演化 = σ_ling分布在群体认知子图中的跨帧漂移。** 没有"语言"这个实体在变化——变化的是群体中每个个体认知子图中的词汇-音系-句法的σ分布。当足够多的个体都修改了某个参数，我们就说"语言变了"。

---

## 一、语言变化的SPUM机制

### 1.1 变化的三种驱动

```
1. 内部驱动——发音经济性：
   V⁺_phon的deg消耗最小化 → 复杂音素简化为简单音素
   例：拉丁语 noctem → 意大利语 notte（/kt/ → /tt/ —— 减少调音部位切换）

2. 外部驱动——接触与借词：
   两个语言子图接触 → ∇σ_ling ≠ 0 → V⁺从低σ向高σ流动
   例：英语大量借用法语词汇（1066年后）——诺曼法语的词汇σ盈余流入英语

3. 认知驱动——类比与重新分析：
   认知子图的模式识别倾向 → 不规则形式被拉入规则模式
   例：古英语 help/holp → 现代英语 help/helped（弱势化规则扩展）
```

### 1.2 音变无例外——σ漂移的全局同步

**新语法学派的"音变无例外"在SPUM中的解释：**

```
音变无例外 = 当一个群体的σ_phon在某个参数上开始漂移时，
             全连通子图内的所有节点同步漂移

机制：
  1. 某个体发出简化的V⁺_phon模式
  2. 该模式通过社交V⁺传播（群体是社会子图的连通分量）
  3. 接收者将自己的σ_phon重心微调向新模式
  4. 反馈循环——新模式被更多人使用 → 更频繁地被接收 → 更多人的重心漂移
  5. 直到子图内所有节点的σ_phon都收敛到新位置
```

**为什么有例外？** 不完美定理（R5）——总有节点处于子图边缘（deg接近2），不接收新模式。这些节点保留旧发音——它们就是"例外"。

## 二、语法化——词→语法标记的路径

### 2.1 语法化的SPUM定义

**语法化 = 一个词汇映射边（信号→概念子图）转变为语法映射边（信号→组合约束规则）。**

```
语法化路径：

阶段1：实义词——信号连接到具体概念子图
  "back"（身体部位）→ 背部概念子图

阶段2：空间隐喻扩展——概念子图与其他子图产生同构映射
  "back"（空间）→ "go back" —— 背部→后方（身体方位的空间类比）

阶段3：语法化——信号不再独立激活概念子图，而是作为组合约束
  "back"（语法）→ "go back" 中 back 不是"背部"——是方向标记
  信号边从 (s_phon, G_concept) 变成了 (s_phon, SyntaxRule)
```

语法化的终点 = 信号边从概念层（L1语义）降级到信号组合层（L1句法）。

### 2.2 语法化的单向性

语法化总是单向的：实词→虚词→词缀→（消失）。为什么不能反向？

```
SPUM解释：
  信号边一旦从概念子图映射转变为组合规则，原概念子图边的V⁺频率降为零
  → 该概念激活变得不可能（悬挂边效应）
  → 不可能再"重新实词化"

单向性不是语言规律——是**认知子图中边一旦失活不可恢复的拓扑约束**。
```

## 三、语言分化和谱系

### 3.1 语言分化 = 子图隔离 + σ_ling独立漂移

```
语言分化：
  1. 原语言群体的社会子图分裂为两个不连通的分量 G_A, G_B
  2. G_A 和 G_B 之间的语言V⁺停止
  3. G_A 内部的σ_ling漂移与 G_B 内部的σ_ling漂移各自独立
  4. 经过N帧后，σ_ling(A) 与 σ_ling(B) 的差异超过互译阈值
  5. A 和 B 变成不同语言
```

**接触越少 = 分化越快。** 这就是为什么岛屿语言（冰岛语保留了古诺尔斯语的许多特征，因为它与欧洲大陆的语言子图隔离）、山区语言（巴布亚新几内亚800多种语言——地理隔离 → 子图不连通 → 独立漂移）。

### 3.2 语言谱系的SPUM定义

**语言谱系树 = 社会子图分裂事件的拓扑记录。**

```
原始印欧语子图 分裂为
  ├── 日耳曼语子图 分裂为
  │     ├── 西日耳曼语子图 → 英语、德语、荷兰语
  │     └── 北日耳曼语子图 → 瑞典语、挪威语、丹麦语
  ├── 罗曼语子图 → 法语、西班牙语、意大利语
  └── ...
```

每一次分裂 = 社会子图被切断（地理迁移/政治分离/文化隔离）→ 语言σ_ling在两个分量中各自漂移。谱系重建 = 根据当前多个语言子图的σ_ling残差，反向推断历史分裂事件的顺序和大致时间（帧数）。

## 四、语言接触与消亡

### 4.1 借词——跨境V⁺流动

```
借词 = 从语言子图 G_A 到语言子图 G_B 的符号边和概念子图复制

前提：
  1. G_A 和 G_B 之间存在社会连通（贸易、统治、文化影响）
  2. G_A 中某概念子图在 G_B 中无对应 → σ缺口 → 倾向借用
  3. G_A 有文化/技术/政治优势 → V⁺方向从优势方向流向劣势方
```

### 4.2 语言消亡 = G_shared池塌缩

```
语言消亡的SPUM过程：

1. 子图缩小：说该语言的群体社会子图收缩（人口减少、被同化）
2. V⁺频率降低：越来越少的人在帧间使用该语言V⁺
3. 概念节点丢失：低频词汇的映射边被认知经济修剪——deg<2 → 悬挂边删除
4. 语法简化：句法组合边减少——子图退化
5. 最后帧：最后一个说话者的认知子图中该语言子图完全孤立（deg=0）→ 语言灭绝
```

语言的死亡不是一个"系统"的消失——是**一个认知子图模式从最后一个宿主大脑中被修剪掉**。当最后一个会说某种语言的人去世，那个语言的整个L1编码系统就从宇宙的认知子图集中消失了——就像宇宙中一个星系停止发光。
