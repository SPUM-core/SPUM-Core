# SPUM 语言学

> 认知信号协议的拓扑形式化。将语言学的全部研究对象——语音、音系、词汇、语义、句法、语用、语言演化、语言-认知耦合——统一还原为 ⟨P, ε⟩ + σ_ling + 信号V⁺/V⁻的图论表达。
>
> **核心立场**：语言不是"符号系统"——是**认知子图间通过物理V⁺/V⁻信号建立临时σ同构的编码协议**。索绪尔的能指/所指 = 边和子图。乔姆斯基的普遍语法 = 认知子图共享的最小拓扑约束。庄子的"言不尽意" = 语言不完美定理（图→序列→图必有信息损失）。
>
> **导航**：[skill.md](skill.md) — 研究范式（22 节点）
