# SPUM × 语言网络

> 归约路径：语言 = 认知子图间的信号V⁺/V⁻系统 → 语音=物理层V⁺/V⁻脉冲模式 → 词=子图同构的稳定锚点 → 句子=边的组合序列 → 语法=组合约束规则集
> 语言不是"交流工具"——是**两个认知子图之间通过物理层建立临时的σ同构映射**的过程。索绪尔的"能指/所指"=边(信号)与子图(概念)的映射对。乔姆斯基的"普遍语法"=所有人类认知子图共享的最小拓扑约束集。

---

## 核心命题

**语言是认知子图之间通过物理V⁺/V⁻信号建立临时σ同构的协议。** 说一句话 = 将说话者认知子图中的某个概念子图，编码为物理层的语音/文字V⁺事件序列，让听话者在其认知子图中重建一个σ同构的子图。语言学的全部研究对象——语音、词汇、句法、语义、语用——都是这个编码-传输-解码协议的各个层面。

---

## 一、语言子图的形式化定义

### 1.1 基本对象

```
语言通信 = (G_speaker, G_listener, Channel, Protocol)

G_speaker = 说话者的认知子图（概念+关系的网络）
G_listener = 听话者的认知子图
Channel = 物理层V⁺/V⁻信号通道——声波（语音）、光子（文字/手语）
Protocol = 编码规则——将子图结构映射为信号序列，再从信号序列重建子图
```

一次成功的语言交流 = `G_listener` 中重建的子图 `G'_speaker_reconstructed` 与 `G_speaker` 中源子图 **σ同构**——即两个子图具有相同的节点集基数和相同的连接模式。

### 1.2 语言的三层架构

| 层 | SPUM 对应 | 语言学对应 |
|----|----------|-----------|
| [L0] 物理层 | 声波V⁺/V⁻事件序列——空气介质的压缩/稀疏脉冲 | 语音学——发音器官的物理运动 |
| [L1] 编码层 | 信号模式→概念子图的映射规则 | 音系学、词汇学、句法学、语义学 |
| [L2] 元语言层 | 关于语言的V⁺——讨论语言本身的语句 | 元语言学、语法书 |

### 1.3 语言边的基本属性

| 属性 | SPUM 定义 | 语言学含义 |
|------|----------|-----------|
| 符号边 | (信号模式, 概念子图) 的映射边 | 索绪尔的"能指-所指"——词 |
| 组合边 | 信号模式之间的合法连接约束 | 句法规则——什么可以和什么相邻 |
| 跨层边 | 物理层信号 → 编码层识别 → 概念层激活 | 言语理解——从声音到意义的路径 |
| 子图同构度 | G_reconstructed 与 G_source 的匹配率 | 沟通精度——"你听懂了吗" |
| σ_ling | 语言子图密度——词汇连接数/词汇量 | 语言的"丰富度"——多义词密度=高σ |

## 二、语言V⁺/V⁻——说话与理解

### 2.1 说话 = 概念子图 → 信号V⁺序列

```
Speaking = 编码过程：

1. 说话者在认知子图中定位到目标概念子图 G_concept
2. Protocol.encode(G_concept) → 信号序列 S = [s₁, s₂, ..., sₖ]
   - 每个 sᵢ 是一个物理层 V⁺/V⁻ 脉冲模式（音素/音节/词）
3. 通过 Channel 发射 S
4. 物理层：声带振动→空气压缩→声波传播
```

编码过程 = 将非线性的子图结构**线性化**为时间序列。这是一次拓扑压缩——图 → 序列。信息的"丢失"发生在无法被线性化的子图拓扑特征上（如环形关系的线性表达困难）。

### 2.2 理解 = 信号V⁺序列 → 概念子图重建

```
Listening = 解码过程：

1. 听话者通过 Channel 接收信号序列 S
2. Protocol.decode(S) → G'_reconstructed
   - 每个 sᵢ 激活听话者认知子图中的对应概念节点
   - 信号间的顺序关系映射为概念节点间的边
3. 重建成功条件：G'_reconstructed ≅ G_concept（σ同构）
```

理解不是"被动接收"——是**主动重建**。听话者用自己认知子图中已有的概念节点来"匹配"接收到的信号模式。如果听话者缺乏对应的概念节点（比如不知道某个词的含义），重建必然失败。

## 三、语言不完美定理

**任何语言通信在任何帧内都不可能完美传递认知子图的全部拓扑信息。**

```
语言不完美定理的三重来源：

1. 编码损失：子图（二维拓扑）→ 序列（一维时间）→ 不可避免的拓扑信息丢失
   - 环形关系（A→B→C→A）在序列中必须被打破成线性关系
   
2. 认知不对称：G_speaker 与 G_listener 的基底概念子图不σ同构
   - 每个词在不同人的认知子图中关联的概念节点集不同
   - "爱情"在诗人脑中与在物理学家脑中的概念子图完全不同
   
3. 信道噪声：物理层V⁺/V⁻信号在传输中衰减/变形
   - 环境噪声 → 音素识别错误 → 概念节点匹配错误
```

这就是为什么"言不尽意"（庄子）——不是修辞，是**拓扑必然**。语言的极限不是人类认知的极限——是**图→序列→图**过程中不可避免的信息损失。

## 四、语言与σ的关系

### 4.1 σ_ling——语言的密度度量

```
σ_ling = |V_lexicon| / |E_semantic|
其中：
  V_lexicon = 词汇量——认知子图中被语言标记锚定的概念节点数
  E_semantic = 这些概念节点之间的语义边数——同义、反义、上下位、联想等
```

- 高σ_ling（词多、义连少）→ 语言"精确"——每个词含义单一
- 低σ_ling（词少、义连多）→ 语言"丰富"——多义词密集，依赖上下文

### 4.2 ∇σ_ling——方言和语言边界

**方言/语言之间的边界 = σ_ling 的不连续面。** 当两个群体的词汇-语义子图不能σ同构（无法互译），它们就是不同语言。当σ同构但不完全相同（可互译但有口音/用词差异），它们是同一语言的不同方言。
