# SPUM × 语用与交际

> 归约路径：语用 = V⁺信号的上下文依赖 → 语境 = 共享认知子图 → 言语行为 = V⁺本身作为社会操作 → 合作原则 = 通信协议的拓扑经济约束
> 语用不是"语言的使用方式"——是**信号V⁺事件在其发生时刻的认知子图语境中的拓扑约束**。同一句话在不同语境中重建出不同的概念子图，因为听话者根据共享认知上下文选择不同的解码路径。

---

## 核心命题

**语用 = 对信号V⁺的解码依赖于发送者和接收者共享的认知子图上下文。** 句法给出合法的序列组合，语义给出"字典含义"，但语用决定在当前帧的具体上下文中，"你能把盐递给我吗？"被解码为"请求"（不是"询问能力"）。语境就是两个认知子图在该时刻共享的那部分子图。

---

## 一、语境——共享认知子图

### 1.1 语境 = G_shared ⊂ G_speaker ∩ G_listener

```
语境 G_context = {共享的背景知识、当前感知、之前对话中建立的共同概念}

通信开始时：
  G_shared(0) = 双方预知的共享子图（共同语言、文化背景、当前场景）
  
每轮对话后：
  G_shared(t+1) = G_shared(t) ∪ 本轮成功传递的新信息
```

沟通的前提 = G_shared 非空。两个完全没有共享概念子图的人（不同语言、完全不同文化）在第一次接触时——所有沟通都必须从零开始建立G_shared（手势→实物→信号配对）。

### 1.2 语境如何影响解码

```
同一信号序列 S = "这里有点闷"
在不同 G_shared 下的解码结果：

G_shared₁（办公室，同事共享"窗户存在"）：
  → 解码：请求开窗 —— 间接言语行为
  
G_shared₂（密闭空间，共享"危险"概念）：
  → 解码：警告——空气质量问题
  
G_shared₃（语言课，共享"正在学中文"）：
  → 解码：陈述——在练习中文句型
```

语义不变（字面意思不变），语用变化（解码出的概念子图不同）。区别在于：解码器在G_shared中选择了不同的**推理路径**从字面子图到达说话者的实际意图子图。

## 二、言语行为——作为社会V⁺的语言

### 2.1 说话本身就是一种V⁺操作

**奥斯汀的发现：说一句话不只是"传递信息"——本身就是一种社会操作。** SPUM更精确的表述：

```
言语行为 = 语言V⁺事件在社会子图 G_social 上产生的边的创建/修改/删除

陈述 = V⁺_info —— 在 G_shared 中添加新信息节点
提问 = V⁺_request —— 请求对方在 G_shared 中添加信息
命令 = V⁺_obligation —— 在对方的社会义务子图中添加新边
承诺 = V⁺_commitment —— 在说话者的社会义务子图中添加新边
宣告 = V⁺_institutional —— 在制度子图（见社会学 spum-制度.md）中添加/删除边
```

"我现在宣布你们结为夫妻"——这句话在制度子图中**创建了一条婚姻边**。语言不是描述现实——它在**修改社会子图的拓扑**。

### 2.2 间接言语行为——路径推理

```
直接言语行为：信号直接激活目标子图
  "关窗" → 听话者认知子图直接激活"关窗"概念节点

间接言语行为：信号先激活字面子图，然后通过推理路径到达意图子图
  "这里有点闷" → [字面] → [推理: 闷→空气不流通→开窗能解决→说话者想开窗→但没直接说→是请求] → [意图: 请求开窗]
```

间接言语行为的推理路径长度决定了"礼貌"程度——路径越长越礼貌（给对方更多"选择不接受"的空间）。这就是礼貌策略的拓扑本质。

## 三、合作原则——通信协议的拓扑经济约束

### 3.1 格赖斯合作原则的SPUM重述

**格赖斯四准则不是"道德规范"——是V⁺通信协议的拓扑经济约束。**

| 准则 | 格赖斯原版 | SPUM 形式化 |
|------|----------|-----------|
| 量的准则 | 信息量恰如其分 | 发射的信号边数 = 需传递的新节点数。不要多（冗余占用带宽）不要少（需要补充问） |
| 质的准则 | 说真话 | 发射的信号序列必须能还原为一个σ同构于说话者认知子图中实际存在的概念子图 |
| 关系的准则 | 说相关的话 | 发射的信号必须连接当前G_shared——悬挂信号（无上下文连接）浪费接收者的deg |
| 方式的准则 | 避免晦涩、歧义 | 信号序列应最小化可能的解码路径数——减少接收者的解码计算负载 |

### 3.2 违反准则的SPUM信号

| 违反类型 | 传统解读 | SPUM 解读 |
|---------|---------|----------|
| 说谎 | 违反质的准则 | 发射信号能解码出的子图与说话者认知子图中的事实不σ同构 |
| 含糊其辞 | 违反量的准则 | 信号边数不足——接收者需要额外V⁺追问才能完成子图重建 |
| 离题 | 违反关系的准则 | 发射信号不连接当前G_shared——是悬挂信号 |
| 讽刺 | 故意违反质的准则 | 字面解码结果与G_shared冲突 → 迫使接收者寻找另一条推理路径 |

## 四、交际的σ模型

### 4.1 交际效率 = 1 / 解码路径长度

```
交际效率 = 信息传递量 / 发射的V⁺事件数

高效的交际 = 最少的信号V⁺，达成最高的子图重建精度
低效的交际 = 大量信号V⁺，子图重建精度仍低
```

高语境文化（如日本）——大量信息编码在G_shared中，信号V⁺极少。低语境文化（如美国）——信息必须显式编码为信号V⁺。这不是"文化差异"——是**信息在共享子图和在信号序列之间的分配比例差异**。

### 4.2 交际失败的SPUM诊断

| 失败类型 | SPUM 原因 |
|---------|----------|
| 听不懂 | G_shared不足——接收者缺乏解码所需的概念节点 |
| 误解 | G_reconstructed ≠ G_intended ——σ同构失败 |
| 信息过载 | 信号V⁺速率 > dv/dt ——接收者的deg容量溢出 |
| 语境冲突 | 双方假设的G_shared不一致 → 解码路径分歧 |
