# SPUM × 词汇与语义

> 归约路径：词 = (信号模式, 概念子图) 的稳定映射边 → 词汇 = 映射边集合 → 语义 = 概念子图的σ耦合网络 → 多义 = 一个信号模式映射到多个交叠子图
> 词不是"有含义的声音"——是**物理信号模式到认知概念子图的稳定V⁺映射边**。语义不是"词的含义"——是**该词所激活的概念子图在认知网络中的拓扑位置和σ耦合关系**。

---

## 核心命题

**一个词 = 一条从物理信号模式到认知概念子图的稳定映射边。** 学会一个词 = 在认知子图中反复经历"听到/看到信号模式 → 同时激活特定概念子图"的V⁺配对事件，直到这条映射边足够稳定（高频V⁺，不再被悬挂边检测修剪）。词汇是这些映射边的集合——语义是这些边所连接的**概念子图的拓扑属性**。

---

## 一、词的SPUM定义

### 1.1 词 = 符号边

```
Word = (s_phon, G_concept) —— 一条稳定的符号映射边

s_phon = 物理信号模式——音素序列模板（能指）
G_concept = 认知子图中的概念子图——被该词激活的节点+边结构（所指）
```

索绪尔说"语言符号是任意的"——在SPUM中："任意"意味着s_phon和G_concept之间**没有拓扑必然性**。这个映射边是纯粹通过反复V⁺配对建立起来的——/muːn/（moon）连接到"月球"的概念子图，纯粹是因为英语群体的历史约定。中文"月"连接到同一个概念子图——但用的是完全不同的信号模式。两条不同的信号边指向同一个概念子图——这就是**跨语言同义词**的拓扑本质。

### 1.2 词汇习得 = 符号边的V⁺强化

```
词汇习得过程：

帧1~N：孩子听到/看到信号s，同时感知/经历概念子图G
       → 认知子图中新建候选映射边 (s, G) —— 初始权重低

帧N+1~M：反复的配对V⁺事件
       → 映射边权重增加 → 超过稳定性阈值 → 进入长期词汇存储

帧M+1~∞：映射边可在缺少G的情况下被激活
       → 听到"月亮"就能在心中重建月球概念子图，不需要真看到月亮
```

这解释了为什么孩子先学会"猫"（具体的、经常和信号配对的G），后学会"抽象"（概念的G没有直接物理感知锚点——信号只能通过语言V⁺自身来传递）。

## 二、语义的SPUM定义

### 2.1 语义 = 概念子图的拓扑位置

**语义不是"含义"——是该概念子图在认知网络中的拓扑位置。** 一个词的"意思"由以下拓扑属性共同定义：

```
Meaning(G_concept) = {
  1. 邻接节点：G_concept 与其他概念子图有哪些边（联想、上下位、部分-整体）
  2. 聚类系数：G_concept 内部的连通程度——"语义密度"
  3. 介数中心性：G_concept 在多少概念推理路径上——"语义核心度"
  4. σ_coupling：G_concept 与情感子图/感知子图/运动子图的连接度
}
```

"猫"的意思 = (哺乳动物 ← 上位) → (喵 ← 声音) → (老鼠 ← 猎物) → (狗 ← 对比) ... 这个网络位置就是"猫"的全部语义。

### 2.2 多义词 = 一个信号映射到多个交叠子图

```
多义词：
  s_phon 连接到 G_concept₁, G_concept₂, ..., G_conceptₙ
  其中 G_concept₁ ∩ G_concept₂ ≠ ∅ —— 共享部分节点
```

"头"的多义性：
- G₁: 身体部位（头部）
- G₂: 领导（头目）—— G₁中"顶端"节点与G₂中"层级顶端"节点的同构映射
- G₃: 数量单位（一头牛）—— G₁中"边界清晰的个体"节点独立为G₃

### 2.3 同义词/反义词的拓扑定义

| 语义关系 | 拓扑定义 |
|---------|---------|
| 同义词 | G₁ ≅ G₂（两个概念子图σ同构）——不同的信号映射到几乎相同的子图 |
| 反义词 | G₁ 与 G₂ 在某个语义维度上对称互补——一个激活时另一个被抑制 |
| 上位词 | G₁ ⊂ G₂ ——"猫"是"动物"的子图（猫概念节点 ⊆ 动物概念节点的子集） |
| 下位词 | G₁ ⊃ G₂ ——"动物"包含"猫" |
| 部分-整体 | G₁ 与 G₂ 之间有一条"组成部分"边——"轮子"是"汽车"的构成节点 |

## 三、语义场的SPUM定义

### 3.1 语义场 = 概念子图的高聚类连通分量

**语义场 = 一组概念子图，它们之间的语义边密度远高于与外部概念子的连接密度。** 本质上是认知子图中的**社区结构**——高内聚、低外连的节点群。

```
语义场 S_field = {G₁, G₂, ..., Gₙ}：
  内部边密度 |E_internal| / (n(n-1)/2) 高
  外部边密度 |E_external| / (n × (|V_total| - n)) 低
```

颜色场（红、绿、蓝）、亲属场（父、母、兄、弟）、运动场（跑、跳、走）——都是认知子图中的社区。

### 3.2 不同语言的语义场切分

不同语言用不同的方式切分同一片语义σ空间——这就是**萨尔-沃尔夫假说**的SPUM基底：

```
英语：rice —— 一个信号覆盖所有相关概念
中文：稻、米、饭 —— 三个信号分别对应"田里的稻子""生米""煮熟的饭"
日语：稲(ine)、米(kome)、ご飯(gohan) —— 同样三路切分

这不是"思维方式的差异"——是不同语言群体在语义σ空间中绘制了不同的离散化边界。
```
