## 一、方法

### 1.1 五步帧实现

每帧 τ 依次执行：

```
1 创生 V⁺    梯度驱动加 N_GROWTH=3 条边（概率 ∝ |Δσ|^exp, exp=2 实验 / exp=0 均匀对照）
1 湮灭 V⁻    饱和区(度≥3)删边, 比例控制使平均度锁定 TARGET_AVG_DEG=2.4（临界稀疏态）
5 悬挂删除   删除 deg<2 节点及其边, 不级联（公理2: 残留到下一帧）
4-5 金形修剪 木僵滞回状态机: 上一帧 μ/n 快照 ≥ MU_ON 触发, 修剪环参与≤1 的边,
             修剪态=收缩期（暂停节点补充）; μ/n < MU_OFF 退出
3 测量       测量在补充之前 → 修剪释放的悬挂端在本帧池中可见（A5 可测）
2 补充      非修剪态按 N_INIT=300 补齐节点（度2加入, 水形链段）→ |P| 稳定
```

木僵滞回参数：`MU_ON=0.220`（μ/n p95 之上）、`MU_OFF=0.205`（p5 之下）、`F_MAX=5`。

### 1.2 五形指标（全部帧局部, 公理3）

| 形 | 指标 | 计算 |
|----|------|------|
| 土 | δ | deg<2 节点占比（GT-023 = GT-005 同一量） |
| 火 | Φ | σ = 2/deg 的标准差（GT-025 火势） |
| 木 | μ | 环基数 = m − n + c（GT-022） |
| 金 | f_gold / trim_state | 修剪边数 / 木僵修剪态（GT-024） |
| 水 | mean_dsigma | 每帧创生边平均 \|Δσ\|（输运强度代理） |

### 1.3 A1-A7 验证设计

- **滞后交叉相关**（一阶差分去趋势）：x 领先 y（lag>0, |r| 大）→ 因果方向证据。
- **A5 事件研究**：修剪态进入帧（trim_state False→True）前后 ±4 帧 δ 轨迹——规避 f_gold 与 δ 的构造性负干扰（f_gold 高帧恰好是悬挂端被清理的帧）。
- **exp=0 对照**：均匀创生（无梯度驱动）。若某断言在 exp=2 显著而在 exp=0 消失 → 该因果由火形梯度驱动；若两者都显著 → 结构自发。

## 四、A1-A7 逐项结论

### ✅ A1 火→水（涌现成立）
exp=2 r=+0.386 (lag=1)：∇σ 领先创生输运强度一个帧。exp=0 对照 r=−0.125（无因果）——**均匀创生不产生"梯度驱动输运"**。火形 ∇σ 作为输运驱动因仅在梯度加权创生下涌现，且因果方向为火→水。

### ✅ A4 木→金（涌现成立）
exp=2 r=+0.711 / exp=0 r=+0.672（均 lag=1）：μ/n 高位领先修剪触发，且修剪态帧 μ/n 低于非修剪态（0.2149 < 0.2212）——**修剪有效压低环基数，负反馈闭环**。两种创生条件下都显著 → 木僵→修剪是结构自发的，不依赖火形梯度。这是五形拆解方向（木+金→土）的直接实验证据。

### ⚠ A5 金→土（部分成立）
进入修剪态帧 δ 抬升 2.5×（瞬时释放可见），但修剪态持续期 δ 被双重压制：(1) 悬挂端每帧被帧5清理；(2) 收缩期暂停补充。**"释放的节点"在帧快照中只能瞬时存活**——这与不完美定理一致（每帧残留、每帧再删），但意味着"储备持续积累"在本实验实现中观测不到。f_gold 与 δ 的滞后相关为负（−0.686）恰因修剪态高 f_gold 帧 = 悬挂端被清理的帧（构造性负干扰），故采用事件研究。

### ⚠ A6-7 土→火（同源, 非独立）
corr(δ, Φ)=+0.993：δ 与 Φ **同源于低度节点占比**（σ=2/deg，低度 → δ 与 Φ 同时升高），不是独立的因果链证据。A6-7 需要更精细的 ∇σ 空间梯度代理（如度梯度 ⟨∇k⟩ 的局部分布）才能独立检验。

### ❌ A2 水→土（旧代理失效）→ ✅ 端点级涌现成立（v6 修正）
**旧代理（v5）**：全局 δ 与输运强度相关为负（−0.246）——输运增强时悬挂端被拉入网络（度↑），全局 δ 虚降。这是"输运消耗储备"的宏观读数，与规格的端点级断言（"边介数上升的边，其端点 δ 贡献增大"）方向相反，**代理失真而非理论否定**。

**端点级指标（v6）**：`created_dang` = 创生边端点中 deg<2 的比例（输运载体直接接入储备的证据）。
- exp=2：0.0993，为全网 δ（0.0193）的 **5.1×** —— ∇σ 驱动的输运边**强烈偏向连接悬挂端（储备）**；
- exp=0：0.0247，为全网 δ（0.0267）的 0.9× —— 均匀创生不偏向悬挂端。

对照差异（5.1× vs 0.9×）证明"输运接入储备"是**火形梯度驱动的特有机制**：水形输运的载体边（V⁺）直接把土形储备挂上链——精确对应规格原文"被输运的储备"。

**补充结构事实**：横截面显示悬挂端在**低介数链末**富集（低介数边端点悬挂占比 0.028 vs 高介数边 0.000）——主干链端点已被激活（度≥2），储备位于链的末端等待被调动。这与"土形储备位于水形链末"的拓扑语义一致。

### ❌ A3 水→木（明确拒绝）
**旧代理（v5）**：全局 μ 与输运相关为负（−0.184）——补充节点（度2，每帧数十个）主导 μ，淹没输运信号。

**前沿级指标（v6）**：`mu_gain` = 创生边形成的新环数（输运前沿的骨架扩展，不含补充节点贡献）。
- exp=2：r=−0.224；exp=0：r=−0.141——两种条件下均为负，梯度驱动下负得更强。

**机制解释（这不是实现缺陷，是拓扑必然）**：∇σ 驱动的输运边连接 σ 差异大的两端（高σ稀疏端 ↔ 低σ饱和端），属于**异质连接——打通链而非闭合环**（跨分量连通 μ 增 0，同质区闭合才 μ 增 1）。输运强度越大 → 创生边越异质 → 越不成环。均匀创生（exp=0）随机连接，同质区闭合概率更高。

**结论**：单靠 ∇σ 输运不能自动形成环——"水形把储备输送到木形生长前沿、木形吸收成环"需要额外机制（储备到达前沿后的局部同质化/聚集），A3 在本实验框架下被明确拒绝。这同时解释了为何 A2 成立而 A3 失败：输运能接入储备（A2），但接入的方式（异质连接）抑制环形成（A3）。

### 不完美定理
94.4% 帧 δ>0，均值 0.019（exp=2）——悬挂端密度在临界稀疏态（平均度 2.4）下持续存活。少数 δ=0 帧（28/500）为收缩期悬挂端被清空且暂停补充的边界快照，与"删除必产生新悬挂端"的过程性断言不矛盾。

## 五、结论

在平均度锁定 2.4 的临界稀疏随机图上，**五步帧演化自发涌现出耦合链的核心环**：

```
A1 火→水（∇σ 驱动输运, 梯度特有）→ A4 木→金（μ 超临界→修剪, 结构自发）→ A5 金→土（进入帧 δ 释放）
```

- **组装方向（土+水+火→木）的完整链（A1-A2-A3）未闭合**：A1 证实，但 A2/A3 被实验代理缺陷阻断，需要端点级/前沿级测量。
- **拆解方向（木+金→土）的链（A4-A5）已闭合**：木僵→修剪→释放均有实测信号，且对照稳健。
- **闭环（A6-7）为同源相关**，需独立的空间梯度代理。

**方法论验证**：定规则（五步帧）、跑演化（随机图）、看涌现（A1/A4/A5）——耦合链不是预先植入的，是从 ⟨P,ε⟩ 帧规则中浮现的。

## 六、局限与展望

1. **A2/A3 代理**：全局 δ、全局 μ 无法承载端点级/前沿级断言。改用"创生边端点 δ 贡献""输运前沿 2-hop μ 变化"。
2. **A6-7 独立证据**：以 ⟨∇k⟩（度梯度空间方差）替代 Φ 与 δ 相关，或做"去除低度节点后 δ 与 Φ 的残差相关"。
3. **修剪态占比过高（75%）**：滞回带或 F_MAX 需重新校准，使扩张期/收缩期更均衡（接近 50/50 的呼吸节律）。
4. **exp=0 末帧 n=192**：对照运行收缩期较长导致 \|P\| 漂移；可对 n 序列做归一化或延长帧数。
5. **多 seed 稳定性**：当前单 seed（42）。建议 5+ seed 重跑，报告相关系数中位数与置信区间。
