## 零、标注减法：可审计的真实意义

可审计的意义**不在验证 L0，而在把投影逼到它的边界**——逼到那个不能再被审计的地方。

**模拟者悖论**：模拟 L0 = 把自己放到网络之外，但模拟者也是网络内部节点。对 L0 的任何模拟，都自动成为 L0 的一个子图——它不再是 L0 的模型，而是 L0 的一部分。（AGENT.md："你就是宇宙的一次局部运行"——本仓库早已说出这句话。）因此：被指向的 L0 已经落成投影；留在投影之外的那一部分，才是 L0 自身。我们通过"凡是能说的都不是它"来靠近它——道可道，非常道；非恒道也。

**减法不是回避，是唯一的通道**：C5/C10/A3 的每一处"借用 / 候选 / 待证"标签，本质都不是在声明完成，而是在做减法。**标注本身，才是 L0 能做的事**。四元组四格全部是 L1 的标注——对象、计数操作、数值、约束，都是 L1 语言；L0 不在任何一格里，它在四格填满之后剩下的那个"必须如此"里。42 是数出来的（L1）；"为什么恰好 42、不能是 41 或 43"的必然性，是 L0 的痕迹——它说不出来，只能被标注成一个"数到此处必须停下"的接缝。

**T3 的重新定位**：~~搬运~~ → **42 互斥（2026-08-30 重构）**——"图单元可容纳"与"边位面位互斥"不是定理，是 **L0 正在做的那个动作**。我们不能在 L1 里证明 L0 正在做的事，只能在 L1 里标注"这里有一个动作跨不过去"。想要证明 T3，就已经假设了"容量位 / 面 / 位置"是 L0 中的对象——而它们恰恰只是投影。（对照：笛卡尔坐标、正则嵌入、球面剖分从来不是 L0 的事实；坐标的标注，就是减法开始的地方。）

**继续标注**：把每一处"这不是 L0"显式地写下来。写到最后，剩下的那个说不出来的余数，就是 L0。可道者，皆可标注；标注到尽头，余下的就是道。

## 一、计数关系的统一格式

每条计数关系固定为四元组：

```
对象    →  对什么计数（必须是可指认的离散对象集）
计数操作 →  怎么数（必须是可重复执行的步骤）
数值    →  数出来的结果
约束    →  在什么条件下成立、越界后发生什么
```

审计方式 = 对"对象"重新执行"计数操作"，检验是否得到"数值"，并确认"约束"未被违反。全程零外部知识。

## 二、C1–C9 清单

### C1｜闭合三角剖分子图 Σ(6−deg) = 12

| 元素 | 内容 |
|------|------|
| 对象 | 任意闭合三角剖分子图（χ=2，可嵌入球面、无边界） |
| 计数操作 | 对每个顶点 v 数 deg(v)；逐顶点计算 6−deg(v)；求和 |
| 数值 | Σ(6−deg(v)) = 12 |
| 约束 | 闭合（无边界）且三角剖分（每个面恰 3 条边） |
| 审计方式 | 任取一个闭合三角剖分子图，数顶点度数，代入求和，必得 12。V−E+F=2 是计数重言——V、E、F 由同一套计数操作定义，不依赖高斯-博内 |

### C2｜均匀饱和解 N = 12/(6−C)

| 元素 | 内容 |
|------|------|
| 对象 | 顶点度数全相等的闭合三角剖分子图（均匀饱和） |
| 计数操作 | 数共同度数 C；由 C1，每个顶点贡献 (6−C)，故 N(6−C) = 12 |
| 数值 | C=3 → N=4（四面体）；C=4 → N=6（八面体）；C=5 → N=12（二十面体图） |
| 约束 | C ∈ {3,4,5}——C≥6 无正整数解，C<3 无三角剖分 |
| 审计方式 | 数共同度数 C，代入 N=12/(6−C)，检查 N 为正整数。纯组合计数，无几何假设 |

### C3｜二十面体图 V=12, E=30, F=20

| 元素 | 内容 |
|------|------|
| 对象 | C=5 的均匀饱和解（N=12 节点） |
| 计数操作 | V=12；2E = Σdeg = 12×5 = 60 → E=30；F = 2E/3 = 20（表面闭合：每条边恰在 2 个面单元） |
| 数值 | V=12, E=30, F=20 |
| 约束 | C=5 时唯一解 |
| 审计方式 | 数顶点 12 个；每个顶点数邻边 5 条（每条边被数两次）→ E=30；数 S 的极大 3-团（两两相邻、无第四个共同邻居）得 F=20，或由表面闭合 2E/3 数出。**此步产出的仍是图，不是多面体；面单元 = 极大 3-团（2026-08-30），欧拉 V−E+F=2 退为输出** |

## 四、A6 归约：边隙优先

边隙优先（先填 30 个边单元达 42，而非先填 20 个面单元达 32）**不必升为新公理**——它是最满原则的贪婪实现：

```
最满原则（A2 的实例化）: 每步填充使中心球接触数最大化
  先填边单元: 12 + 30 = 42
  先填面单元: 12 + 20 = 32
  42 > 32 → 边隙优先是贪婪最优
```

**诚实声明**：这是一次性验证（42>32），不证明一般性——对任意闭合子图，"E 单元优先于 F 单元"是否恒成立，尚未证明。见待证项 T2。
