# SPUM × 图论应用桥接

> 归约路径：所有应用模块的度数/σ/δ/V⁺/V⁻ 操作 = SPUM-图论的实例化 → 本节展示每个应用模块如何使用图论指标
> SPUM-图论是所有应用模块的形式基底——社会学、经济学、语言学的量化公式本质上是图论指标的特化。

---

## 核心命题

**应用模块不定义新的图论——它们复用 SPUM-图论的 5 公理和指标，在各自领域做语义映射。** 社会学的"社会孤立率" = 图论的 δ_social；经济学的"危机" = 图论的 V⁻ 级联。

---

## 一、社会学中的 SPUM-图论 (GT-013)

### G_social ⊂ ⟨P, ε⟩

```
社会网络是 SPUM 本体图在"人类关系"语义下的子图:
  V_social = 人类个体/群体节点
  E_social = 社会交互边（通信、交易、情感、权力）
```

### 社会学中使用的 SPUM-图论概念

| 社会学概念 | SPUM-图论定义 | 来源 |
|-----------|-------------|------|
| 社会孤立率 | δ_social = |{v: deg(v) < 2}| / N | 公理2（悬挂端密度） |
| 社会凝聚力 | ρ_in / ρ_out = 群体内边密度/群体外边密度 | 模块度 Q 的导数 (GT-005) |
| 权力集中度 | max(BC_norm) —— 最高单节点介数 | 介数中心性的帧局部化 |
| 社会碎片化 | F = 1 − |V_largest| / N | 连通分量分析 (GT-003) |
| 不平等度 | G_deg = 度分布的基尼系数 | 度数分布 → σ 分布 |
| 社会变迁触发 | δ > δ_crit → 快变迁 | 公理2: δ 阈值跨界 = 悬挂端处理速率突变 |
| 制度锁定强度 | L_lock = 制度边在环中的参与度 | 公理4: 环结构阻止修剪 |

### 具体链接

```

─────────────────────────────────────
spum-社会网络.md   → 公理1（节点由连接定义）+ δ_social

spum-社会变迁.md   → δ 阈值 + P_cascade（级联概率 = V⁻ 级联）
```

## 二、经济学中的 SPUM-图论 (GT-014)

### G_econ ⊂ G_social ⊂ ⟨P, ε⟩

```
经济网络是社会网络在经济关系语义下的子图:
  V_econ = 经济参与者（个体、企业、政府）
  E_econ = 交易边（商品V⁺、服务V⁺、货币V⁺）
  权重 = σ 差——交易双方的 σ 差决定水流方向
```

### 经济学中使用的 SPUM-图论概念

| 经济学概念 | SPUM-图论定义 | 来源 |
|-----------|-------------|------|
| 市场 | 高连通替代路径子图 | 连通性 → deg ≥ 2 密集区域 |
| 价格 | σ 交换比 = σ(u)/σ(v) | σ 梯度 = 火形驱动 |
| 货币 | V⁺/V⁻ 对偶的标准化令牌 | 边权重的可量化表达 |
| 价值 | ∇σ_resource —— 资源 σ 的梯度 | σ 的空间导数 |
| 危机 | V⁻ 级联 = 连接边批量被修剪 | 公理2: 悬挂端级联触发 |
| GDP | 交易边权重和 = Σ_w·|E_trade| | 边计数 + σ 权重 |
| 增长 | 净 V⁺ 累积 = |V⁺| − |V⁻| | 帧间拓扑距离 d_topo 的正负分解 |

### 具体链接

```
经济学模块:          SPUM-图论基底:
─────────────────────────────────────
spum-经济网络.md     → 公理3（帧快照）——经济网络每帧重新估值
spum-货币与价值.md   → σ 梯度 + σ 交换比
spum-市场与价格.md   → 连通性 + 替代路径（多路径 deg ≥ 2→竞争）
spum-供需与分配.md   → σ 分布——供给=σ盈余，需求=σ缺口
spum-劳动与资本.md   → deg消耗(流量) vs 累积V⁺(存量)
spum-增长与周期.md   → 帧间拓扑距离 d_topo + σ 阻尼振荡
spum-经济危机.md     → V⁻ 级联 = δ 阈值跨越 → 公理2
```

## 三、语言学中的 SPUM-图论 (GT-015)

### G_ling = 认知子图间的 V⁺ 信号 σ 同构协议

```
语言网络不是独立的图——是认知子图中"概念→信号"映射边的全网集合:
  V_ling = 信号节点（语音/文字符号）+ 概念节点（认知子图节点）
  E_ling = 映射边（信号↔概念）+ 序列边（信号→信号语法连接）
```

### 语言学中使用的 SPUM-图论概念

| 语言学概念 | SPUM-图论定义 | 来源 |
|-----------|-------------|------|
| 词 | (信号, 概念子图) 映射边 | 公理1: 节点的存在由边定义 |
| 语义 | 概念节点的拓扑位置 | 节点度分布 + 邻居成分 |
| 句法 | 图→序列线性化 | 子图拓扑排序（违反环的若干约束） |
| 语言习得 | 映射边的权重累积 → 超过固化阈值 | δ ∝ 未固化边的比例 |
| 双语优势 | 双套映射边体系 | 两张子图的 σ 同构度 I_σ |
| 不可译 | 目标语言无 σ 同构子图 | 图匹配失败 |
| 语言不完美 | 图→序列→图有信息损失 | 公理4: 完美不达 |

### 具体链接

```
语言学模块:            SPUM-图论基底:
─────────────────────────────────────
spum-语言网络.md       → 公理5（全局暂态矛盾 = 语言歧义正常态）
spum-语音与音系.md     → 信号节点 → V⁺ 脉冲的离散化
spum-词汇与语义.md     → 映射边的建立与固化（δ_ling ∝ 未固化词比例）
spum-句法与结构.md     → 图的线性化——环→断环→序列
spum-语用与交际.md     → G_shared 的 δ 依赖——共享概念子图不足则交流失败
spum-语言演化.md       → σ_ling 漂移 = 图结构的慢速 d_topo
spum-语言与认知.md     → 语言 = 概念子图的符号化基础设施（公理1特化）
```

## 四、物理学中的 SPUM-图论 (GT-016)

### G_physics = ⟨P, ε⟩（本体图本身）

```
物理网络 = SPUM 本体图的直接实例:
  V_physics = κ-粒子（空间粒子）
  E_physics = 接触边（粒子相切）
  权重 = σ 差 → 空间密度梯度
```

### 物理学中使用的 SPUM-图论概念

| 物理学概念 | SPUM-图论定义 | 来源 |
|-----------|-------------|------|
| 空间 | 关系网络——不存在"容器" | 公理1: 位置 = 边关系定义的拓扑坐标 |
| 时间 | 帧计数 τ | 公理3: 没有"时间本身"——τ 是图状态的序号 |
| 引力 | ∇σ —— σ 的空间梯度 | σ 梯度（公理4+σ梯度） |
| 物质粒子 | 12 个 deg=5 永恒节点 → 正二十面体锁定 | 公理4导出: Σ(6−deg)=12 ↔ 12个5度节点 |
| 温度 | 高 σ → 低度数 → 更热（低σ→高度数→更冷） | ⟨deg⟩ 的倒数 |
| 量子不确定性 | 局域观察者信息不完备——不是概率本体 | 公理3+公理5: 暂态矛盾被误读为"概率" |
| 暗物质 | δ 极高的悬挂端——未参与闭合结构 | δ_physics ≈ 0.85 |

### 五形对应

| 五形 | 图论定义 | 公理来源 |
|------|---------|---------|
| 水 | 节点度 ≤ 2 的极大无分支路径 | 公理2: 悬挂端 → 链式结构自然形成 |
| 木 | 闭合环 μ = M − N + C | 公理4: Σ(6−deg)=12 的强制闭合 → 环必然存在 |
| 土 | 悬挂端集合 D_τ | 公理2: 每帧必残留的悬挂端 = 储备池 |
| 金 | 桥边（不参与任何环的边） | 公理2: 桥边两端度数低 → 被修剪优先候选 |
| 火 | ∇σ ≠ 0 | 公理4: σ 梯度 = 度差的函数 |
| 耦合循环 | 火→水→木→金→土→火 | 公理2+4: δ 驱动链式传输→环积累→桥修剪→σ梯度再生 |

> 五形完整可计算定义（指标集、健康区间、S_五形↔S_graph 映射）见 `spum-图论五形桥.md`（GT-021~026）。本表仅为物理学视角的快照。
