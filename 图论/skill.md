## 技能描述

SPUM-图论是 L0.5 工具层——不是经典图论的应用，而是从 SPUM 公理（N001-N013）重建的独立图论体系。v2.0 修正：消除"球体相切"隐喻，SPUM-图论 = **关系张力的几何投影理论**——边 = 排他性确认事件，空间 = 排他性张力不可容纳时的"拉开距离"现象，球体 = 各向同性张力平衡的等势面。v2.2 补充：注册**几何图论层 GT-027~032**——拓扑层的不变量（δ、μ、Σ(6−deg)=12）只回答"结构是否合法"；几何层（球体语言：G1 球体存在 / G2 不可相入 / G3 相切即边 / G4 缺口方向 / G5 角度自由度）回答"结构能如何相对运动"（摆动角、键角、缺口朝向），两者不可互推。几何层是 L0.5 拓扑层与 L3/L4 物质层（元素化学）之间的几何桥——到达物质层级，球体几何是直接本体。本 skill 提供 SPUM-图论的 32 节点知识网络和加载策略。

## 核心范式

### 五大公理（v2.0 张力场重述）

1. **连接优先于属性** (GT-001): 边 = 排他性确认事件 → 占用方向 → 撑开空间。无边即无空间占据 = 虚无。
2. **悬挂端不可消除** (GT-002): 悬挂端 = 单侧张力未配平 → 球体向虚空泄压 → 删除必破配平 → 新不平衡。
3. **图状态是帧快照** (GT-003): 空间每帧重建——边集→张力场→球体形状→空间涌现。帧间插值 = 连续错觉 [L1]。
4. **完美是极限** (GT-004): 全局张力完全配平 = 所有方向同时满足——被涨落锁死，无限帧不可达。
5. **局部闭合充分** (GT-005): 局部张力可配平，但产生边界张力台阶——不同区域配平参数不兼容 = 暂态矛盾。

### 与经典图论的绝对分野

```
经典图论: 静态结构 → 全局属性 → 可达完美 → 外部演化规则
SPUM-图论: 张力场快照 → 帧局部配平 → 全局配平不达 → 张力重分布自驱动
```

### 操作限制

- ✅ 帧局部度数/σ/δ/d_topo 计算（张力场指标）
- ✅ 每帧独立验证握手引理（排他性方向总数 = 2×确认事件数）
- ✅ 几何层（GT-027~032）在物质层级（L3/L4）使用球体语言——球体几何是结晶后关系的**直接本体**，非隐喻（见 spum-几何图论.md §1.2 分层澄清）
- ❌ 使用"球体相切""泡泡""接触"隐喻解释 L0.5 拓扑层——张力场是源头，球体是结果
- ❌ 全局属性（直径、全局连通度、全局中心性）——不同帧张力场不同
- ❌ 跨帧累加统计量——张力场分布已不同
- ❌ 假设全局坐标系或背景度量——空间从边集每帧涌现
- ❌ 预设节点属性——度数、球体半径、方向皆从边集的排他性张力涌现

## 关键公式速查

```
 δ(τ) = |D_τ| / |V_τ|                        悬挂端密度（单侧张力未配平比例 = 球体各向异性率）
 Δμ(τ) = (1/C) Σ ||μ_c(τ)−μ_c(τ−1)||₂        锚点漂移率（张力场重分布导致认知漂移）
 d_topo(Gτ,Gτ+1) = |Eτ Δ Eτ+1| / max(|Eτ|,|Eτ+1|)  帧间拓扑距离（张力场重新分布幅度）
 σ = 2 / ⟨deg⟩                               空间密度的图论基底（球体被压缩程度的全局均值）
 ⟨deg⟩ = 2|E| / |V|                           平均度数（平均排他性方向数）
 Σ deg(v) = 2|E|                             握手引理（每帧独立验证——确认事件数一致性）
 Σ(6−deg(v)) = 12                            闭合子图欧拉恒等式（12 = 方向上界）
```

| 错误输出 | 违规类型 | 正确 SPUM-图论 |
