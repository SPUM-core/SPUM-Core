# SPUM × 图论 — 应用模块统一基底

> 定位：L0.5 工具层 — SPUM 本体论 (L0) 的图论投影 = 关系张力的几何投影理论，所有应用模块的共享形式基底。**认识论诚实声明**：L0.5 不是"无认知"，而是"认知的最小可操作单元"——差异（N002）、边界（N003）、节点（N004）本已是认知行为/产物/抽象，L0.5 将其压至不可进一步还原的硬核。
> 与经典图论的关系：**不是分支，是重建** — 不同本体论预设下的独立图论体系。v2.0：消除"球体相切"隐喻，代以"关系张力场生成空间"。

## R1-R9 还原映射

| 还原 | 经典术语 | SPUM-图论对应（v2.0 张力场） |
|------|---------|-------------|
| R1 | 图 (graph) | 当前帧的张力场几何快照 — 不存在"全局图" (GT-003) |
| R2 | 节点 (vertex) | 各方向排他性张力向量的集合 — add_edge 是唯一创建入口 (GT-001) |
| R3 | 边 (edge) | 排他性确认事件 — 在两个节点间建立不可共享的方向占用 (GT-001) |
| R4 | 悬挂端 (leaf) | 单侧张力未配平 → 球体泄压 → 各向异性起点 — 不可消除 (GT-002) |
| R5 | 连通 (connected) | 帧局部张力配平 — 跨帧张力场已不同 (GT-003) |
| R6 | 同构 (isomorphism) | 邻接+帧历史 — 张力场演化路径不可约简 (GT-010) |
| R7 | 谱 (spectrum) | Δμ 谱（锚点漂移矩阵谱分解）— 非拉普拉斯特征值 (GT-012) |
| R8 | 完全图 (complete) | 不可达理想 — 全局张力同时配平 = 热力学第二定律违背 (GT-004) |
| R9 | 演化 (evolution) | 张力重分布自驱动 — 五步帧 → 不完美永存 (GT-020) |
