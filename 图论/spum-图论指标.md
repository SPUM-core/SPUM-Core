# SPUM × 图论可计算化指标

> 归约路径：可计算化指标 = 公理1-5在有限帧内的数值表达 → δ, Δμ, 帧间拓扑距离, σ量化 → 各应用模块的统一度量基底
> 所有公式必须在单帧内独立计算——不跨帧累加、不预设全局坐标。

---

## 核心命题

**SPUM-图论的指标不"描述图的结构"——它们记录当前帧的张力场状态，并为下一帧张力重新分布提供数值边界。** 悬挂端密度 δ 不是"图有多不完美"——它是"当前帧有多少张力未配平方向"。

---

## 一、悬挂端密度 δ（GT-005）

### 定义

```
在 G_τ 中，悬挂端集合 D_τ = { v ∈ V : deg(v) < 2 }
悬挂端密度:

  δ(τ) = |D_τ| / |V_τ|

张力场语义:
  悬挂端 = 单侧张力未配平的节点
  deg=1 = 只有一个方向的排斥压力 → 球体在其他方向膨胀（向虚空泄压）
  δ = 全局未配平张力方向占所有方向的比例
  δ 越大 → 越多节点的球体是各向异性（非正球体）
```

### SPUM 性质

```
δ(τ) > 0  对任意有限 τ  （公理2）
δ(τ) → 0  当 τ → ∞      （公理4）

但 δ(τ) 不能作为闭合的充分判据:
  即使 δ ≈ 0.01，如果 Δμ > θ_μ，闭合仍不成立（N016 实验发现）
```

### 判断阈值

```
δ ∈ (0.20, 1.00]: 高悬挂——稀疏网络，大量节点仅靠 1 条边连接
δ ∈ (0.05, 0.20]: 中等悬挂——网络正在凝聚
δ ∈ (0.01, 0.05]: 低悬挂——网络高度连接
δ < 0.01:         疑似闭合——需联合 Δμ 验证
δ = 0:            不可达——直接标记为计算错误或 δ_min 数值截断
```

### 在各模块中的对应

| 领域 | δ 含义 | 例 |
|------|--------|---|
| 社会学 | 社会孤立率 = δ_social | 日本独居老人率 ≈ 0.15 |
| 经济学 | 经济边缘化率 = deg < 2 的市场参与者比例 | 长期失业率 ≈ 0.05 ~ 0.15 |
| 语言学 | 低频词/已消亡词汇比例 | 语言 δ_ling ≈ 词表中 hapax legomenon 率 ~ 0.3 |
| 物理学 | 未参与闭合结构的 κ-粒子比例 | 暗物质候选量 ≈ 0.85 |

## 二、锚点漂移率 Δμ（GT-006）

### 定义

```
Δμ(τ) = (1/C) · Σ_{c=1}^{C} || μ_c(τ) − μ_c(τ−1) ||_2

其中:
  C = 锚点类别数（如 SOC 分类数）
  μ_c(τ) = 类别 c 在帧 τ 的锚点位置（各节点度的质心坐标）
  ||·||_2 = 欧几里得距离

μ_c 的计算:
  μ_c(τ) = (1/|V_c|) · Σ_{v∈V_c} deg(v)   (最简单的1维情况，多维则用度向量)
```

### 双阈值判据

```
闭合成立的充要条件（N016 修正）:
  δ(τ) < θ_δ  且  Δμ(τ) < θ_μ  持续 k 帧以上

实验建议:
  θ_δ ≈ 0.03  (从 97.1% 正确率中推算)
  θ_μ ≈ 2.0   (从最小 Δμ = 6.16 中发现，需要大幅收紧)
  k ≈ 5 帧     (短暂波动不应误判为闭合)
```

### 漂移率解释

```
Δμ → 0: 锚点稳定——认知分类体系在该子图中已收敛
Δμ 小幅波动: 正常——中心不完美（N013第二层）
Δμ 持续增大: 类结构正在重构——可能触发 V⁻ 级联
Δμ 突跳 (跳跃 > 5): 锚点被重新定义——范式转换/革命
```

## 三、帧间拓扑距离 d_{topo}（GT-007）

### 定义

```
d_{topo}(G_τ, G_{τ+1}) = |E_τ Δ E_{τ+1}| / max(|E_τ|, |E_{τ+1}|)

其中:
  E_τ Δ E_{τ+1} = 两帧的邻接矩阵汉明距离（对称差）
  = 新增的边数 + 被删除的边数

取值范围: [0, 1]
  0: 两帧图结构完全一致——无 V⁺ 也无 V⁻
  1: 两帧图结构完全不同——全部边被替换
```

### 归一化变形

```
// 对等值图更敏感的版本
d_{norm}(G_τ, G_{τ+1}) = |E_τ Δ E_{τ+1}| / (|E_τ| + |E_{τ+1}|)

// 加权版本——区分 V⁺ 和 V⁻ 的不同语义
d_w(G_τ, G_{τ+1}) = w_V⁺·|V⁺| + w_V⁻·|V⁻|
默认: w_V⁺=1, w_V⁻=2  (V⁻ 对社会系统的影响更大 → 给予更高权重)
```

### 速率约束

```
由 dv/dt ≤ const 推导:
  d_{topo}(G_τ, G_{τ+1}) ≤ const / |E_τ|

即: 拓扑距离在一帧内不能超过容量上限。大图（|E| 很大）单帧变化比例极小——系统惯性。
```

## 四、σ 的图论精确定义（GT-008）

### 经典 σ 重述

```
σ = |V| / |E|  的图论重写:

σ(G_τ) = 2 / ⟨deg⟩_τ

其中 ⟨deg⟩_τ = (1/|V|) · Σ_v deg_τ(v) = 2|E_τ| / |V_τ|
```

### σ 梯度

```
对于相邻节点 u, v:

σ(u) − σ(v) = 2·(deg(v) − deg(u)) / (deg(u)·deg(v))

张力场语义:
  deg 越高 → 排他性方向越密 → 球体半径越小（被压缩）→ σ 越低
  deg 越低 → 排他性方向越稀疏 → 球体向外膨胀 → σ 越高
  ∇σ = 球体形状的压缩梯度 → 定向决定"水流方向"

### σ 的不等式约束

```
对任意节点 v:
  σ(v) ∈ (0, 1]

σ(v) = 1: deg(v) = 2 —— 最小存在确认
σ(v) = 0: deg(v) → ∞ —— 完全饱和（不可达）
```

### 在各模块中 σ 对应的图论量

| 领域 | σ 的对应 |
|------|---------|
| 社会学 | 社会关系饱和度——高 deg（政客/网红）↔ 低 σ |
| 经济学 | 资本/资源集中度——deg 高者 σ 低 = 连接富集 |
| 语言学 | 词的语义饱和度——多义词 deg 高、σ 低；低频词 σ 高 |
| 物理学 | 空间局部密度——物质粒子周围 deg 极高、σ 极低 |

## 五、综合图论健康向量 S_graph

```
S_graph(τ) = (δ(τ), Δμ(τ), d_{topo}(τ), ⟨deg⟩_τ, σ_global(τ))

各维度的健康区间:
  δ ∈ (0.01, 0.20]    —— 有演化动力但不碎片化
  Δμ ∈ (1.0, 5.0]     —— 有学习但不震荡
  d_{topo} ∈ (0.001, 0.1] —— 渐变而非革命
  ⟨deg⟩ ∈ [3, 100]     —— 不低于存在确认，不超认知容量
  σ_global ∈ [0.01, 0.67] —— 不饱和（0 < σ）也不过于分散（σ < 2/3）
```
