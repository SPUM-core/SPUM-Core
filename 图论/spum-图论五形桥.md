# SPUM × 图论五形桥——五种结构相位的可计算定义

> 归约路径：五形（五行） = 图论指标在"结构相位"语义下的诊断层 → GT-021~026 把散落在 spum-core 第六节与五行/README 的五形定义，正式注册进图论模块，成为应用模块统一基底的一部分
> 定位：L0.5（图论工具层）与 L1.5（五行诊断语义层）之间的桥。图论提供可计算指标（δ, μ, ∇σ, 介数），五形提供诊断语义（水形通畅？木形僵化？土形枯竭？）。
> 权威基准：`.trae/rules/spum-core.md` 第六节（公理还原路径）· `五行/README.md`（五形速查）· `F:\知乎问答\26-6\五形的离散网络形式化.md`（完整指标集与健康判据）

## 核心命题

**五形不是五种"元素"，也不是五只分类抽屉——它们是同一张图在当前帧内必然共存的五种结构相位。** 任何节点同时参与全部五种相位：它可能同时在一条链上（水）、在一个环上（木）、作为储备等待被调动（土）、被修剪候选（金）、受梯度驱动（火）。

图论模块此前只注册了"张力场指标"（δ, Δμ, d_topo, σ），没有注册"结构相位"。本桥补齐这一层：**δ、Δμ、d_topo、σ 回答"这张图健康吗"，五形回答"这张图正在以什么结构模式运转"。** 两者是同一帧的两个投影。

---

## 一、五形 = 帧内相位，不是永久属性

```
传统五行: 实体归属——"肝属木" → 一棵树同时只能是一种元素
SPUM 五形: 帧内相位——同一节点在一帧内同时参与五种相位
          → 相位不是标签，是结构状态的实时测量值
          → 下帧重新测量——帧快照（GT-003）在五形上的投影
```

与传统"生克"的绝对分野：

```
传统: 固定生克链 木→火→土→金→水→木（机械决定论）
SPUM: 仅两个操作方向，由网络当前状态决定
  组装方向: 土 + 水(载具) + 火(驱动) → 木   （松散节点被输运、嵌入成环）
  拆解方向: 木 + 金(信号/V⁻) → 土            （环被桥边修剪拆散，节点回归储备）
```

## 二、五形指标节点（GT-021~025）

### GT-021 水形：链式传输结构

**图论定义**：节点度 ≤ 2 的极大无分支路径——网络中的链式关系。

```
指标集:
  L(τ)        平均最短路径——链式传输的总长度
  E_glob(τ)   全局效率 = 1/平均最短路径——传输通畅度
  BC(e)       边介数分布——哪些边承担了最多路径（主干链）
  来源: V⁺ 创生阶段——新节点以度 2 加入，自然形成链

健康区间: 见《五形的离散网络形式化》凸多面体判据
异常态:
  水断 —— 关键边被金形删除后 L 骤增、介数集中到少数幸存边上
  → 对应临床: 经络传导阻滞（水形主干断裂）
```

### GT-022 木形：闭合环路骨架

**图论定义**：网络中的闭合环。度量：环基数 μ = M − N + C（M 边数, N 节点数, C 连通分量数）。

```
指标集:
  μ(τ)        环基数——闭合环的数量（骨架密度）
  C_Δ(τ)      全局聚类系数——三角闭合密度
  λ₂(τ)       代数连通性——骨架的抗分割性
  来源: 拓扑守恒 Σ(6−deg)=12 的强制闭合——环不是偶然，是不变量强迫

异常态:
  木僵 —— μ 超临界、λ₂ 异常升高 → 图极难分割（锁死）
  木虚 —— μ 过低 → 骨架松散，环无法提供稳定确认
```

### GT-023 土形：松散储备池

**图论定义**：低度数（deg ≤ 2）节点与碎小连通分量构成的松散集合——等待被调动的储备。

```
指标集:
  δ(τ)        悬挂端密度 = |{v: deg(v) < 2}| / |V|   ← 与 GT-005 同一指标
  F(τ)        碎片化指数 = 1 − |最大连通分量| / N
  低度节点累计频率
  来源: 悬挂边删除（五步帧第五步）的必然副产品 + 不完美定理保证每帧残留

关键对应: S_土 与 S_graph 的 δ 是同一个量——土形储备池 = 未配平张力端
异常态:
  土虚 —— 悬挂节点被过度消耗，F → 0（全网络被拉入主分量，储备枯竭）
```

### GT-024 金形：修剪与拆解

**图论定义**：网络中位于少数环（或不在任何环）上的边——桥边 / 低环参与边，修剪操作的天然目标。

```
指标集:
  bridge(τ)   桥边数量（割边）——修剪候选
  割集大小    修剪一个结构所需的最小删边数
  f_gold(τ)   修剪频率——单位帧内执行的 V⁻ 次数
  修剪潜力    (边介数 − 环数贡献) ——介数高且不在环中的边 = 最优修剪目标
  来源: 五步帧判断→删除第五步

异常态:
  金亢 —— 桥边被过度删除 → 网络碎裂为过多小分量（过度治疗）
  金弱 —— 桥边积累 → 骨架僵化无法更新（不作为）
```

### GT-025 火形：密度梯度驱动

**图论定义**：节点度 / 邻接密度在空间上的不均匀分布——σ 梯度 ≠ 0。

```
指标集:
  ⟨∇k⟩(τ)     节点度梯度均值——结构差异的驱动强度
  Φ(τ)        火势 = Var(ΔV_i) ——体积变化方差——梯度的脉动幅度
  拉普拉斯特征谱（帧局部投影，见 GT-012）
  来源: σ = 2/⟨deg⟩ 的区域差异——高 σ（稀疏热区）↔ 低 σ（饱和冷区）

张力场语义: ∇σ = 球体形状的压缩梯度——定向决定"水流方向"（驱动力，非力）
异常态:
  火衰 —— 梯度趋零 → 网络均匀化 → 水流停滞（没有方向，一切都不动）
  火亢 —— 梯度极大 → 流动过猛 → 冲毁木形骨架（恐慌/过热）
```

## 三、五形耦合与统一健康向量（GT-026）

### 3.1 两个操作方向的图论形式化

```
组装方向（土+水+火→木）:
  输入: D_τ(土) + 链式路径(水) + ∇σ(火)
  操作: 悬挂端沿链式路径被 σ 梯度定向输运到生长前沿
  输出: 环基数 μ 上升（木形骨架扩展）
  约束: dv/dt ≤ const —— 单帧输运量受容量上限约束（GT-007 速率约束）

拆解方向（木+金→土）:
  输入: 环结构(木) + 桥边候选(金)
  操作: 桥边被删除（V⁻）→ 环断裂 → 节点度数下降
  输出: D_τ 增大（土形储备回归）
  约束: 五步帧每帧一次删除——不级联消解（帧协议）
```

### 3.2 五形耦合链——可计算的断言序列

```
A1  火: ∇σ(τ) 增大 → 定向输运增强
A2  水: 链上介数 BC(e) 上升的边，其端点 δ 贡献增大（被输运的储备）
A3  木: 输运前沿 μ 上升 → 骨架扩展（新环形成）
A4  木僵: μ 超临界 → λ₂ 异常升高 → 修剪需求触发
A5  金: 桥边删除率 f_gold 上升 → 环断裂 → 被锁节点释放
A6  土: 释放节点回归 D_τ → δ 上升
A7  火: 结构重排产生新的 σ 不均匀 → ∇σ 再生 → 回到 A1

每条断言对应可测指标（μ, λ₂, f_gold, δ, ∇σ）——供演化模拟实验逐帧验证（方法论: 定规则、跑演化、看涌现）
```

### 3.3 S_五形 ↔ S_graph 映射（两套健康向量的统一）

```
S_五形(τ) = (S_水, S_木, S_土, S_金, S_火)    五行诊断语义层
S_graph(τ) = (δ, Δμ, d_topo, ⟨deg⟩, σ)        张力场指标层

直接映射（同量或派生）:
  S_土 ← δ(τ)                同一个量——悬挂端密度即储备池规模
  S_火 ← ∇σ(τ) 的离散度       火形势能 = σ 梯度的空间方差
  S_金 ← V⁻(τ) / |E_τ|       金形活动度 = 帧内修剪边占比
  S_水 ← L(τ), BC(e)         链式效率 = 帧局部路径指标
  S_木 ← μ(τ), C_Δ(τ)        骨架密度 = 环基数 + 聚类

补充关系:
  d_topo = w_V⁺·|V⁺| + w_V⁻·|V⁻|   分解为创生分量(→水形)与修剪分量(→金形)
  Δμ(τ) → 火形方向稳定性的认知投影——锚点漂移剧烈 ⇔ 梯度方向失序
  ⟨deg⟩ ↔ σ → 火形/木形的全局背景——σ 低 = 饱和区（木密火缓），σ 高 = 稀疏区（火强水畅）
```

**统一结论**：S_五形 与 S_graph 是同一帧的两种读法。诊断时：先算 S_graph（指标），再投影为 S_五形（语义），最后给出五形证型（如"木僵 + 土虚 + 金亢"）。**没有独立于图论指标的五行诊断——五形的一切断言必须可还原为 δ、μ、∇σ、介数、f_gold 之一。**
