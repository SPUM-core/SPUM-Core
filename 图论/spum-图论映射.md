# SPUM × 图论映射词典

> 归约路径：L2 经典图论的所有概念都可以追溯到 SPUM-图论的 5 公理 → 映射 ≠ 等价——是"L2 误读了 L0 的什么" → 完整词典
> 核心原则：经典图论的每个概念都是一次误读——误读不是"错"，是 [L1] 认知投影对 [L0] 本体做了认知压缩。

---

## 核心命题

**经典图论不是"另一个理论"——它是 SPUM-图论在假设全局视角、连续时间、可达完美三个条件下的退化投影。** 映射词典揭示每个经典概念丢失了什么。

---

## 一、节点相关

### 节点/顶点 (GT-009)

```
经典: 图的基本组成单元——预先存在的实体
SPUM: 差异的边界——通过边与他者建立差异的认知单元
丢失: 节点"身份"不是属性——是边集。SPUM 中不存在"有属性的节点"。
```

| L2 使用 | SPUM 转换 | 注意事项 |
|---------|----------|---------|
| `G.add_node(v, label, weight)` | `G.add_edge(u, v)` — 节点由边的创建隐式创建 | SPUM 不暴露 `add_node` 给外部 |
| `G.has_node(v)` | 检查 v 的邻接集是否非空 | 度 = 0 → "节点"不存在 |
| `G.degree(v)` | 帧局部度数 = |neighbors(v)| | 下一帧可能变化 |

### 节点的度

```
经典: 节点的邻居数——内在属性
SPUM: 节点在当前帧的存在确认数——涌现量，非预设属性
丢失: 度数不说明"节点的重要性"——说明"节点被确认的程度"
```

---

## 二、边相关

### 边/连接

```
经典: 两个顶点之间的关系——外部定义的关联
SPUM: 差异的确认——边是对两个节点同时存在的唯一认证方式
丢失: 边不是"连接两个已有实体"——边"创造"了两个实体的相互确认
```

| L2 使用 | SPUM 转换 | 注意事项 |
|---------|----------|---------|
| 有向边 (u→v) | 无向边 + ∇σ 方向 | 方向性 = σ 梯度——不是边的内置属性 |
| 加权边 | 无向边 + σ 差值 | 权重 = 两个节点的 σ 差 |
| 自环 (v→v) | **禁止** | 自环违反差异原则——同一节点不能区分自己 |

### 悬挂边/端

```
经典: 度数为 1 的边——可修剪的冗余
SPUM: 演化引擎——每帧 V⁻ 的唯一候选集
丢失: 经典认为"消除悬挂端 = 优化"。SPUM 认为"消除 = 熄火"
```

---

## 三、结构相关

### 连通分量

```
经典: 图中通过路径可达的最大子集——全局属性
SPUM: 帧局部可达子集——下一帧可能合并或分裂
丢失: 跨帧连通不可靠——锚点漂移使"在同一分量"的语义在帧间变化
```

| L2 使用 | SPUM 转换 | 注意事项 |
|---------|----------|---------|
| `connected_components(G)` | 帧局部计算——不缓存 | 下一帧的结果必须重新计算 |
| "图连通" | "帧 τ 中所有的度 ≥ 2 节点可达" | 悬挂端不计入连通——它尚未确认存在 |

### 生成树

```
经典: 覆盖所有节点的树——最小连通骨架
SPUM: 极限近似——有限帧中不可达
丢失: N013 保证悬挂端存在——"覆盖所有节点"意味着 δ = 0，不可达
```

### 最小割

```
经典: 将图分为两个分量的最小边集——网络瓶颈
SPUM: 悬挂端聚类边界——两类锚点之间的 δ 密集带
丢失: "割"的大小反映的是两个子图之间的 σ 梯度——不是网络结构弱点，是演化前线
```

### 环 (Cycle)

```
经典: 起点=终点的非重复边序列——冗余封闭结构
SPUM: 木形骨架——拓扑闭合的图论表达
丢失: 环不是"冗余"——是 Σ(6−deg) = 12 的强制结构。环 = 稳定的存在确认。
```

---

## 四、度量相关

### 图直径

```
经典: 所有节点对间最短路径的最大值——全局距离度量
SPUM: 悬挂端平均传播距离——帧局部计算
丢失: 全局直径在下一帧可能因一条新边而减半——"直径"不是图的固有属性
```

### 图中心性（介数、紧密、特征向量）

```
经典: 节点在网络中的位置重要性——全局计算
SPUM: 必须帧局部重算——不跨帧平均
丢失: 中心性是 [L1] 认知投影——[L0] 只有度数分布。BC(v) 依赖最短路径，而路径在 SPUM 中不是全局概念。
```

### 图拉普拉斯 L = D − A

```
经典: L 的特征值 = 图的谱性质——代数连通性 λ_2
SPUM: 需重新定义为 Δμ 谱——锚点漂移的谱分析
丢失: 经典 L 预设全局图——SPUM 中没有"一"张图，故没有"一"个 L。
     SPUM 替代: Δμ(t) = 类间锚点漂移矩阵的谱分解
```

## 五、同构与变换相关

### 图同构 (GT-010)

```
经典: G_A ≅ G_B 当存在保持邻接的双射 f: V_A → V_B
SPUM: 同构要求帧历史一致——演化路径不可约简
丢失: 两个结构相等的图可以有完全不同的演化语义
     (A 经过 100 帧演化到结构 S; B 从结构 S 开始——结构相同但帧历史不同 → SPUM 中不等价)
```

### 图着色

```
经典: 将节点分配到 k 种颜色——相邻节点不同色（着色数 χ(G)）
SPUM: 锚点分类——着色是 L1 认知投影，[L0] 只有节点-边
丢失: 颜色不是图的属性——是观察者为节点分类而投影的认知标签
```

### 二分图

```
经典: V 可分为两个不相交集 U, W ——所有边跨过 U 和 W
SPUM: 两类锚点间的悬挂端分布——两类之间的连接模式
丢失: "二分"是一个断然切割——SPUM 中节点可以同时与多类锚点有弱连接（悬挂端特性）
```

## 六、完整映射速查表

| L2 概念 | SPUM-图论等价 | α 转换压缩率 | 丢失了什么 |
|---------|-------------|-------------|-----------|
| 孤立节点 | **不存在** (GT-001) | 1:0 — 直接消除 | 存在确认的前提条件 |
| 悬挂边 | 演化引擎 (GT-002) | 1:1 — 保留但重释 | 悬挂边 = 下一个变化点 |
| 连通分量 | 帧局部可达集 (GT-003) | 1:1 — 帧局部化 | 跨帧稳定性 |
| 图同构 | 结构 + 帧历史 (GT-010) | 1:2 — 增加时间维度 | 演化语义 |
| 完全图 | 不可实例化的极限 (GT-004) | 1:0 — 禁止实例化 | 现实可达性 |
| 生成树 | 极限近似 | 1:0 — 禁止声称达 | δ=0的前提为假 |
| 图拉普拉斯 | Δμ 谱 | 1:1 — 完全重定义 | 全局图假设 |
| 图着色 | 锚点分类投影 | 1:1 — 认知降级 | 本体地位 |
| 最小割 | 悬挂端聚类边界 | 1:1 — 重解释 | 网络脆弱性的语义 |
| 环 | 木形骨架 | 1:1 — 保留结构 | 环不冗余——是强制结构 |
| 有向边 | 无向边 + ∇σ 方向 | 2:1 — 合并 | 方向性来源 |
| 加权边 | 无向边 + σ 差值 | 2:1 — 合并 | 权重来源 |
| 自环 | **禁止** | 1:0 | 差异原则违反 |
| 图直径 | 悬挂端平均传播 | 1:1 — 帧局部化 | 全局算符 |
| 二分图 | 双锚点分布 | 1:1 — 重解释 | 断然二分假设 |

> α 转换压缩率 = 经典L2概念数 : SPUM-图论概念数。1:0 表示 L2 概念在 SPUM 中被消除（合并或禁止），2:1 表示两个 L2 概念在 SPUM 中是同一事物的两种表象。

## 节点注册

| 节点 ID | 概念 | 定义 |
|---------|------|------|
| GT-009 | **经典节点 → SPUM** | 孤立节点被消除（不可确认不存在者）；节点身份 = 邻接集，无内置属性 |
| GT-010 | **经典同构 → SPUM** | 同构 = 邻接结构 + 帧历史 —— 演化路径不可约简 |
| GT-011 | **经典有向/加权 → SPUM** | 有向 = 无向 + ∇σ；加权 = 无向 + σ差 —— 两个L2概念合并为1个L0.5概念 |
| GT-012 | **经典谱 → Δμ 谱** | 拉普拉斯特征值 → 锚点漂移矩阵的谱分解 —— 全局图假设被帧局部重新定义 |
