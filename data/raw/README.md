# 原始数据目录

本目录用于存放从文献、数据库等来源直接获取的**原始数据文件**，包括但不限于：

- 论文的 PDF 扫描件（仅限公开版权或已获授权的文献）
- 数据表格截图（从 PDF 中截取）
- 实验记录本照片（若已公开）
- 从 WebPlotDigitizer 等工具导出的原始坐标点（未经清洗）

**重要提示**：本目录下的文件保持“原样”，**不进行任何格式清洗、单位换算或字段标准化**。所有清洗后的结构化数据应存入 `../processed/` 目录。

---

## 文件命名规范

建议采用以下命名格式，便于追溯来源：

**示例**：
- `Crookes_1874_phil_trans.pdf`
- `Lewis_1933_phys_rev_fig2.png`
- `Oseen_1925_arkiv_table1.csv`

若同一文献有多个文件，可在关键词后添加 `_part1`、`_fig2` 等标识。

---

## 版权声明

- 请仅上传**版权已过期**（通常为 1926 年之前出版）或**明确开放获取**（如 CC BY 协议）的文献全文。
- 对于现代付费论文，**请勿上传全文**，仅可提取数据点（保存为 CSV 或截图）并注明来源。
- 若您无法确定版权状态，请提供文献的 **DOI、URL 或 bibcode**，在 `../external/` 目录中记录链接即可，不要直接上传文件。

## 如何贡献

1. 将原始文件放入本目录。
2. 在表格中记录文件名、来源和说明。
3. 在 `../processed/` 中提供对应的清洗后数据文件。
4. 在 Pull Request 中说明数据来源和提取方法。
