## 核心命题

**SPUM-图论的 L0.5 层 = 关系张力的几何投影理论。**

因果关系不可逆：不是先有空间再有关系——是关系本身的排他性产生了空间。

```
边 = 排他性确认事件。一条边意味着两个节点之间发生了排他性的确认——该方向被占用，排斥其他边。
空间 = 排他性张力无法被容纳时形成的"拉开距离"现象。
球体 = 各向同性张力平衡下的最小能量等势面。
帧 = 所有球体根据当前边集重新计算形状的快照。
演化 = 球体形状变化引发的张力重新分布，驱动下一帧边集调整。
完美 = 所有节点在所有方向的张力完全配平——极限，不可达。
矛盾 = 球体在边界处的张力方向不兼容。
```

## 一、五大公理（v2.0 张力场完整语言）

### 公理 1：连接优先于属性（GT-001）

**边定义节点需要占据的空间体积。** 一个节点之所以"存在"，是因为它的出边需要撑开一个不可入区域——边的排他性确认事件在两个节点之间建立了不可共享的"确认权"：这条边占据的方向，其他边不能同时占据。这个排他性向外推开，就是空间占据的起源。没有出边，就没有撑开的张力，也就没有空间被占据——等价于虚无。

```
推导链: N001 宇宙存在 → N002 差异 → N003 边界 → N004 节点 → N005 边
       边的排他性确认 → 占用方向 → 推开空间 → 球体形状

经典图论: 孤立节点合法，节点和边是独立数据类型
SPUM-图论: 孤立 = 无张力场 = 无空间占据 = 虚无。add_node 不暴露，节点只能通过 add_edge 隐式创建。
         节点 = 各方向排他性张力向量的集合。
```

### 公理 2：悬挂端不可消除（GT-002）

**悬挂端 = 单侧张力未配平的边界区域。** deg=1 意味着只有一个方向有排斥压力——球体在其余方向上膨胀（向虚空泄压），产生各向异性。删除悬挂端 = 其唯一邻居失去一个方向的压力配平 → 该方向球体边界向外膨胀 → 挤压到下一层节点 → 产生新的未配平边界。"删除悬挂边必然产生新悬挂边"的深层原因不是组合数学——是张力配平被打破后，膨胀波在关系网络中传播。

```
推导链: N013 不完美定理
       悬挂端不是"缺陷"——是单侧张力未配平→球体向虚空泄压→各向异性起点
       "悬挂端"是对"张力不平衡"的图论转录。

经典图论: 删除悬挂边 = 优化，可得到 δ=0 的图
SPUM-图论: 删除 = 张力配平被打破 → 膨胀波传播 → 新不平衡
```

### 公理 3：图状态是帧序列快照（GT-003）

**空间本身每帧重建。** 没有边集就没有球体形状，没有球体形状就没有空间——空间不是背景容器，是每帧从边集中涌现的几何快照。帧间边集变化 → 每个节点的方向压力分布变化 → 球体形状和半径重新计算。人们感知中的"连续欧氏空间"来自高帧率下的球体形状插值——是 [L1] 认知投影，不是 [L0] 本体。

```
推导链: N012 离散帧、时间 = 帧计数
       宇宙不存储全部历史——只存储当前帧的边集
       帧间插值 = 连续空间的错觉来源 [L1]

经典图论: 图有静态结构，空间是背景
SPUM-图论: 图 = 当前帧的张力场几何快照；空间 = 每帧各节点球体的并集——帧间完全重建
```

### 公理 4：完美是极限，不是状态（GT-004）

**完美闭合 = 所有节点在所有方向上的张力完全配平。** 即每个球体都是完美的正球体，全局无未配平边界。但边集的动态变化必然产生局部张力涨落——这等价于热力学第二定律在图论上的版本。新增一条边 = 增加一个新的排他性方向 = 打破现有的张力配平 = 球体变形。每一次"趋于完美"的操作都在制造新的不完美——完美闭合被拓扑锁死。

```
推导链: N008 总边数守恒 + N013 不完美
       闭合子图创生抑制定理：刚性骨架上新增边破坏 Σ(6−deg)=12
       张力视角：新增边 = 新排他性方向 → 打破配平 → 球体变形
       δ=0 = 全局张力完全配平 = 无涨落 = 热力学第二定律违背

经典图论: 可以构造 K_n 使 δ=0
SPUM-图论: δ=0 不可达——所有节点的所有方向的张力逐方向同时满足，数学不可能
```

### 公理 5：局部闭合充分，全局暂态矛盾允许（GT-005）

**局部张力可配平，但全局张力传递必然产生冲突。** 一个小区域内的边集可以反复调整使球体趋于规则堆积（局部配平可行）。但每个局部配平都在其边界上产生一个"张力台阶"——相邻区域的配平参数不一致。这个台阶就是全局矛盾的图论起源。全局一致性要求所有区域同时以相同参数配平——被 GT-004 锁死。

```
推导链: N013 第二层——"中心不完美"
       局部配平 → 边界张力台阶 → 相邻区域参数不兼容 = 全局矛盾
       矛盾不是逻辑错误——是不同区域张力在边界处无法同时满足配平条件

经典图论: 矛盾边使图无效，全局一致性是前提
SPUM-图论: 矛盾 = 张力台阶 = 不同区域配平参数不兼容 → 下一帧驱动力
```

## 四、可计算化指标

### 4.1 悬挂端密度 δ（GT-005）

```
δ(τ) = |{v: deg(v) < 2}| / |V_τ|

张力场语义:
  悬挂端 = 单侧张力未配平的节点
  deg=1 = 只有一个方向的排斥压力 → 球体在其他方向膨胀（向虚空泄压）
  δ = 全局未配平张力方向占所有方向的比例 → 球体各向异性率
  δ > 0 对任意有限帧（GT-002 推论）

阈值:
  δ ∈ (0.20, 1.00]: 高悬挂——大量节点球体是各向异性的
  δ ∈ (0.05, 0.20]: 中等——网络正在凝聚
  δ ∈ (0.01, 0.05]: 低悬挂——高度连接，多数张力方向配平
  δ < 0.01: 疑似闭合——需联合 Δμ 验证
  δ = 0: 不可达——直接标记为计算错误
```

### 4.2 锚点漂移率 Δμ（GT-006）

```
Δμ(τ) = (1/C) · Σ ||μ_c(τ) − μ_c(τ−1)||₂

闭合的充要条件（N016 修正）:
  δ(τ) < θ_δ  且  Δμ(τ) < θ_μ  持续 k 帧以上

Δμ → 0: 锚点稳定——该子图张力配平已收敛
Δμ 小幅波动: 正常——中心不完美（N013 第二层）
Δμ 持续增大: 张力场正在重构——可能触发 V⁻ 级联
Δμ 突跳 (>5): 张力场被重新定义——范式转换/革命
```

### 4.3 帧间拓扑距离 d_topo（GT-007）

```
d_topo(G_τ, G_{τ+1}) = |E_τ Δ E_{τ+1}| / max(|E_τ|, |E_{τ+1}|)

张力场语义:
  边集的对称差 = 两帧间张力场重新分布的幅度
  由 dv/dt ≤ const 约束: d_topo ≤ const / |E_τ|
  大图单帧变化比例极小——系统惯性

加权版（V⁻ 权重大于 V⁺——消解张力比建立张力影响更大）:
  d_w(G_τ, G_{τ+1}) = V⁺ · 1 + V⁻ · 2
```

### 4.4 σ 的图论精确定义（GT-008）

```
σ(G_τ) = 2 / ⟨deg⟩_τ = |V| / |E|

张力场语义:
  deg 越高 → 排他性方向越密 → 球体半径越小（被压缩）→ σ 越低
  deg 越低 → 排他性方向越稀疏 → 球体向外膨胀 → σ 越高
  ∇σ = 球体形状的压缩梯度 → 定向决定"水流方向"
  引力 = ∇σ —— σ 梯度的物理语义
```

### 4.5 综合图论健康向量 S_graph

```
S_graph(τ) = (δ(τ), Δμ(τ), d_topo(τ), ⟨deg⟩_τ, σ_global(τ))

各维度健康区间:
  δ ∈ (0.01, 0.20]    有张力未配平但不碎片化
  Δμ ∈ (1.0, 5.0]     有学习但张力场不震荡
  d_topo ∈ (0.001, 0.1]  张力渐变而非场崩塌
  ⟨deg⟩ ∈ [3, 100]     不低于存在确认，不超方向容量
  σ_global ∈ [0.01, 0.67]  不饱和也不过于分散
```

## 五、操作限制

### ✅ 允许

- 描述当前帧的节点-边结构（张力场几何快照）
- 计算帧局部的度数分布（排他性方向统计）、σ（球体压缩度）、δ（未配平率）
- 追踪边密度变化——dv/dt ≤ const 约束下的张力重新分布速率
- 计算帧间拓扑差异——两帧张力场分布的对称差
- 统计悬挂端在类别间的分布——各向异性球体的锚点归属
- 验证握手引理 Σ deg(v) = 2|ε|（每帧独立验证——排他性方向总数 = 2×确认事件数）

### ❌ 禁止（必须退回 L0 本体）

- 使用"球体相切"隐喻——空间不先于关系存在。张力场是源头，球体是结果
- 假设全局坐标系或背景度量——空间从边集每帧涌现
- 直接使用经典图论的谱性质（拉普拉斯特征值、谱半径）——改用 Δμ 谱（锚点漂移）
- 预设节点/边的先验属性——度数、球体半径、方向皆从边集的排他性张力涌现
- 声称可达完美状态（如"最小生成树"）——全局张力完全配平不可达
- 将"图"视为独立于关系网络本体的抽象对象——图 = 当前帧的张力场几何快照
- 跨帧累加图的统计量——不同帧的张力场分布已不同

## 六、范式转换：[L1] 科普隐喻 ↔ [L0.5] 张力场本体

本转换表仅供 AI 在需要将 SPUM2610 的"泡泡相切"语言翻译为深层图论时使用。

| [L1] 科普隐喻 | [L0.5] 张力场本体 |
|-------------|-------------------|
| 球体相切，切点构成边 | 边先发生排他性确认 → 张力推开空间 → 张力等势面呈球体形状。两个张力场边界在某方向达到局部平衡时出现"切点" |
| 球体半径由度数决定 | 球体半径由该节点所有出边的方向分布均匀度决定——越均匀越圆；度越密排斥越集中 → 半径越小（被压缩） |
| 两个球体相切 = 有边 | 两个节点的排斥边界在某方向达到最小距离阈值——该阈值由两边张力平衡定义，不是"接触"的产物 |
| 泡泡"大小""层级" | 球体 = 排他性方向密度的函数。边多→方向密→空间被压缩→球体小。层级 = 张力在各级的重新分布深度 |
| 分形填充——层级嵌套 | 局部张力配平在边界产生张力台阶——下一级球体在台阶处形成，填补上级张力的未配平空隙 |
| 悬挂端 = 边界球体 | 悬挂端 = 单侧张力未配平的边界区域——只有一个方向有排斥压力，球体在未配平方向膨胀（向虚空泄压）→ 各向异性 |
