# SPUM2610 拓扑演化规则

一、文档说明

本文档详细阐述 SPUM2610 理论的拓扑演化规则，包括离散帧结构、演化驱动力、分形约束生长、拓扑常数 12 的导出、演化机制等核心内容，是理论可演化、可推导的关键支撑。

本文档内容与 `knowledge.md`（SPUM 世界观评判依据）保持一致，演化规则以 `knowledge.md` 第二至四章为权威来源。

二、演化的根本驱动力：几何矛盾

### 2.1 演化不是由外部推动的

在 SPUM 中，演化的根本驱动力不是"力"、不是"能量"、不是"第一推动"——而是一个内生的、不可消除的**几何矛盾**：

**填补一个空隙，必然产生更多新空隙。**

当局部网络通过创生事件填补已有空隙时，新生成的粒子之间的相切关系，必然产生更小尺度的新生空隙。填补得越多，新生缝隙越多。变化不是被"驱动"的，变化本身就是关系网络存在的常态。

### 2.2 闭合子图中的净湮灭效应

这一矛盾在闭合子图中尤为致命：闭合边界内，填补空隙的努力永远产生更多需填补的空隙，而新空隙在闭合边界内无法被外部的创生事件直接补偿。结果就是**持续的内部边删除（净湮灭效应）**——引力不是被"设定"的，是被堵住的几何矛盾。

### 2.3 不完美是持续演化的动力

一帧结束时，网络永远无法达到"所有节点度数 ≥ 2"的完美状态。因为删除悬挂边必然会产生新的悬挂边（被删除节点的邻居可能因此度数降到 1）。这种永不消逝的"逻辑不完美"，正是宇宙持续演化的根本动力。旧帧的残留，是新帧的动力。

三、离散帧结构

### 3.1 帧定义

离散帧是 SPUM 理论演化的基本单元。一个完整的离散帧定义为五步序列：

```
1. 创生     →  新边被创建（V⁺ 事件），新节点可能被引入
2. 连接     →  新边建立后，节点的连接关系更新，度数重算
3. 变化体积 →  节点度数变化导致等效体积变化，σ 局部波动
4. 判断     →  检查所有节点的度数：是否有悬挂边（度数 < 2）？
5. 删除     →  删除悬挂边。如果某节点度数降至 0，同步删除该节点
```

**关键约束**：
- 一帧内没有循环，没有"级联消解"——一帧只做一次删除操作
- 删除后新产生的悬挂边，是**下一帧**处理的起点，不在本帧内递归处理
- 帧与帧之间没有中间状态，系统状态由内部关系网络唯一且确定地定义
- 不存在"概率云"或"叠加态"——节点要么连接，要么不连接

### 3.2 帧间关联

相邻离散帧之间，通过以下机制实现关联：
- **拓扑不变量**：角度亏损总和、拓扑常数 12、开口占比约束在帧间持续生效
- **创生-湮灭对偶**：上一帧的净湮灭量，在下一帧以背景创生形式补偿
- **不完美传递**：帧结束时的悬挂边残留，是下一帧创生的启动信号

四、分形约束生长：空间的结构语法

### 4.1 生成逻辑

宇宙不是"填充"出来的，是"生长"出来的。从无尺度节点出发，以**相切**为唯一关系，以**闭合**为唯一约束，逐级生成结构、生成缝隙、生成下一代节点。

### 4.2 层级定义

| 层级 | 定义 | 角色 |
|------|------|------|
| **0 层级** | 最先形成（或局部最大）的泡泡 | 构成空间骨架。彼此相切，形成局部密集网络。每个 0 层级节点度数有差异，但总体接近拓扑容量上限。 |
| **1 层级** | 由 0 层级缝隙生成 | 衔接骨架之间的过渡。与若干 0 层级泡泡（有时也包括其他 1 层级泡泡）相切。 |
| **2 层级** | 由 1 层级缝隙生成 | 填充更细微的空隙。与 0、1 层级节点相切。 |
| **≥ 3 层级** | 递归下限 | 当缝隙无法容纳任何能维持稳定连接的节点时，递归终止。对应量子尺度下限——由关系几何容量约束（D_max = 4κ）自然截断。 |

**层级由生成时序定义**，不是由绝对大小决定。

### 4.3 层级比例

```
k₀ : k₁ : k₂ = 1 : 1 : 2
```

总关系负载：L = k₀ + k₁ + k₂ = 4k₀。层级 ≥ 3 因尺度突破最小差异阈值，逻辑截断。

五、拓扑常数 12：宇宙的数字指纹

### 5.1 路径一：几何容量约束（启发式）

由 D_max = 4h 代入球体表面积 S = πD²，除以最小切点面积 h²：

```
N_max = π(4h)² / h² = 16π ≈ 50.3
```

约束：4k₀ ≤ 50.3 → k₀ ≤ 12.575。稳定性原则取最满最闭合整数：k₀ = 12 为唯一闭合、自洽、满配解。k₀ = 13 超限（逻辑破缺），k₀ = 11 未满（不自洽）。

### 5.2 路径二：纯组合约束（严格本体论）

完全剥离几何、球体、半径、π。对任意闭合结构三角剖分，离散欧拉恒等式：

```
∑ᵥ (6 − deg(v)) = 12
```

总角度亏损必须严格等于 12。为达零应力、最对称、最稳定，每个 0 层级节点贡献 1 单位亏损 → 必须恰好 12 个 0 层级节点。12 是纯拓扑的强制解，与几何无关、与填充无关、与经验无关。

### 5.3 双路径统一

高斯-博内定理将路径二的纯组合角度亏损与路径一的几何表面积约束完美统一。12 同时是：
- 拓扑生长的唯一自洽整数
- 几何容量的唯一稳定解
- 欧拉恒等式的强制结果
- 三维空间、正二十面体、接吻数的真正起源

### 5.4 π 的终极认识论地位

π 不是宇宙的固有常数。它是人类以六方向直角坐标认知各向同性球体时，必然引入的认知压缩因子。宇宙本体只记录整数 12 和拓扑约束，π 是这些约束在连续几何屏幕上的翻译语法。在路径二中 π 完全不出现。π 被降级为"认知投影的转换因子"。

### 5.5 正二十面体：最小稳定结构

12 个顶点、20 个三角形面、30 条边的正二十面体，是满足四大稳定判据的最小、最对称、涌现概率最高的结构：尺度恰好 D = 4κ（满足临界约束）、完全三角剖分球面拓扑（χ = 2）、对称性最高（60 个旋转对称操作）、内部创生概率严格为 0。

六、演化机制

### 6.1 创生事件 V⁺

一条新边被创建。必须遵循全局对偶约束（每个创生必是某湮灭的对偶补偿）。伴随效应：局部边数增加、σ 降低、体积膨胀。

### 6.2 湮灭事件 V⁻

一条已存在的边被断开。触发级联消解——若某节点度数降至 1，同步删除该节点及其所有关联边，重复直至所有节点度数 ≥ 2。伴随效应：σ 升高、体积收缩。

### 6.3 悬挂边删除

在一帧结束时，度数 < 2 的边被逻辑修剪。这是逻辑自洽的强制执行，不是物理过程。

### 6.4 净湮灭效应

闭合子图内部创生被严格禁止（因破坏拓扑不变量），湮灭仍自由发生，形成稳定的净边删除。引力不是"力"——它就是净湮灭效应本身。

### 6.5 空间密度梯度

σ 从内向外递减的稳定分布。物质粒子的净湮灭导致周围 σ 升高，形成以引力源为中心的梯度场——这就是引力场的拓扑定义。

### 6.6 dv/dt ≤ const

单帧跃迁中单个节点关系变化的上限。dt = 离散帧 τ，const = 拓扑容量上限。任何事物发展的增长天花板。D_max = 4κ 意味着没有节点可以一次帧内"吞下"超过自身容量上限的关系量。

七、开口机制

拓扑开口是 SPUM 中粒子特性的拓扑本质。

### 7.1 开口产生

当局部创生/湮灭事件在闭合子图边界上产生不完整的连接模式时，形成拓扑开口。开口不是"缺陷"——它是闭合子图与外部网络交互的必然结构特征。

### 7.2 开口约束：占比 ≤ 1/3

由带边界的离散高斯-博内定理导出。任何带物理开口的闭合子图，开口的等效面积与母体总表面积之比不得超过 1/3。超过此阈值，边界节点的测地曲率补偿无法满足拓扑自洽，结构将解体。

### 7.3 永恒粒子的单开口

永恒粒子作为稳定结构，必须具有恰好一个开口——这是它在网络中自持位移的拓扑前提。单开口允许粒子方向性地吞噬前方空间粒子，同时保持内部结构稳定。

### 7.4 开口的物理对应

开口的大小和数量对应物理粒子的基本属性。不同的开口模式对应不同的粒子类型——这是 SPUM 中粒子分类的拓扑基础。

八、密度梯度驱动规则

空间密度梯度是驱动局部演化的核心动力：

1. **梯度定义**：相邻区域的空间密度差值，∇σ = σ₁ − σ₂
2. **创生倾向**：σ 越低的区域（连接稀疏），创生事件概率越高——网络倾向于填补"稀疏区"
3. **湮灭倾向**：σ 越高的区域（连接饱和），湮灭事件概率越高——网络倾向于释放"过密区"
4. **引力对应**：净湮灭效应导致引力源周围形成 σ 从内向外递减的梯度场。梯度越大，引力越强
5. **规则本质**：密度梯度规则不是底层公理，而是从拓扑约束中涌现的统计规律，可被实验证伪
