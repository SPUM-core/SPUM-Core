二、核心公理

### 2.1 宇宙是离散关系网络 ⟨P, ε⟩

宇宙的本体是一张动态关系网络，P 为节点集合，ε 为边集合。该图无悬挂边（最小度数 ≥ 2），所有节点统称为空间粒子（κ‑particle）。

**关键推论**：没有背景容器，没有时空舞台，没有空无一物的"空间"。泡泡本身就是空间——泡泡之间的接触关系定义了哪里是"这里"、哪里是"那里"。就像区块链不需要预先分配"存储地址"，数据的存在完全由交易链条的拓扑结构定义。没有背景，世界依然通过拓扑自洽完美运行。

**离散系统的本体论证明**：计算机与 AI 模型本身就是 ⟨P, ε⟩ 在宇宙中真实存在的物理实例。它们能完美模拟一切连续现象，证明连续是离散的认知投影。离散系统之所以能模拟连续现象，是因为连续本身就是离散关系网络在认知投影中的有效近似。

**差异第一性原则**：一切存在和一切认知的第一前提不是"存在"，而是差异。若万物无差异，则一切同一，"存在"与"虚无"无法区分。差异 → 区别 → 概念，这是宇宙中任何事物产生的唯一路径。单传感器无法产生任何概念——因为单帧图像就是"一切"，没有对比参照。成对同频传感器才能产生感知概念：两个同类型传感器在相同时刻产生微小差异，这个差异本身定义了边界，边界定义了物体，物体定义了概念。

### 2.2 关系定义存在

节点与边是一体两面——没有脱离边的节点，也没有脱离节点的边。孤立节点无法被确认存在，连接是对存在的确认。

**关系是第一性的**：不是"体积大的粒子承载更多连接"，而是"能维持更多稳定连接的节点，在认知投影中必然呈现为更大体积"。体积之内是混沌——无差异、无结构、无关系，仅作为关系的边界存在。体积之外是关系网络——宇宙唯一真实的本体。

### 2.3 拓扑守恒

SPUM 的守恒律不是全局性的宣言，而是**局部的、可验证的拓扑不变量**。任何观察者（包括你我）都只是宇宙的局部子图，永远无法"看到"宇宙的总边数。全局总边数守恒是一个无法被任何观察者直接验证的理论外推。

**真正可操作、可检验的，是局部拓扑守恒**——即任何闭合子图内部，存在一组必须严格保持的拓扑不变量。这些不变量不依赖参考系、不依赖观测尺度、不依赖坐标选择。

#### 局部拓扑不变量（可观测的守恒律）

1. **角度亏损总和恒为 4π（离散高斯-博内定理）**：对于任意完全三角剖分的闭合子图 S（球面拓扑 χ = 2），内部所有节点的角度亏损之和严格等于 4π。这是纯组合约束——与几何无关、与 π 无关、与坐标系无关。
   ```
   Σᵥ (6 − deg(v)) = 12   →   Σ δᵢ = 4π
   ```
   任何试图在闭合子图内部新增一条边的创生事件，都必然破坏这个不变量，因此被严格禁止——这就是**闭合子图创生抑制定理**。

2. **最小度数 ≥ 2**：任何节点的度数不得低于 2。度为 0 是孤立（等同于不存在），度为 1 是悬挂边（无法闭合，逻辑不自洽）。这条约束在每一帧结束时被强制执行——悬挂边删除操作。

3. **拓扑常数 12**：0 层级节点恰好为 12 个。这不是经验拟合，而是欧拉恒等式 Σ(6 − deg(v)) = 12 的强制解——总角度亏损 12 必须由 0 层级节点均摊，每个贡献恰好 1 单位亏损。

4. **开口占比 ≤ 1/3**：任何带物理开口的闭合子图，开口的等效面积与母体总表面积之比不得超过 1/3。由带边界的离散高斯-博内定理导出——超过此阈值，边界节点的测地曲率补偿无法满足拓扑自洽。

#### 全局形式：总边数守恒

将上述局部拓扑不变量外推到宇宙整体，得到全局形式：|ε| 永恒不变，全局严格守恒。关系是存在的度量，存在的总量等价于关系的总量。变化的只是边的连接方式，而非边的总数量。

**认识论定位**：全局总边数守恒是理论外推，局部拓扑守恒是可检验事实。SPUM 的实用判据全部建立在局部拓扑不变量上——它们可以被任何局部观察者独立验证，无需"看到宇宙全貌"。

由此推导：创生事件（新边创建）与湮灭事件（边删除）必须严格对偶——任何一个局部闭合子图内部的湮灭事件，其净边删除量必然转移到背景混沌网络中，表现为背景的净创生。演化的本质不是"创造"或"毁灭"，而是关系容量的重分配。

### 2.4 时间是离散帧计数

没有"时间本身"，只有"网络演化到第几步"。时间不是背景、不是河流、不是均匀流逝的实体。

离散帧的定义：一个完整帧 = **创生 → 连接 → 变化体积 → 判断悬挂边 → 删除悬挂边**。一帧内没有循环，没有"级联消解"，一帧只做一次删除。删除后新产生的悬挂边，是下一帧处理的起点。

帧与帧之间没有中间状态。不存在"概率云"或"叠加态"——节点要么连接，要么不连接，系统状态由内部关系网络唯一且确定地定义。

### 2.5 空间密度 σ 与增长天花板 dv/dt ≤ const

**空间密度**：σ = |P| / |ε|。节点平均度数 ⟨deg⟩ = 2/σ，因此 σ 与平均度数成反比：
- 高 σ 区域：节点平均度数低、等效直径小、连接稀疏 → 温度更高
- 低 σ 区域：节点平均度数高、等效直径大、连接饱和 → 温度更低

**dv/dt ≤ const** ——这是整个 SPUM 理论的核心引擎，是离散之所以可以离散的根基。

dv 指的是单个节点在一次离散帧跃迁中，其关系变化量（等效体积变化）的绝对值。dt = τ（一个离散帧周期）。const 是由关系网络的拓扑容量决定的内禀上限。

**它是物理事实，不是认知约束**：任何一个节点在一次离散帧中，其度数变化、边缘接关系的变化量，受限于该节点在关系网络中的拓扑位置和连接容量。D_max = 4κ 意味着没有节点可以一次帧内"吞下"超过自身容量上限的关系量。

**深层含义**：任何事物的增长都存在一个硬性的天花板。当一个系统发展到一定规模后，无论继续投入多少资源，都无法突破这个速率上限。单个空间粒子的直径存在绝对上限 D_max = 4κ，超过此上限关系网络无法维持稳定连接。一个闭合子图的表面容量有限：总关系负载 L = 4k₀，当超过容量上限时系统逻辑不自洽。

### 2.6 不完美是持续演化的动力

一帧结束时，网络永远无法达到"所有节点度数 ≥ 2"的完美状态。因为删除悬挂边必然会产生新的悬挂边（被删除节点的邻居可能因此度数降到 1）。这种永不消逝的"逻辑不完美"，正是宇宙持续演化的根本动力。

旧帧的残留，是新帧的动力。

| 永恒粒子 | 多个晶子通过拓扑锁定形成的稳定结构。具有单开口、能自持位移。可在网络中持续徜徉。 |

四、底层约束

1. **最小度数 ≥ 2**：任何节点的度数不得低于 2。度为 0 是孤立（等同于不存在），度为 1 是悬挂边（无法形成闭合环路），逻辑不自洽。这是悬挂边删除的根本原因。

2. **总边数守恒（全局）**：|ε| 永恒不变，全局严格守恒。关系是存在的度量，存在的总量等价于关系的总量。变化的只是边的连接方式，而非边的总数量。

3. **创生-湮灭对偶（局部）**：任何一个局部闭合子图内部的湮灭事件，其净边删除量必然转移到背景混沌网络中，表现为背景的净创生。演化的本质是关系容量的重分配。

4. **拓扑不变量约束**：整个离散网络的核心拓扑不变量（欧拉示性数、角度亏损总和等）在演化过程中保持不变，是理论全局稳定的核心保障。局部可观测的不变量包括：角度亏损总和恒为 4π、拓扑常数 12、开口占比 ≤ 1/3。

5. **dv/dt ≤ const**：任何事物发展的增长天花板。演化速率有硬上限，不可无限增长、无限加速、无限密度。

6. **演化不可逆约束**：离散帧的演化过程具有不可逆性，一旦局部关系更新完成，无法回溯至前一帧状态。

7. **无内置目标约束**：底层无预设目标函数、无奖励机制，演化方向由空间密度梯度驱动。
