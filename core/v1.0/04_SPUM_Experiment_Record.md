# SPUM2610 统一版本
一、文档说明
本文档完整记录SPUM2610理论的实证实验——低压温差力矩实验的全过程，包括实验设计、参数设置、现象总结、原始特征及实验限制，是理论可证伪、可检验的核心实证支撑。
二、实验名称
低压温差力矩实验（SPUM理论预言验证实验）
三、实验目的
验证SPUM理论基于离散拓扑演化推导的“优先方向锁定”预言，即：在低压环境下，温差作用会引发物体的不可逆偏转，偏转方向具有锁定性，与电极极性无关，且低压环境会增强该效应，常压环境下效应消失。
四、实验参数（AI协助推导优化）
1. 实验环境：气压10-20kPa（低压环境），室温25℃，无外界磁场干扰；
2. 实验装置：云母悬臂（厚度0.1mm，长度5cm）、帕尔贴芯片（温差控制范围±5℃）、电极（两极间距2cm）、数据采集仪（精度0.01mm）；
3. 操作参数：脉冲时长0.4s，温差梯度5℃（帕尔贴芯片两端温差），实验周期10s/次，单次实验时长30分钟；
4. 对照实验参数：分别在5kPa、10kPa、20kPa、常压（101kPa）环境下重复实验，其他参数保持一致，共设置4组对照，每组实验重复10次以上。
五、实验过程
1. 实验搭建：组装云母悬臂与帕尔贴芯片，固定电极位置，连接数据采集仪，调节实验环境气压至目标值；
2. 基线校准：在无温差、无电极电压的情况下，记录云母悬臂的初始位置，作为基准；
3. 正式实验：开启帕尔贴芯片，设置温差梯度与脉冲时长，施加电极电压，记录云母悬臂的偏转情况（偏转方向、偏转幅度）；
4. 对照实验：依次调整环境气压，重复上述步骤，记录不同气压下的实验现象；
5. 数据整理：汇总所有实验数据，分析偏转规律、周期性特征，对比不同气压下的效应差异。
六、实验现象总结（四十余次对照实验结果）
通过四十余次不同条件的对照实验，观测到以下核心反常现象，与SPUM理论预言一致：
1. 不可逆偏转：低压环境（10-20kPa）下，云母悬臂在温差脉冲作用下，会产生明显的不可逆偏转，偏转后无法自行恢复至初始位置；
2. 方向锁定：偏转方向具有固定性，无论电极极性如何切换，偏转方向始终不变（即“优先方向锁定”）；
3. 极性影响：电极极性仅影响偏转幅度（极性切换时，偏转幅度变化±10%），不影响偏转方向；
4. 气压效应：低压环境（10-20kPa）下，偏转效应明显；气压降低至5kPa时，效应增强；气压升高至常压（101kPa）时，偏转效应完全消失；
5. 周期性特征：实验过程中，每5个实验周期（约50s），云母悬臂会出现“静止-再启动”的周期性行为，即前4个周期正常偏转，第5个周期静止，随后重新启动偏转。
七、原始现象特征
1. 偏转幅度：低压10-20kPa环境下，单次脉冲的偏转幅度为0.1-0.3mm，随着实验次数增加，偏转幅度逐渐趋于稳定；
2. 静止-再启动特征：每5个周期的静止时间约2-3s，静止后重新启动时，偏转幅度与前4个周期一致，无明显衰减；
3. 重复性：同一气压、同一参数下，重复实验10次以上，偏转方向、周期性特征完全一致，实验重复性良好；
4. 干扰排除：排除外界磁场、振动、温度波动等干扰因素后，实验现象无明显变化，证明现象与SPUM理论预言的“空间密度梯度效应”直接相关。
八、实验限制与不足
1. 实验精度限制：云母悬臂的偏转幅度较小（0.1-0.3mm），数据采集精度受仪器限制，无法捕捉更细微的偏转变化；
2. 环境控制限制：无法完全排除极微弱的外界磁场干扰，可能对偏转幅度产生微小影响；
3. 机制验证不足：目前仅观测到“优先方向锁定”等现象，尚未完全验证现象与SPUM拓扑演化机制的直接关联，需进一步设计更精准的实验；
4. 实验规模限制：实验仅完成四十余次对照，实验样本量有限，需扩大实验规模，验证现象的普适性；
5. 设备限制：缺乏高精度的空间密度检测仪器，无法直接观测空间密度梯度的变化，只能通过偏转现象间接推导。
