一、项目总览

SPUM2610（空间粒子宇宙模型）是一套以离散关系拓扑为核心的理论体系，核心特征为「文档即代码」——无需微调、无需开发，将本仓库核心文档与对应 Prompt 提交给任意大模型，即可实现 AI 与理论的深度共建，涵盖答辩辅助、理论推导、实验分析、科普创作等全场景。

本仓库核心世界观以 `knowledge.md`（SPUM 世界观评判依据）为权威基准，所有核心文档的公理定义、演化规则、概念用语均需与 `knowledge.md` 保持一致。`knowledge.md` 蒸馏自 `nodes.txt` / `edges.txt` / `SPUM2610.md`，是评估世界观一致性的唯一依据。

二、核心定位

离散关系拓扑体系 + AI 原生同构框架，聚焦「AI 协同基础科学研究」新范式，不追求颠覆主流物理，侧重结构创新与协作模式突破。

五、世界观一致性保证

`knowledge.md` 是 SPUM 世界观的唯一权威评判依据。仓库内所有核心文档在以下方面与 `knowledge.md` 保持一致：

- 核心公理：宇宙是离散关系网络 ⟨P, ε⟩，最小度数 ≥ 2，总边数守恒，时间是离散帧计数
- 演化规则：创生→连接→变化体积→判断→删除（五步帧），几何矛盾驱动，净湮灭效应
- 核心常数：拓扑常数 12（欧拉恒等式强制解），π 被降级为认知压缩因子
- 禁用概念：连续统隐喻（容器、河流、场、波、奇点）、实体本位（独立实体、点粒子、力）
- 本体论用语：节点/空间粒子、边/连接、晶子、永恒粒子、分形约束生长、几何发生学

如有不一致，以 `knowledge.md` 为准。
