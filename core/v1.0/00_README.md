一、项目总览
SPUM2610（空间粒子宇宙模型）是一套以离散关系拓扑为核心的理论体系，核心特征为「文档即代码」——无需微调、无需开发，将本仓库核心文档与对应Prompt提交给任意大模型，即可实现AI与理论的深度共建，涵盖答辩辅助、理论推导、实验分析、科普创作等全场景。本版本为知乎Hackathon参赛归档版本，所有内容开源可追溯、可核验、可复现。
二、核心定位
离散关系拓扑体系 + AI原生同构框架，聚焦「AI协同基础科学研究」新范式，不追求颠覆主流物理，侧重结构创新与协作模式突破。
