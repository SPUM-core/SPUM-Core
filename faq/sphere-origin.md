# Q003：球形几何的来源

> **核心问题**：为何撑出的是"球形"空间单元？球对称（SO(3)）是极强的几何预设。在关系网 ε 尚未撑出空间时，ε 中并不含"距离"或"方向"信息。"球形"这个形态，是 ε 的连接度数（degree）决定的，还是被一个隐藏的"最小作用量"拓扑势所规定？若是后者，这个势本身就是关系，需要被显化，会构成自举。
>
> **一句话结论**：球形不是额外几何预设，是**等度数节点在无方向约束下的唯一无偏拓扑投影形态**。先有饱和等高连接度数，后有球形观测形态。几何是拓扑连接的表象，而非前置前提。不存在隐藏的最小作用量拓扑势。
>
> **权威总纲**：根目录 [`SPUM_系统总纲.md`](../SPUM_系统总纲.md) §2（空间粒子的内禀属性）。图谱对应节点：N019（几何结构是边连接关系的统计投影）。

## 一、归谬起点：假设球对称是预设

假设 SO(3) 球对称是独立于连接关系之外、预先存在的几何属性。

那么：
1. 这个"预先存在的几何"独立于 ⟨P, ε⟩ —— 违背"关系是唯一本原"公理。
2. 为了解释"为何是球形而非立方体/四面体"，必须引入一个额外的"最小作用量"或"熵最大"原则。
3. 该原则本身不是关系，而是外加元规则 → 自举（它必须被显化，而显化又需要另一个原则 → 无限递归）。

**结论：球形不能是预设。它必须能从"仅存在连接度数"这一信息中必然推导出来。**

---

## 二、推导：从等度数到球对称

### 2.1 节点 P 的结构分析

一个节点 P 是一堆实边汇聚的结晶：

- 每一条连接到 P 的边拥有**完全等价拓扑权重**
- 不存在边优先级（没有一条边比另一条"更重"）
- 不存在方向区分（边与边之间没有角度关系，因为角度尚未涌现）

当存在这样一个度数 d 的节点时，d 条边对外延伸。由于它们完全等价，**没有任何理由让其中一条边在延伸方向上区别于另一条**。

### 2.2 无偏等向排布

在无外部参照、无方向信息、无边优先级的条件下，d 条边的向外延伸方式取"均匀等向排布"——因为：

- 任何非均匀排布都隐含了一个区分：某方向与其他方向不同
- 但没有任何关系信息支持这种区分
- **系统的唯一无偏状态就是各向同性**

这就是拉普拉斯的"无差别原理"在拓扑关系场中的版本：在没有偏置信息时，等概率（等方向权重）是唯一无偏选择。

### 2.3 球体 = 等距面的认知投影

当 d 趋向饱和值 κ 时，均匀等向排布的端点构成的轨迹面——在认知投影（L1）下——等价于球体 SO(3) 对称。

```
[L0] 度数 d 的节点，d 条边无偏均匀延伸
    → 端点构成的等距面在 [L1] 认知投影下呈球形
    → SO(3) 对称是连接均匀性的表观结果
    → 不是"空间中有个球"，而是"连接均匀投影为球"
```

## 三、接吻数 12 的必然涌现

球对称的必然推论是三维空间中的**接吻数 12**：

1. 均匀等向延伸 → 等距面为球体
2. 球体的最优密堆排列：每个球体最多与 12 个同样大小的球体相切
3. 相切 = 排他性确认事件的达成
4. 因此 d_max ≥ 12（晶子度数下限必然 ≥ 12）

在代码实现中，`step3_volume` 的 degree→radius 映射正是这一逻辑的数学表达：

```
radius = κ / (κ + degree)
```

度数越大，球体越大，接触邻居越多——反过来又限制了最大度数。这个互锁约束自然涌现出正二十面体拓扑（12顶点），而非某个外力"设置"了接吻数。

## 四、不存在隐藏拓扑势

| 概念 | 经典物理 | SPUM |
|------|----------|------|
| 球形 | 最小表面能 | 等度数无偏等向排布的投影 |
| 最小作用量 | 外加变分原理 | 不需要——无偏排布等价于路径积分无偏方式 |
| 势函数 | 由哈密顿量定义 | 不需要——拓扑压力直接驱动 |
| 角度 | 预设的几何属性 | 在度数 + 均匀排布后派生 |

**"均匀等向排布"不是最小作用量——它是"没有偏置信息时的唯一状态"。** 不需要额外原则来"选择"它。

## 五、逻辑强制链

```
节点 P 由 d 条实边汇聚（N004 → N005）
    → 所有边拓扑权重完全等价
    → 无任何信息支持方向区分
    → 唯一无偏状态：均匀等向排布
    → 端点轨迹构成等距面
    → [L1] 认知投影下等距面 = 球体 SO(3)
    → 球体密堆约束 → 接吻数 12 → 正二十面体
    → 度数越大 → 体积越大 → 拓扑常数 12 涌现
    → 无预设几何、无隐藏势、无自举
```
